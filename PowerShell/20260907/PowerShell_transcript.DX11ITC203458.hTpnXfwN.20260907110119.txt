<section class='section'>
    <h2>Teorija: Profesionāli rīki</h2>
    <div class='logic-box'>
<p><b>Visual Studio Code (VS Code)</b> ir koda redaktors, nevis teksta apstrādes rīks (kā Word). Tas saprot koda struktūru un palīdz to rakstīt ar krāsu izcelšanu un paplašinājumiem. <b>GitHub</b> ir koda "mākonis", kas glabā visas tavas izmaiņas (versijas). Tas ļauj tev piekļūt savam darbam no jebkura datora un droši iesniegt mājasdarbus skolotājam.</p>
    <p><b>Git</b> glabā izmaiņu vēsturi tavā datorā; tam nav atsevišķa konta, kurā pieteikties. Lai nosūtītu darbu uz <b>GitHub</b>, dosi VS Code piekļuvi savam GitHub kontam, apstiprinot pieslēgšanos pārlūkā. Pieslēgšanās tikai GitHub mājaslapā vēl nepieslēdz VS Code.</p>
    <p>Failu sagatavošanu, commit un push veiksi VS Code <b>Source Control</b> sadaļā. Tikai commit autora sākotnējai iestatīšanai izmantosi divas termināļa komandas. <b>Ctrl+S</b> saglabā failu datorā; uz GitHub izmaiņas nosūta <b>Publish to GitHub</b> vai <b>Push</b>.</p>
    <p>Svarīgākie jēdzieni:</p>
        <ul>
            <li><b>Repository (Repo):</b> Tava projekta mape mākonī.</li>
            <li><b>Commit:</b> Izmaiņu "nofotografēšana" un saglabāšana ar komentāru.</li>
            <li><b>Push:</b> Saglabāto izmaiņu nosūtīšana no lokālā datora uz GitHub serveri.</li>
            <li><b>Source Control:</b> VS Code sadaļa, kur vari saglabāt izmaiņas, publicēt repozitoriju un sinhronizēt darbu ar GitHub.</li>
        </ul>
    </div>
</section>

<section class='section'>
    <h2>Praktiskie uzdevumi</h2>
    <div class='logic-box'>
        <h3>1. uzdevums - Izveido projekta mapi un sagatavo Git</h3>
        <p>Beigās tavā datorā būs mape <code>spele</code>, kas atvērta VS Code, un Git zinās tavu commit autora vārdu. VS Code pieslēgšanos GitHub pabeigsi 2. uzdevumā, publicējot pirmo failu.</p>
        <ol class="step-list">
            <li><b>Atver</b> Microsoft store un lejuplādē Visual Studio Code.</li>
            <li><b>Atver</b> datorā VS Code. Ja VS Code vai Git vēl nav uzstādīts, izmanto saites sadaļā “Pirms sāc”. Pēc Git instalēšanas aizver un atver VS Code no jauna.</li>
            <li><b>Atver</b> <a href="https://github.com/">GitHub mājaslapu</a> un pieslēdzies savam kontam. Ja konta nav, izveido to un apstiprini e-pastu.</li>
            <li><b>Izveido</b> uz darbvirsmas mapi ar nosaukumu <code>spele</code> (bez garumzīmēm un atstarpēm).</li>
            <li><b>Atver</b> šo mapi VS Code: File → Open Folder → <code>spele</code>.</li>
            <li><b>Atver</b> Source Control sadaļu kreisajā rīkjoslā (ikona ar sazarojumu) un nospied <b>Initialize Repository</b>. Ja Git nav pieejams, pārbaudi tā instalēšanu kopā ar skolotāju.</li>
            <li><b>Atver</b> VS Code izvēlni <b>Terminal → New Terminal</b>. Terminālim jāatrodas mapē <code>spele</code>. Izpildi zemāk redzamās komandas pa vienai, aizstājot vārdu un e-pastu ar saviem datiem.</li>
        </ol>
        <pre><code>git config user.name "Vārds Uzvārds"
git config user.email "tavs@pasts.lv"</code></pre>
        <p>Šie iestatījumi attiecas uz šo projektu un norāda commit autoru; tie nav GitHub pieteikšanās dati. E-pasta vietā vari izmantot GitHub <b>Settings → Emails</b> redzamo privāto <code>noreply</code> adresi. Paroli šajās komandās neraksti.</p>
        <p class="done-when"><b>Gatavs, kad:</b> VS Code ir atvērta mape <code>spele</code>, Git krātuve ir inicializēta un abas autora iestatīšanas komandas izpildītas bez kļūdas.</p>
    </div>
    <div class='logic-box'>
        <h3>2. uzdevums - Publicē pirmo failu GitHub</h3>
        <p>Beigās tavs fails <code>index.html</code> būs redzams GitHub lapā jebkurā datorā.</p>
        <ol class="step-list">
            <li><b>Izveido</b> mapē <code>spele</code> failu <code>index.html</code> ar rindu <code>&lt;h1&gt;Mana spēle&lt;/h1&gt;</code> un saglabā (Ctrl+S).</li>
            <li><b>Atver</b> Source Control sadaļu un nospied Initialize Repository, ja VS Code to piedāvā.</li>
            <li><b>Nospied</b> plusa ikonu pie <code>index.html</code> vai Stage All Changes, lai sagatavotu failu saglabāšanai.</li>
            <li><b>Ieraksti</b> commit ziņu <code>Add game page</code> un nospied Commit.</li>
            <li><b>Nospied</b> <b>Publish to GitHub</b>. Ja pogu neredzi, atver <b>View → Command Palette</b>, ieraksti <code>Publish to GitHub</code> un izvēlies šo komandu. Krātuvi GitHub mājaslapā iepriekš neveido — VS Code to izveidos publicēšanas laikā.</li>
            <li id="github-pieslegsanas"><b>Pieslēdz VS Code savam GitHub kontam:</b> ja parādās piekļuves pieprasījums, nospied <b>Allow</b> vai <b>Sign in</b>. Atvērtajā pārlūkā pārbaudi, ka izmantots tavs GitHub konts, pieslēdzies un apstiprini VS Code piekļuvi ar <b>Authorize Visual Studio Code</b>, ja šāda poga tiek piedāvāta. Ja kontam ieslēgta divu faktoru autentifikācija, izpildi arī to.</li>
            <li><b>Atļauj pārlūkam atvērt Visual Studio Code</b>, ja tas jautā, un atgriezies redaktorā. Kontu izvēlnē (<b>Accounts</b>, cilvēciņa ikona) pārbaudi savu GitHub lietotājvārdu. Ja VS Code jau ir pieslēgts tavam kontam, atkārtota pieteikšanās var nebūt vajadzīga. Ja publicēšana tika pārtraukta, vēlreiz izvēlies <b>Publish to GitHub</b>.</li>
            <li><b>Izvēlies</b> repozitorija nosaukumu <code>spele</code> un redzamību Public, ja skolotājs nav norādījis citādi.</li>
            <li><b>Ja tiek piedāvāta failu izvēle,</b> pārliecinies, ka ir atlasīts <code>index.html</code>, un apstiprini publicēšanu. Sagaidi paziņojumu par veiksmīgu publicēšanu un izvēlies <b>Open on GitHub</b> vai pārlūkā atver <code>https://github.com/TAVS-LIETOTAJVARDS/spele</code>, aizstājot lietotājvārdu ar savu.</li>
        </ol>
        <p><b>Publish to GitHub</b> izveido attālo krātuvi, savieno to ar projekta mapi datorā un nosūta pirmo commit. Nākamās izmaiņas sūtīsi ar <b>Push</b>.</p>
        <p class="done-when"><b>Gatavs, kad:</b> savā GitHub repozitorijā <code>spele</code> redzi failu <code>index.html</code> ar rindu <code>&lt;h1&gt;Mana spēle&lt;/h1&gt;</code> un commit ziņu <code>Add game page</code>.</p>
    </div>
    <div class='logic-box'>
        <h3>3. uzdevums - Pievieno otro commit un izlasi vēsturi</h3>
        <p>Beigās GitHub sadaļā "Commits" būs divi ieraksti, un tu redzēsi, kas mainījās katrā.</p>
        <ol class="step-list">
            <li><b>Pievieno</b> failā <code>index.html</code> rindu <code>&lt;p&gt;Vadi spēli ar bultiņu taustiņiem.&lt;/p&gt;</code> un saglabā.</li>
            <li><b>Atver</b> Source Control sadaļu un sagatavo <code>index.html</code> izmaiņas ar plusa ikonu.</li>
            <li><b>Ieraksti</b> commit ziņu <code>Add control hint</code> un nospied Commit.</li>
            <li><b>Source Control izvēlnē “…” izvēlies Push</b>, lai nosūtītu izmaiņas uz GitHub. Vari arī izmantot <b>Sync Changes</b>, kas vispirms saņem attālās izmaiņas un tad nosūta tavējās. Ja tiek prasīta pieslēgšanās, izpildi <a href="#github-pieslegsanas">2. uzdevuma pieslēgšanās soļus</a>. Sagaidi darbības pabeigšanu bez kļūdas.</li>
            <li><b>Atver</b> GitHub repozitoriju un noklikšķini uz saraksta "Commits".</li>
            <li><b>Noklikšķini</b> uz jaunākā commit - zaļā krāsā jābūt tieši tai rindai, ko pievienoji.</li>
            <li><b>Pieraksti</b> vienu secinājumu: ar ko Commit atšķiras no Push.</li>
        </ol>
        <p class="done-when"><b>Gatavs, kad:</b> GitHub "Commits" sarakstā ir divi ieraksti un jaunākajā zaļā krāsā redzama pievienotā <code>&lt;p&gt;</code> rinda.</p>
    </div>
    <div class='logic-box'>
        <h3>Papildu uzdevums - Pievieno README ar projekta aprakstu</h3>
        <p>Beigās tava repozitorija sākumlapā būs redzams spēles nosaukums un īss apraksts.</p>
        <ol class="step-list">
            <li><b>Izveido</b> mapē <code>spele</code> failu <code>README.md</code>.</li>
            <li><b>Ieraksti</b> pirmajā rindā <code># Mana spēle</code> ar savu spēles nosaukumu.</li>
            <li><b>Pievieno</b> zem tā divus teikumus par to, ko spēlētājs darīs.</li>
            <li><b>Sagatavo</b> <code>README.md</code> izmaiņas Source Control sadaļā.</li>
            <li><b>Ieraksti</b> commit ziņu <code>Add project README</code>, nospied Commit un pēc tam Sync Changes.</li>
            <li><b>Pārlādē</b> GitHub lapu.</li>
        </ol>
        <p class="done-when"><b>Gatavs, kad:</b> GitHub repozitorija sākumlapā zem failu saraksta redzams tavs spēles nosaukums un apraksts.</p>
    </div>
</section>
<section class='section'>
    <h2>Biežākās kļūdas (un kā tās labot):</h2>
    <div class='logic-box'>
<ul>
        <li><b>Fails neparādās GitHub:</b> Pārliecinies, vai pēc Commit nospiedi Push vai Sync Changes.</li>
        <li><b>Accounts izvēlnē nav Sign in to GitHub:</b> Sāc <b>Publish to GitHub</b> no komandu paletes, kā norādīts 2. uzdevumā; šī darbība vajadzības gadījumā atvērs pieslēgšanos. Settings Sync sinhronizē redaktora iestatījumus, nevis projekta failus.</li>
        <li><b>Pārlūks neatgriežas VS Code vai pieteikšanās atcelta:</b> Atļauj atvērt Visual Studio Code un atkārto publicēšanu vai Push. Ja VS Code piedāvā citu pieteikšanās veidu vai koda ievadi, seko tā norādēm.</li>
        <li><b>Commit prasa user.name un user.email:</b> Izpildi 1. uzdevuma autora iestatīšanas komandas projekta terminālī un vēlreiz nospied Commit.</li>
        <li><b>Push rāda Authentication failed vai Permission denied:</b> Pārbaudi, vai VS Code Accounts izvēlnē un pārlūkā izmantots tavs GitHub konts un krātuve pieder tev. Ja redzams cits konts, izraksties no tā un pieslēdzies savam. Ja saglabājusies cita lietotāja piekļuve datorā, lūdz skolotāja palīdzību. GitHub konta paroli Git HTTPS paroles pieprasījumā neizmanto; atjauno pieslēgšanos pārlūkā.</li>
        <li><b>VS Code neatpazīst Git:</b> Pasauc skolotāju, lai pārbaudītu datora uzstādījumus.</li>
        <li><b>Krātuve spele jau eksistē:</b> Ja tā ir iepriekš izveidota krātuve, lūdz skolotājam palīdzēt to atvērt ar Clone Repository; ja šis ir jauns projekts, publicējot izvēlies citu nosaukumu, piemēram, <code>spele-2</code>.</li>
    </ul>
    </div>
</section>

    <h2>VS Code darbību secība bez termināļa</h2>
    <p>Pēc vienreizējās Git iestatīšanas: <b>Saglabā failu → Stage (+) → Commit → Push → pārbaudi GitHub</b>. Pirmajā reizē Push vietā izmanto <b>Publish to GitHub</b> un apstiprini pieslēgšanos.</p>
    <div class='code-example'>
        <ol class="step-list">
            <li><b>Source Control</b> sadaļā apskati izmainītos failus.</li>
            <li><b>Sagatavo</b> vajadzīgos failus ar plusa ikonu.</li>
            <li><b>Ieraksti</b> īsu commit ziņu, piemēram, <code>Add control hint</code>.</li>
            <li><b>Nospied</b> Commit.</li>
            <li><b>Nospied</b> Sync Changes vai Push.</li>
            <li><b>Pārbaudi</b> GitHub repozitorijā, vai faili un "Commits" saraksts ir atjaunoti.</li>
        </ol>
        <div class='result'>
            GitHub repozitorija lapā fails <code>index.html</code> ir atjaunots, un "Commits" sarakstā ir jauns ieraksts ar tavu ziņu.
