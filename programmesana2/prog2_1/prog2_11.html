1. tēma / 1.1

1.1 Godot instalācija un projekta sagatavošana

Stundas uzdevums: Sagatavot Godot .NET Pong projektu, palaist galveno scēnu un saglabāt sākumpunktu GitHub.

SR 2.4.12. Programmēšanas vide SR 3.1.2. Darba vides riski SR 2.3.1. Datorikas nozares attīstība padziļinātos projektos

80 min plāns: Ievads (~10 min) · darba vide (~20 min) · pirmais projekts (~25 min) · Git saglabāšana (~20 min) · pašpārbaude (~5 min).

Pirms sāc: šī ir pirmā Godot nodarbība. Vajadzīgs dators, internets, iespēja uzstādīt programmas un skolotāja norādīts GitHub konts. Šajā tēmā visas sešas stundas turpināsi vienu Pong projektu.

Darba ritms: pēc katra uzdevuma saglabā un pārbaudi rezultātu. Kad projektam pievienots C# skripts, pirms palaišanas nospied Build. Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Ko izveidosi sešās stundās

Divi spēlētāji ar vienu tastatūru vada raketes un atsit bumbu. Par pretinieka neatsistu bumbu saņem punktu; pirmais līdz 5 punktiem uzvar. Spēle parāda vadību, gaida Space pirms serves un ļauj ar R sākt jaunu partiju.

1.1 sagatavosi projektu; 1.2 izveidosi redzamus objektus; 1.3 pārbaudīsi C# vidi; 1.4 aprakstīsi raketi ar mainīgajiem; 1.5 ieviesīsi kustību un atlēkšanu; 1.6 pabeigsi spēles ciklu un savu noformējumu. Tu izvēlēsies nosaukumu, komandas, pasauli un sacensības stāstu.

Teorija: kur atrodas projekts

Godot .NET ir spēles redaktors ar C# atbalstu. .NET SDK kompilē C# kodu; to pārbaudīsim 1.3 stundā. VS Code ir koda redaktors, Git saglabā izmaiņu vēsturi, bet GitHub glabā krātuves kopiju internetā.

project.godot glabā iestatījumus; .tscn faili — scēnas; .cs faili — C# klases. Ceļš res:// nozīmē tava projekta mapi. Mape .godot ir ģenerēta kešatmiņa.

1. uzdevums -

Atver Godot .NET un izveido Pong projektu

  1. Atver Godot lejupielādi un izvēlies .NET variantu savai operētājsistēmai. Kursa piemērs pārbaudīts ar Godot 4.7.2 .NET; klasē izmantojiet skolotāja izvēlētu vienotu Godot 4 .NET versiju.
  2. Windows vai Linux izpako visu lejupielādēto arhīvu un palaid tajā esošo Godot izpildfailu; macOS atver lejupielādēto lietotni. Saglabā arī blakus esošo GodotSharp mapi, ja tā ir pievienota.
  3. Project Manager izvēlies New Project, nosaukums Pong, tukša projekta mape, piemēram, Documents/Godot/Pong. Izvēlies Compatibility renderētāju un Create & Edit.
  4. Uzstādi vai pārbaudi VS Code un Git. VS Code terminālī git --version jāparāda versija. Ja tikko uzstādīji Git, atver VS Code no jauna.

Gatavs, kad: atvērts tieši Pong projekts Godot .NET redaktorā un Git ir pieejams.

2. uzdevums -

Izveido un palaid pirmo scēnu

  1. Atrodi Scene paneli (mezglu koks), FileSystem (faili), 2D skatlogu, Inspector (īpašības) un Output (izdruka). README.md vēlāk pieraksti katram vienu pielietojumu.
  2. FileSystem panelī ar labo pogu uz res:// izveido mapes Scenes un Scripts. Scene panelī izvēlies 2D Scene; saknes Node2D nosauc Main. Saglabā res://Scenes/Main.tscn.
  3. Project → Project Settings → Display → Window: Viewport Width = 1280, Viewport Height = 720, Stretch Mode = canvas_items, Stretch Aspect = keep. Ja kāds lauks nav redzams, ieslēdz Advanced Settings.
  4. Nospied F5, izvēlies Select Current vai norādi Main.tscn kā galveno scēnu. Tukšs spēles logs šodien ir pareizs rezultāts — vēl nav redzamu objektu. Apturi ar F8.
  5. Aizver un atkal atver projektu no Project Manager. Pārbaudi, ka Main.tscn un loga iestatījumi ir saglabāti. F5 palaiž galveno scēnu; F6 — pašlaik redaktorā atvērto scēnu.

Gatavs, kad: F5 atver spēles logu, un pēc projekta atkārtotas atvēršanas var turpināt tajā pašā scēnā.

3. uzdevums -

Saglabā sākumpunktu GitHub

  1. VS Code izvēlies File → Open Folder un atver tieši mapi, kurā atrodas project.godot. Izveido README.md ar projekta nosaukumu, Godot versiju un piecu editora paneļu aprakstu.
  2. Izveido .gitignore vai papildini esošo: katru savā rindā ieraksti .godot/, bin/, obj/, *.tmp.
  3. Atver Source Control. Ja krātuves vēl nav, izvēlies Initialize Repository. Pārskati izmaiņas: jābūt project.godot, Scenes/Main.tscn, README.md un .gitignore, bet ne kešatmiņas saturam.
  4. Pievieno izmaiņas ar Stage All Changes, ievadi ziņu “Pong projekta sākums” un veic Commit. Ja Git prasa autora vārdu un e-pastu, norādi savus vai skolotāja noteiktos Git iestatījumus; tad atkārto Commit.
  5. Izvēlies Publish to GitHub, pieraksties un izveido krātuvi pong-godot ar skolotāja prasīto pieejamību. Ja projektam jau ir GitHub attālā krātuve, izmanto Push/Sync Changes. Pārlūkā pārbaudi, ka faili ir augšupielādēti.

Detalizētās darbības: VS Code versiju pārvaldības pamācība. Saglabāšanas darbības turpmākajās stundās atkārto tajā pašā krātuvē.

Gatavs, kad: GitHub redzams pirmais commit un Main.tscn; kešatmiņa nav iekļauta. Privātai krātuvei skolotājam ir piešķirta piekļuve.

Papildu uzdevums — izdomā spēles pasauli

README.md ieraksti vienu teikumu par savu spēles ieceri: kas ir abas komandas un par ko tās sacenšas? Piemēram, zemūdenes sargā pērli vai kosmosa kuģi sacenšas par enerģiju.

Ko sagatavo

Stundas mērķis: ir atverams Pong projekts, galvenā scēna un pirmā versija GitHub.

GitHub krātuvē jābūt:

  1. project.godot, Scenes/Main.tscn, .gitignore.
  2. README.md: Godot versija un piecu redaktora paneļu pielietojums; palaistā loga ekrānuzņēmums.

Saglabā projekta iestatījumus, izveidotās scēnas un resursus; no 1.3 stundas arī C# skriptus un projekta failus (.csproj u.c.). .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.

Kā iesniedz: veic commit un push. Skolotāja norādītajā vietā iesniedz GitHub krātuves saiti; README.md un pārbaudes pierādījumiem jābūt krātuvē.
