Teorija: izstrādes rīki un projekta failu struktūra

Izstrādes vides rīku sadarbība

Mūsdienu programmatūras izstrādē vienas universālas programmas vietā parasti sadarbojas vairāki specializēti rīki — līdzīgi kā video studijā atsevišķi strādā ar kadru kompozīciju, scenārija tekstu un materiālu arhīvu:

  • Godot .NET — vizuālais dzinējs un redaktors ar C# atbalstu, kurā veido ekrāna objektus, fiziku un saskarni.
  • VS Code — pirmkoda redaktors, kurā raksta un rediģē skriptus un projekta dokumentāciju.
  • .NET SDK (programmatūras izstrādes komplekts) — rīku kopums ar kompilatoru, kas pārtulko cilvēkam lasāmo C# kodu datoram izpildāmā formā.
  • Git — lokāla versiju pārvaldības sistēma, kas fiksē izmaiņu vēsturi tavā datorā kā kontrolpunktus, ļaujot droši eksperimentēt un vajadzības gadījumā atgriezties pie iepriekšējās versijas.
  • GitHub — attālināta mākoņkrātuve internetā (līdzīgi mākoņdiskam, bet pielāgota pirmkodam un Git vēsturei), kas glabā projekta kopiju un ļauj strādāt no dažādām ierīcēm.

Projekta mape, failu veidi un ceļš res://

Katrs Godot projekts atrodas savā mapē. Lai failu adreses darbotos vienādi jebkurā datorā neatkarīgi no tā, kurā diskā vai lietotāja mapē projekts saglabāts, Godot izmanto prefiksu res:// (resources) — tas vienmēr apzīmē projekta saknes mapi (kā norāde „no ēkas galvenās ieejas”, nevis pilna pilsētas adrese).

Projekta mapē katram failu veidam ir sava loma: project.godot glabā galvenos projekta iestatījumus, .tscn faili — scēnas (objektu uzbūvi), bet .cs faili — C# class (klases) ar programmas loģiku. Savukārt mape .godot/ ir dzinēja automātiski ģenerēta cache (kešatmiņa) ātrākai ielādei; tāpat kā pārlūkprogrammas pagaidu failus, to jebkurā brīdī var atjaunot automātiski, tāpēc versiju vēsturē to neiekļauj:

ProjektaMape/             ← Godot vidē šī sakne ir res://
├── project.godot         ← res://project.godot (iestatījumi)
├── .gitignore            ← Git ignorējamās mapes (.godot/, bin/, obj/)
├── Scenes/
│   └── GalvenaScena.tscn ← res://Scenes/GalvenaScena.tscn (scēna)
├── Scripts/
│   └── ObjektaLogika.cs  ← res://Scripts/ObjektaLogika.cs (C# klase)
└── .godot/               ← automātiska cache (Git vēsturē neiekļauj)

1. uzdevums

Atver Godot .NET un izveido Pong projektu

Kur strādāt: Godot Project Manager logā izveido jaunu projektu Pong (Godot tajā automātiski izveidos failu project.godot). Komandu git --version pārbaudi VS Code terminālī.

  1. Lejupielādē Godot 4 .NET: atver Godot lejupielādes lapu un izvēlies Godot Engine - .NET versiju savai operētājsistēmai (kursa piemērs veidots ar Godot 4.7.2 .NET; C# kompilēšanai vajadzīgo .NET SDK pārbaudīsim 1.3. stundā).
  2. Izpako un palaid Godot .NET: Windows vai Linux sistēmā izpako visu lejupielādēto arhīvu vienā mapē (saglabājot blakus esošo GodotSharp mapi) un palaid Godot izpildfailu; macOS sistēmā atver lejupielādēto lietotni.
  3. Izveido projektu Pong: Godot sākuma logā (Project Manager) spied Create (vai New Project), laukā Project Name ieraksti Pong, izvēlies tukšu projekta mapi (piemēram, Documents/Godot/Pong), kā renderētāju izvēlies Compatibility un spied Create & Edit.
  4. Pārbaudi VS Code un Git: pārliecinies, ka datorā ir uzstādīts Visual Studio Code un Git. Atver VS Code, augšējā izvēlnē izvēlies Terminal → New Terminal un izpildi komandu git --version (terminālī jāparādās Git versijas numuram).

Gatavs, kad: Godot .NET redaktorā ir atvērts projekts Pong (ar failu project.godot) un VS Code terminālī darbojas git --version.

2. uzdevums

Izveido un palaid pirmo scēnu

Kur strādāt: Godot redaktorā izveido mapes Scenes/ un Scripts/, saglabā galveno scēnu Scenes/Main.tscn un iestati loga izmēru Project Settings logā (saglabājas failā project.godot).

Projekta struktūra pēc 2. uzdevuma:

res:// (projekta Pong saknes mape)
├── project.godot (loga izmērs 1280×720, galvenā scēna Main.tscn)
├── Scenes/
│   └── Main.tscn (saknes mezgls: Main (Node2D))
└── Scripts/      (mape C# skriptiem nākamajās stundās)
  1. Iepazīsti 5 galvenos Godot redaktora paneļus: atrodi ekrānā visus piecus tabulā zemāk aprakstītos paneļus (3. uzdevumā to nozīmi pierakstīsi README.md failā).
  2. Izveido mapes Scenes un Scripts: FileSystem panelī (kreisajā apakšējā stūrī) ar labo peles pogu klikšķini uz res:// → Create New → Folder un izveido mapi Scenes. Tāpat zem res:// izveido otru mapi Scripts.
  3. Izveido galveno scēnu Scenes/Main.tscn: Scene panelī (kreisajā augšējā stūrī) spied 2D Scene. Izveidotajam saknes mezglam Node2D nospied F2, pārdēvē to par Main un ar Ctrl+S saglabā scēnu mapē res://Scenes/Main.tscn.
  4. Iestati spēles loga izmēru (project.godot): augšējā izvēlnē atver Project → Project Settings → Display → Window. Sadaļā Size iestati Viewport Width = 1280 un Viewport Height = 720. Sadaļā Stretch iestati Mode = canvas_items un Aspect = keep (ja kāds lauks nav redzams, ieslēdz slēdzi Advanced Settings).
  5. Palaid projektu ar F5: nospied Run Project (F5) un apstiprini Select Current, lai Scenes/Main.tscn kļūtu par projekta galveno scēnu. Atvērsies tukšs 1280 × 720 spēles logs — apturi to ar Stop (F8). (Atceries: F5 vienmēr palaiž galveno scēnu, bet F6 — pašlaik atvērto scēnu.)
Panelis Godot redaktorāKur atrodasKam to izmanto

FileSystemKreisajā apakšējā pusēRāda visas projekta mapes un failus zem res://.
2D ViewportCentrā (slēdzis 2D augšā)Vizuālais spēles laukums, kurā izkārto 2D objektus.

Gatavs, kad: nospiežot F5, atveras 1280 × 720 spēles logs ar scēnu Scenes/Main.tscn, un iestatījumi saglabājas arī pēc projekta aizvēršanas un atvēršanas.

3. uzdevums

Saglabā sākumpunktu GitHub

Kur strādāt: VS Code redaktorā atver projekta saknes mapi (kur atrodas project.godot) un tajā izveido failus README.md un .gitignore.

  1. Izveido failu README.md projekta saknē: VS Code izvēlies File → Open Folder un atver savu Pong projekta mapi (tā, lai kreisajā failu sarakstā redzētu project.godot un mapi Scenes). Izveido jaunu failu README.md un ieraksti tajā projekta nosaukumu, Godot .NET versiju un īsu 5 redaktora paneļu aprakstu.
  2. Izveido vai papildini failu .gitignore projekta saknē: blakus project.godot izveido failu .gitignore un ieraksti tajā šādas četras rindas, lai Git neiekļautu automātiski ģenerēto kešatmiņu: 
    .godot/
bin/
obj/
*.tmp
  3. Inicializē Git krātuvi: VS Code kreisajā joslā atver cilni Source Control (vai spied Ctrl+Shift+G). Ja poga Initialize Repository ir redzama, nospied to. Pārbaudi sarakstu Changes: tajā jābūt project.godot, Scenes/Main.tscn, README.md un .gitignore, bet nedrīkst būt mapei .godot/.
  4. Izveido pirmo Commit: pievieno visus failus ar Stage All Changes (+), ievades laukā ieraksti ziņu Pong projekta sākums un nospied Commit (ja Git prasa user.name un user.email, ievadi tos terminālī un atkārto Commit).
  5. Publicē projektu GitHub: nospied Publish Branch / Publish to GitHub, pieraksties savā GitHub kontā un izveido krātuvi pong-godot. Atver krātuvi pārlūkprogrammā un pārliecinies, ka tajā ir redzami visi četri faili.

Detalizēta palīdzība: VS Code versiju pārvaldības pamācība. Turpmākajās stundās izmaiņas saglabāsi šajā pašā krātuvē ar Commit un Push / Sync Changes.

Gatavs, kad: GitHub krātuvē ir redzams pirmais commit ar project.godot, Scenes/Main.tscn, README.md un .gitignore (bez .godot/ mapes).

Papildu uzdevums un README.md paraugs - izdomā spēles pasauli

Kur strādāt: Spēles ieceri pievieno projekta saknes failā README.md.

Failā README.md pievieno vienu teikumu par savu spēles ieceri: kas ir abas komandas un par ko tās sacenšas (piemēram, zemūdenes sargā pērli vai kosmosa kuģi sacenšas par enerģijas kodolu)? Šo stāstu iedzīvināsi 1.6. stundā.

# Pong (Godot 4 .NET)

- **Godot versija:** Godot 4.x .NET
- **Spēles iecere:** Divas kosmosa stacijas sacenšas par enerģijas kodolu.

## Godot redaktora paneļi
1. **Scene** - rāda atvērtās scēnas mezglu koku (Scene Tree).
2. **FileSystem** - rāda projekta failus un mapes (`res://`).
3. **2D Viewport** - vizuālais 2D redaktors objektu izvietošanai.
4. **Inspector** - ļauj mainīt izvēlētā mezgla īpašības.
5. **Output** - izvada `GD.Print` ziņojumus un kļūdas.

Ko sagatavo

Stundas mērķis: ir atverams Pong projekts, galvenā scēna un pirmā versija GitHub.

GitHub krātuvē jābūt:

  • project.godot, Scenes/Main.tscn, .gitignore.
  • README.md: Godot versija un piecu redaktora paneļu pielietojums; palaistā loga ekrānuzņēmums.

Saglabā projekta iestatījumus, izveidotās scēnas un resursus; no 1.3 stundas arī C# skriptus un projekta failus (.csproj u.c.). .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.

Kā iesniedz: veic commit un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā iesniedz GitHub krātuves saiti; README.md un pārbaudes pierādījumiem jābūt krātuvē.
