1. tēma / 1.1

1.1 Godot installation (instalācija) un project (projekta) sagatavošana

Stundas uzdevums: Sagatavot Godot .NET Pong project (projektu), palaist main scene (galveno scēnu) un saglabāt sākumpunktu GitHub.

SR 2.4.12. Development environment (programmēšanas vide) SR 3.1.2. Darba vides riski SR 2.3.1. Computer science (datorikas) nozares attīstība padziļinātos project (projektos)

80 min plāns: Ievads (~10 min) · darba vide (~20 min) · pirmais project (projekts) (~25 min) · Git save (saglabāšana) (~20 min) · pašpārbaude (~5 min).

Pirms sāc: šī ir pirmā Godot nodarbība. Vajadzīgs computer (dators), internet (internets), iespēja uzstādīt program (programmas) un skolotāja norādīts GitHub account (konts). Šajā tēmā visas sešas stundas turpināsi vienu Pong project (projektu).

Darba ritms: pēc katra uzdevuma saglabā un pārbaudi rezultātu. Kad project (projektam) pievienots C# script (skripts), pirms palaišanas nospied Build (būvēt projektu). Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Ko izveidosi sešās stundās

Divi spēlētāji ar vienu keyboard (tastatūru) vada raketes un atsit bumbu. Par pretinieka neatsistu bumbu saņem punktu; pirmais līdz 5 punktiem uzvar. Spēle parāda vadību, gaida Space pirms serves un ļauj ar R sākt jaunu partiju.

1.1 sagatavosi project (projektu); 1.2 izveidosi redzamus object (objektus); 1.3 pārbaudīsi C# vidi; 1.4 aprakstīsi raketi ar variable (mainīgajiem); 1.5 ieviesīsi kustību un atlēkšanu; 1.6 pabeigsi game loop (spēles ciklu) un savu noformējumu. Tu izvēlēsies nosaukumu, komandas, pasauli un sacensības stāstu.

Teorija: kur atrodas project (projekts)

Godot .NET ir spēles editor (redaktors) ar C# atbalstu. .NET SDK (programmatūras izstrādes komplekts) kompilē C# code (kodu); to pārbaudīsim 1.3 stundā. VS Code ir code editor (koda redaktors), Git saglabā izmaiņu vēsturi, bet GitHub glabā repository (krātuves) kopiju internet (internetā).

project.godot glabā settings (iestatījumus); .tscn file (faili) — scene (scēnas); .cs file (faili) — C# class (klases). Path (ceļš) res:// nozīmē tava project (projekta) folder (mapi). Folder (mape) .godot ir ģenerēta cache (kešatmiņa).

1. uzdevums -

Atver Godot .NET un izveido Pong project (projektu)

  1. Atver Godot download (lejupielādi) un izvēlies .NET variantu savai operating system (operētājsistēmai). Kursa piemērs pārbaudīts ar Godot 4.7.2 .NET; klasē izmantojiet skolotāja izvēlētu vienotu Godot 4 .NET version (versiju).
  2. Windows vai Linux izpako visu lejupielādēto archive (arhīvu) un palaid tajā esošo Godot executable (izpildfailu); macOS atver lejupielādēto application (lietotni). Saglabā arī blakus esošo GodotSharp folder (mapi), ja tā ir pievienota.
  3. Project Manager (projektu pārvaldnieks) izvēlies New Project (jauns projekts), nosaukums Pong, tukša project (projekta) folder (mape), piemēram, Documents/Godot/Pong. Izvēlies Compatibility (saderības režīms) renderer (renderētāju) un Create & Edit (izveidot un rediģēt).
  4. Uzstādi vai pārbaudi VS Code un Git. VS Code terminal (terminālī) git --version jāparāda version (versija). Ja tikko uzstādīji Git, atver VS Code no jauna.

Gatavs, kad: atvērts tieši Pong project (projekts) Godot .NET editor (redaktorā) un Git ir pieejams.

2. uzdevums -

Izveido un palaid pirmo scene (scēnu)

  1. Atrodi Scene (scēna) panel (paneli), FileSystem (failu sistēma), 2D viewport (skatlogu), Inspector (īpašību panelis) un Output (izvade). README.md vēlāk pieraksti katram vienu pielietojumu.
  2. FileSystem (failu sistēma) panel (panelī) ar labo button (pogu) uz res:// izveido folder (mapes) Scenes un Scripts. Scene (scēna) panel (panelī) izvēlies 2D Scene (2D scēna); root (saknes) Node2D (2D mezgls) nosauc Main. Saglabā res://Scenes/Main.tscn.
  3. Project (projekts) → Project Settings (projekta iestatījumi) → Display (attēlojums) → Window (logs): Viewport Width (skatloga platums) = 1280, Viewport Height (skatloga augstums) = 720, Stretch Mode (izstiepšanas režīms) = canvas_items, Stretch Aspect (izstiepšanas proporcijas) = keep. Ja kāds field (lauks) nav redzams, ieslēdz Advanced Settings (papildu iestatījumi).
  4. Nospied F5, izvēlies Select Current (izvēlēties pašreizējo) vai norādi Main.tscn kā main scene (galveno scēnu). Tukšs spēles window (logs) šodien ir pareizs rezultāts — vēl nav redzamu object (objektu). Apturi ar F8.
  5. Aizver un atkal atver project (projektu) no Project Manager (projektu pārvaldnieks). Pārbaudi, ka Main.tscn un window (loga) settings (iestatījumi) ir saglabāti. F5 palaiž main scene (galveno scēnu); F6 — pašlaik editor (redaktorā) atvērto scene (scēnu).

Gatavs, kad: F5 atver spēles window (logu), un pēc project (projekta) atkārtotas atvēršanas var turpināt tajā pašā scene (scēnā).

3. uzdevums -

Saglabā sākumpunktu GitHub

  1. VS Code izvēlies File (fails) → Open Folder (atvērt mapi) un atver tieši folder (mapi), kurā atrodas project.godot. Izveido README.md ar project (projekta) nosaukumu, Godot version (versiju) un piecu editor (redaktora) panel (paneļu) aprakstu.
  2. Izveido .gitignore vai papildini esošo: katru savā rindā ieraksti .godot/, bin/, obj/, *.tmp.
  3. Atver Source Control (versiju pārvaldība). Ja repository (krātuves) vēl nav, izvēlies Initialize Repository (izveidot krātuvi). Pārskati izmaiņas: jābūt project.godot, Scenes/Main.tscn, README.md un .gitignore, bet ne cache (kešatmiņas) saturam.
  4. Pievieno izmaiņas ar Stage All Changes (sagatavot visas izmaiņas), ievadi ziņu “Pong project (projekta) sākums” un veic Commit (izmaiņu fiksējums). Ja Git prasa autora vārdu un email (e-pastu), norādi savus vai skolotāja noteiktos Git settings (iestatījumus); tad atkārto Commit (izmaiņu fiksējums).
  5. Izvēlies Publish to GitHub (publicēt GitHub), pieraksties un izveido repository (krātuvi) pong-godot ar skolotāja prasīto pieejamību. Ja project (projektam) jau ir GitHub remote repository (attālā krātuve), izmanto Push (nosūtīšana uz attālo krātuvi)/Sync Changes (sinhronizēt izmaiņas). Browser (pārlūkā) pārbaudi, ka file (faili) ir augšupielādēti.

Detalizētās darbības: VS Code version control (versiju pārvaldības) pamācība. Save (saglabāšanas) darbības turpmākajās stundās atkārto tajā pašā repository (krātuvē).

Gatavs, kad: GitHub redzams pirmais commit (izmaiņu fiksējums) un Main.tscn; cache (kešatmiņa) nav iekļauta. Privātai repository (krātuvei) skolotājam ir piešķirta access (piekļuve).

Papildu uzdevums — izdomā spēles pasauli

README.md ieraksti vienu teikumu par savu spēles ieceri: kas ir abas komandas un par ko tās sacenšas? Piemēram, zemūdenes sargā pērli vai kosmosa kuģi sacenšas par enerģiju.

Ko sagatavo

Stundas mērķis: ir atverams Pong project (projekts), main scene (galvenā scēna) un pirmā version (versija) GitHub.

GitHub repository (krātuvē) jābūt:

  1. project.godot, Scenes/Main.tscn, .gitignore.
  2. README.md: Godot version (versija) un piecu editor (redaktora) panel (paneļu) pielietojums; palaistā window (loga) screenshot (ekrānuzņēmums).

Saglabā project (projekta) settings (iestatījumus), izveidotās scene (scēnas) un resource (resursus); no 1.3 stundas arī C# script (skriptus) un project (projekta) file (failus) (.csproj u.c.). .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.

Kā iesniedz: veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā iesniedz GitHub repository (krātuves) link (saiti); README.md un pārbaudes pierādījumiem jābūt repository (krātuvē).
