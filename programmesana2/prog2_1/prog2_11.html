Fokuss: dari tikai vienu bloku reizē: vispirms programma atveras, tad tu atrodi paneļus, tad saglabā projektu Git. Pēc katra bloka pārbaudi Gatavs, kad rindu un tikai tad ej tālāk.

Teorija: Godot Engine un editor (redaktors)

Godot 4 Engine (Godot dzinējs) ir bezmaksas, atvērtā koda spēļu dzinējs ar visu nepieciešamo 2D un 3D spēļu izstrādei. Šajā kursā Godot tiek lietots kā vizuālais redaktors, scēnu pārvaldnieks un spēles izpildes vide, bet spēles loģika tiek rakstīta C# Godot .NET vidē.

Godot projektā jāatšķir trīs slāņi: projekta iestatījumi nosaka logu un palaišanu, scēnas glabā objektu struktūru, bet C# klases piešķir objektiem uzvedību. Ja šie slāņi tiek jaukti, vēlāk ir grūti saprast, vai kļūda ir editorā, resursā vai kodā.

Editor (redaktora) galvenās daļas:

  • Scene Tree (Skatu koks) - kreisajā augšā; spēles objektu hierarhija.
  • FileSystem (Failu sistēma) - kreisajā apakšā; projekta faili.
  • Viewport (Skatlogs) - centrā; vizuālais redaktors.
  • Inspector (Inspektors) - labajā; aktīvā Node īpašības.
  • Output / Debugger (Atkļūdotājs) - apakšā; izvades konsole.

Renderera izvēle: ja dators ir jauns un grafikas draiveri ir atjaunināti, izvēlies Forward+. Ja skolā ir vecāki datori vai virtuālās mašīnas, Compatibility bieži ir drošāka izvēle. Pong ir 2D projekts, tāpēc mācību rezultātu tas praktiski nemaina.

# Godot 4 instalācija
# 1. Lejupielādē Godot 4 .NET no godotengine.org/download
# 2. Izpako ZIP
# 3. Palaiž godot.exe (Windows) vai ./godot (Linux/Mac)
# 4. Project Manager → New Project
public class PongProjectReadiness
{
    private bool godotInstalled = false;
    private bool projectCreated = false;
    private bool gitInitialized = false;

    public bool IsReadyForCSharp()
    {
        return godotInstalled && projectCreated && gitInitialized;
    }
}

Praktiskie uzdevumi

1. uzdevums -

Uzstādi Godot 4 .NET un izveido Pong projektu

Beigās tavā datorā būs atvērts tukšs Godot projekts ar nosaukumu Pong.

Ko šis māca: atšķirt Godot .NET versiju no parastās Godot versijas un saprast, ka projekts sākas ar pareizu darba vidi.

  1. Atver godotengine.org/download un lejupielādē Godot 4 .NET savai sistēmai.
  2. Izpako ZIP arhīvu mapē, kuras ceļā nav garumzīmju un atstarpju.
  3. Palaid godot.exe (Windows) vai ./godot (Linux/macOS).
  4. Nospied Project Manager logā pogu New Project.
  5. Ieraksti projekta nosaukumu Pong un izvēlies tukšu mapi.
  6. Izvēlies renderer Compatibility, ja dators ir vecāks, citādi Forward+.
  7. Nospied Create & Edit un pagaidi, līdz atveras editors.

Gatavs, kad: ekrānā ir atvērts Godot editors, un loga augšā redzams projekta nosaukums Pong.

2. uzdevums -

Atrodi piecas editora daļas

Beigās tu zināsi, kur editorā ko meklēt, un vairs neapmaldīsies.

Ko šis māca: sasaistīt teorijas vārdus Scene Tree, FileSystem, Viewport, Inspector un Output ar konkrētu vietu ekrānā.

  1. Atrodi kreisajā augšā paneli Scene - tur veidosi objektu koku.
  2. Atrodi kreisajā apakšā paneli FileSystem - tur ir visi projekta faili.
  3. Atrodi centrā Viewport - tur redzēsi spēles laukumu.
  4. Atrodi labajā pusē paneli Inspector - tur maina izvēlētā objekta īpašības.
  5. Atrodi apakšā cilni Output - tur parādīsies tavas programmas izdrukas.
  6. Izveido README.md failā loga shēmu un ieraksti tajā visu piecu daļu nosaukumus pareizajās vietās.
  7. Paslēp un atkal parādi vienu paneli, lai pārliecinātos, ka atradīsi to no jauna.

Gatavs, kad: tavā README.md failā ir shēma, kurā visas piecas editora daļas atzīmētas pareizajās vietās.

3. uzdevums -

Iestati logu un saglabā projektu Git

Beigās tavs projekts būs pareizā izmērā un saglabāts krātuvē.

Ko šis māca: atšķirt projekta iestatījumus no projekta failiem un saglabāt darba sākumstāvokli tā, lai pie tā varētu atgriezties.

  1. Atver izvēlni Project -> Project Settings.
  2. Atrodi sadaļu Display -> Window.
  3. Ieraksti Viewport Width vērtību 1280 un Viewport Height vērtību 720.
  4. Aizver iestatījumus un saglabā projektu ar Ctrl+S.
  5. Izveido projekta mapē failu .gitignore ar rindām .godot/ un *.tmp.
  6. Izpildi mapē git init, git add . un git commit -m "Pong projekta sakums".
  7. Izveido GitHub krātuvi pong-godot un izpildi git push.

Gatavs, kad: GitHub krātuvē redzams fails project.godot, bet mape .godot/ tur nav nonākusi.

Papildu uzdevums - Saglabā savu editora izkārtojumu

Ja pamatdarbs ir gatavs, pielāgo editoru sev un saglabā šo izkārtojumu.

Ko šis māca: lietot Godot palīdzību un pielāgot darba vidi tā, lai nākamajā stundā vieglāk atrast vajadzīgo.

  1. Pārvieto paneļus tā, kā tev ērtāk strādāt.
  2. Atver Editor -> Editor Layout -> Save Layout.
  3. Ieraksti izkārtojuma nosaukumu Mans.
  4. Atver Help -> Search Help un atrodi tajā Node2D.
  5. Pieraksti vienā teikumā, ko dara Node2D.

Gatavs, kad: izvēlnē Editor Layout ir tavs izkārtojums Mans, un README.md failā ir Node2D apraksts.

Ko sagatavo

Stundas mērķis: Tev ir uzstādīts Godot 4 .NET un izveidots tukšs Pong projekts pareizā loga izmērā, kas saglabāts, un tu proti nosaukt piecas editora galvenās daļas.

GitHub krātuvē jābūt:

  1. Saite uz savu GitHub krātuvi pong-godot.
  2. Ekrānuzņēmums ar atvērtu Godot editoru, kurā loga augšā redzams projekta nosaukums Pong.
  3. README.md sadaļa ar editora shēmu, kurā atzīmētas piecas daļas.

Kā iesniedz: Veic commit un push. Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Pašpārbaude pirms iesniegšanas

Ātri pārbaudi, vai nākamajā stundā varēsi turpināt bez meklēšanas.

  • Atver vēlreiz Pong projektu no Project Manager un pārliecinies, ka tas ielādējas bez kļūdām.
  • Parādi ar pirkstu visas piecas editora daļas, neskatoties pierakstos.
  • Pārbaudi GitHub: tur jābūt project.godot, README pierakstiem un ekrānuzņēmumam.

Biežākās kļūdas

  • Editor neatveras: Pārbaudi, vai sistēma atbalsta Godot 4 (Windows 10+, macOS 10.15+, Linux).
  • Lēna darbība: Forward+ prasa atjauninātus grafikas draiverus. Vecākiem datoriem mēģini Compatibility.
  • Saglabājot crashojas: Mapes ceļā nevajadzētu lietot diakritiskās zīmes, speciālos simbolus vai ļoti garus nosaukumus.

public class ProjectSetupReport
{
    public string ProjectName = "Pong";
    public string GodotVersion = "Godot 4 .NET";
    public bool UsesCSharpScripts = true;
    public bool HasGitRepository = true;

    public bool CanContinueToLesson12()
    {
        return ProjectName == "Pong"
            && GodotVersion.Contains(".NET")
            && UsesCSharpScripts
            && HasGitRepository;
    }
}
