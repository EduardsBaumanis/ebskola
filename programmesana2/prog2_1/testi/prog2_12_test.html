Atkārtojuma tests: 1.1 Godot instalācija un projekta sagatavošana

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kāds ir .NET SDK uzdevums Godot C# projektā?

Objektus veido Godot, kodu raksta VS Code, kopiju glabā GitHub, bet C# kompilēšanai vajag .NET SDK. Atkārto: 1.1 — Teorija: izstrādes rīki un projekta failu struktūra ↗

2. Ko Godot projektā apzīmē res://?

res://Scenes/Main.tscn nozīmē „no projekta saknes”, tāpēc ceļi strādā neatkarīgi no tā, kur projekts saglabāts. Atkārto: 1.1 — Teorija: izstrādes rīki un projekta failu struktūra ↗

3. Kāpēc mapi .godot/ ieraksta .gitignore un nesūta uz GitHub?

Kešatmiņa tiek izveidota no jauna ātrākai ielādei. Versiju vēsturē glabā tikai to, ko veido cilvēks: scēnas, skriptus, iestatījumus. Atkārto: 1.1 — 3. uzdevums — Saglabā sākumpunktu GitHub ↗

4. Ar ko atšķiras F5 un F6 Godot redaktorā?

Tāpēc pirmajā F5 reizē izvēlas Select Current, lai Main.tscn kļūtu par galveno scēnu. Spēli aptur ar F8. Atkārto: 1.1 — 2. uzdevums — Izveido un palaid pirmo scēnu ↗

5. Kurā Godot redaktora panelī redz GD.Print ziņojumus un kļūdas?

Output ir apakšējā joslā. Inspector rāda mezgla īpašības, FileSystem — failus, Scene — mezglu koku. Atkārto: 1.1 — 2. uzdevums — Izveido un palaid pirmo scēnu ↗
