Atkārtojuma tests: 1.4 Pirmais C# skripts: variable (mainīgie) un izvade

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Jautājumi

1. Kāds datu tips ir laukam Speed = 420.0f?

float ir skaitlis ar daļu aiz komata, un burts f norāda float vērtību. Atkārto: 1.4 — Teorija: C# class, datu tipi un Inspector īpašības ↗

2. Kur piesaista skriptu Scripts/Paddle.cs, lai tas darbotos abām raketēm?

Veidnes skripts ir visiem tās eksemplāriem — tāpēc Output panelī parādās gan PaddleLeft, gan PaddleRight izdruka. Atkārto: 1.4 — 1. uzdevums — Pievieno Paddle.cs kopīgajai raketes scēnai ↗

3. Kodā ir [Export] public float Speed = 420.0f;, bet PaddleRight Inspector panelī iestatīts Speed = 300. Kādu ātrumu izdrukā labā rakete?

Inspector panelī saglabātā vērtība ir svarīgāka par koda noklusējumu — kā konkrētai ierīcei iestatīts profils pret rūpnīcas iestatījumu. Atkārto: 1.4 — 2. uzdevums — Iestati katrai raketei savus datus ↗

4. Metodes _Ready() sākumā ir šīs rindas. Ko katra rakete izdrukā katrā spēles palaišanā? 
int testScore = 0;
testScore += 1;
GD.Print(testScore);

testScore ir lokāls mainīgais: tas katru reizi sākas no 0, un _Ready() katram mezglam izpildās vienreiz. Atkārto: 1.4 — 3. uzdevums — Paskaidro vērtības un saglabā strādājošo versiju ↗

5. Ko dara $ rindā GD.Print($"{Name}: ātrums {Speed}");?

Tā ir teksta interpolācija — tāpat kā Python f-string. Name ir konkrētā eksemplāra nosaukums scēnā. Atkārto: 1.4 — Teorija: C# class, datu tipi un Inspector īpašības ↗
