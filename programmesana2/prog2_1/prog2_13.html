1.3 C# un .NET sagatavošana

Stundas uzdevums: Sagatavot Godot .NET projektu, lai varētu rakstīt, būvēt un palaist C# skriptus Godot.

SR 2.4.12. Programmēšanas vide SR 2.4.2. Argumentēti izvēlas rīkus SR 2.3.2. Datorikas virzieni un profesijas SR 2.4.8. Koda dokumentēšana un noformēšana SR 2.4.9. Versiju pārvaldība SR 2.4.11. Standartizētas bibliotēkas un API

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - pārbaudi Godot .NET un .NET SDK · 2. uzdevums (~25 min) - izveido pirmo Hello.cs skriptu · 3. uzdevums (~20 min) - pieslēdz VS Code un Git · Iesniegšana (~5 min).

Pirms sāc: šī ir darba vides stunda. Ja kāds solis neizdodas, pieraksti precīzu kļūdas tekstu - C# kļūdas parasti pasaka, kura programma vai fails vēl trūkst.

Teorija: Godot C# un .NET build sistēma

Godot 4 C# projekti izmanto .NET. Tas nozīmē: vajag Godot .NET versiju, atsevišķi uzstādītu .NET SDK un C# skriptus ar paplašinājumu .cs.

Šajā kursā spēles skripti ir C# klases. Katram skriptam ir viens .cs fails, klases nosaukums sakrīt ar faila nosaukumu, un skripts tiek piesaistīts Godot mezglam tāpat kā citi Godot skripti.

Kāpēc C#?

  • Veiktspēja: piemērots intensīvai fizikai, datu apstrādei un AI algoritmiem.
  • Industrijas standarts: C# un .NET tiek plaši lietoti spēļu izstrādē un lietotņu veidošanā.
  • Kontrole: skaidri tipi, autocompletion, kļūdu pārbaude pirms palaišanas un ērta atkļūdošana.

Nepieciešamie rīki: Godot 4 .NET versija, .NET SDK, VS Code ar C# paplašinājumu un Git. Pēc pirmā C# skripta izveides Godot ģenerē .sln un .csproj failus - tos glabā GitHub kopā ar projektu.

# Pārbaude terminālī
dotnet --version

# Projekta būvēšana no projekta mapes
dotnet build
using Godot;

public partial class DotnetSetupCheck : Node
{
    public override void _Ready()
    {
        GD.Print("Godot .NET projekts ir gatavs C# skriptiem.");
    }
}

Praktiskie uzdevumi

1. uzdevums - Pārbaudi Godot .NET un .NET SDK

Beigās tavs dators pratīs būvēt Godot C# skriptus.

  1. Pārliecinies, ka lejupielādēta un palaista Godot versija ar nosaukumu .NET.
  2. Uzstādi .NET SDK, ja tas vēl nav uzstādīts.
  3. Atver termināli un izpildi dotnet --version.
  4. Pieraksti README.md failā .NET SDK versijas numuru.
  5. Atver Pong projektu Godot .NET editorā.
  6. Pārliecinies, ka Godot augšējā labajā stūrī ir pieejama poga Build.

Gatavs, kad: dotnet --version atbild ar versijas numuru un Godot projektā ir pieejama C# Build poga.

2. uzdevums - Izveido pirmo C# skriptu

Beigās Godot būs izveidojis C# projekta failus un palaidis tavu pirmo skriptu.

  1. Izveido scēnā mezglu Node un nosauc to Hello.
  2. Nospied Attach Script.
  3. Izvēlies valodu C# un faila nosaukumu Hello.cs.
  4. Ieraksti _Ready() metodē GD.Print("Sveiks no C#!");.
  5. Nospied Godot pogu Build.
  6. Palaid projektu ar F5 un paskaties Output paneli.
  7. Pārbaudi, ka projekta mapē parādījās .sln un .csproj faili.

Gatavs, kad: spēles palaišanas brīdī Output panelī parādās teksts no Hello.cs, un projekta mapē ir C# projekta faili.

3. uzdevums - Pieslēdz VS Code un Git

Beigās C# kodu varēsi ērti rediģēt VS Code un droši saglabāt GitHub.

  1. Atver Godot izvēlni Editor -> Editor Settings.
  2. Atrodi sadaļu Dotnet -> Editor un kā ārējo editoru izvēlies Visual Studio Code.
  3. Atver projektu VS Code ar pogu Godot editorā vai terminālī ar code ..
  4. Instalē VS Code paplašinājumu C# vai C# Dev Kit, ja tas vēl nav uzstādīts.
  5. Pievieno .gitignore failam rindas .godot/, bin/ un obj/.
  6. Pārliecinies, ka Git redz Hello.cs, .sln, .csproj un project.godot.
  7. Veic commit un push.

Gatavs, kad: VS Code atver C# failu ar izcelšanu, Godot Build darbojas, un ir C# projekta faili bez .godot/, bin/ un obj/ mapēm.

Papildu uzdevums - Saprot, ko dara katrs solis

Ja pamatdarbs ir gatavs, pieraksti sev atgādni turpmākajām reizēm.

  1. Uzraksti failu BUILD.md projekta mapē.
  2. Pieraksti tajā komandas dotnet --version un dotnet build.
  3. Pieraksti katrai vienu teikumu, ko tā dara.
  4. Pieraksti, kur Godot editorā atrodas Build poga.
  5. Pieraksti vienu kļūdu, ar ko saskāries, un kā to atrisināji.
  6. Veic commit un push.

Gatavs, kad: pēc BUILD.md instrukcijas klasesbiedrs varētu atkārtot uzstādīšanu bez tavas palīdzības.

Ko sagatavo

Stundas mērķis: Tavā datorā ir Godot .NET projekts ar strādājošu Hello.cs skriptu, .NET SDK ir pārbaudīts, un C# projekta faili ir saglabāti GitHub.

GitHub krātuvē jābūt:

  1. Ekrānuzņēmums ar termināli, kurā redzams dotnet --version rezultāts.
  2. Ekrānuzņēmums ar Godot cilni Output, kurā redzama Hello.cs izdruka.
  3. GitHub krātuvē redzami Hello.cs, .sln, .csproj un project.godot.
  4. Ja kaut kas neizdevās - precīzs kļūdas teksts, nokopēts no Godot vai termināļa.

Kā iesniedz: Veic commit un push. Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Papildu izaicinājumi

Iestati ērtāku C# rediģēšanu.

  • Atver projektu VS Code ar code ..
  • Instalē C# paplašinājumu, lai redzētu autocompletion un kļūdas pirms palaišanas.
  • Pievieno VS Code task, kas palaiž dotnet build.

Biežākās kļūdas

  • C# izvēle neparādās: palaista parastā Godot versija, nevis Godot .NET.
  • dotnet: command not found: .NET SDK nav uzstādīts vai terminālis vēl nav atvērts no jauna.
  • Cannot find class: Hello.cs faila nosaukumam jāsakrīt ar klases nosaukumu Hello.
  • Inspector neredz jaunu īpašību: pēc C# koda maiņas nospied Godot Build.
