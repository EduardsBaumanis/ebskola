1.2 Scene Tree - biežāk lietotie mezgli

Main (Node2D)              <- scēnas sakne, tur visu kopā
├── PaddleLeft              (CharacterBody2D) + CollisionShape2D
├── PaddleRight             (CharacterBody2D) + CollisionShape2D
├── Ball                    (CharacterBody2D) + CollisionShape2D
├── SienaAugsa              (StaticBody2D)    + CollisionShape2D
├── SienaApaksa             (StaticBody2D)    + CollisionShape2D
├── VidusLinija             (Line2D)
├── Punkti                  (Label)
└── Camera2D

Mezglu tipi:
  Node2D            bāzes 2D objekts, ir pozīcija un rotācija
  Sprite2D          parāda attēlu
  Label             parāda tekstu
  CharacterBody2D   kustīgs objekts, kuram kustību raksti pats
  StaticBody2D      nekustīgs šķērslis (siena, grīda)
  Area2D            zona, kas pamana ieiešanu (monēta, finišs)
  CollisionShape2D  BEZ ŠĪ nav nekādu sadursmju

Atkārtoti lietojams objekts: labais klikšķis -> Save Branch as Scene

Katram mezglam dod nosaukumu, no kura var saprast, kas tas ir. Node2D2 pēc nedēļas neko nepateiks.

using Godot;

public partial class Hello : Node
{
    private int counter = 0;
    private string playerName = "Pong Player";

    public override void _Ready()
    {
        GD.Print(playerName, " / ", counter);   // = print() Python
        SayHello();
    }

    public void SayHello()
    {
        counter++;
        GD.Print("Sveiciens Nr. ", counter);
    }
}

1.6 Pong: kustība, atlēkšana, punkti

// --- Paddle.cs: vadība ar taustiņiem ---
using Godot;

public partial class Paddle : CharacterBody2D
{
    [Export] public string InputUp = "p1_up";
    [Export] public string InputDown = "p1_down";
    [Export] public float Speed = 420.0f;

    public override void _PhysicsProcess(double delta)
    {
        Vector2 v = Vector2.Zero;
        if (Input.IsActionPressed(InputUp)) v.Y -= Speed;
        if (Input.IsActionPressed(InputDown)) v.Y += Speed;
        Velocity = v;
        MoveAndSlide();
    }
}

// --- Ball.cs: lidojums un atlēkšana ---
public partial class Ball : CharacterBody2D
{
    [Export] public float BaseSpeed = 420.0f;
    private Vector2 velocity;

    public override void _Ready()
    {
        ResetBall();
    }

    public void ResetBall()
    {
        Position = new Vector2(640, 360);
        velocity = new Vector2(BaseSpeed, (float)GD.RandRange(-180.0, 180.0));
    }

    public override void _PhysicsProcess(double delta)
    {
        KinematicCollision2D col = MoveAndCollide(velocity * (float)delta);
        if (col != null) velocity = velocity.Bounce(col.GetNormal());
    }
}

Taustiņu nosaukumus (p1_up, p1_down, p2_up, p2_down) definē Project Settings -> Input Map, nevis kodā.
