1.2 Scene Tree (scēnu koks) un Node (mezgls) sistēma

Sasniedzamais rezultāts: Izveidot redzamas Paddle un Ball scēnas, to instance (eksemplāri) un precīzu Pong scene tree.

SR 2.4.13. Data type (datu tipi) SR 2.4.15. Modulāras programmas

Teorija: node, scēna un instance

No būvblokiem līdz atkārtoti lietojamiem eksemplāriem

Godot projekts tiek būvēts hierarhiskā koka struktūrā, ko var salīdzināt ar modulāru konstruktoru vai arhitektūras rasējumiem:

  • Node (mezgls) — mazākais pamatelements ar vienu skaidru uzdevumu (piemēram, glabāt koordinātes, attēlot figūru vai noteikt sadursmi).
  • Scene Tree (scēnu koks) un scēna (.tscn) — savstarpēji savienotu mezglu koks ar vienu galveno jeb saknes mezglu, kas saglabāts failā kā gatava objekta veidne.
  • Instance (eksemplārs) — konkrēts objekts, kas izveidots pēc saglabātās scēnas veidnes un ievietots citā scēnā (tāpat kā vienu un to pašu krēsla rasējumu telpas plānā var izvietot vairākās vietās). Mainot pašu scēnas veidni, izmaiņas parādās visos tās eksemplāros, turpretim katram eksemplāram atsevišķi var pielāgot individuālās īpašības, piemēram, novietojumu vai krāsas tonējumu.
# Saglabāta scēnas veidne (Scenes/LampasModulis.tscn):
LampasModulis (Node2D)
└── Izskats (Polygon2D)

# Galvenā scēna ar diviem tās pašas veidnes eksemplāriem (Scenes/Telpa.tscn):
Telpa (Node2D)
├── KreisaLampa (LampasModulis.tscn) → Position: (200, 150)
└── LabaLampa   (LampasModulis.tscn) → Position: (800, 150), cita Modulate

2D mezglu lomas un relatīvās koordinātas

Lai objekts 2D vidē gan būtu saskatāms, gan fiziski mijiedarbotos ar citiem ķermeņiem, vienā scēnā apvieno specializētus mezglus: Node2D (2D mezgls) kalpo kā konteiners objektu grupēšanai, CharacterBody2D (vadāma 2D tēla mezgls) ir kustīgs fizikas ķermenis, CollisionShape2D (2D sadursmes forma) piešķir tam fizisko kontūru, bet Polygon2D (2D daudzstūris) uzzīmē redzamo izskatu - pats fizikas ķermenis ekrānā nav redzams.

Child node (bērnmezglu) pozīcijas vienmēr tiek rēķinātas attiecībā pret to vecāku, nevis ekrāna malu - gluži kā pasažieris, kurš nekustīgi sēž savā vilciena sēdvietā (0, 0), pārvietojas telpā kopā ar visu vagonu. Tāpēc, pārvietojot objekta saknes mezglu, precīzi kopā ar to pārvietojas arī tam pievienotais izskats un sadursmes forma:

KustigsBloks (CharacterBody2D)   → Position: (400, 300) vecāka scēnā
├── Izskats (Polygon2D)          → Position: (0, 0) pret KustigsBloks
└── Kontura (CollisionShape2D)   → Position: (0, 0) pret KustigsBloks

1. uzdevums

Izveido atkārtoti izmantojamu raketi

Kur strādāt: Godot redaktorā izveido jaunu scēnu Scenes/Paddle.tscn. (Šajā stundā veidojam tikai scēnas un mezglus; C# skriptus pievienosim 1.3. un 1.4. stundā.)

Raketes scēnas Scenes/Paddle.tscn mezglu koks:

Paddle (CharacterBody2D, Position: (0, 0), Motion Mode: Floating, Layer: 2, Mask: 1)
├── CollisionShape2D (RectangleShape2D, Size: (24, 120), Position: (0, 0))
└── Visual (Polygon2D, 4 punkti: (-12,-60), (12,-60), (12,60), (-12,60), Position: (0, 0))
  1. Izveido scēnu Scenes/Paddle.tscn: augšējā izvēlnē izvēlies Scene → New Scene, kreisajā panelī spied Other Node, meklē CharacterBody2D un spied Create. Ar F2 pārdēvē saknes mezglu par Paddle un ar Ctrl+S saglabā scēnu mapē res://Scenes/Paddle.tscn.
  2. Iestati Paddle saknes īpašības: Scene panelī atlasi Paddle. Inspector panelī pārliecinies, ka Transform → Position ir (0, 0) un Scale ir (1, 1), bet laukā Motion Mode izvēlies Floating (jo rakete peldēs bez gravitācijas).
  3. Pievieno sadursmes formu CollisionShape2D zem Paddle: atlasi Paddle un ar + pievieno bērnmezglu CollisionShape2D. Inspector laukā Shape izvēlies New RectangleShape2D, noklikšķini uz izveidotās taisnstūra formas un iestati Size = (24, 120). Pašam CollisionShape2D mezglam atstāj Transform → Position = (0, 0).
  4. Pievieno redzamo izskatu Visual zem Paddle: atkal atlasi sakni Paddle (nevis CollisionShape2D!) un ar + pievieno Polygon2D bērnmezglu ar nosaukumu Visual. Inspector sadaļā Data → Polygon iestati Size = 4 un ievadi četras virsotnes: (-12, -60), (12, -60), (12, 60), (-12, 60). Laukā Color izvēlies gaišu krāsu un pārbaudi, ka Visual Position ir (0, 0).
  5. Iestati Paddle sadursmju slāņus un saglabā: Scene panelī atlasi sakni Paddle. Inspector sadaļā Collision rindā Layer atstāj ieslēgtu tikai kvadrātiņu 2 (izslēdz 1), bet rindā Mask — tikai 1. Nospied Ctrl+S, lai saglabātu Scenes/Paddle.tscn.

Gatavs, kad: scēna Scenes/Paddle.tscn satur sakni Paddle (CharacterBody2D) un divus bērnmezglus (CollisionShape2D un Visual) pozīcijā (0, 0).

2. uzdevums

Izveido bumbu un saliec Main scēnu

Kur strādāt: Vispirms izveido jaunu bumbas scēnu Scenes/Ball.tscn. Pēc tam pārslēdzies uz galveno scēnu Scenes/Main.tscn un ievieto tajā divus Paddle.tscn eksemplārus (PaddleLeft, PaddleRight) un vienu Ball.tscn eksemplāru (Ball).

Abu scēnu mezglu koks (nejauc tās kopā!):

1) Bumbas veidnes scēna Scenes/Ball.tscn:
Ball (CharacterBody2D, Position: (0, 0), Motion Mode: Floating, Layer: 3, Mask: 1 un 2)
├── CollisionShape2D (RectangleShape2D, Size: (20, 20), Position: (0, 0))
└── Visual (Polygon2D, 4 punkti: (-10,-10), (10,-10), (10,10), (-10,10), Position: (0, 0))

2) Galvenā spēles scēna Scenes/Main.tscn:
Main (Node2D, Position: (0, 0))
├── PaddleLeft  (ievilkts Scenes/Paddle.tscn eksemplārs, Position: (60, 360))
├── PaddleRight (ievilkts Scenes/Paddle.tscn eksemplārs, Position: (1220, 360))
└── Ball        (ievilkts Scenes/Ball.tscn eksemplārs, Position: (640, 360))
  1. Izveido jaunu scēnu Scenes/Ball.tscn: izvēlies Scene → New Scene → Other Node, meklē CharacterBody2D un spied Create. Pārdēvē sakni par Ball, Inspector panelī iestati Motion Mode = Floating, Transform → Position = (0, 0) un ar Ctrl+S saglabā kā res://Scenes/Ball.tscn.
  2. Scēnā Scenes/Ball.tscn pievieno CollisionShape2D un Visual: zem Ball pievieno CollisionShape2D ar New RectangleShape2D un Size = (20, 20). Tad atkal atlasi Ball un pievieno Polygon2D ar nosaukumu Visual, Data → Polygon punktiem (-10, -10), (10, -10), (10, 10), (-10, 10) un gaišu Color.
  3. Scēnā Scenes/Ball.tscn iestati slāņus: atlasi sakni Ball un Inspector → Collision rindā Layer ieslēdz tikai 3 (izslēdz 1), bet rindā Mask ieslēdz gan 1, gan 2 (lai bumba pamanītu gan sienas 1. slānī, gan raketes 2. slānī). Saglabā Scenes/Ball.tscn (Ctrl+S).
  4. Galvenajā scēnā Scenes/Main.tscn ievieto abas raketes: atver cilni Main.tscn. No FileSystem paneļa divas reizes ievelc Scenes/Paddle.tscn tieši uz saknes mezgla Main. Pirmo eksemplāru pārdēvē par PaddleLeft un tā Inspector → Transform → Position iestati (60, 360); otro pārdēvē par PaddleRight un iestati Position = (1220, 360).
  5. Galvenajā scēnā Scenes/Main.tscn ievieto bumbu un palaid F5: no FileSystem ievelc Scenes/Ball.tscn uz saknes mezgla Main, pārliecinies, ka eksemplāra nosaukums ir Ball, un iestati tā Transform → Position = (640, 360). Saglabā Scenes/Main.tscn un nospied F5.

3. uzdevums

Pārbaudi, ko maina scēnā un ko instance

Kur strādāt: Kopīgo raketes izskatu pārbaudi scēnā Scenes/Paddle.tscn, bet atsevišķu eksemplāru īpašības — scēnā Scenes/Main.tscn. Secinājumus pieraksti failā README.md.

  1. Maini kopīgo krāsu veidnē Scenes/Paddle.tscn: atver cilni Paddle.tscn, atlasi Visual un Inspector → Color izvēlies citu gaišu krāsu. Saglabā (Ctrl+S) un pārslēdzies uz cilni Main.tscn — jaunā krāsa automātiski parādās abām raketēm (PaddleLeft un PaddleRight).
  2. Maini tonējumu tikai vienam eksemplāram scēnā Scenes/Main.tscn: cilnē Main.tscn Scene panelī atlasi tikai PaddleRight un Inspector → Visibility → Modulate izvēlies atšķirīgu krāsu. Pārliecinies, ka šī izmaiņa ietekmē tikai labo raketi.
  3. Pārbaudi eksemplāra pozīciju scēnā Scenes/Main.tscn: cilnē Main.tscn atlasi PaddleLeft un Inspector → Transform → Position uz laiku nomaini y no 360 uz 200 — redzamais taisnstūris un sadursmes forma pārvietojas kopā kā viens vesels. Pēc pārbaudes atjauno PaddleLeft Position = (60, 360) un saglabā Main.tscn.
  4. Dokumentē secinājumus failā README.md: projekta README.md failā īsi izskaidro atšķirību starp Node (mezglu), Scene (scēnas veidni .tscn) un Instance (eksemplāru), kā arī pievieno Main.tscn mezglu koka ekrānuzņēmumu.

Gatavs, kad: izproti atšķirību starp izmaiņām veidnē Scenes/Paddle.tscn un eksemplārā Scenes/Main.tscn, un visi objekti atrodas savās sākuma pozīcijās.

Papildu uzdevums - pievieno savu emblēmu raketei

Kur strādāt: Godot redaktorā papildini scēnu Scenes/Paddle.tscn ar dekoratīvu Polygon2D bērnmezglu.

Atver Scenes/Paddle.tscn, atlasi sakni Paddle un ar + pievieno vēl vienu Polygon2D bērnmezglu (piemēram, Emblem) ar mazu četru vai trīs virsotņu simbolu raketes vidū. Galveno CollisionShape2D nemaini. Saglabā Paddle.tscn un pārbaudi cilnē Main.tscn, ka simbols parādās abām raketēm.

Ko sagatavo

Stundas mērķis: ir redzams Pong sākuma laukums ar vienotu node struktūru.

GitHub krātuvē jābūt:

  • Scenes/Main.tscn, Scenes/Paddle.tscn, Scenes/Ball.tscn.
  • Palaistās scēnas un scene tree attēli; README.md skaidrojums par instance.

Saglabā projekta iestatījumus, izveidotās scēnas un resursus; no 1.3 stundas arī C# skriptus un projekta failus (.csproj u.c.). .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.
