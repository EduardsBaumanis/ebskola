Teorija: node (mezgls), scene (scēna) un instance (instancei)

Node (mezgls) ir viens object (objekts); scene (scēna) ir file (failā) saglabāts scene tree (mezglu koks). Instance (instancei) ir šīs scene (scēnas) eksemplārs citā scene (scēnā). Abi spēlētāji izmantos vienu Paddle.tscn, bet katrai instance (eksemplārei) būs sava position (pozīcija) un vēlāk sava vadība.

CharacterBody2D (vadāma 2D tēla mezgls) ir kustīgs collision (sadursmju) ķermenis, CollisionShape2D (2D sadursmes forma) nosaka fizisko formu, Polygon2D (2D daudzstūris) nodrošina izskatu. Pats ķermenis nav redzams. Node2D (2D mezgls) tur object (objektus) kopā. Child node (bērnu) position (pozīcijas) ir attiecībā pret vecāku: pārvietojot raketes root (sakni), pārvietojas arī izskats un forma.

1. uzdevums -

Izveido atkārtoti izmantojamu raketi

  1. Izveido jaunu scene (scēnu): Other Node (cits mezgls) → CharacterBody2D (vadāma 2D tēla mezgls). Root (sakni) nosauc Paddle, saglabā res://Scenes/Paddle.tscn. Root (saknes) Position (pozīcija) = (0,0), Scale (mērogs) = (1,1), Motion Mode (kustības režīms) = Floating.
  2. Pievieno child node (bērnu) CollisionShape2D (2D sadursmes forma). Inspector (īpašību panelis) Shape (forma) → New RectangleShape2D (jauna 2D taisnstūra forma) → Size (izmērs) = (24,120). Bērna Position (pozīcija) = (0,0). Dzeltenajam brīdinājumam par tukšu formu jāpazūd.
  3. Pievieno child node (bērnu) Polygon2D (2D daudzstūris), nosauc Visual. Inspector (īpašību panelis) property (īpašībā) Polygon (daudzstūris) ievadi četras virsotnes: (-12,-60), (12,-60), (12,60), (-12,60). Iestati gaišu Color (krāsa); Position (pozīcija) = (0,0). Forma un izskats tagad ir vienāda izmēra.
  4. Paddle root (saknes) Collision (sadursme) sadaļā noņem sākotnējos checkbox (ķeksīšus) un ieslēdz Layer (slānis) tikai 2, Mask (maska) tikai 1. Šeit runa ir par checkbox (ķeksīšu) numuriem.
  5. Saglabā Paddle.tscn. 2D editor (redaktorā) pārbaudi, ka redzamais taisnstūris sakrīt ar collision shape (sadursmes formu).

Gatavs, kad: Paddle.tscn satur vienu fizikas root (sakni) un divus child node (bērnus): Visual un CollisionShape2D (2D sadursmes forma).

2. uzdevums -

Izveido bumbu un saliec Main scene (scēnu)

  1. Jaunā scene (scēnā) izveido CharacterBody2D (vadāma 2D tēla mezgls) root (sakni) Ball, Motion Mode (kustības režīms) = Floating; saglabā res://Scenes/Ball.tscn. Root (saknes) Position (pozīcija) = (0,0), Scale (mērogs) = (1,1).
  2. Ball pievieno CollisionShape2D (2D sadursmes forma) ar RectangleShape2D (2D taisnstūra forma) Size (izmērs) (20,20). Pamatversijā bumba ir mazs kvadrāts, lai izskats un forma sakristu. Visual Polygon2D (2D daudzstūris) punkti: (-10,-10), (10,-10), (10,10), (-10,10); izvēlies gaišu krāsu.
  3. Ball root (saknei) iestati Layer (slānis) tikai 3, Mask (maska) 1 un 2. Tā noteiks sienas un raketes. Saglabā.
  4. Atver Main.tscn. No FileSystem (failu sistēma) ievelc Paddle.tscn divas reizes tieši zem Main. Pārsauc instances (instances) PaddleLeft un PaddleRight. Iestati Position (pozīcija) attiecīgi (60,360) un (1220,360).
  5. Ievelc arī Ball.tscn instance (eksemplāri) ar nosaukumu Ball, Position (pozīcija) = (640,360). Main root (saknes) Position (pozīcija) saglabā (0,0). Saglabā visu un palaid F5.

Gatavs, kad: vienā window (logā) redzamas abas raketes un bumba; tie vēl nekustas.

3. uzdevums -

Pārbaudi, ko maina scene (scēnā) un ko instance (eksemplārē)

  1. Atver Paddle.tscn un nomaini Visual Color (krāsa). Saglabā un atver Main: jaunā krāsa redzama abām raketēm, jo abas izmanto vienu scene (scēnu).
  2. Pašā Main scene (scēnā) atlasītajai PaddleRight instance (eksemplārei) nomaini Modulate (krāsas tonējums) krāsu. Pārbaudi, ka šī izmaiņa skar tikai labo raketi.
  3. Uz laiku Main scene (scēnā) PaddleLeft Position.Y maini no 360 uz 200. Pārvietojas gan attēls, gan forma; X paliek 60. Atjauno Y = 360. Izmaiņas veic instance (eksemplārei), nevis Paddle.tscn root (saknei).
  4. README.md izskaidro atšķirību starp node (mezglu), scene (scēnu) un instance (eksemplāri). Pievieno koka screenshot (ekrānuzņēmumu) un pārbaudi precīzus PaddleLeft, PaddleRight un Ball nosaukumus. Tie būs C# code (kodā) izmantotie ceļi.

Gatavs, kad: proti nomainīt kopīgu izskatu un tikai vienas instances (instances) property (īpašību); visas sākuma position (pozīcijas) ir atjaunotas.

Papildu uzdevums — pievieno savu emblēmu

Paddle.tscn pievieno vēl vienu Polygon2D (2D daudzstūris) child node (bērnu) ar savu mazu simbolu. Simbolam jāpaliek raketes robežās; galveno collision shape (sadursmes formu) nemaini. Pārbaudi, ka simbols parādās abām instance (eksemplārēm).
