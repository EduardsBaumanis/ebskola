Stundas uzdevums: Izveidot redzamas Paddle un Ball scēnas, to instance (eksemplāri) un precīzu Pong scene tree.

80 min plāns: Ievads (~10 min) · raketes scēna (~20 min) · bumba un instance (~25 min) · struktūras pārbaude (~20 min) · saglabāšana (~5 min).

Pirms sāc: atver 1.1 izveidoto Pong projektu. Šodien veidosi redzamus objektus un to sadursmju formas. C# kodu vēl nepievieno; kustība sāksies 1.5 stundā.

Darba ritms: pēc katra uzdevuma saglabā un pārbaudi rezultātu. Kad projektam pievienots C# skripts, pirms palaišanas nospied Build. Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Failu ceļi: ceļi ir norādīti no tava Godot projekta mapes, kur atrodas project.godot; piemēram, Scripts/Player.cs Godot panelī ir res://Scripts/Player.cs. Ja norādītais fails jau ir izveidots, atver un papildini to.

Teorija: node, scēna un instance

No būvblokiem līdz atkārtoti lietojamiem eksemplāriem

Godot projekts tiek būvēts hierarhiskā koka struktūrā, ko var salīdzināt ar modulāru konstruktoru vai arhitektūras rasējumiem:

  • Node (mezgls) — mazākais pamatelements ar vienu skaidru uzdevumu (piemēram, glabāt koordinātes, attēlot figūru vai noteikt sadursmi).
  • Scene Tree (scēnu koks) un scēna (.tscn) — savstarpēji savienotu mezglu koks ar vienu galveno jeb saknes mezglu, kas saglabāts failā kā gatava objekta veidne.
  • Instance (eksemplārs) — konkrēts objekts, kas izveidots pēc saglabātās scēnas veidnes un ievietots citā scēnā (tāpat kā vienu un to pašu krēsla rasējumu telpas plānā var izvietot vairākās vietās). Mainot pašu scēnas veidni, izmaiņas parādās visos tās eksemplāros, turpretim katram eksemplāram atsevišķi var pielāgot individuālās īpašības, piemēram, novietojumu vai krāsas tonējumu.

2D mezglu lomas un relatīvās koordinātas

Lai objekts 2D vidē gan būtu saskatāms, gan fiziski mijiedarbotos ar citiem ķermeņiem, vienā scēnā apvieno specializētus mezglus: Node2D (2D mezgls) kalpo kā konteiners objektu grupēšanai, CharacterBody2D (vadāma 2D tēla mezgls) ir kustīgs fizikas ķermenis, CollisionShape2D (2D sadursmes forma) piešķir tam fizisko kontūru, bet Polygon2D (2D daudzstūris) uzzīmē redzamo izskatu — pats fizikas ķermenis ekrānā nav redzams.

Child node (bērnmezglu) pozīcijas vienmēr tiek rēķinātas attiecībā pret to vecāku, nevis ekrāna malu — gluži kā pasažieris, kurš nekustīgi sēž savā vilciena sēdvietā (0, 0), pārvietojas telpā kopā ar visu vagonu. Tāpēc, pārvietojot objekta saknes mezglu, precīzi kopā ar to pārvietojas arī tam pievienotais izskats un sadursmes forma.

1. uzdevums -

Izveido atkārtoti izmantojamu raketi

Kur strādāt: Godot redaktorā izveido Scenes/Paddle.tscn. Šajā uzdevumā veido scēnu; C# skripts vēl nav vajadzīgs.

  1. Izveido jaunu scēnu: Other Node → CharacterBody2D. Sakni nosauc Paddle, saglabā res://Scenes/Paddle.tscn. Saknes Pozīcija = (0,0), Mērogs = (1,1), Motion Mode = Floating.
  2. Pievieno child node CollisionShape2D. Inspector Shape → New RectangleShape2D (jauna 2D taisnstūra forma) → Size = (24,120). Bērna Pozīcija = (0,0). Dzeltenajam brīdinājumam par tukšu formu jāpazūd.
  3. Pievieno child node Polygon2D, nosauc Visual. Inspector īpašībā Polygon ievadi četras virsotnes: (-12,-60), (12,-60), (12,60), (-12,60). Iestati gaišu Krāsa; Pozīcija = (0,0). Forma un izskats tagad ir vienāda izmēra.
  4. Paddle saknes Sadursme sadaļā noņem sākotnējos ķeksīšus un ieslēdz Layer tikai 2, Mask tikai 1. Šeit runa ir par ķeksīšu numuriem.
  5. Saglabā Paddle.tscn. 2D redaktorā pārbaudi, ka redzamais taisnstūris sakrīt ar sadursmes formu.

Gatavs, kad: Paddle.tscn satur vienu fizikas sakni un divus child node: Visual un CollisionShape2D.

2. uzdevums -

Izveido bumbu un saliec Main scēnu

Kur strādāt: Godot redaktorā izveido Scenes/Ball.tscn un ievieto abas raketes un bumbu esošajā Scenes/Main.tscn.

  1. Jaunā scēnā izveido CharacterBody2D sakni Ball, Motion Mode = Floating; saglabā res://Scenes/Ball.tscn. Saknes Pozīcija = (0,0), Mērogs = (1,1).
  2. Ball pievieno CollisionShape2D ar RectangleShape2D (2D taisnstūra forma) Size (20,20). Pamatversijā bumba ir mazs kvadrāts, lai izskats un forma sakristu. Visual Polygon2D punkti: (-10,-10), (10,-10), (10,10), (-10,10); izvēlies gaišu krāsu.
  3. Ball saknei iestati Layer tikai 3, Mask 1 un 2. Tā noteiks sienas un raketes. Saglabā.
  4. Atver Main.tscn. No FileSystem ievelc Paddle.tscn divas reizes tieši zem Main — abi spēlētāji izmantos vienu kopīgu Paddle.tscn scēnu, bet katrai instance būs sava pozīcija un vēlāk sava vadība. Pārsauc instance PaddleLeft un PaddleRight un iestati Pozīcija attiecīgi (60,360) un (1220,360).
  5. Ievelc arī Ball.tscn instance ar nosaukumu Ball, Pozīcija = (640,360). Main saknes Pozīcija saglabā (0,0). Saglabā visu un palaid F5.

Gatavs, kad: vienā logā redzamas abas raketes un bumba; tie vēl nekustas.

3. uzdevums -

Pārbaudi, ko maina scēnā un ko instance

Kur strādāt: Kopīgo raketes izskatu maini Scenes/Paddle.tscn, atsevišķo rakešu īpašības — Scenes/Main.tscn. Skaidrojumu raksti README.md.

  1. Atver Paddle.tscn un nomaini Visual Krāsa. Saglabā un atver Main: jaunā krāsa redzama abām raketēm, jo abas izmanto vienu scēnu.
  2. Pašā Main scēnā atlasītajai PaddleRight instance nomaini Modulate krāsu. Pārbaudi, ka šī izmaiņa skar tikai labo raketi.
  3. Uz laiku Main scēnā PaddleLeft Position.Y maini no 360 uz 200. Pārvietojas gan attēls, gan forma; X paliek 60. Atjauno Y = 360. Izmaiņas veic instance, nevis Paddle.tscn saknei.
  4. README.md izskaidro atšķirību starp node, scēnu un instance. Pievieno koka ekrānuzņēmumu un pārbaudi precīzus PaddleLeft, PaddleRight un Ball nosaukumus. Tie būs C# kodā izmantotie ceļi.

Gatavs, kad: proti nomainīt kopīgu izskatu un tikai vienas instance īpašību; visas sākuma pozīcijas ir atjaunotas.

Papildu uzdevums — pievieno savu emblēmu

Kur strādāt: Godot redaktorā papildini Scenes/Paddle.tscn ar emblēmas mezglu.

Paddle.tscn pievieno vēl vienu Polygon2D child node ar savu mazu simbolu. Simbolam jāpaliek raketes robežās; galveno sadursmes formu nemaini. Pārbaudi, ka simbols parādās abām instance.

Ko sagatavo

Stundas mērķis: ir redzams Pong sākuma laukums ar vienotu node struktūru.

  1. Scenes/Main.tscn, Scenes/Paddle.tscn, Scenes/Ball.tscn.
