Pirms sāc: šis ir 1. tēmas noslēguma projekts. Laukums jau ir gatavs no 1.5 stundas - šodien pievienosi kustību. Strādā pa vienam objektam: vispirms paddle, tad bumba, tad punkti.

Teorija: Spēles apraksts un arhitektūra

Pong ir klasiska 1972. gada arkādes spēle. Divi spēlētāji vada vertikālas paddles un atsit bumbu pretiniekam. Pirmais ar 5 punktiem uzvar.

Šis projekts ir labs 1. tēmas noslēgumam, jo tajā ir maz objektu, bet tie pārbauda gandrīz visu pamatu: Scene Tree, atkārtoti lietojamas scēnas, Input Map, C++ klases, sadursmes, UI atjaunināšanu un spēles stāvokli. Pong nav izvēlēts tāpēc, ka tas ir vizuāli sarežģīts; tas ir izvēlēts tāpēc, ka kļūdas tajā ir viegli pamanāmas.

Spēles loģika tiek rakstīta C++. Godot editorā drīkst salikt scēnas un iestatīt resursus, bet paddle kustība, bumbas atlēkšana, punktu pieskaitīšana un uzvaras pārbaude jārealizē GDExtension klasēs.

C++ klases:

  • Paddle - spēlētāja vadītā raķete ar ievades darbībām input_up un input_down.
  • Ball - bumba ar ātrumu, sadursmju apstrādi un reset mehāniku.
  • Game - punktu uzskaite, UI atjaunināšana, uzvaras noteikšana un raunda restartēšana.
class Game : public Node {
    GDCLASS(Game, Node)
private:
    int score_left = 0;
    int score_right = 0;
    Ball *ball = nullptr;
public:
    void _ready() override;
    void on_score(bool left_player);
    void reset_ball();
    void update_score_labels();
};

Praktiskie uzdevumi

1. uzdevums - Liec paddle kustēties

Beigās abi spēlētāji varēs vadīt savu paddle ar taustiņiem.

  1. Atver Project -> Project Settings -> Input Map.
  2. Izveido darbības kreisais_augsup, kreisais_lejup, labais_augsup, labais_lejup.
  3. Piesaisti tām taustiņus W, S, augšupbulta un lejupbulta.
  4. Izveido C++ klasi Paddle, kas manto no CharacterBody2D.
  5. Uzraksti metodē _physics_process(double delta) ātruma aprēķinu pēc Input::get_singleton()->is_action_pressed(...).
  6. Izsauc move_and_slide() un kompilē ar scons.
  7. Palaid spēli un pārbaudi abus paddle.

Gatavs, kad: abi paddle kustas augšup un lejup ar saviem taustiņiem un neiziet ārpus sienām.

2. uzdevums - Liec bumbai lidot un atlekt

Beigās bumba lidos pa laukumu un atlēks no sienām un paddle.

  1. Izveido C++ klasi Ball, kas manto no CharacterBody2D.
  2. Pievieno lauku Vector2 velocity; un double base_speed;.
  3. Uzraksti metodi reset_ball(), kas noliek bumbu centrā un dod nejaušu y ātrumu.
  4. Izsauc _physics_process metodē move_and_collide(velocity * delta).
  5. Pārbaudi, vai atgrieztā sadursme ir derīga, un atspoguļo ātrumu ar velocity.bounce(...).
  6. Kompilē un palaid spēli.
  7. Pieraksti, kāpēc ātrums jāreizina ar delta.

Gatavs, kad: bumba lido, atlec no abām sienām un no abiem paddle, un neiestrēgst sienā.

3. uzdevums - Pievieno punktus un uzvaru

Beigās spēle skaitīs punktus un paziņos uzvarētāju.

  1. Pievieno pārbaudi: ja bumbas x ir mazāks par 0, punktu saņem labais spēlētājs.
  2. Pievieno otru pārbaudi: ja x ir lielāks par 1280, punktu saņem kreisais.
  3. Atjaunini Punkti mezgla tekstu pēc katra punkta.
  4. Izsauc pēc punkta reset_ball().
  5. Pievieno pārbaudi: kad kāds sasniedz 5 punktus, parādi uzvarētāju un aptur bumbu.
  6. Izspēlē vienu pilnu partiju līdz 5 punktiem.
  7. Veic commit un push.

Gatavs, kad: spēle pareizi skaita punktus abiem spēlētājiem un beidzas, kad kāds sasniedz 5.

Papildu uzdevums - Paātrini bumbu pēc katra sitiena

Ja pamatdarbs ir gatavs, padari spēli grūtāku ar laiku.

  1. Pievieno klasei Ball lauku ar paātrinājuma koeficientu.
  2. Palielini ātrumu par dažiem procentiem pēc katras sadursmes ar paddle.
  3. Ierobežo maksimālo ātrumu, lai bumba neizlido cauri sienai.
  4. Atgriez sākuma ātrumu pēc katra punkta.
  5. Izspēlē partiju un pārbaudi, vai bumba nekad neizlido cauri paddle.

Gatavs, kad: bumba ar katru sitienu kļūst manāmi ātrāka, bet nekad neizlido cauri objektiem.

Ko iesniedz skolotājam

Stundas mērķis: Tev ir strādājoša Pong spēle: abi spēlētāji vada savus paddle, bumba lido un atlec, spēle skaita punktus un paziņo uzvarētāju pie 5 punktiem. Visa spēles loģika ir C++ klasēs.

Iesniedzamais:

  1. Saite uz GitHub krātuvi ar visu projektu.
  2. Īss video vai 3 ekrānuzņēmumi: spēles sākums, punktu skaitīšana, uzvaras paziņojums.
  3. Faili paddle.cpp un ball.cpp ar tavu spēles loģiku.
  4. README.md: viens teikums par to, kāpēc ātrums jāreizina ar delta.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un attēlus skolotāja norādītajā vietā. Spēle jāspēj palaist no tavas krātuves.

Papildu izaicinājumi

Pievieno vienu uzlabojumu, kas neizjauc pamata spēli.

  • Izveido AIPaddle : public Paddle, kas seko bumbai tikai tad, kad bumba kustas tā virzienā.
  • Pievieno skaņas efektu paddle sadursmei un punktam, bet skaņas palaišanu izsauc no C++.
  • Pievieno pauzes režīmu ar bool paused, kas aptur bumbas un paddle kustību.

Biežākās kļūdas

  • Bumba iziet cauri paddle: Speed pārāk augsts; lieto move_and_collide nevis set_position.
  • Punkti netiek atjaunināti: Pārliecinies par get_node<Label>("ScoreLeft") references.
  • Build neizmainās: Izdzēs .sconsign.dblite un kompilē no jauna.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

void Ball::reset_ball() {
    set_position(Vector2(640, 360));
    double y_speed = UtilityFunctions::randf_range(-180.0, 180.0);
    velocity = Vector2(base_speed, y_speed);
}

void Ball::_physics_process(double delta) {
    auto collision = move_and_collide(velocity * delta);
    if (collision.is_valid()) {
        velocity = velocity.bounce(collision->get_normal());
        velocity *= 1.05f;
    }
}

void Game::on_score(bool left_player) {
    if (left_player) score_left++;
    else score_right++;
    update_score_labels();
    ball->reset_ball();
}

void Game::update_score_labels() {
    score_left_label->set_text(String::num_int64(score_left));
    score_right_label->set_text(String::num_int64(score_right));
}
