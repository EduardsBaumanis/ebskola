C# skripta saistība ar mezglu

Direktīva using Godot; faila sākumā pieslēdz dzinēja bibliotēku un ļauj izmantot tā iebūvētos type (tipus). Deklarācija, piemēram, public partial class KustigsObjekts : CharacterBody2D, apraksta C# class (klasi), kuras nosaukumam precīzi jāsakrīt ar faila nosaukumu (KustigsObjekts.cs), atslēgvārdam partial (pa failiem sadalāma klase) jāļauj dzinējam kompilācijas laikā pievienot savu palīgkodu, bet bāzes tipam aiz kola : jāatbilst scēnas mezgla tipam.

Savukārt šīs klases instance (eksemplāriem) citā scēnā var dot atšķirīgus mezglu vārdus — gluži kā viena modeļa viedierīcēm darbojas vienāda programmatūra, taču katrai ierīcei var piešķirt savu nosaukumu:

// Fails: res://Scripts/KustigsObjekts.cs
using Godot;

public partial class KustigsObjekts : CharacterBody2D
{
    // Vienu klasi var izmantot vairāki scēnas eksemplāri ar dažādiem vārdiem
}

Sākuma metode _Ready(), teksta izvade un [Export]

Metodi _Ready() Godot automātiski izsauc vienreiz brīdī, kad node (mezgls) ir sagatavots scēnā. GD.Print izvada tekstu Output panelī, bet teksta interpolācija $"...{Speed}..." (simbols $ pirms pēdiņām) ievieto variable (mainīgā) vērtību tieši string (virknē).

Atribūts [Export] (Inspector pieejamas īpašības atribūts) ļauj mainīt vērtību Inspector panelī pēc veiksmīga Build. Koda noklusējuma vērtība darbojas kā ierīces rūpnīcas iestatījums, bet Inspector panelī saglabātā vērtība — kā konkrētam eksemplāram iestatīts profils: izpildes laikā Inspector saglabātā vērtība ir svarīgāka par koda noklusējumu:

[Export] public float Speed = 250.0f; // Noklusējums kodā (maināms Inspector)
public bool IsActive { get; set; } = true;

public override void _Ready()
{
    // Name atgriež konkrētā eksemplāra mezgla nosaukumu scēnā
    GD.Print($"{Name}: ātrums = {Speed}, aktīvs = {IsActive}");
}

Biežākie datu tipi (data type)

C# ir statiski tipizēta valoda - katram mainīgajam deklarējot norāda tipu kā marķētu konteineru noteikta veida datiem:

TypePiemērs un pielietojums
float (daļskaitlis)Speed = 250.0f - nepārtraukts skaitlis ar komatu (piemēram, ātrums); f norāda float literāli.
string (teksta virkne)ActionName = "move_up" - simbolu virkne pēdiņās (piemēram, nosaukums vai ievades darbības kods).
bool (loģiska vērtība)IsActive = true - loģisks slēdzis ar diviem stāvokļiem (true vai false), piemēram, vai objekts ir aktīvs.
int (vesels skaitlis)Counter = 0 - vesels skaitāms lielums bez komata (piemēram, skaitītājs vai mēģinājumu skaits).
Vector2 (divdimensiju vektors)Position vai Velocity - vērtību pāris ar X un Y komponentēm 2D plaknē.

Mainīgo deklarēšana un pamatdarbības C# kodā:

float atrums = 250.0f;                       // Daļskaitlim pievieno f
string darbibasKods = "move_up";             // Teksta virkne pēdiņās
bool irAktivs = true;                        // Loģiska vērtība (true/false)
int skaititajs = 0;                          // Vesels skaitlis
skaititajs += 1;                             // Palielina vērtību par 1
Vector2 sakumaVieta = new Vector2(640, 360); // 2D koordinātas (X, Y)

Pievieno Paddle.cs kopīgajai raketes scēnai

Kur strādāt: Skriptu Scripts/Paddle.cs izveido un piesaisti raketes veidnes scēnas Scenes/Paddle.tscn saknes mezglam Paddle (nevis katrai raketei atsevišķi scēnā Main.tscn!). Pēc tam palaid spēli no Scenes/Main.tscn.

Kā viens skripts darbojas abām raketēm:

Veidne Scenes/Paddle.tscn:
Paddle (CharacterBody2D, skripts: Scripts/Paddle.cs)
├── CollisionShape2D
└── Visual

Galvenā scēna Scenes/Main.tscn:
Main (Node2D)
├── PaddleLeft  (izmanto Scripts/Paddle.cs no Paddle.tscn!)
└── PaddleRight (izmanto to pašu Scripts/Paddle.cs no Paddle.tscn!)
  1. Izveido un piesaisti skriptu Scripts/Paddle.cs scēnā Scenes/Paddle.tscn: atver cilni Scenes/Paddle.tscn, Scene panelī ar labo peles pogu klikšķini uz saknes mezgla Paddle (CharacterBody2D) → Attach Script. Izvēlies Language: C#, ceļu res://Scripts/Paddle.cs un spied Create.
  2. Ievieto pilno kodu failā Scripts/Paddle.cs: atver Scripts/Paddle.cs savā VS Code redaktorā, izdzēs Godot automātiski ģenerēto paraugu un aizstāj ar pilno kodu zemāk. Saglabā failu (Ctrl+S) un saglabā scēnu Paddle.tscn.
  3. Pārbaudi deklarētos laukus failā Scripts/Paddle.cs: atrodi eksportētos laukus Speed (float), InputUp un InputDown (string), kā arī īpašību IsActive (bool), kas vēlāk 1.6. stundā ļaus apturēt raketes pēc uzvaras.
  4. Kompilē un pārbaudi Output paneli: Godot nospied Build, pārslēdzies uz Scenes/Main.tscn un palaid spēli ar F5. Apakšējā Output panelī jāparādās divām izdrukām — pa vienai no PaddleLeft un PaddleRight (projektā ir tikai viens fails Paddle.cs, un abi eksemplāri to izmanto).
1.4 Paddle.cs - pilns fails salīdzināšanai

Lejupielādēt Paddle.cs. Atver failu Scripts/Paddle.cs un aizstāj tā saturu ar šo kodu.

using Godot;

public partial class Paddle : CharacterBody2D
{
    [Export] public float Speed = 420.0f;
    [Export] public string InputUp = "p1_up";
    [Export] public string InputDown = "p1_down";
    public bool IsActive { get; set; } = true;

    public override void _Ready()
    {
        GD.Print($"{Name}: ātrums {Speed}, vadība {InputUp}/{InputDown}, aktīva {IsActive}");
    }
}

Gatavs, kad: projektā ir viens Scripts/Paddle.cs, tas piesaistīts Scenes/Paddle.tscn un pēc F5 panelī Output parādās gan PaddleLeft, gan PaddleRight izdruka.

2. uzdevums

Iestati katrai raketei savus datus

Kur strādāt: Katras raketes individuālās vērtības (Input Up, Input Down, Speed) iestati scēnā Scenes/Main.tscn Inspector panelī; pagaidu pozīcijas izdruku uz laiku pievieno failā Scripts/Paddle.cs metodē _Ready().

  1. Pārbaudi PaddleLeft datus scēnā Scenes/Main.tscn: atver cilni Main.tscn, Scene panelī atlasi PaddleLeft un Inspector panelī pārliecinies, ka zem skripta sadaļas redzami lauki Speed = 420, Input Up = p1_up, Input Down = p1_down.
  2. Nomaini PaddleRight ievades nosaukumus scēnā Scenes/Main.tscn: Scene panelī atlasi PaddleRight un tikai šim eksemplāram Inspector panelī nomaini Input Up uz p2_up un Input Down uz p2_down (pašus taustiņus Input Map pievienosim 1.5. stundā).
  3. Izmēģini individuālu Speed scēnā Scenes/Main.tscn: atlasi PaddleRight, uz laiku iestati Speed = 300, saglabā un palaid ar F5 — Output panelī kreisajai raketei paliek 420, bet labajai ir 300. Apturi ar F8 un atjauno PaddleRight Speed = 420.
  4. Pārbaudi pozīciju izdruku failā Scripts/Paddle.cs: atver Scripts/Paddle.cs un metodes _Ready() beigās uz laiku pievieno GD.Print($"Pozīcija: {Position}");. Saglabā, nospied Build un F5 — Output panelī jābūt (60, 360) un (1220, 360). Pēc pārbaudes izdzēs šo GD.Print rindu no Scripts/Paddle.cs.

Gatavs, kad: scēnā Scenes/Main.tscn kreisajai raketei ir p1_up / p1_down, labajai p2_up / p2_down, abām Speed = 420 un pareizas pozīcijas.
