SR 2.4.13. Mainīgie un datu tipi SR 2.4.15. Modulāras programmas

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - uzraksti .hpp un .cpp failu pāri · 2. uzdevums (~25 min) - reģistrē klasi un nokompilē · 3. uzdevums (~20 min) - pievieno mainīgo un izdrukā to Godot · Iesniegšana (~5 min).

Pirms sāc: atver savu projektu ar sagatavoto godot-cpp no 1.3 stundas. Atceries no Python: print() izdrukā tekstu. C++ Godot vidē to dara UtilityFunctions::print().

Teorija: C++ klases struktūra GDExtension ietvaros

Godot C++ klase tiek definēta divos failos: .hpp (header) un .cpp (implementation). Header fails pasaka, kas klase ir un kādas metodes tai ir; implementation fails pasaka, ko šīs metodes dara. Šāds dalījums ir būtisks C++ valodā, jo kompilators katru failu apstrādā atsevišķi.

Lai Godot redzētu C++ klasi kā node tipu, klasei jāmanto no Godot klases, piemēram, Node vai Node2D, jāizmanto GDCLASS makro un jābūt reģistrētai ar ClassDB::register_class. Bez reģistrācijas C++ kods var kompilēties, bet Godot editorā klase neparādīsies.

// hello.hpp
#pragma once
#include <godot_cpp/classes/node.hpp>
#include <godot_cpp/variant/string.hpp>

namespace godot {

class Hello : public Node {
    GDCLASS(Hello, Node)

private:
    int counter = 0;
    String player_name = "Pong Player";

protected:
    static void _bind_methods();

public:
    Hello();
    ~Hello();
    void _ready() override;
    void say_hello();
};

}  // namespace godot

Dzīves cikls: konstruktors sagatavo C++ objektu, _ready() tiek izsaukts, kad node jau ir scēnā, bet _bind_methods() savieno C++ metodes ar Godot atspoguļošanas sistēmu. Spēles sākumā visdrošāk testēt izvadi ar UtilityFunctions::print.

Praktiskie uzdevumi

1. uzdevums - Uzraksti .hpp un .cpp failu pāri

Beigās tev būs pirmā C++ klase, kas var kļūt par Godot mezglu.

  1. Izveido mapē gdext/src failu hello.hpp.
  2. Ieraksti tajā #pragma once un iekļauj <godot_cpp/classes/node.hpp>.
  3. Uzraksti klasi class Hello : public Node { ar makro GDCLASS(Hello, Node).
  4. Pieteic header failā metodi void say_hello();.
  5. Izveido otru failu hello.cpp un iekļauj tajā hello.hpp.
  6. Uzraksti tur metodes ķermeni, kas izsauc UtilityFunctions::print("Sveiks no C++!");.
  7. Pieraksti, ar ko header fails atšķiras no implementācijas faila.

Gatavs, kad: abos failos ir viena un tā pati metode say_hello, un tu vari pateikt, kurš fails pasaka kas, bet kurš ko dara.

2. uzdevums - Reģistrē klasi un nokompilē

Beigās tava C++ klase parādīsies Godot editorā kā jauns mezgla tips.

  1. Atver failu register_types.cpp.
  2. Iekļauj tajā hello.hpp.
  3. Pievieno inicializācijas funkcijā rindu ClassDB::register_class<Hello>();.
  4. Uzraksti klasē Hello tukšu metodi void Hello::_bind_methods() {}.
  5. Izpildi mapē gdext komandu scons platform=windows.
  6. Atver Godot un pievieno scēnai jaunu mezglu, meklējot Hello.
  7. Pieraksti, kas notiek, ja reģistrācijas rindu izdzēš un kompilē vēlreiz.

Gatavs, kad: Godot mezglu meklētājā parādās tips Hello, un bez reģistrācijas rindas tas pazūd.

3. uzdevums - Pievieno mainīgo un izdrukā to Godot

Beigās tava klase izdrukās tekstu Output panelī, kad palaidīsi spēli.

  1. Pievieno header failā privātu lauku int counter;.
  2. Pievieno arī lauku String player_name;.
  3. Uzraksti konstruktoru, kas iestata counter = 0 un player_name = "Pong Player".
  4. Pieteic metodi void _ready() override; un izdrukā tajā abus laukus.
  5. Kompilē ar scons un palaid spēli ar F5.
  6. Paskaties cilnē Output un pieraksti izdrukāto tekstu.
  7. Nomaini player_name vērtību, kompilē vēlreiz un pārbaudi izmaiņu.

Gatavs, kad: palaižot spēli, Output panelī parādās tavs teksts ar spēlētāja vārdu un skaitli 0.

Papildu uzdevums - Salīdzini ar Python

Ja pamatdarbs ir gatavs, pieraksti, ar ko C++ atšķiras no jau zināmā.

  1. Uzraksti burtnīcā tabulu ar divām kolonnām: Python un C++.
  2. Ieraksti tajā, kā abās valodās izdrukā tekstu.
  3. Ieraksti, kā abās valodās pieteic mainīgo ar veselu skaitli.
  4. Ieraksti, kas C++ ir obligāts katras komandas beigās.
  5. Pieraksti vienu lietu, kas C++ ir jādara, bet Python nav.

Gatavs, kad: tabulā ir vismaz trīs rindas, un tu vari nosaukt vienu C++ prasību, kuras Python nav.

Ko iesniedz skolotājam

Stundas mērķis: Tev ir uzrakstīta pirmā C++ klase Hello, kas ir reģistrēta, nokompilēta, pievienota Godot scēnai un palaižot spēli izdrukā tekstu Output panelī.

Iesniedzamais:

  1. Faili hello.hpp un hello.cpp tavā GitHub krātuvē.
  2. Ekrānuzņēmums ar Godot Output paneli, kurā redzama tava izdruka.
  3. Viens teikums burtnīcā: kāpēc bez ClassDB::register_class klase editorā neparādās.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un ekrānuzņēmumu skolotāja norādītajā vietā.

Papildu izaicinājumi

Eksperimentē ar datu tipiem, nezaudējot C++ struktūru.

  • Pievieno float score = 0.0f un izdrukā to _ready() metodē.
  • Pievieno Vector2 spawn_position un izdrukā tā x un y vērtības.
  • Salīdzini, kurus mainīgos labāk glabāt kā C++ klases laukus un kurus aprēķināt tikai metodē.

Biežākās kļūdas

  • error: 'GDCLASS' was not declared: Trūkst include statement.
  • Klase neparādās Godot: Aizmirsts register_class.
  • Crash, palaižot: .gdextension fails nepareizi konfigurēts.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

// hello.cpp
#include "hello.hpp"
#include <godot_cpp/core/class_db.hpp>
#include <godot_cpp/variant/utility_functions.hpp>

using namespace godot;

void Hello::_bind_methods() {
    ClassDB::bind_method(D_METHOD("say_hello"), &Hello::say_hello);
}

Hello::Hello() {
    counter = 0;
    player_name = "Pong Player";
}

Hello::~Hello() {}

void Hello::_ready() {
    UtilityFunctions::print("Hello, Godot! No C++.");
    say_hello();
}

void Hello::say_hello() {
    counter++;
    UtilityFunctions::print("Sveiciens Nr. ", counter, " spēlētājam ", player_name);
}
Godot Output panelis rāda, ka pielāgota C++ klase ir ielādēta, reģistrēta un izpilda metodi no _ready().
