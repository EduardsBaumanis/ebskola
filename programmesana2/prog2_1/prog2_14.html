1.4 Pirmais C# skripts: mainīgie un izvade

Stundas uzdevums: Uzrakstīt pirmo strādājošu C# klasi un attiecināt to uz Godot Node.

SR 2.4.13. Mainīgie un datu tipi SR 2.4.15. Modulāras programmas

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido Hello.cs skriptu · 2. uzdevums (~25 min) - piesaisti skriptu mezglam un būvē projektu · 3. uzdevums (~20 min) - pievieno mainīgos un izdrukā tos Godot · Iesniegšana (~5 min).

Pirms sāc: atver savu Godot .NET projektu no 1.3 stundas. BuildCheck.cs var palikt kā vides pārbaude, bet šodien strādāsi ar jaunu Hello.cs skriptu. Atceries no Python: print() izdrukā tekstu. C# Godot vidē to dara GD.Print().

Fokuss: nemēģini uzreiz rakstīt spēli. Vispirms panāc vienu izdruku, tad pievieno vienu mainīgo, tad pārbaudi, kā izmaiņa parādās Output panelī.

Teorija: C# skripta struktūra Godot

Godot C# skripts ir viens .cs fails ar klasi, kas manto no Godot mezgla, piemēram, Node, Node2D vai CharacterBody2D. Faila nosaukumam un klases nosaukumam jāsakrīt: Hello.cs satur klasi Hello.

C# skriptos Godot metodes raksta ar lielajiem sākuma burtiem: _Ready(), _Process(double delta), _PhysicsProcess(double delta). Lai klase būtu piesaistāma mezglam, tā parasti ir public partial class un izmanto using Godot;.

using Godot;

public partial class Hello : Node
{
    private int counter = 0;
    private string playerName = "Pong Player";

    public override void _Ready()
    {
        GD.Print("Hello, Godot! No C#.");
        SayHello();
    }

    public void SayHello()
    {
        counter++;
        GD.Print("Sveiciens Nr. ", counter, " spēlētājam ", playerName);
    }
}

Dzīves cikls: konstruktors sagatavo C# objektu, _Ready() tiek izsaukts, kad mezgls jau ir scēnā, bet _Process(double delta) darbojas katrā kadrā. Spēles sākumā visdrošāk testēt izvadi ar GD.Print().

Praktiskie uzdevumi

1. uzdevums -

Izveido Hello.cs skriptu

Beigās tev būs pirmā C# klase, kas var kļūt par Godot mezglu.

Ko šis māca: saprast C# faila un klases saikni: Godot meklē klasi pēc tā paša nosaukuma, kāds ir failam.

  1. Izveido scēnā jaunu mezglu Node un nosauc to Hello.
  2. Nospied Attach Script un izvēlies valodu C#.
  3. Saglabā skriptu kā Hello.cs.
  4. Pārbaudi, ka failā ir using Godot; un public partial class Hello : Node.
  5. Ieraksti _Ready() metodē GD.Print("Sveiks no C#!");.
  6. Saglabā failu un atgriezies Godot editorā.
  7. Pieraksti, kāpēc Hello.cs un Hello nosaukumiem jāsakrīt.

Gatavs, kad: Hello.cs satur klasi Hello, kas manto no Node, un tajā ir GD.Print() izsaukums.

2. uzdevums -

Būvē un palaid skriptu

Beigās tava C# klase būs piesaistīta mezglam un izpildīsies spēles palaišanas brīdī.

Ko šis māca: atšķirt koda saglabāšanu no būvēšanas. C# izmaiņas Godot redz droši tikai pēc Build.

  1. Nospied Godot pogu Build.
  2. Pārbaudi, ka Output panelī nav sarkanu C# kļūdu.
  3. Palaid projektu ar F5.
  4. Atver apakšā cilni Output.
  5. Pārbaudi, ka redzi tekstu Sveiks no C#!.
  6. Atver projektu VS Code un palaid terminālī dotnet build.
  7. Pieraksti, kura kļūda parādās, ja izdzēs semikolu pēc GD.Print(...) rindas.

Gatavs, kad: Godot Output panelī parādās tava C# izdruka un dotnet build beidzas bez kļūdām.

3. uzdevums -

Pievieno mainīgo un izdrukā to Godot

Beigās tava klase izdrukās tekstu Output panelī, kad palaidīsi spēli.

Ko šis māca: lietot skaidrus datu tipus (int, string, Vector2) un redzēt to vērtības spēles palaišanas laikā.

  1. Pievieno klasē privātu lauku private int counter = 0;.
  2. Pievieno arī lauku private string playerName = "Pong Player";.
  3. Pievieno lauku private Vector2 spawnPosition = new Vector2(640, 360);.
  4. Izdrukā _Ready() metodē visus trīs laukus.
  5. Būvē projektu ar Godot Build pogu un palaid spēli ar F5.
  6. Paskaties cilnē Output un pieraksti izdrukāto tekstu.
  7. Nomaini playerName vērtību, būvē vēlreiz un pārbaudi izmaiņu.

Gatavs, kad: palaižot spēli, Output panelī parādās tavs teksts ar spēlētāja vārdu, skaitli 0 un sākuma pozīciju.

Papildu uzdevums - Salīdzini ar Python

Ja pamatdarbs ir gatavs, pieraksti, ar ko C# atšķiras no jau zināmā.

Ko šis māca: pārcelt jau zināmo Python domāšanu uz C# sintaksi, nezaudējot jēgu.

  1. Uzraksti README.md failā tabulu ar divām kolonnām: Python un C#.
  2. Ieraksti tajā, kā abās valodās izdrukā tekstu.
  3. Ieraksti, kā abās valodās pieteic mainīgo ar veselu skaitli.
  4. Ieraksti, kas C# ir obligāts katras komandas beigās.
  5. Pieraksti vienu lietu, kas C# ir jādara, bet Python nav.

Gatavs, kad: tabulā ir vismaz trīs rindas, un tu vari nosaukt vienu C# prasību, kuras Python nav.

Ko sagatavo

Stundas mērķis: Tev ir uzrakstīts pirmais C# skripts Hello.cs, tas ir piesaistīts Godot mezglam, projekts ir uzbūvēts, un palaižot spēli tas izdrukā tekstu Output panelī.

GitHub krātuvē jābūt:

  1. Fails Hello.cs.
  2. Ekrānuzņēmums ar Godot Output paneli, kurā redzama tava izdruka.
  3. Viens teikums README.md failā: kāpēc C# faila nosaukumam jāsakrīt ar klases nosaukumu.

Kā iesniedz: Veic commit un push. Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Pašpārbaude pirms iesniegšanas

Pārbaudi, vai skripts tiešām izpildās un dati nav tikai ierakstīti failā.

  • Godot Output panelī redzama izdruka no Hello.cs, nevis tikai vecais BuildCheck.cs teksts.
  • Maini playerName vērtību, uzbūvē projektu un pārbaudi, ka Output teksts mainās.
  • README.md ir viens teikums par to, kāpēc faila un klases nosaukumam jāsakrīt.

Biežākās kļūdas

  • C# opcija neparādās: projekts atvērts parastajā Godot, nevis Godot .NET versijā.
  • Cannot find class Hello: faila nosaukums un klases nosaukums nesakrīt.
  • Build kļūda pēc maiņas: pārbaudi semikolus, figūriekavas un precīzu metodes nosaukumu _Ready().
