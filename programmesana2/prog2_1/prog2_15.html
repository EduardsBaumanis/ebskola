Pirms sāc: vajadzīgas 1.4 scene (scēnas) un Paddle.cs ar Speed (ātrums) un input (ievades) nosaukumiem. Šodien laukums kļūs kustīgs: pārbaudīsi raketes un bumbu. Punktu uzskaite un spēles vadība būs 1.6 stundā.

Darba ritms: pēc katra uzdevuma saglabā un pārbaudi rezultātu. Kad project (projektam) pievienots C# script (skripts), pirms palaišanas nospied Build (būvēt projektu). Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Teorija: koordinātes, ātrums un collision (sadursme)

1280 × 720 laukumā centrs ir (640,360). X pieaug pa labi, Y — uz leju. Root (saknes) Position (pozīcija) novieto object (objektu) laukumā, bet tās child node (bērnu) Visual un CollisionShape2D (2D sadursmes forma) position (pozīcijas) paliek (0,0). Fizikas root (saknes) Scale (mērogs) atstāj (1,1); izmēru maina formā.

Velocity (ātrums) glabā ātrumu pikseļos sekundē. Raketei MoveAndSlide() laiku ņem vērā pats. Bumbai MoveAndCollide(Velocity * (float)delta) nododam viena soļa pārbīdi. Tāpēc delta (soļa ilgums) šajās divās method (metodēs) lieto atšķirīgi.

Ja MoveAndCollide atgriež collision (sadursmi), Velocity.Bounce(collision.GetNormal()) aprēķina atlēkušo ātrumu. Bez collision (sadursmes) rezultāts ir null (tukša atsauce). Fizikas kustība notiek _PhysicsProcess. Godot kustības un atlēkšanas dokumentācija.

1. uzdevums -

Izveido redzamas laukuma robežas

  1. Atver Main.tscn. Pārbaudi PaddleLeft (60,360), PaddleRight (1220,360), Ball (640,360). Main root (sakne) paliek (0,0).
  2. Main pievieno StaticBody2D (nekustīga 2D ķermeņa mezgls) child node (bērnu) WallTop, Position (pozīcija) = (640,10). Tam pievieno CollisionShape2D (2D sadursmes forma) ar New RectangleShape2D (jauna 2D taisnstūra forma), Size (izmērs) = (1280,20); formas node (mezgla) Position (pozīcija) = (0,0).
  3. WallTop pievieno Polygon2D (2D daudzstūris) child node (bērnu) Visual ar punktiem (-640,-10), (640,-10), (640,10), (-640,10) un redzamu krāsu. Sienas fizikas forma viena pati spēlē nav redzama.
  4. Dublē visu WallTop par WallBottom, root (saknes) Position (pozīcija) = (640,710). Abām sienām Layer (slānis) tikai 1, Mask (maska) neviena ķeksīša. No dublēšanas kopīgs Shape (forma) ir derīgs, kamēr abām vajadzīgs vienāds izmērs.
  5. Pievieno Main child node (bērnu) Line2D ar nosaukumu CenterLine, Points = (640,20) un (640,700), Width = 2, neuzkrītošu krāsu. Tā ir dekorācija un nedrīkst apturēt bumbu.
  6. Pārbaudi visu object (objektu) Layer (slānis) un Mask (maska) pēc tabulas. Palaid F5: redzamas divas sienas, raketes un bumba. Šim fiksētajam laukumam Camera2D (2D kamera) nav vajadzīga.

Gatavs, kad: attēls un collision (sadursmes) ir vienā vietā, sienas iet gar augšu un apakšu, sānu malas paliek atvērtas punktiem.

2. uzdevums -

Pievieno vadību abām raketēm

  1. Project (projekts) → Project Settings (projekta iestatījumi) → Input Map (ievades darbību karte) ar Add (pievienot) izveido visas sešas tabulas darbības; ar + pievieno attiecīgo key (taustiņu). Pārbaudi mazos burtus un pasvītrojumus.
  2. Paddle.cs saglabā _Ready un esošos field (laukus). Class (klases) iekšpusē pievieno _PhysicsProcess no pilnā file (faila) zemāk. Ja izmanto visu file (failu), aizstāj esošo saturu, neveido otru Paddle class (klasi).
  3. Saglabā un Build (būvēt projektu). Main scene (scēnā) PaddleRight Input (ievadei) Up/Down joprojām jābūt p2_up/p2_down, kreisajai — p1_up/p1_down; Speed (ātrums) abām 420.

  5. Turi katru raketi pret augšējo un apakšējo sienu. Tām jāpaliek laukumā: raketes centra Y robežas ir aptuveni 80 un 640 (siena 20 px + raketes pusaugstums 60 px).

1.5 Paddle.cs ar kustību — pilns file (fails) salīdzināšanai

Lejupielādēt Paddle.cs. Aizstāj tikai atbilstošā file (faila) saturu; neveido otru tāda paša nosaukuma class (klasi).

using Godot;

public partial class Paddle : CharacterBody2D
{
    [Export] public float Speed = 420.0f;
    [Export] public string InputUp = "p1_up";
    [Export] public string InputDown = "p1_down";
    public bool IsActive { get; set; } = true;

    public override void _Ready()
    {
        GD.Print($"{Name}: ātrums {Speed}, vadība {InputUp}/{InputDown}, aktīva {IsActive}");
    }

    public override void _PhysicsProcess(double delta)
    {
        if (!IsActive)
        {
            Velocity = Vector2.Zero;
            return;
        }

        float direction = Input.GetAxis(InputUp, InputDown);
        Velocity = new Vector2(0, direction * Speed);
        MoveAndSlide();
    }
}

Gatavs, kad: divi spēlētāji vienlaikus vada savas raketes un neviena neiziet cauri sienām.

3. uzdevums -

Pievieno bumbas kustību un atlēkšanu

  1. Atver Ball.tscn un tās root (saknei) pievieno res://Scripts/Ball.cs. Aizstāj saturu ar pilno file (failu) zemāk. Base (bāzes klase) Speed (ātrums) = 420, Motion Mode (kustības režīms) = Floating. Saglabā un Build (būvēt projektu).
  2. Palaid Main ar F5. Ball _Ready sāk bumbas kustību pa labi ar nelielu nejaušu vertikālo komponenti. Normalized saglabā kopējo ātrumu 420 px/s.
  3. Pārbaudi atlēkšanu no abām raketēm un abām sienām. Redzamā viduslīnija bumbu neaptur. Ja vajag, atkārto F5 vairākas reizes, lai novērotu abus vertikālos virzienus.
  4. Ļauj bumbai iziet aiz labās vai kreisās malas. Kad tā pilnībā atstāj laukumu, tā apstājas; ExitSide kļūst par 1 vai -1. Šajā stundā turpināšanai apturi un palaid F5 no jauna. Nākamajā stundā šo value (vērtību) nolasīs Game, piešķirs punktu un sagatavos jaunu servi.
  5. README.md pieraksti, kāpēc bumbai pārbīdi reizina ar delta (soļa ilgums), bet raketes Velocity (ātrums) pirms MoveAndSlide — ne. Saglabā video ar vadību un atlēkšanu.
1.5 Ball.cs — pilns file (fails) salīdzināšanai

Lejupielādēt Ball.cs. Aizstāj tikai atbilstošā file (faila) saturu; neveido otru tāda paša nosaukuma class (klasi).

using Godot;

public partial class Ball : CharacterBody2D
{
    [Export] public float BaseSpeed = 420.0f;
    public bool IsMoving { get; private set; } = false;
    // -1: bumba izgājusi pa kreisi; 1: pa labi; 0: nav iziešanas.
    public int ExitSide { get; private set; } = 0;

    public override void _Ready()
    {
        ResetBall();
        Serve(1); // 1.5 stundā bumba sāk kustēties pati.
    }

    public void ResetBall()
    {
        Stop();
        Position = new Vector2(640, 360);
        ExitSide = 0;
    }

    public void Serve(int horizontalDirection)
    {
        float verticalDirection = (float)GD.RandRange(0.25, 0.6);
        if (GD.Randf() < 0.5f) verticalDirection = -verticalDirection;
        Velocity = new Vector2(horizontalDirection, verticalDirection).Normalized() * BaseSpeed;
        IsMoving = true;
    }

    public void Stop()
    {
        IsMoving = false;
        Velocity = Vector2.Zero;
    }

    public override void _PhysicsProcess(double delta)
    {
        if (!IsMoving) return;

        KinematicCollision2D collision = MoveAndCollide(Velocity * (float)delta);
        if (collision != null)
            Velocity = Velocity.Bounce(collision.GetNormal());

        if (Position.X < -10)
        {
            ExitSide = -1;
            Stop();
        }
        else if (Position.X > 1290)
        {
            ExitSide = 1;
            Stop();
        }
    }
}

Gatavs, kad: abas raketes kustas, bumba atlec un pēc iziešanas apstājas; punktu sistēmai ir skaidri definēts ExitSide.

Papildu uzdevums — izmēģini spēles tempu

Ball instance (eksemplārei) pamēģini Base (bāzes klase) Speed (ātrums) 350 un 500, katru reizi izspēlējot vairākas atlēkšanas. Pieraksti, kuru ātrumu ir vieglāk spēlēt. Pirms nākamās stundas atjauno 420; vēlāk savu izvēli vari pamatot kā dizaina lēmumu.
