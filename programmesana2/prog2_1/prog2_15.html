Teorija: 2D koordinātes, ātrums un sadursmes

2D koordinātu plakne un fizikas objekta mērogs

Atšķirībā no matemātikas Dekarta plaknes, 2D datorgrafikā koordinātu sākumpunkts (0, 0) atrodas loga kreisajā augšējā stūrī: X pieaug pa labi, bet Y — uz leju (piemēram, 1280 × 720 pikseļu logā centrs ir (640, 360)).

Saknes Position novieto visu objektu telpā, kamēr tās child node (bērnmezglu — vizuālā attēla un CollisionShape2D (2D sadursmes forma)) pozīcijas saglabā (0, 0). Fizikas saknes mērogu (Scale / Mērogs) atstāj (1, 1) — objekta izmēru maina pašā sadursmes formā, lai fizikas aprēķini saglabātos precīzi:

// 1280 × 720 loga centrs (X pieaug pa labi, Y pieaug uz leju)
Position = new Vector2(640, 360);
Scale = new Vector2(1, 1); // Fizikas saknei saglabā mērogu (1, 1)

Vector2 uzAugsu = new Vector2(0, -1); // Negatīvs Y virza uz augšu
Vector2 uzLeju = new Vector2(0, 1);   // Pozitīvs Y virza uz leju

Fizikas cikls, delta un divas kustības metodes

Fizikas kustība notiek metodē _PhysicsProcess(double delta), kur delta (soļa ilgums sekundēs) nodrošina vienādu pārvietošanās ātrumu neatkarīgi no datora jaudas (līdzīgi kā nobrauktais ceļš fizikas formulā ir ātrums, reizināts ar laiku). Īpašība Velocity glabā ātrumu pikseļos sekundē, taču divās CharacterBody2D method (metodēs) delta lieto atšķirīgi:

  • MoveAndSlide() — pārvieto ķermeni ar slīdēšanu gar šķēršļiem un laika soli delta iekšēji ņem vērā pati, tāpēc Velocity pirms tās papildus ar delta nereizina.
  • MoveAndCollide(Velocity * (float)delta) — pārvieto ķermeni līdz pirmajai sadursmei un prasa tieši viena soļa pārbīdes vektoru, tāpēc ātrumu reizina ar (float)delta.

Ja sadursmes nav, MoveAndCollide rezultāts ir null (tukša atsauce). Ja sadursme notiek, Velocity.Bounce(collision.GetNormal()) pēc virsmas perpendikula (normāles) aprēķina atlēkušo ātrumu - gluži kā gaismas stars atstarojas no spoguļa. Plašāk skati Godot kustības un atlēkšanas dokumentāciju.

// 1. variants (slīdošam ķermenim): MoveAndSlide jau iekšēji izmanto delta
public override void _PhysicsProcess(double delta)
{
    float virziens = Input.GetAxis("move_up", "move_down");
    Velocity = new Vector2(0, virziens * Speed);
    MoveAndSlide();
}

// 2. variants (atlecošam ķermenim): pārbīdi reizina ar (float)delta
public override void _PhysicsProcess(double delta)
{
    KinematicCollision2D sadursme = MoveAndCollide(Velocity * (float)delta);
    if (sadursme != null)
        Velocity = Velocity.Bounce(sadursme.GetNormal());
}

Sadursmju slāņi (Layer) un maskas (Mask)

Sadursmju filtrēšana darbojas līdzīgi rāciju kanāliem: Collision Layer (slānis) nosaka, kurā kanālā objekts pats atrodas („kas es esmu”), bet Collision Mask (maska) - kurus kanālus objekts uzmana kā šķēršļus („ar ko es saskaros”).

Inspector panelī atzīmē slāņu kārtas numurus (1, 2, 3...), savukārt .tscn teksta failā tie glabājas kā bināri bit (bitu) karodziņi divnieka pakāpēs (20 = 1, 21 = 2, 22 = 4 - piemēram, 3. slāņa bitu vērtība ir 4, bet vienlaikus ieslēgtu 1. un 2. slāņa maskas summa ir 3):

// Slāņu iestatīšana C# kodā: pēc kārtas numura vai kā bitu summa
SetCollisionLayerValue(3, true); // 3. slāņa ķeksītis (bitu vērtība: 2² = 4)
CollisionMask = 1 + 2;           // 1. un 2. slāņa maska kopā (vērtība: 3)

1.5 Paddle.cs ar kustību - pilns fails salīdzināšanai

Lejupielādēt Paddle.cs. Atver failu Scripts/Paddle.cs un salīdzini vai aizstāj tā saturu ar šo kodu.

using Godot;

public partial class Paddle : CharacterBody2D
{
    [Export] public float Speed = 420.0f;
    [Export] public string InputUp = "p1_up";
    [Export] public string InputDown = "p1_down";
    public bool IsActive { get; set; } = true;

    public override void _Ready()
    {
        GD.Print($"{Name}: ātrums {Speed}, vadība {InputUp}/{InputDown}, aktīva {IsActive}");
    }

    public override void _PhysicsProcess(double delta)
    {
        if (!IsActive)
        {
            Velocity = Vector2.Zero;
            return;
        }

        float direction = Input.GetAxis(InputUp, InputDown);
        Velocity = new Vector2(0, direction * Speed);
        MoveAndSlide();
    }
}

Gatavs, kad: abi spēlētāji vienlaikus var vadīt savas raketes ar W/S un ↑/↓, un neviena rakete neiziet cauri sienām.

1.5 Ball.cs - pilns fails salīdzināšanai

Lejupielādēt Ball.cs. Atver failu Scripts/Ball.cs un aizstāj tā saturu ar šo kodu.

using Godot;

public partial class Ball : CharacterBody2D
{
    [Export] public float BaseSpeed = 420.0f;
    public bool IsMoving { get; private set; } = false;
    // -1: bumba izgājusi pa kreisi; 1: pa labi; 0: nav iziešanas.
    public int ExitSide { get; private set; } = 0;

    public override void _Ready()
    {
        ResetBall();
        Serve(1); // 1.5 stundā bumba sāk kustēties pati.
    }

    public void ResetBall()
    {
        Stop();
        Position = new Vector2(640, 360);
        ExitSide = 0;
    }

    public void Serve(int horizontalDirection)
    {
        float verticalDirection = (float)GD.RandRange(0.25, 0.6);
        if (GD.Randf() < 0.5f) verticalDirection = -verticalDirection;
        Velocity = new Vector2(horizontalDirection, verticalDirection).Normalized() * BaseSpeed;
        IsMoving = true;
    }

    public void Stop()
    {
        IsMoving = false;
        Velocity = Vector2.Zero;
    }

    public override void _PhysicsProcess(double delta)
    {
        if (!IsMoving) return;

        KinematicCollision2D collision = MoveAndCollide(Velocity * (float)delta);
        if (collision != null)
            Velocity = Velocity.Bounce(collision.GetNormal());

        if (Position.X < -10)
        {
            ExitSide = -1;
            Stop();
        }
        else if (Position.X > 1290)
        {
            ExitSide = 1;
            Stop();
        }
    }
}

Gatavs, kad: abas raketes kustas, bumba atlec no sienām un raketēm, un pēc sānu malas šķērsošanas apstājas ar atjauninātu ExitSide.
