SR 2.4.7. Lietotāja saskarne (UI) SR 2.4.13. Datu tipi

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - novieto objektus pēc koordinātēm · 2. uzdevums (~25 min) - pievieno sienas un vidus līniju · 3. uzdevums (~20 min) - pievieno punktu skaitītāju un kameru · Iesniegšana (~5 min).

Pirms sāc: atver savu main.tscn. Atceries galveno: Godot koordinātes sākas kreisajā AUGŠĒJĀ stūrī, un Y pieaug uz LEJU, nevis uz augšu kā matemātikā.

Teorija: Coordinates (Koordinātes) un transformācijas

Godot 2D koordinātes sākas kreisajā augšējā stūrī: (0, 0). X pieaug pa labi, Y uz leju. Tas nozīmē, ka Pong laukuma centrs 1280×720 logā ir (640, 360), augšējā siena ir pie mazas Y vērtības, bet apakšējā siena ir pie lielas Y vērtības.

Spēles laukuma izveidē svarīgi nodalīt vizuālo slāni, sadursmju slāni un UI slāni. Vizuālie objekti parāda spēli, sadursmju objekti nosaka fizikas robežas, bet UI elementi, piemēram, Label, rāda punktus. Vēlāk C++ kods atsauksies uz šiem elementiem pēc nosaukuma.

// Pozīciju manipulācija C++
Vector2 pos = get_position();
pos.x += 10;             // pa labi par 10 pikseļiem
pos.y -= 5;              // uz augšu par 5 pikseļiem
set_position(pos);

set_position(Vector2(640, 360));  // ekrāna centrs 1280x720

Transform = Position + Rotation + Scale. Bērnu nodes pārmanto vecāku transform.

Viewport (Skatlogs) ir loga apgabals, kurā renderē scēnu. Standarta Pong izmērs šajā tēmā ir 1280×720. Lai spēle uz dažādiem ekrāniem uzvestos paredzami, Project Settings sadaļā jāiestata gan loga izmērs, gan stretch režīms.

#include <godot_cpp/classes/label.hpp>
#include <godot_cpp/variant/string.hpp>

using namespace godot;

void GameHud::set_score(int left, int right) {
    get_node<Label>("ScoreLeft")->set_text(String::num_int64(left));
    get_node<Label>("ScoreRight")->set_text(String::num_int64(right));
}

Praktiskie uzdevumi

1. uzdevums - Novieto objektus pēc koordinātēm

Beigās abi paddle stāvēs precīzi laukuma malās, nevis nejaušās vietās.

  1. Izvēlies PaddleLeft un atver Inspector paneli.
  2. Ieraksti Transform -> Position vērtības x = 60, y = 360.
  3. Ieraksti PaddleRight pozīciju x = 1220, y = 360.
  4. Novieto bumbu pašā centrā: x = 640, y = 360.
  5. Palaid spēli ar F5 un pārbaudi, vai visi trīs objekti ir redzami.
  6. Nomaini viena paddle y uz 0 un palaid vēlreiz.
  7. Pieraksti, uz kuru pusi objekts pārvietojās, un ieliec vērtību atpakaļ.

Gatavs, kad: abi paddle ir pretējās malās vienā augstumā, un tu vari pateikt, ka y = 0 ir ekrāna augšā.

2. uzdevums - Pievieno sienas un vidus līniju

Beigās bumbai būs no kā atlēkt, un laukums izskatīsies kā īsts Pong.

  1. Pievieno StaticBody2D ar nosaukumu SienaAugsa.
  2. Pievieno tai bērnu CollisionShape2D ar RectangleShape2D formu.
  3. Iestati formas platumu 1280 un augstumu 20, pozīciju x = 640, y = 10.
  4. Izveido tāpat SienaApaksa ar pozīciju y = 710.
  5. Pievieno Line2D ar nosaukumu VidusLinija.
  6. Ieraksti tās punktus: (640, 0) un (640, 720).
  7. Palaid spēli un pārbaudi, ka līnija sadala laukumu uz pusēm.

Gatavs, kad: ekrānā ir divas sienas ar sadursmes formām un līnija tieši pa vidu.

3. uzdevums - Pievieno punktu skaitītāju un kameru

Beigās laukumā būs vieta, kur vēlāk parādīsies rezultāts.

  1. Izvēlies mezglu Punkti un iestati tā tekstu uz 0 : 0.
  2. Novieto to pozīcijā x = 600, y = 40.
  3. Palielini fonta izmēru Inspector sadaļā Theme Overrides -> Font Sizes.
  4. Pievieno zem Main mezglu Camera2D.
  5. Iestati kameras pozīciju x = 640, y = 360.
  6. Palaid spēli un pārbaudi, ka viss laukums ietilpst ekrānā.
  7. Saglabā scēnu un veic commit.

Gatavs, kad: palaižot spēli, redzams viss laukums ar sienām, līniju un rezultātu 0 : 0 augšā.

Papildu uzdevums - Izrēķini pozīcijas pats

Ja pamatdarbs ir gatavs, pārbaudi, vai proti strādāt ar koordinātēm.

  1. Izrēķini, kāda būtu centra pozīcija logā 1920 x 1080.
  2. Pieraksti atbildi README.md failā pirms pārbaudes.
  3. Nomaini projekta loga izmēru uz 1920 x 1080.
  4. Pārvieto bumbu uz savu izrēķināto pozīciju un palaid.
  5. Atgriez loga izmēru atpakaļ uz 1280 x 720.

Gatavs, kad: tava izrēķinātā centra pozīcija bija pareiza, un bumba tiešām bija ekrāna vidū.

Ko iesniedz skolotājam

Stundas mērķis: Tavā main.tscn scēnā ir gatavs Pong laukums: abi paddle malās, bumba centrā, divas sienas ar sadursmes formām, vidus līnija, rezultāta uzraksts un kamera.

Iesniedzamais:

  1. Ekrānuzņēmums ar palaistu spēli, kurā redzams viss laukums.
  2. Ekrānuzņēmums ar Scene paneli, kurā redzams pilns mezglu koks.
  3. Fails main.tscn tavā GitHub krātuvē.
  4. README.md: kāda ir laukuma centra pozīcija un kā tu to izrēķināji.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un abus ekrānuzņēmumus skolotāja norādītajā vietā.

Papildu izaicinājumi

Noslīpē laukuma lasāmību.

  • Pievieno smalku fonu vai krāsu kontrastu, bet saglabā Pong minimālo lasāmību.
  • Pārliecinies, ka ScoreLeft un ScoreRight nav bērni zem kustīgiem objektiem.
  • Izveido īsu skici README failā, kur parādi 1280×720 koordinātu sistēmu.

Biežākās kļūdas

  • Spēle palaižas baltā logā: Main Scene Project Settings nav iestatīta.
  • Objekti aizsedz Background: Pārbaudi Z-index Inspector.
  • Camera2D nedarbojas: Make Current Inspector vai current = true kodā.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

#include <godot_cpp/classes/camera2d.hpp>
#include <godot_cpp/classes/label.hpp>
#include <godot_cpp/classes/line2d.hpp>
#include <godot_cpp/variant/packed_vector2_array.hpp>
#include <godot_cpp/variant/string.hpp>
#include <godot_cpp/variant/vector2.hpp>

using namespace godot;

void CourtSetup::_ready() {
    get_node<Label>("ScoreLeft")->set_text(String::num_int64(0));
    get_node<Label>("ScoreRight")->set_text(String::num_int64(0));

    Line2D *center_line = get_node<Line2D>("CenterLine");
    PackedVector2Array points;
    points.push_back(Vector2(640, 0));
    points.push_back(Vector2(640, 720));
    center_line->set_points(points);
    center_line->set_width(4.0);

    Camera2D *camera = get_node<Camera2D>("Camera2D");
    camera->set_position(Vector2(640, 360));
    camera->make_current();
}
