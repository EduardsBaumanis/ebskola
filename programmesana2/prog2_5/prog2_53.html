5.3 Saglabāšana/ielāde architecture (arhitektūra)

Stundas uzdevums: Izveidot pilnvērtīgu saglabāšanas sistēmu ar vairākiem saglabāšanas vietām un automātiskā saglabāšana.

SR 2.4.17. File I/O (failu ievade un izvade) SR 2.4.6. Plāno izstrādes procesu

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido SaveManager ar saglabāšanas vietām · 2. uzdevums (~25 min) - liec objektiem saglabāt sevi pašiem · 3. uzdevums (~20 min) - pievieno automātiskā saglabāšana un versiju · Iesniegšana (~5 min).

Pirms sāc: atver savu projektu ar JSON (JavaScript objektu pieraksts) saglabāšanu no 5.2 stundas. Šodien no vienas function (funkcijas) taisīsi sistēmu, kas der visai spēlei.

Teorija: Saglabāt sistēmas architecture

Profesionāla saglabāt sistēma sastāv no vairākiem komponentiem:

  • SaveManager - galvenais koordinators.
  • Saveable interfeiss - visi saglabājami objekti to implementē.
  • Saglabāšanas vieta - vairāki saglabāšanas faili (slot1.json, slot2.json, ...).
  • Automātiskā saglabāšana - automātiska saglabāšana ik pa N minūtēm vai pie checkpoint.
using Godot;
using Godot.Collections;
using System.Collections.Generic;

public interface ISaveable
{
    Dictionary SaveState();
    void LoadState(Dictionary state);
}

public partial class SaveManager : Node
{
    private readonly List<ISaveable> saveables = new();

    public void RegisterSaveable(ISaveable saveable)
    {
        saveables.Add(saveable);
    }

    public void SaveToSlot(int slot) { }
    public void LoadFromSlot(int slot) { }
}

Kā šo izmantot projektā

Atceries: ar redzamu efektu redaktorā nepietiek. Paskaidro, kura C# class (klase) glabā stāvokli, kura method (metode) to maina un kā Godot node (mezgls) struktūra izmanto šo kodu.

Pārbaudi: C# kods pārbauda failu kļūdas, validē datus, izmanto versijas lauku un pamato time complexity (algoritmu sarežģītību).

Praktiskie uzdevumi

1. uzdevums -

Izveido SaveManager ar saglabāšanas vietām

Beigās spēlētājs varēs izvēlēties, kurā vietā saglabāt.

  1. Izveido class SaveManager ar method private string SlotPath(int slot).
  2. Atgriez tajā ceļu user://slot1.json atbilstoši numuram.
  3. Uzraksti method public void Save(int slot) un public bool Load(int slot).
  4. Saglabā dažādus datus slotos 1 un 2.
  5. Ielādē saglabāšanas vietu 1 un pārbaudi, ka dati ir pareizie.
  6. Ielādē saglabāšanas vietu 2 un salīdzini.
  7. Uzraksti method, kas pasaka, kuri sloti vispār eksistē.

Gatavs, kad: abi sloti glabā atšķirīgus datus, un method pareizi pasaka, kuri sloti ir aizpildīti.

2. uzdevums -

Liec objektiem saglabāt sevi pašiem

Beigās katrs objekts pats zinās, ko par sevi saglabāt.

  1. Izveido interfeisu public interface ISaveable ar divām method.
  2. Pieteic tajā Dictionary SaveState();.
  3. Pieteic arī void LoadState(Dictionary state);.
  4. Liec spēlētāja class implementēt ISaveable un abas method.
  5. Liec arī inventāra class to pašu.
  6. Savāc SaveManager visus ISaveable objektus vienā sarakstā.
  7. Izsauc loop (ciklā) katram SaveState() un saliec rezultātus vienā Dictionary (vārdnīca).

Gatavs, kad: viens Save() izsaukums saglabā gan spēlētāju, gan inventāru, un SaveManager nezina to iekšējo uzbūvi.

3. uzdevums -

Pievieno automātiskā saglabāšana un versiju

Beigās spēle saglabāsies pati, un vecie faili neradīs kļūdas.

  1. Pievieno saglabātajam Dictionary lauku version ar vērtību 1.
  2. Pārbaudi ielādējot, vai versija sakrīt.
  3. Izdrukā brīdinājumu un lieto noklusējumus, ja versija ir citāda.
  4. Pievieno Timer (taimeris) node, kas ik pēc 60 sekundēm izsauc automātiskā saglabāšana.
  5. Saglabā automātiskā saglabāšana atsevišķā saglabāšanas vietā, lai tas nepārrakstītu spēlētāja saglabāšanas vietu.
  6. Palaid spēli un pagaidi vienu automātiskā saglabāšana loop.
  7. Nomaini failā versiju uz 2 un pārbaudi brīdinājumu.

Gatavs, kad: automātiskā saglabāšana fails parādās pats, un ar nepareizu versiju spēle brīdina, nevis avarē.

Papildu uzdevums - Parādi saglabāšanas vietu izvēlni

Ja pamatdarbs ir gatavs, ļauj slotus izvēlēties uz ekrāna.

  1. Izveido UI (lietotāja saskarne) ar trim pogām - pa vienai katram slotam.
  2. Parādi pie katras, vai slots (saglabāšanas vietas) ir tukšs vai aizpildīts.
  3. Ielādē attiecīgo saglabāšanas vietu, nospiežot pogu.
  4. Pievieno pogu slota dzēšanai.
  5. Pārbaudi, ka pēc dzēšanas slots rāda 'tukšs'.

Gatavs, kad: izvēlnē redzams katra slota statuss, un slotus var ielādēt un dzēst ar pogām.

Ko sagatavo

Stundas mērķis: Tavā spēlē ir SaveManager ar vairākiem saglabāšanas vietām, objekti paši saglabā savus datus caur ISaveable interfeisu, darbojas automātiskā saglabāšana, un saglabātajam failam ir versijas pārbaude.

GitHub krātuvē jābūt:

  1. Faili SaveManager.cs un ISaveable.cs.
  2. Divi paraugi saglabāto JSON failu no dažādiem saglabāšanas vietām.
  3. Ekrānuzņēmums ar brīdinājumu par nepareizu versiju.
  4. README.md: kāpēc SaveManager nav jāzina, kas tieši ir spēlētāja iekšienē.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Biežākās kļūdas

  • Save fails fragmented: Saglabāt daļas atsevišķos failos vs viens - izvēlies vienu pieeju.
  • Race condition (sacensības stāvoklis): Saglabāt un ielādēt notiek vienlaikus - lieto mutex (savstarpējās izslēgšanas slēdzene) vai sekvenciāli.
  • Slot (saglabāšanas vieta) UI nesinhronizējas: Pārbaudi metadata (metadati) refresh pēc saglabāt.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

using Godot;
using Godot.Collections;
using System.Collections.Generic;

public partial class SaveManager : Node
{
    private readonly List<Node> saveables = new();
    private float autosaveTimer = 0.0f;

    public override void _Process(double delta)
    {
        autosaveTimer += (float)delta;
        if (autosaveTimer >= 300.0f)  // 5 min
        {
            SaveToSlot(0);  // 0 = autosave
            autosaveTimer = 0.0f;
        }
    }

    public void SaveToSlot(int slot)
    {
        Dictionary allData = new();
        foreach (Node node in saveables)
        {
            if (node.HasMethod("SaveState"))
            {
                allData[node.GetPath().ToString()] = node.Call("SaveState");
            }
        }
        allData["timestamp"] = Time.GetUnixTimeFromSystem();
        allData["version"] = 1;

        string path = $"user://save_{slot}.json";
        using FileAccess file = FileAccess.Open(path, FileAccess.ModeFlags.Write);
        file?.StoreString(Json.Stringify(allData, "  "));
    }
}
3 saglabāšanas vieta ar metadata (level, time played, last saglabāt), automātiskā saglabāšana ik 5 min, korekta ielādēt.
