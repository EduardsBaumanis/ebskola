5.3 Saglabāšana/ielāde architecture (arhitektūra)

Sasniedzamais rezultāts: Izveidot pilnvērtīgu saglabāšanas sistēmu ar vairākiem saglabāšanas vietām un automātiskā saglabāšana.

SR 2.4.17. File I/O (failu ievade un izvade) SR 2.4.6. Plāno izstrādes procesu

Teorija: modulāra saglabāšanas un ielādes arhitektūra

Atbildību sadale ar C# saskarni (interface) un koordinatoru

Kad lietotnē ir vairākas neatkarīgas apakšsistēmas, viena centrālā klase nedrīkst tieši lasīt katra objekta privātos laukus — citādi jebkura izmaiņa vienā modulī liktu pārrakstīt arī failu saglabātāju. Tīra arhitektūra (architecture) šo problēmu atrisina ar saskarni jeb interfeisu (interface), kas definē vienotu līgumu bez iekšējās realizācijas — līdzīgi kā pārvākšanās uzņēmuma kurjeram nav jāzina, kā izjaukt katras istabas mēbeles: katrs saimnieks pats sapako savas lietas standartizētā kastē un vēlāk tās izpako, bet koordinators tikai savāc marķētās kastes un nogādā noliktavā:

using Godot;
using Godot.Collections;
using System.Collections.Generic;

public interface ISaglabajams
{
    Dictionary EksportetStavokli();
    void ImportetStavokli(Dictionary dati);
}

public partial class DatuKoordinators : Node
{
    private readonly List<ISaglabajams> vienumi = new();

    public void Registret(ISaglabajams vienums) => vienumi.Add(vienums);
}

Glabājot objektus List<ISaglabajams> sarakstā, koordinators ciklā katram izsauc EksportetStavokli() un apvieno iegūtās vārdnīcas vienā kopējā JSON struktūrā, nemaz nezinot konkrēto klašu iekšējo uzbūvi.

Saglabāšanas vietas (slots), automātiskā saglabāšana un versiju kontrole

Pilnvērtīga datu glabāšanas sistēma papildus pamatierakstam nodrošina trīs aizsardzības mehānismus:

  • Vairākas saglabāšanas vietas (slots): datus sadala numurētos failos (piemēram, user://vieta_1.json, user://vieta_2.json), lai lietotājs varētu uzturēt vairākus neatkarīgus stāvokļus un pārbaudīt, kuri faili ar FileAccess.FileExists(...) jau ir aizpildīti.
  • Atdalīta automātiskā saglabāšana (autosave): ar Timer mezglu periodiski (vai pēc svarīga posma pabeigšanas) izsauc fona ierakstu atsevišķā vietā, piemēram, vieta_0.json — gluži kā mākoņdokumentu melnrakstu vēsture nepārraksta lietotāja manuāli nosaukto gala versiju.
  • Formāta versija (version) un metadati: kopējā vārdnīcā ietver lauku "version": 1 (un pēc vajadzības laika zīmogu Time.GetUnixTimeFromSystem()). Kad programma nākotnē tiek atjaunināta un datu lauki mainās, versijas pārbaude ļauj savlaicīgi atpazīt novecojušu failu un izvairīties no avārijas:
private const int Versija = 1;
private string VietasCels(int vieta) => $"user://vieta_{vieta}.json";

public bool VaiVietaAizpildita(int vieta) =>
    FileAccess.FileExists(VietasCels(vieta));

// Timer signāla apstrādātājs — automātiski saglabā atsevišķā 0. vietā:
private void KadPienakAutosaglabasana() => Saglabat(0);

public bool ParbauditVersiju(Dictionary dati)
{
    if (!dati.ContainsKey("version") || dati["version"].AsInt32() != Versija)
    {
        GD.PrintErr("Nesaderīga faila versija — lieto noklusējumus.");
        return false;
    }
    return true;
}

Liec objektiem saglabāt sevi pašiem ar ISaveable saskarni

Kur strādāt: 1) Mapē Scripts/ izveido jaunu failu Scripts/ISaveable.cs (saskarne public interface ISaveable).
2) Mapē Scripts/ izveido failu Scripts/PlayerProfile.cs (mezgls, kas implementē ISaveable) un pievieno to kā bērnmezglu PlayerProfile scēnā Scenes/FileDemo.tscn.
3) Failā Scripts/SaveManager.cs pievieno List<ISaveable> sarakstu un metodes RegisterSaveable, Save(int slot) un Load(int slot).

Lai SaveManager klasei nebūtu jāzina visu spēles objektu privātie lauki, ieviesīsim saskarni ISaveable: katrs reģistrētais objekts pats sagatavos savu Dictionary ar SaveState() un pats to atjaunos ar LoadState(...).

  1. Mapē Scripts/ izveido jaunu C# failu Scripts/ISaveable.cs un definē tajā saskarni: 
    using Godot.Collections;

public interface ISaveable
{
    string SaveKey { get; }
    Dictionary SaveState();
    void LoadState(Dictionary state);
}
  2. Mapē Scripts/ izveido jaunu C# skriptu Scripts/PlayerProfile.cs, kas glabā spēlētāja vārdu, rekorda līmeni un kopējos pieredzes punktus (TotalXp) un implementē ISaveable: 
    using Godot;
using Godot.Collections;

public partial class PlayerProfile : Node, ISaveable
{
    public string SaveKey => "player_profile";

    public string PlayerName { get; set; } = "Anna";
    public int BestLevel { get; set; } = 1;
    public int TotalXp { get; set; } = 0;

    public Dictionary SaveState()
    {
        return new Dictionary
        {
            ["name"] = PlayerName,
            ["best_level"] = BestLevel,
            ["total_xp"] = TotalXp
        };
    }

    public void LoadState(Dictionary state)
    {
        if (state.ContainsKey("name")) PlayerName = state["name"].AsString();
        if (state.ContainsKey("best_level")) BestLevel = state["best_level"].AsInt32();
        if (state.ContainsKey("total_xp")) TotalXp = state["total_xp"].AsInt32();
    }
}
  3. Atver scēnu Scenes/FileDemo.tscn, pievieno saknei FileDemo vēl vienu Node bērnmezglu, pārsauc to par PlayerProfile un piesaisti tam skriptu Scripts/PlayerProfile.cs.
  4. Atver failu Scripts/SaveManager.cs, pievieno using System.Collections.Generic;, sarakstu private readonly List<ISaveable> saveables = new(); un metodes RegisterSaveable(...), Save(int slot) un Load(int slot): 
    private readonly List<ISaveable> saveables = new();

public void RegisterSaveable(ISaveable item)
{
    if (item != null && !saveables.Contains(item))
    {
        saveables.Add(item);
    }
}

public void Save(int slot)
{
    Dictionary allData = new();
    foreach (ISaveable item in saveables)
    {
        allData[item.SaveKey] = item.SaveState();
    }
    SaveSlotData(slot, allData);
}

public bool Load(int slot)
{
    Dictionary allData = LoadSlotData(slot);
    if (allData.Count == 0) return false;

    foreach (ISaveable item in saveables)
    {
        if (allData.ContainsKey(item.SaveKey))
        {
            item.LoadState(allData[item.SaveKey].AsGodotDictionary());
        }
    }
    return true;
}
  5. Atver failu Scripts/FileDemo.cs un metodē _Ready() reģistrē PlayerProfile pie SaveManager, saglabā 1. un 2. vietu ar dažādiem datiem un pēc tam ielādē 1. vietu atpakaļ:

profile.BestLevel = 5;
profile.TotalXp = 320;

profile.PlayerName = "Jānis";
profile.BestLevel = 9;
profile.TotalXp = 850;
saveManager.Save(2);

saveManager.Load(1);
GD.Print($"[FileDemo] Pēc Slot 1 ielādes: {profile.PlayerName}, BestLevel={profile.BestLevel}, TotalXp={profile.TotalXp}");

Gatavs, kad: SaveManager saglabā un atjauno visus reģistrētos ISaveable objektus ciklā, nezinot to iekšējos laukus.

Pievieno formāta versiju (version) un automātisko saglabāšanu (autosave)

Kur strādāt: 1) Failā Scripts/SaveManager.cs pievieno versijas pārbaudi (CurrentVersion = 1) un automātiskās saglabāšanas taimeri (0. vietā — user://slot0.json).
2) Pārbaudei ar roku nomaini "version": 2 failā user://slot1.json.
3) Secinājumus pieraksti projekta saknes failā README.md.

Pievienosim divus drošības mehānismus: formāta versijas numuru "version": 1 (lai nākotnē vecs fails nesalauztu spēli) un automātisko saglabāšanu atsevišķā 0. vietā (user://slot0.json), kas nepārraksta spēlētāja manuāli saglabātās 1. un 2. vietas.

Gatavs, kad: ik pēc 10 sekundēm tiek atjaunots user://slot0.json, bet mēģinājums ielādēt failu ar "version": 2 izvada brīdinājumu un nesalauž spēli.

3. fails — Scripts/SaveManager.cs (piesaistīts FileDemo/SaveManager mezglam):

using Godot;
using Godot.Collections;
using System.Collections.Generic;

public partial class SaveManager : Node
{
    private const int CurrentVersion = 1;

    [Export] public float AutosaveInterval { get; set; } = 10.0f;

    private readonly List<ISaveable> saveables = new();
    private double autosaveTimer = 0.0;

    public string SlotPath(int slot) => $"user://slot{slot}.json";

    public bool SlotExists(int slot) => FileAccess.FileExists(SlotPath(slot));

    public void RegisterSaveable(ISaveable item)
    {
        if (item != null && !saveables.Contains(item))
        {
            saveables.Add(item);
        }
    }

    public override void _Process(double delta)
    {
        if (saveables.Count == 0) return;

        autosaveTimer += delta;
        if (autosaveTimer >= AutosaveInterval)
        {
            autosaveTimer = 0.0;
            Save(0);
            GD.Print("[SaveManager] Automātiskā saglabāšana (autosave) pabeigta 0. vietā.");
        }
    }

    public void Save(int slot)
    {
        Dictionary allData = new()
        {
            ["version"] = CurrentVersion,
            ["timestamp"] = Time.GetUnixTimeFromSystem()
        };

        foreach (ISaveable item in saveables)
        {
            allData[item.SaveKey] = item.SaveState();
        }

        SaveSlotData(slot, allData);
    }

    public bool Load(int slot)
    {
        Dictionary allData = LoadSlotData(slot);
        if (allData.Count == 0) return false;

        if (!allData.ContainsKey("version") || allData["version"].AsInt32() != CurrentVersion)
        {
            GD.PrintErr($"[SaveManager] Nesaderīga faila versija {slot}. vietā (gaidīta v{CurrentVersion}) — ielāde atcelta!");
            return false;
        }

        foreach (ISaveable item in saveables)
        {
            if (allData.ContainsKey(item.SaveKey))
            {
                item.LoadState(allData[item.SaveKey].AsGodotDictionary());
            }
        }

        GD.Print($"[SaveManager] Veiksmīgi ielādēta {slot}. vieta.");
        return true;
    }

    public void SaveSlotData(int slot, Dictionary data)
    {
        string path = SlotPath(slot);
        using FileAccess file = FileAccess.Open(path, FileAccess.ModeFlags.Write);
        if (file != null)
        {
            file.StoreString(Json.Stringify(data, "    "));
            GD.Print($"[SaveManager] Saglabāta {slot}. vieta ({path})");
        }
    }

    public Dictionary LoadSlotData(int slot)
    {
        if (!SlotExists(slot)) return new Dictionary();

        using FileAccess file = FileAccess.Open(SlotPath(slot), FileAccess.ModeFlags.Read);
        if (file == null) return new Dictionary();

        Json json = new();
        Error err = json.Parse(file.GetAsText());
        if (err != Error.Ok)
        {
            GD.PrintErr($"[SaveManager] Bojāts JSON {slot}. vietā!");
            return new Dictionary();
        }

        return json.Data.AsGodotDictionary();
    }
}

Ko sagatavo

Stundas mērķis: Tavā projektā ir SaveManager ar vairākām saglabāšanas vietām, objekti paši saglabā savus datus caur ISaveable saskarni, darbojas automātiskā saglabāšana (slot0.json) un tiek pārbaudīta faila versija.

GitHub krātuvē jābūt:

  • Failiem Scripts/ISaveable.cs, Scripts/PlayerProfile.cs, Scripts/SaveManager.cs un Scripts/FileDemo.cs.
  • Diviem saglabāto JSON failu paraugiem (slot1.json un slot2.json) un ekrānuzņēmumam ar brīdinājumu par nesaderīgu versiju.
  • Failam README.md ar skaidrojumu, kāpēc SaveManager nav jāzina PlayerProfile iekšējie lauki un kāpēc autosave glabā atsevišķā vietā.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Save fails fragmented: Saglabāt daļas atsevišķos failos vs viens - izvēlies vienu pieeju.
  • Race condition (sacensības stāvoklis): Saglabāt un ielādēt notiek vienlaikus - lieto mutex (savstarpējās izslēgšanas slēdzene) vai sekvenciāli.
  • Slot (saglabāšanas vieta) UI nesinhronizējas: Pārbaudi metadata (metadati) refresh pēc saglabāt.
