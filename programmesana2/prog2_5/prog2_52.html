5.2 JSON serializācija un Resource sistēma

Stundas uzdevums: Saglabāt sarežģītus datu struktūras, izmantojot JSON un Godot Resource klases.

SR 2.4.17. Failu SR 2.4.16. Datu struktūras

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - pārvērs Dictionary par JSON · 2. uzdevums (~25 min) - nolasi JSON atpakaļ · 3. uzdevums (~20 min) - apstrādā bojātu JSON · Iesniegšana (~5 min).

Pirms sāc: atceries no Programmēšanas I JSON failus. Godot to dara JSON klase. Priekšrocība pret 5.1 metodi: JSON failu var atvērt un izlasīt ar acīm.

Teorija: JSON un Resources

JSON (JavaScript Object Notation) ir cilvēkam un mašīnai lasāms datu formāts. Godot piedāvā JSON klasi tā parsēšanai.

#include <godot_cpp/classes/json.hpp>

// Dictionary -> JSON string
Dictionary save_data;
save_data["player_name"] = "Anna";
save_data["level"] = 5;
save_data["inventory"] = Array(); // var saturēt vēl Dictionary

String json_str = JSON::stringify(save_data, "  ");  // 2-space indent

// JSON string -> Dictionary
Ref<JSON> json = memnew(JSON);
Error err = json->parse(json_str);
if (err == OK) {
    Variant data = json->get_data();
    Dictionary loaded = data;
    String name = loaded["player_name"];
}

Resource ir Godot iebūvēta klase resursu (audio, attēli, custom data) saglabāšanai .tres failos.

Kā šo izmantot projektā

Atceries: ar redzamu efektu editorā nepietiek. Paskaidro, kura C++ klase glabā stāvokli, kura metode to maina un kā Godot node struktūra izmanto šo kodu.

Pārbaudi: C++ kods pārbauda failu kļūdas, validē datus, izmanto versijas lauku un pamato algoritmu sarežģītību.

Praktiskie uzdevumi

1. uzdevums - Pārvērs Dictionary par JSON

Beigās tavs saglabātais fails būs salasāms cilvēkam.

  1. Iekļauj #include <godot_cpp/classes/json.hpp>.
  2. Izveido Dictionary save_data;.
  3. Pievieno tam player_name, level un score.
  4. Pārvērs to ar String json_str = JSON::stringify(save_data, " ");.
  5. Ieraksti rezultātu failā user://save.json.
  6. Atver failu teksta redaktorā un apskati saturu.
  7. Pieraksti, ko dara otrais stringify arguments.

Gatavs, kad: fails save.json ir salasāms ar atkāpēm un satur visas trīs vērtības.

2. uzdevums - Nolasi JSON atpakaļ

Beigās spēle atjaunos stāvokli no salasāma faila.

  1. Nolasi faila saturu ar get_as_text().
  2. Izveido Ref<JSON> json; un izsauc json->parse(text);.
  3. Paņem rezultātu ar Dictionary d = json->get_data();.
  4. Izdrukā visas trīs vērtības.
  5. Pārbaudi, vai skaitlis ielādējas kā skaitlis, nevis kā teksts.
  6. Nomaini failā ar roku līmeņa vērtību un palaid vēlreiz.
  7. Pieraksti, kāpēc tas ir gan ērti, gan bīstami.

Gatavs, kad: izdrukātās vērtības sakrīt ar failā redzamajām, arī pēc tam, kad failu izlaboji ar roku.

3. uzdevums - Apstrādā bojātu JSON

Beigās bojāts fails vairs nenogāzīs spēli.

  1. Atver save.json un izdzēs vienu figūriekavu.
  2. Palaid spēli un pieraksti, kas notiek.
  3. Pievieno pārbaudi Error err = json->parse(text);.
  4. Pārbaudi if (err != OK) un izdrukā brīdinājumu.
  5. Atgriez tādā gadījumā noklusējuma vērtības.
  6. Palaid ar bojātu failu vēlreiz un pārliecinies, ka spēle turpina darboties.
  7. Salabo failu un pārbaudi, ka ielāde atkal strādā.

Gatavs, kad: ar bojātu JSON spēle parāda brīdinājumu un sāk ar noklusējuma vērtībām, nevis avarē.

Papildu uzdevums - Saglabā sarakstu JSON failā

Ja pamatdarbs ir gatavs, saglabā vairākus rezultātus.

  1. Izveido Array highscores;.
  2. Pievieno tam trīs Dictionary ierakstus ar vārdu un punktiem.
  3. Ieliec masīvu galvenajā Dictionary un saglabā.
  4. Nolasi to atpakaļ un izdrukā ciklā.
  5. Sakārto rezultātus dilstošā secībā pirms izdrukas.

Gatavs, kad: failā ir trīs rezultāti, un ielādējot tie izdrukājas no lielākā uz mazāko.

Ko iesniedz skolotājam

Stundas mērķis: Tava spēle saglabā stāvokli salasāmā JSON failā, ielādē to atpakaļ ar pareiziem datu tipiem un neapstājas, ja fails ir bojāts.

Iesniedzamais:

  1. Fails save.json paraugs un C++ kods ar JSON::stringify un parse.
  2. Ekrānuzņēmums ar Output paneli, kurā redzams brīdinājums par bojātu failu un noklusējuma vērtības.
  3. README.md: kāpēc salasāms saglabāšanas fails ir gan ērts, gan bīstams.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un ekrānuzņēmumu skolotāja norādītajā vietā.

Biežākās kļūdas

  • Crash, parse JSON: Tukšs vai bojāts fails. Pārbaudi err == OK vienmēr.
  • Dictionary keys nav konsistenti: Lieto strukturas vai konstantes (kods centra).
  • Resource fails neielādējas: Path nepareizs vai resurss bojāts.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

Dictionary Player::to_dict() const {
    Dictionary d;
    d["name"] = name;
    d["hp"] = hp;
    d["max_hp"] = max_hp;
    d["level"] = level;
    d["xp"] = xp;
    d["position_x"] = get_position().x;
    d["position_y"] = get_position().y;

    Array inv;
    for (const auto& [item, count] : inventory) {
        Dictionary entry;
        entry["item"] = item;
        entry["count"] = count;
        inv.append(entry);
    }
    d["inventory"] = inv;
    return d;
}

void Player::from_dict(const Dictionary& d) {
    name = d["name"];
    hp = d["hp"];
    max_hp = d["max_hp"];
    level = d["level"];
    xp = d["xp"];
    set_position(Vector2(d["position_x"], d["position_y"]));

    inventory.clear();
    Array inv = d["inventory"];
    for (int i = 0; i < inv.size(); i++) {
        Dictionary e = inv[i];
        inventory[e["item"]] = e["count"];
    }
}
