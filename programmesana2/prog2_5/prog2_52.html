5.2 JSON (JavaScript objektu pieraksts) serialization (serializācija) un Resource (resurss) sistēma

Stundas uzdevums: Saglabāt sarežģītus data structure (datu struktūras), izmantojot JSON un Godot Resource class (klases).

SR 2.4.17. Failu SR 2.4.16. Data structure

Teorija: datu serializācija JSON formātā un Godot Resource sistēma

Serializācija (Stringify) un parsēšana (Parse) ar JSON

Lai vārdnīcas vai sarakstus no operatīvās atmiņas varētu saglabāt failā vai pārsūtīt tīklā, veic serializāciju (serialization) — saliktu datu struktūru pārvēršanu vienotā teksta vai baitu virknē. JSON (JavaScript Object Notation) ir gan cilvēkam, gan datoram lasāms teksta formāts — tas darbojas līdzīgi kā mēbeļu izjaukšana un sapakošana marķētā kastē, kur katrai detaļai pievienota skaidra etiķete ("atslēga": vērtība), lai pēc tam to varētu precīzi salikt atpakaļ.

using Godot;
using Godot.Collections;

// Vārdnīca -> formatēta JSON teksta virkne
Dictionary profils = new();
profils["vards"] = "Anna";
profils["kurss"] = 12;
profils["moduli"] = new Array { "Algoritmi", "Datubāzes" };

string jsonTeksts = Json.Stringify(profils, "    "); // Otrais arguments pievieno atkāpes lasāmībai.

// JSON teksta virkne -> atpakaļ par vārdnīcu
Json json = new();
Error kluda = json.Parse(jsonTeksts);
if (kluda == Error.Ok)
{
    Dictionary ieladets = json.Data.AsGodotDictionary();
    string vards = ieladets["vards"].AsString();
    int kurss = ieladets["kurss"].AsInt32();
}

Bojātu datu apstrāde un atšķirība no Godot Resource

Tā kā JSON failu var atvērt un rediģēt jebkurā teksta redaktorā, to ir ļoti ērti pārbaudīt un atkļūdot. Vienlaikus tas rada divus riskus: lietotājs var failā patvaļīgi izmainīt skaitļus vai nejauši izdzēst kādu pēdiņu vai figūriekavu }. Tāpēc pirms datu nolasīšanas vienmēr pārbauda, vai json.Parse(...) atgrieza Error.Ok; kļūdas gadījumā programma nedrīkst avarēt, bet izvada brīdinājumu un ielādē drošas noklusējuma vērtības, savukārt nolasītos Variant laukus pārvērš vajadzīgajā tipā ar .AsString(), .AsInt32() vai .AsSingle().

Savukārt Resource ir Godot iebūvēta bāzes klase strukturētu resursu (attēlu, skaņu vai pielāgotu C# konfigurācijas klašu ar [Export] īpašībām) glabāšanai .tres (teksta) vai .res (bināros) failos. Resource faili ir cieši integrēti ar Godot Inspector paneli un lieliski der nemainīgiem sagatavju datiem mapē res://, turpretim ārējiem lietotāja datiem mapē user:// drošāks un universālāks ir tīrs JSON teksts:

// 1. Aizsardzība pret bojātu JSON — kļūdas gadījumā atgriež noklusējumus:
Json json = new();
if (json.Parse(teksts) != Error.Ok)
{
    GD.PrintErr("Bojāts JSON fails — tiek ielādēti noklusējumi.");
    return new Dictionary { { "vards", "Viesis" }, { "kurss", 10 } };
}

// 2. Pielāgota Godot Resource klase sagatavju datiem (.tres mapē res://):
[GlobalClass]
public partial class ModulaApraksts : Resource
{
    [Export] public string Nosaukums { get; set; } = "Algoritmi";
    [Export] public int StunduSkaits { get; set; } = 36;
}

1. uzdevums

Pārvērs Dictionary par JSON

Kur strādāt: Turpini Scripts/SaveManager.cs: pievieno metodi SaveJson() un tajā raksti vārdnīcas izveidi, Json.Stringify un ierakstīšanu user://save.json. Izsauc to Scripts/FileDemo.cs metodē _Ready(); using direktīvas liec faila sākumā.

Beigās tavs saglabātais fails būs salasāms cilvēkam.

  1. Pārliecinies, ka faila sākumā ir using Godot.Collections;.
  2. Izveido Godot.Collections.Dictionary saveData = new();.
  3. Pievieno tam player_name, level un score.
  4. Pārvērs to ar string jsonStr = Json.Stringify(saveData, " ");.
  5. Ieraksti rezultātu failā user://save.json.
  6. Atver failu teksta redaktorā un apskati saturu.
  7. Pieraksti, ko dara otrais stringify argument (arguments).
Godot.Collections.Dictionary saveData = new();
saveData["player_name"] = "Anna";
saveData["level"] = 5;
saveData["score"] = 150;

string jsonStr = Json.Stringify(saveData, "    "); // 4 atstarpju atkāpe

Gatavs, kad: fails save.json ir salasāms ar atkāpēm un satur visas trīs vērtības.

2. uzdevums

Nolasi JSON atpakaļ

Kur strādāt: Failā Scripts/SaveManager.cs pievieno LoadJson() ar lasīšanu un parsēšanu; izsauc to no Scripts/FileDemo.cs metodes _Ready(). Vērtību ar roku maini user://save.json; šīs pārbaudes laikā pirms ielādes neizsauc SaveJson().

Beigās spēle atjaunos stāvokli no salasāma faila.

  1. Nolasi faila saturu ar GetAsText().
  2. Izveido Json json = new(); un izsauc json.Parse(text);.
  3. Paņem rezultātu ar Dictionary d = json.Data.AsGodotDictionary();.
  4. Izdrukā visas trīs vērtības.
  5. Pārbaudi, vai skaitlis ielādējas kā skaitlis, nevis kā teksts.
  6. Nomaini failā ar roku līmeņa vērtību un palaid vēlreiz.
  7. Pieraksti, kāpēc tas ir gan ērti, gan bīstami.
Json json = new();
Error err = json.Parse(jsonStr);
if (err == Error.Ok)
{
    Godot.Collections.Dictionary loaded = json.Data.AsGodotDictionary();
    string name = loaded["player_name"].AsString();
    int level = loaded["level"].AsInt32();
}

Gatavs, kad: izdrukātās vērtības sakrīt ar failā redzamajām, arī pēc tam, kad failu izlaboji ar roku.

3. uzdevums

Apstrādā bojātu JSON

Kur strādāt: Kļūdas pārbaudi un noklusējumus pievieno Scripts/SaveManager.cs metodei LoadJson(). Figūriekavu izdzēs un pēc pārbaudes atjauno datu failā user://save.json.

Beigās bojāts fails vairs nenogāzīs spēli.

  1. Atver save.json un izdzēs vienu figūriekavu.
  2. Palaid spēli un pieraksti, kas notiek.
  3. Pievieno pārbaudi Error err = json.Parse(text);.
  4. Pārbaudi if (err != Error.Ok) un izdrukā brīdinājumu.
  5. Atgriez tādā gadījumā noklusējuma vērtības.
  6. Palaid ar bojātu failu vēlreiz un pārliecinies, ka spēle turpina darboties.
  7. Salabo failu un pārbaudi, ka ielāde atkal strādā.

Gatavs, kad: ar bojātu JSON spēle parāda brīdinājumu un sāk ar noklusējuma vērtībām, nevis avarē.

Papildu uzdevums - Saglabā sarakstu JSON failā

Kur strādāt: Saraksta saglabāšanu pievieno Scripts/SaveManager.cs metodei SaveJson(), bet nolasīšanu, kārtošanu un izdruku — LoadJson().

Ja pamatdarbs ir gatavs, saglabā vairākus rezultātus.

  1. Izveido Godot.Collections.Array highscores = new();.
  2. Pievieno tam trīs Dictionary ierakstus ar vārdu un punktiem.
  3. Ieliec array (masīvu) galvenajā Dictionary un saglabā.
  4. Nolasi to atpakaļ un izdrukā loop (ciklā).
  5. Sakārto rezultātus dilstošā secībā pirms izdrukas.

Gatavs, kad: failā ir trīs rezultāti, un ielādējot tie izdrukājas no lielākā uz mazāko.

Paplašināts koda piemērs 
using Godot;
using Godot.Collections;
using System.Collections.Generic;

public partial class Player : CharacterBody2D
{
    private string playerName;
    private int hp;
    private int maxHp;
    private int level;
    private int xp;
    private Dictionary<string, int> inventory = new();

    public Godot.Collections.Dictionary ToDict()
    {
        Godot.Collections.Dictionary data = new();
        data["name"] = playerName;
        data["hp"] = hp;
        data["max_hp"] = maxHp;
        data["level"] = level;
        data["xp"] = xp;
        data["position_x"] = Position.X;
        data["position_y"] = Position.Y;

        Array inv = new();
        foreach ((string item, int count) in inventory)
        {
            Godot.Collections.Dictionary entry = new();
            entry["item"] = item;
            entry["count"] = count;
            inv.Add(entry);
        }
        data["inventory"] = inv;
        return data;
    }

    public void FromDict(Godot.Collections.Dictionary data)
    {
        playerName = data["name"].AsString();
        hp = data["hp"].AsInt32();
        maxHp = data["max_hp"].AsInt32();
        level = data["level"].AsInt32();
        xp = data["xp"].AsInt32();
        Position = new Vector2(data["position_x"].AsSingle(), data["position_y"].AsSingle());
    }
}
Saglabāt fails saturēs JSON ar player datiem; pēc ielādēt - viss stāvoklis atjaunots korekti.

Ko sagatavo

Stundas mērķis: Tava spēle saglabā stāvokli salasāmā JSON failā, ielādē to atpakaļ ar pareiziem data type (datu tipiem) un neapstājas, ja fails ir bojāts.

GitHub krātuvē jābūt:

  • Fails save.json paraugs un C# kods ar Json.Stringify un Parse.
  • Ekrānuzņēmums ar Output paneli, kurā redzams brīdinājums par bojātu failu un noklusējuma vērtības.
  • README.md: kāpēc salasāms saglabāšanas fails ir gan ērts, gan bīstams.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Crash, parse JSON: Tukšs vai bojāts fails. Pārbaudi err == OK vienmēr.
  • Dictionary keys (vārdnīcas atslēga) nav konsistenti: Lieto strukturas vai constant (konstantes) (kods centra).
  • Resource fails neielādējas: Ceļš nepareizs vai resurss bojāts.
