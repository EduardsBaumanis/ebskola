5.2 JSON (JavaScript objektu pieraksts) serialization (serializācija) un Resource (resurss) sistēma

Sasniedzamais rezultāts: Saglabāt sarežģītus data structure (datu struktūras), izmantojot JSON un Godot Resource class (klases).

SR 2.4.17. Failu SR 2.4.16. Data structure

Teorija: datu serializācija JSON formātā un Godot Resource sistēma

Serializācija (Stringify) un parsēšana (Parse) ar JSON

Lai vārdnīcas vai sarakstus no operatīvās atmiņas varētu saglabāt failā vai pārsūtīt tīklā, veic serializāciju (serialization) — saliktu datu struktūru pārvēršanu vienotā teksta vai baitu virknē. JSON (JavaScript Object Notation) ir gan cilvēkam, gan datoram lasāms teksta formāts — tas darbojas līdzīgi kā mēbeļu izjaukšana un sapakošana marķētā kastē, kur katrai detaļai pievienota skaidra etiķete ("atslēga": vērtība), lai pēc tam to varētu precīzi salikt atpakaļ.

using Godot;
using Godot.Collections;

// Vārdnīca -> formatēta JSON teksta virkne
Dictionary profils = new();
profils["vards"] = "Anna";
profils["kurss"] = 12;
profils["moduli"] = new Array { "Algoritmi", "Datubāzes" };

string jsonTeksts = Json.Stringify(profils, "    "); // Otrais arguments pievieno atkāpes lasāmībai.

// JSON teksta virkne -> atpakaļ par vārdnīcu
Json json = new();
Error kluda = json.Parse(jsonTeksts);
if (kluda == Error.Ok)
{
    Dictionary ieladets = json.Data.AsGodotDictionary();
    string vards = ieladets["vards"].AsString();
    int kurss = ieladets["kurss"].AsInt32();
}

Bojātu datu apstrāde un atšķirība no Godot Resource

Tā kā JSON failu var atvērt un rediģēt jebkurā teksta redaktorā, to ir ļoti ērti pārbaudīt un atkļūdot. Vienlaikus tas rada divus riskus: lietotājs var failā patvaļīgi izmainīt skaitļus vai nejauši izdzēst kādu pēdiņu vai figūriekavu }. Tāpēc pirms datu nolasīšanas vienmēr pārbauda, vai json.Parse(...) atgrieza Error.Ok; kļūdas gadījumā programma nedrīkst avarēt, bet izvada brīdinājumu un ielādē drošas noklusējuma vērtības, savukārt nolasītos Variant laukus pārvērš vajadzīgajā tipā ar .AsString(), .AsInt32() vai .AsSingle().

Savukārt Resource ir Godot iebūvēta bāzes klase strukturētu resursu (attēlu, skaņu vai pielāgotu C# konfigurācijas klašu ar [Export] īpašībām) glabāšanai .tres (teksta) vai .res (bināros) failos. Resource faili ir cieši integrēti ar Godot Inspector paneli un lieliski der nemainīgiem sagatavju datiem mapē res://, turpretim ārējiem lietotāja datiem mapē user:// drošāks un universālāks ir tīrs JSON teksts:

// 1. Aizsardzība pret bojātu JSON — kļūdas gadījumā atgriež noklusējumus:
Json json = new();
if (json.Parse(teksts) != Error.Ok)
{
    GD.PrintErr("Bojāts JSON fails — tiek ielādēti noklusējumi.");
    return new Dictionary { { "vards", "Viesis" }, { "kurss", 10 } };
}

// 2. Pielāgota Godot Resource klase sagatavju datiem (.tres mapē res://):
[GlobalClass]
public partial class ModulaApraksts : Resource
{
    [Export] public string Nosaukums { get; set; } = "Algoritmi";
    [Export] public int StunduSkaits { get; set; } = 36;
}

1. uzdevums

Pārvērs Dictionary par salasāmu JSON failu

Kur strādāt: 1) Esošajā failā Scripts/SaveManager.cs (no 5.1. stundas) pievieno using Godot.Collections; un metodi SaveJson(string playerName, int level, int score).
2) Esošajā failā Scripts/FileDemo.cs (piesaistīts Scenes/FileDemo.tscn) metodē _Ready() izsauc SaveJson("Anna", 5, 150).
3) Izveidoto failu user://save.json apskati caur Project → Open User Data Folder.

Bināro failu no 5.1. stundas teksta redaktorā izlasīt nevarēja. Tagad saglabāsim spēlētāja datus strukturētā, cilvēkam salasāmā JSON failā user://save.json.

  1. Atver failu Scripts/SaveManager.cs un pašā faila augšā pievieno rindu: 
    using Godot.Collections;
  2. Tajā pašā Scripts/SaveManager.cs failā pievieno konstanti JsonPath un metodi SaveJson(string playerName, int level, int score), kas izveido Godot.Collections.Dictionary, pārvērš to JSON tekstā ar 4 atstarpju atkāpi un ieraksta failā: 
    private const string JsonPath = "user://save.json";

public void SaveJson(string playerName, int level, int score)
{
    Dictionary saveData = new()
    {
        ["player_name"] = playerName,
        ["level"] = level,
        ["score"] = score
    };

    string jsonText = Json.Stringify(saveData, "    ");

    using FileAccess file = FileAccess.Open(JsonPath, FileAccess.ModeFlags.Write);
    if (file != null)
    {
        file.StoreString(jsonText);
        GD.Print($"[SaveManager] JSON saglabāts failā {JsonPath}:\n{jsonText}");
    }
}
  3. Atver failu Scripts/FileDemo.cs un metodē _Ready() izsauc jauno metodi: 
    SaveManager saveManager = new();
saveManager.SaveJson("Anna", 5, 150);
  4. Nospied Build un palaid scēnu Scenes/FileDemo.tscn (F5).
  5. Atver Project → Open User Data Folder, atrodi failu save.json un atver to teksta redaktorā — pārliecinies, ka tajā ir skaisti formatēts JSON objekts ar atslēgām "player_name", "level" un "score".

Gatavs, kad: lietotāja datu mapē ir izveidots fails save.json ar atkāpēm un visām trim atslēgām ("player_name", "level", "score").

2. uzdevums

Nolasi un parsē JSON failu atpakaļ vārdnīcā

Kur strādāt: 1) Failā Scripts/SaveManager.cs pievieno metodi LoadJson().
2) Failā Scripts/FileDemo.cs metodē _Ready() nolasi atgriezto vārdnīcu un izdrukā laukus.
3) Pārbaudei ar roku izmaini "level" vērtību failā user://save.json.

Tagad nolasīsim user://save.json saturu atpakaļ C# programmā, pārvērtīsim JSON tekstu par Godot.Collections.Dictionary un nolasīsim katru vērtību ar tās īsto datu tipu (.AsString() un .AsInt32()).

  1. Atver failu Scripts/SaveManager.cs un pievieno metodi LoadJson(): 
    public Dictionary LoadJson()
{
    using FileAccess file = FileAccess.Open(JsonPath, FileAccess.ModeFlags.Read);
    string text = file.GetAsText();

    Json json = new();
    Error err = json.Parse(text);
    if (err == Error.Ok)
    {
        return json.Data.AsGodotDictionary();
    }
    return new Dictionary();
}
  2. Atver failu Scripts/FileDemo.cs un metodē _Ready() aiz SaveJson(...) izsaukuma pievieno ielādi un tipizētu vērtību izdruku: 
    Dictionary loaded = saveManager.LoadJson();
string name = loaded["player_name"].AsString();
int level = loaded["level"].AsInt32();
int score = loaded["score"].AsInt32();

GD.Print($"[FileDemo] Ielādēts — Spēlētājs: {name}, Līmenis: {level} (+1 = {level + 1}), Punkti: {score}");
  3. Nospied Build un palaid scēnu (F5): pārliecinies, ka Output konsolē parādās Spēlētājs: Anna, Līmenis: 5 (+1 = 6), Punkti: 150 (kas pierāda, ka level ir nolasīts kā vesels skaitlis int, nevis teksts).
  4. Pārbaudi manuālu rediģēšanu: failā Scripts/FileDemo.cs aizkomentē rindu // saveManager.SaveJson("Anna", 5, 150);, tad atver user://save.json teksta redaktorā, nomaini "level": 5 uz "level": 99 un saglabā failu.
  5. Nospied Build un palaid spēli (F5): pārliecinies, ka spēle ielādē tavu ar roku ierakstīto Līmenis: 99!

Gatavs, kad: spēle korekti nolasa save.json laukus kā string un int, un atspoguļo izmaiņas, ko veici failā ar teksta redaktoru.

3. uzdevums

Apstrādā bojātu vai trūkstošu JSON failu

Kur strādāt: 1) Failā Scripts/SaveManager.cs pievieno palīgmetodi CreateDefaultData() un papildini LoadJson() ar kļūdu apstrādi.
2) Pārbaudei apzināti sabojā sintaksi failā user://save.json.
3) Secinājumus pieraksti projekta saknes failā README.md.

Ja spēlētājs rediģējot save.json nejauši izdzēš pēdiņu vai figūriekavu }, json.Parse(text) atgriež kļūdu, un nepārbaudīta piekļuve loaded["player_name"] nogāž spēli. Padarīsim LoadJson() pilnīgi drošu.

  1. Atver failu Scripts/SaveManager.cs un pievieno palīgmetodi CreateDefaultData(), kas atgriež drošas sākuma vērtības: 
    private Dictionary CreateDefaultData()
{
    return new Dictionary
    {
        ["player_name"] = "Viesis",
        ["level"] = 1,
        ["score"] = 0
    };
}
  2. Tajā pašā Scripts/SaveManager.cs failā atjaunini metodi LoadJson(), lai tā pārbaudītu gan faila esamību, gan err != Error.Ok: 
    public Dictionary LoadJson()
{
    if (!FileAccess.FileExists(JsonPath))
    {
        GD.PrintErr($"[SaveManager] Fails {JsonPath} nav atrasts — lietojam noklusējumus.");
        return CreateDefaultData();
    }

    using FileAccess file = FileAccess.Open(JsonPath, FileAccess.ModeFlags.Read);
    if (file == null) return CreateDefaultData();

    string text = file.GetAsText();
    Json json = new();
    Error err = json.Parse(text);

    if (err != Error.Ok)
    {
        GD.PrintErr($"[SaveManager] Bojāts JSON fails (rinda {json.GetErrorLine()}: {json.GetErrorMessage()}) — lietojam noklusējumus!");
        return CreateDefaultData();
    }

    return json.Data.AsGodotDictionary();
}
  3. Pārbaudi aizsardzību: pārliecinies, ka Scripts/FileDemo.cs rinda SaveJson(...) ir aizkomentēta, atver user://save.json teksta redaktorā, izdzēs pašu pēdējo figūriekavu } un saglabā failu.
  4. Nospied Build un palaid spēli (F5): pārliecinies, ka spēle neavarē, bet Output konsolē izdrukā brīdinājumu Bojāts JSON fails ... lietojam noklusējumus! un ielādē Spēlētājs: Viesis, Līmenis: 1, Punkti: 0.
  5. Atkomentē saveManager.SaveJson("Anna", 5, 150); failā Scripts/FileDemo.cs un palaid spēli vēlreiz, lai atjaunotu derīgu save.json failu.
  6. Projekta saknē atver README.md un pieraksti:
    • ko dara otrais arguments metodē Json.Stringify(saveData, ...);
    • kāpēc salasāms JSON saglabāšanas fails izstrādātājam ir ērts, bet kāpēc tam nekad nedrīkst uzticēties bez Error.Ok pārbaudes.

Gatavs, kad: ar sabojātu save.json failu spēle neavarē, bet parāda brīdinājumu un ielādē noklusējuma datus (Viesis, 1, 0).

Papildu uzdevums — Saglabā rekordu sarakstu (Array) JSON failā

Kur strādāt: Papildini Scripts/SaveManager.cs metodi SaveJson(...) ar rekordu sarakstu Godot.Collections.Array un nolasi to Scripts/FileDemo.cs metodē _Ready().

Ja pamatdarbs ir gatavs, pievieno save.json failam ligzdotu sarakstu ar 3 labākajiem rezultātiem.

  1. Failā Scripts/SaveManager.cs metodē SaveJson(...) izveido Godot.Collections.Array highscores = new() { 250, 180, 150 }; un pievieno to vārdnīcai: saveData["highscores"] = highscores;.
  2. Failā Scripts/FileDemo.cs pēc LoadJson() nolasīšanas pārbaudi if (loaded.ContainsKey("highscores")), iegūsti masīvu ar Array scores = loaded["highscores"].AsGodotArray(); un ar foreach (Variant s in scores) izdrukā visus rekordus.

Gatavs, kad: failā save.json redzams lauks "highscores": [ 250, 180, 150 ] un visi trīs skaitļi izdrukājas Output konsolē.

Pilnie faili salīdzināšanai

1. fails — Scripts/SaveManager.cs:

using Godot;
using Godot.Collections;

public partial class SaveManager : Node
{
    private const string ScorePath = "user://score.bin";
    private const string JsonPath = "user://save.json";

    public void SaveScore(int score)
    {
        using FileAccess file = FileAccess.Open(ScorePath, FileAccess.ModeFlags.Write);
        if (file != null)
        {
            file.Store32((uint)score);
        }
    }

    public int LoadScore()
    {
        if (!FileAccess.FileExists(ScorePath)) return 0;

        using FileAccess file = FileAccess.Open(ScorePath, FileAccess.ModeFlags.Read);
        return file != null ? (int)file.Get32() : 0;
    }

    public void SaveJson(string playerName, int level, int score)
    {
        Dictionary saveData = new()
        {
            ["player_name"] = playerName,
            ["level"] = level,
            ["score"] = score
        };

        string jsonText = Json.Stringify(saveData, "    ");

        using FileAccess file = FileAccess.Open(JsonPath, FileAccess.ModeFlags.Write);
        if (file != null)
        {
            file.StoreString(jsonText);
            GD.Print($"[SaveManager] JSON saglabāts failā {JsonPath}:\n{jsonText}");
        }
    }

    public Dictionary LoadJson()
    {
        if (!FileAccess.FileExists(JsonPath))
        {
            GD.PrintErr($"[SaveManager] Fails {JsonPath} nav atrasts — lietojam noklusējumus.");
            return CreateDefaultData();
        }

        using FileAccess file = FileAccess.Open(JsonPath, FileAccess.ModeFlags.Read);
        if (file == null) return CreateDefaultData();

        string text = file.GetAsText();
        Json json = new();
        Error err = json.Parse(text);

        if (err != Error.Ok)
        {
            GD.PrintErr($"[SaveManager] Bojāts JSON fails (rinda {json.GetErrorLine()}: {json.GetErrorMessage()}) — lietojam noklusējumus!");
            return CreateDefaultData();
        }

        return json.Data.AsGodotDictionary();
    }

    private Dictionary CreateDefaultData()
    {
        return new Dictionary
        {
            ["player_name"] = "Viesis",
            ["level"] = 1,
            ["score"] = 0
        };
    }
}

Saglabāšanas fails user://save.json satur cilvēkam salasāmu JSON ar atkāpēm; ielādes metode atjauno pareizos datu tipus vai bojāta faila gadījumā droši atgriež noklusējumus.

Ko sagatavo

Stundas mērķis: Tava spēle saglabā stāvokli salasāmā user://save.json failā, ielādē to atpakaļ ar pareiziem datu tipiem (.AsString(), .AsInt32()) un neapstājas, ja fails ir bojāts.

GitHub krātuvē jābūt:

  • Atjauninātajiem skriptiem Scripts/SaveManager.cs un Scripts/FileDemo.cs, kā arī save.json paraugam.
  • Ekrānuzņēmumam ar Output paneli, kurā redzams brīdinājums par bojātu JSON failu un ielādētās noklusējuma vērtības.
  • Failam README.md ar skaidrojumu, kāpēc salasāms JSON saglabāšanas fails ir gan ērts, gan bīstams.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Crash, parse JSON: Tukšs vai bojāts fails. Pārbaudi err == OK vienmēr.
  • Dictionary keys (vārdnīcas atslēga) nav konsistenti: Lieto strukturas vai constant (konstantes) (kods centra).
  • Resource fails neielādējas: Ceļš nepareizs vai resurss bojāts.
