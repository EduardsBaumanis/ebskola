Teorija: JSON (JavaScript objektu pieraksts) un Resources (resurss)

JSON (JavaScript objektu pieraksts) ir cilvēkam un mašīnai lasāms data format (datu formāts). Godot piedāvā JSON (datu apmaiņas formāts) class (klasi) tā parsing (parsēšanai).

using Godot;
using Godot.Collections;

// Dictionary -> JSON string
Dictionary saveData = new();
saveData["player_name"] = "Anna";
saveData["level"] = 5;
saveData["inventory"] = new Array(); // var saturēt vēl Dictionary

string jsonStr = Json.Stringify(saveData, "  ");  // 2-space indent

// JSON string -> Dictionary
Json json = new Json();
Error err = json.Parse(jsonStr);
if (err == Error.Ok)
{
    Dictionary loaded = json.Data.AsGodotDictionary();
    string name = loaded["player_name"].AsString();
}

Resource (resurss) ir Godot iebūvēta class (klase) resource (resursu) (audio (skaņa), attēli, custom data (pielāgoti dati)) save (saglabāšanai) .tres file (failos).

Praktiskie uzdevumi

1. uzdevums -

Pārvērs Dictionary (vārdnīca) par JSON (JavaScript objektu pieraksts)

Beigās tavs saglabātais file (fails) būs salasāms cilvēkam.

  1. Pārliecinies, ka file (faila) sākumā ir using Godot.Collections;.
  2. Izveido Godot.Collections.Dictionary saveData = new();.
  3. Pievieno tam player_name, level un score.
  4. Pārvērs to ar string jsonStr = Json.Stringify(saveData, " ");.
  5. Ieraksti rezultātu file (failā) user://save.json.
  6. Atver file (failu) teksta editor (redaktorā) un apskati saturu.
  7. Pieraksti, ko dara otrais stringify arguments (arguments).

Gatavs, kad: file (fails) save.json ir salasāms ar atkāpēm un satur visas trīs value (vērtības).

2. uzdevums -

Nolasi JSON (JavaScript objektu pieraksts) atpakaļ

Beigās spēle atjaunos state (stāvokli) no salasāma file (faila).

  1. Nolasi file (faila) saturu ar GetAsText().
  2. Izveido Json json = new(); un izsauc json.Parse(text);.
  3. Paņem rezultātu ar Dictionary d = json.Data.AsGodotDictionary();.
  4. Izdrukā visas trīs value (vērtības).
  5. Pārbaudi, vai skaitlis ielādējas kā skaitlis, nevis kā teksts.
  6. Nomaini file (failā) ar roku līmeņa value (vērtību) un palaid vēlreiz.
  7. Pieraksti, kāpēc tas ir gan ērti, gan bīstami.

Gatavs, kad: izdrukātās value (vērtības) sakrīt ar file (failā) redzamajām, arī pēc tam, kad file (failu) izlaboji ar roku.

3. uzdevums -

Apstrādā bojātu JSON (JavaScript objektu pieraksts)

Beigās bojāts file (fails) vairs nenogāzīs spēli.

  1. Atver save.json un izdzēs vienu figūriekavu.
  2. Palaid spēli un pieraksti, kas notiek.
  3. Pievieno pārbaudi Error err = json.Parse(text);.
  4. Pārbaudi if (err != Error.Ok) un izdrukā brīdinājumu.
  5. Atgriez tādā gadījumā default value (noklusējuma vērtības).
  6. Palaid ar bojātu file (failu) vēlreiz un pārliecinies, ka spēle turpina darboties.
  7. Salabo file (failu) un pārbaudi, ka load (ielāde) atkal strādā.

Gatavs, kad: ar bojātu JSON (JavaScript objektu pieraksts) spēle parāda brīdinājumu un sāk ar noklusējuma value (vērtībām), nevis avarē.

Papildu uzdevums - Saglabā list (sarakstu) JSON (JavaScript objektu pieraksts) file (failā)

Ja pamatdarbs ir gatavs, saglabā vairākus rezultātus.

  1. Izveido Godot.Collections.Array highscores = new();.

  3. Ieliec array (masīvu) galvenajā Dictionary (vārdnīca) un saglabā.
  4. Nolasi to atpakaļ un izdrukā loop (ciklā).

using Godot;
using Godot.Collections;
using System.Collections.Generic;

public partial class Player : CharacterBody2D
{
    private string playerName;
    private int hp;
    private int maxHp;
    private int level;
    private int xp;
    private Dictionary<string, int> inventory = new();

    public Godot.Collections.Dictionary ToDict()
    {
        Godot.Collections.Dictionary data = new();
        data["name"] = playerName;
        data["hp"] = hp;
        data["max_hp"] = maxHp;
        data["level"] = level;
        data["xp"] = xp;
        data["position_x"] = Position.X;
        data["position_y"] = Position.Y;

        Array inv = new();
        foreach ((string item, int count) in inventory)
        {
            Godot.Collections.Dictionary entry = new();
            entry["item"] = item;
            entry["count"] = count;
            inv.Add(entry);
        }
        data["inventory"] = inv;
        return data;
    }

    public void FromDict(Godot.Collections.Dictionary data)
    {
        playerName = data["name"].AsString();
        hp = data["hp"].AsInt32();
        maxHp = data["max_hp"].AsInt32();
        level = data["level"].AsInt32();
        xp = data["xp"].AsInt32();
        Position = new Vector2(data["position_x"].AsSingle(), data["position_y"].AsSingle());
    }
}
