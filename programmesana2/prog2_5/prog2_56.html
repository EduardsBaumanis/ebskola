Teorija: īslaicīgā un pastāvīgā stāvokļa nošķiršana procedurālās sistēmās

Īslaicīgie sesijas dati pret pastāvīgajiem datiem

Daudzposmu programmās datus pēc to dzīves cikla iedala divās kategorijās: īslaicīgajā jeb sesijas stāvoklī (transient / session state) un pastāvīgajā stāvoklī (persistent state). To var salīdzināt ar treniņu lietotni telefonā — viena skrējiena hronometrs un pašreizējais temps darbojas tikai konkrētā treniņa laikā un nākamajā reizē sākas no nulles, turpretim kopējais mēneša kilometru skaits un personīgais rekords tiek saglabāti profilā starp visām sesijām:

// Īslaicīgie sesijas dati — glabājas tikai operatīvajā atmiņā (RAM)
public class SesijasStavoklis
{
    public int PasreizejaisPosms = 1;
    public int SesijasPunkti = 0;
    public void Atiestatit() { PasreizejaisPosms = 1; SesijasPunkti = 0; }
}

// Pastāvīgie dati — tiek serializēti JSON failā mapē user://
public class PastavigaisProgress
{
    public int KopejiePunkti = 0;
    public int AugstakaisPosms = 1;
}

Nošķirot abas datu grupas atsevišķās C# klasēs, sesijas pārtraukšana vai restarts atiestata tikai SesijasStavoklis laukus, nejauši neizdzēšot ilgtermiņa uzkrājumu un neierakstot diskā pagaidu mainīgos.

Procedurālas vides posmu izpildes plūsma un datu saskaņotība

Apvienojot procedurālu režģa ģenerēšanu, dinamisku objektu izvietošanu un failu saglabāšanu vienā sistēmā, izpildi organizē stingrā secībā:

  • Ģenerēšana un sasniedzamības pārbaude: katra jauna posma sākumā algoritms izveido 2D datu režģi un ar apgabala aizpildīšanu (flood fill) pārliecinās, ka ceļš no sākumpunkta līdz izejas zonai ir nepārtraukts, pirms scēnā tiek izvietoti vizuālie mezgli.
  • Objektu izvietošana derīgajās koordinātās: papildu interaktīvās zonas (Area2D) nekad nenovieto aklā nejaušībā pa visu laukumu — vispirms savāc brīvo šūnu koordinātas (rezgis[x, y] == 0, izņemot sākuma un beigu punktu) sarakstā un izvēlas pozīcijas tikai no šīs kopas, lai objekti neiesprūstu sienās.
  • Droša pāreju un saglabāšanas secība: noslēdzot posmu vai sesiju, vispirms pieskaita rezultātus pastāvīgajam progresam un ieraksta pārbaudītu JSON failu mapē user://, un tikai pēc tam notīra vai pārbūvē nākamā posma scēnu:
// 1. Savāc tikai brīvās šūnas (izlaižot sākumpunktu un izejas punktu):

for (int x = 0; x < Platums; x++)
{

        Vector2I p = new Vector2I(x, y);

// 2. Vispirms saglabā pastāvīgo progresu, tad atiestata sesiju:
progress.KopejiePunkti += sesija.SesijasPunkti;
progress.AugstakaisPosms = Math.Max(

using Godot;
using System;
using System.Collections.Generic;

public class MazeGenerator
{
    public const int Width = 15;
    public const int Height = 15;

    private readonly int[,] grid = new int[Width, Height];

    public Vector2I StartPos { get; } = new Vector2I(1, 1);
    public Vector2I ExitPos { get; } = new Vector2I(Width - 2, Height - 2);

    public int GetCell(int x, int y) => grid[x, y];

    public void GenerateOnce(int seed)
    {
        Random rng = new Random(seed);

        for (int x = 0; x < Width; x++)
        {
            for (int y = 0; y < Height; y++)
            {
                grid[x, y] = 1;
            }
        }

        int px = StartPos.X;
        int py = StartPos.Y;
        grid[px, py] = 0;

        for (int step = 0; step < 220; step++)
        {
            int dir = rng.Next(0, 4);
            if (dir == 0 && px > 1) px--;
            else if (dir == 1 && px < Width - 2) px++;
            else if (dir == 2 && py > 1) py--;
            else if (dir == 3 && py < Height - 2) py++;

            grid[px, py] = 0;
        }

        grid[ExitPos.X, ExitPos.Y] = 0;
    }

    public int GenerateValidMaze(int baseSeed)
    {
        int attempts = 0;
        do
        {
            GenerateOnce(baseSeed + attempts);
            attempts++;
        }
        while (!IsExitReachable() && attempts < 100);

        return attempts;
    }

    public bool IsExitReachable()
    {
        bool[,] visited = new bool[Width, Height];
        FloodFill(StartPos.X, StartPos.Y, visited);
        return visited[ExitPos.X, ExitPos.Y];
    }

    private void FloodFill(int x, int y, bool[,] visited)
    {
        if (x < 0 || x >= Width || y < 0 || y >= Height) return;
        if (grid[x, y] != 0 || visited[x, y]) return;

        visited[x, y] = true;

        FloodFill(x + 1, y, visited);
        FloodFill(x - 1, y, visited);
        FloodFill(x, y + 1, visited);
        FloodFill(x, y - 1, visited);
    }

    public List<Vector2I> GetFreeFloorCells()
    {
        List<Vector2I> free = new();
        for (int x = 0; x < Width; x++)
        {
            for (int y = 0; y < Height; y++)
            {
                Vector2I pos = new(x, y);
                if (grid[x, y] == 0 && pos != StartPos && pos != ExitPos)
                {
                    free.Add(pos);
                }
            }
        }
        return free;
    }
}

            Name = "ExitZone",
            Position = GridToWorld(generator.ExitPos)
        };
        CollisionShape2D col = new()
        {
            Shape = new RectangleShape2D { Size = new Vector2(CellSize - 8, CellSize - 8) }
        };
        exitArea.AddChild(col);

        ColorRect rect = new()
        {
            Size = new Vector2(CellSize - 6, CellSize - 6),
            Position = new Vector2(-(CellSize - 6) / 2.0f, -(CellSize - 6) / 2.0f),
            Color = new Color(0.2f, 0.85f, 0.38f)
        };
        exitArea.AddChild(rect);
        exitArea.BodyEntered += OnExitReached;
        mazeContainer.AddChild(exitArea);
    }

    private void SpawnItemsAndHazards(int seed)
    {
        List<Vector2I> freeCells = generator.GetFreeFloorCells();
        Random rng = new Random(seed);

        // Sajaucam brīvo šūnu secību (Fisher-Yates shuffle)
        for (int i = freeCells.Count - 1; i > 0; i--)
        {
            int j = rng.Next(0, i + 1);
            (freeCells[i], freeCells[j]) = (freeCells[j], freeCells[i]);
        }

        int index = 0;
        int collectibleCount = Math.Min(5, freeCells.Count);
        for (int i = 0; i < collectibleCount; i++)
        {
            CreateCollectible(GridToWorld(freeCells[index++]));
        }

        int hazardCount = Math.Min(2 + currentLevel / 2, freeCells.Count - index);
        for (int i = 0; i < hazardCount; i++)
        {
            CreateHazard(GridToWorld(freeCells[index++]));
        }
    }

    private void CreateCollectible(Vector2 pos)
    {
        Area2D item = new() { Position = pos };
        CollisionShape2D col = new() { Shape = new CircleShape2D { Radius = 10.0f } };
        item.AddChild(col);

        ColorRect visual = new()
        {
            Size = new Vector2(16, 16),
            Position = new Vector2(-8, -8),
            Color = new Color(0.98f, 0.82f, 0.18f) // Dzeltens XP kristāls
        };
        item.AddChild(visual);

        item.BodyEntered += body =>
        {
            if (!runActive || body is not Player) return;
            runXp += 15;
            SetMessage("Savākts materiāls (+15 XP)!");
            UpdateHud();
            item.QueueFree();
        };

        mazeContainer.AddChild(item);
    }

    private void CreateHazard(Vector2 pos)
    {
        Area2D hazard = new() { Position = pos };
        CollisionShape2D col = new() { Shape = new CircleShape2D { Radius = 11.0f } };
        hazard.AddChild(col);

        ColorRect visual = new()
        {
            Size = new Vector2(20, 20),
            Position = new Vector2(-10, -10),
            Color = new Color(0.92f, 0.22f, 0.25f) // Sarkans slazds
        };
        hazard.AddChild(visual);

        hazard.BodyEntered += body =>
        {
            if (!runActive || body is not Player) return;
            lives--;
            SetMessage($"Uzkāpi uz slazda! Atlikušas dzīvības: {lives}");
            hazard.QueueFree();

            if (lives <= 0)
            {
                OnRunFailed();
            }
            else
            {
                UpdateHud();
            }
        };

        mazeContainer.AddChild(hazard);
    }

    private void OnExitReached(Node2D body)
    {
        if (!runActive || body is not Player) return;

        runXp += 25; // Bonuss par līmeņa iziešanu
        currentLevel++;
        bestLevel = Math.Max(bestLevel, currentLevel);

        // Saglabājam pastāvīgo progresu starp līmeņiem
        totalXp += 25;
        saveManager?.Save(1);

        SetMessage($"Līmenis pabeigts! Pārejam uz {currentLevel}. līmeni (+25 XP).");
        CallDeferred(nameof(StartLevel));
    }

    private void OnRunFailed()
    {
        runActive = false;
        if (player != null)
        {
            player.SetPhysicsProcess(false);
            player.Modulate = new Color(0.5f, 0.5f, 0.5f, 0.7f);
        }

        // Pieskaitām mēģinājuma XP pastāvīgajam progresam un saglabājam JSON failā
        totalXp += runXp;
        bestLevel = Math.Max(bestLevel, currentLevel);
        runsCount++;
        saveManager?.Save(1);

        UpdateHud();
        SetMessage($"MĒĢINĀJUMS BEIDZIES {currentLevel}. līmenī!\nKopējais XP saglabāts ({totalXp}). Nospied R jaunam mēģinājumam.");
    }

    public Dictionary SaveState()
    {
        return new Dictionary
        {
            ["total_xp"] = totalXp,
            ["best_level"] = bestLevel,
            ["runs_count"] = runsCount
        };
    }

    public void LoadState(Dictionary state)
    {
        if (state.ContainsKey("total_xp")) totalXp = state["total_xp"].AsInt32();
        if (state.ContainsKey("best_level")) bestLevel = state["best_level"].AsInt32();
        if (state.ContainsKey("runs_count")) runsCount = state["runs_count"].AsInt32();
    }

    private void UpdateHud()
    {
        if (statusLabel == null) return;

        statusLabel.Text =
            $"=== MĒĢINĀJUMS (RUN) ===\n" +
            $"Līmenis: {currentLevel}\n" +
            $"Dzīvības: {lives} / 3\n" +
            $"Mēģinājuma XP: {runXp}\n\n" +
            $"=== META-PROGRESS (JSON) ===\n" +
            $"Kopējais XP: {totalXp}\n" +
            $"Rekorda līmenis: {bestLevel}\n" +
            $"Mēģinājumi: {runsCount}\n\n" +
            $"[WASD — kustība | R — jauns mēģinājums]";
    }

    private void SetMessage(string text)
    {
        if (messageLabel != null)
        {
            messageLabel.Text = text;
        }
        GD.Print($"[MazeGame] {text}");
    }

    private Vector2 GridToWorld(Vector2I cell)
    {
        return new Vector2(cell.X * CellSize + CellSize / 2.0f, cell.Y * CellSize + CellSize / 2.0f);
    }
}

Procedurālā ģenerēšana un izejamības pārbaude
1. uzdevums · 5.4. stunda		 Labirints netiek ģenerēts vai spēlētājs tajā nevar pārvietoties. Labirints tiek uzģenerēts, bet gājējs iziet ārpus malām, sienām nav sadursmju vai dažkārt izeja ir nepieejama aiz sienām. MazeGenerator ar Random Walk izveido 15×15 režģi, ar Flood Fill (IsExitReachable) garantē, ka izeja (13, 13) ir sasniedzama no starta (1, 1), un sasniedzot izeju sākas nākamais līmenis. Izpildīts “Apguvis”; README.md pamatota seed (sēklas) nozīme un izskaidrots, kā rekursīvā Flood Fill metode atrod savienoto apgabalu.
Objektu izvietošana brīvajās šūnās un HUD
2. uzdevums · Pārbaudes		 Labirintā nav savācamo priekšmetu vai šķēršļu. Priekšmeti un šķēršļi parādās, bet dažkārt iedzimst sienās vai virs starta/izejas, vai HUD neatjaunojas. Savācamie kristāli (+XP) un slazdi (-1 dzīvība) tiek izvietoti tikai brīvajās ejas šūnās (GetFreeFloorCells()); HUD nepārtraukti rāda gan mēģinājuma, gan meta-progresa datus. Izpildīts “Apguvis”; grūtība pieaug līdz ar līmeni un README.md paskaidrots, kāpēc objektus izvieto no filtrēta brīvo šūnu saraksta.
JSON saglabāšana, ielāde un kļūdu drošība
3. uzdevums · 5.1.–5.3. stunda		 Spēle nesaglabā vai neielādē datus no user:// mapes. Dati tiek saglabāti failā, bet trūkstošs vai bojāts JSON fails izraisa avāriju vai netiek izmantota ISaveable saskarne. SaveManager saglabā un ielādē ISaveable stāvokli user://slot1.json failā ar Json.Stringify un Json.Parse, pārbaudot FileExists, Error.Ok un faila version. Izpildīts “Apguvis”; README.md paskaidrota res:// un user:// atšķirība un kāpēc ISaveable atdala SaveManager no konkrētās spēles klases.
Sesijas datu un pastāvīgā meta-progresa nošķiršana
3. uzdevums · Pārbaudes		 Pēc zaudējuma spēle nereaģē vai pazūd visi dati. Zaudējot dzīvības mēģinājums beidzas, bet kopējais XP nesummējas starp mēģinājumiem vai netiek atiestatīts līmenis. Zaudējot visas dzīvības, mēģinājuma XP un sasniegtais līmenis vispirms tiek saglabāti pastāvīgajā meta-progresā (total_xp, best_level), un jauns mēģinājums (R vai spēles restarts) sākas no 1. līmeņa, saglabājot meta-progresu. Izpildīts “Apguvis”; README.md skaidri pamatots, kāpēc saglabāšana notiek pirms sesijas mainīgo atiestatīšanas, vai izpildīts papildu uzdevums.

Ja kaut kas nestrādā

  • Save un mēģinājuma beigas: Pārbaudi, ka dzēst saglabāt fails notiek tikai pēc run_end, ne pirms.
  • Veiktspēja ar 50+ šķēršļiem: Lieto spatial hashing (telpisko jaukšanu) un pool (objektu krātuve) no 4. tēmas.
  • Procedural balance: Pārāk daudz/maz bonusa materiālu - pielāgo varbūtības.
