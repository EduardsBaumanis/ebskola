5.1 File I/O (failu ievade un izvade) Godot vidē

Stundas uzdevums: Apgūt FileAccess (failu piekļuve) class (klasi) un Godot file system (failu sistēmu).

Pirms sāc: atceries no Programmēšanas I file (failu) darbu: with open("dati.txt", "w"). Godot to dara FileAccess (failu piekļuve) class (klase). Galvenais jaunums: path (ceļš) user://, nevis parasta folder (mape).

Teorija: FileAccess (failu piekļuve) class (klase)

Godot piedāvā FileAccess (failu piekļuve) class (klasi) file (failu) lasīšanai un rakstīšanai. Tā strādā ar res:// (read-only resources (tikai lasāmi resursi)) un user:// (lokālā lietotāja repository (krātuve)).

using Godot;

// Rakstīšana
using FileAccess file = FileAccess.Open("user://save.txt", FileAccess.ModeFlags.Write);
if (file != null)
{
    file.StoreString("Hello, file!");
    file.StoreLine("Otrā rinda");
    file.Store32(42);  // binary
}

// Lasīšana
using FileAccess readFile = FileAccess.Open("user://save.txt", FileAccess.ModeFlags.Read);
if (readFile != null)
{
    string content = readFile.GetAsText();
    // vai pa rindām:
    while (!readFile.EofReached())
    {
        string line = readFile.GetLine();
    }
}

Praktiskie uzdevumi

1. uzdevums -

Ieraksti un nolasi file (failu)

Beigās tava spēle pratīs saglabāt tekstu diskā.

  1. Pārliecinies, ka file (faila) sākumā ir using Godot;.
  2. Atver file (failu) ar using FileAccess f = FileAccess.Open("user://save.txt", FileAccess.ModeFlags.Write);.
  3. Pārbaudi if (f != null) pirms rakstīšanas.
  4. Ieraksti tekstu ar f.StoreString("Sveiks, fails!");.
  5. Atver file (failu) no jauna režīmā Read un nolasi ar GetAsText().
  6. Izdrukā nolasīto tekstu.
  7. Atrodi file (failu) diskā: Godot menu (izvēlnē) Project (projekts) -> Open User Data Folder (atvērt lietotāja datu mapi).

Gatavs, kad: Output (izvade) panel (panelī) izdrukājas tas pats teksts, ko ierakstīji, un file (fails) ir atrodams user data (lietotāja dati) folder (mapē).

2. uzdevums -

Saglabā spēles rezultātu

Beigās rezultāts saglabāsies arī pēc spēles aizvēršanas.

  1. Izveido class (klasi) SaveManager ar method (metodi) public void SaveScore(int score).
  2. Ieraksti file (failā) rezultātu ar file.Store32((uint)score);.
  3. Uzraksti method (metodi) public int LoadScore(), kas to nolasa ar (int)file.Get32().
  4. Izsauc save (saglabāšanu) ar value (vērtību) 150.
  5. Aizver spēli pilnībā un palaid no jauna.
  6. Izdrukā ielādēto rezultātu.
  7. Pieraksti, kāpēc user:// ir labāks par res:// save (saglabāšanai).

Gatavs, kad: pēc spēles aizvēršanas un atvēršanas ielādētais rezultāts joprojām ir 150.

3. uzdevums -

Apstrādā trūkstošu file (failu)

Beigās pirmā spēles palaišana vairs neradīs kļūdu.

  1. Izdzēs saglabāto file (failu) no user data (lietotāja dati) folder (mapes).
  2. Palaid spēli un pieraksti, kas notiek ar LoadScore().
  3. Pievieno pārbaudi if (!FileAccess.FileExists("user://save.txt")).
  4. Atgriez tādā gadījumā default value (noklusējuma vērtību) 0.
  5. Palaid vēlreiz ar izdzēstu file (failu) un pārbaudi rezultātu.
  6. Saglabā jaunu rezultātu un pārbaudi, ka tas ielādējas.
  7. Pieraksti, ar ko šī pārbaude līdzinās Python FileNotFoundError apstrādei.

Gatavs, kad: ar izdzēstu file (failu) spēle rāda rezultātu 0 un neizmet kļūdu.

Papildu uzdevums - Saglabā vairākas value (vērtības)

Ja pamatdarbs ir gatavs, saglabā visu spēlētāja state (stāvokli).

  1. Papildini save (saglabāšanu) ar HP (dzīvības punkti), līmeni un spēlētāja vārdu.
  2. Ieraksti tos noteiktā secībā ar Store32 un StoreString.
  3. Nolasi tos TIEŠI tādā pašā secībā.
  4. Samaini apzināti divas nolasīšanas rindas vietām un palaid.
  5. Pieraksti, kāpēc secība ir tik svarīga.

Gatavs, kad: visas value (vērtības) ielādējas pareizi, bet, samainot nolasīšanas secību, data (dati) sajūk.

Biežākās kļūdas

  • file is null (fails nav pieejams): Permission denied (piekļuve liegta) vai path (ceļš) nepareizs.
  • Encoding errors (kodējuma kļūdas): UTF-8 (Unicode rakstzīmju kodējums) ir noklusējuma, bet pārbaudi ar speciāliem simboliem.
  • res:// ir read-only (tikai lasāms): Production build (buildos) to nevar rakstīt - lieto user://.

using Godot;

public partial class SaveSystem : Node
{
    public void SaveText(string filename, string content)
    {
        string path = "user://" + filename;
        using FileAccess file = FileAccess.Open(path, FileAccess.ModeFlags.Write);
        if (file != null)
        {
            file.StoreString(content);
            GD.Print("Saglabāts: ", path);
        }
        else
        {
            GD.PrintErr("Neizdevās atvērt: ", path);
        }
    }

    public string LoadText(string filename)
    {
        string path = "user://" + filename;
        if (!FileAccess.FileExists(path)) return "";

        using FileAccess file = FileAccess.Open(path, FileAccess.ModeFlags.Read);
        return file != null ? file.GetAsText() : "";
    }
}
