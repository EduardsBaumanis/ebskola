Atkārtojuma tests: 5.2 JSON serializācija un Resource sistēma

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kas ir serializācija?

Json.Stringify pārvērš vārdnīcu JSON tekstā, bet json.Parse — atpakaļ. Atkārto: 5.2 — Teorija: JSON serializācija un Godot Resource ↗

2. Ko dara otrais arguments " " rindā Json.Stringify(saveData, " ")?

Bez tā viss JSON ir vienā rindā. Ar atkāpēm failu ērti pārbaudīt teksta redaktorā. Atkārto: 5.2 — 1. uzdevums — Pārvērs Dictionary par JSON failu ↗

3. Kāpēc līmeni nolasa ar loaded["level"].AsInt32()?

.AsString(), .AsInt32() un .AsSingle() pārvērš nolasīto vērtību īstajā tipā. Atkārto: 5.2 — 2. uzdevums — Nolasi un parsē JSON ↗

4. Failā save.json izdzēsta pēdējā figūriekava }. Ko dara drošā LoadJson()?

JSON failu var rediģēt jebkurš, tāpēc tam nedrīkst uzticēties bez Error.Ok pārbaudes. Atkārto: 5.2 — 3. uzdevums — Bojāts vai trūkstošs JSON ↗

5. Kad izvēlas Godot Resource (.tres), bet kad — JSON?

Resource faili ir cieši saistīti ar Inspector paneli. JSON ir universāls teksts saglabājumiem. Atkārto: 5.2 — Teorija: JSON serializācija un Godot Resource ↗
