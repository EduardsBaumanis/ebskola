Sasniedzamais rezultāts: Izveido šķēršļa klasi un iestati trīs dažādus šķēršļus Inspector panelī.

SR 2.4.7. UI (lietotāja saskarne) SR 2.4.18. Objektorientētā programmēšana

Teorija: C# īpašības un redaktora atribūti Godot vidē

Viena klase vairākiem mezgliem un atribūti [GlobalClass] un [Export]

Ja vairāki scēnas objekti darbojas pēc vienādiem noteikumiem un atšķiras tikai ar nosaukumu vai skaitlisku parametru, nav jāveido atsevišķs skripts katram vienumam — vienu C# klasi pievieno vairākiem neatkarīgiem mezgliem (ja mezglam nav vajadzīgas koordinātas vai sadursmes, tas manto tieši no Node).

[GlobalClass] virs klasesĻauj atrast partial klasi pēc nosaukuma Add Node logā (ja faila un klases nosaukumi sakrīt).Neizveido un nepievieno mezglu scēnai izstrādātāja vietā.
[Export] virs lauka vai īpašībasParāda vērtību Inspector panelī un saglabā to kopā ar konkrēto mezglu scēnā.Neizpilda aprēķinus pats par sevi — to izmanto programmas kods.

Parasts public padara datus pieejamus citam C# kodam, bet bez [Export] tie neparādās Inspector panelī. Pēc atribūtu pievienošanas fails jāsaglabā un jānospiež Build:

using Godot;

[GlobalClass]
public partial class Termostats : Node
{
    [Export]
    public string TelpasNosaukums { get; set; } = "Kabinets";

    // Bez [Export] lauks ir pieejams C# kodā, bet ne Inspector panelī:
    public bool IrIeslegts = true;
}

C# īpašības (get, set un value) un diapazona norāde

Atšķirībā no parasta lauka, īpašība (property) apvieno vērtības nolasīšanu (get) un piešķiršanu (set). Ja papildu pārbaude nav vajadzīga, lieto īso pierakstu [Export] public string Virsraksts { get; set; } = "Noklusējums";, kur glabāšanas vietu C# izveido automātiski. Ja jāaizsargā derīgo vērtību robežas — līdzīgi kā digitālam termostatam, kas neļauj iestatīt temperatūru zem drošā minimuma —, datus glabā private laukā un piešķiršanu kontrolē caur set:

private int intensitate = 20;

[Export(PropertyHint.Range, "1,50,1")]
public int Intensitate
{
    get { return intensitate; }
    set { intensitate = Math.Max(1, value); }
}

Nolasot objekts.Intensitate, izpildās get. Piešķirot jaunu skaitli, izpildās set, kur iebūvētais atslēgvārds value satur jaunpiešķirto vērtību, bet Math.Max(1, value) neļauj saglabāt skaitli, kas mazāks par 1. Norāde PropertyHint.Range ("min,max,solis") sniedz ērtu ievades ierobežojumu Inspector panelī, savukārt set nosacījums nosargā minimumu arī piešķīrumiem tieši C# kodā.

Scēnā saglabāto Inspector vērtību prioritāte un mezgla nosaukums

Kodā ierakstītā sākumvērtība kalpo kā noklusējums jauniem mezgliem. Ja konkrētam mezglam Inspector panelī iestata citu skaitli un saglabā scēnu, palaižot programmu, tieši šī scēnā saglabātā vērtība ir noteicošā (vēlāka noklusējuma maiņa C# failā nepārraksta jau saglabātu mezgla iestatījumu, kamēr to neatjauno Inspector panelī; arī pārējie tās pašas klases mezgli saglabā katrs savus datus).

Tāpat jāatšķir mezgla tehniskais Name Scene kokā (pēc kura mezglu atrod kodā, piemēram, ar GetNode) no eksportētas teksta īpašības, ko izvada lasāmai saziņai ar lietotāju — tiem nav jāsakrīt, un patieso izpildes laika vērtību drošāk pārbaudīt ar GD.Print metodē _Ready():

// Katrs Termostats mezgls izdrukā savu Scene vārdu un Inspector datus:
public override void _Ready()
{
    GD.Print("[", Name, "] ", TelpasNosaukums, ": ", Intensitate);
}

// Vadības skriptā mezglu atrod pēc tā tehniskā Name scēnas kokā:
Termostats pirmais = GetNode<Termostats>("Termostats1");

1. uzdevums

Reģistrē savu mezgla tipu Obstacle ar [GlobalClass]

Kur strādāt: Izveido skriptu Scripts/Obstacle.cs ar klasi Obstacle un Godot redaktorā izveido un saglabā scēnu Scenes/ObstacleDemo.tscn.

Scēnas koka uzbūve (Scenes/ObstacleDemo.tscn pēc 1.–3. uzdevuma):

ObstacleDemo (Node)
 ├── PrinterQueue (Obstacle - Obstacle Name: "Rinda pie printera", Penalty: 20)
 ├── WifiDrop (Obstacle - Obstacle Name: "Pazūd internets", Penalty: 12)
 └── MissingMarker (Obstacle - Obstacle Name: "Pazudis marķieris", Penalty: 8)
  1. Izveido mapē Scripts/ jaunu C# failu res://Scripts/Obstacle.cs (faila nosaukumam precīzi jāsakrīt ar klases nosaukumu Obstacle, ieskaitot lielo sākumburtu).
  2. Ieraksti failā Scripts/Obstacle.cs sākuma klasi ar atribūtu [GlobalClass] un mantošanu no Node (skat. paraugu zemāk).
  3. Saglabā failu un nospied Build Godot augšējā labajā stūrī, lai redaktors reģistrētu jauno mezgla tipu.
  4. Izveido jaunu scēnu ar Node sakni ObstacleDemo un saglabā to kā res://Scenes/ObstacleDemo.tscn.
  5. Nospied uz saknes ObstacleDemo pogu Add Child Node (Ctrl+A), meklētājā ieraksti Obstacle, pievieno to kā bērna mezglu un pārdēvē par PrinterQueue.
// Fails: Scripts/Obstacle.cs (1. uzdevuma sākuma versija)

{
}

Gatavs, kad: pēc Build nospiešanas logs Create New Node atrod tipu Obstacle un tas ir pievienots scēnai Scenes/ObstacleDemo.tscn.

2. uzdevums

Pievieno [Export] īpašības ObstacleName un Penalty ar minimuma sargu

Kur strādāt: Papildini failu Scripts/Obstacle.cs ar lauku penalty, īpašībām ObstacleName un Penalty, kā arī metodi _Ready().

  1. Atver failu Scripts/Obstacle.cs un pievieno augšgalā using System; (lai būtu pieejams Math.Max).
  2. Pievieno klases Obstacle iekšienē eksportētu teksta īpašību: [Export] public string ObstacleName { get; set; } = "Rinda pie printera";.
  3. Pievieno turpat privātu lauku private int penalty = 20; un eksportētu īpašību Penalty ar [Export(PropertyHint.Range, "1,50,1")], kur set daļa ar penalty = Math.Max(1, value); neļauj saglabāt sodu, kas mazāks par 1.
  4. Pievieno metodi _Ready(), kas izdrukā šķēršļa nosaukumu un sodu: GD.Print(ObstacleName, ": sods ", Penalty);.
  5. Nospied Build, Scene kokā atlasi mezglu PrinterQueue un pārliecinies, ka labās puses Inspector panelī ir parādījušies lauki Obstacle Name un Penalty.
  6. Pārbaudi set aizsardzību: metodē _Ready() pirms GD.Print uz vienu palaišanu ieraksti pagaidu rindu Penalty = -5;, palaid scēnu ar F6 un pārliecinies, ka Output izdrukā 1 (nevis -5). Pēc pārbaudes rindu Penalty = -5; izdzēs!
// Fails: Scripts/Obstacle.cs (2. uzdevuma kods)
using Godot;
using System;

[GlobalClass]
public partial class Obstacle : Node
{
    private int penalty = 20;

    [Export]
    public string ObstacleName { get; set; } = "Rinda pie printera";

    [Export(PropertyHint.Range, "1,50,1")]
    public int Penalty
    {
        get { return penalty; }
        set { penalty = Math.Max(1, value); }
    }

    public override void _Ready()
    {
        GD.Print(ObstacleName, ": sods ", Penalty);
    }
}

Gatavs, kad: Obstacle Name un Penalty ir redzami Inspector panelī, un negatīvs piešķīrums kodā tiek automātiski pārvērsts par 1.

3. uzdevums

Iestati trīs dažādus Obstacle mezglus Inspector panelī

Kur strādāt: Mezgliem nosaukumus un Inspector vērtības iestati scēnā Scenes/ObstacleDemo.tscn (visi trīs mezgli izmanto vienu un to pašu skriptu Scripts/Obstacle.cs). Secinājumus ieraksti README.md.

  1. Atver scēnu Scenes/ObstacleDemo.tscn un zem saknes ObstacleDemo pievieno vēl divus Obstacle bērna mezglus, lai kopā būtu trīs mezgli ar precīziem Scene koka nosaukumiem: PrinterQueue, WifiDrop un MissingMarker.
  2. Atlasi katru no trim mezgliem Scene kokā un labās puses Inspector panelī iestati tā Obstacle Name un Penalty vērtības pēc tabulas zemāk. Saglabā scēnu (Ctrl+S).
  3. Palaid scēnu Scenes/ObstacleDemo.tscn ar F6 un pārbaudi, ka Output panelī parādās trīs dažādas izdrukas (ar sodiem 20, 12 un 8).
  4. Atlasi tikai mezglu PrinterQueue, Inspector panelī nomaini tā Penalty uz 25, saglabā un palaid ar F6 vēlreiz — pēc tam atgriez PrinterQueue sodu atpakaļ uz 20.
  5. Pieraksti failā README.md: (a) kāpēc izmainījās tikai PrinterQueue izdruka, bet pārējie divi mezgli saglabāja savus skaitļus; (b) kāpēc scēnā saglabātā Inspector vērtība ir noteicošā pār C# kodā ierakstīto sākuma vērtību penalty = 20.

Papildu uzdevums - Pievieno eksportētu apraksta īpašību Description

Kur strādāt: Īpašību Description un papildināto GD.Print pievieno failā Scripts/Obstacle.cs; aprakstu tekstus ievadi scēnas Scenes/ObstacleDemo.tscn Inspector panelī.

Ja pamatdarbs ir gatavs, papildini šķērsli ar īsu situācijas aprakstu redaktorā.

  1. Pievieno failā Scripts/Obstacle.cs īpašību [Export] public string Description { get; set; } = "Kavē sagatavošanos kārtai";.
  2. Papildini metodi _Ready(), lai tā izdrukātu arī Description vērtību.
  3. Nospied Build, scēnā Scenes/ObstacleDemo.tscn katram no trim šķēršļiem Inspector panelī ieraksti savu Description tekstu un pārbaudi izdruku ar F6.

Gatavs, kad: jaunā īpašība Description parādās Inspector panelī un katrs mezgls izdrukā savu aprakstu.

Ko sagatavo

Stundas mērķis: Izveidota ar [GlobalClass] reģistrēta klase Scripts/Obstacle.cs ar eksportētām īpašībām ObstacleName un Penalty (ar minimuma pārbaudi set daļā), un scēnā Scenes/ObstacleDemo.tscn konfigurēti trīs dažādi šķēršļi.

GitHub krātuvē saglabā projektu un šādus pierādījumus:

  • Failu Scripts/Obstacle.cs un scēnu Scenes/ObstacleDemo.tscn ar trim iestatītiem šķēršļiem (PrinterQueue, WifiDrop, MissingMarker).
  • Ekrānuzņēmumu vai izdruku ar Inspector un Output salīdzinājumu pirms un pēc viena šķēršļa maiņas.
  • README.md: skaidrojums par [GlobalClass], [Export], set minimuma sargu un to, kura vērtība ir noteicošā pēc scēnas saglabāšanas.

Kā iesniedz: Saglabā failus, veic git commit un git push. Skolotāja norādītajā vietā iesniedz GitHub krātuves saiti.

Ja kaut kas nestrādā

  • Obstacle neparādās: pārbaudi faila nosaukumu, [GlobalClass], partial un Build kļūdas.
  • Inspector lauka nav: pārbaudi [Export] un to, vai atlasīts pareizais mezgls.
  • Visiem sods ir 1: izdzēs pagaidu Penalty = -5 pārbaudi no _Ready.
  • Mainīju kodu, bet skaitlis palika: pārbaudi konkrētā mezgla scēnā saglabāto Inspector vērtību.
