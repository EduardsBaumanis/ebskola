3.4 Custom (pielāgots) C# class (klases) editor (redaktorā) redzamas

Stundas uzdevums: Padarīt savu C# class (klasi) pilnvērtīgi izmantojamu Godot editor (redaktors) (ar Inspector (īpašību panelis) property (īpašībām)).

SR 2.4.7. UI (lietotāja saskarne) SR 2.4.18. OOP (objektorientētā programmēšana)

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - padari class (klasi) redzamu editor (redaktorā) · 2. uzdevums (~25 min) - pievieno rediģējamas property (īpašības) · 3. uzdevums (~20 min) - iestati value (vērtības) Inspector (īpašību panelis) un pārbaudi · Iesniegšana (~5 min).

Pirms sāc: atver savu project (projektu). Šodien tavu C# class (klasi) varēs noregulēt bez code (koda) maiņas - tieši Godot editor (redaktorā), kā jebkuru citu node (mezglu).

Teorija: GlobalClass (globāli pieejama klase) un Export (eksportēt) property (īpašības)

Lai C# class (klase) parādītos Godot Add (pievienot) Node (mezgls) dialogā, tai pievieno attribute (atribūtu) [GlobalClass] (globāli pieejamas klases atribūts). Lai field (laukus) varētu rediģēt Inspector (īpašību panelis) panel (panelī), tiem pievieno [Export] (Inspector pieejamas īpašības atribūts). Pēc C# izmaiņām project (projekts) ir jāuzbūvē ar Godot Build (būvēt projektu) button (pogu).

using Godot;
using System;

[GlobalClass]
public partial class Obstacle : CharacterBody2D
{
    private int energy = 50;
    private float speed = 100.0f;

    [Export]
    public string ObstacleName { get; set; } = "PrinterQueue";

    [Export(PropertyHint.Range, "0,500")]
    public int Energy
    {
        get => energy;
        set => energy = Math.Max(0, value);
    }

    [Export(PropertyHint.Range, "0,500,0.1")]
    public float Speed
    {
        get => speed;
        set => speed = Math.Max(0.0f, value);
    }
}

Kā šo izmantot project (projektā)

Atceries: ar redzamu efektu editor (redaktorā) nepietiek. Paskaidro, kura C# class (klase) glabā state (stāvokli), kura method (metode) to maina un kā Godot node (mezgls) structure (struktūra) izmanto šo code (kodu).

Pārbaudi: katrai būtiskai turnīra lomai ir C# class (klase) vienā .cs file (failā), ar constructor (konstruktoriem), method (metodēm), signal (signāliem) vai inheritance (mantošanu).

Praktiskie uzdevumi

1. uzdevums -

Padari class (klasi) redzamu editor (redaktorā)

Beigās tavu C# class (klasi) varēs pievienot scene (scēnai) kā parastu node (mezglu).

  1. Izveido file (failu) Obstacle.cs ar class (klasi) Obstacle, kas manto no CharacterBody2D (vadāma 2D tēla mezgls).
  2. Pievieno virs class (klases) attribute (atribūtu) [GlobalClass] (globāli pieejamas klases atribūts).
  3. Pievieno privātus field (laukus) private int energy = 50; un private float speed = 100.0f;.
  4. Pārbaudi, ka file name (faila nosaukums) ir tieši Obstacle.cs, jo C# global class (klase) ir reģistrjutīgs.
  5. Būvē project (projektu) ar Godot Build (būvēt projektu) button (pogu).
  6. Pievieno node (mezglu) scene (scēnai), meklējot Obstacle.
  7. Pieraksti, kas notiek, ja [GlobalClass] (globāli pieejamas klases atribūts) rindu izdzēš un būvē vēlreiz.

Gatavs, kad: node (mezglu) meklētājā parādās type (tips) Obstacle, un to var pievienot scene (scēnai).

2. uzdevums -

Pievieno rediģējamas property (īpašības)

Beigās field (laukus) varēs mainīt Inspector (īpašību panelis) panel (panelī).

  1. Uzraksti property (īpašību) [Export] public int Energy { get; set; } = 50;.
  2. Pievieno ātrumam diapazonu ar [Export(PropertyHint.Range, "0,500,0.1")] public float Speed { get; set; } = 100.0f;.
  3. Pievieno tekstam [Export] public string ObstacleName { get; set; } = "PrinterQueue";.
  4. Pievieno setter (iestatīšanas metode) ar pārbaudi, ja vēlies neļaut negatīvu enerģiju.
  5. Būvē un atver node (mezgla) Inspector (īpašību panelis) panel (paneli).
  6. Pārbaudi, ka tur redzami abi field (lauki).

Gatavs, kad: Inspector (īpašību panelis) panel (panelī) pie tava node (mezgla) ir redzami field (lauki) energy un speed.

3. uzdevums -

Iestati value (vērtības) Inspector (īpašību panelis) un pārbaudi

Beigās viena class (klase) apkalpos vairākus dažādus šķēršļus.

  1. Ievelc scene (scēnā) trīs Obstacle mezglus.
  2. Iestati katram Inspector (īpašību panelis) panel (panelī) citu energy un speed value (vērtību).
  3. Izdrukā _Ready() method (metodē) abus field (laukus).
  4. Palaid spēli un pārbaudi, vai izdrukā ir tavas ievadītās value (vērtības).
  5. Mēģini Inspector (īpašību panelis) panel (panelī) ievadīt negatīvu enerģiju.
  6. Pieraksti, vai tava pārbaude to noķēra.
  7. Saglabā scene (scēnu) un veic commit (izmaiņu fiksējums).

Gatavs, kad: trīs node (mezgli) izdrukā trīs dažādas value (vērtības), un negatīva enerģija tiek automātiski salabota.

Papildu uzdevums - Pievieno menu (izvēlni) ar variantiem

Ja pamatdarbs ir gatavs, ļauj Inspector (īpašību panelis) panel (panelī) izvēlēties šķēršļa veidu.

  1. Pievieno field (lauku) [Export(PropertyHint.Enum, "PrinterQueue,WifiDrop,MissingMarker")] public string ObstacleType { get; set; } = "PrinterQueue";.
  2. Būvē un atver Inspector (īpašību panelis) panel (paneli).
  3. Izvēlies nolaižamajā list (sarakstā) vienu variantu.
  4. Izdrukā izvēlēto veidu, palaižot spēli.

Gatavs, kad: Inspector (īpašību panelis) panel (panelī) ir nolaižams list (saraksts) ar trim šķēršļu veidiem.

Ko sagatavo

Stundas mērķis: Tava C# class (klase) parādās Godot editor (redaktorā) kā node (mezgla) type (tips), tās field (lauki) ir rediģējami Inspector (īpašību panelis) panel (panelī), un vairāki viena type (tipa) node (mezgli) var strādāt ar dažādām value (vērtībām) bez code (koda) maiņas.

GitHub repository (krātuvē) jābūt:

  1. File (fails) Obstacle.cs ar [GlobalClass] (globāli pieejamas klases atribūts) un [Export] (Inspector pieejamas īpašības atribūts) property (īpašībām).
  2. Screenshot (ekrānuzņēmums) ar Inspector (īpašību panelis) panel (paneli), kurā redzami tavi field (lauki).
  3. Screenshot (ekrānuzņēmums) ar Output (izvade) panel (paneli), kurā trīs node (mezgli) izdrukā trīs dažādas value (vērtības).
  4. README.md: kāpēc noderīgi, ka value (vērtību) var mainīt editor (redaktorā), nevis code (kodā).

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub repository (krātuves) link (saiti); visiem prasītajiem file (failiem), README.md pierakstiem un pierādījumiem jābūt pašā repository (krātuvē).

Biežākās kļūdas

  • Inspector (īpašību panelis) field (lauks) neparādās: pēc [Export] (Inspector pieejamas īpašības atribūts) pievienošanas nospied Godot Build (būvēt projektu).
  • Class (klase) neparādās Add (pievienot) Node (mezgls): pārbaudi [GlobalClass] (globāli pieejamas klases atribūts) un to, ka file (fails) saucas Obstacle.cs.
  • Export (eksportēt) hint kļūda: pārbaudi PropertyHint.Range vai PropertyHint.Enum syntax (sintaksi).
