3.4 Custom GDExtension klases editorā redzamas

Stundas uzdevums: Padarīt savu C++ klasi pilnvērtīgi izmantojamu Godot editor (ar Inspector īpašībām).

SR 2.4.7. UI SR 2.4.18. OOP

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - padari klasi redzamu editorā · 2. uzdevums (~25 min) - pievieno rediģējamas īpašības · 3. uzdevums (~20 min) - iestati vērtības Inspector un pārbaudi · Iesniegšana (~5 min).

Pirms sāc: atver savu projektu. Šodien tavu C++ klasi varēs noregulēt bez koda maiņas - tieši Godot editorā, kā jebkuru citu mezglu.

Teorija: GDCLASS un property exposing

Lai C++ klase parādītos Godot editor un tās laukus varētu rediģēt Inspector, jāizmanto GDCLASS makro un jāreģistrē properties.

class Obstacle : public CharacterBody2D {
    GDCLASS(Obstacle, CharacterBody2D)

private:
    int energy = 50;
    float speed = 100.0f;
    String obstacle_name = "PrinterQueue";

protected:
    static void _bind_methods() {
        ClassDB::bind_method(D_METHOD("get_energy"), &Obstacle::get_energy);
        ClassDB::bind_method(D_METHOD("set_energy", "v"), &Obstacle::set_energy);
        // Padari property redzamu Inspector
        ADD_PROPERTY(PropertyInfo(Variant::INT, "energy"), "set_energy", "get_energy");

        ClassDB::bind_method(D_METHOD("get_speed"), &Obstacle::get_speed);
        ClassDB::bind_method(D_METHOD("set_speed", "v"), &Obstacle::set_speed);
        ADD_PROPERTY(PropertyInfo(Variant::FLOAT, "speed"), "set_speed", "get_speed");
    }

public:
    int get_energy() const { return energy; }
    void set_energy(int v) { energy = v; }
    float get_speed() const { return speed; }
    void set_speed(float v) { speed = v; }
};

Kā šo izmantot projektā

Atceries: ar redzamu efektu editorā nepietiek. Paskaidro, kura C++ klase glabā stāvokli, kura metode to maina un kā Godot node struktūra izmanto šo kodu.

Pārbaudi: katrai būtiskai turnīra lomai ir C++ klase ar header/implementation dalījumu, konstruktoriem, metodēm, signāliem vai mantošanu.

Praktiskie uzdevumi

1. uzdevums - Padari klasi redzamu editorā

Beigās tavu C++ klasi varēs pievienot scēnai kā parastu mezglu.

  1. Izveido klasi Obstacle, kas manto no CharacterBody2D.
  2. Ieraksti klases sākumā GDCLASS(Obstacle, CharacterBody2D) bez semikola.
  3. Pievieno privātus laukus int energy = 50; un float speed = 100.0f;.
  4. Pievieno tukšu static void _bind_methods(); sadaļā protected:.
  5. Reģistrē klasi register_types.cpp failā.
  6. Kompilē un pievieno mezglu scēnai, meklējot Obstacle.
  7. Pieraksti, kas notiek, ja GDCLASS rindu izdzēš.

Gatavs, kad: mezglu meklētājā parādās tips Obstacle, un to var pievienot scēnai.

2. uzdevums - Pievieno rediģējamas īpašības

Beigās laukus varēs mainīt Inspector panelī.

  1. Uzraksti metodes int get_energy() const; un void set_energy(int v);.
  2. Reģistrē abas ar ClassDB::bind_method(D_METHOD("get_energy"), &Obstacle::get_energy);.
  3. Pievieno ADD_PROPERTY(PropertyInfo(Variant::INT, "energy"), "set_energy", "get_energy");.
  4. Atkārto to pašu laukam speed ar tipu Variant::FLOAT.
  5. Pievieno set_energy metodē pārbaudi, ka vērtība nav negatīva.
  6. Kompilē un atver mezgla Inspector paneli.
  7. Pārbaudi, ka tur redzami abi lauki.

Gatavs, kad: Inspector panelī pie tava mezgla ir redzami lauki energy un speed.

3. uzdevums - Iestati vērtības Inspector un pārbaudi

Beigās viena klase apkalpos vairākus dažādus šķēršļus.

  1. Ievelc scēnā trīs Obstacle mezglus.
  2. Iestati katram Inspector panelī citu energy un speed vērtību.
  3. Izdrukā _ready metodē abus laukus.
  4. Palaid spēli un pārbaudi, vai izdrukā ir tavas ievadītās vērtības.
  5. Mēģini Inspector panelī ievadīt negatīvu enerģiju.
  6. Pieraksti, vai tava pārbaude to noķēra.
  7. Saglabā scēnu un veic commit.

Gatavs, kad: trīs mezgli izdrukā trīs dažādas vērtības, un negatīva enerģija tiek automātiski salabota.

Papildu uzdevums - Pievieno izvēlni ar variantiem

Ja pamatdarbs ir gatavs, ļauj Inspector panelī izvēlēties šķēršļa veidu.

  1. Pievieno lauku int obstacle_type = 0; ar get un set metodēm.
  2. Reģistrē to ar PROPERTY_HINT_ENUM un vērtībām "PrinterQueue,WifiDrop,MissingMarker".
  3. Kompilē un atver Inspector paneli.
  4. Izvēlies nolaižamajā sarakstā vienu variantu.
  5. Izdrukā izvēlēto veidu, palaižot spēli.

Gatavs, kad: Inspector panelī ir nolaižams saraksts ar trim šķēršļu veidiem.

Ko iesniedz skolotājam

Stundas mērķis: Tava C++ klase parādās Godot editorā kā mezgla tips, tās lauki ir rediģējami Inspector panelī, un vairāki viena tipa mezgli var strādāt ar dažādām vērtībām bez koda maiņas.

Iesniedzamais:

  1. Fails obstacle.hpp ar GDCLASS un ADD_PROPERTY izsaukumiem.
  2. Ekrānuzņēmums ar Inspector paneli, kurā redzami tavi lauki.
  3. Ekrānuzņēmums ar Output paneli, kurā trīs mezgli izdrukā trīs dažādas vērtības.
  4. Burtnīcā: kāpēc noderīgi, ka vērtību var mainīt editorā, nevis kodā.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un abus ekrānuzņēmumus skolotāja norādītajā vietā.

Biežākās kļūdas

  • Inspector lauks neparādās: Aizmirsts ADD_PROPERTY pēc bind_method.
  • Set funkcija nestrādā: Property name jāatbilst getter/setter pattern.
  • Export hint kļūda: Pārbaudi sintaksi ar Godot dokumentāciju.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

class Obstacle : public CharacterBody2D {
    GDCLASS(Obstacle, CharacterBody2D)
private:
    int energy = 50;
    float speed = 100.0f;
public:
    int get_energy() const { return energy; }
    void set_energy(int v) { energy = std::max(0, v); }
    float get_speed() const { return speed; }
    void set_speed(float v) { speed = std::max(0.0f, v); }

protected:
    static void _bind_methods() {
        ClassDB::bind_method(D_METHOD("get_energy"), &Obstacle::get_energy);
        ClassDB::bind_method(D_METHOD("set_energy", "v"), &Obstacle::set_energy);
        ADD_PROPERTY(PropertyInfo(Variant::INT, "energy",
            PROPERTY_HINT_RANGE, "0,500"), "set_energy", "get_energy");

        ClassDB::bind_method(D_METHOD("get_speed"), &Obstacle::get_speed);
        ClassDB::bind_method(D_METHOD("set_speed", "v"), &Obstacle::set_speed);
        ADD_PROPERTY(PropertyInfo(Variant::FLOAT, "speed",
            PROPERTY_HINT_RANGE, "0,500,0.1"), "set_speed", "get_speed");
    }
};
