3.4 C# class (klases) Godot redaktorā

Stundas uzdevums: Padarīt savu C# class pilnvērtīgi izmantojamu Godot redaktorā (ar Inspector īpašībām).

SR 2.4.7. UI (lietotāja saskarne) SR 2.4.18. OOP (objektorientētā programmēšana)

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - padari class redzamu redaktorā · 2. uzdevums (~25 min) - pievieno rediģējamas īpašības · 3. uzdevums (~20 min) - iestati vērtības Inspector un pārbaudi · Iesniegšana (~5 min).

Pirms sāc: atver savu projektu. Šodien tavu C# class varēs noregulēt bez koda maiņas - tieši Godot redaktorā, kā jebkuru citu node (mezglu).

Teorija: GlobalClass (globāli pieejama klase) un Eksportēt property (īpašības)

Lai C# class parādītos Godot Add Node dialogā, tai pievieno attribute (atribūtu) [GlobalClass] (globāli pieejamas klases atribūts). Lai laukus varētu rediģēt Inspector panelī, tiem pievieno [Export] (Inspector pieejamas īpašības atribūts). Pēc C# izmaiņām projekts ir jāuzbūvē ar Godot Build pogu.

using Godot;
using System;

[GlobalClass]
public partial class Obstacle : CharacterBody2D
{
    private int energy = 50;
    private float speed = 100.0f;

    [Export]
    public string ObstacleName { get; set; } = "PrinterQueue";

    [Export(PropertyHint.Range, "0,500")]
    public int Energy
    {
        get => energy;
        set => energy = Math.Max(0, value);
    }

    [Export(PropertyHint.Range, "0,500,0.1")]
    public float Speed
    {
        get => speed;
        set => speed = Math.Max(0.0f, value);
    }
}

Kā šo izmantot projektā

Atceries: ar redzamu efektu redaktorā nepietiek. Paskaidro, kura C# class glabā stāvokli, kura method (metode) to maina un kā Godot node struktūra izmanto šo kodu.

Pārbaudi: katrai būtiskai turnīra lomai ir C# class vienā .cs failā, ar constructor (konstruktoriem), method, signal (signāliem) vai inheritance (mantošanu).

Praktiskie uzdevumi

1. uzdevums -

Padari class redzamu redaktorā

Beigās tavu C# class varēs pievienot scēnai kā parastu node.

  1. Izveido failu Obstacle.cs ar class Obstacle, kas manto no CharacterBody2D (vadāma 2D tēla mezgls).
  2. Pievieno virs class attribute [GlobalClass].
  3. Pievieno privātus field (laukus) private int energy = 50; un private float speed = 100.0f;.
  4. Pārbaudi, ka faila nosaukums ir tieši Obstacle.cs, jo C# global class ir reģistrjutīgs.
  5. Būvē projektu ar Godot Build pogu.
  6. Pievieno node scēnai, meklējot Obstacle.
  7. Pieraksti, kas notiek, ja [GlobalClass] rindu izdzēš un būvē vēlreiz.

Gatavs, kad: node meklētājā parādās type (tips) Obstacle, un to var pievienot scēnai.

2. uzdevums -

Pievieno rediģējamas property

Beigās laukus varēs mainīt Inspector panelī.

  1. Uzraksti property [Export] public int Energy { get; set; } = 50;.
  2. Pievieno ātrumam diapazonu ar [Export(PropertyHint.Range, "0,500,0.1")] public float Speed { get; set; } = 100.0f;.
  3. Pievieno tekstam [Export] public string ObstacleName { get; set; } = "PrinterQueue";.
  4. Pievieno setter (iestatīšanas metode) ar pārbaudi, ja vēlies neļaut negatīvu enerģiju.
  5. Būvē un atver node Inspector paneli.
  6. Pārbaudi, ka tur redzami abi field.

Gatavs, kad: Inspector panelī pie tava node ir redzami lauki energy un speed.

3. uzdevums -

Iestati vērtības Inspector un pārbaudi

Beigās viena class apkalpos vairākus dažādus šķēršļus.

  1. Ievelc scēnā trīs Obstacle mezglus.
  2. Iestati katram Inspector panelī citu energy un speed vērtību.
  3. Izdrukā _Ready() method abus field.
  4. Palaid spēli un pārbaudi, vai izdrukā ir tavas ievadītās vērtības.
  5. Mēģini Inspector panelī ievadīt negatīvu enerģiju.
  6. Pieraksti, vai tava pārbaude to noķēra.
  7. Saglabā scēnu un veic commit (izmaiņu fiksējums).

Gatavs, kad: trīs node izdrukā trīs dažādas vērtības, un negatīva enerģija tiek automātiski salabota.

Papildu uzdevums - Pievieno izvēlni ar variantiem

Ja pamatdarbs ir gatavs, ļauj Inspector panelī izvēlēties šķēršļa veidu.

  1. Pievieno field [Export(PropertyHint.Enum, "PrinterQueue,WifiDrop,MissingMarker")] public string ObstacleType { get; set; } = "PrinterQueue";.
  2. Būvē un atver Inspector paneli.
  3. Izvēlies nolaižamajā sarakstā vienu variantu.
  4. Izdrukā izvēlēto veidu, palaižot spēli.

Gatavs, kad: Inspector panelī ir nolaižams saraksts ar trim šķēršļu veidiem.

Ko sagatavo

Stundas mērķis: Tava C# class parādās Godot redaktorā kā node type, tās lauki ir rediģējami Inspector panelī, un vairāki viena type node var strādāt ar dažādām vērtībām bez koda maiņas.

GitHub krātuvē jābūt:

  1. Fails Obstacle.cs ar [GlobalClass] un [Export] property.
  2. Ekrānuzņēmums ar Inspector paneli, kurā redzami tavi lauki.
  3. Ekrānuzņēmums ar Output paneli, kurā trīs node izdrukā trīs dažādas vērtības.
  4. README.md: kāpēc noderīgi, ka vērtību var mainīt redaktorā, nevis kodā.

Kā iesniedz: Veic commit un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Biežākās kļūdas

  • Inspector lauks neparādās: pēc [Export] pievienošanas nospied Godot Build.
  • Class neparādās Add Node: pārbaudi [GlobalClass] un to, ka fails saucas Obstacle.cs.
  • Export hint kļūda: pārbaudi PropertyHint.Range vai PropertyHint.Enum syntax (sintaksi).
