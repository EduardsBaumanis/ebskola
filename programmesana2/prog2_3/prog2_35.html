3.5 Statistikas sistēma un struct

Stundas uzdevums: Izmantot struct datu grupēšanai un kompozīciju (composition) klašu organizēšanai.

SR 2.4.16. Saliktas datu struktūras SR 2.4.18. OOP

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido struct statistikai · 2. uzdevums (~25 min) - ieliec struct klasē un pievieno metodes · 3. uzdevums (~20 min) - pievieno pagaidu bonusus sarakstā · Iesniegšana (~5 min).

Pirms sāc: atver savu dalībnieku klasi. Šodien sakārtosi tās laukus: tā vietā, lai klasē būtu desmit atsevišķi skaitļi, tie visi dzīvos vienā struct.

Teorija: struct un kompozīcija

struct ir vienkāršāka klase - visi lauki ir public pēc noklusējuma. Lietojama datu grupēšanai.

struct Stats {
    int energy = 100;
    int max_energy = 100;
    int focus = 10;
    int calm = 5;
    int speed = 5;

    void heal(int amount) {
        energy = std::min(max_energy, energy + amount);
    }
};

class Participant {
private:
    Stats stats;        // kompozīcija!
    String name;
public:
    Participant(String n) : name(n) {}

    Stats& get_stats() { return stats; }  // atgriež references
};

Kompozīcija (klase satur citu klasi) bieži ir labāka par mantošanu - fleksiblāka un mazāk saistīta.

Kā šo izmantot projektā

Atceries: ar redzamu efektu editorā nepietiek. Paskaidro, kura C++ klase glabā stāvokli, kura metode to maina un kā Godot node struktūra izmanto šo kodu.

Pārbaudi: katrai būtiskai turnīra lomai ir C++ klase ar header/implementation dalījumu, konstruktoriem, metodēm, signāliem vai mantošanu.

Praktiskie uzdevumi

1. uzdevums - Izveido struct statistikai

Beigās visi dalībnieka skaitļi būs vienuviet.

  1. Uzraksti failā stats.hpp struct Stats {.
  2. Pievieno laukus int energy = 100; un int max_energy = 100;.
  3. Pievieno arī int focus = 10;, int calm = 5; un int speed = 5;.
  4. Ievēro, ka struct laukiem nav jāraksta public: - tie tādi ir jau paši par sevi.
  5. Izveido objektu Stats s; un izdrukā visus laukus.
  6. Nomaini vienu lauku un izdrukā vēlreiz.
  7. Pieraksti, ar ko struct atšķiras no class.

Gatavs, kad: izdrukā redzamas visas noklusējuma vērtības, un tu vari nosaukt atšķirību no class.

2. uzdevums - Ieliec struct klasē un pievieno metodes

Beigās klase glabās statistiku vienā laukā, nevis piecos.

  1. Pievieno Participant klasei privātu lauku Stats stats;.
  2. Izdzēs vecos atsevišķos skaitļu laukus.
  3. Pievieno Stats struktūrai metodi void heal(int amount);.
  4. Ieraksti tajā energy = std::min(max_energy, energy + amount);.
  5. Pievieno klasei publisku metodi Stats& get_stats();.
  6. Izsauc p.get_stats().heal(30); un izdrukā enerģiju.
  7. Pārbaudi, ka enerģija nepārsniedz maksimumu.

Gatavs, kad: pēc lielas dziedināšanas enerģija apstājas tieši uz max_energy, nevis to pārsniedz.

3. uzdevums - Pievieno pagaidu bonusus sarakstā

Beigās dalībniekam varēs uzlikt bonusus, kas summējas.

  1. Izveido struct Buff { String name; int focus_bonus; };.
  2. Pievieno Stats struktūrai lauku std::vector<Buff> buffs;.
  3. Uzraksti metodi int get_total_focus() const;.
  4. Saskaiti tajā ciklā pamata focus plus visu bonusu summu.
  5. Pievieno divus bonusus un izdrukā kopējo fokusu.
  6. Izdzēs vienu bonusu un izdrukā vēlreiz.
  7. Pieraksti, kāpēc kopējo vērtību labāk rēķināt, nevis glabāt atsevišķā laukā.

Gatavs, kad: kopējais fokuss mainās, pievienojot un noņemot bonusus, un vienmēr sakrīt ar summu.

Papildu uzdevums - Pievieno bonusiem ilgumu

Ja pamatdarbs ir gatavs, liec bonusiem beigties pēc dažām kārtām.

  1. Pievieno Buff struktūrai lauku int turns_left;.
  2. Uzraksti metodi, kas samazina visiem bonusiem turns_left par vienu.
  3. Izdzēs no saraksta tos, kuriem tas sasniedzis nulli.
  4. Izsauc šo metodi trīs reizes pēc kārtas.
  5. Izdrukā pēc katras reizes kopējo fokusu.

Gatavs, kad: bonusi pazūd paši pēc norādītā kārtu skaita, un fokuss atgriežas sākuma vērtībā.

Ko iesniedz skolotājam

Stundas mērķis: Tu proti izveidot struct datu grupēšanai, ielikt to klasē kā lauku (kompozīcija) un rēķināt kopējo vērtību no saraksta, nevis glabāt to atsevišķi.

Iesniedzamais:

  1. Faili stats.hpp un atjauninātais participant.hpp GitHub krātuvē.
  2. Ekrānuzņēmums ar Output paneli, kurā redzams kopējais fokuss pirms un pēc bonusa noņemšanas.
  3. README.md: ar ko struct atšķiras no class un kāpēc kopējo fokusu labāk rēķināt.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un ekrānuzņēmumu skolotāja norādītajā vietā; README.md failā jābūt prasītajiem pierakstiem.

Biežākās kļūdas

  • Stats default values neuzstādās: C++ struct lauki bez init = nedef vērtība. Vienmēr inicializē.
  • Vector iteration crash: Mainot vektoru cikla laikā, neizvairies no UB.
  • Slow buff lookup: Lielam vector lieto std::map vai std::unordered_map.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

struct Stats {
    int energy = 100, max_energy = 100;
    int focus = 10, calm = 5, speed = 5;
    std::vector<Buff> buffs;

    int get_total_focus() const {
        int total = focus;
        for (const auto& b : buffs) {
            if (b.target == "focus") total += b.amount;
        }
        return total;
    }

    void apply_penalty(int amount) {
        int actual = std::max(1, amount - calm);
        energy = std::max(0, energy - actual);
    }

    void update(float delta) {
        for (auto& b : buffs) b.duration -= delta;
        buffs.erase(std::remove_if(buffs.begin(), buffs.end(),
            [](const Buff& b) { return b.duration <= 0; }),
            buffs.end());
    }
};
Participant get_total_focus atgriež 15 (10 base + 5 buff), pēc 30 sec - atkal 10.
