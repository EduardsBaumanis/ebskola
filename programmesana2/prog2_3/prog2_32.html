3.2 Inheritance (mantošana) C# un Godot

Stundas uzdevums: Izveidot specializētas dalībnieku class (klases), izmantojot inheritance.

SR 2.4.18. OOP (objektorientētā programmēšana) SR 2.4.15. Modulāras programmas

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido derived class (bērna klasi) · 2. uzdevums (~25 min) - pārraksti method (metodi) ar override (metodes pārrakstīšana) · 3. uzdevums (~20 min) - izsauc visas lomas vienā loop (ciklā) · Iesniegšana (~5 min).

Pirms sāc: atver savu Participant class no 3.1 stundas. Šodien no vienas class taisīsi vairākas lomas, nekopējot kodu.

Teorija: Inheritance un virtual function (virtuālas funkcijas)

Inheritance ļauj bērna class pārmantot vecāka attribute (atribūtus) un method, pievienojot vai pārrakstot.

public class Participant { /* base klase */ }

public class Captain : Participant
{
    public int Stability;

    public Captain(string name) : base(name, 150, 18, 12)  // izsauc vecāku konstruktoru
    {
        Stability = 10;
    }

    // Pārraksta (override) vecāka metodi
    public override void ApplyPenalty(int amount)
    {
        amount -= Stability;  // stabilitāte samazina soda punktus
        base.ApplyPenalty(amount);
    }
}

public class Presenter : Participant
{
    public int Ideas = 100;

    public Presenter(string name) : base(name, 80, 25, 3) { }

    public void PresentBonus(Participant target)
    {
        if (Ideas >= 20)
        {
            Ideas -= 20;
            target.ApplyPenalty(40);
        }
    }
}

virtual (pārrakstāma metode) keyword (atslēgvārds) ļauj izsaukt bērna method caur vecāka pointer (rādītājs) (polymorphism (polimorfisms)).

Praktiskie uzdevumi

1. uzdevums -

Izveido derived class

Beigās jaunā class mantos visu no vecāku class.

  1. Izveido failu Captain.cs.
  2. Ieraksti public class Captain : Participant { }.
  3. Pievieno constructor public Captain(string name) : base(name, 150) { }.
  4. Pievieno privātu field (lauku) private int stability = 10;.
  5. Izveido object (objektu) Captain c = new Captain("Anna"); un izsauc tam IsActive().
  6. Pieraksti, no kurienes šī method radās, ja tu to Captain class nerakstīji.
  7. Izdzēs : base(name, 150) daļu, būvē projektu un izlasi kļūdu.

Gatavs, kad: bērna object strādā vecāka method, bet bez vecāka constructor izsaukuma kods nekompilējas.

2. uzdevums -

Pārraksti method ar override

Beigās kapteinis sodu izturēs labāk nekā parasts dalībnieks.

  1. Pievieno vecāka class keyword virtual pirms ApplyPenalty.
  2. Pievieno Captain class public override void ApplyPenalty(int amount).
  3. Ieraksti tajā amount = Math.Max(1, amount - stability);.
  4. Izsauc pēc tam vecāka versiju ar base.ApplyPenalty(amount);.
  5. Izmēģini vienādu sodu abiem: parastam dalībniekam un kapteinim.
  6. Pieraksti, cik enerģijas katrs zaudēja.
  7. Izdzēs virtual vārdu, būvē projektu un pieraksti, kas mainās.

Gatavs, kad: ar vienādu sodu kapteinis zaudē mazāk enerģijas nekā parasts dalībnieks.

3. uzdevums -

Izsauc visas lomas vienā loop

Beigās viens loop apkalpos jebkuru lomu skaitu.

  1. Izveido vēl vienu derived class Presenter ar citu enerģiju.
  2. Pārraksti arī tai ApplyPenalty savā veidā.
  3. Izveido List<Participant> party = new();.
  4. Pievieno tam pa vienam object no katras class.
  5. Uzraksti loop, kas katram izsauc ApplyPenalty(20).
  6. Izdrukā pēc loop katra vārdu un atlikušo enerģiju.
  7. Pieraksti, kāpēc loop nezina, kura loma tam tiek padota.

Gatavs, kad: viens loop apstrādā visas lomas, un katra zaudē atšķirīgu enerģijas daudzumu.

Papildu uzdevums - Pievieno trešo lomu

Ja pamatdarbs ir gatavs, paplašini hierarhiju.

  1. Izveido class TimeKeeper ar mazāku enerģiju, bet lielāku ātrumu.
  2. Pārraksti tai ApplyPenalty tā, lai tā zaudētu vairāk.
  3. Pievieno to sarakstam.
  4. Palaid loop vēlreiz un pārbaudi, vai kods bija jāmaina.
  5. Pieraksti, cik rindu bija jāpieraksta loop.

Gatavs, kad: trešā loma darbojas loop, un pašā loop nebija jāmaina neviena rinda.

Biežākās kļūdas

  • Cannot call base constructor (nevar izsaukt bāzes konstruktoru): Trūkst initializer list (inicializēšanas saraksts) ar : Participant(...).
  • 'override' was not declared (override nav deklarēts): C#11+ vajadzīgs (Godot prasa C#17).
  • Slicing problem (objekta daļas nogriešanas problēma): Pieliecot Participant object, ne Participant*, polymorphism nedarbojas.
