Kā lasīt šo tēmu

Visās sešās stundās izmantojam vienu piemēru. Dalībnieks glabā savus datus, loma nosaka soda noteikumu, bet turnīra vadītājs organizē kārtas. Sākumā pietiek ar teksta izdrukām — tās ļauj redzēt, kas mainījās pēc katras koda rindas.

Katrā stundā vispirms izlasi situāciju un paredzi skaitlisko rezultātu. Tad palaid piemēru un salīdzini. Ja rezultāts atšķiras, atrodi pirmo darbību, kurā mainījās nepareizā vērtība. Pilnie faili ir atverami zem uzdevumiem, lai vari salīdzināt konkrēto vietu.

Atgādne: ko katrs pieraksts dara?

Šie ir īsi fragmenti atkārtošanai. Pilnie faili un vieta, kur kodu ievietot, norādīti katras stundas teorijā.

3.1. Izveido objektu un veic darbību

Participant anna = new Participant("Anna", 100);
anna.ApplyPenalty(30);
GD.Print(anna.GetEnergy()); // 70

Izveidošana dod sākuma datus. Metode maina tieši šo dalībnieku. Izseko enerģijas maiņai.

3.2. Vienāds izsaukums, atšķirīgs noteikums

Participant p = new Captain("Anna");
p.ApplyPenalty(20);
GD.Print(p.GetEnergy()); // 140: kapteinis sāka ar 150 un zaudēja 10.

virtual atļauj atšķirīgu versiju, override to nosaka, bet base.ApplyPenalty(...) izsauc kopīgo bāzes kodu. Salīdzini lomu rezultātus.

3.3. Pieslēdz saņēmēju pirms notikuma

// Vadītāja _Ready() metodē; anna ir scēnā atrasts Participant mezgls.
anna.Setup("Anna", 30);
anna.Finished += OnParticipantFinished;
anna.ApplyPenalty(30); // Tagad saņēmējs saņem izstāšanās paziņojumu.

Signālu raida dalībnieks, bet izdrukas metodi pieslēdz vadītājs. Apskati visas trīs signāla darbības.

3.4. Pārbaudi iestatīto vērtību

// Obstacle klases iekšienē.
private int penalty = 20;
[Export]
public int Penalty
{
    get { return penalty; }
    set { penalty = System.Math.Max(1, value); }
}

Inspector maina konkrētā mezgla datus; set nepieļauj sodu zem 1. Izlasi get, set un value skaidrojumu.

3.5. Atšķir kopiju no īstajiem datiem

Stats copy = anna.GetStats();
copy.Energy = 1; // Maina tikai kopiju.
anna.Heal(20);  // Maina dalībnieka īstos datus, ievērojot maksimumu.

Kopējo fokusu aprēķina no pamata vērtības un pašreizējā bonusu saraksta. Salīdzini struct kopiju un klases objektu.

3.6. Pirms nākamās kārtas pārbaudi beigas

while (GetActiveParticipants().Count > 1 && currentTurn < 1000)
{
    PlayTurn();
}

Sodu saņem tikai aktīvs dalībnieks. Nejaušā izvēle drīkst atkārtoties. Izskaidro, kāpēc turnīrs beidzas.
