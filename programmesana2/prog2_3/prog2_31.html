3.1 C# class (klases) pamati

Stundas uzdevums: Saprast OOP (objektorientētā programmēšana) fundamentālo konceptu - class (klases) un object (objekti) - un izveidot pirmo dalībnieka class (klasi).

SR 2.4.18. OOP (objektorientētā programmēšana) pamati SR 2.4.15. Modular program (modulāras programmas)

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido pirmo class (klasi) ar field (laukiem) · 2. uzdevums (~25 min) - pievieno constructor (konstruktoru) un method (metodes) · 3. uzdevums (~20 min) - pārbaudi private (privāta piekļuve) un public (publiska piekļuve) atšķirību · Iesniegšana (~5 min).

Pirms sāc: šī ir pirmā stunda par class (klasēm). Atceries no Programmēšanas I dictionary (vārdnīcas): dalibnieks = {"vards": "Anna", "energija": 100}. Class (klase) ir tas pats, tikai ar iebūvētām function (funkcijām) un stingru kārtību.

Teorija: C# class (klases) structure (struktūra)

Class (klase) ir template (veidne) object (objektu) radīšanai. Tā satur data (datus) (attribute (atribūtus)) un function (funkcijas) (method (metodes)).

public class Participant
{
    private int energy;      // tikai klases iekšienē pieejams
    private int maxEnergy;

    public string Name;
    public int Level = 1;

    // Konstruktors
    public Participant(string name, int energy)
    {
        Name = name;
        this.energy = energy;
        maxEnergy = energy;
    }

    // Metodes
    public void ApplyPenalty(int amount)
    {
        energy -= amount;
        if (energy < 0) energy = 0;
    }

    public bool IsActive()
    {
        return energy > 0;
    }

    public int GetEnergy() => energy;
}

public (publiska piekļuve)/private (privāta piekļuve)/protected (aizsargāta piekļuve) kontrolē encapsulation (iekapsulāciju).

Praktiskie uzdevumi

1. uzdevums -

Izveido pirmo class (klasi) ar field (laukiem)

Beigās viens object (objekts) glabās visus dalībnieka data (datus) kopā.

  1. Uzraksti README.md file (failā) Python dictionary (vārdnīcu), kas glabā dalībnieka vārdu, enerģiju un līmeni.
  2. Izveido file (failu) Participant.cs.
  3. Ieraksti public class Participant { }.
  4. Pievieno publiskus field (laukus) ar keyword (atslēgvārdu) public (publiska piekļuve).
  5. Pieteic tajā field (laukus) public string Name;, public int Energy; un public int Level = 1;.
  6. Izveido object (objektu) citā file (failā) un piešķir tā field (laukiem) value (vērtības).
  7. Izdrukā visus trīs field (laukus) un būvē project (projektu).

Gatavs, kad: izdrukā redzami visi trīs field (lauki), un tu vari parādīt, kura code (koda) rinda atbilst kurai dictionary (vārdnīcas) atslēgai.

2. uzdevums -

Pievieno constructor (konstruktoru) un method (metodes)

Beigās object (objektu) varēsi izveidot vienā rindā, un tas pats pratīs sevi mainīt.

  1. Pievieno class (klasē) constructor (konstruktoru) public Participant(string name, int energy) { Name = name; Energy = energy; }.
  2. Izveido object (objektu) ar Participant p = new Participant("Anna", 100);.
  3. Pievieno method (metodi) public void ApplyPenalty(int amount).
  4. Ieraksti tajā enerģijas samazināšanu un pārbaudi, ka tā nekļūst negatīva.
  5. Pievieno method (metodi) public bool IsActive(), kas atgriež Energy > 0.
  6. Izsauc abas method (metodes) un izdrukā rezultātu.
  7. Pieraksti, ar ko method (metode) atšķiras no parastas function (funkcijas).

Gatavs, kad: object (objektu) var izveidot vienā rindā, un pēc liela soda enerģija ir tieši 0, nevis negatīva.

3. uzdevums -

Pārbaudi private (privāta piekļuve) un public (publiska piekļuve) atšķirību

Beigās tu zināsi, kāpēc daļu data (datu) paslēpj.

  1. Pārvieto field (lauku) Energy uz privātu field (lauku) private int energy;.
  2. Mēģini to nomainīt no ārpuses ar p.energy = 9999;.
  3. Būvē project (projektu) un pieraksti compiler error (kompilatora kļūdas) tekstu.
  4. Pievieno publisku method (metodi) public int GetEnergy().
  5. Nolasi enerģiju caur šo method (metodi) un izdrukā to.
  6. Pieraksti, kāpēc ir labi, ka enerģiju var mainīt tikai caur ApplyPenalty().
  7. Pārliecinies, ka project (projekts) būvējas bez kļūdām.

Gatavs, kad: tieša access (piekļuve) privātam field (laukam) dod compiler error (kompilatora kļūdu), bet caur method (metodi) value (vērtību) nolasīt var.

Papildu uzdevums - Izveido komandu no trim dalībniekiem

Ja pamatdarbs ir gatavs, strādā ar vairākiem object (objektiem) reizē.

  1. Pievieno file (faila) sākumā using System.Collections.Generic;.
  2. Izveido List<Participant> team = new();.
  3. Pievieno tam trīs dalībniekus ar dažādām enerģijām.
  4. Uzraksti loop (ciklu), kas izdrukā katra vārdu un enerģiju.
  5. Saskaiti loop (ciklā), cik dalībnieku vēl ir aktīvi.

Gatavs, kad: loop (cikls) izdrukā visus trīs dalībniekus un pareizi saskaita aktīvos.

  • Cannot access private member (nevar piekļūt privātam loceklim): Mēģini piekļūt private (privāta piekļuve) field (laukam) ārpus class (klases) - lieto getter (nolasīšanas metode).

Code sample (koda piemērs) (paplašināts)

using Godot;
using System;

public class Participant
{
    private int energy;
    private int maxEnergy;
    private int focus;
    private int calm;

    public string Name { get; }

    public Participant(string name, int energy, int focus, int calm)
    {
        Name = name;
        this.energy = energy;
        maxEnergy = energy;
        this.focus = focus;
        this.calm = calm;
    }

    public void ApplyPenalty(int amount)
    {
        int actual = Math.Max(0, amount - calm);
        energy = Math.Max(0, energy - actual);
        GD.Print(Name, " zaudē ", actual, " enerģijas punktus. ENERGY: ", energy);
    }

    public bool IsActive() => energy > 0;

    public void PrintStatus()
    {
        GD.Print(Name, " ENERGY: ", energy, "/", maxEnergy,
            " FOCUS: ", focus, " CALM: ", calm);
    }
}
Output (izvade): 'Anna ENERGY: 100/100 FOCUS: 15 CALM: 5' un pēc soda punktiem 'ENERGY: 80'.
