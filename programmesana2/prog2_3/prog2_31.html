3.1 C++ klases pamati

Stundas uzdevums: Saprast OOP fundamentālo konceptu - klases un objekti - un izveidot pirmo dalībnieka klasi.

SR 2.4.18. OOP pamati SR 2.4.15. Modulāras programmas

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido pirmo klasi ar laukiem · 2. uzdevums (~25 min) - pievieno konstruktoru un metodes · 3. uzdevums (~20 min) - pārbaudi private un public atšķirību · Iesniegšana (~5 min).

Pirms sāc: šī ir pirmā stunda par klasēm. Atceries no Programmēšanas I vārdnīcas: dalibnieks = {"vards": "Anna", "energija": 100}. Klase ir tas pats, tikai ar iebūvētām funkcijām un stingru kārtību.

Teorija: C++ klases struktūra

Klase ir veidne objektu radīšanai. Tā satur datus (atribūtus) un funkcijas (metodes).

class Participant {
private:           // tikai klases iekšienē pieejams
    int energy;
    int max_energy;

public:            // pieejams ārpusē
    String name;
    int level = 1;

    // Konstruktors
    Participant(String n, int h) {
        name = n;
        energy = max_energy = h;
    }

    // Metodes
    void apply_penalty(int amount) {
        energy -= amount;
        if (energy < 0) energy = 0;
    }

    bool is_active() const {
        return energy > 0;
    }

    int get_energy() const { return energy; }
};

public/private/protected kontrolē encapsulation (iekapsulāciju).

Kā šo izmantot projektā

Atceries: ar redzamu efektu editorā nepietiek. Paskaidro, kura C++ klase glabā stāvokli, kura metode to maina un kā Godot node struktūra izmanto šo kodu.

Pārbaudi: katrai būtiskai turnīra lomai ir C++ klase ar header/implementation dalījumu, konstruktoriem, metodēm, signāliem vai mantošanu.

Praktiskie uzdevumi

1. uzdevums - Izveido pirmo klasi ar laukiem

Beigās viens objekts glabās visus dalībnieka datus kopā.

  1. Uzraksti burtnīcā Python vārdnīcu, kas glabā dalībnieka vārdu, enerģiju un līmeni.
  2. Izveido failu participant.hpp ar #pragma once.
  3. Ieraksti class Participant { un beigās }; ar semikolu.
  4. Pievieno sadaļu public:.
  5. Pieteic tajā laukus String name;, int energy; un int level = 1;.
  6. Izveido objektu citā failā un piešķir tā laukiem vērtības.
  7. Izdrukā visus trīs laukus un kompilē.

Gatavs, kad: izdrukā redzami visi trīs lauki, un tu vari parādīt, kura koda rinda atbilst kurai vārdnīcas atslēgai.

2. uzdevums - Pievieno konstruktoru un metodes

Beigās objektu varēsi izveidot vienā rindā, un tas pats pratīs sevi mainīt.

  1. Pievieno klasē konstruktoru Participant(String n, int h) { name = n; energy = h; }.
  2. Izveido objektu ar Participant p("Anna", 100);.
  3. Pievieno metodi void apply_penalty(int amount);.
  4. Ieraksti tajā enerģijas samazināšanu un pārbaudi, ka tā nekļūst negatīva.
  5. Pievieno metodi bool is_active();, kas atgriež energy > 0.
  6. Izsauc abas metodes un izdrukā rezultātu.
  7. Pieraksti, ar ko metode atšķiras no parastas funkcijas.

Gatavs, kad: objektu var izveidot vienā rindā, un pēc liela soda enerģija ir tieši 0, nevis negatīva.

3. uzdevums - Pārbaudi private un public atšķirību

Beigās tu zināsi, kāpēc daļu datu paslēpj.

  1. Pārvieto lauku energy uz sadaļu private:.
  2. Mēģini to nomainīt no ārpuses ar p.energy = 9999;.
  3. Kompilē un pieraksti kompilatora kļūdas tekstu.
  4. Pievieno publisku metodi int get_energy();.
  5. Nolasi enerģiju caur šo metodi un izdrukā to.
  6. Pieraksti, kāpēc ir labi, ka enerģiju var mainīt tikai caur apply_penalty.
  7. Pārliecinies, ka projekts kompilējas bez kļūdām.

Gatavs, kad: tieša piekļuve privātam laukam dod kompilatora kļūdu, bet caur metodi vērtību nolasīt var.

Papildu uzdevums - Izveido komandu no trim dalībniekiem

Ja pamatdarbs ir gatavs, strādā ar vairākiem objektiem reizē.

  1. Iekļauj #include <vector>.
  2. Izveido std::vector<Participant> team;.
  3. Pievieno tam trīs dalībniekus ar dažādām enerģijām.
  4. Uzraksti ciklu, kas izdrukā katra vārdu un enerģiju.
  5. Saskaiti ciklā, cik dalībnieku vēl ir aktīvi.

Gatavs, kad: cikls izdrukā visus trīs dalībniekus un pareizi saskaita aktīvos.

Ko iesniedz skolotājam

Stundas mērķis: Tu proti C++ uzrakstīt klasi ar laukiem, konstruktoru un metodēm, izveidot no tās objektu un paskaidrot, kāpēc daļa lauku ir private.

Iesniedzamais:

  1. Faili participant.hpp un participant.cpp tavā GitHub krātuvē.
  2. Ekrānuzņēmums ar Output paneli, kurā redzami dalībnieka dati un enerģija pēc soda.
  3. Burtnīcā: Python vārdnīca un tai atbilstošā C++ klase blakus, un viens teikums, kāpēc energy ir private.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti, ekrānuzņēmumu un burtnīcas fotogrāfiju skolotāja norādītajā vietā.

Biežākās kļūdas

  • Cannot access private member: Mēģini piekļūt private laukam ārpus klases - lieto getter.
  • Multiple definition error: Implementācija .hpp failā - pārvieto uz .cpp.
  • Crash, lietojot const objektu: Metode jāmarķē kā const, lai tiktu izsaukta uz const objekta.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

#include "participant.hpp"
#include <godot_cpp/variant/utility_functions.hpp>

using namespace godot;

Participant::Participant(String n, int h, int a, int d)
    : name(n), energy(h), max_energy(h), focus(a), calm(d) {}

void Participant::apply_penalty(int amount) {
    int actual = std::max(0, amount - calm);
    energy = std::max(0, energy - actual);
    UtilityFunctions::print(name, " zaudē ", actual, " enerģijas punktus. ENERGY: ", energy);
}

bool Participant::is_active() const { return energy > 0; }

void Participant::print_status() const {
    UtilityFunctions::print(name, " ENERGY: ", energy, "/", max_energy,
                            " FOCUS: ", focus, " CALM: ", calm);
}
Output: 'Anna ENERGY: 100/100 FOCUS: 15 CALM: 5' un pēc soda punktiem 'ENERGY: 80'.
