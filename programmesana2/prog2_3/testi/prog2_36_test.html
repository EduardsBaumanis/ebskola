Atkārtojuma tests: 3.5 Dalībnieka dati un pagaidu bonusi

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Ko izdrukā šis kods? Stats ir struct. 
Stats original = new Stats(100, 10);
Stats copy = original;
copy.Energy = 40;
GD.Print(original.Energy);

struct ir vērtību tips: piešķiršana izveido neatkarīgu kopiju, tāpēc oriģināls nemainās. Atkārto: 3.5 — 1. uzdevums — Struktūra Stats un vērtību kopēšana ↗

2. Konts ir class. Ko izdrukā šis kods? 
Konts pirmais = new Konts("Līga", 100);
Konts otrs = pirmais;
otrs.Atlikums = 40;
GD.Print(pirmais.Atlikums);

class ir atsauces tips: abi mainīgie norāda uz vienu un to pašu objektu. Atkārto: 3.5 — Teorija: datu struktūras (struct), vērtību kopēšana un kompozīcija ↗

3. Dalībniecei ir 70 no 100 enerģijas. Cik ir pēc Heal(50)? 
public void Heal(int amount)
{
    if (amount <= 0) return;
    Energy = Math.Min(MaxEnergy, Energy + amount);
}

70 + 50 = 120, bet Math.Min(100, 120) izvēlas mazāko — enerģija nepārsniedz griestus 100. Atkārto: 3.5 — 2. uzdevums — Enerģija struktūrā Stats un Heal() ↗

4. Bāzes fokuss ir 10, un sarakstā ir bonusi +5 un +3. Ko atgriež divi GetTotalFocus() izsaukumi pēc kārtas? 
public int GetTotalFocus()
{
    int total = stats.Focus;
    foreach (Buff buff in buffs)
    {
        total += buff.FocusBonus;
    }
    return total;
}

Summu katru reizi sāk lokālā mainīgajā no bāzes 10, tāpēc bonusi neuzkrājas un bāzes fokuss nemainās. Atkārto: 3.5 — 3. uzdevums — Struktūra Buff un kopējais fokuss ↗

5. Pēc tam izsauc RemoveBuffAt(0). Cik ir GetTotalFocus()?

Indekss 0 ir pirmais bonuss (+5). Paliek 10 + 3 = 13. Atkārto: 3.5 — 3. uzdevums — Struktūra Buff un kopējais fokuss ↗
