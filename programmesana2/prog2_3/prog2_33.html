Pirms sāc: atver savu project (projektu) ar dalībnieku class (klasēm). Signal (signāls) ir kā paziņojums: viens object (objekts) pasaka "tas notika", bet citi paši izlemj, vai klausīties.

Teorija: Godot Signals (signāli)

Godot signal (signāli) ir veids, kā object (objekti) var sazināties bez tieša savienojuma. Viens object (objekts) emit (raida) signal (signālu), citi connect (pievienojas), lai uz to reaģētu.

using Godot;
using System;

public partial class Participant : Node
{
    [Signal] public delegate void FinishedEventHandler(string name);
    [Signal] public delegate void PenaltyAppliedEventHandler(int amount);

    private int energy = 100;
    private string participantName = "Anna";

    public void ApplyPenalty(int amount)
    {
        energy -= amount;
        EmitSignal(SignalName.PenaltyApplied, amount);
        if (energy <= 0)
            EmitSignal(SignalName.Finished, participantName);
    }
}

Citur code (kodā):

hero.Finished += OnHeroFinished;

Praktiskie uzdevumi

1. uzdevums -

Reģistrē un raidi signal (signālu)

Beigās tavs object (objekts) pratīs paziņot, ka tas beidzis darbu.

  1. Nomaini Participant tā, lai tā mantotu no Node (mezgls): public partial class Participant : Node.
  2. Pievieno class (klasē) signal (signālu) [Signal] public delegate void FinishedEventHandler(string name);.
  3. Uzraksti method (metodē) ApplyPenalty pārbaudi, vai enerģija nokritusi līdz 0.
  4. Izsauc tajā EmitSignal(SignalName.Finished, Name);.
  5. Būvē project (projektu) un pievieno object (objektu) scene (scēnai).
  6. Pārbaudi Godot editor (redaktorā) tab (cilnē) Node (mezgls) -> Signals (signāli), vai signal (signāls) finished tur ir redzams.
  7. Pieraksti, kas notiek, ja [Signal] (signāla atribūts) rindu izdzēš.

Gatavs, kad: Godot editor (redaktora) Signals (signāli) list (sarakstā) parādās tavs signal (signāls) finished.

2. uzdevums -

Pieslēdzies signal (signālam) no cita object (objekta)

Beigās cits object (objekts) uzzinās par event (notikumu), tieši to nepārbaudot.

  1. Izveido C# class (klasi) TournamentManager, kas manto no Node (mezgls).
  2. Pievieno tai method (metodi) private void OnParticipantFinished(string name).
  3. Paņem dalībnieku ar Participant participant = GetNode<Participant>("Participant");.
  4. Savieno _Ready() method (metodē) signal (signālu) ar participant.Finished += OnParticipantFinished;.
  5. Izdrukā handler (apstrādātājā), kurš dalībnieks beidzis darbu.
  6. Būvē un samazini dalībnieka enerģiju līdz nullei.
  7. Pārbaudi Output (izdrukām) panel (panelī), ka paziņojums pienāca.

Gatavs, kad: kad dalībnieka enerģija sasniedz 0, menedžeris izdrukā tā vārdu, lai gan pats to nepārbaudīja.

3. uzdevums -

Salīdzini signal (signālu) ar tiešu izsaukumu

Beigās tu zināsi, kāpēc signal (signāli) ir ērtāki par tiešu link (saiti).

  1. Pievieno otru dalībnieku un pieslēdz arī to tam pašam signal (signālam).
  2. Samazini abu enerģiju un pārbaudi, ka pienāk divi paziņojumi.
  3. Iedomājies variantu, kur Participant pats izsauktu menedžeri, un pieraksti, ko tad vajadzētu glabāt katrā dalībniekā.
  4. Pieraksti, kas notiktu ar šo variantu, ja menedžera scene (scēnā) nav.
  5. Atvieno vienu dalībnieku ar participant.Finished -= OnParticipantFinished; un pārbaudi vēlreiz.
  6. Pieraksti, cik paziņojumu tagad pienāca.
  7. Pieraksti secinājumu: kurš object (objekts) zina par kuru.

Gatavs, kad: abi dalībnieki raida signal (signālu) neatkarīgi, un atvienotais vairs neizraisa paziņojumu.

Papildu uzdevums - Pievieno signal (signālam) vairāk data (datu)

Ja pamatdarbs ir gatavs, nodod signal (signālā) arī skaitli.

  1. Papildini signal (signāla) delegate (deleģāts) ar otru parameter (parametru), piemēram atlikušo enerģiju.
  2. Nodod to EmitSignal izsaukumā.
  3. Papildini handler (apstrādātāja) method (metodi) ar otru parameter (parametru).
  4. Izdrukā abus data (datus).
  5. Pārbaudi, ka compiler (kompilators) sūdzas, ja parameter (parametru) skaits nesakrīt.

Gatavs, kad: signal (signāls) nodod gan vārdu, gan skaitli, un tie abi parādās izdrukā.

Code sample (koda piemērs) (paplašināts)

using Godot;
using System;

public partial class Participant : Node
{
    [Signal] public delegate void PenaltyAppliedEventHandler(int amount);
    [Signal] public delegate void FinishedEventHandler(string name);

    private int energy = 100;
    private string participantName = "Anna";

    public void ApplyPenalty(int amount)
    {
        energy = Math.Max(0, energy - amount);
        EmitSignal(SignalName.PenaltyApplied, amount);
        if (energy == 0)
            EmitSignal(SignalName.Finished, participantName);
    }
}

public partial class Game : Node
{
    public override void _Ready()
    {
        Participant anna = GetNode<Participant>("Anna");
        anna.PenaltyApplied += OnPenalty;
        anna.Finished += OnFinished;
    }

    private void OnPenalty(int amount) { }
    private void OnFinished(string name) { }
}
