6.5 Eksports un publicēšana

Stundas uzdevums: Eksportēt spēli uz vairākām platformām un publicēt internetā.

SR 2.4.6. Plāno izstrādes procesu SR 3.1.4. IP tiesības SR 2.3.1. Datorikas nozares attīstība padziļinātos projektos SR 2.3.2. Datorikas virzieni un profesijas SR 2.4.9. Versiju pārvaldība

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - eksportē spēli uz datoru · 2. uzdevums (~25 min) - eksportē uz tīmekli un palaid lokāli · 3. uzdevums (~20 min) - publicē spēli internetā · Iesniegšana (~5 min).

Pirms sāc: atver savu spēli. Šodien no projekta taisīsi failu, ko var iedot citam cilvēkam. Pirms sāc, lejupielādē export templates: Editor -> Manage Export Templates.

Teorija: Export presets

Godot atbalsta eksportu uz: Windows, Linux, macOS, Web (HTML5), Android, iOS un konsolēm.

# Web eksporta soļi
# 1. Project → Export → Add → Web
# 2. Lejupielādē export templates: Editor → Manage Export Templates
# 3. Custom HTML - par default labi
# 4. Export Project → save as index.html mapē web_build/
# 5. web_build/ satur: index.html, .pck, .wasm, .js

# Lokāli testē:
python3 -m http.server 8000
# Atver http://localhost:8000

GitHub Pages publicēšana: ielādē web_build saturu uz gh-pages branch un GitHub automātiski hosto.

Kā šo izmantot projektā

Atceries: ar redzamu efektu editorā nepietiek. Paskaidro, kura C++ klase glabā stāvokli, kura metode to maina un kā Godot node struktūra izmanto šo kodu.

Pārbaudi: UI signāli, audio darbības, debug izvade un publicēšanas sagatave ir sasaistīta ar C++ spēles stāvokli.

#include <godot_cpp/variant/string.hpp>

using namespace godot;

struct PolishCheckpoint {
    String lesson = "6.5 Eksports un publicēšana";
    bool uses_cpp = true;
    bool connects_ui_signals = true;
    bool routes_audio_events = true;
    bool verifies_export_build = true;
};

Praktiskie uzdevumi

1. uzdevums - Eksportē spēli uz datoru

Beigās tev būs fails, ko var palaist bez Godot.

  1. Atver Project -> Export.
  2. Nospied Add un izvēlies savu platformu (Windows, Linux vai macOS).
  3. Pārbaudi, vai zem loga nav sarkana brīdinājuma par trūkstošiem templates.
  4. Nospied Export Project un saglabā mapē build/.
  5. Aizver Godot pilnībā.
  6. Palaid eksportēto failu un izspēlē vienu līmeni.
  7. Pievieno .gitignore failam rindu build/.

Gatavs, kad: eksportētā spēle palaižas bez Godot editora, un mape build/ nenonāk GitHub.

2. uzdevums - Eksportē uz tīmekli un palaid lokāli

Beigās tavu spēli varēs spēlēt pārlūkā.

  1. Pievieno eksporta profilu Web.
  2. Eksportē projektu mapē web_build/ ar nosaukumu index.html.
  3. Pārbaudi, ka mapē ir faili ar paplašinājumiem .wasm, .pck un .js.
  4. Mēģini atvērt index.html tieši no diska un pieraksti, kas notiek.
  5. Palaid mapē python -m http.server 8000.
  6. Atver pārlūkā localhost:8000 un izspēlē spēli.
  7. Pieraksti, kāpēc vajadzēja serveri, nevis pietika ar faila atvēršanu.

Gatavs, kad: spēle darbojas pārlūkā caur localhost:8000, bet, atverot failu tieši, tā nestrādā.

3. uzdevums - Publicē spēli internetā

Beigās tavu spēli varēs atvērt jebkurš pēc saites.

  1. Izveido kontu vietnē itch.io.
  2. Nospied Upload new project un izvēlies HTML tipu.
  3. Saspied mapes web_build/ saturu ZIP arhīvā.
  4. Augšupielādē arhīvu un ieķeksē This file will be played in the browser.
  5. Iestati loga izmēru atbilstoši savam projektam.
  6. Saglabā un atver spēles publisko saiti telefonā vai citā datorā.
  7. Pieraksti, vai spēle strādāja tāpat kā tavā datorā.

Gatavs, kad: spēle atveras un ir spēlējama no citas ierīces pa publisko saiti.

Papildu uzdevums - Uzraksti spēles aprakstu

Ja pamatdarbs ir gatavs, noformē spēles lapu.

  1. Uzraksti divus teikumus par to, kas spēlē jādara.
  2. Pievieno vadības aprakstu: kuri taustiņi ko dara.
  3. Augšupielādē divus ekrānuzņēmumus.
  4. Pievieno savu vārdu kā autoru un norādi uz izmantotajiem resursiem.
  5. Palūdz klasesbiedram izspēlēt spēli, neko nepaskaidrojot.

Gatavs, kad: klasesbiedrs saprata, kā spēlēt, tikai izlasot tavu lapu.

Ko iesniedz skolotājam

Stundas mērķis: Tava spēle ir eksportēta gan kā datora programma, gan kā tīmekļa versija, un tā ir publicēta internetā ar publisku saiti, kas strādā arī citās ierīcēs.

Iesniedzamais:

  1. Publiskā saite uz tavu spēli itch.io vietnē.
  2. Ekrānuzņēmums ar spēli, kas darbojas pārlūkā citā ierīcē.
  3. Ekrānuzņēmums ar Godot eksporta logu, kurā redzami abi profili.
  4. Burtnīcā: kāpēc web eksportu nevar palaist, vienkārši atverot index.html.

Kā iesniedz: Iesniedz publisko spēles saiti un abus ekrānuzņēmumus skolotāja norādītajā vietā. Saitei jāstrādā arī skolotāja datorā.

Biežākās kļūdas

  • Web build crashes browser: Threading issue - disable threading export setting.
  • EXE not running: Antivirus block - sign executable.
  • Large export size: Optimize textures (PNG → WebP), audio (compress).

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

#include <godot_cpp/classes/os.hpp>
#include <godot_cpp/variant/string.hpp>
#include <godot_cpp/variant/utility_functions.hpp>

using namespace godot;

struct ExportChecklist {
    bool has_export_template = false;
    bool has_cpp_library_for_target = false;
    bool has_index_html = false;
    bool tested_outside_editor = false;

    bool is_ready_to_publish() const {
        return has_export_template
            && has_cpp_library_for_target
            && has_index_html
            && tested_outside_editor;
    }
};

void ExportReporter::print_status(const ExportChecklist &checklist) {
    UtilityFunctions::print("Platform: ",
        OS::get_singleton()->get_name());
    UtilityFunctions::print("Ready to publish: ",
        checklist.is_ready_to_publish());
}
