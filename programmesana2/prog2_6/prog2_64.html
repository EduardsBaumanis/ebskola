Teorija: Debugger (atkļūdotājs) un profiler (profileris)

Godot piedāvā vairākus rīkus problēmu atrašanai:

  • Output (izvade) panel (panelis) - GD.Print() un GD.PrintErr() ziņojumi.
  • Debugger (atkļūdotājs) - breakpoints (pārtraukumpunkts), step through, watch variables (mainīgie).
  • Profiler (profilētājs) - function (funkciju) laika analīze.
  • Network Profiler (profilētājs) - RPC un networking.
  • Visual Profiler (profilētājs) - vizuāls diagrammu uzziņa.
// Debugging C# kodā
GD.Print("Player position: ", Position);
GD.PrintErr("Error: enemy is null!");
GD.PushWarning("Suspicious value: " + value);

// Pašpārbaudes
if (player == null)
{
    GD.PrintErr("Player not found!");

if (hp < 0)

Praktiskie uzdevumi

1. uzdevums -

Atrodi kļūdu ar output (izdrukām)

Beigās tu pratīsi atrast, kurā vietā value (vērtība) kļūst nepareiza.

  1. Ievies savā code (kodā) apzinātu kļūdu, piemēram nomaini + uz -.
  2. Palaid spēli un pieraksti, kas izskatās nepareizi.
  3. Pievieno GD.Print("pozicija: ", Position); pirms aprēķina.
  4. Pievieno tādu pašu output (izdruku) pēc aprēķina.
  5. Palaid un salīdzini abas value (vērtības).
  6. Atrodi pēc output (izdrukām) precīzo rindu, kur value (vērtība) kļūst nepareiza.
  7. Salabo kļūdu un izdzēs output (izdrukas).

Gatavs, kad: tu vari nosaukt konkrētu rindu, kurā value (vērtība) kļuva nepareiza, un kļūda ir izlabota.

2. uzdevums -

Lieto breakpoint (pārtraukumpunkts) un variable (mainīgo) skatu

Beigās tu pratīsi apturēt spēli un apskatīt visus variable (mainīgos) uzreiz.

  1. Atver tab (cilni) Debugger (atkļūdotājs).
  2. Uzliec breakpoint (pārtraukumpunkts) uz vienas code (koda) rindas, uzklikšķinot rindas numura kreisajā malā.
  3. Palaid spēli un pagaidi, līdz tā apstājas.
  4. Apskati panel (panelī) Stack (steks) Variables (mainīgie) visu variable (mainīgo) value (vērtības).
  5. Nospied Step Into (ieiet metodē) un vēro, kā izpilde iet pa vienai rindai.
  6. Pieraksti, kāda value (vērtība) bija tavam galvenajam variable (mainīgajam).
  7. Pieraksti, kad breakpoint (pārtraukumpunkts) ir ērtāks par output (izdrukām).

Gatavs, kad: spēle apstājas norādītajā rindā, un tu vari nolasīt variable (mainīgo) value (vērtības), tās neizdrukājot.

3. uzdevums -

Atrodi lēnāko vietu ar profiler (profileri)

Beigās tu zināsi, kura function (funkcija) patērē visvairāk laika.

  1. Atver Debugger (atkļūdotājs) -> Profiler (profilētājs) un nospied Start.
  2. Spēlē 30 sekundes ar aktīvu spēli.
  3. Aptur profiler (profileri) un sakārto list (sarakstu) pēc laika.
  4. Pieraksti trīs function (funkcijas), kas aizņem visvairāk laika.
  5. Pārbaudi, vai kāda no tām tiek izsaukta biežāk, nekā vajadzētu.
  6. Salīdzini _Process un _PhysicsProcess kopējo laiku.
  7. Pieraksti vienu ideju, ko varētu uzlabot.

Gatavs, kad: tev ir pierakstītas trīs laikietilpīgākās function (funkcijas) un viena konkrēta uzlabojuma ideja.

Papildu uzdevums - Pievieno pašpārbaudes output (izdrukas)

Ja pamatdarbs ir gatavs, liec kodam pašam brīdināt par kļūdām.

  1. Pievieno pārbaudi, vai svarīgs node (mezgls) tiešām tika atrasts.
  2. Izdrukā GD.PrintErr("Nav atrasts mezgls!");, ja tas ir null (tukša atsauce).
  3. Pārsauc node (mezglu) scene (scēnā) un palaid spēli.
  4. Pieraksti, ar ko sarkanā GD.PrintErr output (izdruka) atšķiras no parastās.
  5. Atgriez nosaukumu un pārbaudi, ka brīdinājums pazūd.

Gatavs, kad: pārsaucot node (mezglu), console (konsolē) parādās sarkans brīdinājums, nevis spēle klusi avarē.

Code sample (koda piemērs) (paplašināts)

using Godot;
using System;

public partial class Player : CharacterBody2D
{
    [Signal] public delegate void DamagedEventHandler(int amount);

    private string playerName = "Player";
    private int hp = 100;

    public void TakeDamage(int amount)
    {
        // Validate input
        if (amount < 0)
            throw new ArgumentOutOfRangeException(nameof(amount), amount,
                "Damage amount must be non-negative.");

        // Log for debugging
        GD.Print("Player ", playerName, " taking ", amount,
            " damage. Current HP: ", hp);

        // Apply damage
        hp = Math.Max(0, hp - amount);

        // Conditional debug
#if DEBUG
        if (hp == 0)
        {
            GD.Print("Player died at position ", Position);
        }
#endif

        EmitSignal(SignalName.Damaged, amount);
    }
}
Output (izvade) panel (panelī) redzami detalizēti debug (atkļūdošana) ziņojumi; pie nederīgas input (ievades) - error ar context.
