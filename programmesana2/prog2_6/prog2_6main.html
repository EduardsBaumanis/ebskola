6.1 UI: Control mezgli un konteineri

// Control mezgli NAV Node2D - tiem ir enkuri, konteineri un tēma.
//   Label            teksts            Button       poga
//   LineEdit         viena rinda       TextEdit     vairākas rindas
//   VBoxContainer    kārto vertikāli   HBoxContainer  horizontāli
//   GridContainer    režģis            PanelContainer fons un rāmis
// Konteiners kārto bērnus PATS - nelieto rokas pozīcijas tajā.

using Godot;

public partial class MainMenu : Control
{
    public override void _Ready()
    {
        Button button = GetNode<Button>("VBoxContainer/StartButton");
        button.Pressed += OnStartPressed;
    }

    private void OnStartPressed()
    {
        GetTree().ChangeSceneToFile("res://level1.tscn");
    }
}

Enkurs (Layout -> Anchors Preset -> Center) notur izvēlni vidū, mainot loga izmēru.

6.2 Tween - animācija ar kodu

Tween tween = CreateTween();

// no pašreizējās vērtības uz (600, 300) vienā sekundē
tween.TweenProperty(node, "position", new Vector2(600, 300), 1.0);

// izgaismošanās
node.Modulate = new Color(1, 1, 1, 0);
tween.TweenProperty(node, "modulate:a", 1.0, 0.5);

tween.SetParallel(true);                              // visas reizē, nevis pēc kārtas
tween.SetTrans(Tween.TransitionType.Elastic);        // atlec mērķī

// Ja notikums var atkārtoties ātri - apturi veco:
if (activeTween != null && activeTween.IsRunning()) activeTween.Kill();

// AnimationPlayer = vizuāli veidota animācija ar atslēgkadriem
//   player.Play("uzvara");

Animācija nav tikai skaistums - tā pasaka spēlētājam, ka darbība tika pamanīta.

6.3 Audio: efekti, mūzika un bus

AudioStreamPlayer sfx = GetNode<AudioStreamPlayer>("SFX");
sfx.Play();

// Mūzikas mīksta ienākšana
AudioStreamPlayer music = GetNode<AudioStreamPlayer>("Music");
music.VolumeDb = -40;
music.Play();
CreateTween().TweenProperty(music, "volume_db", 0.0, 1.0);

// Atsevišķi bus (apakšā cilne Audio): Master -> Music , SFX
int index = AudioServer.GetBusIndex("Music");
AudioServer.SetBusVolumeDb(index, -10.0f);

// Skaļumu mēra decibelos:  0 dB = pilns , -80 dB = kluss

Mūziku un efektus liec atsevišķos bus - tad spēlētājs var izslēgt mūziku, saglabājot skaņas.
