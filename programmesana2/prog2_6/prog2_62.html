6.2 Animācijas un Tween (pakāpeniska vērtību maiņa)

Stundas uzdevums: Pievienot animācijas UI (lietotāja saskarne) un spēles objektiem ar AnimationPlayer (animāciju atskaņotājs) un Tween.

SR 2.4.7. UI SR 2.4.15. Modulāras programmas

Teorija: vizuālā atgriezeniskā saite ar AnimationPlayer un Tween

Divas animēšanas pieejas: AnimationPlayer un Tween

Plūdenas pārejas lietotāja saskarnē kalpo ne vien estētikai, bet arī kā tūlītēja vizuālā atgriezeniskā saite (visual feedback), kas apstiprina, ka lietotāja klikšķis vai cita darbība ir uztverta. Godot piedāvā divus savstarpēji papildinošus rīkus — tos var salīdzināt ar iepriekš samontētu videoklipu uz laika skalas un viedās spuldzes automātisko aptumšošanu (dimmer):

  • AnimationPlayer: atsevišķs scēnas mezgls ar vizuālu laika skalas redaktoru (timeline editor), kurā manuāli atzīmē atslēgkadrus (keyframes) vairākām īpašībām vienlaikus. Piemērots sarežģītām, atkārtojamām secībām ar precīzi fiksētu ritmu.
  • Tween (in-betweening): viegls C# kodā ar CreateTween() izveidojams palīgobjekts, kuram norāda tikai mērķa īpašību, gala vērtību un ilgumu sekundēs, bet visas starpvērtības no pašreizējā stāvokļa dzinējs aprēķina automātiski:
// 1. Iepriekš sagatavotas laika skalas animācijas palaišana:
AnimationPlayer animAtskanotajs = GetNode<AnimationPlayer>("AnimAtskanotajs");
animAtskanotajs.Play("PanelaAtversana");

// 2. Dinamiska secīga pāreja ar Tween (palielina un atgriež sākuma izmērā):
Tween tween = CreateTween();
tween.TweenProperty(indikators, "scale", new Vector2(1.2f, 1.2f), 0.15);
tween.TweenProperty(indikators, "scale", Vector2.One, 0.15);

Īpašību interpolācija (TweenProperty), secīgums un pārtraukšana (Kill)

Ar metodi TweenProperty(objekts, "ipasiba", galaVertiba, ilgums) var plūdeni mainīt pozīciju ("position"), mērogu ("scale"), krāsu toni ("modulate") vai tikai caurspīdīguma jeb alfa kanālu ("modulate:a" no 0.0 līdz 1.0). Pēc noklusējuma visi viena Tween soļi izpildās secīgi cits pēc cita, bet izsaukums SetParallel(true) liek tiem norisināties vienlaikus; savukārt SetTrans(...) maina kustības raksturu (piemēram, TransitionType.Elastic rada atsperīgu svārstību mērķa punktā):

private Tween aktivaisTween;

private void IzgaismotPaneli(Control panelis)
{
    aktivaisTween?.Kill(); // Ja iepriekšējā pāreja vēl turpinās, to droši aptur.
    aktivaisTween = CreateTween();
    aktivaisTween.SetParallel(true);

    panelis.Modulate = new Color(1, 1, 1, 0);
    aktivaisTween.TweenProperty(panelis, "modulate:a", 1.0f, 0.4);
    aktivaisTween.TweenProperty(panelis, "position:y", 100.0f, 0.4)
        .SetTrans(Tween.TransitionType.Cubic);
}

Ja viens un tas pats notikums atkārtojas ļoti strauji, divi vienlaicīgi Tween objekti var sākt savstarpēji konfliktēt par vienas īpašības vērtību. Glabājot atsauci klases laukā un pirms jaunas animācijas izsaucot aktivaisTween?.Kill(), iepriekšējā pāreja tiek korekti pārtraukta.

1. uzdevums

Uztaisi pirmo Tween animāciju

Kur strādāt: Izveido Scenes/TweenDemo.tscn ar Node2D sakni un redzamu bērna mezglu Visual; saknei piesaisti Scripts/TweenDemo.cs. Tā metodē _Ready() iegūsti Visual kā objekts un raksti Tween piemēru.

Beigās objekts vienmērīgi pārvietosies no vienas vietas uz otru.

  1. Pārliecinies, ka faila sākumā ir using Godot;.
  2. Izveido kodā Tween tween = CreateTween();.
  3. Pievieno tween.TweenProperty(objekts, "position", new Vector2(600, 300), 1.0);.
  4. Būvē un palaid - objektam vienmērīgi jāaizslīd.
  5. Nomaini ilgumu uz 0.2 un palaid vēlreiz.
  6. Pievieno .SetTrans(Tween.TransitionType.Elastic);.
  7. Pieraksti, kā mainījās kustības raksturs.

Gatavs, kad: objekts pārvietojas vienmērīgi, un ar TransitionType.Elastic tas mērķī nedaudz atlec.

2. uzdevums

Animē izvēlnes parādīšanos

Kur strādāt: Papildini esošā Scripts/MainMenu.cs metodi _Ready() ar izvēlnes parādīšanās animāciju. Izvēlnes mezgli atrodas Scenes/Menu.tscn.

Beigās izvēlne parādīsies mīksti, nevis uzreiz.

  1. Iestati izvēlnei sākumā Modulate = new Color(1, 1, 1, 0);.
  2. Izveido _Ready method Tween.
  3. Animē īpašību modulate:a no 0 uz 1 vienā sekundē.
  4. Palaid un vēro, kā izvēlne parādās.
  5. Pievieno arī nelielu nobīdi no augšas uz vietu.
  6. Savieno abas animācijas ar tween.SetParallel(true);.
  7. Pieraksti, ar ko paralēla animācija atšķiras no secīgas.
Modulate = new Color(1, 1, 1, 0);
Tween tween = CreateTween();
tween.SetParallel(true);
tween.TweenProperty(this, "modulate:a", 1.0f, 1.0);

Gatavs, kad: izvēlne vienlaikus izgaismojas un noslīd vietā, nevis dara to pa vienam.

3. uzdevums

Pievieno atsauksmes animāciju spēlē

Kur strādāt: Savākšanas animāciju pievieno priekšmeta skripta savākšanas metodei: Scripts/Collectible.cs labirinta projektā vai Scripts/Pickup.cs platformas projektā. Trieciena mirgojumu pievieno Scripts/Player.cs bojājumu apstrādei; Tween atsauci glabā attiecīgās klases laukā.

Beigās spēlētājs redzēs, ka viņa darbība tika pamanīta.

  1. Izvēlies vienu event (notikumu) savā spēlē, piemēram monētas savākšanu.
  2. Pievieno tam Tween, kas objektu uz brīdi palielina un tad atgriež.
  3. Pievieno arī krāsas mirgojumu, kad spēlētājs saņem triecienu.
  4. Pārliecinies, ka animācija netraucē spēles gaitu.
  5. Pārbaudi, kas notiek, ja event atkārtojas ļoti ātri.
  6. Apturi iepriekšējo Tween ar Kill(), ja tas vēl darbojas.
  7. Pieraksti, kāpēc animācija palīdz saprast spēli.

Gatavs, kad: savācot monētu, tā uz mirkli palielinās, un ātri atkārtojot event, animācijas nesajūk.

Papildu uzdevums - Izmēģini AnimationPlayer

Kur strādāt: AnimationPlayer pievieno Scenes/TweenDemo.tscn; tā atrašanu un Play izsaukumu raksti Scripts/TweenDemo.cs metodē _Ready().

Ja pamatdarbs ir gatavs, salīdzini otru pieeju.

  1. Pievieno scēnai AnimationPlayer node.
  2. Izveido tajā animāciju ar diviem atslēgkadriem.
  3. Palaid to no koda ar animationPlayer.Play("nosaukums");.
  4. Pieraksti, kura pieeja bija ātrāk izveidojama.
  5. Pieraksti, kurā gadījumā labāk lietot katru no tām.

Gatavs, kad: abas pieejas dod animāciju, un tu vari nosaukt, kad kura ir ērtāka.

Paplašināts koda piemērs 
using Godot;

public partial class Player : CharacterBody2D
{
    public void OnTakeDamage(int amount)
    {
        // Damage number popup
        Label damageLabel = new Label();
        damageLabel.Text = "-" + amount;
        damageLabel.Position = Position + new Vector2(0, -30);
        damageLabel.AddThemeColorOverride("font_color", new Color(1, 0, 0));
        GetParent().AddChild(damageLabel);

        // Tween: peld augšup un izgaist
        Tween tween = damageLabel.CreateTween();
        tween.SetParallel(true);  // abas animācijas paralēli
        tween.TweenProperty(damageLabel, "position", damageLabel.Position + new Vector2(0, -50), 0.8);
        tween.TweenProperty(damageLabel, "modulate:a", 0.0, 0.8);
        tween.Chain().TweenCallback(Callable.From(damageLabel.QueueFree));

        // Player flash red
        Tween flash = CreateTween();
        Modulate = new Color(1, 0, 0);
        flash.TweenProperty(this, "modulate", new Color(1, 1, 1), 0.3);
    }
}
Bojājot ienaidnieku, parādās '-25' sarkanā tekstā, peld augšup un izgaist; player sarkans flash 0.3 sec.

Ko sagatavo

Stundas mērķis: Tavā spēlē darbojas Tween animācijas: izvēlne parādās mīksti, un vismaz viens spēles event dod spēlētājam vizuālu atsauksmi, kas nesajūk pie ātras atkārtošanas.

GitHub krātuvē jābūt:

  • README.md ievietota video saite, kurā redzama izvēlnes spawn (parādīšanās) un spēles event animācija.
  • C# fails ar CreateTween un TweenProperty izsaukumiem.
  • README.md: ar ko paralēla animācija atšķiras no secīgas un kāpēc vajag Kill().

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Tween nedarbojas: CreateTween() izveido Tween objektu; ja vēlāk tas jāaptur, saglabā to laukā.
  • AnimationPlayer skip kadrs: Animation length (animācijas ilgums) pārāk īss vai Play() izsaukts vairākkārt.
  • Particles invisible: CollisionShape2D (2D sadursmes forma) vai Sprite2D (2D attēla mezgls) parent var ietekmēt redzamība.
