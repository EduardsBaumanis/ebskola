6.2 Animācijas un Tween (pakāpeniska vērtību maiņa)

Sasniedzamais rezultāts: Pievienot animācijas UI (lietotāja saskarne) un spēles objektiem ar AnimationPlayer (animāciju atskaņotājs) un Tween.

SR 2.4.7. UI SR 2.4.15. Modulāras programmas

Teorija: vizuālā atgriezeniskā saite ar AnimationPlayer un Tween

Divas animēšanas pieejas: AnimationPlayer un Tween

Plūdenas pārejas lietotāja saskarnē kalpo ne vien estētikai, bet arī kā tūlītēja vizuālā atgriezeniskā saite (visual feedback), kas apstiprina, ka lietotāja klikšķis vai cita darbība ir uztverta. Godot piedāvā divus savstarpēji papildinošus rīkus — tos var salīdzināt ar iepriekš samontētu videoklipu uz laika skalas un viedās spuldzes automātisko aptumšošanu (dimmer):

  • AnimationPlayer: atsevišķs scēnas mezgls ar vizuālu laika skalas redaktoru (timeline editor), kurā manuāli atzīmē atslēgkadrus (keyframes) vairākām īpašībām vienlaikus. Piemērots sarežģītām, atkārtojamām secībām ar precīzi fiksētu ritmu.
  • Tween (in-betweening): viegls C# kodā ar CreateTween() izveidojams palīgobjekts, kuram norāda tikai mērķa īpašību, gala vērtību un ilgumu sekundēs, bet visas starpvērtības no pašreizējā stāvokļa dzinējs aprēķina automātiski:
// 1. Iepriekš sagatavotas laika skalas animācijas palaišana:
AnimationPlayer animAtskanotajs = GetNode<AnimationPlayer>("AnimAtskanotajs");
animAtskanotajs.Play("PanelaAtversana");

// 2. Dinamiska secīga pāreja ar Tween (palielina un atgriež sākuma izmērā):
Tween tween = CreateTween();
tween.TweenProperty(indikators, "scale", new Vector2(1.2f, 1.2f), 0.15);
tween.TweenProperty(indikators, "scale", Vector2.One, 0.15);

Īpašību interpolācija (TweenProperty), secīgums un pārtraukšana (Kill)

Ar metodi TweenProperty(objekts, "ipasiba", galaVertiba, ilgums) var plūdeni mainīt pozīciju ("position"), mērogu ("scale"), krāsu toni ("modulate") vai tikai caurspīdīguma jeb alfa kanālu ("modulate:a" no 0.0 līdz 1.0). Pēc noklusējuma visi viena Tween soļi izpildās secīgi cits pēc cita, bet izsaukums SetParallel(true) liek tiem norisināties vienlaikus; savukārt SetTrans(...) maina kustības raksturu (piemēram, TransitionType.Elastic rada atsperīgu svārstību mērķa punktā):

private Tween aktivaisTween;

private void IzgaismotPaneli(Control panelis)
{
    aktivaisTween?.Kill(); // Ja iepriekšējā pāreja vēl turpinās, to droši aptur.
    aktivaisTween = CreateTween();
    aktivaisTween.SetParallel(true);

    panelis.Modulate = new Color(1, 1, 1, 0);
    aktivaisTween.TweenProperty(panelis, "modulate:a", 1.0f, 0.4);
    aktivaisTween.TweenProperty(panelis, "position:y", 100.0f, 0.4)
        .SetTrans(Tween.TransitionType.Cubic);
}

Ja viens un tas pats notikums atkārtojas ļoti strauji, divi vienlaicīgi Tween objekti var sākt savstarpēji konfliktēt par vienas īpašības vērtību. Glabājot atsauci klases laukā un pirms jaunas animācijas izsaucot aktivaisTween?.Kill(), iepriekšējā pāreja tiek korekti pārtraukta.

1. uzdevums

Uztaisi pirmo Tween animāciju

Kur strādāt: Izveido demonstrācijas scēnu Scenes/TweenDemo.tscn ar Node2D sakni TweenDemo un bērna mezglu Visual (ColorRect). Izveido skriptu Scripts/TweenDemo.cs un piesaisti to saknei TweenDemo.

Beigās lauciņš vienmērīgi aizslīdēs pāri ekrānam un ar pārejas līkni TransitionType.Elastic mērķa punktā atsperīgi iešūposies.

Scēnas koka uzbūve (Scenes/TweenDemo.tscn):

TweenDemo (Node2D - piesaistīts Scripts/TweenDemo.cs)
 ├── Visual (ColorRect - Size: 80 × 80, Pivot Offset: 40 × 40, Position: 120, 260)
 └── InfoLabel (Label - Text: "Nospied Space vai kreiso peles pogu, lai pārbaudītu 3. uzdevuma animāciju")
  1. Izveido jaunu scēnu ar Node2D sakni TweenDemo, pievieno tai bērnu ColorRect ar nosaukumu Visual (iestati Layout -> Transform -> Size = 80 × 80, Pivot Offset = 40 × 40, Position = (120, 260) un spilgtu krāsu) un saglabā kā res://Scenes/TweenDemo.tscn.
  2. Izveido skriptu res://Scripts/TweenDemo.cs (public partial class TweenDemo : Node2D) un piesaisti to saknei TweenDemo.
  3. Atrodi metodē _Ready() lauciņu: visual = GetNode<ColorRect>("Visual");.
  4. Izveido pāreju ar Tween tween = CreateTween(); un pievieno kustību: tween.TweenProperty(visual, "position", new Vector2(600, 260), 1.0);.
  5. Nospied Build, palaid Scenes/TweenDemo.tscn (F6) un pārliecinies, ka lauciņš 1 sekundes laikā vienmērīgi aizslīd pa labi.
  6. Pievieno izsaukuma galā pārejas līkni un bremzēšanu: .SetTrans(Tween.TransitionType.Elastic).SetEase(Tween.EaseType.Out); un palaid vēlreiz.
  7. Pieraksti failā README.md, kā mainījās kustības raksturs ar TransitionType.Elastic salīdzinājumā ar noklusēto pāreju.

Gatavs, kad: Visual lauciņš vienmērīgi pārvietojas uz mērķa koordinātām un ar TransitionType.Elastic galapunktā atsperīgi iešūpojas.

2. uzdevums

Animē sākuma izvēlnes parādīšanos

Kur strādāt: Atver 6.1. stundā izveidoto skriptu Scripts/MainMenu.cs (kas piesaistīts Scenes/Menu.tscn saknei Menu) un papildini metodi _Ready() ar paralēlu Tween parādīšanās animāciju.

Beigās sākuma izvēlne, atverot spēli, vienlaikus plūdeni izgaismosies un noslīdēs savā vietā.

  1. Atver failu Scripts/MainMenu.cs un metodē _Ready() atrodi konteineru: Control vbox = GetNode<Control>("VBox");.
  2. Saglabā konteinera sākotnējo pozīciju Vector2 targetPos = vbox.Position; un pacel to 40 pikseļus augstāk: vbox.Position = targetPos + new Vector2(0, -40);.
  3. Padari izvēlni sākumā pilnīgi caurspīdīgu ar Modulate = new Color(1, 1, 1, 0);.
  4. Izveido Tween un ieslēdz paralēlo režīmu: Tween tween = CreateTween(); tween.SetParallel(true);.
  5. Pievieno divas paralēlas animācijas (0.6 sekundēs): tween.TweenProperty(this, "modulate:a", 1.0f, 0.6); un tween.TweenProperty(vbox, "position", targetPos, 0.6).SetTrans(Tween.TransitionType.Cubic).SetEase(Tween.EaseType.Out);.
  6. Nospied Build, palaid Scenes/Menu.tscn un vēro, kā izvēlne vienlaikus izgaismojas un noslīd vietā.
  7. Pieraksti failā README.md, ar ko paralēla animācija (SetParallel(true)) atšķiras no secīgas (Chain()).

3. uzdevums

Pievieno klikšķa atsauksmes animāciju ar Kill() aizsardzību

Kur strādāt: Papildini skriptu Scripts/TweenDemo.cs (scēnā Scenes/TweenDemo.tscn) ar klases lauku private Tween pulseTween;, ievades apstrādi _UnhandledInput() un metodi PlayFeedbackPulse().

Beigās katrs spēlētāja klikšķis vai Space nospiešana izsauks pamanāmu mēroga palielināšanos un krāsas mirgojumu, kas nesajūk pat pie ļoti ātras, atkārtotas spiešanas.

  1. Pievieno klasei TweenDemo (failā Scripts/TweenDemo.cs) lauku private Tween pulseTween;.
  2. Izveido metodi public void PlayFeedbackPulse(), kuras sākumā pārbaudi un apturi iepriekšējo animāciju: if (pulseTween != null && pulseTween.IsRunning()) pulseTween.Kill();.
  3. Atjauno tūlīt pēc Kill() sākuma stāvokli (visual.Scale = Vector2.One; visual.Modulate = Colors.White;), lai strauji atkārtoti klikšķi neuzkrātu palielinājumu.
  4. Izveido jaunu pulseTween = CreateTween();, kas vispirms 0.12 sekundēs palielina visual mērogu uz new Vector2(1.25f, 1.25f) un iekrāso dzeltenīgu, bet pēc pulseTween.Chain() 0.18 sekundēs atgriež Vector2.One un Colors.White.
  5. Izsauc PlayFeedbackPulse() no metodes _UnhandledInput(InputEvent @event), kad nospiests ui_accept (Space) vai peles kreisā poga.
  6. Palaid Scenes/TweenDemo.tscn (F6) un spied Space vai peles pogu ļoti ātri pēc kārtas, pārbaudot, ka lauciņa izmērs un krāsa vienmēr korekti atgriežas normālā stāvoklī.
  7. Pieraksti failā README.md, kāpēc spēlēs ir svarīga vizuālā atsauksme un kāpēc pirms jauna Tween palaišanas vajag izsaukt Kill().

Gatavs, kad: nospiežot Space vai peles pogu, Visual uz mirkli palielinās un iekrāsojas, un pat pie ļoti ātras spiešanas animācija nekad „neiestrēgst" palielinātā izmērā.

Papildu uzdevums - Izmēģini AnimationPlayer un salīdzini ar Tween

Kur strādāt: Mezglu AnimationPlayer pievieno scēnai Scenes/TweenDemo.tscn; salīdzinājumu pieraksti README.md.

Ja pamatdarbs ir gatavs, salīdzini kodu bāzētu Tween ar laika joslas redaktoru AnimationPlayer.

  1. Pievieno scēnai Scenes/TweenDemo.tscn mezglu AnimationPlayer.
  2. Atver apakšējā panelī cilni Animation, nospied Animation -> New un izveido animāciju pulse (garums 0.4 s).
  3. Ievieto divus atslēgkadrus (atslēgas ikona Inspector panelī blakus Visual īpašībai Scale): 0.0 sekundē (1, 1), 0.2 sekundē (1.25, 1.25) un 0.4 sekundē (1, 1).
  4. Izsauc animāciju no koda ar GetNode<AnimationPlayer>("AnimationPlayer").Play("pulse");.
  5. Pieraksti README.md, kurā situācijā ērtāks ir Tween (dinamiskām koordinātām un UI pārejām) un kurā — AnimationPlayer (sarežģītām vairāku īpašību un kadru animācijām).

Gatavs, kad: AnimationPlayer atskaņo animāciju un README.md ir pierakstīts abu pieeju salīdzinājums.

Pilnais koda piemērs — gatavs šīs stundas risinājums

1. fails: Scripts/TweenDemo.cs (piesaistīts TweenDemo saknei scēnā Scenes/TweenDemo.tscn)

using Godot;

public partial class TweenDemo : Node2D
{
    private ColorRect visual;
    private Tween pulseTween;

    public override void _Ready()
    {
        visual = GetNode<ColorRect>("Visual");
        visual.PivotOffset = visual.Size / 2.0f;

        // 1. uzdevums: vienmērīga pārvietošanās ar Elastic pāreju
        Tween moveTween = CreateTween();
        moveTween.TweenProperty(visual, "position", new Vector2(600, 260), 1.0)
            .SetTrans(Tween.TransitionType.Elastic)
            .SetEase(Tween.EaseType.Out);
    }

    public override void _UnhandledInput(InputEvent @event)
    {
        if (@event.IsActionPressed("ui_accept") ||
            (@event is InputEventMouseButton mouseBtn && mouseBtn.Pressed && mouseBtn.ButtonIndex == MouseButton.Left))
        {
            PlayFeedbackPulse();
        }
    }

    // 3. uzdevums: klikšķa atsauksme ar Kill() aizsardzību
    public void PlayFeedbackPulse()
    {
        if (pulseTween != null && pulseTween.IsRunning())
        {
            pulseTween.Kill();
        }

        visual.Scale = Vector2.One;
        visual.Modulate = Colors.White;

        pulseTween = CreateTween();
        pulseTween.SetParallel(true);
        pulseTween.TweenProperty(visual, "scale", new Vector2(1.25f, 1.25f), 0.12)
            .SetTrans(Tween.TransitionType.Quad)
            .SetEase(Tween.EaseType.Out);
        pulseTween.TweenProperty(visual, "modulate", new Color(1.0f, 0.85f, 0.3f), 0.12);

        pulseTween.Chain();
        pulseTween.TweenProperty(visual, "scale", Vector2.One, 0.18)
            .SetTrans(Tween.TransitionType.Back)
            .SetEase(Tween.EaseType.Out);
        pulseTween.TweenProperty(visual, "modulate", Colors.White, 0.18);
    }
}

Ko sagatavo

Stundas mērķis: Tavā projektā darbojas Tween animācijas: objekta pārvietošana ar pārejas līkni, sākuma izvēlnes plūdena parādīšanās un klikšķa atsauksmes animācija, kas ar Kill() ir pasargāta no dubultas pārklāšanās.

GitHub krātuvē jābūt:

  • Skriptiem Scripts/TweenDemo.cs un Scripts/MainMenu.cs, kā arī scēnām Scenes/TweenDemo.tscn un Scenes/Menu.tscn.
  • README.md ievietotai video saitei, kurā redzama izvēlnes parādīšanās un klikšķa atsauksmes animācija.
  • README.md atbildēm: kā mainījās kustība ar TransitionType.Elastic, ar ko paralēla animācija (SetParallel(true)) atšķiras no secīgas (Chain()) un kāpēc pirms jaunas animācijas vajag Kill().

Kā iesniedz: Veic git commit un git push. Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Tween nedarbojas: CreateTween() izveido Tween objektu; ja vēlāk tas jāaptur, saglabā to laukā.
  • AnimationPlayer skip kadrs: Animation length (animācijas ilgums) pārāk īss vai Play() izsaukts vairākkārt.
  • Particles invisible: CollisionShape2D (2D sadursmes forma) vai Sprite2D (2D attēla mezgls) parent var ietekmēt redzamība.
