Stundas uzdevums: Pievienot animation (animācijas) UI (lietotāja saskarne) un spēles object (objektiem) ar AnimationPlayer (animāciju atskaņotājs) un Tween (pakāpeniska vērtību maiņa).

Teorija: Animation (animācijas) Godot

Godot piedāvā divas pieejas animation (animācijām):

  • AnimationPlayer (animāciju atskaņotājs) - vizuāli (timeline editor (laika skalas redaktors)) izveidotas animation (animācijas).
  • Tween (pakāpeniska vērtību maiņa) - programmatiski izveidotas vienkāršas animation (animācijas).
// Tween - fade in
private void ShowButton()
{
    Tween tween = CreateTween();
    button.Modulate = new Color(1, 1, 1, 0);  // sākotnēji caurspīdīgs
    tween.TweenProperty(button, "modulate", new Color(1, 1, 1, 1), 0.5);
}

// Tween - kustība ar bounce
private void ShakeButton()
{
    Tween tween = CreateTween();
    Vector2 original = button.Position;
    tween.TweenProperty(button, "position", original + new Vector2(10, 0), 0.05);
    tween.TweenProperty(button, "position", original - new Vector2(10, 0), 0.05);
    tween.TweenProperty(button, "position", original, 0.05);
}

Praktiskie uzdevumi

1. uzdevums -

Uztaisi pirmo Tween (pakāpeniska vērtību maiņa) animation (animāciju)

Beigās object (objekts) vienmērīgi pārvietosies no vienas vietas uz otru.

  1. Pārliecinies, ka file (faila) sākumā ir using Godot;.
  2. Izveido code (kodā) Tween tween = CreateTween();.
  3. Pievieno tween.TweenProperty(objekts, "position", new Vector2(600, 300), 1.0);.
  4. Būvē un palaid - object (objektam) vienmērīgi jāaizslīd.
  5. Nomaini ilgumu uz 0.2 un palaid vēlreiz.
  6. Pievieno .SetTrans(Tween.TransitionType.Elastic);.
  7. Pieraksti, kā mainījās kustības raksturs.

Gatavs, kad: object (objekts) pārvietojas vienmērīgi, un ar TransitionType.Elastic tas mērķī nedaudz atlec.

2. uzdevums -

Animē menu (izvēlnes) parādīšanos

Beigās menu (izvēlne) parādīsies mīksti, nevis uzreiz.

  1. Iestati menu (izvēlnei) sākumā Modulate = new Color(1, 1, 1, 0);.
  2. Izveido _Ready method (metodē) Tween (pakāpeniska vērtību maiņa).
  3. Animē property (īpašību) modulate:a no 0 uz 1 vienā sekundē.
  4. Palaid un vēro, kā menu (izvēlne) parādās.
  5. Pievieno arī nelielu nobīdi no augšas uz vietu.
  6. Savieno abas animation (animācijas) ar tween.SetParallel(true);.
  7. Pieraksti, ar ko paralēla animation (animācija) atšķiras no secīgas.

Gatavs, kad: menu (izvēlne) vienlaikus izgaismojas un noslīd vietā, nevis dara to pa vienam.

3. uzdevums -

Pievieno atsauksmes animation (animāciju) spēlē

Beigās spēlētājs redzēs, ka viņa darbība tika pamanīta.

  1. Izvēlies vienu event (notikumu) savā spēlē, piemēram monētas savākšanu.
  2. Pievieno tam Tween (pakāpeniska vērtību maiņa), kas object (objektu) uz brīdi palielina un tad atgriež.
  3. Pievieno arī krāsas mirgojumu, kad spēlētājs saņem triecienu.
  4. Pārliecinies, ka animation (animācija) netraucē spēles gaitu.
  5. Pārbaudi, kas notiek, ja event (notikums) atkārtojas ļoti ātri.
  6. Apturi iepriekšējo Tween (pakāpeniska vērtību maiņa) ar Kill(), ja tas vēl darbojas.
  7. Pieraksti, kāpēc animation (animācija) palīdz saprast spēli.

Gatavs, kad: savācot monētu, tā uz mirkli palielinās, un ātri atkārtojot event (notikumu), animation (animācijas) nesajūk.

Papildu uzdevums - Izmēģini AnimationPlayer (animāciju atskaņotājs)

Ja pamatdarbs ir gatavs, salīdzini otru pieeju.

  1. Pievieno scene (scēnai) AnimationPlayer (animāciju atskaņotājs) node (mezglu).
  2. Izveido tajā animation (animāciju) ar diviem atslēgkadriem.
  3. Palaid to no code (koda) ar animationPlayer.Play("nosaukums");.
  4. Pieraksti, kura pieeja bija ātrāk izveidojama.
  5. Pieraksti, kurā gadījumā labāk lietot katru no tām.

Gatavs, kad: abas pieejas dod animation (animāciju), un tu vari nosaukt, kad kura ir ērtāka.

Biežākās kļūdas

  • Tween (pakāpeniska vērtību maiņa) nedarbojas: CreateTween() izveido Tween (pakāpeniska vērtību maiņa) object (objektu); ja vēlāk tas jāaptur, saglabā to field (laukā).
  • AnimationPlayer (animāciju atskaņotājs) skip frames (kadrs): Animation length (animācijas ilgums) pārāk īss vai Play() izsaukts vairākkārt.
  • Particles invisible: CollisionShape2D (2D sadursmes forma) vai Sprite2D (2D attēla mezgls) parent var ietekmēt visibility (redzamība).

Code sample (koda piemērs) (paplašināts)

using Godot;

public partial class Player : CharacterBody2D
{
    public void OnTakeDamage(int amount)
    {
        // Damage number popup
        Label damageLabel = new Label();
        damageLabel.Text = "-" + amount;
        damageLabel.Position = Position + new Vector2(0, -30);
        damageLabel.AddThemeColorOverride("font_color", new Color(1, 0, 0));
        GetParent().AddChild(damageLabel);

        // Tween: peld augšup un izgaist
        Tween tween = damageLabel.CreateTween();
        tween.SetParallel(true);  // abas animācijas paralēli
        tween.TweenProperty(damageLabel, "position", damageLabel.Position + new Vector2(0, -50), 0.8);
        tween.TweenProperty(damageLabel, "modulate:a", 0.0, 0.8);
        tween.Chain().TweenCallback(Callable.From(damageLabel.QueueFree));

        // Player flash red
        Tween flash = CreateTween();
        Modulate = new Color(1, 0, 0);
        flash.TweenProperty(this, "modulate", new Color(1, 1, 1), 0.3);
    }
}
