Teorija: skaņas atskaņošana, decibelu skala un skaņas kopnes (Audio Buses)

Skaņas plūsmas (AudioStreamPlayer) un skaļums decibelos (dB)

Audio failu atskaņošanai Godot izmanto mezglu AudioStreamPlayer (vienmērīgai skaņai neatkarīgi no vietas ekrānā) vai AudioStreamPlayer2D (pozicionālai skaņai, kas kļūst klusāka attālinoties). Īpašībai Stream piešķir ielādētu skaņas resursu (piemēram, .ogg vai .wav failu) un atskaņošanu sāk ar metodi Play(); ja uz viena un tā paša mezgla Play() izsauc atkārtoti, pirms iepriekšējais ieraksts beidzies, skaņa tiek pārtraukta un sākta no sākuma.

Cilvēka dzirde skaņas intensitātes izmaiņas uztver logaritmiski, nevis lineāri, tāpēc skaļumu programmēšanā regulē decibelos (VolumeDb): 0 dB atbilst oriģinālajam ieraksta līmenim bez pastiprinājuma, savukārt negatīvas vērtības (piemēram, -10 dB vai -40 dB) skaņu pakāpeniski klusina, ko var vienmērīgi animēt ar Tween:

using Godot;

private void AtskanotArPareju(AudioStreamPlayer atskanotajs, string cels)
{
    atskanotajs.Stream = ResourceLoader.Load<AudioStream>(cels);
    atskanotajs.VolumeDb = -40.0f;
    atskanotajs.Play();
    CreateTween().TweenProperty(atskanotajs, "volume_db", 0.0f, 1.5);
}

Skaņas kopņu arhitektūra (Audio Buses) un AudioServer

Ja lietotnē skan gan fona celiņš, gan īsi saskarnes paziņojumi, katra atskaņotāja individuāla regulēšana būtu neērta. Tāpēc Godot izmanto skaņas kopņu (Audio Bus) sistēmu — tā darbojas gluži kā koncertzāles skaņu pults, kur katrs mikrofons vai instruments vispirms ieplūst savā grupas kanālā (piemēram, Music, SFX, Voice), un visi grupu kanāli tālāk apvienojas galvenajā izejā Master.

Piesaistot katram AudioStreamPlayer atbilstošo kopni, C# kodā ar AudioServer var neatkarīgi mainīt visas grupas skaļumu vienuviet (piemēram, ar AudioServer.SetBusVolumeDb(AudioServer.GetBusIndex("Music"), vertibaDb)), pilnībā apklusinot fona pavadījumu, kamēr īsie skaņas signāli citā kopnē turpina skanēt netraucēti:

// Mezglus piesaista atbilstošajām kopnēm (var iestatīt arī Inspector panelī):
fonaAtskanotajs.Bus = "Music";
signaluAtskanotajs.Bus = "SFX";

// Maina visas kopnes skaļumu vienuviet (piemēram, no HSlider.ValueChanged):
private void IestatitKopnesSkalumu(string kopnesNosaukums, double vertibaDb)
{
    int indekss = AudioServer.GetBusIndex(kopnesNosaukums);
    AudioServer.SetBusVolumeDb(indekss, (float)vertibaDb);
    AudioServer.SetBusMute(indekss, vertibaDb <= -40.0);
}

Izveido Scripts/AudioManager.cs un atskaņo skaņas efektu

Kur strādāt: Ievieto īsu skaņas failu mapē Sounds/click.ogg (vai Sounds/click.wav). Scēnā Scenes/Menu.tscn pievieno mezglu AudioManager (Node) ar bērnu SFX (AudioStreamPlayer) un piesaisti Scripts/AudioManager.cs. Izsaukumu pievieno Scripts/MainMenu.cs pogu klikšķiem.

Beigās katrs pogas klikšķis izvēlnē atskaņos skaņas efektu.

Papildinātais scēnas koks (Scenes/Menu.tscn):

Menu (Control - piesaistīts Scripts/MainMenu.cs)
 ├── Background (ColorRect)
 ├── VBox (VBoxContainer - TitleLabel, StartButton, SettingsButton, QuitButton)
 ├── SettingsPanel (PanelContainer)
 │    └── SettingsVBox (VBoxContainer)
 │         ├── SettingsTitle (Label - Text: "Iestatījumi")
 │         ├── MusicLabel (Label - Text: "Mūzikas skaļums (dB)")
 │         ├── MusicSlider (HSlider - Min: -40, Max: 0, Step: 0.5, Value: 0)
 │         ├── SfxLabel (Label - Text: "Efektu skaļums (dB)")
 │         ├── SfxSlider (HSlider - Min: -40, Max: 0, Step: 0.5, Value: 0)
 │         └── BackButton (Button - Text: "Aizvērt")
 └── AudioManager (Node - piesaistīts Scripts/AudioManager.cs)
      ├── SFX (AudioStreamPlayer - Bus: "SFX")
      └── Music (AudioStreamPlayer - Bus: "Music")
  1. Iekopē īsu klikšķa skaņas failu projekta mapē res://Sounds/click.ogg (vai res://Sounds/click.wav; ja faila vēl nav, pilnajā piemērā zemāk ir iekļauta metode, kas skaņas vilni uzģenerē automātiski kodā).
  2. Atver Scenes/Menu.tscn un pievieno saknei Menu bērna mezglu Node ar nosaukumu AudioManager, bet tam — bērnu AudioStreamPlayer ar nosaukumu SFX.
  3. Izveido skriptu res://Scripts/AudioManager.cs (public partial class AudioManager : Node) un piesaisti to mezglam AudioManager.
  4. Atrodi metodē _Ready() atskaņotāju sfxPlayer = GetNode<AudioStreamPlayer>("SFX"); un ielādē skaņu (vai piešķir to Inspector laukā Stream).
  5. Izveido metodi public void PlaySfx(), kas izsauc sfxPlayer.Play();, un izsauc to no Scripts/MainMenu.cs pogu nospiešanas metodēs (piemēram, OnSettingsPressed() un OnBackPressed()).
  6. Nospied Build, palaid spēli (F5) un pārbaudi, ka pogu klikšķi atskaņo skaņu.
  7. Nospied pogu ļoti ātri vairākas reizes pēc kārtas un pieraksti failā README.md, kas notiek ar vienu AudioStreamPlayer, kad Play() izsauc atkārtoti pirms iepriekšējās skaņas beigām.
// Fragments no Scripts/AudioManager.cs:
private AudioStreamPlayer sfxPlayer;

public override void _Ready()
{
    sfxPlayer = GetNode<AudioStreamPlayer>("SFX");
    if (sfxPlayer.Stream == null && ResourceLoader.Exists("res://Sounds/click.ogg"))
    {
        sfxPlayer.Stream = ResourceLoader.Load<AudioStream>("res://Sounds/click.ogg");
    }
}

public void PlaySfx()
{
    sfxPlayer?.Play();
}

Gatavs, kad: nospiežot izvēlnes pogas, atskan skaņas efekts, un README.md ir pierakstīts novērojums par ātru atkārtotu atskaņošanu.

Pievieno fona mūziku ar Tween skaļuma pāreju

Kur strādāt: Pievieno mezglam AudioManager (scēnā Scenes/Menu.tscn) otru bērnu Music (AudioStreamPlayer). Papildini Scripts/AudioManager.cs ar metodēm StartMusicFadeIn() un FadeOutMusic().

Beigās fona mūzika spēles sākumā pakāpeniski pieņemsies spēkā no klusuma (-40 dB) līdz normālam skaļumam (0 dB), nevis sāksies ar pēkšņu lēcienu.

  1. Pievieno mezglam AudioManager scēnā Scenes/Menu.tscn bērnu AudioStreamPlayer ar nosaukumu Music un piešķir tam mūzikas failu (piemēram, res://Sounds/music.ogg ar ieslēgtu Loop importa iestatījumos).
  2. Atrodi metodē _Ready() (failā Scripts/AudioManager.cs) mūzikas atskaņotāju: musicPlayer = GetNode<AudioStreamPlayer>("Music");.
  3. Izveido metodi public void StartMusicFadeIn(double duration = 1.5), kurā iestati sākuma skaļumu musicPlayer.VolumeDb = -40.0f;, palaid musicPlayer.Play(); un ar Tween pacel skaļumu līdz 0.0f dB: CreateTween().TweenProperty(musicPlayer, "volume_db", 0.0f, duration);.
  4. Izveido metodi public Tween FadeOutMusic(double duration = 0.6), kas ar TweenProperty(musicPlayer, "volume_db", -40.0f, duration) klusina mūziku pirms scēnas maiņas.
  5. Nospied Build, palaid spēli un ieklausies, kā mūzika 1.5 sekunžu laikā plūdeni ienāk.
  6. Pieraksti failā README.md, kāpēc skaņas dzinējos skaļumu mēra decibelos (dB, kur 0 dB ir pilns skaļums un negatīvas vērtības samazina skaļumu logaritmiski), nevis lineāros procentos.
public void StartMusicFadeIn(double duration = 1.5)
{
    if (musicPlayer == null) return;
    musicPlayer.VolumeDb = -40.0f;
    musicPlayer.Play();
    CreateTween().TweenProperty(musicPlayer, "volume_db", 0.0f, duration);
}

Gatavs, kad: fona mūzika startā pakāpeniski pieņemas spēkā un README.md ir izskaidrots decibelu (dB) mērogam paredzētais pielietojums.

Sakārto skaļumu ar skaņas kopnēm (Audio Bus) un HSlider

Kur strādāt: Godot apakšējā Audio panelī izveido kopnes Music un SFX (saglabā kā default_bus_layout.tres). Scēnā Scenes/Menu.tscn iekš SettingsPanel/SettingsVBox pievieno slīdņus MusicSlider un SfxSlider un savieno tos Scripts/MainMenu.cs.

Beigās spēlētājs iestatījumu logā varēs neatkarīgi regulēt mūzikas un skaņas efektu skaļumu.

  1. Atver Godot redaktora apakšējā joslā cilni Audio un divreiz nospied Add Bus, lai blakus Master izveidotu divas jaunas skaņas kopnes ar precīziem nosaukumiem Music un SFX.
  2. Atver Scenes/Menu.tscn, izvēlies mezglu AudioManager/Music un Inspector laukā Bus izvēlies Music; mezglam AudioManager/SFX laukā Bus izvēlies SFX.
  3. Pārliecinies, ka iekš SettingsPanel/SettingsVBox ir divi HSlider mezgli: MusicSlider un SfxSlider, un abiem Inspector panelī iestati Min Value = -40, Max Value = 0, Step = 0.5 un Value = 0.
  4. Atver Scripts/MainMenu.cs un metodē _Ready() atrodi abus slīdņus un pieslēdz notikumu ValueChanged: musicSlider.ValueChanged += OnMusicVolumeChanged; un sfxSlider.ValueChanged += OnSfxVolumeChanged;.
  5. Izveido palīgmetodi private void SetBusVolume(string busName, double valueDb), kas atrod kopnes indeksu ar int busIndex = AudioServer.GetBusIndex(busName); un uzstāda skaļumu ar AudioServer.SetBusVolumeDb(busIndex, (float)valueDb); un apklusināšanu pie minimuma AudioServer.SetBusMute(busIndex, valueDb <= -39.5);.
  6. Palaid spēli, atver „Iestatījumi", pavelc MusicSlider pa kreisi līdz galam (-40 dB) un nospied pogu „Aizvērt" — pārliecinies, ka mūzika apklust, bet klikšķa skaņas efekts (SFX) joprojām skan pilnā skaļumā.

Gatavs, kad: abi slīdņi (MusicSlider un SfxSlider) neatkarīgi regulē katrs savas kopnes skaļumu un pie -40 dB pilnībā apklusina attiecīgo kopni.

Papildu uzdevums - Saglabā skaļuma iestatījumus failā user://audio_settings.json

Kur strādāt: Papildini Scripts/MainMenu.cs ar metodēm SaveAudioSettings() un LoadAudioSettings(), izmantojot Godot.FileAccess un Godot.Json.

Ja pamatdarbs ir gatavs, saglabā spēlētāja izvēlēto mūzikas un efektu skaļumu starp spēles palaišanas reizēm.

  1. Izveido metodi SaveAudioSettings(double musicDb, double sfxDb), kas Godot.Collections.Dictionary vārdnīcā ieraksta abas vērtības un ar FileAccess.Open("user://audio_settings.json", FileAccess.ModeFlags.Write) saglabā JSON virkni.
  2. Izsauc saglabāšanu, kad spēlētājs maina slīdņa vērtību vai aizver iestatījumu paneli.
  3. Izveido metodi LoadAudioSettings() un izsauc to _Ready() sākumā: ja fails user://audio_settings.json eksistē, nolasi abas vērtības un uzstādi musicSlider.Value un sfxSlider.Value.
  4. Aizver spēli, palaid no jauna un pārbaudi, ka slīdņi un skaļums ir saglabājušies.

Gatavs, kad: pēc spēles aizvēršanas un atkārtotas palaišanas skaļuma slīdņi paliek iepriekš iestatītajā pozīcijā.

Pilnais koda piemērs — gatavs šīs stundas risinājums

1. fails: Scripts/AudioManager.cs (piesaistīts AudioManager mezglam scēnā Scenes/Menu.tscn; ietver arī automātisku WAV skaņas ģeneratoru, ja Sounds/ mapē vēl nav ārēju failu)

using Godot;
using System;

public partial class AudioManager : Node
{
    private AudioStreamPlayer sfxPlayer;
    private AudioStreamPlayer musicPlayer;

    public override void _Ready()
    {
        sfxPlayer = GetNodeOrNull<AudioStreamPlayer>("SFX");
        musicPlayer = GetNodeOrNull<AudioStreamPlayer>("Music");

        if (sfxPlayer != null)
        {
            if (AudioServer.GetBusIndex("SFX") >= 0)
                sfxPlayer.Bus = "SFX";

            if (sfxPlayer.Stream == null)
            {
                sfxPlayer.Stream = ResourceLoader.Exists("res://Sounds/click.ogg")
                    ? ResourceLoader.Load<AudioStream>("res://Sounds/click.ogg")
                    : CreateToneWav(660.0f, 0.09f, false);
            }
        }

        if (musicPlayer != null)
        {
            if (AudioServer.GetBusIndex("Music") >= 0)
                musicPlayer.Bus = "Music";

            if (musicPlayer.Stream == null)
            {
                musicPlayer.Stream = ResourceLoader.Exists("res://Sounds/music.ogg")
                    ? ResourceLoader.Load<AudioStream>("res://Sounds/music.ogg")
                    : CreateToneWav(220.0f, 2.0f, true);
            }

            StartMusicFadeIn(1.5);
        }
    }

    public void PlaySfx(float pitchScale = 1.0f)
    {
        if (sfxPlayer == null) return;
        sfxPlayer.PitchScale = pitchScale;
        sfxPlayer.Play();
    }

    public void StartMusicFadeIn(double duration = 1.5)
    {
        if (musicPlayer == null) return;
        musicPlayer.VolumeDb = -40.0f;
        musicPlayer.Play();
        CreateTween().TweenProperty(musicPlayer, "volume_db", -6.0f, duration);
    }

    public Tween FadeOutMusic(double duration = 0.5)
    {
        if (musicPlayer == null) return null;
        return CreateTween().TweenProperty(musicPlayer, "volume_db", -40.0f, duration);
    }

    // Palīgmetode: uzģenerē tīru 16-bit PCM skaņas vilni, lai projekts skanētu pat bez ārējiem OGG/WAV failiem
    public static AudioStreamWav CreateToneWav(float frequencyHz, float durationSec, bool loop)
    {
        int sampleRate = 22050;
        int sampleCount = Mathf.Max(1, (int)(sampleRate * durationSec));
        byte[] data = new byte[sampleCount * 2];

        for (int i = 0; i < sampleCount; i++)
        {
            float t = (float)i / sampleRate;
            float envelope = loop ? 0.25f : Mathf.Max(0.0f, 1.0f - (float)i / sampleCount);
            float wave = Mathf.Sin(2.0f * Mathf.Pi * frequencyHz * t) * envelope;
            short pcm = (short)Mathf.Clamp(wave * short.MaxValue * 0.5f, short.MinValue, short.MaxValue);
            data[i * 2] = (byte)(pcm & 0xFF);
            data[i * 2 + 1] = (byte)((pcm >> 8) & 0xFF);
        }

        AudioStreamWav wav = new AudioStreamWav
        {
            Format = AudioStreamWav.FormatEnum.Format16Bits,
            MixRate = sampleRate,
            Stereo = false,
            LoopMode = loop ? AudioStreamWav.LoopModeEnum.Forward : AudioStreamWav.LoopModeEnum.Disabled,
            LoopBegin = 0,
            LoopEnd = sampleCount,
            Data = data
        };
        return wav;
    }
}

using Godot;

public partial class MainMenu : Control
{
    private Control settingsPanel;
    private AudioManager audioManager;

    public override void _Ready()
    {
        Control vbox = GetNode<Control>("VBox");
        Button startBtn = GetNode<Button>("VBox/StartButton");
        Button settingsBtn = GetNode<Button>("VBox/SettingsButton");
        Button quitBtn = GetNode<Button>("VBox/QuitButton");

        audioManager = GetNodeOrNull<AudioManager>("AudioManager");

        startBtn.Pressed += OnStartPressed;
        settingsBtn.Pressed += OnSettingsPressed;
        quitBtn.Pressed += OnQuitPressed;

        settingsPanel = GetNodeOrNull<Control>("SettingsPanel");
        if (settingsPanel != null)
        {
            settingsPanel.Visible = false;

            Button backBtn = settingsPanel.GetNodeOrNull<Button>("SettingsVBox/BackButton");
            if (backBtn != null)
                backBtn.Pressed += OnBackPressed;

            HSlider musicSlider = settingsPanel.GetNodeOrNull<HSlider>("SettingsVBox/MusicSlider");
            if (musicSlider != null)
                musicSlider.ValueChanged += OnMusicVolumeChanged;

            HSlider sfxSlider = settingsPanel.GetNodeOrNull<HSlider>("SettingsVBox/SfxSlider");
            if (sfxSlider != null)
                sfxSlider.ValueChanged += OnSfxVolumeChanged;
        }

        Vector2 targetPos = vbox.Position;
        vbox.Position = targetPos + new Vector2(0, -40);
        Modulate = new Color(1, 1, 1, 0);

        Tween introTween = CreateTween();
        introTween.SetParallel(true);
        introTween.TweenProperty(this, "modulate:a", 1.0f, 0.6);
        introTween.TweenProperty(vbox, "position", targetPos, 0.6)
            .SetTrans(Tween.TransitionType.Cubic)
            .SetEase(Tween.EaseType.Out);
    }

    private void OnMusicVolumeChanged(double valueDb)
    {
        SetBusVolume("Music", valueDb);
    }

    private void OnSfxVolumeChanged(double valueDb)
    {
        SetBusVolume("SFX", valueDb);
        audioManager?.PlaySfx();
    }

    private void SetBusVolume(string busName, double valueDb)
    {
        int busIdx = AudioServer.GetBusIndex(busName);
        if (busIdx < 0)
        {
            busIdx = AudioServer.GetBusIndex("Master");
        }
        AudioServer.SetBusVolumeDb(busIdx, (float)valueDb);
        AudioServer.SetBusMute(busIdx, valueDb <= -39.5);
    }

    private void OnStartPressed()
    {
        audioManager?.PlaySfx();
        if (ResourceLoader.Exists("res://Scenes/Puzzle.tscn"))
        {
            GetTree().ChangeSceneToFile("res://Scenes/Puzzle.tscn");
        }
    }

    private void OnSettingsPressed()
    {
        audioManager?.PlaySfx();
        if (settingsPanel != null)
        {
            settingsPanel.Visible = !settingsPanel.Visible;
        }
    }

    private void OnBackPressed()
    {
        audioManager?.PlaySfx(0.85f);
        if (settingsPanel != null)
        {
            settingsPanel.Visible = false;
        }
    }

    private void OnQuitPressed()
    {
        GetTree().Quit();
    }
}

Ko sagatavo

Stundas mērķis: Tavā spēlē skan skaņas efekti un fona mūzika ar plūdenu Tween skaļuma pāreju, un mūziku ar efektiem var regulēt atsevišķi caur Music un SFX skaņas kopnēm.

GitHub krātuvē jābūt:

  • Skriptiem Scripts/AudioManager.cs un Scripts/MainMenu.cs, kā arī skaņas kopņu izkārtojumam default_bus_layout.tres.
  • README.md ievietotai video saitei ar skaņu, kurā dzirdama mūzikas ienākšana, pogu klikšķi un skaļuma maiņa ar slīdņiem.
  • Ekrānuzņēmumam ar Godot Audio cilni, kurā redzamas kopnes Master, Music un SFX.
  • README.md atbildēm: kas notiek, ātri atkārtojot Play() vienam atskaņotājam, kāpēc skaļumu mēra decibelos (dB) un kāpēc mūziku un efektus nodala atsevišķās skaņas kopnēs.

Kā iesniedz: Veic git commit un git push. Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Skaņa neskan: stream (skaņas plūsma) nav ielādēts vai skaņas kopne ir apklusināta.
  • Lag (aizture) mūzika start: OGG fails liels - ielādē to ar ResourceLoader.Load jau līmeņa sākumā.
  • SFX cuts off: Lieto pool (objektu krātuve), lai daudzi vienlaikus.
