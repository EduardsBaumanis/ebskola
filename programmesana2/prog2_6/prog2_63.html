6.3 Audio (skaņa) system (sistēma)

Stundas uzdevums: Pievienot mūziku, sound effect (skaņas efektus) un audio buses (skaņas kopne) spēlei.

SR 2.4.7. UI (lietotāja saskarne) SR 2.4.15. Modular program (modulāras programmas)

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - atskaņo pirmo audio (skaņu) · 2. uzdevums (~25 min) - pievieno background music (fona mūziku) ar pāreju · 3. uzdevums (~20 min) - sakārto skaļumu ar audio bus (skaņas kopne) · Iesniegšana (~5 min).

Pirms sāc: atver savu spēli. Sagatavo divus audio (skaņa) file (failus): vienu īsu efektu un vienu garāku mūziku. Ja tādu nav, lejupielādē bezmaksas audio (skaņas) no freesound.org vai opengameart.org.

Teorija: Godot audio (skaņa)

Godot audio (skaņa) system (sistēma) izmanto AudioStreamPlayer (skaņas atskaņotājs) nodes (mezgli) ar audio bus (skaņas kopne) architecture (arhitektūru).

using Godot;

// Atskaņot SFX
AudioStreamPlayer sfx = GetNode<AudioStreamPlayer>("SFX");
sfx.Stream = ResourceLoader.Load<AudioStream>("res://sounds/jump.ogg");
sfx.Play();

// Mūzika ar fade-in
private void PlayMusicFadeIn(string path)
{
    musicPlayer.Stream = ResourceLoader.Load<AudioStream>(path);
    musicPlayer.VolumeDb = -30;
    musicPlayer.Play();
    CreateTween().TweenProperty(musicPlayer, "volume_db", -10.0, 2.0);  // fade up
}

Audio buses (skaņas kopne): Master (galvenais skaņas kanāls) → Music (mūzika), SFX (skaņas efekts), Voice (balss). Lietotājs var pielāgot katru atsevišķi.

Kā šo izmantot project (projektā)

Atceries: ar redzamu efektu editor (redaktorā) nepietiek. Paskaidro, kura C# class (klase) glabā state (stāvokli), kura method (metode) to maina un kā Godot node (mezgls) structure (struktūra) izmanto šo code (kodu).

Praktiskie uzdevumi

1. uzdevums -

Atskaņo pirmo audio (skaņu)

Beigās spēle noskanēs, kad kaut kas notiek.

  1. Ievelc audio (skaņa) file (failu) project (projekta) folder (mapē), piemēram res://sounds/jump.ogg.
  2. Pievieno scene (scēnai) AudioStreamPlayer (skaņas atskaņotājs) node (mezglu) ar nosaukumu SFX (skaņas efekti).
  3. Pārliecinies, ka file (faila) sākumā ir using Godot;.
  4. Paņem node (mezglu) ar AudioStreamPlayer sfx = GetNode<AudioStreamPlayer>("SFX");.
  5. Izsauc sfx.Play(); lēciena vai savākšanas brīdī.
  6. Būvē un pārbaudi audio (skaņu).
  7. Izsauc event (notikumu) ļoti ātri vairākas reizes un pieraksti, kas notiek ar audio (skaņu).

Gatavs, kad: event (notikuma) brīdī atskan audio (skaņa), un tu esi pierakstījis, kas notiek, atkārtojot to ļoti ātri.

2. uzdevums -

Pievieno background music (fona mūziku) ar pāreju

Beigās mūzika sāksies mīksti, nevis uzreiz pilnā skaļumā.

  1. Pievieno otru AudioStreamPlayer (skaņas atskaņotājs) ar nosaukumu Music (mūzika).
  2. Iestati tā audio (skaņa) file (failu) un ieslēdz atkārtošanos import (importa) settings (iestatījumos).
  3. Iestati sākumā skaļumu uz music.VolumeDb = -40;.
  4. Izveido Tween (pakāpeniska vērtību maiņa), kas vienā sekundē paceļ skaļumu līdz 0 dB.
  5. Palaid un ieklausies, vai mūzika ienāk pakāpeniski.
  6. Pievieno arī izejošu pāreju, kad spēle beidzas.
  7. Pieraksti, kāpēc skaļumu mēra decibelos, nevis procentos.

Gatavs, kad: mūzika ienāk pakāpeniski, atkārtojas bez pauzes un beigās izgaist.

3. uzdevums -

Sakārto skaļumu ar audio bus (skaņas kopne)

Beigās spēlētājs varēs atsevišķi regulēt mūziku un efektus.

  1. Atver apakšā tab (cilni) Audio (skaņa).
  2. Izveido divus jaunus bus (skaņas kopne): Music (mūzika) un SFX (skaņas efekti).
  3. Piesaisti katru atskaņotāju savam bus (skaņas kopne) Inspector (īpašību panelis) panel (panelī).
  4. Pievieno settings (iestatījumu) logam divus HSlider (horizontāls slīdnis) mezglus.
  5. Savieno tos ar AudioServer.SetBusVolumeDb(AudioServer.GetBusIndex("Music"), valueDb);.
  6. Pārbaudi, ka mūzikas slider (slīdnis) nemaina efektu skaļumu.
  7. Iestati mūziku uz nulli un pārbaudi, ka efekti joprojām skan.

Gatavs, kad: abi slider (slīdņi) darbojas neatkarīgi: izslēdzot mūziku, sound effect (skaņas efekti) joprojām atskan.

Papildu uzdevums - Saglabā skaļuma settings (iestatījumus)

Ja pamatdarbs ir gatavs, atceries spēlētāja izvēli.

  1. Saglabā abu bus (skaņas kopne) skaļumu JSON (JavaScript objektu pieraksts) file (failā) ar 5.3 stundas SaveManager.
  2. Ielādē tos spēles startā.
  3. Iestati slīdņu position (pozīcijas) pēc ielādētajām value (vērtībām).
  4. Aizver spēli un palaid no jauna.
  5. Pārbaudi, ka skaļums palicis tāds, kādu to atstāji.

Gatavs, kad: pēc spēles restart (restarta) skaļuma slider (slīdņi) ir tajā pašā vietā, kur tu tos atstāji.

Ko sagatavo

Stundas mērķis: Tavā spēlē skan sound effect (skaņas efekti) un background music (fona mūzika) ar mīkstām pārejām, un mūziku ar efektiem var regulēt atsevišķi caur diviem audio bus (skaņas kopne).

GitHub repository (krātuvē) jābūt:

  1. README.md ievietota video link (saite) ar audio (skaņu), kurā dzirdama mūzikas ienākšana un vismaz viens sound effect (skaņas efekts).
  2. Screenshot (ekrānuzņēmums) ar Audio (skaņa) tab (cilni), kurā redzami tavi divi bus (skaņas kopne).
  3. C# file (fails) ar audio (skaņa) code (kodu).
  4. README.md: kāpēc skaļumu mēra decibelos un kāpēc mūziku un efektus tur atsevišķos bus (skaņas kopne).

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub repository (krātuves) link (saiti); visiem prasītajiem file (failiem), README.md pierakstiem un pierādījumiem jābūt pašā repository (krātuvē).

Biežākās kļūdas

  • Audio (skaņa) nestrādā: stream (skaņas plūsma) nav ielādēts vai bus (skaņas kopne) mute.
  • Lag (aizture) music (mūzika) start: OGG (skaņas failu formāts) file (fails) liels - ielādē to ar ResourceLoader.Load jau līmeņa sākumā.
  • SFX (skaņas efekts) cuts off: Lieto pool (objektu krātuve), lai daudzi vienlaikus.

Code sample (koda piemērs) (paplašināts)

using Godot;
using System.Collections.Generic;

public partial class AudioManager : Node
{
    private readonly List<AudioStreamPlayer> sfxPool = new();
    private AudioStreamPlayer musicPlayer;
    private const int PoolSize = 8;

    public override void _Ready()
    {
        for (int i = 0; i < PoolSize; i++)
        {
            AudioStreamPlayer player = new AudioStreamPlayer();
            player.Bus = "SFX";
            AddChild(player);
            sfxPool.Add(player);
        }

        musicPlayer = new AudioStreamPlayer();
        musicPlayer.Bus = "Music";
        AddChild(musicPlayer);
    }

    public void PlaySfx(string path)
    {
        foreach (AudioStreamPlayer player in sfxPool)
        {
            if (!player.Playing)
            {
                player.Stream = ResourceLoader.Load<AudioStream>(path);
                player.Play();
                return;
            }
        }
    }

    public void PlayMusic(string path)
    {
        musicPlayer.Stream = ResourceLoader.Load<AudioStream>(path);
        musicPlayer.Play();
    }
}
