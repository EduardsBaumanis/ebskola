Stundas uzdevums: Pievienot mūziku, skaņas efektus un skaņas kopnes spēlei.

SR 2.4.7. UI (lietotāja saskarne) SR 2.4.15. Modulāras programmas

Teorija: skaņas atskaņošana, decibelu skala un skaņas kopnes (Audio Buses)

Skaņas plūsmas (AudioStreamPlayer) un skaļums decibelos (dB)

Audio failu atskaņošanai Godot izmanto mezglu AudioStreamPlayer (vienmērīgai skaņai neatkarīgi no vietas ekrānā) vai AudioStreamPlayer2D (pozicionālai skaņai, kas kļūst klusāka attālinoties). Īpašībai Stream piešķir ielādētu skaņas resursu (piemēram, .ogg vai .wav failu) un atskaņošanu sāk ar metodi Play(); ja uz viena un tā paša mezgla Play() izsauc atkārtoti, pirms iepriekšējais ieraksts beidzies, skaņa tiek pārtraukta un sākta no sākuma.

Cilvēka dzirde skaņas intensitātes izmaiņas uztver logaritmiski, nevis lineāri, tāpēc skaļumu programmēšanā regulē decibelos (VolumeDb): 0 dB atbilst oriģinālajam ieraksta līmenim bez pastiprinājuma, savukārt negatīvas vērtības (piemēram, -10 dB vai -40 dB) skaņu pakāpeniski klusina, ko var vienmērīgi animēt ar Tween:

using Godot;

private void AtskanotArPareju(AudioStreamPlayer atskanotajs, string cels)
{
    atskanotajs.Stream = ResourceLoader.Load<AudioStream>(cels);
    atskanotajs.VolumeDb = -40.0f;
    atskanotajs.Play();
    CreateTween().TweenProperty(atskanotajs, "volume_db", 0.0f, 1.5);
}

Skaņas kopņu arhitektūra (Audio Buses) un AudioServer

Ja lietotnē skan gan fona celiņš, gan īsi saskarnes paziņojumi, katra atskaņotāja individuāla regulēšana būtu neērta. Tāpēc Godot izmanto skaņas kopņu (Audio Bus) sistēmu — tā darbojas gluži kā koncertzāles skaņu pults, kur katrs mikrofons vai instruments vispirms ieplūst savā grupas kanālā (piemēram, Music, SFX, Voice), un visi grupu kanāli tālāk apvienojas galvenajā izejā Master.

Piesaistot katram AudioStreamPlayer atbilstošo kopni, C# kodā ar AudioServer var neatkarīgi mainīt visas grupas skaļumu vienuviet (piemēram, ar AudioServer.SetBusVolumeDb(AudioServer.GetBusIndex("Music"), vertibaDb)), pilnībā apklusinot fona pavadījumu, kamēr īsie skaņas signāli citā kopnē turpina skanēt netraucēti:

// Mezglus piesaista atbilstošajām kopnēm (var iestatīt arī Inspector panelī):
fonaAtskanotajs.Bus = "Music";
signaluAtskanotajs.Bus = "SFX";

// Maina visas kopnes skaļumu vienuviet (piemēram, no HSlider.ValueChanged):
private void IestatitKopnesSkalumu(string kopnesNosaukums, double vertibaDb)
{
    int indekss = AudioServer.GetBusIndex(kopnesNosaukums);
    AudioServer.SetBusVolumeDb(indekss, (float)vertibaDb);
    AudioServer.SetBusMute(indekss, vertibaDb <= -40.0);
}

1. uzdevums

Atskaņo pirmo skaņu

Kur strādāt: Skaņu glabā sounds/jump.ogg. SFX mezglu pievieno Scenes/Player.tscn zem saknes, kurai piesaistīts Scripts/Player.cs; skriptā atsauci iegūsti _Ready(), bet Play izsauc lēciena vai savākšanas metodē.

Beigās spēle noskanēs, kad kaut kas notiek.

  1. Ievelc skaņas failu projekta mapē, piemēram res://sounds/jump.ogg.
  2. Pievieno scēnai AudioStreamPlayer node ar nosaukumu SFX.
  3. Pārliecinies, ka faila sākumā ir using Godot;.
  4. Paņem node ar AudioStreamPlayer sfx = GetNode<AudioStreamPlayer>("SFX");.
  5. Izsauc sfx.Play(); lēciena vai savākšanas brīdī.
  6. Būvē un pārbaudi skaņu.
  7. Izsauc event (notikumu) ļoti ātri vairākas reizes un pieraksti, kas notiek ar skaņu.
AudioStreamPlayer sfx = GetNode<AudioStreamPlayer>("SFX");
sfx.Stream = ResourceLoader.Load<AudioStream>("res://sounds/jump.ogg");
sfx.Play();

Gatavs, kad: event brīdī atskan skaņa, un tu esi pierakstījis, kas notiek, atkārtojot to ļoti ātri.

2. uzdevums

Pievieno fona mūziku ar pāreju

Kur strādāt: Spēles scēnā izveido Node mezglu ar bērnu Music un piesaisti vecākam Scripts/AudioManager.cs. Tajā raksti _Ready() un mūzikas pāreju metodes; beigu pāreju izsauc no esošā spēles beigu apstrādātāja.

Beigās mūzika sāksies mīksti, nevis uzreiz pilnā skaļumā.

  1. Pievieno otru AudioStreamPlayer ar nosaukumu Music.
  2. Iestati tā skaņas failu un ieslēdz atkārtošanos importa iestatījumos.
  3. Iestati sākumā skaļumu uz music.VolumeDb = -40;.
  4. Izveido Tween (pakāpeniska vērtību maiņa), kas vienā sekundē paceļ skaļumu līdz 0 dB.
  5. Palaid un ieklausies, vai mūzika ienāk pakāpeniski.
  6. Pievieno arī izejošu pāreju, kad spēle beidzas.
  7. Pieraksti, kāpēc skaļumu mēra decibelos, nevis procentos.
music.VolumeDb = -40.0f;
music.Play();
CreateTween().TweenProperty(music, "volume_db", 0.0f, 1.0);

Gatavs, kad: mūzika ienāk pakāpeniski, atkārtojas bez pauzes un beigās izgaist.

3. uzdevums

Sakārto skaļumu ar skaņas kopnēm

Kur strādāt: Kopnes saglabā Godot Audio panelī kā default_bus_layout.tres; slīdņus pievieno Scenes/Menu.tscn Settings panelim. To signālus un skaļuma maiņas apstrādātājus raksti Scripts/MainMenu.cs.

Beigās spēlētājs varēs atsevišķi regulēt mūziku un efektus.

  1. Atver apakšā cilni Audio.
  2. Izveido divus jaunus skaņas kopne: Music un SFX.
  3. Piesaisti katru atskaņotāju savai skaņas kopnei Inspector panelī.
  4. Pievieno iestatījumu logam divus HSlider (horizontāls slīdnis) mezglus.
  5. Savieno tos ar AudioServer.SetBusVolumeDb(AudioServer.GetBusIndex("Music"), valueDb);.
  6. Pārbaudi, ka mūzikas slīdnis nemaina efektu skaļumu.
  7. Iestati mūziku uz nulli un pārbaudi, ka efekti joprojām skan.

Gatavs, kad: abi slīdņi darbojas neatkarīgi: izslēdzot mūziku, skaņas efekti joprojām atskan.

Papildu uzdevums - Saglabā skaļuma iestatījumus

Kur strādāt: Skaļumu saglabāšanu un ielādi pievieno Scripts/SaveManager.cs. Slīdņu vērtību atjaunošanu raksti Scripts/MainMenu.cs, bet ielādēto kopņu skaļumu lietošanu — Scripts/AudioManager.cs.

Ja pamatdarbs ir gatavs, atceries spēlētāja izvēli.

  1. Saglabā abu skaņas kopņu skaļumu JSON (JavaScript objektu pieraksts) failā ar 5.3 stundas SaveManager.
  2. Ielādē tos spēles startā.
  3. Iestati slīdņu pozīcijas pēc ielādētajām vērtībām.
  4. Aizver spēli un palaid no jauna.
  5. Pārbaudi, ka skaļums palicis tāds, kādu to atstāji.

Gatavs, kad: pēc spēles restarta skaļuma slīdņi ir tajā pašā vietā, kur tu tos atstāji.

Paplašināts koda piemērs 
using Godot;
using System.Collections.Generic;

public partial class AudioManager : Node
{
    private readonly List<AudioStreamPlayer> sfxPool = new();
    private AudioStreamPlayer musicPlayer;
    private const int PoolSize = 8;

    public override void _Ready()
    {
        for (int i = 0; i < PoolSize; i++)
        {
            AudioStreamPlayer player = new AudioStreamPlayer();
            player.Bus = "SFX";
            AddChild(player);
            sfxPool.Add(player);
        }

        musicPlayer = new AudioStreamPlayer();
        musicPlayer.Bus = "Music";
        AddChild(musicPlayer);
    }

    public void PlaySfx(string path)
    {
        foreach (AudioStreamPlayer player in sfxPool)
        {
            if (!player.Playing)
            {
                player.Stream = ResourceLoader.Load<AudioStream>(path);
                player.Play();
                return;
            }
        }
    }

    public void PlayMusic(string path)
    {
        musicPlayer.Stream = ResourceLoader.Load<AudioStream>(path);
        musicPlayer.Play();
    }
}
Spēlē fonā mūzika, klikšķis pogai dod 'click.ogg', lec dod 'jump.ogg', skaņas pārklājas bez problēmām.

Ko sagatavo

Stundas mērķis: Tavā spēlē skan skaņas efekti un fona mūzika ar mīkstām pārejām, un mūziku ar efektiem var regulēt atsevišķi caur diviem skaņas kopne.

GitHub krātuvē jābūt:

  • README.md ievietota video saite ar skaņu, kurā dzirdama mūzikas ienākšana un vismaz viens skaņas efekts.
  • Ekrānuzņēmums ar Skaņa cilni, kurā redzami tavi divi skaņas kopne.
  • C# fails ar skaņas kodu.
  • README.md: kāpēc skaļumu mēra decibelos un kāpēc mūziku un efektus tur atsevišķās skaņas kopnēs.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Skaņa neskan: stream (skaņas plūsma) nav ielādēts vai skaņas kopne ir apklusināta.
  • Lag (aizture) mūzika start: OGG fails liels - ielādē to ar ResourceLoader.Load jau līmeņa sākumā.
  • SFX cuts off: Lieto pool (objektu krātuve), lai daudzi vienlaikus.
