6.6 Noslēguma project (projekts): Puzzle game (atjautības spēle)

Stundas uzdevums: Izveidot un publicēt pilnvērtīgu puzzle game (atjautības spēli) ar visu apgūto.

SR 2.4.1. Problem decomposition (problēmu dekompozīcija) SR 2.4.7. UI (lietotāja saskarne) SR 2.4.6. Plāno SR 3.1.4. Licences SR 2.4.3. Prototipu izstrāde un testing (testēšana) SR 2.4.8. Code (koda) dokumentēšana un noformēšana SR 2.4.11. Standartizētas library (bibliotēkas) un API (lietojumprogrammas saskarne)

80 min plāns: Ievads un kritēriju pārruna (~10 min) · 1. uzdevums (~20 min) - izvēlies puzli un uztaisi laukumu · 2. uzdevums (~25 min) - uzraksti uzvaras noteikumu un līmeņus · 3. uzdevums (~20 min) - pievieno menu (izvēlni), audio (skaņu) un eksportē · Iesniegšana (~5 min).

Pirms sāc: šis ir visa kursa noslēguma project (projekts). Izvēlies VIENU puzles veidu un uztaisi to pilnībā - labāk viena pabeigta spēle nekā trīs iesāktas. Izmanto visu, ko esi apguvis.

Teorija: Spēles apraksts

Puzzle game (atjautības spēle): spēlētājs risina sēriju problēmu, kā Sokoban, Tetris vai krāsu match-3.

Izvēlies vienu no opcijām (vai izveido savu):

  1. Sokoban - bīdi kastes uz mērķa vietām.
  2. Match-3 - savieno 3+ vienādas krāsas.
  3. Tetris klons - krītošie bloki.
  4. Sliding puzzle (atjautības uzdevums) - 4×4 attēla mozaīka.

Prasības:

  • Sākuma menu (izvēlne), settings (iestatījumi), augstākie rezultāti.
  • Vismaz 10 līmeņi (Sokoban) vai endless mode (režīms) (Match-3, Tetris).
  • Audio (skaņa): mūzika + 5+ SFX (skaņas efekts).
  • Animation (animācijas)/Tween (pakāpeniska vērtību maiņa) efekti.
  • Save (saglabāt) system (sistēma) (highscore (rekords) + progress).
  • Eksportēta kā desktop (darbvirsma) build (būvējums) un publicēta lejupielādējamā itch.io lapā.

Kā šo izmantot project (projektā)

Atceries: ar redzamu efektu editor (redaktorā) nepietiek. Paskaidro, kura C# class (klase) glabā state (stāvokli), kura method (metode) to maina un kā Godot node (mezgls) structure (struktūra) izmanto šo code (kodu).

Pārbaudi: UI (lietotāja saskarne) signal (signāli), audio (skaņa) darbības, debug (atkļūdošana) output (izvade) un publishing (publicēšanas) template (sagatave) ir sasaistīta ar C# game state (spēles stāvokli).

Praktiskie uzdevumi

1. uzdevums -

Izvēlies puzli un uztaisi laukumu

Beigās tev būs spēles laukums, ko var apskatīt un ar ko darboties.

  1. Izvēlies vienu variantu: Sokoban, Match-3, Tetris klons vai 4x4 mozaīka.
  2. Izveido README.md file (failā) īsu laukuma plānu: kā izskatīsies laukums un kas ir uzvara.
  3. Izveido grid (režģi) ar int[,] grid = new int[Width, Height];.
  4. Attēlo grid (režģi) uz screen (ekrāna) ar TileMap (flīžu karte) vai ColorRect node (mezgliem).
  5. Pievieno vadību, kas maina grid (režģa) saturu.
  6. Palaid un pārbaudi, ka screen (ekrāns) atbilst grid (režģa) saturam.
  7. Pārliecinies, ka nevar izdarīt neatļautu gājienu.

Gatavs, kad: screen (ekrānā) redzamais laukums vienmēr atbilst grid (režģa) data (datiem), un neatļauts gājiens netiek pieņemts.

2. uzdevums -

Uzraksti uzvaras noteikumu un līmeņus

Beigās spēli varēs pabeigt un pāriet uz nākamo līmeni.

  1. Uzraksti method (metodi) private bool IsSolved(), kas pārbauda uzvaras condition (nosacījumu).
  2. Izsauc to pēc katra gājiena.
  3. Parādi uzvaras paziņojumu, kad tas atgriež true (patiess).
  4. Izveido vismaz trīs līmeņus - vai nu file (failā), vai code (kodā).
  5. Ielādē nākamo līmeni pēc uzvaras.
  6. Pievieno gājienu skaitītāju un button (pogu) Sākt no jauna.
  7. Izej visus trīs līmeņus pēc kārtas.

Gatavs, kad: visus trīs līmeņus var atrisināt, uzvara tiek atpazīta pareizi, un restart (restarta) button (poga) strādā.

3. uzdevums -

Pievieno menu (izvēlni), audio (skaņu) un eksportē

Beigās tava spēle būs pabeigts, izdodams produkts.

  1. Pievieno main menu (sākuma izvēlni) no 6.1 stundas.
  2. Pievieno sound effect (skaņas efektu) gājienam un uzvarai no 6.3 stundas.
  3. Pievieno animation (animāciju) uzvaras brīdim no 6.2 stundas.
  4. Saglabā labāko rezultātu ar 5.3 stundas SaveManager.
  5. Eksportē spēli kā desktop (darbvirsma) build (būvējums) pēc 6.5 stundas soļiem.
  6. Publicē ZIP (saspiests arhīvs) archive (arhīvu) itch.io lapā un pārbaudi download (lejupielādi) citā computer (datorā).
  7. Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi) ar visu project (projektu).

Gatavs, kad: spēle sākas ar menu (izvēlni), skan audio (skaņas), labākais rezultāts saglabājas, un publiskā download (lejupielādes) link (saite) strādā.

Papildu uzdevums - Pievieno padoma button (pogu)

Ja pamatdarbs ir gatavs, palīdzi spēlētājam, kurš iestrēdzis.

  1. Uzraksti method (metodi), kas atrod vienu derīgu nākamo gājienu.
  2. Pievieno button (pogu) Padoms, kas to izceļ uz screen (ekrāna).
  3. Ierobežo padomu skaitu vienā līmenī.
  4. Parādi, cik padomu vēl atlicis.
  5. Pārbaudi, ka pēc padomu beigām button (poga) vairs nedarbojas.

Gatavs, kad: padoma button (poga) izceļ derīgu gājienu un pēc noteikta reižu skaita pārstāj darboties.

using Godot;
using System;
using System.Collections.Generic;

// Match-3 spēles core
public partial class Match3Board : Node2D
{
    private const int Width = 8;
    private const int Height = 8;
    private readonly int[,] grid = new int[Width, Height];
    private readonly Random rng = new();

    public void Initialize()
    {
        for (int x = 0; x < Width; x++)
            for (int y = 0; y < Height; y++)
                grid[x, y] = rng.Next(0, 5);  // 5 colors
    }

    public List<Vector2I> FindMatches()
    {
        List<Vector2I> matches = new();
        for (int x = 0; x < Width; x++)
        {
            for (int y = 0; y < Height - 2; y++)
            {
                if (grid[x, y] == grid[x, y + 1] && grid[x, y + 1] == grid[x, y + 2])
                {
                    matches.Add(new Vector2I(x, y));
                    matches.Add(new Vector2I(x, y + 1));
                    matches.Add(new Vector2I(x, y + 2));
                }
            }
        }
        // similarly for horizontal
        return matches;
    }

    public void ClearAndDrop(List<Vector2I> matches)
    {
        // mark cleared, gravity, refill
    }
}
