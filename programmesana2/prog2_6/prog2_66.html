Teorija: datu modeļa un saskarnes nošķiršana pabeigtā lietotnē

Loģiskā datu modeļa un vizuālā attēlojuma atdalīšana

Interaktīvās režģa lietotnēs patieso sistēmas stāvokli neglabā ekrāna attēlu koordinātās, bet atsevišķā C# datu modelī (piemēram, int[,] rezgis). Tas darbojas gluži kā elektroniskā izklājlapa (Excel): ekrānā redzamā diagramma ir tikai tabulas skaitļu vizuāls atspoguļojums — lai mainītu rezultātu, pārbauda un izmaina skaitli šūnā, un attēlojums pārzīmējas pēc tā.

Katra lietotāja darbība iziet vienotu pārbaudes un atjaunošanas ciklu: ievades uztveršana → darbības atļautības pārbaude robežās → masīva datu maiņa → mērķa kritērija pārbaude → vizuālo mezglu, pāreju un skaņas atjaunošana:

private int[,] rezgis = new int[4, 4];
private int[,] merkaParaugs = new int[4, 4];

public bool MainitSunu(int x, int y, int jaunaVertiba)
{
    // 1. Pārbauda, vai koordinātas ir masīva robežās:
    if (x < 0 || x >= rezgis.GetLength(0) || y < 0 || y >= rezgis.GetLength(1))
        return false;

    // 2. Atjauno loģisko datu modeli un pārzīmē saskarni:
    rezgis[x, y] = jaunaVertiba;
    AtjaunotSkatu(x, y);

    // 3. Pārbauda, vai sasniegts meklētais gala stāvoklis:
    if (VaiMekletaisStavoklisSasniegts(rezgis, merkaParaugs))
        PazinotParPabeigsanu();

    return true;
}

private bool VaiMekletaisStavoklisSasniegts(int[,] dati, int[,] paraugs)
{
    for (int x = 0; x < dati.GetLength(0); x++)
        for (int y = 0; y < dati.GetLength(1); y++)
            if (dati[x, y] != paraugs[x, y]) return false;

    return true; // Visas šūnas sakrīt ar mērķa stāvokli.
}

Programmatūras izstrādes cikls: no prototipa līdz dokumentētam laidienam

Apjomīgāka projekta izstrādi plāno ar problēmas dekompozīciju un iteratīvu prototipēšanu, sadalot darbu trīs secīgos slāņos:

  • Minimālais kodola prototips: vispirms vienā datu struktūrā pilnībā izstrādā un notestē galveno loģiku un robežnosacījumus nelielam datu apjomam, nevis paralēli iesāk vairākas nepabeigtas funkcijas.
  • Saskarnes un atgriezeniskās saites slānis: pārbaudītajam kodolam caur skaidrām metodēm un signāliem piesaista Control navigācijas skatus, Tween pārejas, AudioServer skaņas kopnes un user:// rezultātu saglabāšanu.
  • Kvalitātes pārbaude un dokumentēšana: pirms nodošanas pārbauda kompilēto darbvirsmas būvējumu ārpus izstrādes vides, apraksta uzbūvi un vadību README.md dokumentācijā un norāda izmantoto ārējo resursu licences.

Izveido atjautības spēles laukumu un gājienu loģiku

Kur strādāt: Īsu spēles plānu ieraksti README.md. Atver 6.1. stundā izveidoto scēnu Scenes/Puzzle.tscn, pievieno tai laukuma konteineru BoardGrid (GridContainer) un vadības pogas, bet saknei Puzzle piesaisti jaunu skriptu Scripts/PuzzleBoard.cs.

Beigās tev būs interaktīvs 4×4 režģa puzles laukums, kurā 2D masīva int[,] grid stāvoklis vienmēr precīzi atbilst ekrānā redzamajiem lauciņiem un neatļauti gājieni tiek noraidīti.

Ieteicamais pamata variants ar pilnu parauga kodu zemāk ir 4×4 bīdāmā skaitļu mozaīka (Sliding Puzzle, kur tukšais lauciņš ir 0), bet vari izvēlēties arī Sokoban, Match-3 vai Lights-Out.
  2. Atver scēnu Scenes/Puzzle.tscn un izveido augstāk redzamo UI mezglu struktūru ar GridContainer mezglu MainVBox/BoardGrid (Inspector iestati Columns = 4).
  3. Izveido skriptu res://Scripts/PuzzleBoard.cs (public partial class PuzzleBoard : Control) un piesaisti to Scenes/Puzzle.tscn saknei Puzzle.
  4. Definē klases lauku private readonly int[,] grid = new int[4, 4]; un metodi RenderBoard(), kas pēc grid[x, y] vērtībām atjauno 16 lauciņu pogu tekstus un krāsas iekš BoardGrid.
  5. Uzraksti gājiena metodi private void OnTilePressed(int x, int y), kas pārbauda, vai nospiestais lauciņš ir tiešs kaimiņš (pa kreisi, pa labi, augšā vai apakšā) tukšajam lauciņam (0) ar Manhetenas attālumu Math.Abs(x - emptyX) + Math.Abs(y - emptyY) == 1.
  6. Ja gājiens ir atļauts, apmaini grid[x, y] un grid[emptyX, emptyY] vērtības vietām, palielini moves++, izsauc RenderBoard() un ar Tween animē pārvietoto lauciņu; ja gājiens nav atļauts, noraidi to (nemainot moves).
  7. Nospied Build, palaid spēli un pārbaudi, ka pārbīdīt var tikai tukšajam lauciņam blakus esošos kauliņus.

Atjautības spēles žanru varianti izvēlei: (1) 4×4 bīdāmā mozaīka (Sliding Puzzle) - sakārto skaitļus 1..15; (2) Sokoban - bīdi kastes uz mērķa vietām; (3) Match-3 - savieno 3+ vienādas krāsas figūras; (4) Lights-Out / Takuzu - loģiskā režģa aizpildīšana.

Gatavs, kad: ekrānā redzamais laukums vienmēr atbilst grid[,] masīva datiem, derīgi gājieni darbojas ar Tween animāciju, un neatļauts gājiens netiek pieņemts.

2. uzdevums

Pievieno uzvaras pārbaudi IsSolved(), 3 līmeņus un restartu

Kur strādāt: Papildini Scripts/PuzzleBoard.cs ar metodēm IsSolved(), LoadLevel(int level) un OnRestartPressed(). Pogu RestartButton un uzrakstus StatusLabel / MessageLabel izmanto no Scenes/Puzzle.tscn.

Beigās spēlē būs vismaz trīs secīgi līmeņi ar pieaugošu grūtību, automātiska uzvaras noteikšana pēc katra gājiena un iespēja jebkurā brīdī sākt līmeni no jauna.

  1. Uzraksti failā Scripts/PuzzleBoard.cs metodi private bool IsSolved(), kas pārbauda visas grid[x, y] šūnas un atgriež true tikai tad, kad visi lauciņi atrodas mērķa secībā (1..15 un pēdējā šūna 0).
  2. Izveido metodi private void LoadLevel(int levelIndex), kas ielādē vismaz 3 dažādas, garantēti atrisināmas sākuma konfigurācijas (piemēram, 1. līmenī 4 sajaukšanas soļi no atrisināta stāvokļa, 2. līmenī — 8 soļi, 3. līmenī — 14 soļi) un nomet moves = 0.
  3. Izsauc IsSolved() pēc katra derīga gājiena: ja tā atgriež true, parādi uzvaras paziņojumu MessageLabel uzrakstā, atskaņo uzvaras Tween animāciju un pārej uz nākamo līmeni (currentLevel++).
  4. Atjauno pēc katra gājiena StatusLabel.Text ar pašreizējo līmeni un veikto gājienu skaitu (moves).
  5. Savieno pogu RestartButton (MainVBox/ButtonsHBox/RestartButton) ar metodi OnRestartPressed(), kas izsauc LoadLevel(currentLevel).
  6. Izspēlē visus trīs līmeņus pēc kārtas un pārliecinies, ka katrs līmenis ir atrisināms un pēc 3. līmeņa parādās pilnas uzvaras apsveikums.

Gatavs, kad: visus trīs līmeņus var iziet pēc kārtas, IsSolved() precīzi atpazīst uzvaru un poga „Sākt no jauna" atjauno pašreizējo līmeni.

    private void BuildGridButtons()
    {
        foreach (Node child in boardGrid.GetChildren())
        {
            child.QueueFree();
        }

        for (int y = 0; y < BoardSize; y++)
        {
            for (int x = 0; x < BoardSize; x++)
            {
                int capturedX = x;
                int capturedY = y;

                {
                    CustomMinimumSize = new Vector2(76, 76),

    private void LoadLevel(int level)
    {
        levelTransitioning = false;
        moves = 0;

        // Sākam ar pilnīgi sakārtotu laukumu (1..15 un 0 beigās)
        int value = 1;
        for (int y = 0; y < BoardSize; y++)
        {
            for (int x = 0; x < BoardSize; x++)
            {
                grid[x, y] = (x == BoardSize - 1 && y == BoardSize - 1) ? 0 : value++;
            }
        }

        // Veicam noteiktu skaitu garantēti atrisināmu sajaukšanas gājienu katram līmenim
        Vector2I[] levelShuffles = GetLevelShufflePath(level);
        Vector2I empty = new Vector2I(BoardSize - 1, BoardSize - 1);
        foreach (Vector2I step in levelShuffles)
        {
            Vector2I next = empty + step;
            if (next.X >= 0 && next.X < BoardSize && next.Y >= 0 && next.Y < BoardSize)
            {
                grid[empty.X, empty.Y] = grid[next.X, next.Y];
                grid[next.X, next.Y] = 0;
                empty = next;
            }
        }

        messageLabel.Text = $"Sakārto skaitļus 1..15 pēc kārtas! ({level}. līmenis no {MaxLevel})";
        RenderBoard();
        UpdateStatusText();
    }

    private Vector2I[] GetLevelShufflePath(int level)
    {
        if (level == 1)
        {
            // 1. līmenis: atrisināms 4 gājienos
            return new[]
            {
                new Vector2I(0, -1), new Vector2I(-1, 0),
                new Vector2I(0, 1), new Vector2I(1, 0)
            };
        }
        if (level == 2)
        {
            // 2. līmenis: atrisināms 8 gājienos
            return new[]
            {
                new Vector2I(0, -1), new Vector2I(-1, 0), new Vector2I(-1, 0),
                new Vector2I(0, -1), new Vector2I(1, 0), new Vector2I(0, 1),
                new Vector2I(1, 0), new Vector2I(0, 1)
            };
        }
        // 3. līmenis: atrisināms 12 gājienos
        return new[]
        {
            new Vector2I(0, -1), new Vector2I(0, -1), new Vector2I(-1, 0),
            new Vector2I(-1, 0), new Vector2I(0, 1), new Vector2I(1, 0),
            new Vector2I(0, -1), new Vector2I(-1, 0), new Vector2I(0, 1),
            new Vector2I(0, 1), new Vector2I(1, 0), new Vector2I(1, 0)
        };
    }

    private void OnTilePressed(int x, int y)
    {
        if (levelTransitioning) return;

        Vector2I empty = FindEmptyCell();
        int manhattan = Math.Abs(x - empty.X) + Math.Abs(y - empty.Y);

        if (manhattan != 1)
        {
            // Neatļauts gājiens: īss brīdinājuma tonis
            audioManager?.PlaySfx(0.6f);
            return;
        }

        // Apmainām nospiesto lauciņu ar tukšo šūnu 2D masīvā
        grid[empty.X, empty.Y] = grid[x, y];
        grid[x, y] = 0;
        moves++;

        audioManager?.PlaySfx(1.0f);
        RenderBoard();
        UpdateStatusText();

        // Tween animācija pārvietotajam lauciņam
        Button movedBtn = tileButtons[empty.X, empty.Y];
        movedBtn.Scale = new Vector2(0.82f, 0.82f);
        movedBtn.CreateTween()
            .TweenProperty(movedBtn, "scale", Vector2.One, 0.14)
            .SetTrans(Tween.TransitionType.Back)
            .SetEase(Tween.EaseType.Out);

        if (IsSolved())
        {
            OnLevelSolved();
        }
    }

    private Vector2I FindEmptyCell()
    {
        for (int y = 0; y < BoardSize; y++)
            for (int x = 0; x < BoardSize; x++)
                if (grid[x, y] == 0)
                    return new Vector2I(x, y);
        return new Vector2I(BoardSize - 1, BoardSize - 1);
    }

    private bool IsSolved()
    {
        int expected = 1;
        for (int y = 0; y < BoardSize; y++)
        {
            for (int x = 0; x < BoardSize; x++)
            {
                if (x == BoardSize - 1 && y == BoardSize - 1)
                    return grid[x, y] == 0;

                if (grid[x, y] != expected)
                    return false;

                expected++;
            }
        }
        return true;
    }

    private void OnLevelSolved()
    {
        levelTransitioning = true;
        audioManager?.PlaySfx(1.35f);

        if (!bestMovesPerLevel.ContainsKey(currentLevel) || moves < bestMovesPerLevel[currentLevel])
        {
            bestMovesPerLevel[currentLevel] = moves;
            SaveBestMoves();
        }

        UpdateStatusText();

        Tween winTween = CreateTween();
        winTween.TweenProperty(boardGrid, "modulate", new Color(0.6f, 1.0f, 0.6f), 0.25);
        winTween.TweenProperty(boardGrid, "modulate", Colors.White, 0.25);

        if (currentLevel < MaxLevel)
        {
            messageLabel.Text = $"Līmenis {currentLevel} atrisināts ar {moves} gājieniem! Ielādē {currentLevel + 1}. līmeni...";
            winTween.TweenInterval(0.9);
            winTween.TweenCallback(Callable.From(() =>
            {
                currentLevel++;
                LoadLevel(currentLevel);
            }));
        }
        else
        {
            messageLabel.Text = $"APSVEICAM! Visi {MaxLevel} līmeņi atrisināti! Spied 'Sākt no jauna', lai uzlabotu rekordu.";
            levelTransitioning = false;
        }
    }

    private void RenderBoard()
    {
        int expected = 1;
        for (int y = 0; y < BoardSize; y++)
        {
            for (int x = 0; x < BoardSize; x++)
            {
                int val = grid[x, y];
                Button btn = tileButtons[x, y];
                bool isCorrectSpot = (val != 0) && (val == expected);

                btn.Text = val == 0 ? "" : val.ToString();
                btn.Disabled = val == 0;
                btn.Modulate = val == 0
                    ? new Color(1, 1, 1, 0.15f)
                    : (isCorrectSpot ? new Color(0.55f, 0.95f, 0.65f) : new Color(0.75f, 0.85f, 1.0f));

                expected++;
            }
        }
    }

    private void UpdateStatusText()
    {
        string bestText = bestMovesPerLevel.ContainsKey(currentLevel)
            ? $"{bestMovesPerLevel[currentLevel]} gājieni"
            : "-";
        statusLabel.Text = $"{currentLevel}. līmenis no {MaxLevel} | Gājieni: {moves} | Rekords: {bestText}";
    }

    private void SaveBestMoves()
    {
        using FileAccess file = FileAccess.Open(SavePath, FileAccess.ModeFlags.Write);
        if (file == null) return;
        file.StoreString(Json.Stringify(bestMovesPerLevel));
    }

    private void LoadBestMoves()
    {
        if (!FileAccess.FileExists(SavePath)) return;
        using FileAccess file = FileAccess.Open(SavePath, FileAccess.ModeFlags.Read);
        if (file == null) return;

        Variant parsed = Json.ParseString(file.GetAsText());
        if (parsed.VariantType == Variant.Type.Dictionary)
        {
            Godot.Collections.Dictionary dict = parsed.AsGodotDictionary();
            foreach (Variant key in dict.Keys)
            {
                if (int.TryParse(key.ToString(), out int lvl))
                {
                    bestMovesPerLevel[lvl] = (int)dict[key];
                }
            }
        }
    }

    private void OnRestartPressed()
    {
        audioManager?.PlaySfx(0.9f);
        LoadLevel(currentLevel);
    }

    private void OnMenuPressed()
    {
        audioManager?.PlaySfx(0.85f);
        if (ResourceLoader.Exists("res://Scenes/Menu.tscn"))
        {
            GetTree().ChangeSceneToFile("res://Scenes/Menu.tscn");
        }
    }
}
