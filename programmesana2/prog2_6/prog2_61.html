6.1 UI (lietotāja saskarne) elementi un Control (saskarnes vadīkla) nodes (mezgli)

Stundas uzdevums: Izveidot saskarni ar Godot Control nodes - Button (poga), Label (teksta etiķete), Container (konteiners).

SR 2.4.7. UI SR 2.4.15. Modulāras programmas

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - uzbūvē sākuma izvēlni · 2. uzdevums (~25 min) - savieno pogas ar kodu · 3. uzdevums (~20 min) - pievieno enkurus un pārbaudi izmērus · Iesniegšana (~5 min).

Pirms sāc: atver savu projektu. UI Godot lieto Control mezglus, nevis Node2D (2D mezgls) - tiem ir enkuri un container, kas paši kārto elementus.

Failu ceļi: ceļi ir norādīti no tava Godot projekta mapes, kur atrodas project.godot; piemēram, Scripts/Player.cs Godot panelī ir res://Scripts/Player.cs. Ja norādītais fails jau ir izveidots, atver un papildini to.

Jaunus C# failus veido mapē Scripts, scēnas — norādītajā ceļā; trūkstošās mapes izveido. Ja tavā projektā skripts glabājas citur, rediģē esošo failu. using direktīvas raksti faila sākumā, laukus un metodes — klases iekšienē. Esošu _Ready() vai _PhysicsProcess() papildini, neveido otru tāda paša nosaukuma metodi.

Teorija: lietotāja saskarnes (UI) izkārtojums un Control mezgli

Control mezglu hierarhija un konteineru automātiskais izkārtojums

Kamēr Node2D novieto objektus fiksētās pikseļu koordinātās, Godot lietotāja saskarnei (UI) izmanto Control saimes mezglus. Tiem piemīt elastīgs izkārtojums, enkuri (Anchors) un vienotas noformējuma tēmas (Themes) — līdzīgi kā mūsdienu tīmekļa lapās (CSS Flexbox / Grid), kur elementi paši pielāgojas dažādiem ekrāna izmēriem, nevis paliek iespiesti vienā stūrī:

Mezgls (Node)Nozīme un pielietojums
LabelStatiska vai no koda atjaunojama teksta etiķete.
Button / HSliderKlikšķināma poga darbības izsaukšanai un horizontāls slīdnis skaitliskas vērtības izvēlei.
LineEdit / TextEditVienas rindas vai vairāku rindu teksta ievades lauki.
VBoxContainer / HBoxContainerKonteineri, kas bērnmezglus automātiski sakārto vertikālā kolonnā vai horizontālā rindā (ar vienotu atstarpi Separation).
GridContainer / PanelContainerElementu izkārtojums vairāku kolonnu režģī un fona panelis ar iekšējām apmalēm.

Enkuri (Anchors) un saskarnes signālu savienošana C# kodā

Enkurs (Anchor) nosaka, pie kuras vecākā rāmja daļas (piemēram, kreisā augšējā stūra Top Left vai ekrāna vidus Center) saskarnes elements ir piesaistīts, kad lietotājs maina loga izmēru. Ja konteineram uzstādīts Center enkurs, tas saglabā pozīciju loga vidū jebkurā izšķirtspējā.

Lai saskarnes vadīklas reaģētu uz lietotāja klikšķiem, C# skripta metodē _Ready() atrod attiecīgo mezglu un ar operatoru += abonē tā signālu (piemēram, pogas notikumu Pressed), apstrādātājā pārslēdzot aktīvo skatu ar GetTree().ChangeSceneToFile(...) vai korekti aizverot lietotni ar GetTree().Quit():

public override void _Ready()
{
    Button atvertPoga = GetNode<Button>("VBox/AtvertPoga");
    atvertPoga.Pressed += KadNospiestsAtvert;
}

private void KadNospiestsAtvert()
{
    GetTree().ChangeSceneToFile("res://Scenes/GalvenaisSkats.tscn");
}

Praktiskie uzdevumi

1. uzdevums -

Uzbūvē sākuma izvēlni

Kur strādāt: Godot redaktorā izveido un saglabā Scenes/Menu.tscn ar Control sakni Menu. Konteineru nosauc VBox, pogas — StartButton, SettingsButton un QuitButton, lai tās sakristu ar koda ceļiem.

Beigās tavai spēlei būs sākuma ekrāns ar trim pogām.

  1. Izveido jaunu scēnu ar Control sakni un nosaukumu Menu.
  2. Pievieno tai child node (bērnu) VBoxContainer.
  3. Pievieno container Label ar spēles nosaukumu.
  4. Pievieno trīs Button mezglus: Sākt, Iestatījumi, Iziet.
  5. Ievēro, ka container pats sakārto pogas vienu zem otras.
  6. Pievieno container atstarpi ar Theme Overrides -> Separation.
  7. Palaid scēnu un pārbaudi, ka visas pogas ir redzamas.

Gatavs, kad: ekrānā ir virsraksts un trīs pogas vienu zem otras ar vienādām atstarpēm.

2. uzdevums -

Savieno pogas ar kodu

Kur strādāt: Izveido Scripts/MainMenu.cs un piesaisti to Scenes/Menu.tscn saknei. Pogu atrašanu un signālus raksti _Ready(), apstrādātājus — atsevišķās klases metodēs. ChangeSceneToFile norādi savas spēles scēnas ceļu; res://game.tscn der, ja tā saglabāta projekta saknē.

Beigās pogas tiešām kaut ko darīs.

  1. Izveido C# class MainMenu, kas manto no Control.
  2. Pievieno method private void OnStartPressed().
  3. Paņem pogu ar Button startButton = GetNode<Button>("VBox/StartButton");.
  4. Savieno _Ready method pogas signal ar startButton.Pressed += OnStartPressed;.
  5. Ielādē handler (apstrādātājā) spēles scēnu ar GetTree().ChangeSceneToFile("res://game.tscn");.
  6. Savieno arī Iziet pogu ar GetTree().Quit();.
  7. Būvē un pārbaudi abas pogas.
Button startButton = GetNode<Button>("VBox/StartButton");
startButton.Pressed += OnStartPressed;

private void OnStartPressed()
{
    GetTree().ChangeSceneToFile("res://game.tscn");
}

Gatavs, kad: Sākt poga atver spēles scēnu, un Iziet poga aizver spēli.

3. uzdevums -

Pievieno enkurus un pārbaudi izmērus

Kur strādāt: Enkurus un izvietojumu maini Scenes/Menu.tscn Inspector panelī; novērojumus pieraksti README.md.

Beigās izvēlne izskatīsies pareizi jebkurā loga izmērā.

  1. Izvēlies VBoxContainer un atver Layout -> Anchors Preset.
  2. Izvēlies Center, lai container paliktu ekrāna vidū.
  3. Palaid spēli un mainiet loga izmēru ar peli.
  4. Pieraksti, vai izvēlne palika centrā.
  5. Nomaini enkuru uz Top Left un atkārto testu.
  6. Pieraksti, kas mainījās.
  7. Ieliec Center atpakaļ un saglabā scēnu.

Gatavs, kad: mainot loga izmēru, izvēlne paliek centrā, bet ar Top Left enkuru tā aizbēg uz stūri.

Papildu uzdevums - Pievieno iestatījumu logu

Kur strādāt: Settings paneli un pogas izveido Scenes/Menu.tscn; sākotnējo paslēpšanu, pogu signālus un apstrādātājus pievieno esošajam Scripts/MainMenu.cs.

Ja pamatdarbs ir gatavs, uztaisi otro ekrānu.

  1. Izveido PanelContainer ar nosaukumu Settings.
  2. Pievieno tam skaļuma slīdni HSlider (horizontāls slīdnis).
  3. Paslēp to sākumā ar settings.Visible = false;.
  4. Parādi to, nospiežot Iestatījumu pogu.
  5. Pievieno Atpakaļ pogu, kas to atkal paslēpj.

Gatavs, kad: Iestatījumu logs parādās un pazūd ar pogām, neizejot no izvēlnes.

Ko sagatavo

Stundas mērķis: Tavai spēlei ir sākuma izvēlne ar trim pogām Control node, pogas ir savienotas ar C# kodu caur signal, un izvēlne paliek centrā, mainot loga izmēru.

GitHub krātuvē jābūt:

  1. Fails MainMenu.cs ar pogu signal savienojumiem.
  2. README.md ievietota video saite vai divi ekrānuzņēmumi krātuvē: izvēlne un tas, kas notiek, nospiežot Sākt.
  3. Ekrānuzņēmums ar izvēlni pēc loga izmēra maiņas.
  4. README.md: ar ko Control node atšķiras no Node2D.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Biežākās kļūdas

  • Button signal nestrādā: Pārbaudi, vai Pressed += izsaukums notiek _Ready method un node ceļš ir pareizs.
  • UI elementi pārklājas: Lieto Container nodes izkārtojuma pārvaldība.
  • Enkuri confusing: Layout → Set Anchors and Offsets to Preset → Top Wide vai Center.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

using Godot;

public partial class Menu : Control
{
    public override void _Ready()
    {
        Button startBtn = GetNode<Button>("VBox/StartButton");
        Button settingsBtn = GetNode<Button>("VBox/SettingsButton");
        Button quitBtn = GetNode<Button>("VBox/QuitButton");

        startBtn.Pressed += OnStart;
        settingsBtn.Pressed += OnSettings;
        quitBtn.Pressed += OnQuit;
    }

    private void OnStart()
    {
        GetTree().ChangeSceneToFile("res://game.tscn");
    }

    private void OnSettings()
    {
        GetTree().ChangeSceneToFile("res://settings.tscn");
    }

    private void OnQuit()
    {
        GetTree().Quit();
    }
}
