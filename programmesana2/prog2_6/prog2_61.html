6.1 UI (lietotāja saskarne) element (elementi) un Control (saskarnes vadīkla) nodes (mezgli)

Stundas uzdevums: Izveidot user interface (lietotāja saskarni) ar Godot Control (saskarnes vadīkla) nodes (mezgli) - Button (poga), Label (teksta etiķete), Container (konteiners).

Praktiskie uzdevumi

1. uzdevums -

Uzbūvē main menu (sākuma izvēlni)

Beigās tavai spēlei būs sākuma screen (ekrāns) ar trim button (pogām).

  1. Izveido jaunu scene (scēnu) ar Control (saskarnes vadīkla) root (sakni) un nosaukumu Menu.
  2. Pievieno tai child node (bērnu) VBoxContainer (vertikāls konteiners).
  3. Pievieno container (konteinerā) Label (teksta etiķete) ar spēles nosaukumu.
  4. Pievieno trīs Button (poga) mezglus: Sākt, Settings (iestatījumi), Iziet.
  5. Ievēro, ka container (konteiners) pats sakārto button (pogas) vienu zem otras.
  6. Pievieno container (konteinerā) atstarpi ar Theme Overrides -> Separation.
  7. Palaid scene (scēnu) un pārbaudi, ka visas button (pogas) ir redzamas.

Gatavs, kad: screen (ekrānā) ir virsraksts un trīs button (pogas) vienu zem otras ar vienādām atstarpēm.

2. uzdevums -

Savieno button (pogas) ar code (kodu)

Beigās button (pogas) tiešām kaut ko darīs.

  1. Izveido C# class (klasi) MainMenu, kas manto no Control (saskarnes vadīkla).
  2. Pievieno method (metodi) private void OnStartPressed().
  3. Paņem button (pogu) ar Button startButton = GetNode<Button>("VBox/StartButton");.
  4. Savieno _Ready method (metodē) button (pogas) signal (signālu) ar startButton.Pressed += OnStartPressed;.
  5. Ielādē handler (apstrādātājā) spēles scene (scēnu) ar GetTree().ChangeSceneToFile("res://game.tscn");.
  6. Savieno arī Iziet button (pogu) ar GetTree().Quit();.
  7. Būvē un pārbaudi abas button (pogas).

Gatavs, kad: Sākt button (poga) atver spēles scene (scēnu), un Iziet button (poga) aizver spēli.

3. uzdevums -

Pievieno anchor (enkurus) un pārbaudi izmērus

Beigās menu (izvēlne) izskatīsies pareizi jebkurā window (loga) izmērā.

  1. Izvēlies VBoxContainer (vertikāls konteiners) un atver Layout (izkārtojums) -> Anchors Preset (enkuru sagatave).
  2. Izvēlies Center (centrā), lai container (konteiners) paliktu screen (ekrāna) vidū.
  3. Palaid spēli un mainiet window (loga) izmēru ar mouse (peli).
  4. Pieraksti, vai menu (izvēlne) palika centrā.
  5. Nomaini anchor (enkuru) uz Top Left (augšā pa kreisi) un atkārto test (testu).
  6. Pieraksti, kas mainījās.
  7. Ieliec Center (centrā) atpakaļ un saglabā scene (scēnu).

Gatavs, kad: mainot window (loga) izmēru, menu (izvēlne) paliek centrā, bet ar Top Left (augšā pa kreisi) anchor (enkuru) tā aizbēg uz stūri.

Papildu uzdevums - Pievieno settings (iestatījumu) window (logu)

Ja pamatdarbs ir gatavs, uztaisi otro screen (ekrānu).

  1. Izveido PanelContainer (paneļa konteiners) ar nosaukumu Settings.
  2. Pievieno tam skaļuma slider (slīdni) HSlider (horizontāls slīdnis).
  3. Paslēp to sākumā ar settings.Visible = false;.
  4. Parādi to, nospiežot Settings (iestatījumu) button (pogu).
  5. Pievieno Atpakaļ button (pogu), kas to atkal paslēpj.

Gatavs, kad: Settings (iestatījumu) window (logs) parādās un pazūd ar button (pogām), neizejot no menu (izvēlnes).

Code sample (koda piemērs) (paplašināts)

using Godot;

public partial class Menu : Control
{
    public override void _Ready()
    {
        Button startBtn = GetNode<Button>("VBox/StartButton");
        Button settingsBtn = GetNode<Button>("VBox/SettingsButton");
        Button quitBtn = GetNode<Button>("VBox/QuitButton");

        startBtn.Pressed += OnStart;
        settingsBtn.Pressed += OnSettings;
        quitBtn.Pressed += OnQuit;
    }

    private void OnStart()
    {
        GetTree().ChangeSceneToFile("res://game.tscn");
    }

    private void OnSettings()
    {
        GetTree().ChangeSceneToFile("res://settings.tscn");
    }

    private void OnQuit()
    {
        GetTree().Quit();
    }
}
