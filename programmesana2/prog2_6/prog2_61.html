6.1 UI (lietotāja saskarne) elementi un Control (saskarnes vadīkla) nodes (mezgli)

Sasniedzamais rezultāts: Izveidot saskarni ar Godot Control nodes - Button (poga), Label (teksta etiķete), Container (konteiners).

SR 2.4.7. UI SR 2.4.15. Modulāras programmas

Teorija: lietotāja saskarnes (UI) izkārtojums un Control mezgli

Control mezglu hierarhija un konteineru automātiskais izkārtojums

Kamēr Node2D novieto objektus fiksētās pikseļu koordinātās, Godot lietotāja saskarnei (UI) izmanto Control saimes mezglus. Tiem piemīt elastīgs izkārtojums, enkuri (Anchors) un vienotas noformējuma tēmas (Themes) — līdzīgi kā mūsdienu tīmekļa lapās (CSS Flexbox / Grid), kur elementi paši pielāgojas dažādiem ekrāna izmēriem, nevis paliek iespiesti vienā stūrī:

Mezgls (Node)Nozīme un pielietojums
LabelStatiska vai no koda atjaunojama teksta etiķete.
Button / HSliderKlikšķināma poga darbības izsaukšanai un horizontāls slīdnis skaitliskas vērtības izvēlei.
LineEdit / TextEditVienas rindas vai vairāku rindu teksta ievades lauki.
VBoxContainer / HBoxContainerKonteineri, kas bērnmezglus automātiski sakārto vertikālā kolonnā vai horizontālā rindā (ar vienotu atstarpi Separation).
GridContainer / PanelContainerElementu izkārtojums vairāku kolonnu režģī un fona panelis ar iekšējām apmalēm.

Praksē saskarnes skatu veido kā ligzdotu konteineru koku, kur saknes mezgls aizņem visu logu, bet konteineri automātiski izlīdzina vadīklas:

SakumaSkats (Control — Anchors: Full Rect)
├── GalvenaKolonna (VBoxContainer — Anchors: Center)
│   ├── Virsraksts (Label)
│   ├── AtvertPoga (Button)
│   └── IzietPoga (Button)
└── IestatijumuPanelis (PanelContainer — Visible: false)
    └── SkalumaRinda (HBoxContainer)
        ├── Nosaukums (Label)
        └── SkalumaSlidnis (HSlider)

Enkuri (Anchors) un saskarnes signālu savienošana C# kodā

Enkurs (Anchor) nosaka, pie kuras vecākā rāmja daļas (piemēram, kreisā augšējā stūra Top Left vai ekrāna vidus Center) saskarnes elements ir piesaistīts, kad lietotājs maina loga izmēru. Ja konteineram uzstādīts Center enkurs, tas saglabā pozīciju loga vidū jebkurā izšķirtspējā.

Lai saskarnes vadīklas reaģētu uz lietotāja klikšķiem, C# skripta metodē _Ready() atrod attiecīgo mezglu un ar operatoru += abonē tā signālu (piemēram, pogas notikumu Pressed), apstrādātājā pārslēdzot aktīvo skatu ar GetTree().ChangeSceneToFile(...) vai korekti aizverot lietotni ar GetTree().Quit():

public override void _Ready()
{
    Button atvertPoga = GetNode<Button>("GalvenaKolonna/AtvertPoga");
    Button izietPoga = GetNode<Button>("GalvenaKolonna/IzietPoga");
    atvertPoga.Pressed += KadNospiestsAtvert;
    izietPoga.Pressed += KadNospiestsIziet;
}

private void KadNospiestsAtvert()
{
    GetTree().ChangeSceneToFile("res://Scenes/GalvenaisSkats.tscn");
}

private void KadNospiestsIziet()
{
    GetTree().Quit(); // Korekti aizver lietotnes logu.
}

1. uzdevums

Izveido projektu un uzbūvē sākuma izvēlni

Kur strādāt: Izveido jaunu Godot 4 (.NET) projektu PuzzleGame ar mapēm Scenes/, Scripts/ un Sounds/. Šajā uzdevumā veido divas scēnas: sākuma izvēlni Scenes/Menu.tscn un spēles ekrāna sagatavi Scenes/Puzzle.tscn (C# kods šajā solī vēl nav jāraksta).

Beigās tavai 6. tēmas atjautības spēlei būs strukturēta sākuma izvēlne ar virsrakstu, trim pogām, iestatījumu paneli un spēles scēnas sagatavi.

Scēnas koka uzbūve (Scenes/Menu.tscn):

Menu (Control - Layout: Full Rect, piesaistīts Scripts/MainMenu.cs 2. uzdevumā)
 ├── Background (ColorRect - Layout: Full Rect, Color: #1a2234)
 ├── VBox (VBoxContainer - Layout: Center, Separation: 14)
 │    ├── TitleLabel (Label - Text: "ATJAUTĪBAS SPĒLE")
 │    ├── StartButton (Button - Text: "Sākt spēli", Custom Minimum Size: 240 × 44)
 │    ├── SettingsButton (Button - Text: "Iestatījumi", Custom Minimum Size: 240 × 44)
 │    └── QuitButton (Button - Text: "Iziet", Custom Minimum Size: 240 × 44)
 └── SettingsPanel (PanelContainer - Layout: Center, Visible: Off)
      └── SettingsVBox (VBoxContainer - Separation: 10)
           ├── SettingsTitle (Label - Text: "Iestatījumi")
           └── BackButton (Button - Text: "Aizvērt")
  1. Izveido Godot 4 (.NET) projektu PuzzleGame un FileSystem panelī izveido mapes Scenes/, Scripts/ un Sounds/.
  2. Izveido jaunu scēnu ar Control sakni (User Interface), pārdēvē to par Menu, augšējā rīkjoslā izvēlies Layout -> Anchors Preset -> Full Rect un saglabā kā res://Scenes/Menu.tscn.
  3. Pievieno saknei Menu bērna mezglu ColorRect ar nosaukumu Background, uzliec tam Layout -> Full Rect un Inspector panelī iestati tumšu fona krāsu (piemēram, #1a2234).
  4. Pievieno saknei Menu bērna mezglu VBoxContainer un pārdēvē to par VBox. Inspector sadaļā Theme Overrides -> Constants -> Separation ieraksti 14.
  5. Pievieno VBox konteineram bērnu Label ar nosaukumu TitleLabel, ieraksti Text = "ATJAUTĪBAS SPĒLE", Horizontal Alignment = Center un Theme Overrides -> Font Sizes -> Font Size = 36.
  6. Pievieno VBox konteineram trīs Button bērnus ar precīziem nosaukumiem StartButton (Text = "Sākt spēli"), SettingsButton (Text = "Iestatījumi") un QuitButton (Text = "Iziet"). Katrai pogai sadaļā Layout -> Custom Minimum Size iestati X = 240, Y = 44.
  7. Pievieno saknei Menu arī mezglu PanelContainer ar nosaukumu SettingsPanel (tajā ievieto VBoxContainer SettingsVBox ar Label SettingsTitle un Button BackButton) un paslēp to, izslēdzot acs ikonu vai Visibility -> Visible = Off.
  8. Izveido otru scēnu ar Control sakni Puzzle, pievieno tai Label ar tekstu "Spēles laukums (pilna loģika 6.6. stundā)" un saglabā kā res://Scenes/Puzzle.tscn, lai 2. uzdevumā pāreja uz spēles scēnu strādātu bez kļūdas.

Gatavs, kad: saglabātā scēnā Scenes/Menu.tscn ir virsraksts un trīs pogas vienā kolonnā ar vienādām atstarpēm, kā arī izveidota mērķa scēna Scenes/Puzzle.tscn.

2. uzdevums

Savieno izvēlnes pogas ar C# kodu

Kur strādāt: Izveido Scripts/MainMenu.cs un piesaisti to scēnas Scenes/Menu.tscn saknei Menu. Pogu meklēšanu un Pressed += pierakstīšanos raksti metodē _Ready(), bet darbības - metodēs OnStartPressed(), OnSettingsPressed(), OnBackPressed() un OnQuitPressed().

Beigās visas izvēlnes pogas reaģēs uz klikšķiem: atvērs spēles scēnu, parādīs vai paslēps iestatījumu paneli un aizvērs spēli.

  1. Izveido skriptu res://Scripts/MainMenu.cs (klase public partial class MainMenu : Control) un piesaisti to Scenes/Menu.tscn saknei Menu.
  2. Atrodi metodē _Ready() pogas pēc to ceļiem scēnas kokā: Button startButton = GetNode<Button>("VBox/StartButton");, Button settingsButton = GetNode<Button>("VBox/SettingsButton"); un Button quitButton = GetNode<Button>("VBox/QuitButton");.
  3. Atrodi arī iestatījumu paneli settingsPanel = GetNodeOrNull<Control>("SettingsPanel"); un tā aizvēršanas pogu GetNodeOrNull<Button>("SettingsPanel/SettingsVBox/BackButton").
  4. Savieno metodē _Ready() pogu signālus ar C# notikumu apstrādātājiem: startButton.Pressed += OnStartPressed;, settingsButton.Pressed += OnSettingsPressed; un quitButton.Pressed += OnQuitPressed;.
  5. Izveido metodi private void OnStartPressed(), kurā pārslēdz scēnu ar GetTree().ChangeSceneToFile("res://Scenes/Puzzle.tscn");.
  6. Izveido metodes private void OnSettingsPressed() (kas ieslēdz settingsPanel.Visible = true;) un private void OnQuitPressed() (kas izsauc GetTree().Quit();).
  7. Nospied Build, iestati Scenes/Menu.tscn kā galveno scēnu un ar F5 pārbaudi visas pogas.
// Fragments no Scripts/MainMenu.cs:
public override void _Ready()
{
    Button startButton = GetNode<Button>("VBox/StartButton");
    Button settingsButton = GetNode<Button>("VBox/SettingsButton");
    Button quitButton = GetNode<Button>("VBox/QuitButton");

    startButton.Pressed += OnStartPressed;
    settingsButton.Pressed += OnSettingsPressed;
    quitButton.Pressed += OnQuitPressed;
}

private void OnStartPressed()
{
    GetTree().ChangeSceneToFile("res://Scenes/Puzzle.tscn");
}

Gatavs, kad: poga „Sākt spēli" atver Scenes/Puzzle.tscn, „Iestatījumi" atver SettingsPanel, bet „Iziet" aizver spēles logu.

3. uzdevums

Pievieno enkurus (Anchors) un pārbaudi loga izmēra maiņu

Kur strādāt: Enkurus un izkārtojumu maini Scenes/Menu.tscn mezglam VBox un SettingsPanel Godot redaktorā; novērojumus pieraksti projekta saknes failā README.md.

Beigās izvēlne vienmēr paliks ekrāna vidū pat tad, ja spēlētājs izstiepj vai samazina spēles logu.

  1. Atver Scenes/Menu.tscn, Scene kokā izvēlies mezglu VBox un 2D skata augšējā rīkjoslā atver izvēlni Layout -> Anchors Preset.
  2. Izvēlies Center (to pašu uzliec arī mezglam SettingsPanel), lai abi konteineri tiktu piesaistīti ekrāna centram (Anchor = 0.5, 0.5).
  3. Palaid spēli (F5), ar peli pavelc spēles loga malu, mainot tā platumu un augstumu, un novēro izvēlnes novietojumu.
  4. Nomaini eksperimenta nolūkā VBox enkuru uz Layout -> Anchors Preset -> Top Left, palaid spēli un vēlreiz izmaini loga izmēru.
  5. Salīdzini abus gadījumus un pieraksti atšķirību failā README.md (arī to, ar ko Control mezgls atšķiras no Node2D).
  6. Atjauno mezglam VBox enkuru Layout -> Anchors Preset -> Center un saglabā scēnu (Ctrl+S).

Gatavs, kad: mainot spēles loga izmēru, izvēlne ar Center enkuru paliek precīzi ekrāna vidū, un salīdzinājums ir pierakstīts README.md.

Papildu uzdevums - Pievieno skaļuma slīdņus iestatījumu panelī un pogu „Atpakaļ uz izvēlni"

Kur strādāt: Papildini SettingsPanel scēnā Scenes/Menu.tscn ar diviem HSlider mezgliem (MusicSlider un SfxSlider), kā arī pievieno Scenes/Puzzle.tscn pogu MenuButton atgriešanai uz res://Scenes/Menu.tscn.

Ja pamatdarbs ir gatavs, sagatavo iestatījumu paneli 6.3. stundas skaņas kopnēm un abpusēju pāreju starp izvēlni un spēli.

  1. Pievieno SettingsPanel/SettingsVBox konteinerā Label ("Mūzikas skaļums") un HSlider ar nosaukumu MusicSlider (Min Value = -40, Max Value = 0, Value = 0).
  2. Pievieno zem tā otru Label ("Efektu skaļums") un HSlider ar nosaukumu SfxSlider (Min Value = -40, Max Value = 0, Value = 0).
  3. Pārbaudi, ka poga BackButton (SettingsPanel/SettingsVBox/BackButton) metodē OnBackPressed() paslēpj SettingsPanel (settingsPanel.Visible = false;).
  4. Pievieno scēnā Scenes/Puzzle.tscn pogu MenuButton, kas izsauc GetTree().ChangeSceneToFile("res://Scenes/Menu.tscn");, lai vari brīvi pārslēgties starp abiem ekrāniem.

Gatavs, kad: iestatījumu panelis ar slīdņiem atveras un aizveras no izvēlnes, un no spēles scēnas var atgriezties sākuma izvēlnē.

Pilnais koda piemērs — gatavs šīs stundas risinājums

Fails: Scripts/MainMenu.cs (piesaistīts Menu saknei scēnā Scenes/Menu.tscn)

using Godot;

public partial class MainMenu : Control
{
    private Control settingsPanel;

    public override void _Ready()
    {
        Button startBtn = GetNode<Button>("VBox/StartButton");
        Button settingsBtn = GetNode<Button>("VBox/SettingsButton");
        Button quitBtn = GetNode<Button>("VBox/QuitButton");

        startBtn.Pressed += OnStartPressed;
        settingsBtn.Pressed += OnSettingsPressed;
        quitBtn.Pressed += OnQuitPressed;

        settingsPanel = GetNodeOrNull<Control>("SettingsPanel");
        if (settingsPanel != null)
        {
            settingsPanel.Visible = false;
            Button backBtn = settingsPanel.GetNodeOrNull<Button>("SettingsVBox/BackButton");
            if (backBtn != null)
            {
                backBtn.Pressed += OnBackPressed;
            }
        }
    }

    private void OnStartPressed()
    {
        if (ResourceLoader.Exists("res://Scenes/Puzzle.tscn"))
        {
            GetTree().ChangeSceneToFile("res://Scenes/Puzzle.tscn");
        }
        else
        {
            GD.PrintErr("Scēna res://Scenes/Puzzle.tscn vēl nav izveidota!");
        }
    }

    private void OnSettingsPressed()
    {
        if (settingsPanel != null)
        {
            settingsPanel.Visible = !settingsPanel.Visible;
        }
    }

    private void OnBackPressed()
    {
        if (settingsPanel != null)
        {
            settingsPanel.Visible = false;
        }
    }

    private void OnQuitPressed()
    {
        GetTree().Quit();
    }
}
Pilna sākuma izvēlne ar C# pogu signāliem, iestatījumu paneļa pārslēgšanu un drošu pāreju uz res://Scenes/Puzzle.tscn.

Ko sagatavo

Stundas mērķis: Tavai spēlei ir sākuma izvēlne Scenes/Menu.tscn ar trim pogām Control konteinerā, pogas ir savienotas ar C# kodu Scripts/MainMenu.cs caur Pressed += signāliem, un izvēlne paliek centrā, mainot loga izmēru.

GitHub krātuvē jābūt:

  • Skriptam Scripts/MainMenu.cs un scēnām Scenes/Menu.tscn un Scenes/Puzzle.tscn.
  • README.md ievietotai video saitei vai diviem ekrānuzņēmumiem krātuvē: sākuma izvēlnei un skatam pēc pogas „Sākt spēli" vai „Iestatījumi" nospiešanas.
  • Ekrānuzņēmumam ar izvēlni pēc spēles loga izmēra maiņas.
  • README.md atbildei: kā uzvedās Center un Top Left enkuri un ar ko Control mezgls atšķiras no Node2D.

Kā iesniedz: Veic git commit un git push. Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • Button signal nestrādā: Pārbaudi, vai Pressed += izsaukums notiek _Ready method un node ceļš ir pareizs.
  • UI elementi pārklājas: Lieto Container nodes izkārtojuma pārvaldība.
  • Enkuri confusing: Layout → Set Anchors and Offsets to Preset → Top Wide vai Center.
