2.1 Pirmais kustīgais object (objekts)

Stundas uzdevums: Izveido Godot project (projektu), palaid kustīgu taisnstūri un maini tā ātrumu Inspector (īpašību panelis) panel (panelī).

SR 2.4.14. Control structure (vadības struktūras) SR 2.4.15. Modular program (modulāras programmas)

80 min plāns: Ievads (~10 min) · 1. uzdevums (~20 min) · 2. uzdevums (~25 min) · 3. uzdevums (~20 min) · save (saglabāšana) (~5 min).

Pirms sāc: vajadzīga 1. tēmā sagatavotā Godot 4 .NET vide un .NET SDK (programmatūras izstrādes komplekts). Izveidosim jaunu Platformer (platformas spēle) project (projektu), kuru turpināsim visas sešas stundas. Ja C# file (failu) nevar izveidot vai Build (būvēt projektu) rāda kļūdu, atgriezies C# vides sagatavošanā.

Pēc izmaiņām: saglabā file (failus). Ja mainīji C# code (kodu), Godot augšējā labajā stūrī nospied Build (būvēt projektu) (āmura icon (ikona)). Tad palaid spēli. Pirms nākamā uzdevuma izlabo pirmo parādīto kļūdu.

Ko veidosim

Šodien izveidosi kustīgu taisnstūri. Nākamajās stundās pievienosi vadību, punktus, platformas un lēcienu. Beigās būs viena spēle ar finišu, tavu nosaukumu un stāstu.

Visās sešās stundās turpini vienu project (projektu) — Platformer (platformas spēle).

1. uzdevums -

Izveido project (projektu) un redzamu kustīgu object (objektu)

  1. Godot sākuma window (logā) (Project Manager (projektu pārvaldnieks)) spied Create (izveidot). Nosauc project (projektu) Platformer (platformas spēle), izvēlies tā folder (mapi) un Compatibility (saderības režīms), tad Create & Edit (izveidot un rediģēt).
  2. FileSystem (failu sistēma) panel (panelī) ar labo mouse (peles) button (pogu) klikšķini uz res:// → Create New (izveidot jaunu) → Folder (mape). Izveido folder (mapi) Scenes, pēc tam tāpat izveido Scripts.
  3. Augšējā menu (izvēlnē) atver Project (projekts) → Project Settings (projekta iestatījumi) → Display (attēlojums) → Window (logs). Sadaļā Size (izmērs) iestati Viewport Width (skatloga platums) = 1280 un Viewport Height (skatloga augstums) = 720. Sadaļā Stretch (izstiepšana) field (laukā) Mode (režīms) izvēlies canvas_items. Aizver settings (iestatījumus).
  4. Scene (scēna) panel (panelī) spied 2D Scene (2D scēna). Atlasi izveidoto Node2D (2D mezgls), nospied F2 un pārdēvē to par MovementLab. Ar Ctrl+S saglabā to folder (mapē) Scenes kā MovementLab.tscn.
  5. Atlasi MovementLab, spied +, meklē Node2D (2D mezgls) un spied Create (izveidot). Ar F2 nosauc to Mover. Inspector (īpašību panelis) sadaļā Transform (pārveidojums) → Position (pozīcija) ievadi (80,360).
  6. Atlasi Mover un ar + pievieno Polygon2D (2D daudzstūris). Nosauc to Visual. Inspector (īpašību panelis) atver Data (dati) → Polygon (daudzstūris), izvērs punktu list (sarakstu) un iestati Size (izmērs) = 4. Četrās rindās secīgi ievadi (-16,-24), (16,-24), (16,24), (-16,24). Pie Color (krāsa) izvēlies gaišu krāsu. 2D skatā parādās taisnstūris.
  7. Ar labo mouse (peles) button (pogu) klikšķini uz Mover → Attach Script (pievienot skriptu). Izvēlies Language (valoda): C#, field (laukā) Path (ceļš) ieraksti res://Scripts/Mover.cs un spied Create (izveidot). Atver file (failu) savā C# editor (redaktorā) un aizstāj tā saturu ar pilno code (kodu) zemāk.
  8. Saglabā code (kodu) un scene (scēnu). Godot nospied Build (būvēt projektu), tad Run Current Scene (palaist pašreizējo scēnu) (F6). Taisnstūris kustas pa labi un pēc tam atgriežas sākumā. Ar Stop (apturēt) (F8) apturi spēli.
2.1 Mover.cs — pilns file (fails) salīdzināšanai

Lejupielādēt Mover.cs. Atver esošo tāda paša nosaukuma file (failu) un aizstāj tā saturu ar šo code (kodu).

using Godot;

public partial class Mover : Node2D
{
    [Export] public float Speed = 200.0f;

    public override void _PhysicsProcess(double delta)
    {
        Position += new Vector2(Speed, 0) * (float)delta;
        if (Position.X > 1200)
            Position = new Vector2(80, Position.Y);
    }
}

Gatavs, kad: object (objekts) ir redzams un atkārtoti šķērso screen (ekrānu).

2. uzdevums -

Apskati code (koda) ziņas Output (izvade) panel (panelī)

  1. FileSystem (failu sistēma) → Scripts (skripti) atver Mover.cs. Pirms file (faila) pēdējās } pievieno zemāk doto _Process daļu. Tā izvadīs ziņu, bet nekustinās taisnstūri.
  2. Esošajā _PhysicsProcess uzreiz aiz atverošās { uz laiku ievieto GD.Print($"Physics: {delta:F4}");.
  3. Saglabā, nospied Build (būvēt projektu), tad F6. Pēc 1–2 sekundēm nospied F8 un apakšā atver Output (izvade). Atrodi rindas, kas sākas ar Process un Physics (fizika).
  4. _Process darbojas, kad spēle atjauno attēlu. _PhysicsProcess izmantojam kustībai un collision (sadursmēm). Skaitlis delta rāda, cik sekundes ilgst viens solis. Abu output (izdruku) skaitļi var būt līdzīgi.
  5. Saglabā Output (izvade) screenshot (ekrānuzņēmumu). Tad izdzēs pievienoto _Process daļu un GD.Print rindu no kustības code (koda). Saglabā un nospied Build (būvēt projektu).
public override void _Process(double delta)
{
    GD.Print($"Process: {delta:F4}");
}

Gatavs, kad: Output (izvade) panel (panelī) esi atradis abas ziņas un pēc pārbaudes tās noņēmis no code (koda).

3. uzdevums -

Maini ātrumu un salīdzini kustību

  1. Scene (scēna) panel (panelī) atlasi Mover. Inspector (īpašību panelis) field (laukā) Speed (ātrums) ieraksti 100, palaid ar F6 un apskati kustību. Apturi, izmēģini 400, tad atjauno 200.
  2. Atver Project (projekts) → Project Settings (projekta iestatījumi), ieslēdz Advanced Settings (papildu iestatījumi) un atver Physics (fizika) → Common (kopīgie iestatījumi). Field (lauku) Physics Ticks per Second (fizikas soļi sekundē) nomaini no 60 uz 30. Tas nosaka, cik reižu sekundē Godot izpilda kustības code (kodu). Palaid scene (scēnu): taisnstūrim screen (ekrāns) jāšķērso aptuveni tikpat ilgā laikā.
  3. Apturi spēli. Kustības rindā uz laiku izdzēs * (float)delta. Saglabā, nospied Build (būvēt projektu) un palaid scene (scēnu). Taisnstūris pārvietojas daudz ātrāk, jo tagad katrā solī pārlec par 200 pixel (pikseļiem).
  4. Atjauno * (float)delta, Speed (ātrums) = 200 un Physics Ticks per Second (fizikas soļi sekundē) = 60. Saglabā, nospied Build (būvēt projektu) un pārbaudi kustību vēlreiz.
  5. README.md ieraksti, kas notika, mainot Speed (ātrums), un kas notika bez delta. Pietiek ar diviem īsiem teikumiem: delta palīdz saglabāt kustības ātrumu arī tad, ja kustības code (kodu) izpilda retāk.

Gatavs, kad: eksperiments pabeigts, code (kodā) atkal ir delta un project (projektā) atjaunoti 60 physics tick (fizikas soļi) sekundē.

Papildu uzdevums — izvēlies sava varoņa krāsu

Scene (scēna) panel (panelī) atlasi Visual un Inspector (īpašību panelis) field (laukā) Color (krāsa) izvēlies sava varoņa krāsu. README.md uzraksti, kas būs tavs varonis un ko viņš vēlas sasniegt. Šo ideju turpināsi 6. stundā.

Ko sagatavo

GitHub repository (krātuvē) jābūt:

  1. MovementLab.tscn un Mover.cs.
  2. Output (izvade) screenshot (ekrānuzņēmums) un README.md: divi novērojumi par kustību un viens teikums par spēles ideju.

Saglabā visu project (projektu): project.godot, .csproj, scene (scēnas), script (skriptus) un izmantotos attēlus. .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.

Kā iesniedz: saglabā izmaiņas Git un nosūti tās uz GitHub tāpat kā 1. tēmā (commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi)). Skolotāja norādītajā vietā iesniedz GitHub repository (krātuves) link (saiti); README.md un pārbaudes pierādījumiem jābūt repository (krātuvē).
