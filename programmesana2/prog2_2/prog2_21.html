2.1 Process un fizikas cikli

Stundas uzdevums: Izveidot platformas spēles projektu un kustības eksperimentā saprast laika soli delta.

SR 2.4.14. Vadības struktūras SR 2.4.15. Modulāras programmas

80 min plāns: Ievads (~10 min) · 1. uzdevums (~20 min) · 2. uzdevums (~25 min) · 3. uzdevums (~20 min) · saglabāšana (~5 min).

Pirms sāc: vajadzīga 1. tēmā sagatavotā Godot 4 .NET vide un .NET SDK. Izveidosim jaunu Platformer projektu, kuru turpināsim visas sešas stundas. Ja C# skriptu nevar izveidot vai kompilēt, atgriezies C# vides sagatavošanā.

Darba ritms: pēc katra uzdevuma saglabā, nospied Build un pārbaudi rezultātu. Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Ceļš līdz savai spēlei

Vispirms izmēģināsi kustību atsevišķā MovementLab.tscn scēnā. 2.2 stundā izveidosi spēlētāju; 2.3 — priekšmetu loģiku; 2.4 — sadursmes un savācamos; 2.5 — lēcienus; 2.6 — uzvaru, zaudējumu, atkārtotu spēli un savu noformējumu.

Gala rezultāts ir viens izspēlējams līmenis ar tavu nosaukumu, dizainu un stāstu. Skolēna izvēle var būt, piemēram, kosmosa ceļojums, meža glābšana vai pilsētas piedzīvojums.

Teorija: laiks un kustība

_Process(double delta) darbojas katrā attēlotajā kadrā, kura ilgums var mainīties. _PhysicsProcess(double delta) darbojas ar atsevišķi iestatītu fizikas biežumu (noklusēti 60 reizes sekundē). Monitora 144 Hz pats par sevi nemaina fizikas biežumu.

delta ir viena soļa ilgums sekundēs. Pārbīdot Node2D.Position, attālums = ātrums × laiks. Piemēram, 200 px/s × 0,5 s = 100 px.

Nākamajām stundām: CharacterBody2D.Velocity glabā ātrumu px/s; MoveAndSlide() laiku ņem vērā pats. Tam nododamo ātrumu vēlreiz ar delta nereizina. Gravitācijas paātrinājumu ar delta reizina, jo tas maina ātrumu. Skati Godot kustības dokumentāciju.

1. uzdevums -

Izveido projektu un redzamu kustīgu objektu

  1. Godot Project Manager izveido projektu Platformer ar Compatibility renderētāju. Izveido mapes Scenes un Scripts.
  2. Project → Project Settings → Display → Window iestati Viewport Width 1280, Viewport Height 720 un Stretch Mode canvas_items.
  3. Izveido Node2D sakni MovementLab, saglabā res://Scenes/MovementLab.tscn. Pievieno bērnu Node2D ar nosaukumu Mover, tā Position = (80, 360).
  4. Mover pievieno bērnu Polygon2D ar nosaukumu Visual. Inspector īpašībā Polygon ievadi četras virsotnes: (-16,-24), (16,-24), (16,24), (-16,24); Color izvēlies gaišu. Mezgls Node2D viens pats nav redzams.
  5. Mover mezglam pievieno C# skriptu res://Scripts/Mover.cs. Aizstāj tā saturu ar zemāk doto kodu. Faila nosaukumam un public partial class Mover jāsakrīt.
  6. Saglabā, nospied Build un F6 (pašreizējā scēna). Objekts kustas pa labi un aiz labās robežas atgriežas sākumā.
2.1 Mover.cs — pilns fails salīdzināšanai

Lejupielādēt Mover.cs. Aizstāj tikai atbilstošā faila saturu; neveido otru tāda paša nosaukuma klasi.

using Godot;

public partial class Mover : Node2D
{
    [Export] public float Speed = 200.0f;

    public override void _PhysicsProcess(double delta)
    {
        Position += new Vector2(Speed, 0) * (float)delta;
        if (Position.X > 1200)
            Position = new Vector2(80, Position.Y);
    }
}

Gatavs, kad: objekts ir redzams un atkārtoti šķērso ekrānu.

2. uzdevums -

Salīdzini abus ciklus

  1. Mover klases iekšpusē pievieno zemāk doto _Process metodi. Tā nemaina pozīciju.
  2. Esošās _PhysicsProcess metodes sākumā uz laiku pievieno GD.Print($"Physics: {delta:F4}");. Otru _PhysicsProcess neveido.
  3. Palaid scēnu uz 1–2 sekundēm, apturi un Output panelī salīdzini rindiņas ar abiem nosaukumiem. Vērtības uz ātra datora var būt ļoti līdzīgas.
  4. Pieraksti README.md, kurš cikls ir paredzēts fizikas kustībai. Noņem abas diagnostikas izdrukas un lieko _Process metodi.
public override void _Process(double delta)
{
    GD.Print($"Process: {delta:F4}");
}

Gatavs, kad: vari atšķirt abu ciklu izdrukas un paskaidrot, ka fizikas biežums tiek iestatīts atsevišķi no attēlošanas FPS.

3. uzdevums -

Pārbaudi delta ar aprēķinu un eksperimentu

  1. Pie Speed = 200 aprēķini pārbīdi vienā fizikas solī: ar delta pie 60 Hz tā ir ap 3,33 px, pie 30 Hz — ap 6,67 px. Vienā sekundē abos gadījumos sanāk 200 px.
  2. Project Settings → Physics → Common → Physics Ticks per Second pārslēdz no 60 uz 30 (ja lauks nav redzams, ieslēdz Advanced Settings). Palaid un salīdzini šķērsošanas laiku.
  3. Uz laiku kustības rindā noņem * (float)delta. Pārbaudi pie 30 un 60 fizikas soļiem sekundē. Tagad katrā solī objekts pārvietojas par 200 px, tāpēc rezultāts ir 6000 vai 12000 px/s.
  4. Atjauno reizināšanu ar delta un 60 Physics Ticks per Second. Pārbaudi sākotnējo kustību. README.md ieraksti četru variantu aprēķinus un savu novērojumu.

Gatavs, kad: eksperiments pabeigts, kodā atkal ir delta un projektā atjaunoti 60 fizikas soļi sekundē.

Papildu uzdevums — izvēlies sava varoņa krāsu

Maini Visual.Color un README.md uzraksti, kas būs tavs varonis un ko viņš vēlas sasniegt. Šo ideju turpināsi 6. stundā.
