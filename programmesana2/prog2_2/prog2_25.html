2.5 Gravitācija un platformas mehānika

Stundas uzdevums: Pievienot gravitāciju un lēcienu, saglabāt priekšmetu loģiku un pārbaudīt līmeņa izspēlējamību.

SR 2.4.14. Vadības struktūras SR 2.4.13. Datu tipi

80 min plāns: Ievads (~10 min) · gravitācija (~20 min) · lēciens (~25 min) · maršruta pārbaude (~20 min) · saglabāšana (~5 min).

Pirms sāc: turpini 2.4 līmeni. Saglabā Player punktus, HasKey un OnPickup. Tagad vienīgā kustība ar virzienu taustiņiem būs pa kreisi un pa labi; W/S vairs nepārvieto varoni vertikāli.

Darba ritms: pēc katra uzdevuma saglabā, nospied Build un pārbaudi rezultātu. Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Teorija: lēciens un gravitācija

Godot Y ass aug uz leju: pozitīvs Y ātrums nozīmē krišanu, negatīvs — kustību augšup. Gravitācija maina ātrumu: velocity.Y += Gravity * (float)delta;. Lēciens vienu reizi piešķir negatīvu ātrumu.

IsOnFloor() izmanto pēdējā MoveAndSlide sadursmes rezultātu; pirms pirmā fizikas soļa tas vēl nav patiess. Saglabā Motion Mode = Grounded un Up Direction = (0,-1). Katru soli sākam ar Vector2 velocity = Velocity;, jo MoveAndSlide var izmainīt ātrumu pēc sadursmes.

Pamatversijā lēciens ir tikai no zemes. Mainīgs augstums un īsa lēciena tolerance pēc malas ir papildu uzlabojums, kad jau iespējams iziet līmeni.

1. uzdevums -

Aizstāj brīvo vertikālo kustību ar gravitāciju

  1. Player klasē pievieno [Export] public float Gravity = 1200.0f; un [Export] public float JumpVelocity = -550.0f;. Speed paliek 300.
  2. Aizstāj tikai veco _PhysicsProcess metodi ar zemāk doto. Tā saglabā IsActive pārbaudi, lasa iepriekšējo ātrumu, pieskaita gravitāciju un vada tikai horizontālo virzienu.
  3. Pārliecinies, ka nav palicis Velocity = direction.Normalized() * Speed vai vertikāla move_up/move_down apstrāde. Tā nodzēstu krišanas ātrumu.
  4. Level1 Player instancei Position = (80,570). Build un F5: varonis nokrīt līdz grīdai un tur paliek; A/D joprojām darbojas.
public override void _PhysicsProcess(double delta)
{
    if (!IsActive)
    {
        Velocity = Vector2.Zero;
        return;
    }

    Vector2 velocity = Velocity;
    if (!IsOnFloor())
        velocity.Y += Gravity * (float)delta;

    // Nākamajā uzdevumā šeit pievienosi lēcienu.
    velocity.X = Input.GetAxis("move_left", "move_right") * Speed;
    Velocity = velocity;
    MoveAndSlide();
}

Gatavs, kad: varonis krīt, stāv uz grīdas un pārvietojas horizontāli.

2. uzdevums -

Pievieno vienu lēcienu no zemes

  1. Komentāra vietā, pirms horizontālā ātruma piešķiršanas, ievieto zemāk doto lēciena nosacījumu. jump ar Space jau ir Input Map no 2.2.
  2. Build un F5: uz zemes nospied Space. Turot taustiņu, lēcienam nav jāatkārtojas; gaisā atkārtota nospiešana nedod vēl vienu lēcienu.
  3. Uz laiku noņem && IsOnFloor() un izmēģini vairākus Space nospiedienus gaisā. Atjauno šo nosacījumu.
  4. Ja izmēģini pozitīvu JumpVelocity, pēc eksperimenta atjauno -550. Pārbaudi vērtību arī Inspector: iepriekš saglabātās Export vērtības var pārrakstīt koda noklusējumu.
if (Input.IsActionJustPressed("jump") && IsOnFloor())
    velocity.Y = JumpVelocity;
2.5 Player.cs ar saglabātu priekšmetu loģiku — pilns fails salīdzināšanai

Lejupielādēt Player.cs. Aizstāj tikai atbilstošā faila saturu; neveido otru tāda paša nosaukuma klasi.

using Godot;

public enum PickupType { Coin, Gem, Key }

public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;
    [Export] public float Gravity = 1200.0f;
    [Export] public float JumpVelocity = -550.0f;

    public int Score { get; private set; } = 0;
    public bool HasKey { get; private set; } = false;
    public bool IsActive { get; set; } = true;

    public override void _PhysicsProcess(double delta)
    {
        if (!IsActive)
        {
            Velocity = Vector2.Zero;
            return;
        }

        Vector2 velocity = Velocity;
        if (!IsOnFloor())
            velocity.Y += Gravity * (float)delta;

        if (Input.IsActionJustPressed("jump") && IsOnFloor())
            velocity.Y = JumpVelocity;

        velocity.X = Input.GetAxis("move_left", "move_right") * Speed;
        Velocity = velocity;
        MoveAndSlide();
    }

    public void OnPickup(PickupType type)
    {
        if (!IsActive) return;

        switch (type)
        {
            case PickupType.Coin:
                Score += 1;
                break;
            case PickupType.Gem:
                Score += 5;
                break;
            case PickupType.Key:
                HasKey = true;
                break;
        }

        GD.Print($"Punkti: {Score}; atslēga: {HasKey}");
    }
}

Gatavs, kad: varonis lec augšup, piezemējas un nevar atkārtoti lēkt gaisā.

3. uzdevums -

Izveido pārvaramu ceļu līdz atslēgai

  1. Palaid Level1 un ar lēcieniem sasniedz Platform1, Platform2 un Platform3. Uz pēdējās savāc Key. Pirmajai platformai lec pretī jau no sākuma pozīcijas, turot D un nospiežot Space: sākot lēcienu tieši zem platformas, atsitīsies pret tās apakšu. Pārbaudi arī, ka joprojām vari savākt Coin un Gem.
  2. Ar Gravity 1200 un JumpVelocity -550 teorētiskais lēciena augstums ir ap 550² / (2 × 1200) ≈ 126 px. Dotās platformas paceļas par 90 px; starp blakus platformu malām ir 40 px. Atstāj rezervi, lai lēciens nebūtu jāizpilda perfekti.
  3. Ja veido savu izkārtojumu, katru jauno pāreju uzreiz izspēlē no iepriekšējās platformas. Maini vienu parametru vai vienas platformas vietu reizē.
  4. Apzināti noej aiz grīdas kreisās vai labās malas. Šodien spēli apturi un palaid no jauna; 2.6 stundā kritiens rādīs zaudējumu un R atjaunos visu līmeni.
  5. Saglabā īsu video ar maršrutu līdz atslēgai un README.md ieraksti izmantotos Speed, Gravity, JumpVelocity.

Gatavs, kad: atslēga un visi punktu priekšmeti ir sasniedzami ar A/D un Space; projektā paliek strādājošas, pārbaudītas vērtības.

Papildu uzdevums — mainīgs lēciena augstums un coyote time

Saglabā strādājošo versiju Git. Klasei pievieno private double coyote = 0.0;. Esošajā _PhysicsProcess aizstāj lēciena if ar zemāk doto bloku, pirms Velocity piešķiršanas. Coyote laiku pēc lēciena patērē, lai nevarētu palēkt vēlreiz tajā pašā tolerances logā.

if (IsOnFloor()) coyote = 0.1;
else coyote = System.Math.Max(0.0, coyote - delta);

if (Input.IsActionJustPressed("jump") && coyote > 0.0)
{
    velocity.Y = JumpVelocity;
    coyote = 0.0;
}
if (Input.IsActionJustReleased("jump") && velocity.Y < 0)
    velocity.Y *= 0.5f;

Pārbaudi īsu un ilgu Space piespiedienu, lēcienu uzreiz pēc malas un divus ātrus nospiedienus gaisā. Otrs lēciens nedrīkst izdoties. Vēlreiz pārbaudi, ka ceļš līdz atslēgai ir pārvarams.
