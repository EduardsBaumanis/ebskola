SR 2.4.14. Vadības struktūras SR 2.4.13. Data type (datu tipi)

Teorija: gravitācijas paātrinājums, impulss un balsta pārbaude

Gravitācija kā vertikāls paātrinājums

Brīvā kritienā objekts nepārvietojas ar nemainīgu ātrumu — katrā sekundē tā vertikālais ātrums pieaug par noteiktu lielumu jeb paātrinājumu. Tā kā 2D ekrāna koordinātu sistēmā Y ass ir vērsta uz leju, krišanu simulē, katrā fizikas solī pieskaitot pozitīvu skaitli vertikālajam ātrumam: velocity.Y += Gravity * (float)delta (jo lielāka Gravity vērtība, jo straujāk ķermenis paātrinās lejup):

[Export] public float Gravity = 1200.0f; // Paātrinājums lejup (px/s²)

// Katrā brīvā kritiena solī vertikālais ātrums Y pieaug uz leju
if (!IsOnFloor())
    velocity.Y += Gravity * (float)delta;

Vertikālais impulss un mīnusa zīme kustībai augšup

Atšķirībā no pakāpeniskas krišanas, atgrūšanās no pamatnes piešķir ķermenim tūlītēju sākuma ātrumu pretējā virzienā — uz augšu. Tāpēc vertikālā impulsa vērtībai priekšā ir mīnusa zīme (piemēram, -550.0f pikseļi sekundē; skaitlis -650 dod stiprāku grūdienu un augstāku pacēlumu nekā -550).

Pēc atgrūšanās gravitācija katrā nākamajā kadrā šo negatīvo ātrumu pakāpeniski samazina līdz 0 (trajektorijas augstākais punkts) un pēc tam sāk vilkt ķermeni atpakaļ uz leju — tieši tāpat kā vertikāli gaisā pamestam priekšmetam reālajā pasaulē:

[Export] public float PushImpulse = -550.0f; // Negatīvs Y = kustība uz augšu

// Piešķir tūlītēju ātrumu augšup; turpmākajos kadros Gravity to maina:
// -550 (startā) → ... → 0 (augstākais punkts) → +400 (kritiens lejup)
velocity.Y = PushImpulse;

Balsta pārbaude (IsOnFloor()) un ass nolasīšana (Input.GetAxis)

CharacterBody2D režīmā Grounded metode IsOnFloor() nosaka, vai ķermenis pēc pēdējā MoveAndSlide() soļa saskaras ar atbalsta virsmu zem tā. Apvienojot vienreizēju taustiņa nospiešanu ar šo pārbaudi (Input.IsActionJustPressed(...) && IsOnFloor()), atgrūšanās notiek tikai no pamatnes, neļaujot atkārtoti atsperties gaisā.

Horizontālās ass apstrādei metode Input.GetAxis("negativa_darbiba", "pozitiva_darbiba") vienā izteiksmē atgriež virzienu no -1 līdz 1 (vai 0, ja netiek turēts neviens virziens vai abi pretējie tiek turēti vienlaikus):

public override void _PhysicsProcess(double delta)
{
    Vector2 velocity = Velocity;

    if (!IsOnFloor())
        velocity.Y += Gravity * (float)delta;

    if (Input.IsActionJustPressed("push_up") && IsOnFloor())
        velocity.Y = PushImpulse; // Nostrādā tikai uz atbalsta virsmas

    velocity.X = Input.GetAxis("move_left", "move_right") * Speed;
    Velocity = velocity;
    MoveAndSlide(); // Izpilda kustību un atjauno IsOnFloor() stāvokli
}

Pievieno vienu lēcienu no zemes

Kur strādāt: Lēciena pārbaudi ievieto failā Scripts/Player.cs metodē _PhysicsProcess(double delta); lēciena spēku Jump Velocity eksperimentam maini scēnā Scenes/Level1.tscn mezgla Player Inspector panelī.

  1. Pievieno lēciena rindas failā Scripts/Player.cs: atver Scripts/Player.cs un metodē _PhysicsProcess(double delta) komentāra // 2. uzdevumā šeit pievienosi lēcienu! vietā ievieto: 
    if (Input.IsActionJustPressed("jump") && IsOnFloor())
    velocity.Y = JumpVelocity;
  2. Pārbaudi lēcienu no grīdas: saglabā Scripts/Player.cs, nospied Build un F5. Kad varonis stāv uz grīdas, nospied Space — tam jāuzlec gaisā un jāpiezemējas atpakaļ uz grīdas.
  3. Pārbaudi IsOnFloor() ierobežojumu: paturi Space nospiestu (varonis nedrīkst lēkāt nepārtraukti) un pamēģini nospiest Space lēciena laikā gaisā (dubultlēcienam gaisā nav jānotiek).

2.5 Player.cs ar kustību, lēcienu un punktiem - pilns fails

Lejupielādēt Player.cs. Atver failu Scripts/Player.cs un salīdzini vai aizstāj tā saturu ar šo kodu.

using Godot;

public enum PickupType { Coin, Gem, Key }

public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;
    [Export] public float Gravity = 1200.0f;
    [Export] public float JumpVelocity = -550.0f;

    public int Score { get; private set; } = 0;
    public bool HasKey { get; private set; } = false;
    public bool IsActive { get; set; } = true;

    public override void _PhysicsProcess(double delta)
    {
        if (!IsActive)
        {
            Velocity = Vector2.Zero;
            return;
        }

        Vector2 velocity = Velocity;
        if (!IsOnFloor())
            velocity.Y += Gravity * (float)delta;

        if (Input.IsActionJustPressed("jump") && IsOnFloor())
            velocity.Y = JumpVelocity;

        velocity.X = Input.GetAxis("move_left", "move_right") * Speed;
        Velocity = velocity;
        MoveAndSlide();
    }

    public void OnPickup(PickupType type)
    {
        if (!IsActive) return;

        switch (type)
        {
            case PickupType.Coin:
                Score += 1;
                break;
            case PickupType.Gem:
                Score += 5;
                break;
            case PickupType.Key:
                HasKey = true;
                break;
        }

        GD.Print($"Punkti: {Score}; atslēga: {HasKey}");
    }
}

Gatavs, kad: varonis ar Space lec augšup, piezemējas uz platformām un nevar atkārtoti atsperties gaisā.

3. uzdevums

Izveido pārvaramu ceļu līdz atslēgai

Kur strādāt: Platformu (Platform1..3) un priekšmetu pozīcijas vajadzības gadījumā pielāgo scēnā Scenes/Level1.tscn; novērojumus par lēciena augstumu ieraksti failā README.md.

  1. Izspēlē maršrutu līdz atslēgai: nospied F5 un ar A/D un Space uzlec uz Platform1, no tās uz Platform2 un tālāk uz Platform3, kur atrodas Key. Atceries: lec uz platformu ar nelielu ieskrējienu no sāniem, nevis stāvot tieši zem tās (citādi varonis atsitīsies pret platformas apakšu).
  2. Pielāgo platformu pozīciju scēnā Scenes/Level1.tscn (ja nepieciešams): ja kāda platforma ir par augstu vai par tālu, apturi spēli ar F8, cilnē Level1.tscn atlasi attiecīgo platformu (Platform1, Platform2 vai Platform3) un Inspector → Transform → Position nedaudz pamaini x vai y (lielāks y skaitlis nolaiž platformu zemāk). Saglabā un uzreiz pārbaudi ar F5.
  3. Pārbaudi visus priekšmetus un kritienu aiz malas: pārliecinies, ka ar lēcieniem vari savākt visas 4 monētas, Gem un Key (kopā 9 punkti un atslēga: True). Pamēģini arī noiet aiz grīdas labās vai kreisās malas (2.6. stundā kritienam zem Y > 800 pievienosi automātisku zaudējumu un R taustiņu).
  4. Sagatavo pierādījumus un pieraksti README.md: uzņem Inspector ekrānuzņēmumu ar Player laukiem Speed, Gravity un Jump Velocity, ieraksti īsu video ar uzlēkšanu līdz atslēgai un failā README.md vienā teikumā apraksti atšķirību starp Jump Velocity = -400 un -650.

Gatavs, kad: atslēga un visi punktu priekšmeti scēnā Scenes/Level1.tscn ir sasniedzami ar A/D un Space, un novērojumi ir saglabāti README.md.

Papildu uzdevums - īss un garš lēciens

Kur strādāt: Papildini failu Scripts/Player.cs — pievieno lauku private double coyote = 0.0; klases sākumā un papildini lēciena daļu metodē _PhysicsProcess(double delta).

Vispirms saglabā strādājošo pamatversiju Git. Tad failā Scripts/Player.cs zem JumpVelocity rindas pievieno private double coyote = 0.0;, bet metodē _PhysicsProcess(double delta) 2. uzdevuma divas lēciena rindas aizstāj ar kodu zemāk (tas pievieno 0,1 s „coyote time” pēc malas šķērsošanas un zemāku lēcienu, ja Space atlaiž ātri):

if (IsOnFloor()) coyote = 0.1;
else coyote = System.Math.Max(0.0, coyote - delta);

if (Input.IsActionJustPressed("jump") && coyote > 0.0)
{
    velocity.Y = JumpVelocity;
    coyote = 0.0;
}
if (Input.IsActionJustReleased("jump") && velocity.Y < 0)
    velocity.Y *= 0.5f;

Saglabā Scripts/Player.cs, nospied Build un ar F5 pārbaudi īsu un garu Space nospiedienu, kā arī to, ka gaisā joprojām nevar izlēkt otro reizi.

Ko sagatavo

Stundas mērķis: varonis lec pa platformām un var savākt atslēgu.

GitHub krātuvē jābūt:

  • Player.cs ar vienu _PhysicsProcess, gravitāciju, lēcienu un OnPickup.
  • Inspector ekrānuzņēmums, video ar ceļu līdz atslēgai un README.md novērojums par lēciena augstumu.

Saglabā visu projektu: project.godot, .csproj, scēnas, skriptus un izmantotos attēlus. .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.

Kā iesniedz: saglabā izmaiņas Git un nosūti tās uz GitHub tāpat kā 1. tēmā (commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi)). Skolotāja norādītajā vietā iesniedz GitHub krātuves saiti; README.md un pārbaudes pierādījumiem jābūt krātuvē.
