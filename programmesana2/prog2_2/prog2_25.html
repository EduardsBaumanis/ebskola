Teorija: gravitācijas paātrinājums, impulss un balsta pārbaude

Gravitācija kā vertikāls paātrinājums

Brīvā kritienā objekts nepārvietojas ar nemainīgu ātrumu — katrā sekundē tā vertikālais ātrums pieaug par noteiktu lielumu jeb paātrinājumu. Tā kā 2D ekrāna koordinātu sistēmā Y ass ir vērsta uz leju, krišanu simulē, katrā fizikas solī pieskaitot pozitīvu skaitli vertikālajam ātrumam: velocity.Y += Gravity * (float)delta (jo lielāka Gravity vērtība, jo straujāk ķermenis paātrinās lejup):

[Export] public float Gravity = 1200.0f; // Paātrinājums lejup (px/s²)

// Katrā brīvā kritiena solī vertikālais ātrums Y pieaug uz leju
if (!IsOnFloor())
    velocity.Y += Gravity * (float)delta;

Vertikālais impulss un mīnusa zīme kustībai augšup

Atšķirībā no pakāpeniskas krišanas, atgrūšanās no pamatnes piešķir ķermenim tūlītēju sākuma ātrumu pretējā virzienā — uz augšu. Tāpēc vertikālā impulsa vērtībai priekšā ir mīnusa zīme (piemēram, -550.0f pikseļi sekundē; skaitlis -650 dod stiprāku grūdienu un augstāku pacēlumu nekā -550).

Pēc atgrūšanās gravitācija katrā nākamajā kadrā šo negatīvo ātrumu pakāpeniski samazina līdz 0 (trajektorijas augstākais punkts) un pēc tam sāk vilkt ķermeni atpakaļ uz leju — tieši tāpat kā vertikāli gaisā pamestam priekšmetam reālajā pasaulē:

[Export] public float PushImpulse = -550.0f; // Negatīvs Y = kustība uz augšu

// Piešķir tūlītēju ātrumu augšup; turpmākajos kadros Gravity to maina:
// -550 (startā) → ... → 0 (augstākais punkts) → +400 (kritiens lejup)
velocity.Y = PushImpulse;

Balsta pārbaude (IsOnFloor()) un ass nolasīšana (Input.GetAxis)

CharacterBody2D režīmā Grounded metode IsOnFloor() nosaka, vai ķermenis pēc pēdējā MoveAndSlide() soļa saskaras ar atbalsta virsmu zem tā. Apvienojot vienreizēju taustiņa nospiešanu ar šo pārbaudi (Input.IsActionJustPressed(...) && IsOnFloor()), atgrūšanās notiek tikai no pamatnes, neļaujot atkārtoti atsperties gaisā.

Horizontālās ass apstrādei metode Input.GetAxis("negativa_darbiba", "pozitiva_darbiba") vienā izteiksmē atgriež virzienu no -1 līdz 1 (vai 0, ja netiek turēts neviens virziens vai abi pretējie tiek turēti vienlaikus):

public override void _PhysicsProcess(double delta)
{
    Vector2 velocity = Velocity;

    if (!IsOnFloor())
        velocity.Y += Gravity * (float)delta;

    if (Input.IsActionJustPressed("push_up") && IsOnFloor())
        velocity.Y = PushImpulse; // Nostrādā tikai uz atbalsta virsmas

    velocity.X = Input.GetAxis("move_left", "move_right") * Speed;
    Velocity = velocity;
    MoveAndSlide(); // Izpilda kustību un atjauno IsOnFloor() stāvokli
}

2.5 Player.cs ar kustību, lēcienu un punktiem — pilns fails

Lejupielādēt Player.cs. Atver esošo tāda paša nosaukuma failu un aizstāj tā saturu ar šo kodu.

using Godot;

public enum PickupType { Coin, Gem, Key }

public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;
    [Export] public float Gravity = 1200.0f;
    [Export] public float JumpVelocity = -550.0f;

    public int Score { get; private set; } = 0;
    public bool HasKey { get; private set; } = false;
    public bool IsActive { get; set; } = true;

    public override void _PhysicsProcess(double delta)
    {
        if (!IsActive)
        {
            Velocity = Vector2.Zero;
            return;
        }

        Vector2 velocity = Velocity;
        if (!IsOnFloor())
            velocity.Y += Gravity * (float)delta;

        if (Input.IsActionJustPressed("jump") && IsOnFloor())
            velocity.Y = JumpVelocity;

        velocity.X = Input.GetAxis("move_left", "move_right") * Speed;
        Velocity = velocity;
        MoveAndSlide();
    }

    public void OnPickup(PickupType type)
    {
        if (!IsActive) return;

        switch (type)
        {
            case PickupType.Coin:
                Score += 1;
                break;
            case PickupType.Gem:
                Score += 5;
                break;
            case PickupType.Key:
                HasKey = true;
                break;
        }

        GD.Print($"Punkti: {Score}; atslēga: {HasKey}");
    }
}

Gatavs, kad: varonis lec augšup, piezemējas un nevar atkārtoti lēkt gaisā.

3. uzdevums -

Izveido pārvaramu ceļu līdz atslēgai

Kur strādāt: Platformu un priekšmetu novietojumu pielāgo Scenes/Level1.tscn; lēciena novērojumus pieraksti README.md.

  1. Nospied F5 un ar D un Space sasniedz Platform1, Platform2 un Platform3. Uz pēdējās savāc Key. Pirmajai platformai lec pretī jau no sākuma vietas: tieši zem tās varonis atsitīsies pret apakšu.
  2. Ja platformu nevar sasniegt, apturi spēli. Scene panelī atlasi šo platformu un Inspector sadaļā Transform → Position pārvieto to tuvāk vai zemāk. Lielāks y skaitlis pārvieto platformu uz leju. Maini vienu platformu reizē un uzreiz izmēģini lēcienu.
  3. Pārbaudi, ka vari savākt arī visas monētas un Gem. Tad izmēģini noiet aiz grīdas malas. Pagaidām atgriezies sākumā ar Stop (F8) un Run Project (F5); nākamajā stundā tam pievienosi R.
  4. Uzņem Inspector ekrānuzņēmumu ar Player laukiem Speed, Gravity un Jump Velocity. Saglabā īsu video, kurā sasniedz atslēgu. README.md pieraksti, kādu atšķirību redzēji starp -400 un -650.

Gatavs, kad: atslēga un visi punktu priekšmeti ir sasniedzami ar A/D un Space; projektā paliek strādājošas, pārbaudītas vērtības.

Papildu uzdevums — īss un garš lēciens

Kur strādāt: Papildini Scripts/Player.cs: lauku coyote pievieno klasē zem JumpVelocity, bet abas lēciena rindas metodē _PhysicsProcess() aizstāj ar papildu uzdevuma kodu.

Vispirms saglabā strādājošo versiju Git. Zem JumpVelocity (lēciena ātrums) rindas pievieno private double coyote = 0.0;. Abas lēciena rindas no 2. uzdevuma aizstāj ar kodu zemāk. Tas ļaus lēkt zemāk, ja ātri atlaidīsi Space, un vēl 0,1 sekundi pēc platformas malas šķērsošanas. Pēc lēciena laiku atjauno uz 0, lai nevarētu lēkt vēlreiz gaisā.

if (IsOnFloor()) coyote = 0.1;
else coyote = System.Math.Max(0.0, coyote - delta);

if (Input.IsActionJustPressed("jump") && coyote > 0.0)
{
    velocity.Y = JumpVelocity;
    coyote = 0.0;
}
if (Input.IsActionJustReleased("jump") && velocity.Y < 0)
    velocity.Y *= 0.5f;

Pārbaudi īsu un ilgu Space piespiedienu, lēcienu uzreiz pēc malas un divus ātrus nospiedienus gaisā. Otrs lēciens nedrīkst izdoties. Vēlreiz pārbaudi, ka ceļš līdz atslēgai ir pārvarams.
