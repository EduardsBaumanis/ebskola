Teorija: Gravitācija un jump mehānika

Klasiska 2D platformas mehānika ietver:

  • Gravitāciju - y velocity pieaug katrā kadrā.
  • Jump - viena reize y velocity tiek piešķirta negatīva vērtība.
  • Ground check - pārbaude, vai spēlētājs ir uz zemes.
  • Coyote time - neliela tolerance, ja spēlētājs nupat nokrita no malas.
class Player : public CharacterBody2D {
private:
    const float SPEED = 300.0f;
    const float JUMP_FORCE = -550.0f;  // negatīvs = uz augšu
    const float GRAVITY = 1500.0f;
    Vector2 velocity_internal;

public:
    void _physics_process(double delta) override {
        // Gravitācija
        if (!is_on_floor()) {
            velocity_internal.y += GRAVITY * delta;
        }

        // Jump
        Input *input = Input::get_singleton();
        if (input->is_action_just_pressed("jump") && is_on_floor()) {
            velocity_internal.y = JUMP_FORCE;
        }

        // Horizontālā kustība
        float dir = input->get_axis("move_left", "move_right");
        velocity_internal.x = dir * SPEED;

        set_velocity(velocity_internal);
        move_and_slide();
        velocity_internal = get_velocity();
    }
};

Praktiskie uzdevumi

1. uzdevums - Pievieno gravitāciju

Beigās tavs varonis kritīs uz leju, līdz atsitīsies pret grīdu.

  1. Pievieno klasei konstanti const float GRAVITY = 1200.0f;.
  2. Pievieno lauku Vector2 velocity_internal;.
  3. Ieraksti _physics_process metodē if (!is_on_floor()) { velocity_internal.y += GRAVITY * delta; }.
  4. Nodod ātrumu ar set_velocity(velocity_internal); un izsauc move_and_slide();.
  5. Atjauno pēc tam velocity_internal = get_velocity();.
  6. Pievieno scēnai grīdu kā StaticBody2D ar sadursmes formu.
  7. Kompilē un palaid - varonim jākrīt un jāapstājas uz grīdas.

Gatavs, kad: varonis krīt uz leju un apstājas uz grīdas, nevis krīt bezgalīgi.

2. uzdevums - Pievieno lēcienu un zemes pārbaudi

Beigās varonis lēks tikai tad, kad stāv uz zemes.

  1. Izveido Input Map darbību jump ar atstarpes taustiņu.
  2. Pievieno konstanti const float JUMP_FORCE = -550.0f;.
  3. Ieraksti if (input->is_action_just_pressed("jump") && is_on_floor()) { velocity_internal.y = JUMP_FORCE; }.
  4. Kompilē un pārbaudi lēcienu.
  5. Noņem nosacījumu is_on_floor() un pamēģini lēkt gaisā.
  6. Pieraksti, kas notiek bez šīs pārbaudes.
  7. Ieliec pārbaudi atpakaļ un nomaini JUMP_FORCE uz pozitīvu skaitli, lai redzētu, kas notiek.

Gatavs, kad: varonis lec tikai no zemes, un tu vari izskaidrot, kāpēc lēciena spēks ir negatīvs.

3. uzdevums - Pievieno mainīgu lēciena augstumu un coyote time

Beigās lēciens jutīsies daudz labāk - kā īstā platformas spēlē.

  1. Pievieno nosacījumu: ja jump tiek atlaists un velocity_internal.y < 0, samazini y uz pusi.
  2. Kompilē un salīdzini īsu un garu atstarpes piespiedienu.
  3. Pievieno lauku double coyote = 0.0;.
  4. Iestati to uz 0.1, kad varonis ir uz zemes, citādi samazini ar delta.
  5. Nomaini lēciena nosacījumu uz coyote > 0.0 vietā is_on_floor().
  6. Pārbaudi: noej no platformas malas un uzreiz nospied lēcienu.
  7. Pieraksti, kāpēc šī neliela tolerance padara spēli patīkamāku.

Gatavs, kad: īss piespiediens dod zemu lēcienu, garš - augstu, un varonis vēl var palēkt tieši pēc nokāpšanas no malas.

Papildu uzdevums - Pievieno dubulto lēcienu

Ja pamatdarbs ir gatavs, ļauj palēkt vēlreiz gaisā.

  1. Pievieno lauku int jumps_left = 1;.
  2. Atjauno to uz 1, kad varonis pieskaras zemei.
  3. Samazini par vienu pēc katra lēciena.
  4. Atļauj lēkt, kamēr jumps_left > 0.
  5. Pārbaudi, ka gaisā var palēkt tieši vienu papildu reizi.

Gatavs, kad: varonis var palēkt divas reizes, bet trešo reizi gaisā - ne.

Biežākās kļūdas

  • Spēlētājs lec dubultjump: Aizmirsts is_on_floor() pārbaude.

Koda piemērs (paplašināts)

void Player::_physics_process(double delta) {
    Input *input = Input::get_singleton();

    // Gravitācija
    if (!is_on_floor()) {
        velocity_internal.y += GRAVITY * delta;
    }

    // Jump ar variable height
    if (input->is_action_just_pressed("jump") && is_on_floor()) {
        velocity_internal.y = JUMP_FORCE;
    }
    if (input->is_action_just_released("jump") && velocity_internal.y < 0) {
        velocity_internal.y *= 0.5f;
    }

    // Horizontāla
    float dir = input->get_axis("move_left", "move_right");
    velocity_internal.x = dir * SPEED;

    set_velocity(velocity_internal);
    move_and_slide();
    velocity_internal = get_velocity();
}
Spēlētājs lec dabīgi, ar variable height, gravitāciju 1500, jump force 550.
