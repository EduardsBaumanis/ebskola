2.6 Noslēguma projekts: Platformas spēle

Stundas uzdevums: Izveidot pilnvērtīgu 2D platformas spēli ar 3 līmeņiem, savācamiem un finiša bandieri.

SR 2.4.1. Problēmas dekompozīcija SR 2.4.7. UI SR 2.4.14. Vadības struktūras SR 2.4.15. Modulāras programmas

80 min plāns: Ievads un kritēriju pārruna (~10 min) · 1. uzdevums (~20 min) - uzbūvē pirmo līmeni · 2. uzdevums (~25 min) - pievieno ienaidnieku un savācamos · 3. uzdevums (~20 min) - pievieno finišu, HUD un līmeņu maiņu · Iesniegšana (~5 min).

Pirms sāc: šis ir 2. tēmas noslēguma projekts. Varoņa mehānika jau ir gatava no 2.5 stundas - šodien uzbūvēsi ap to spēli. Sāc ar VIENU līmeni; pārējos pievieno tikai tad, ja paliek laiks.

Teorija: Spēles apraksts un arhitektūra

Platformas spēle ar šādām funkcijām:

  • 3 līmeņi ar augošu sarežģītību.
  • Spēlētājs ar gravitāciju, jump, variable height un coyote time.
  • Savācami punktu žetoni, uzlīmes un finiša kartītes.
  • Ienaidnieki, kas pārvietojas patrol ceļā.
  • Finiša bandieris katrā līmenī - pārejas uz nākamo.
  • HUD ar HP, score, atlikušo laiku.

Praktiskie uzdevumi

1. uzdevums - Uzbūvē pirmo līmeni

Beigās tev būs izejams līmenis ar platformām.

  1. Izveido jaunu scēnu level1.tscn ar Node2D sakni.
  2. Ievelc tajā savu varoņa scēnu no 2.5 stundas.
  3. Pievieno grīdu un vismaz trīs platformas dažādos augstumos.
  4. Novieto platformas tā, lai starp tām varētu pārlēkt.
  5. Palaid un izej līmeni no sākuma līdz beigām.
  6. Pārvieto platformu, kas ir par tālu, lai lēciens tomēr izdotos.
  7. Saglabā scēnu.

Gatavs, kad: tu vari izlēkt no līmeņa sākuma līdz galam, nevienu reizi neiekrītot ārpus laukuma.

2. uzdevums - Pievieno ienaidnieku un savācamos

Beigās līmenī būs gan draudi, gan atlīdzība.

  1. Izveido C++ klasi Enemy, kas manto no CharacterBody2D.
  2. Uzraksti patruļas kustību: kad sasniedz robežu, apgriez virzienu.
  3. Pievieno ienaidniekam Area2D, kas atņem varonim dzīvību.
  4. Ievelc līmenī vismaz piecas monētas no 2.4 stundas.
  5. Pievieno spēlētāja klasei laukus int hp = 3; un int score = 0;.
  6. Kompilē un pārbaudi, ka ienaidnieks patrulē un atņem HP.
  7. Pārbaudi, ka monētas palielina rezultātu.

Gatavs, kad: ienaidnieks patrulē starp divām robežām, pieskaroties atņem HP, un monētas palielina rezultātu.

3. uzdevums - Pievieno finišu, HUD un līmeņu maiņu

Beigās spēle būs pabeidzama un rādīs spēlētāja stāvokli.

  1. Pievieno līmeņa galā Area2D ar nosaukumu Finiss.
  2. Pievieno ekrāna augšā Label mezglus HP un rezultātam.
  3. Atjaunini tos katrā kadrā ar aktuālajām vērtībām.
  4. Izveido C++ klasi Game ar lauku int current_level = 1;.
  5. Uzraksti metodi, kas pārslēdz uz nākamo līmeni, kad sasniegts finišs.
  6. Parādi uzvaras paziņojumu, kad izieti visi tavi līmeņi.
  7. Veic commit un push.

Gatavs, kad: izejot līmeni, spēle pāriet uz nākamo vai parāda uzvaru, un HUD visu laiku rāda pareizu HP un rezultātu.

Papildu uzdevums - Pievieno otro līmeni

Ja pamatdarbs ir gatavs, paplašini spēli.

  1. Izveido level2.tscn ar grūtākām platformām.
  2. Pievieno tajā vismaz divus ienaidniekus.
  3. Pārbaudi, ka pāreja no pirmā līmeņa strādā.
  4. Pārbaudi, ka rezultāts un HP saglabājas starp līmeņiem.
  5. Izej abus līmeņus pēc kārtas.

Gatavs, kad: abus līmeņus var izspēlēt pēc kārtas, un rezultāts pārejot netiek nomests uz nulli.

Ko iesniedz skolotājam

Stundas mērķis: Tev ir izspēlējama platformas spēle: varonis ar gravitāciju un lēcienu, vismaz viens līmenis ar platformām, patrulējošs ienaidnieks, savācamas monētas, HUD ar HP un rezultātu, un finišs, kas noved pie uzvaras vai nākamā līmeņa.

Iesniedzamais:

  1. Saite uz GitHub krātuvi ar visu projektu.
  2. Video, kurā izspēlē līmeni no sākuma līdz finišam, savācot vismaz vienu monētu un saskaroties ar ienaidnieku.
  3. Faili player.cpp, enemy.cpp un game.cpp.
  4. Burtnīcā: kas tavā spēlē bija visgrūtāk uztaisāms un kā tu to atrisināji.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un video skolotāja norādītajā vietā. Spēlei jābūt palaižamai no tavas krātuves.

Biežākās kļūdas

  • Scēnas pāreja crash: Pārliecinies, ka mērķa scēnas ceļš ir pareizs.
  • Score reset starp līmeņiem: Game klase jābūt Autoload (Project → Autoload).
  • Patrol AI iet ārpus zonām: Pārbaudi Marker2D pozīcijas līmenī.

class Game : public Node {
    GDCLASS(Game, Node)
private:
    int score = 0;
    int current_level = 1;
public:
    void load_next_level() {
        current_level++;
        if (current_level > 3) {
            UtilityFunctions::print("Game complete! Score: ", score);
            get_tree()->quit();
            return;
        }
        String scene_path = "res://levels/Level" + String::num(current_level) + ".tscn";
        get_tree()->change_scene_to_file(scene_path);
    }
    void add_score(int amount) { score += amount; }
};
