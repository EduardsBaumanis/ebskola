Teorija: centrālā stāvokļa vadība, globālās koordinātes un sargu nosacījumi

Vairāku zonu un saskarnes koordinācija vienā vadības klasē

Kad scēnā darbojas vairākas neatkarīgas Area2D saskares zonas, pašām zonām nav jāpārzina visi sistēmas noteikumi — galvenās scēnas vadības klase metodē _Ready() var pieslēgties bērnmezglu BodyEntered signāliem un vienuviet lemt gan par stāvokļa maiņu, gan par CanvasLayer saskarnes tekstu (Label) atjaunināšanu.

Ikdienā tas darbojas kā ēkas apsardzes vadības pults: durvju un dūmu sensori tikai ziņo par robežas šķērsošanu, bet centrālais bloks pārbauda, vai lietotājam ir derīga piekļuves karte, un izlemj — atvērt ieeju, parādīt brīdinājumu vai ieslēgt trauksmi:

public override void _Ready()
{
    // Vadības klase vienuviet pieslēdzas vairāku Area2D zonu signāliem
    GetNode<Area2D>("IeejasZona").BodyEntered += KadSasniedzIeeju;
    GetNode<Area2D>("BistamaZona").BodyEntered += KadSasniedzRobezu;
}

private void KadSasniedzIeeju(Node2D body)
{
    if (body != lietotajs || IsEnded) return;
    pazinojumsLabel.Text = lietotajs.IrKarte ? "Piekļuve atļauta!" : "Nepieciešama karte.";
}

Lokālā Position pret pasaules GlobalPosition

Katram 2D mezglam ir divi koordinātu pieraksti: Position glabā nobīdi attiecībā pret tiešo vecākmezglu, savukārt GlobalPosition atgriež objekta faktisko atrašanās vietu visas scēnas kopējā koordinātu telpā (līdzīgi kā kabineta numurs stāvā pret pilnu ēkas GPS koordinātu). Pārbaudot, vai kustīgs objekts nav šķērsojis ārējo darba telpas robežu (piemēram, GlobalPosition.Y > robeža), vienmēr izmanto GlobalPosition, lai mērījums paliktu precīzs neatkarīgi no mezglu grupējuma:

// Ja vecākmezgls Grupa atrodas (500, 200) un bērnmezgla Position ir (40, 10),
// tad bērnmezgla GlobalPosition visas scēnas telpā ir (540, 210).
if (!IsEnded && objekts.GlobalPosition.Y > 800.0f)
{
    NoslegtProcesu("Šķērsota darba telpas apakšējā robeža.");
}

Procesa noslēguma fiksēšana un aizsardzības nosacījumi

Kad programma sasniedz gala stāvokli, loģiskais karodziņš (piemēram, bool IsEnded = true;) kopā ar agru atgriešanās pārbaudi metodes sākumā (if (IsEnded) return;) kalpo kā drošības slēdzis. Tas neļauj pēc procesa beigām vienlaikus nostrādāt citiem notikumiem vai turpināties kustībai un skaitītāju izmaiņām. Savukārt GetTree().ReloadCurrentScene() pilnībā pārlādē scēnu, automātiski atjaunojot arī visus ar QueueFree() iepriekš noņemtos mezglus:

public bool IsEnded { get; private set; } = false;

private void NoslegtProcesu(string zinojums)
{
    if (IsEnded) return; // Sarga nosacījums novērš atkārtotu izpildi

    IsEnded = true;
    objekts.IsActive = false;
    objekts.Velocity = Vector2.Zero;
    pazinojumsLabel.Text = zinojums;
}

Pievieno finišu, bīstamo zonu un tekstus

Kur strādāt: Finišu, bīstamo zonu un HUD veido Scenes/Level1.tscn. Izveido Scripts/Level.cs ar pilno piemēra kodu un piesaisti to Level1 saknei.

Kas jāredz gatavajā spēlē: spēles logā ir vadības taustiņi, mērķis un punktu skaits; varonis var pārvarēt trīs platformas un savākt piecus punktu priekšmetus un atslēgu. Finišs (Finish) ar atslēgu rāda uzvaru, bet saskare ar bīstamo zonu (Hazard) vai kritiens aiz grīdas malas rāda zaudējumu; ar R visu līmeni sāk no jauna (punkti ir 0 un priekšmeti atkal savās vietās). Visus šos objektus un HUD tekstus vadīs Level.cs.

  1. Atver Level1.tscn. Scene panelī atlasi Level1, spied + un pievieno Area2D (2D saskares zona). Nosauc to Finish. Inspector sadaļā Transform → Position ievadi (850,590).
  2. Atlasītajam Finish pievieno CollisionShape2D (2D sadursmes forma): Shape → New RectangleShape2D (jauna 2D taisnstūra forma), klikšķis uz formas, Size = (48,100). Atkal atlasi Finish un pievieno Polygon2D (2D daudzstūris) ar nosaukumu Visual: Data → Polygon punkti (-24,-50), (24,-50), (24,50), (-24,50). Pie Color izvēlies zaļu krāsu.

  5. Atlasi Level1 un ar + pievieno CanvasLayer (zīmēšanas slānis), nosauc to HUD. Atlasi HUD un pievieno Label (teksta etiķete) ar nosaukumu Instructions. Atkārto, lai zem HUD būtu arī Status un Message. Tie rādīs tekstu spēles logā.

Atver Theme Overrides → Font Sizes, ieslēdz Font Size un ieraksti 20. Laukā Text vari ierakstīt “Pārbaude”, lai tekstu uzreiz redzētu 2D skatā; palaižot spēli, kods to aizstās.

2.6 Level.cs — pilns fails salīdzināšanai

Lejupielādēt Level.cs. Atver esošo tāda paša nosaukuma failu un aizstāj tā saturu ar šo kodu.

using Godot;

public partial class Level : Node2D
{
    [Export] public string GameTitle = "Bākas gaisma";
    [Export] public string Mission = "Atrodi dzelteno atslēgu un sasniedz zaļo bāku. Izvairies no sarkanās bedres!";
    [Export] public string WinText = "Bāka atkal spīd. Kuģi var atrast mājas!";
    [Export] public string LoseText = "Ceļojums pārtrūka. Mēģini vēlreiz!";
    [Export] public string LockedText = "Vispirms atrodi dzelteno atslēgu augšējā platformā.";

    private Player player;
    private Label status;
    private Label message;
    public bool GameEnded { get; private set; } = false;

    public override void _Ready()
    {
        player = GetNode<Player>("Player");
        status = GetNode<Label>("HUD/Status");
        message = GetNode<Label>("HUD/Message");
        GetNode<Label>("HUD/Instructions").Text =
            $"{GameTitle} | A/D vai ←/→: kustība | Space: lēciens | R: sākt no jauna";
        message.Text = Mission;
        GetNode<Area2D>("Finish").BodyEntered += OnFinishEntered;
        GetNode<Area2D>("Hazard").BodyEntered += OnHazardEntered;
        UpdateHud();
    }

    public override void _Process(double delta)
    {
        if (Input.IsActionJustPressed("restart"))
        {
            GetTree().ReloadCurrentScene();
            return;
        }

        if (!GameEnded && player.GlobalPosition.Y > 800)
            EndGame(false);

        UpdateHud();
    }

    private void UpdateHud()
    {
        string keyStatus = player.HasKey ? "ir" : "nav";
        status.Text = $"Punkti: {player.Score} | Atslēga: {keyStatus}";
    }

    private void OnFinishEntered(Node2D body)
    {
        if (body != player || GameEnded) return;

        if (player.HasKey)
            EndGame(true);
        else
            message.Text = LockedText;
    }

    private void OnHazardEntered(Node2D body)
    {
        if (body == player) EndGame(false);
    }

    private void EndGame(bool won)
    {
        if (GameEnded) return;
        GameEnded = true;
        player.IsActive = false;
        player.Velocity = Vector2.Zero;
        message.Text = (won ? WinText : LoseText) + " | Nospied R, lai spēlētu vēlreiz.";
        UpdateHud();
    }
}

2. uzdevums

Padari projektu par savu spēli

Kur strādāt: Noformējumu maini Scenes/Level1.tscn, Scenes/Player.tscn un Scenes/Pickup.tscn. Tekstu Atslēga: maini Scripts/Level.cs metodē UpdateHud(); pamatojumu raksti README.md.

  1. Izvēlies nosaukumu un uzraksti trīs īsus teikumus: kas ir varonis, ko viņš vēlas un kāpēc. Piemēram: “Robots meklē enerģijas kodolu. Tam jāatjauno bāka. Bez gaismas kuģi nevar atrast mājas.” Izdomā savu stāstu.
  2. Scene panelī atlasi Level1. Inspector laukā Game Title ieraksti spēles nosaukumu, Mission — mērķi, Win Text — uzvaras tekstu, Lose Text — zaudējuma tekstu, Locked Text — norādi, ja atslēgas vēl nav. Palaid ar F5 un pārbaudi tekstus.
  3. Maini vismaz trīs spēles daļu izskatu. Piemēram, atver Player.tscn, atlasi Visual un nomaini Color. Level1 cilnē tāpat vari mainīt platformu un finiša Visual krāsu vai Data → Polygon punktus.
  4. Ja vēlies izmantot savu attēlu, projekta mapē izveido Art un iekopē tajā PNG failu. Godot tas parādīsies FileSystem panelī. Attiecīgajam objektam ar + pievieno Sprite2D (2D attēla mezgls) un no FileSystem ievelc PNG tā Inspector laukā Texture. Pielāgo Sprite2D Transform → Scale; veco Visual paslēp ar acs ikonu Scene panelī. Paša Player, Ground vai Pickup laukā Scale atstāj (1,1). Atlasi CollisionShape2D un pielāgo tā Shape izmēru attēlam.
  5. Izvēlies, ko stāstā nozīmē punkti, atslēga un finišs. Ja atslēga tagad ir enerģijas kodols, failā Level.cs atrodi redzamo tekstu Atslēga: un nomaini to uz Kodols:. Pielāgo arī Mission un Locked Text. Nosaukumus HasKey un PickupType.Key kodā atstāj.
  6. Level1 cilnē atlasi vismaz vienu platformu vai priekšmetu un maini Transform → Position. Izspēlē visu ceļu vēlreiz. Pārbaudi, ka teksti ir salasāmi un finišu var atšķirt no bīstamās zonas. README.md īsi pamato trīs izskata izmaiņas; aizņemtiem attēliem norādi autoru un licenci.

Gatavs, kad: spēlē redzams tavs nosaukums, mērķis un trīs izskata izmaiņas. Esi pārvietojis vismaz vienu platformu vai priekšmetu un pārbaudījis, ka līmeni var iziet.

Uzvara, zaudējums un sākšana no jauna
1. uzdevums · Pārbaudes		 Spēlei nav pārbaudāmas uzvaras vai zaudējuma; sākt no jauna neizdodas. Darbojas tikai daļa beigu nosacījumu: var uzvarēt bez atslēgas, trūkst viena zaudējuma veida, pēc beigām var turpināt spēlēt vai R neatjauno visu līmeni. Bez atslēgas finišs dod norādi, ar atslēgu — uzvaru. Hazard un kritiens katrs rada zaudējumu. Pēc beigām kustība un savākšana apstājas. Projekta faili, Git un iesniegšana
3. uzdevums · Ko sagatavo		 Darbs palicis tikai datorā, saite neatver krātuvi vai trūkst failu, bez kuriem projektu nevar palaist. GitHub projekts ir, bet trūkst resursu, nosūtīta veca versija, nav pārbaudīta atsevišķa kopija vai krātuvē nonākuši ģenerētie faili. Iesniegta atverama GitHub krātuves saite ar pārbaudīto gala versiju: project.godot, .csproj, scēnām, Player.cs, Pickup.cs, Level.cs un izmantotajiem resursiem. .gitignore izslēdz .godot/, bin/ un obj/; tie nav publicēti. Veikts commit un push; atsevišķa kopija bez .godot veiksmīgi izpilda Import, Build un F5. Izpildīts “Apguvis”; GitHub faili atbilst no atsevišķās kopijas pārbaudītajam darbam.
