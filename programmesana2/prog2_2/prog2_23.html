2.3 Vadības struktūras spēles loģikā

Stundas uzdevums: Izmantot if/else, switch un cikli spēles uzvedības loģikā.

SR 2.4.14. Vadības struktūras SR 2.4.13. Mainīgie

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - pārraksti Python if C++ sintaksē · 2. uzdevums (~25 min) - izveido enum un switch priekšmetu veidiem · 3. uzdevums (~20 min) - pievieno ciklu, kas pārbauda visus priekšmetus · Iesniegšana (~5 min).

Pirms sāc: atceries no Programmēšanas I: if, elif, else un for cikls. C++ dara to pašu, bet ar figūriekavām un semikoliem. Šodien pārtulkosi jau zināmo.

Teorija: C++ vadības struktūras

C++ vadības struktūras ir gandrīz identiskas Python ekvivalentiem, bet ar atšķirīgu sintaksi:

// If / else if / else
if (player->health <= 0) {
    player->die();
} else if (player->health < 30) {
    play_warning_sound();
} else {
    show_normal_status();
}

// Switch (kā Python match-case)
switch (state) {
    case PlayerState::IDLE:    play_idle();    break;
    case PlayerState::RUNNING: play_run();     break;
    case PlayerState::JUMPING: play_jump();    break;
    default:                   break;
}

// For cikls
for (int i = 0; i < enemies.size(); i++) {
    enemies[i]->update();
}

// Range-based for (C++11+)
for (Enemy* e : enemies) {
    e->update();
}

// While
while (health > 0 && level_active) {
    process_combat();
}

Praktiskie uzdevumi

1. uzdevums - Pārraksti Python if C++ sintaksē

Beigās tu redzēsi, ka loģika ir tā pati, tikai pieraksts cits.

  1. Uzraksti README.md failā Python nosacījumu: ja enerģija zem 0, varonis mirst; ja zem 30, brīdinājums; citādi viss labi.
  2. Izveido C++ klasē lauku int health = 100;.
  3. Ieraksti if (health <= 0) { ... } ar figūriekavām.
  4. Pievieno else if (health < 30) { ... } - ievēro, ka tas ir divi vārdi, nevis elif.
  5. Pievieno else { ... } un katrā zarā izdruku.
  6. Kompilē un pārbaudi ar trim dažādām health vērtībām.
  7. Pieraksti trīs atšķirības starp Python un C++ pierakstu.

Gatavs, kad: visi trīs zari nostrādā pareizi, un README.md failā ir trīs pierakstītas atšķirības.

2. uzdevums - Izveido enum un switch priekšmetu veidiem

Beigās priekšmetu veidi būs nosaukumi, nevis nesaprotami skaitļi.

  1. Ieraksti virs klases enum class PickupType { COIN, GEM, KEY };.
  2. Uzraksti metodi void on_pickup(PickupType type);.
  3. Ieraksti tajā switch (type) {.
  4. Pievieno katram veidam case PickupType::COIN: ar savu darbību.
  5. Pievieno katram case beigās break;.
  6. Izdzēs vienu break;, kompilē un pieraksti, kas notiek.
  7. Ieliec break; atpakaļ un pārbaudi visus trīs veidus.

Gatavs, kad: katrs priekšmeta veids dod savu rezultātu, un tu zini, ka bez break izpildās arī nākamais case.

3. uzdevums - Pievieno ciklu, kas pārbauda visus priekšmetus

Beigās viena cilpa apstrādās visu priekšmetu sarakstu.

  1. Iekļauj #include <vector>.
  2. Izveido std::vector<PickupType> items = { PickupType::COIN, PickupType::GEM, PickupType::COIN };.
  3. Uzraksti ciklu for (PickupType t : items) { on_pickup(t); }.
  4. Kompilē un pārbaudi, ka izdrukājas trīs rindas.
  5. Pievieno sarakstam vēl vienu priekšmetu un palaid vēlreiz.
  6. Pārbaudi, vai cikls bija jāmaina.
  7. Pieraksti, ar ko šis cikls līdzinās Python for ciklam.

Gatavs, kad: cikls apstrādā visus saraksta priekšmetus, un pievienojot ceturto, kods nav jāmaina.

Papildu uzdevums - Saskaiti katra veida priekšmetus

Ja pamatdarbs ir gatavs, izveido kopsavilkumu.

  1. Pievieno trīs skaitītājus - pa vienam katram veidam.
  2. Palielini attiecīgo skaitītāju katrā case zarā.
  3. Izdrukā pēc cikla visu trīs skaitītāju vērtības.
  4. Pārbaudi, vai summa sakrīt ar saraksta garumu.
  5. Pievieno sarakstam dublikātus un pārbaudi vēlreiz.

Gatavs, kad: skaitītāju summa vienmēr sakrīt ar priekšmetu skaitu sarakstā.

Ko iesniedz skolotājam

Stundas mērķis: Tu proti C++ sintaksē uzrakstīt if/else if/else, izveidot enum class ar switch un apstrādāt priekšmetu sarakstu ar ciklu, un vari nosaukt galvenās atšķirības no Python.

Iesniedzamais:

  1. C++ fails ar visiem trim uzdevumiem tavā GitHub krātuvē.
  2. Ekrānuzņēmums ar Output paneli, kurā redzamas cikla izdrukas.
  3. README.md: trīs atšķirības starp Python un C++ pierakstu un viens teikums, kas notiek bez break.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un ekrānuzņēmumu skolotāja norādītajā vietā; README.md failā jābūt prasītajiem pierakstiem.

Biežākās kļūdas

  • 'enemies' was not declared: Trūkst #include <vector> un namespace.
  • Crash, mēģinot dzēst no vektora cikla laikā: Lieto pareizu iterator pieeju vai dzēš pēc cikla.
  • switch case nestrādā: Aizmirsts break; - kods iet uz nākamo case.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

enum class PickupType { COIN, GEM, KEY };

void Player::on_pickup(PickupType type) {
    switch (type) {
        case PickupType::COIN:
            score += 1;
            UtilityFunctions::print("Coin! Score: ", score);
            break;
        case PickupType::GEM:
            score += 5;
            UtilityFunctions::print("Gem! Score: ", score);
            break;
        case PickupType::KEY:
            has_key = true;
            UtilityFunctions::print("Got the key!");
            break;
    }

    if (score >= 100) {
        UtilityFunctions::print("Level complete!");
    }
}
Spēlētājs savāc 3 dažādus tipus pickup objektus, score atjauninās terminālī.
