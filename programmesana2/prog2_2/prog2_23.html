SR 2.4.14. Vadības struktūras SR 2.4.13. Variable (mainīgie)

Teorija: zarošanās, pārskaitījumi un cikls foreach

Nosacījumu zarošanās (if / else if / else)

Programmas uzvedību atkarībā no datu stāvokļa vada ar if (nosacījuma pārbaude — „ja”) un else (pretējais gadījums — „citādi”). Virknējot vairākas pārbaudes ar else if, C# tās izvērtē secīgi no augšas uz leju un izpilda tikai pirmo zaru, kura nosacījums ir true (patiess), pārējos izlaižot — līdzīgi kā automātiskais termostats vispirms pārbauda kritisko pārkaršanas robežu un tikai tad parasto darba režīmu:

int temperatura = 85;

if (temperatura >= 90)
    GD.Print("Kritiska pārkaršana — izslēdz iekārtu!");
else if (temperatura >= 70)
    GD.Print("Paaugstināta temperatūra — ieslēdz dzesēšanu.");
else
    GD.Print("Normāls darba režīms.");

Pārskaitījuma tips enum un izvēle switch

Ja mainīgajam drīkst būt tikai dažas iepriekš zināmas kategorijas, brīva teksta vietā C# definē enum (pārskaitījuma tipu) — stingru nosauktu vērtību sarakstu (piemēram, enum Size { Small, Medium, Large }). Tas pasargā no drukas kļūdām jau kompilācijas laikā.

Lai katrai kategorijai noteiktu savu darbību, ērti lietot konstrukciju switch (izvēle pēc vērtības): tā salīdzina saņemto vērtību ar case (izvēles gadījums) zariem — gluži kā šķirošanas līnija pakomātā novirza katra izmēra sūtījumu savā nodalījumā. Katra case zara darbības noslēdz atslēgvārds break;:

public enum Size { Small, Medium, Large }

public void RegistretSutijumu(Size izmers)
{
    switch (izmers)
    {
        case Size.Small:
            aiznemtasVienibas += 1;
            break;
        case Size.Medium:
            aiznemtasVienibas += 2;
            break;
        case Size.Large:
            irLielgabarita = true;
            break;
    }
}

Kolekcijas apstrāde ar foreach un kontrolētas īpašības

Vienāda tipa vērtību virkni var glabāt masīvā (piemēram, int[] values = { 10, 20, 30 };), bet konstrukcija foreach (katra elementa cikls) secīgi paņem katru saraksta elementu pa vienam no pirmā līdz pēdējam - tāpat kā kasieris noskenē visas preces uz lentes pēc kārtas.

Savukārt klases īpašība ar pierakstu { get; private set; } ļauj citiem skriptiem vērtību droši nolasīt, bet izmainīt to drīkst tikai pašas klases iekšējās metodes (kā rādītājs aiz aizslēgta stikla, kuru nevar patvaļīgi pagriezt no ārpuses):

public int Kopsumma { get; private set; } = 0; // Ārpusē tikai nolasāma īpašība

public void SaskaititMerijumus()
{
    int[] values = { 10, 20, 30 };
    foreach (int vertiba in values)
        Kopsumma += vertiba; // Pēc cikla Kopsumma ir 60
}

2.3 Player.cs - pilns fails salīdzināšanai

Lejupielādēt Player.cs. Atver failu Scripts/Player.cs un salīdzini vai aizstāj tā saturu ar šo kodu.

using Godot;

public enum PickupType { Coin, Gem, Key }

public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;

    public int Score { get; private set; } = 0;
    public bool HasKey { get; private set; } = false;
    public bool IsActive { get; set; } = true;

    public override void _PhysicsProcess(double delta)
    {
        Vector2 direction = Vector2.Zero;
        if (Input.IsActionPressed("move_left")) direction.X -= 1;
        if (Input.IsActionPressed("move_right")) direction.X += 1;
        if (Input.IsActionPressed("move_up")) direction.Y -= 1;
        if (Input.IsActionPressed("move_down")) direction.Y += 1;

        Velocity = direction.Normalized() * Speed;
        MoveAndSlide();
    }

    public void OnPickup(PickupType type)
    {
        if (!IsActive) return;

        switch (type)
        {
            case PickupType.Coin:
                Score += 1;
                break;
            case PickupType.Gem:
                Score += 5;
                break;
            case PickupType.Key:
                HasKey = true;
                break;
        }

        GD.Print($"Punkti: {Score}; atslēga: {HasKey}");
    }
}

Gatavs, kad: Build izpildās bez kļūdām, Scripts/Player.cs satur PickupType un OnPickup, un varonis joprojām kustas.

// Pagaidu metode failā Scripts/Player.cs (pēc 3. uzdevuma ekrānuzņēmuma izdzēs!):
public override void _Ready()
{
    PickupType[] items = { PickupType.Coin, PickupType.Coin, PickupType.Key };

        OnPickup(item);
