2.2 Input apstrāde un Input Map

Stundas uzdevums: Izveidot Player scēnu un kopīgu Input Map, pārbaudīt vadību ar WASD un bultiņām.

SR 2.4.14. Vadības struktūras SR 2.4.7. UI

80 min plāns: Ievads (~10 min) · Input Map (~20 min) · spēlētāja scēna (~25 min) · kustības pārbaude (~20 min) · saglabāšana (~5 min).

Pirms sāc: turpini Platformer projektu no 2.1. MovementLab.tscn paliek kā eksperiments; spēlei izveidosim atsevišķus Player.tscn un Level1.tscn.

Darba ritms: pēc katra uzdevuma saglabā, nospied Build un pārbaudi rezultātu. Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Teorija: darbības un spēlētāja kustība

Input Map sasaista darbības nosaukumu ar taustiņiem. IsActionPressed ir patiess, kamēr taustiņu tur; IsActionJustPressed — tikai nospiešanas brīdī. Nosaukumu reģistram jāsakrīt precīzi.

Šajā stundā izmēģinām brīvu kustību četros virzienos. (1, 1) garums ir √2 ≈ 1,41; Normalized() izlīdzina diagonāles ātrumu. 2.5 stundā vertikālo vadību aizstāsim ar gravitāciju un lēcienu.

Izmantojam CharacterBody2D jau no sākuma: Velocity = direction * Speed;, tad MoveAndSlide();. Position += ... paliek tikai iepriekšējās stundas eksperimentā.

1. uzdevums -

Iestati visai tēmai kopīgu Input Map

  1. Atver Project → Project Settings → Input Map. Ar Add pievieno katru tabulā doto darbību; ar + piesaisti norādītos taustiņus.
  2. Izmanto tabulas nosaukumus precīzi, arī mazos burtus. jump un restart sāksim izmantot vēlāk.
  3. Saglabā un uzņem Input Map ekrānuzņēmumu. Tā iestatījumi glabājas project.godot.

2. uzdevums -

Izveido spēlētāju un līmeni

  1. Jaunā scēnā izvēlies Other Node → CharacterBody2D, sakni nosauc Player. Saglabā res://Scenes/Player.tscn; saknes Position = (0,0), Scale = (1,1).
  2. Pievieno Polygon2D bērnu Visual ar tiem pašiem četriem punktiem un krāsu kā 2.1 stundā. Pievieno arī CollisionShape2D; Shape → New RectangleShape2D → Size = (32,48). Abiem bērniem Position = (0,0).
  3. Player Inspector sadaļā Collision noņem sākotnējos ķeksīšus: Layer tikai 2, Mask tikai 1. Motion Mode atstāj Grounded. Šeit skaitļi ir ķeksīšu numuri.
  4. Pievieno Player saknei res://Scripts/Player.cs. Ieliec pilno zemāk doto kodu; Mover.cs šim mezglam nepievieno.
  5. Izveido jaunu Node2D scēnu Level1, saglabā res://Scenes/Level1.tscn. No FileSystem ievelc tajā Player.tscn; instances nosaukums Player, Position = (80,570).
  6. Nospied Build, tad F5 un kā galveno scēnu izvēlies Level1.tscn. Turpmāk spēli palaid ar F5. W/A/S/D un bultiņām jāpārvieto varonis.
2.2 Player.cs — pilns fails salīdzināšanai

Lejupielādēt Player.cs. Aizstāj tikai atbilstošā faila saturu; neveido otru tāda paša nosaukuma klasi.

using Godot;

public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;

    public override void _PhysicsProcess(double delta)
    {
        Vector2 direction = Vector2.Zero;
        if (Input.IsActionPressed("move_left")) direction.X -= 1;
        if (Input.IsActionPressed("move_right")) direction.X += 1;
        if (Input.IsActionPressed("move_up")) direction.Y -= 1;
        if (Input.IsActionPressed("move_down")) direction.Y += 1;

        Velocity = direction.Normalized() * Speed;
        MoveAndSlide();
    }
}

Gatavs, kad: F5 palaiž Level1, varonis pārvietojas un apstājas, atlaižot taustiņus.

3. uzdevums -

Pārbaudi vadību un diagonāles ātrumu

  1. Izmēģini atsevišķi A/D, W/S un bultiņas. Nospied abus pretējos virzienus vienlaikus — tiem jāatceļ vienam otru.
  2. Uz laiku aizstāj direction.Normalized() * Speed ar direction * Speed. Pārbaudi D+S; pēc tam atjauno Normalized().
  3. Pārbaudi, ka bez nospiestiem taustiņiem varonis nekustas. Ja tas iziet ārpus ekrāna, apturi un palaid spēli no jauna; līmeņa robežas veidosim vēlāk.
  4. README.md ieraksti √2 aprēķinu un paskaidro, kāpēc Velocity šeit papildus nereizina ar delta.

Gatavs, kad: ir normalizēta kustība, darbojas abi vadības komplekti un nākamajai stundai saglabātas abas jaunās scēnas.

Papildu uzdevums — skriešanas taustiņš

Pievieno run darbību ar Shift. Pirms Velocity piešķiršanas aprēķini float currentSpeed = Input.IsActionPressed("run") ? Speed * 1.5f : Speed; un kustībai izmanto currentSpeed. Pārbaudi arī diagonāli.
