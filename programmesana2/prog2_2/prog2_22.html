2.2 Vadi varoni ar key (taustiņiem)

Stundas uzdevums: Input Map (ievades darbību karte) tab (cilnē) pievieno key (taustiņus) un izveido varoni, kuru vari vadīt ar WASD un bultiņām.

SR 2.4.14. Control structure (vadības struktūras) SR 2.4.7. UI (lietotāja saskarne)

80 min plāns: Ievads (~10 min) · Input Map (ievades darbību karte) (~20 min) · spēlētāja scene (scēna) (~25 min) · kustības pārbaude (~20 min) · save (saglabāšana) (~5 min).

Pirms sāc: turpini Platformer project (projektu) no 2.1. MovementLab.tscn paliek kā eksperiments; spēlei izveidosim atsevišķus Player.tscn un Level1.tscn.

Pēc izmaiņām: saglabā file (failus). Ja mainīji C# code (kodu), Godot augšējā labajā stūrī nospied Build (būvēt projektu) (āmura icon (ikona)). Tad palaid spēli. Pirms nākamā uzdevuma izlabo pirmo parādīto kļūdu.

Kur šodien klikšķināsi

Input Map (ievades darbību karte) tab (cilnē) katrai darbībai pievienosi key (taustiņus). Piemēram, move_left nozīmēs kustību pa kreisi gan ar A, gan ar ←.

Scene (scēna) panel (panelī) veidosi Player ar divām daļām: Visual parāda varoni, bet CollisionShape2D (2D sadursmes forma) nosaka, kur varonis atduras pret šķērsli. Pašus šķēršļus pievienosim 2.4 stundā.

Šodien varonis var kustēties četros virzienos. Vēlāk kustību uz augšu un leju aizstāsim ar lēcienu un krišanu. Godot panel (paneļu) un button (pogu) atgādne.

1. uzdevums -

Input Map (ievades darbību karte) tab (cilnē) pievieno key (taustiņus)

  1. Augšā atver Project (projekts) → Project Settings (projekta iestatījumi) un izvēlies tab (cilni) Input Map (ievades darbību karte).
  2. Field (laukā) Add New Action (pievienot jaunu darbību) ieraksti move_left un spied Add (pievienot). List (sarakstā) parādās jauna rinda.
  3. Šīs rindas labajā pusē spied +. Field (laukā) Listening for Input… (gaida ievadi…) nospied keyboard (tastatūras) A un apstiprini ar OK. Tajā pašā rindā vēlreiz spied + un pievieno ←.
  4. Tāpat pievieno pārējās tabulas rindas. Nosaukumus raksti precīzi, ar mazajiem burtiem. jump un restart izmantosim vēlāk.
  5. Izvērs rindas un pārbaudi piesaistītos key (taustiņus). Uzņem Input Map (ievades darbību karte) screenshot (ekrānuzņēmumu), tad aizver settings (iestatījumu) window (logu).

2. uzdevums -

Izveido spēlētāju un līmeni

  1. Izvēlies Scene (scēna) → New Scene (jauna scēna), tad Other Node (cits mezgls). Meklē CharacterBody2D (vadāma 2D tēla mezgls) un spied Create (izveidot). Ar F2 nosauc to Player. Ar Ctrl+S saglabā folder (mapē) Scenes kā Player.tscn.
  2. Atlasi Player. Inspector (īpašību panelis) sadaļā Transform (pārveidojums) atstāj Position (pozīcija) = (0,0) un Scale (mērogs) = (1,1).
  3. Ar + pievieno Polygon2D (2D daudzstūris), nosauc to Visual. Inspector (īpašību panelis) sadaļā Data (dati) → Polygon (daudzstūris) ievadi četrus punktus tāpat kā 2.1 stundā: (-16,-24), (16,-24), (16,24), (-16,24). Field (laukā) Color (krāsa) izvēlies gaišu krāsu.
  4. Atkal atlasi Player un ar + pievieno CollisionShape2D (2D sadursmes forma). Inspector (īpašību panelis) field (laukā) Shape (forma) atver menu (izvēlni) → New RectangleShape2D (jauna 2D taisnstūra forma). Noklikšķini uz izveidotās formas un field (laukā) Size (izmērs) ievadi (32,48). Visual un CollisionShape2D (2D sadursmes forma) field (laukam) Position (pozīcija) jābūt (0,0).
  5. Atlasi Player. Inspector (īpašību panelis) atver Collision (sadursme). Rindā Layer (slānis) atstāj ieslēgtu tikai kvadrātiņu 2, rindā Mask (maska) — tikai 1. Field (laukā) Motion Mode (kustības režīms) atstāj Grounded (kustība pa zemi).
  6. Ar labo mouse (peles) button (pogu) uz Player → Attach Script (pievienot skriptu). Izvēlies C# un path (ceļu) res://Scripts/Player.cs. Spied Create (izveidot), atver file (failu) C# editor (redaktorā) un aizstāj saturu ar pilno code (kodu) zemāk. Saglabā code (kodu) un scene (scēnu).
  7. Izvēlies Scene (scēna) → New Scene (jauna scēna) → 2D Scene (2D scēna), nosauc to Level1 un saglabā Scenes/Level1.tscn. No FileSystem (failu sistēma) ievelc Player.tscn uz Level1 Scene (scēna) panel (panelī). Izvēlies pievienoto Player un Inspector (īpašību panelis) sadaļā Transform (pārveidojums) → Position (pozīcija) ievadi (80,570).
  8. Nospied Build (būvēt projektu). FileSystem (failu sistēma) panel (panelī) ar labo mouse (peles) button (pogu) uz Level1.tscn → Set as Main Scene (iestatīt kā galveno scēnu). Nospied augšējo Run Project (palaist projektu) (F5) button (pogu). Noklikšķini spēles window (logā) un izmēģini W/A/S/D un bultiņas.
2.2 Player.cs — pilns file (fails) salīdzināšanai

Lejupielādēt Player.cs. Atver esošo tāda paša nosaukuma file (failu) un aizstāj tā saturu ar šo code (kodu).

using Godot;

public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;

    public override void _PhysicsProcess(double delta)
    {
        Vector2 direction = Vector2.Zero;
        if (Input.IsActionPressed("move_left")) direction.X -= 1;
        if (Input.IsActionPressed("move_right")) direction.X += 1;
        if (Input.IsActionPressed("move_up")) direction.Y -= 1;
        if (Input.IsActionPressed("move_down")) direction.Y += 1;

        Velocity = direction.Normalized() * Speed;
        MoveAndSlide();
    }
}

Gatavs, kad: F5 palaiž Level1, varonis pārvietojas un apstājas, atlaižot key (taustiņus).

3. uzdevums -

Izmēģini key (taustiņus) un maini Speed (ātrums)

  1. Palaid ar F5. Izmēģini A/D, W/S un bultiņas. Atlaižot key (taustiņus), varonim jāapstājas. Turot A un D reizē, tas nekustas pa labi vai pa kreisi.
  2. Apturi ar F8. Level1 tab (cilnē) atlasi Player un Inspector (īpašību panelis) field (laukā) Speed (ātrums) izmēģini 150 un 450. Pēc katras izmaiņas palaid spēli un salīdzini. Beigās atjauno 300.
  3. Code (kodā) uz laiku aizstāj direction.Normalized() * Speed ar direction * Speed. Saglabā, nospied Build (būvēt projektu) un izmēģini D+S reizē: pa diagonāli varonis pārvietojas ātrāk. Atjauno Normalized(), vēlreiz saglabā un nospied Build (būvēt projektu).
  4. Normalized() palīdz saglabāt vienādu ātrumu arī pa diagonāli. MoveAndSlide() jau ņem vērā laiku, tāpēc Velocity (ātrums) šeit papildus ar delta nereizina.
  5. README.md ieraksti vadības key (taustiņus) un vienu novērojumu par mainīto ātrumu. Ja varonis iziet ārpus screen (ekrāna), apturi un palaid spēli no jauna.

Gatavs, kad: darbojas WASD un bultiņas, code (kodā) atjaunots Normalized() un Speed (ātrums) ir 300.

Papildu uzdevums — skriešanas key (taustiņš)

Atver Project (projekts) → Project Settings (projekta iestatījumi) → Input Map (ievades darbību karte). Pievieno run rindu un ar + tai piesaisti Shift. Pirms Velocity (ātrums) piešķiršanas aprēķini float currentSpeed = Input.IsActionPressed("run") ? Speed * 1.5f : Speed; un kustībai izmanto currentSpeed. Pārbaudi arī diagonāli.
