2.2 Vadi varoni ar taustiņiem

Sasniedzamais rezultāts: Input Map cilnē pievieno taustiņus un izveido varoni, kuru vari vadīt ar WASD un bultiņām.

SR 2.4.14. Vadības struktūras SR 2.4.7. UI (lietotāja saskarne)

Teorija: ievades darbību karte un virziena vektora normalizācija

Ievades abstrakcija ar Input Map

Tā vietā, lai C# kodā pārbaudītu konkrētus fiziskus tastatūras taustiņus, Godot izmanto Input Map (ievades darbību karti) — sarakstu ar loģiskiem darbību nosaukumiem (piemēram, move_left), kuriem var piesaistīt vienu vai vairākus taustiņus un vadības ierīces. Tas darbojas līdzīgi viedās mājas komandai „Ieslēgt apgaismojumu”, kuru var aktivizēt gan ar sienas slēdzi, gan no tālruņa, nepārbūvējot pašu elektrotīklu: ja vēlāk jāpievieno cits taustiņš, C# kods nav jāmaina.

Metodē _PhysicsProcess īpašība Input.IsActionPressed("darbiba") atgriež true visos kadros, kamēr piesaistītais taustiņš ir turēts nospiests. Sākot katru soli no nulles vektora Vector2.Zero un pieskaitot vai atņemot 1 pa attiecīgo asi, vienlaikus nospiesti pretējie virzieni summējas par 0 (atceļ viens otru), bet atlaižot taustiņus, kustība uzreiz apstājas:

Vector2 virziens = Vector2.Zero; // Katrā solī sāk no (0, 0)

if (Input.IsActionPressed("move_left"))  virziens.X -= 1;
if (Input.IsActionPressed("move_right")) virziens.X += 1;
if (Input.IsActionPressed("move_up"))    virziens.Y -= 1;
if (Input.IsActionPressed("move_down"))  virziens.Y += 1;
// Turot abus pretējos virzienus (-1 un +1), rezultāts attiecīgajā asī ir 0

Diagonālā kustība un vektora Normalized()

Ja objekts vienlaikus pārvietojas pa abām asīm — piemēram, pa labi (X = 1) un uz leju (Y = 1) —, iegūtā vektora (1, 1) garums pēc Pitagora teorēmas nav 1, bet gan √(1² + 1²) ≈ 1,41. Bez korekcijas objekts pa diagonāli slīdētu par ~41 % ātrāk nekā taisni pa horizontāli vai vertikāli (līdzīgi kā šķērsot laukumu ar garākiem soļiem).

Metode direction.Normalized() saglabā vektora virzienu, bet pārrēķina tā garumu par vieninieku (nulles vektoram (0, 0) tā droši atgriež (0, 0)). Reizinot normalizēto virzienu ar Speed un izsaucot CharacterBody2D metodi MoveAndSlide() (kas laika soli delta jau ņem vērā iekšēji), kustības ātrums visos virzienos ir vienāds:

// Pārvērš jebkura virziena garumu par 1.0 (vai saglabā (0, 0), ja stāv uz vietas)
Velocity = virziens.Normalized() * Speed;
MoveAndSlide(); // Iekšēji piemēro laika soli delta

1. uzdevums

Input Map cilnē pievieno taustiņus

Kur strādāt: Vadības darbības (actions) pievieno Godot logā Project → Project Settings → Input Map; Godot tās automātiski saglabā projekta project.godot failā.

  1. Atver Input Map: augšējā izvēlnē atver Project → Project Settings un pārslēdzies uz cilni Input Map.
  2. Izveido darbību move_left: laukā Add New Action ieraksti move_left un spied Add. Sarakstā parādīsies jauna rinda.
  3. Piesaisti taustiņus darbībai move_left: rindas move_left labajā pusē spied +. Laukā Listening for Input… nospied tastatūras taustiņu A un apstiprini ar OK. Tajā pašā move_left rindā vēlreiz spied + un pievieno bultiņu pa kreisi (←), lai kustība pa kreisi strādātu ar abiem taustiņiem.
  4. Pievieno pārējās 5 darbības: pēc tabulas zemāk izveido move_right, move_up, move_down, jump un restart. Nosaukumus raksti precīzi ar mazajiem burtiem (jump un restart izmantosim 2.5. un 2.6. stundā).
  5. Pārbaudi un saglabā ekrānuzņēmumu: izvērs visas 6 darbību rindas, pārliecinies par piesaistītajiem taustiņiem, uzņem Input Map ekrānuzņēmumu un aizver Project Settings logu.
Darbība (Action nosaukums)Piesaistāmie taustiņi
move_leftA un ← (Left)
move_rightD un → (Right)
move_upW un ↑ (Up — 2.2.–2.4. stundas eksperimentiem)

Gatavs, kad: cilnē Input Map ir visas sešas darbības ar tabulā norādītajiem taustiņiem.

2. uzdevums

Izveido spēlētāju un līmeni

Kur strādāt: Šajā uzdevumā izveido divas atsevišķas scēnas un vienu skriptu: 1) spēlētāja scēnu Scenes/Player.tscn ar skriptu Scripts/Player.cs pie saknes mezgla Player; 2) līmeņa scēnu Scenes/Level1.tscn, kurā ievieto Player.tscn eksemplāru.

Abu scēnu struktūra (nejauc tās kopā!):

1) Scēna Scenes/Player.tscn:
Player (CharacterBody2D, skripts: Scripts/Player.cs, Layer: 2, Mask: 1)
├── Visual (Polygon2D - 32×48 taisnstūris, Position: (0, 0))
└── CollisionShape2D (RectangleShape2D 32×48, Position: (0, 0))

2) Scēna Scenes/Level1.tscn (Main Scene):
Level1 (Node2D)
└── Player (ievilkts Scenes/Player.tscn eksemplārs, Position: (80, 570))
  1. Izveido scēnu Scenes/Player.tscn: izvēlies Scene → New Scene, spied Other Node, meklē CharacterBody2D un spied Create. Ar F2 pārdēvē mezglu par Player un ar Ctrl+S saglabā scēnu mapē Scenes kā Player.tscn.
  2. Scēnā Scenes/Player.tscn pārbaudi Player pozīciju: Scene panelī atlasi Player un Inspector sadaļā Transform pārliecinies, ka Position ir (0, 0) un Scale ir (1, 1).
  3. Scēnā Scenes/Player.tscn pievieno Visual: atlasi Player, ar + pievieno Polygon2D bērnmezglu un nosauc to Visual. Inspector sadaļā Data → Polygon iestati 4 punktus: (-16, -24), (16, -24), (16, 24), (-16, 24) un laukā Color izvēlies sava varoņa krāsu.
  4. Scēnā Scenes/Player.tscn pievieno CollisionShape2D: atkal atlasi Player (nevis Visual!) un ar + pievieno CollisionShape2D. Inspector laukā Shape izvēlies New RectangleShape2D, noklikšķini uz izveidotās formas un iestati Size = (32, 48). Gan Visual, gan CollisionShape2D mezglam Position jāpaliek (0, 0).
  5. Scēnā Scenes/Player.tscn iestati sadursmju slāņus: atlasi saknes mezglu Player un Inspector sadaļā Collision rindā Layer atstāj ieslēgtu tikai 2 (izslēdz 1), bet rindā Mask — tikai 1. Laukā Motion Mode atstāj Grounded.
  6. Izveido skriptu Scripts/Player.cs: Scene panelī ar labo peles pogu klikšķini uz Player → Attach Script. Izvēlies Language: C#, ceļu res://Scripts/Player.cs un spied Create. Aizstāj Scripts/Player.cs saturu ar pilno kodu zemāk, tad saglabā skriptu un scēnu Player.tscn (Ctrl+S).
  7. Izveido līmeņa scēnu Scenes/Level1.tscn: izvēlies Scene → New Scene → 2D Scene, pārdēvē sakni par Level1 un ar Ctrl+S saglabā kā Scenes/Level1.tscn. No FileSystem paneļa ievelc Scenes/Player.tscn uz Level1 mezgla Scene panelī. Atlasi pievienoto Player eksemplāru un tā Inspector → Transform → Position iestati (80, 570). Saglabā Level1.tscn.
  8. Iestati galveno scēnu un palaid projektu: nospied Build. FileSystem panelī ar labo peles pogu klikšķini uz Scenes/Level1.tscn → Set as Main Scene. Nospied Run Project (F5), noklikšķini spēles logā un izmēģini kustību ar W/A/S/D un bultiņām.
2.2 Player.cs - pilns fails salīdzināšanai

Lejupielādēt Player.cs. Atver failu Scripts/Player.cs un aizstāj tā saturu ar šo kodu.

using Godot;

public partial class Player : CharacterBody2D
{
    [Export] public float Speed = 300.0f;

    public override void _PhysicsProcess(double delta)
    {
        Vector2 direction = Vector2.Zero;
        if (Input.IsActionPressed("move_left")) direction.X -= 1;
        if (Input.IsActionPressed("move_right")) direction.X += 1;
        if (Input.IsActionPressed("move_up")) direction.Y -= 1;
        if (Input.IsActionPressed("move_down")) direction.Y += 1;

        Velocity = direction.Normalized() * Speed;
        MoveAndSlide();
    }
}

Gatavs, kad: F5 palaiž scēnu Scenes/Level1.tscn, varonis pārvietojas visos četros virzienos un apstājas, atlaižot taustiņus.

3. uzdevums

Izmēģini taustiņus un maini Speed (ātrums)

Kur strādāt: Speed vērtību maini scēnas Scenes/Level1.tscn mezgla Player Inspector panelī, normalizāciju pārbaudi failā Scripts/Player.cs (metodē _PhysicsProcess), bet novērojumus ieraksti README.md.

  1. Pārbaudi pretējos taustiņus spēlē: palaid projektu ar F5. Izmēģini A/D, W/S un bultiņas. Pārliecinies, ka atlaižot taustiņus varonis uzreiz apstājas, bet turot A un D vienlaikus — stāv uz vietas (-1 + 1 = 0).
  2. Izmēģini Speed maiņu scēnā Scenes/Level1.tscn: apturi spēli ar F8. Atver cilni Level1.tscn, Scene panelī atlasi Player un Inspector laukā Speed izmēģini 150, tad 450 (pēc katras maiņas palaid ar F5). Pēc salīdzināšanas atjauno Speed = 300.
  3. Pārbaudi diagonālo kustību bez Normalized() failā Scripts/Player.cs: atver Scripts/Player.cs un metodē _PhysicsProcess rindu Velocity = direction.Normalized() * Speed; uz laiku nomaini uz Velocity = direction * Speed;. Saglabā, nospied Build un ar F5 turi D + S reizē — pa diagonāli varonis slīd manāmi ātrāk.
  4. Atjauno Normalized() failā Scripts/Player.cs: nomaini rindu atpakaļ uz Velocity = direction.Normalized() * Speed;, saglabā un nospied Build. Atceries: MoveAndSlide() jau iekšēji pareizina ātrumu ar delta, tāpēc Velocity ar delta šeit nereizina.
  5. Pieraksti novērojumus failā README.md: projekta README.md failā uzskaiti spēles vadības taustiņus un vienā teikumā pieraksti novērojumu par ātruma un Normalized() darbību.

Gatavs, kad: darbojas WASD un bultiņas, failā Scripts/Player.cs ir atjaunots direction.Normalized() * Speed, Speed ir 300 un secinājumi ierakstīti README.md.

Papildu uzdevums - skriešanas taustiņš

Kur strādāt: Darbību run pievieno Project → Project Settings → Input Map, bet ātruma aprēķinu papildini failā Scripts/Player.cs metodē _PhysicsProcess(double delta).

Atver Project → Project Settings → Input Map, pievieno darbību run un ar + tai piesaisti Shift. Tad failā Scripts/Player.cs metodē _PhysicsProcess pirms Velocity rindas aprēķini float currentSpeed = Input.IsActionPressed("run") ? Speed * 1.5f : Speed; un rindā zem tās ieraksti Velocity = direction.Normalized() * currentSpeed;. Pārbaudi ar Build un F5.
