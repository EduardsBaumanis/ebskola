Stundas uzdevums: Apgūt CharacterBody2D, Area2D un RigidBody2D atšķirības un to lietojumu.

SR 2.4.14. Vadības struktūras SR 2.4.7. UI

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - pievieno sienu un pārbaudi sadursmi · 2. uzdevums (~25 min) - izveido savācamu monētu ar Area2D · 3. uzdevums (~20 min) - iestati Collision Layers · Iesniegšana (~5 min).

Pirms sāc: atver savu projektu ar vadāmu objektu no 2.2 stundas. Šodien objekts vairs nevarēs iet cauri sienām.

Teorija: Sadursmju nodes Godot

Godot piedāvā trīs galvenos sadursmju nodes:

NodeLietojums
StaticBody2DNekustīgi šķēršļi (siena, grīda).
CharacterBody2DSpēlētāji un AI ar pielāgotu kustību (ne fiziku).
RigidBody2DPilna fizika - gravitācija, masa, spēks.
Area2DDetektē ieiešanu/iziešanu zonā (trigger, pickup).

Collision Layers un Masks: nosaka, kas var sadurties ar ko.

// Area2D signāls C++
void Pickup::_ready() {
    connect("body_entered", Callable(this, "on_body_entered"));
}

void Pickup::on_body_entered(Node2D *body) {
    if (body->is_in_group("player")) {
        // savākt pickup
        get_parent()->call("score_up", 1);
        queue_free();  // dzēst sevi
    }
}

Praktiskie uzdevumi

1. uzdevums - Pievieno sienu un pārbaudi sadursmi

Beigās tavs objekts apstāsies pie sienas, nevis ies tai cauri.

  1. Nomaini sava vadāmā objekta tipu uz CharacterBody2D.
  2. Pievieno tam bērnu CollisionShape2D ar taisnstūra formu.
  3. Pievieno scēnai StaticBody2D ar nosaukumu Siena un tās sadursmes formu.
  4. Nomaini kodā kustību uz set_velocity(dir * speed); un move_and_slide();.
  5. Kompilē un mēģini iebraukt sienā.
  6. Izdzēs sienas CollisionShape2D un pamēģini vēlreiz.
  7. Ieliec to atpakaļ un pieraksti, kāpēc bez formas sadursmes nav.

Gatavs, kad: objekts apstājas pie sienas, bet bez CollisionShape2D iet tai cauri.

2. uzdevums - Izveido savācamu monētu ar Area2D

Beigās monēta pazudīs, kad tai pieskarsies.

  1. Pievieno scēnai Area2D ar nosaukumu Monēta un tās sadursmes formu.
  2. Izveido C++ klasi Coin, kas manto no Area2D.
  3. Reģistrē _bind_methods metodē ClassDB::bind_method(D_METHOD("on_body_entered", "body"), &Coin::on_body_entered);.
  4. Savieno _ready metodē signālu ar connect("body_entered", Callable(this, "on_body_entered"));.
  5. Ieraksti apstrādātājā izdruku un queue_free();.
  6. Kompilē un uzbrauc monētai virsū.
  7. Pieraksti, ar ko Area2D atšķiras no StaticBody2D.

Gatavs, kad: uzbraucot monētai, tā pazūd un Output panelī parādās izdruka, bet objekts neapstājas.

3. uzdevums - Iestati Collision Layers

Beigās tu noteiksi, kurš objekts ar kuru drīkst sadurties.

  1. Atver sienas Inspector sadaļu Collision.
  2. Iestati sienai Layer 1 un noņem visus Mask ķeksīšus.
  3. Iestati spēlētājam Layer 2 un Mask 1 un 3.
  4. Iestati monētai Layer 3.
  5. Palaid un pārbaudi, ka spēlētājs joprojām apstājas pie sienas un savāc monētu.
  6. Noņem spēlētājam Mask 1 un pārbaudi, kas notiek ar sienu.
  7. Ieliec ķeksīti atpakaļ un pieraksti, ko nozīmē Layer un ko Mask.

Gatavs, kad: noņemot Mask 1, spēlētājs sāk iet cauri sienai, un tu vari izskaidrot, kāpēc.

Papildu uzdevums - Saskaiti savāktās monētas

Ja pamatdarbs ir gatavs, pievieno rezultāta skaitītāju.

  1. Nokopē monētu vēl trīs reizes dažādās vietās.
  2. Pievieno spēlētāja klasei lauku int score = 0;.
  3. Palielini to, kad monēta tiek savākta.
  4. Izdrukā rezultātu pēc katras savāktās monētas.
  5. Savāc visas monētas un pārbaudi gala skaitli.

Gatavs, kad: pēc visu monētu savākšanas izdrukātais skaitlis sakrīt ar monētu skaitu.

Ko iesniedz skolotājam

Stundas mērķis: Tavā projektā spēlētājs apstājas pie StaticBody2D sienas, savāc Area2D monētu, kas pazūd, un tu proti ar Collision Layers un Masks noteikt, kurš objekts ar kuru sadursies.

Iesniedzamais:

  1. Īss video vai divi ekrānuzņēmumi: objekts pie sienas un monētas savākšanas brīdis.
  2. Fails coin.cpp ar signāla savienojumu GitHub krātuvē.
  3. Burtnīcā: ar ko Area2D atšķiras no StaticBody2D un ko nozīmē Layer un Mask.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un attēlus skolotāja norādītajā vietā.

Biežākās kļūdas

  • Spēlētājs iziet cauri grīdai: CollisionShape2D nav vai forma 0 izmērā.
  • Area2D signal nestrādā: Aizmirsts connect() vai signal nepareizi nosaukts.
  • RigidBody2D negravitē: Gravity Scale = 0 vai Project Settings → Physics → 2D → Default Gravity = 0.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

#include "coin.hpp"
#include <godot_cpp/core/class_db.hpp>
#include <godot_cpp/variant/callable.hpp>

using namespace godot;

void Coin::_bind_methods() {
    ClassDB::bind_method(D_METHOD("on_body_entered", "body"),
                         &Coin::on_body_entered);
}

void Coin::_ready() {
    connect("body_entered", Callable(this, "on_body_entered"));
}

void Coin::on_body_entered(Node2D *body) {
    if (body->is_in_group("player")) {
        // Pavadi ziņu vecākam ar score
        get_tree()->call_group("game", "add_score", 1);
        queue_free();
    }
}
