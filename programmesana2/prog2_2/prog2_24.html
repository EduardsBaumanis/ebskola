2.4 Platformas un savācamie priekšmeti

Stundas uzdevums: Izveido grīdu, trīs platformas un priekšmetus, kas pazūd, kad varonis tiem pieskaras.

SR 2.4.14. Vadības struktūras SR 2.4.7. UI (lietotāja saskarne)

Teorija: nekustīgi šķēršļi, saskares zonas un signāli

Nekustīgs ķermenis (StaticBody2D) pret saskares zonu (Area2D)

2D fizikā nekustīgus vides objektus iedala divos pamata veidos — tos var salīdzināt ar mūra sienu un kustības sensoru pie automātiskajām durvīm:

  • StaticBody2D (nekustīga 2D ķermeņa mezgls) — ciets šķērslis, kas fiziski aptur kustīgus ķermeņus un neļauj tiem iziet cauri.
  • Area2D (2D saskares zona) — caurlaidīga zona, kas objektus fiziski neaptur, bet konstatē brīdi, kad tajā ieiet vai no tās iziet cits ķermenis. Lai zona aktīvi uztvertu citus objektus, tai jābūt ieslēgtai īpašībai Monitoring.

Abiem mezglu veidiem ir nepieciešams gan CollisionShape2D (2D sadursmes forma) ģeometriskajai kontūrai, gan vizuālais bērnmezgls (piemēram, Polygon2D), kā arī saskaņoti Collision Layer (piederības slānis) un Collision Mask (novērojamo slāņu maska) iestatījumi:

Siena (StaticBody2D)    → Layer: 1, Mask: —  (fiziski aptur kustīgu ķermeni)
├── CollisionShape2D    → šķēršļa sadursmes kontūra
└── Izskats (Polygon2D) → šķēršļa redzamā figūra

DurvjuSensors (Area2D)  → Layer: 3, Mask: 2, Monitoring: ieslēgts (tikai pamana)
├── CollisionShape2D    → uztveršanas zonas kontūra
└── Izskats (Polygon2D) → zonas vizuālais marķieris

Notikumu signāls BodyEntered, tipa pārbaude un QueueFree()

Kad saderīga slāņa fizikas ķermenis ieiet Area2D zonā, zona izstaro signālu BodyEntered. C# skriptā apstrādes metodi šim notikumam pieslēdz ar pierakstu BodyEntered += ApstradesMetode; metodē _Ready() — tas darbojas kā automātisks paziņojums notikuma brīdī, nevis nepārtraukta pārbaude katrā kadrā.

Tā kā parametrs saņem vispārīgu Node2D objektu, izteiksme body is not KonkretsTips mainigais droši atsijā svešus objektus un piešķir precīzu tipu tālākai metožu izsaukšanai. Lai objektu noņemtu no scēnas, lieto QueueFree() — tā droši izdzēš mezglu tekošā fizikas soļa beigās, bet papildu bool karodziņš novērš viena notikuma dubultu nostrādāšanu vienā kadrā:

public partial class Kontrolpunkts : Area2D
{
    private bool irApstradats = false;

    public override void _Ready()
    {
        BodyEntered += KadObjektsIeiet; // Pieslēdz apstrādātāju signālam
    }

    private void KadObjektsIeiet(Node2D body)
    {
        if (irApstradats || body is not KustigsObjekts objekts)
            return;

        irApstradats = true;
        objekts.RegistretAtzimi();
        QueueFree(); // Droši noņem mezglu fizikas soļa beigās
    }
}

Kopīgoti formas resursi un Make Unique

Dublējot mezglu redaktorā, jaunā kopija bieži saglabā atsauci uz to pašu iekšējo Shape resursu — līdzīgi kā divi dokumenti, kas piesaistīti vienai kopīgai veidnei. Ja vienai kopijai jāmaina sadursmes formas izmērs, neietekmējot pārējos eksemplārus, šo resursu vispirms atdala kā neatkarīgu (Make Unique).

1. uzdevums

Uzbūvē grīdu un trīs sasniedzamas platformas

Kur strādāt: Grīdu un platformas veido Scenes/Level1.tscn Godot redaktorā.

  1. FileSystem → Scenes ar dubultklikšķi atver Level1.tscn. Scene panelī atlasi Level1, spied +, meklē StaticBody2D un spied Create. Ar F2 nosauc to Ground. Inspector sadaļā Transform → Position ievadi (640,660).
  2. Atlasi Ground un ar + pievieno CollisionShape2D. Inspector laukā Shape izvēlies New RectangleShape2D (jauna 2D taisnstūra forma). Klikšķini uz izveidotās formas un laukā Size ievadi (1280,40). Pašam CollisionShape2D atstāj Position = (0,0).
  3. Atkal atlasi Ground un ar + pievieno Polygon2D (2D daudzstūris), nosauc to Visual. Inspector sadaļā Data → Polygon ievadi četrus punktus: (-640,-20), (640,-20), (640,20), (-640,20). Laukā Color izvēlies redzamu krāsu.
  4. Atlasi Level1 un tāpat izveido otru StaticBody2D ar nosaukumu Platform1. Tā Position = (280,560), Scale = (1,1). Pievieno CollisionShape2D ar taisnstūra Size = (160,20) un Visual ar punktiem (-80,-10), (80,-10), (80,10), (-80,10).
  5. Scene panelī ar labo peles pogu uz Platform1 → Duplicate. Kopiju nosauc Platform2 un iestati Position = (480,470). Izveido vēl vienu kopiju Platform3 ar Position = (680,380).
  6. Pēc kārtas atlasi grīdu, katru platformu un Player. Inspector sadaļā Collision atzīmē numurētos kvadrātiņus Layer un Mask pēc tabulas zemāk (pārējos izslēdz). Saglabā un nospied F5. Ar S mēģini iet grīdā, ar D — platformas sānos: varonim jāapstājas.

Atceries 2. uzdevumam: savācamajam priekšmetam (Pickup) Inspector panelī jābūt ieslēgtam arī Monitoring, lai tas pamanītu varoni.

Ja maini kopijas izmēru: atlasi tās CollisionShape2D. Pie Shape atver izvēlni un spied Make Unique, tad maini Izmērs. Tā pārējo kopiju formas paliks iepriekšējā izmērā. Pielāgo arī Visual punktus.

Gatavs, kad: varonis apstājas pie šķēršļiem un līmenī ir redzama grīda un trīs platformas.

2. uzdevums

Izveido un savāc pirmo monētu

Kur strādāt: Izveido Scenes/Pickup.tscn un Scripts/Pickup.cs. Doto pilno kodu ieraksti skriptā un piesaisti to Pickup saknei; monētas eksemplāru pievieno Scenes/Level1.tscn.

  1. Izvēlies Scene → New Scene → Other Node, meklē Area2D un spied Create. Nosauc to Pickup un saglabā Scenes/Pickup.tscn.
  2. Atlasi Pickup un ar + pievieno CollisionShape2D. Inspector laukā Shape izvēlies New CircleShape2D (jauna 2D apļa forma). Klikšķini uz izveidotās formas un iestati Radius = 12.
  3. Atkal atlasi Pickup un pievieno Polygon2D ar nosaukumu Visual. Sadaļā Data → Polygon ievadi četrus punktus: (0,-12), (12,0), (0,12), (-12,0). Laukā Color izvēlies dzeltenu krāsu.
  4. Atlasi Pickup. Inspector sadaļā Collision ieslēdz tikai Layer 3 un Mask 2. Pārbaudi, ka Monitoring ir ieslēgts.
  5. Ar labo peles pogu uz Pickup → Attach Script. Izvēlies C#, ceļu res://Scripts/Pickup.cs un spied Create. Aizstāj faila saturu ar kodu zemāk. Tas jau apstrādā pieskaršanos; Godot Signals (signāli) panelī nekas papildus nav jāsavieno.
  6. Saglabā failu un scēnu, nospied Build. Atver Level1 cilni. No FileSystem ievelc Pickup.tscn uz Level1 Scene panelī. Pārdēvē pievienoto objektu par Coin1. Inspector iestati Position = (150,600) un laukā Type izvēlies Coin.
  7. Saglabā, nospied F5 un pieved varoni pie monētas. Tai jāpazūd. Apakšējā Output panelī jāparādās 1 punktam. Atgriezies tajā pašā vietā: otru punktu tā nedod.
2.4 Pickup.cs — pilns fails salīdzināšanai

Lejupielādēt Pickup.cs. Atver esošo tāda paša nosaukuma failu un aizstāj tā saturu ar šo kodu.

using Godot;

public partial class Pickup : Area2D
{
    [Export] public PickupType Type = PickupType.Coin;
    private bool collected = false;

    public override void _Ready()
    {
        BodyEntered += OnBodyEntered;
    }

    private void OnBodyEntered(Node2D body)
    {
        if (collected || body is not Player player || !player.IsActive)
            return;

        collected = true;
        player.OnPickup(Type);
        QueueFree();
    }
}

Gatavs, kad: monēta pazūd, kad varonis tai pieskaras, un dod tieši 1 punktu.

3. uzdevums

Kopē priekšmetus un izvēlies Type (tips)

Kur strādāt: Priekšmetu eksemplārus, to Type un sadursmju ķeksīšus maini Scenes/Level1.tscn Inspector panelī.

  1. Level1 Scene panelī ar labo peles pogu uz Coin1 → Duplicate. Katru kopiju pārdēvē un Inspector laukos Position un Type ievadi tabulas vērtības. Maini izvēlēto kopiju Level1 cilnē.
  2. Lai atšķirtu Gem un Key, atlasi tos pa vienam un Inspector sadaļā Visibility → Modulate izvēlies atšķirīgas krāsas.
  3. Palaid ar F5 un savāc visus priekšmetus. Output jāparādās 9 punktiem un atslēga: True. Šodien augšējos priekšmetus vēl sasniedz ar W.
  4. Apturi spēli. Atlasi Coin1, sadaļā Collision → Mask izslēdz 2 un palaid vēlreiz. Monēta vairs nepazūd. Apturi un ieslēdz Mask 2 atpakaļ.
  5. Tāpat izmēģini Player laukā Mask izslēgt 1: varonis iet cauri platformām. Apturi un ieslēdz Mask 1 atpakaļ. Saglabā un vēlreiz pārbaudi gan platformas, gan savākšanu.

Papildu uzdevums — izveido savu priekšmeta simbolu

Kur strādāt: Atver Scenes/Pickup.tscn un maini mezgla Visual daudzstūra punktus.

Atver Pickup.tscn, atlasi Visual un Inspector sadaļā Data → Polygon maini punktus. Atstāj Pickup un CollisionShape2D savās vietās. Pārbaudi, ka redzamais simbols un savākšanas zona atrodas vienā vietā.
