Sasniedzamais rezultāts: Izveido grīdu, trīs platformas un priekšmetus, kas pazūd, kad varonis tiem pieskaras.

SR 2.4.14. Vadības struktūras SR 2.4.7. UI (lietotāja saskarne)

Teorija: nekustīgi šķēršļi, saskares zonas un signāli

Nekustīgs ķermenis (StaticBody2D) pret saskares zonu (Area2D)

2D fizikā nekustīgus vides objektus iedala divos pamata veidos — tos var salīdzināt ar mūra sienu un kustības sensoru pie automātiskajām durvīm:

  • StaticBody2D (nekustīga 2D ķermeņa mezgls) — ciets šķērslis, kas fiziski aptur kustīgus ķermeņus un neļauj tiem iziet cauri.
  • Area2D (2D saskares zona) — caurlaidīga zona, kas objektus fiziski neaptur, bet konstatē brīdi, kad tajā ieiet vai no tās iziet cits ķermenis. Lai zona aktīvi uztvertu citus objektus, tai jābūt ieslēgtai īpašībai Monitoring.

Abiem mezglu veidiem ir nepieciešams gan CollisionShape2D (2D sadursmes forma) ģeometriskajai kontūrai, gan vizuālais bērnmezgls (piemēram, Polygon2D), kā arī saskaņoti Collision Layer (piederības slānis) un Collision Mask (novērojamo slāņu maska) iestatījumi:

Siena (StaticBody2D)    → Layer: 1, Mask: —  (fiziski aptur kustīgu ķermeni)
├── CollisionShape2D    → šķēršļa sadursmes kontūra
└── Izskats (Polygon2D) → šķēršļa redzamā figūra

DurvjuSensors (Area2D)  → Layer: 3, Mask: 2, Monitoring: ieslēgts (tikai pamana)
├── CollisionShape2D    → uztveršanas zonas kontūra
└── Izskats (Polygon2D) → zonas vizuālais marķieris

Notikumu signāls BodyEntered, tipa pārbaude un QueueFree()

Kad saderīga slāņa fizikas ķermenis ieiet Area2D zonā, zona izstaro signālu BodyEntered. C# skriptā apstrādes metodi šim notikumam pieslēdz ar pierakstu BodyEntered += ApstradesMetode; metodē _Ready() - tas darbojas kā automātisks paziņojums notikuma brīdī, nevis nepārtraukta pārbaude katrā kadrā.

Tā kā parametrs saņem vispārīgu Node2D objektu, izteiksme body is not KonkretsTips mainigais droši atsijā svešus objektus un piešķir precīzu tipu tālākai metožu izsaukšanai. Lai objektu noņemtu no scēnas, lieto QueueFree() - tā droši izdzēš mezglu tekošā fizikas soļa beigās, bet papildu bool karodziņš novērš viena notikuma dubultu nostrādāšanu vienā kadrā:

public partial class Kontrolpunkts : Area2D
{
    private bool irApstradats = false;

    public override void _Ready()
    {
        BodyEntered += KadObjektsIeiet; // Pieslēdz apstrādātāju signālam
    }

    private void KadObjektsIeiet(Node2D body)
    {
        if (irApstradats || body is not KustigsObjekts objekts)
            return;

        irApstradats = true;
        objekts.RegistretAtzimi();
        QueueFree(); // Droši noņem mezglu fizikas soļa beigās
    }
}

Kopīgoti formas resursi un Make Unique

Dublējot mezglu redaktorā, jaunā kopija bieži saglabā atsauci uz to pašu iekšējo Shape resursu - līdzīgi kā divi dokumenti, kas piesaistīti vienai kopīgai veidnei. Ja vienai kopijai jāmaina sadursmes formas izmērs, neietekmējot pārējos eksemplārus, šo resursu vispirms atdala kā neatkarīgu (Make Unique).

1. uzdevums

Uzbūvē grīdu un trīs sasniedzamas platformas

Kur strādāt: Grīdu (Ground) un trīs platformas (Platform1, Platform2, Platform3) veido scēnā Scenes/Level1.tscn tieši zem saknes mezgla Level1.

│   └── Visual (Polygon2D, punkti: (-640,-20), (640,-20), (640,20), (-640,20))

  2. Pievieno sadursmes formu zem Ground: Scene panelī atlasi Ground un ar + pievieno CollisionShape2D. Inspector laukā Shape izvēlies New RectangleShape2D, noklikšķini uz izveidotās formas un iestati Size = (1280, 40) (pašam CollisionShape2D atstāj Position = (0, 0)).
  3. Pievieno Visual zem Ground: atkal atlasi Ground (nevis CollisionShape2D!) un ar + pievieno Polygon2D ar nosaukumu Visual. Inspector sadaļā Data → Polygon ievadi 4 punktus: (-640, -20), (640, -20), (640, 20), (-640, 20) un izvēlies redzamu krāsu laukā Color.

Zem Platform1 pievieno CollisionShape2D ar taisnstūra Size = (160, 20) un Visual (Polygon2D) ar punktiem (-80, -10), (80, -10), (80, 10), (-80, 10).
  5. Dublē Platform2 un Platform3 scēnā Scenes/Level1.tscn: Scene panelī ar labo peles pogu klikšķini uz Platform1 → Duplicate (Ctrl+D). Kopiju pārdēvē par Platform2 un iestati Position = (480, 470). Izveido vēl vienu kopiju Platform3 ar Position = (680, 380).
  6. Pārbaudi Collision Layer un Mask scēnā Scenes/Level1.tscn: pēc kārtas atlasi Ground, Platform1, Platform2, Platform3 un Player, un Inspector → Collision iestati Layer un Mask pēc tabulas zemāk. Saglabā scēnu (Ctrl+S), nospied F5 un ar W/A/S/D pārbaudi, ka varonis atduras pret grīdu un platformām.

Atceries 2. uzdevumam: savācamajam priekšmetam (Pickup) Inspector panelī jābūt ieslēgtam arī Monitoring, lai tas pamanītu varoni.

Ja maini vienas kopijas izmēru: atlasi tās CollisionShape2D, pie Shape atver izvēlni un spied Make Unique, un tikai tad maini Size (citādi mainīsies visu kopiju sadursmes forma). Pielāgo arī attiecīgā Visual punktus.

Gatavs, kad: scēnā Scenes/Level1.tscn ir redzama grīda un trīs platformas, un varonis fiziski apstājas pie tām.

2. uzdevums

Izveido un savāc pirmo monētu

Kur strādāt: Vispirms izveido atsevišķu priekšmeta scēnu Scenes/Pickup.tscn un tai piesaistītu skriptu Scripts/Pickup.cs. Pēc tam atver Scenes/Level1.tscn un ievieto tajā pirmo monētas eksemplāru Coin1.

Priekšmeta scēnas Scenes/Pickup.tscn mezglu koks:

Pickup (Area2D, skripts: Scripts/Pickup.cs, Layer: 3, Mask: 2, Monitoring: On)
├── CollisionShape2D (CircleShape2D, Radius: 12)
└── Visual (Polygon2D - rombs: (0,-12), (12,0), (0,12), (-12,0))
  1. Izveido jaunu scēnu Scenes/Pickup.tscn: izvēlies Scene → New Scene → Other Node, meklē Area2D un spied Create. Pārdēvē saknes mezglu par Pickup un ar Ctrl+S saglabā kā Scenes/Pickup.tscn.
  2. Scēnā Scenes/Pickup.tscn pievieno CollisionShape2D: atlasi Pickup un ar + pievieno CollisionShape2D. Inspector laukā Shape izvēlies New CircleShape2D, noklikšķini uz apļa formas un iestati Radius = 12.
  3. Scēnā Scenes/Pickup.tscn pievieno Visual: atkal atlasi Pickup (nevis CollisionShape2D!) un ar + pievieno Polygon2D ar nosaukumu Visual. Inspector → Data → Polygon ievadi 4 punktus (rombu): (0, -12), (12, 0), (0, 12), (-12, 0) un laukā Color izvēlies dzeltenu krāsu.
  4. Scēnā Scenes/Pickup.tscn iestati slāņus: atlasi saknes mezglu Pickup. Inspector → Collision ieslēdz tikai Layer 3 un Mask 2 (izslēdz Layer 1 un Mask 1) un pārliecinies, ka Monitoring ir ieslēgts (On).
  5. Izveido skriptu Scripts/Pickup.cs: scēnā Scenes/Pickup.tscn ar labo peles pogu klikšķini uz Pickup → Attach Script. Izvēlies Language: C#, ceļu res://Scripts/Pickup.cs un spied Create. Aizstāj Scripts/Pickup.cs saturu ar pilno kodu zemāk (signāls BodyEntered += OnBodyEntered; tiek pieslēgts kodā, tāpēc Node panelī nekas papildus nav jāspiež). Saglabā skriptu un scēnu Pickup.tscn, tad nospied Build.
  6. Ievieto Coin1 scēnā Scenes/Level1.tscn: pārslēdzies uz cilni Level1.tscn. No FileSystem paneļa ievelc Scenes/Pickup.tscn uz saknes mezgla Level1. Pārdēvē izveidoto eksemplāru par Coin1, tā Inspector → Transform → Position iestati (150, 600) un laukā Type izvēlies Coin.
  7. Pārbaudi savākšanu: saglabā Scenes/Level1.tscn, nospied F5 un aizved varoni līdz Coin1. Monētai jāpazūd, un apakšējā Output panelī jāparādās Punkti: 1; atslēga: False.
2.4 Pickup.cs - pilns fails salīdzināšanai

Lejupielādēt Pickup.cs. Atver failu Scripts/Pickup.cs un aizstāj tā saturu ar šo kodu.

using Godot;

public partial class Pickup : Area2D
{
    [Export] public PickupType Type = PickupType.Coin;
    private bool collected = false;

    public override void _Ready()
    {
        BodyEntered += OnBodyEntered;
    }

    private void OnBodyEntered(Node2D body)
    {
        if (collected || body is not Player player || !player.IsActive)
            return;

        collected = true;
        player.OnPickup(Type);
        QueueFree();
    }
}

Gatavs, kad: monēta Coin1 scēnā Scenes/Level1.tscn pazūd brīdī, kad varonis tai pieskaras, un piešķir tieši 1 punktu.

3. uzdevums

Kopē priekšmetus un izvēlies Type (tips)

Kur strādāt: Priekšmetu eksemplārus (Coin2, Gem, Coin3, Coin4, Key), to Type un Collision Mask iestatījumus maini scēnā Scenes/Level1.tscn; secinājumus par maskām pieraksti README.md.

  1. Izveido visus priekšmetus scēnā Scenes/Level1.tscn: Scene panelī ar labo peles pogu klikšķini uz Coin1 → Duplicate (Ctrl+D). Izveido 5 kopijas tieši zem Level1, pārdēvē tās un Inspector laukos Position un Type ievadi tabulas vērtības zemāk.
  2. Atšķir Gem un Key krāsu scēnā Scenes/Level1.tscn: Scene panelī atlasi Gem un Inspector → Visibility → Modulate izvēlies zilu vai violetu nokrāsu, bet mezglam Key — spilgti oranžu vai zaļganu nokrāsu, lai spēlētājs tos viegli atšķirtu no monētām.
  3. Pārbaudi visu priekšmetu savākšanu: saglabā Scenes/Level1.tscn, palaid ar F5 un savāc visus 6 priekšmetus (augšējās platformas šodien vēl sasniedz ar W). Output panelī beigās jābūt Punkti: 9; atslēga: True (4 monētas × 1 + 1 dārgakmens × 5 = 9).
  4. Izmēģini Mask 2 izslēgšanu priekšmetam Coin1: apturi spēli ar F8. Scēnā Scenes/Level1.tscn atlasi Coin1, sadaļā Collision → Mask izslēdz 2 un palaid ar F5 — monēta vairs nepamana spēlētāju un nepazūd. Apturi spēli un ieslēdz Coin1 Mask 2 atpakaļ.
  5. Izmēģini Mask 1 izslēgšanu mezglam Player un pieraksti README.md: scēnā Scenes/Level1.tscn atlasi Player, sadaļā Collision → Mask uz laiku izslēdz 1 un palaid ar F5 — varonis iet cauri grīdai un platformām. Apturi spēli, ieslēdz Player Mask 1 atpakaļ, saglabā Level1.tscn un failā README.md īsi paskaidro abus Mask eksperimentus.

Papildu uzdevums - izveido savu priekšmeta simbolu

Kur strādāt: Atver scēnu Scenes/Pickup.tscn un maini bērnmezgla Visual daudzstūra punktus.

Atver Scenes/Pickup.tscn, Scene panelī atlasi Visual un Inspector → Data → Polygon izveido savu formu (piemēram, 6 vai 8 virsotņu kristālu). Atstāj Pickup un CollisionShape2D pozīcijā (0, 0) un pārbaudi, ka redzamā figūra sakrīt ar apļa sadursmes zonu.
