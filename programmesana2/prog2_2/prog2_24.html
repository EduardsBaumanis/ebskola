2.4 Platformas un savācamie priekšmeti

Stundas uzdevums: Izveido grīdu, trīs platformas un priekšmetus, kas pazūd, kad varonis tiem pieskaras.

SR 2.4.14. Control structure (vadības struktūras) SR 2.4.7. UI (lietotāja saskarne)

80 min plāns: Ievads (~10 min) · grīda un platformas (~20 min) · priekšmeti (~25 min) · collision (sadursmju) pārbaudes (~20 min) · save (saglabāšana) (~5 min).

Pirms sāc: atver savu Level1.tscn un izmanto 2.3 stundas Player.cs. Pagaidu _Ready() pārbaudei jābūt izdzēstai. Šodien vēl kustamies četros virzienos, lai ērti pārbaudītu visu laukumu.

Pēc izmaiņām: saglabā file (failus). Ja mainīji C# code (kodu), Godot augšējā labajā stūrī nospied Build (būvēt projektu) (āmura icon (ikona)). Tad palaid spēli. Pirms nākamā uzdevuma izlabo pirmo parādīto kļūdu.

Ko izvēlēties un kur likt checkbox (ķeksīšus)

Grīdai un platformām izvēlies StaticBody2D (nekustīga 2D ķermeņa mezgls): tas aptur varoni. Priekšmetiem izvēlies Area2D (2D saskares zona): varonis tiem var pieskarties un tos savākt.

Katram vajag divas daļas: Visual parāda izskatu, CollisionShape2D (2D sadursmes forma) nosaka saskares vietu.

Scene (scēna) panel (panelī) atlasi object (objektu) un Inspector (īpašību panelis) atver Collision (sadursme). Rindā Layer (slānis) atzīmē, kurai grupai object (objekts) pieder. Rindā Mask (maska) — kuru grupu tas pamana. Klikšķini uz numurētajiem kvadrātiņiem pēc šīs tabulas; pārējos izslēdz.

Ko atlasi Scene (scēna) panel (panelī)Layer (slānis)Mask (maska)
Ground, Platform1, Platform2, Platform3tikai 1neviens

Priekšmetam jābūt ieslēgtam arī Monitoring (saskares noteikšana). Tad tas pamanīs varoni. Šos settings (iestatījumus) maini Inspector (īpašību panelis) panel (panelī).

1. uzdevums -

Uzbūvē grīdu un trīs sasniedzamas platformas

  1. FileSystem (failu sistēma) → Scenes (scēnas) ar double-click (dubultklikšķi) atver Level1.tscn. Scene (scēna) panel (panelī) atlasi Level1, spied +, meklē StaticBody2D (nekustīga 2D ķermeņa mezgls) un spied Create (izveidot). Ar F2 nosauc to Ground. Inspector (īpašību panelis) sadaļā Transform (pārveidojums) → Position (pozīcija) ievadi (640,660).
  2. Atlasi Ground un ar + pievieno CollisionShape2D (2D sadursmes forma). Inspector (īpašību panelis) field (laukā) Shape (forma) izvēlies New RectangleShape2D (jauna 2D taisnstūra forma). Klikšķini uz izveidotās formas un field (laukā) Size (izmērs) ievadi (1280,40). Pašam CollisionShape2D (2D sadursmes forma) atstāj Position (pozīcija) = (0,0).
  3. Atkal atlasi Ground un ar + pievieno Polygon2D (2D daudzstūris), nosauc to Visual. Inspector (īpašību panelis) sadaļā Data (dati) → Polygon (daudzstūris) ievadi četrus punktus: (-640,-20), (640,-20), (640,20), (-640,20). Field (laukā) Color (krāsa) izvēlies redzamu krāsu.
  4. Atlasi Level1 un tāpat izveido otru StaticBody2D (nekustīga 2D ķermeņa mezgls) ar nosaukumu Platform1. Tā Position (pozīcija) = (280,560), Scale (mērogs) = (1,1). Pievieno CollisionShape2D (2D sadursmes forma) ar taisnstūra Size (izmērs) = (160,20) un Visual ar punktiem (-80,-10), (80,-10), (80,10), (-80,10).
  5. Scene (scēna) panel (panelī) ar labo mouse (peles) button (pogu) uz Platform1 → Duplicate (dublēt). Kopiju nosauc Platform2 un iestati Position (pozīcija) = (480,470). Izveido vēl vienu kopiju Platform3 ar Position (pozīcija) = (680,380).
  6. Pēc kārtas atlasi grīdu, katru platformu un Player. Inspector (īpašību panelis) sadaļā Collision (sadursme) atzīmē Layer (slānis) un Mask (maska) pēc tabulas. Saglabā un nospied F5. Ar S mēģini iet grīdā, ar D — platformas sānos: varonim jāapstājas.

Ja maini kopijas izmēru: atlasi tās CollisionShape2D (2D sadursmes forma). Pie Shape (forma) atver menu (izvēlni) un spied Make Unique (izveidot neatkarīgu kopiju), tad maini Size (izmērs). Tā pārējo kopiju formas paliks iepriekšējā izmērā. Pielāgo arī Visual punktus.

Gatavs, kad: varonis apstājas pie šķēršļiem un līmenī ir redzama grīda un trīs platformas.

2. uzdevums -

Izveido un savāc pirmo monētu

  1. Izvēlies Scene (scēna) → New Scene (jauna scēna) → Other Node (cits mezgls), meklē Area2D (2D saskares zona) un spied Create (izveidot). Nosauc to Pickup un saglabā Scenes/Pickup.tscn.
  2. Atlasi Pickup un ar + pievieno CollisionShape2D (2D sadursmes forma). Inspector (īpašību panelis) field (laukā) Shape (forma) izvēlies New CircleShape2D (jauna 2D apļa forma). Klikšķini uz izveidotās formas un iestati Radius (rādiuss) = 12.
  3. Atkal atlasi Pickup un pievieno Polygon2D (2D daudzstūris) ar nosaukumu Visual. Sadaļā Data (dati) → Polygon (daudzstūris) ievadi četrus punktus: (0,-12), (12,0), (0,12), (-12,0). Field (laukā) Color (krāsa) izvēlies dzeltenu krāsu.
  4. Atlasi Pickup. Inspector (īpašību panelis) sadaļā Collision (sadursme) ieslēdz tikai Layer (slānis) 3 un Mask (maska) 2. Pārbaudi, ka Monitoring (saskares noteikšana) ir ieslēgts.
  5. Ar labo mouse (peles) button (pogu) uz Pickup → Attach Script (pievienot skriptu). Izvēlies C#, path (ceļu) res://Scripts/Pickup.cs un spied Create (izveidot). Aizstāj file (faila) saturu ar code (kodu) zemāk. Tas jau apstrādā pieskaršanos; Godot Signals (signāli) panel (panelī) nekas papildus nav jāsavieno.
  6. Saglabā file (failu) un scene (scēnu), nospied Build (būvēt projektu). Atver Level1 tab (cilni). No FileSystem (failu sistēma) ievelc Pickup.tscn uz Level1 Scene (scēna) panel (panelī). Pārdēvē pievienoto object (objektu) par Coin1. Inspector (īpašību panelis) iestati Position (pozīcija) = (150,600) un field (laukā) Type (tips) izvēlies Coin.
  7. Saglabā, nospied F5 un pieved varoni pie monētas. Tai jāpazūd. Apakšējā Output (izdrukām) panel (panelī) jāparādās 1 punktam. Atgriezies tajā pašā vietā: otru punktu tā nedod.
2.4 Pickup.cs — pilns file (fails) salīdzināšanai

Lejupielādēt Pickup.cs. Atver esošo tāda paša nosaukuma file (failu) un aizstāj tā saturu ar šo code (kodu).

using Godot;

public partial class Pickup : Area2D
{
    [Export] public PickupType Type = PickupType.Coin;
    private bool collected = false;

    public override void _Ready()
    {
        BodyEntered += OnBodyEntered;
    }

    private void OnBodyEntered(Node2D body)
    {
        if (collected || body is not Player player || !player.IsActive)
            return;

        collected = true;
        player.OnPickup(Type);
        QueueFree();
    }
}

Gatavs, kad: monēta pazūd, kad varonis tai pieskaras, un dod tieši 1 punktu.

3. uzdevums -

Kopē priekšmetus un izvēlies Type (tips)

  1. Level1 Scene (scēna) panel (panelī) ar labo mouse (peles) button (pogu) uz Coin1 → Duplicate (dublēt). Katru kopiju pārdēvē un Inspector (īpašību panelis) field (laukos) Position (pozīcija) un Type (tips) ievadi tabulas value (vērtības). Maini izvēlēto kopiju Level1 tab (cilnē).
  2. Lai atšķirtu Gem un Key, atlasi tos pa vienam un Inspector (īpašību panelis) sadaļā Visibility (redzamība) → Modulate (krāsas tonējums) izvēlies atšķirīgas krāsas.
  3. Palaid ar F5 un savāc visus priekšmetus. Output (izdrukām) jāparādās 9 punktiem un atslēga: True. Šodien augšējos priekšmetus vēl sasniedz ar W.
  4. Apturi spēli. Atlasi Coin1, sadaļā Collision (sadursme) → Mask (maska) izslēdz 2 un palaid vēlreiz. Monēta vairs nepazūd. Apturi un ieslēdz Mask (maska) 2 atpakaļ.
  5. Tāpat izmēģini Player field (laukā) Mask (maska) izslēgt 1: varonis iet cauri platformām. Apturi un ieslēdz Mask (maska) 1 atpakaļ. Saglabā un vēlreiz pārbaudi gan platformas, gan savākšanu.

Papildu uzdevums — izveido savu priekšmeta simbolu

Atver Pickup.tscn, atlasi Visual un Inspector (īpašību panelis) sadaļā Data (dati) → Polygon (daudzstūris) maini punktus. Atstāj Pickup un CollisionShape2D (2D sadursmes forma) savās vietās. Pārbaudi, ka redzamais simbols un savākšanas zona atrodas vienā vietā.

Ko sagatavo

Stundas mērķis: varonis atduras pret platformām, savāc punktus un atslēgu.

GitHub repository (krātuvē) jābūt:

  1. Pickup.tscn, Pickup.cs un papildināts Level1.tscn.
  2. Video vai attēli ar collision (sadursmi) un savākšanas rezultātu; README.md skaidrojums par abām Mask (maska) pārbaudēm.

Saglabā visu project (projektu): project.godot, .csproj, scene (scēnas), script (skriptus) un izmantotos attēlus. .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.

Kā iesniedz: saglabā izmaiņas Git un nosūti tās uz GitHub tāpat kā 1. tēmā (commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi)). Skolotāja norādītajā vietā iesniedz GitHub repository (krātuves) link (saiti); README.md un pārbaudes pierādījumiem jābūt repository (krātuvē).
