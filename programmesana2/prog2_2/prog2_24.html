2.4 Sadursmju noteikšana

Stundas uzdevums: Uzbūvēt līmeņa platformas un ar Area2D savākt punktus un atslēgu.

SR 2.4.14. Vadības struktūras SR 2.4.7. UI

80 min plāns: Ievads (~10 min) · grīda un platformas (~20 min) · priekšmeti (~25 min) · sadursmju pārbaudes (~20 min) · saglabāšana (~5 min).

Pirms sāc: vajadzīgi 2.3 Player.cs ar publisku OnPickup un Level1.tscn. Noņem pagaidu priekšmetu piešķiršanu _Ready metodē. Šodien vēl kustamies četros virzienos, lai ērti pārbaudītu visu laukumu.

Darba ritms: pēc katra uzdevuma saglabā, nospied Build un pārbaudi rezultātu. Kļūdu gadījumā sāc ar pirmo sarkano kļūdu, nevis nākamo uzdevumu.

Teorija: šķērslis un notikuma zona

StaticBody2D aptur spēlētāju, Area2D pamana ieiešanu zonā, bet neaiztur kustību. Abiem vajadzīga CollisionShape2D forma; redzamam izskatam atsevišķi vajag Visual.

Layer norāda, kurā slānī objekts atrodas. Mask norāda, kurus slāņus tas pārbauda. Lai monētas BodyEntered pamanītu spēlētāju 2. slānī, pašas monētas Mask jābūt 2, Monitoring jābūt ieslēgtam. Skati Area2D dokumentāciju.

Ground un Platform (StaticBody2D)tikai 1neviens
Player (CharacterBody2D)tikai 2tikai 1

Tabulā ir Inspector ķeksīšu numuri. Failā .tscn tie glabājas kā bitu maskas: 1. slānis = 1, 2. = 2, 3. = 4. Noņem visus liekos noklusējuma ķeksīšus.

1. uzdevums -

Uzbūvē grīdu un trīs sasniedzamas platformas

  1. Atver Level1.tscn. Pievieno saknes bērnu StaticBody2D ar nosaukumu Ground, Position = (640,660).
  2. Ground pievieno CollisionShape2D: New RectangleShape2D, Size = (1280,40). Bērna Position = (0,0). Pievieno Polygon2D bērnu Visual ar punktiem (-640,-20), (640,-20), (640,20), (-640,20) un redzamu krāsu.
  3. Līdzīgi izveido StaticBody2D Platform1: Position = (280,560), formas Size = (160,20), Visual punkti (-80,-10), (80,-10), (80,10), (-80,10). Saknes Scale atstāj (1,1).
  4. Dublē Platform1 par Platform2 un Platform3; Position attiecīgi (480,470) un (680,380). Ja kādai kopijai maini formas izmēru, Shape resursam vispirms izvēlies Make Unique, lai neizmainītu visas kopijas.
  5. Iestati Layer un Mask visām platformām, grīdai un Player pēc tabulas. F5 laikā ar S mēģini iebraukt grīdā, ar D — platformas sānos.

Gatavs, kad: spēlētājs apstājas pie fiziskajiem šķēršļiem un līmenī ir redzama grīda un trīs platformas.

2. uzdevums -

Savieno priekšmetu ar spēlētāja punktiem

  1. Izveido jaunu scēnu ar Area2D sakni Pickup, saglabā res://Scenes/Pickup.tscn. Pievieno CollisionShape2D ar CircleShape2D, Radius = 12.
  2. Pievieno Polygon2D bērnu Visual: punkti (0,-12), (12,0), (0,12), (-12,0). Izvēlies dzeltenu krāsu. Iestati Pickup Layer tikai 3, Mask tikai 2, Monitoring = On.
  3. Pickup saknei pievieno res://Scripts/Pickup.cs un ievieto zemāk doto pilno kodu. Tas pats savieno signālu; editorā BodyEntered otrreiz nepievieno.
  4. Build, tad Level1 scēnā ievelc Pickup instanci: nosaukums Coin1, Position = (150,600), Inspector Type = Coin. Ar F5 piebrauc tai klāt.
  5. Pārbaudi: priekšmets pazūd un Output ir 1 punkts. body is Player player nodrošina, ka savāc tikai spēlētājs; collected aizsargā pret atkārtotu pieskaitīšanu pirms QueueFree pabeigšanas.
2.4 Pickup.cs — pilns fails salīdzināšanai

Lejupielādēt Pickup.cs. Aizstāj tikai atbilstošā faila saturu; neveido otru tāda paša nosaukuma klasi.

using Godot;

public partial class Pickup : Area2D
{
    [Export] public PickupType Type = PickupType.Coin;
    private bool collected = false;

    public override void _Ready()
    {
        BodyEntered += OnBodyEntered;
    }

    private void OnBodyEntered(Node2D body)
    {
        if (collected || body is not Player player || !player.IsActive)
            return;

        collected = true;
        player.OnPickup(Type);
        QueueFree();
    }
}

Gatavs, kad: reāla sadursme izsauc 2.3 izveidoto OnPickup un priekšmets dod punktus tikai vienreiz.

3. uzdevums -

Pievieno atlīdzības un atslēgu, pārbaudi slāņus

  1. Level1 pievieno pārējās Pickup instances pēc tabulas. Type maini katrai instancei Inspector, nevis visai Pickup scēnai. Gem un Key vari atšķirt ar instances Modulate krāsu.
  2. Savāc visus priekšmetus: 4 Coin dod 4 punktus, Gem — 5, kopā 9. Key iestata HasKey = true. Šajā stundā tos sasniedz ar četru virzienu kustību.
  3. Uz laiku Coin1 noņem Mask 2: tā vairs nepamana spēlētāju. Atjauno Mask 2. Tad Player noņem Mask 1: tas iet cauri platformām. Atjauno Mask 1.
  4. Palaid vēlreiz: visi priekšmeti ir atpakaļ, punkti sākas ar 0 un atslēga nav savākta. Saglabā strādājošo stāvokli.

Papildu uzdevums — izveido savu priekšmeta simbolu

Maini Visual virsotnes vai pievieno savu Sprite2D attēlu. Saglabā Pickup Area2D sakni, skriptu un sadursmes formu. Pārbaudi, ka redzamais simbols un savākšanas zona atrodas vienā vietā.

Ko sagatavo

Stundas mērķis: redzamie priekšmeti spēlē izmanto jau pārbaudīto punktu un atslēgas loģiku.

GitHub krātuvē jābūt:

  1. Pickup.tscn, Pickup.cs un papildināts Level1.tscn.
  2. Video vai attēli ar sadursmi un savākšanas rezultātu; README.md skaidrojums par abām Mask pārbaudēm.

Saglabā visu projektu: project.godot, .csproj, scēnas, skriptus un izmantotos attēlus. .gitignore ieraksti .godot/, bin/ un obj/ katru savā rindā.

Kā iesniedz: veic commit un push. Skolotāja norādītajā vietā iesniedz GitHub krātuves saiti; README.md un pārbaudes pierādījumiem jābūt krātuvē.
