Teorija: ceļa meklēšanas algoritms A* un navigācijas tīkls

Ceļa meklēšana (pathfinding) un A* novērtējuma funkcija

Virzoties taisnā līnijā tieši pret mērķa koordinātām, kustīgais objekts apstājas pie pirmās šķērssienas vai U veida norobežojuma. Ceļa meklēšana (pathfinding) pārvietošanās telpu attēlo kā savienotu punktu jeb virsotņu grafu un atrod tajā īsāko brīvo maršrutu — līdzīgi kā navigācijas lietotne telefonā nevelk taisnu līniju cauri ēkām un upei, bet izplāno ceļu pa pieejamajām ielām un tiltiem.

Viens no efektīvākajiem maršruta meklēšanas algoritmiem ir A* (A-star), kas katram kandidāta punktam n aprēķina trīs lielumus:

  • g(n) — faktiski jau veiktais ceļa garums no sākumpunkta līdz punktam n;
  • h(n) — heuristika (heuristic) jeb aptuvenais novērtējums (parasti taisnais attālums) no punkta n līdz galamērķim;
  • f(n) = g(n) + h(n) — kopējais novērtējums; algoritms vienmēr pirmo pārbauda to virzienu, kuram f(n) ir vismazākais, tāpēc lieki nepēta ceļus pretējā pusē.

Navigācijas reģions (NavigationRegion2D) un NavigationAgent2D

Godot 4 vidē ceļa meklēšana ir sadalīta divās daļās: mezgls NavigationRegion2D ar resursu NavigationPolygon apraksta brīvi šķērsojamo laukumu, no kura ar darbību Bake NavigationPolygon izgriež nekustīgos šķēršļus, izveidojot navigācijas tīklu (navigation mesh) (ja mērķis nonāk ārpus šī tīkla, ceļš ved līdz tuvākajai sasniedzamajai malas vietai).

Savukārt kustīgajam CharacterBody2D kā bērnmezglu pievieno NavigationAgent2D, kas A* aprēķinu veic automātiski: īpašībai TargetPosition uzdod mērķa koordinātas, ar IsNavigationFinished() pārbauda, vai maršruts jau pabeigts, bet ar GetNextPathPosition() katrā fizikas solī nolasa nākamo pagrieziena punktu:

if (navAgents.IsNavigationFinished()) return;

Vector2 nakamaisPunkts = navAgents.GetNextPathPosition();
Vector2 virziens = (nakamaisPunkts - Position).Normalized();
Velocity = virziens * Atrums;
MoveAndSlide();

Praktiskie uzdevumi

1. uzdevums -

Sagatavo navigation region

Kur strādāt: Godot redaktorā atver spēles līmeņa scēnu un šajā tēmā saglabā to kā Scenes/Arena.tscn. Tajā veido navigācijas reģionu un sienas.

Beigās Godot zinās, pa kurām vietām drīkst staigāt.

  1. Pievieno scēnai node NavigationRegion2D (2D navigācijas reģions).
  2. Izveido tam NavigationPolygon (navigācijas daudzstūris) resursu Inspector panelī.
  3. Uzzīmē daudzstūri, kas aptver visu staigājamo laukumu.
  4. Pievieno laukumā divas sienas kā StaticBody2D (nekustīga 2D ķermeņa mezgls).
  5. Izgriez navigācijas daudzstūrī caurumus ap sienām.
  6. Nospied Bake NavigationPolygon (aprēķināt navigācijas daudzstūri).
  7. Pārbaudi, ka zilā zona neiet pāri sienām.

Gatavs, kad: navigation region aptver grīdu, bet ne sienas, un tā ir redzama redaktorā zilā krāsā.

2. uzdevums -

Liec ienaidniekam sekot ceļam

Kur strādāt: NavigationAgent2D pievieno ienaidnieka scēnā Scenes/Enemy.tscn (saglabā tajā esošo ienaidnieku, ja atsevišķas scēnas vēl nav). Papildini Scripts/Enemy.cs: aģenta atsauci glabā klases laukā, atrodi to _Ready(), mērķa un kustības kodu pievieno _PhysicsProcess() dzīšanās stāvoklim.

Beigās ienaidnieks apstaigās sienu, nevis iestrēgs tajā.

  1. Pievieno ienaidniekam child node (bērnu) NavigationAgent2D.
  2. Atver ienaidnieka C# failu un pārliecinies, ka sākumā ir using Godot;.
  3. Paņem aģentu kodā ar NavigationAgent2D agent = GetNode<NavigationAgent2D>("NavigationAgent2D");.
  4. Iestati mērķi ar agent.TargetPosition = playerPos;.
  5. Paņem nākamo punktu ar Vector2 next = agent.GetNextPathPosition();.
  6. Virzies uz to ar (next - Position).Normalized() * Speed.
  7. Būvē un noliec spēlētāju aiz sienas.
private NavigationAgent2D navAgent;
[Export] public float Speed = 180.0f;

public override void _Ready()
{
    navAgent = GetNode<NavigationAgent2D>("NavigationAgent2D");
}

// Metodē _PhysicsProcess(double delta) dzīšanās režīmā:
navAgent.TargetPosition = playerPos;
if (!navAgent.IsNavigationFinished())
{
    Vector2 nextPos = navAgent.GetNextPathPosition();
    Vector2 dir = (nextPos - Position).Normalized();
    Velocity = dir * Speed;
    MoveAndSlide();
}

Gatavs, kad: ienaidnieks apiet sienu apkārt un nonāk pie spēlētāja, nevis spiežas sienā.

3. uzdevums -

Salīdzini taisno kustību ar pathfinding

Kur strādāt: Taisno kustību un ceļa sekošanu pārmaiņus izmēģini Scripts/Enemy.cs metodē _PhysicsProcess(). Spēlētāja vietu maini Scenes/Arena.tscn; rezultātus raksti README.md.

Beigās tu redzēsi, ko tieši pathfinding atrisina.

  1. Nomaini kodu uz taisnu kustību tieši pret spēlētāju, bez agenta.
  2. Noliec spēlētāju aiz sienas un palaid.
  3. Pieraksti, kur ienaidnieks apstājās.
  4. Ieliec pathfinding kodu atpakaļ un atkārto to pašu testu.
  5. Pieraksti, cik ilgi tagad aizņēma nonākšana pie spēlētāja.
  6. Pārbaudi, kas notiek, ja spēlētājs ir ārpus navigācijas zonas.
  7. Pieraksti, ko dara g un ko h A* algoritmā.

Gatavs, kad: bez pathfinding ienaidnieks iestrēgst pie sienas, bet ar to - apiet apkārt.

Papildu uzdevums - Zīmē ceļu uz ekrāna

Kur strādāt: Line2D pievieno Scenes/Enemy.tscn. Tā atsauci un punktu atjaunošanu pievieno Scripts/Enemy.cs: mezglu atrodi _Ready(), ceļu atjauno _PhysicsProcess().

Ja pamatdarbs ir gatavs, parādi, pa kuru ceļu ienaidnieks iet.

  1. Paņem pilnu ceļu ar agent.GetCurrentNavigationPath();.
  2. Pievieno scēnai Line2D (2D līnija) node.
  3. Iestati tā punktus uz ceļa punktiem katrā kadrā.
  4. Palaid un vēro, kā līnija mainās, kustinot spēlētāju.
  5. Pieraksti, cik punktu parasti ir ceļā.

Gatavs, kad: ekrānā redzama līnija, kas rāda ienaidnieka plānoto ceļu ap sienu.

Biežākās kļūdas

  • NavigationAgent neatrod ceļu: NavigationPolygon nav baked vai nepareiza forma.
  • Ienaidnieki iestrēgst stūros: Ceļš radius (rādiuss) pārāk mazs vai šķēršļi pārāk tuvu.
  • Slow veiktspēja: Pārāk daudz NavigationAgent - pārbaudi update freq.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

using Godot;

public partial class Enemy : CharacterBody2D
{
    private NavigationAgent2D navAgent;
    private Player player;
    [Export] public float Speed = 180.0f;

    public override void _Ready()
    {
        navAgent = GetNode<NavigationAgent2D>("NavigationAgent2D");
        navAgent.AvoidanceEnabled = true;
        UpdateTarget();
    }

    public override void _PhysicsProcess(double delta)
    {
        if (navAgent.IsNavigationFinished()) return;

        Vector2 next = navAgent.GetNextPathPosition();
        Vector2 direction = (next - Position).Normalized();

        Velocity = direction * Speed;
        MoveAndSlide();
    }

    private void UpdateTarget()
    {
        if (player != null) navAgent.TargetPosition = player.Position;
    }
}
Ienaidnieks atrod ceļu ap šķēršļiem un dzenas spēlētājam pa optimālo trasi, vairāki ienaidnieki nesaduras.
