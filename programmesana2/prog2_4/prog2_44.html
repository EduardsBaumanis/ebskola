SR 2.4.19. Algoritmu efektivitāte SR 2.4.16. Data structure (datu struktūras)

Teorija: ceļa meklēšanas algoritms A* un navigācijas tīkls

Ceļa meklēšana (pathfinding) un A* novērtējuma funkcija

Virzoties taisnā līnijā tieši pret mērķa koordinātām, kustīgais objekts apstājas pie pirmās šķērssienas vai U veida norobežojuma. Ceļa meklēšana (pathfinding) pārvietošanās telpu attēlo kā savienotu punktu jeb virsotņu grafu un atrod tajā īsāko brīvo maršrutu — līdzīgi kā navigācijas lietotne telefonā nevelk taisnu līniju cauri ēkām un upei, bet izplāno ceļu pa pieejamajām ielām un tiltiem.

Viens no efektīvākajiem maršruta meklēšanas algoritmiem ir A* (A-star), kas katram kandidāta punktam n aprēķina trīs lielumus:

  • g(n) — faktiski jau veiktais ceļa garums no sākumpunkta līdz punktam n;
  • h(n) — heuristika (heuristic) jeb aptuvenais novērtējums (parasti taisnais attālums) no punkta n līdz galamērķim;
  • f(n) = g(n) + h(n) — kopējais novērtējums; algoritms vienmēr pirmo pārbauda to virzienu, kuram f(n) ir vismazākais, tāpēc lieki nepēta ceļus pretējā pusē:
Vector2 merkaPunkts = new Vector2(500, 100);

// Kandidāts A (virzienā uz mērķi): veiktais ceļš g = 120 px
Vector2 punktsA = new Vector2(200, 100);
float fA = 120.0f + punktsA.DistanceTo(merkaPunkts); // 120 + 300 = 420

// Kandidāts B (pretējā virzienā): veiktais ceļš g = 120 px
Vector2 punktsB = new Vector2(0, 100);
float fB = 120.0f + punktsB.DistanceTo(merkaPunkts); // 120 + 500 = 620

// A* pirmo pārbauda punktsA, jo novērtējums fA (420) < fB (620).

Navigācijas reģions (NavigationRegion2D) un NavigationAgent2D

Godot 4 vidē ceļa meklēšana ir sadalīta divās daļās: mezgls NavigationRegion2D ar resursu NavigationPolygon apraksta brīvi šķērsojamo laukumu, no kura ar darbību Bake NavigationPolygon izgriež nekustīgos šķēršļus, izveidojot navigācijas tīklu (navigation mesh) (ja mērķis nonāk ārpus šī tīkla, ceļš ved līdz tuvākajai sasniedzamajai malas vietai).

Savukārt kustīgajam CharacterBody2D kā bērnmezglu pievieno NavigationAgent2D, kas A* aprēķinu veic automātiski: īpašībai TargetPosition uzdod mērķa koordinātas, ar IsNavigationFinished() pārbauda, vai maršruts jau pabeigts, bet ar GetNextPathPosition() katrā fizikas solī nolasa nākamo pagrieziena punktu:

private NavigationAgent2D navAgents;
[Export] public float Atrums = 180.0f;

public override void _Ready()
{
    navAgents = GetNode<NavigationAgent2D>("NavigationAgent2D");
}

public override void _PhysicsProcess(double delta)
{
    navAgents.TargetPosition = merkaKoordinatas;
    if (navAgents.IsNavigationFinished()) return;

    Vector2 nakamaisPunkts = navAgents.GetNextPathPosition();
    Velocity = (nakamaisPunkts - Position).Normalized() * Atrums;
    MoveAndSlide();
}

1. uzdevums

Sagatavo NavigationRegion2D un sienas scēnā Arena.tscn

Kur strādāt: Godot redaktorā atver 4.3. stundā izveidoto spēles laukuma scēnu Scenes/Arena.tscn. Tajā zem saknes Arena pievieno NavigationRegion2D un divus StaticBody2D sienu mezglus (Wall1 un Wall2), un izcep (Bake) navigācijas daudzstūri.

Beigās Godot redaktorā redzēsi zilu navigācijas tīklu, kas aptver brīvo grīdu un automātiski apiet abas sienas.

  1. Godot redaktorā atver Scenes/Arena.tscn. Scene panelī atlasi sakni Arena, ar + pievieno mezglu NavigationRegion2D un pārvelc to saraksta augšgalā (pirms Player un Enemy).
  2. Atlasi NavigationRegion2D un kā tā bērnmezglu pievieno StaticBody2D ar nosaukumu Wall1 pozīcijā (450, 260). Zem Wall1 pievieno CollisionShape2D (New RectangleShape2D ar izmēru 40 × 260) un pelēku Polygon2D (Visual, punkti (-20,-130), (20,-130), (20,130), (-20,130)).
  3. Atlasi Wall1, nospied Ctrl+D, lai izveidotu otru sienu Wall2 zem NavigationRegion2D, un novieto Wall2 pozīcijā (800, 460) (tagad Wall1 atrodas tieši starp Player (200, 360) un Enemy (700, 360)).
  4. Atlasi NavigationRegion2D un Inspector panelī laukā Navigation Polygon izvēlies New NavigationPolygon. Noklikšķini uz izveidotā resursa, atver sadaļu Geometry → Parsed Geometry Type un izvēlies Static Colliders (lai cepot tiktu izgrieztas StaticBody2D sienas).
  5. 2D skatloga augšējā rīkjoslā izvēlies punktu zīmēšanas rīku (Create Points) un apvelc ārējo četrstūri pa spēles laukuma malām: (20, 20) → (1260, 20) → (1260, 700) → (20, 700) un noslēdz kontūru sākumpunktā.
  6. Augšējā rīkjoslā nospied Bake NavigationPolygon. Pārliecinies, ka zilā zona klāj laukumu, bet ap Wall1 un Wall2 ir izgriezti caurumi, un saglabā Scenes/Arena.tscn.
Arena (Node2D) — Scenes/Arena.tscn
├── NavigationRegion2D (ar izceptu NavigationPolygon 1280×720)
│   ├── Wall1 (StaticBody2D + CollisionShape2D + Visual)

Gatavs, kad: Scenes/Arena.tscn redzama gaiši zila navigācijas zona, kas neiet pāri Wall1 un Wall2 sienām.

2. uzdevums

Pievieno NavigationAgent2D un liec ienaidniekam apiet sienu

Kur strādāt: Atver ienaidnieka scēnu Scenes/Enemy.tscn un pievieno tai bērnmezglu NavigationAgent2D. Pēc tam papildini Scripts/Enemy.cs: aģenta lauku pievieno klasē, mezglu atrodi _Ready(), bet ceļa sekošanas metodi ChasePlayer() izsauc no _PhysicsProcess().

Beigās ienaidnieks pats atradīs ceļu apkārt sienai un nonāks pie spēlētāja.

  1. Godot redaktorā atver Scenes/Enemy.tscn, atlasi sakni Enemy, ar + pievieno bērnmezglu NavigationAgent2D (atstāj nosaukumu NavigationAgent2D) un saglabā scēnu.
  2. Atver failu Scripts/Enemy.cs un klases Enemy laukos pievieno protected NavigationAgent2D navAgent; un [Export] public bool UsePathfinding = true;.
  3. Faila Scripts/Enemy.cs metodē _Ready() (blakus player atrašanai) atrodi aģenta mezglu: navAgent = GetNodeOrNull<NavigationAgent2D>("NavigationAgent2D");.
  4. Failā Scripts/Enemy.cs pievieno metodi protected void ChasePlayer() pēc parauga zemāk: tā uzdod mērķi navAgent.TargetPosition = player.GlobalPosition;, nolasa nākamo pagrieziena punktu ar navAgent.GetNextPathPosition() un virza ienaidnieku uz to ar MoveAndSlide().
  5. Metodē _PhysicsProcess(double delta) failā Scripts/Enemy.cs palielini pamanīšanas attālumu no 300.0f uz 600.0f (un atgriešanās slieksni uz 700.0f), bet case EnemyState.Chase: zarā aizstāj veco taisno kustību ar izsaukumu ChasePlayer();.
  6. Saglabā failu, nospied Build un palaid Scenes/Arena.tscn ar F6. Nostājies ar spēlētāju aiz Wall1 vai Wall2 un pārliecinies, ka ienaidnieks apiet sienu apkārt.
// Scripts/Enemy.cs — lauki, _Ready() un ChasePlayer() metode:
protected NavigationAgent2D navAgent;
[Export] public bool UsePathfinding = true;

public override void _Ready()
{
    player = GetParent()?.GetNodeOrNull<Node2D>("Player");
    navAgent = GetNodeOrNull<NavigationAgent2D>("NavigationAgent2D");
}

protected void ChasePlayer()
{
    Vector2 dir;
    if (UsePathfinding && navAgent != null)
    {
        navAgent.TargetPosition = player.GlobalPosition;
        Vector2 nextPos = navAgent.GetNextPathPosition();
        dir = (nextPos - GlobalPosition).Normalized();
    }
    else
    {
        dir = (player.GlobalPosition - GlobalPosition).Normalized();
    }

    Velocity = dir * Speed;
    MoveAndSlide();
}

Gatavs, kad: ienaidnieks scēnā Scenes/Arena.tscn apiet Wall1 un Wall2 un sasniedz spēlētāju, nevis spiežas sienā.

3. uzdevums

Salīdzini taisno kustību ar A* pathfinding

Kur strādāt: Taisno kustību un A* ceļa meklēšanu salīdzini, pārslēdzot UsePathfinding īpašību scēnā Scenes/Arena.tscn (Enemy mezgla Inspector panelī) vai failā Scripts/Enemy.cs. Rezultātus pieraksti README.md.

Beigās tu praktiski redzēsi un varēsi izskaidrot, ko atrisina A* ceļa meklēšana.

  1. Atver Scenes/Arena.tscn, atlasi mezglu Enemy un Inspector panelī izslēdz Use Pathfinding (false), lai metodē ChasePlayer() izpildītos taisnās kustības else zars.
  2. Palaid scēnu ar F6, novieto spēlētāju tieši aiz Wall1 un novēro, kur ienaidnieks apstājas. Pieraksti šo novērojumu README.md.
  3. Apturi spēli, Enemy mezgla Inspector panelī atkal ieslēdz Use Pathfinding (true), palaid ar F6 un atkārto to pašu testu aiz sienas.
  4. Ar WASD aizved spēlētāju pašā ekrāna malā ārpus zilās NavigationRegion2D zonas un pārbaudi, ka ienaidnieks pieiet līdz tuvākajai sasniedzamajai navigācijas tīkla robežai.
  5. Failā README.md pieraksti abu testu salīdzinājumu un vienā teikumā paskaidro, ko A* novērtējuma formulā f(n) = g(n) + h(n) nozīmē g(n) un ko — h(n).

Gatavs, kad: UsePathfinding = true ir atjaunots, un README.md ir salīdzināta kustība ar un bez pathfinding, kā arī izskaidrots g un h.

Papildu uzdevums — Uzzīmē plānoto ceļu uz ekrāna ar Line2D

Kur strādāt: Mezglu Line2D (PathLine) pievieno ienaidnieka scēnā Scenes/Enemy.tscn. Tā atsauci un punktu atjaunošanu pievieno failā Scripts/Enemy.cs: mezglu atrodi _Ready(), bet līnijas punktus atjauno ChasePlayer().

Ja pamatdarbs ir gatavs, uzzīmē ekrānā līniju, pa kuru NavigationAgent2D plāno vest ienaidnieku.

  1. Atver Scenes/Enemy.tscn, atlasi sakni Enemy un pievieno bērnmezglu Line2D ar nosaukumu PathLine (Inspector iestati Width = 2).
  2. Failā Scripts/Enemy.cs pievieno lauku private Line2D pathLine; un metodē _Ready() ieraksti: pathLine = GetNodeOrNull<Line2D>("PathLine"); if (pathLine != null) pathLine.TopLevel = true; (TopLevel = true nodrošina, ka pasaules koordinātu punkti nezīmējas ar nobīdi).
  3. Metodē ChasePlayer() (kad UsePathfinding ir patiess) pievieno: if (pathLine != null) pathLine.Points = navAgent.GetCurrentNavigationPath();.
  4. Palaid Scenes/Arena.tscn ar F6, kustini spēlētāju ap abām sienām un vēro, kā līnija reāllaikā pārrēķina īsāko maršrutu.

Gatavs, kad: spēles logā redzama līnija no ienaidnieka līdz spēlētājam, kas apliecas ap sienu stūriem.

Pilnie faili salīdzināšanai

Šis ir pilnais Scripts/Enemy.cs fails pēc 4.3. stundas stāvokļu mašīnas un 4.4. stundas NavigationAgent2D apvienošanas.

Scripts/Enemy.cs

using Godot;

public enum EnemyState
{
    Idle,   // gaida
    Patrol, // patrulē
    Chase,  // dzenas pakaļ
    Attack, // uzbrūk
    Dead    // gala stāvoklis
}

public partial class Enemy : CharacterBody2D
{
    public string EnemyName = "Pretinieks";
    [Export] public float Speed = 150.0f;
    [Export] public int Hp = 30;
    [Export] public bool UsePathfinding = true;

    protected EnemyState state = EnemyState.Patrol;
    protected Node2D player;
    protected NavigationAgent2D navAgent;

    public bool IsAlive => state != EnemyState.Dead;

    public override void _Ready()
    {
        player = GetParent()?.GetNodeOrNull<Node2D>("Player");
        navAgent = GetNodeOrNull<NavigationAgent2D>("NavigationAgent2D");
    }

    protected void ChangeState(EnemyState newState)
    {
        if (state == EnemyState.Dead || state == newState) return;
        GD.Print("Stāvokļa maiņa: ", state, " -> ", newState);
        state = newState;
    }

    protected void ChasePlayer()
    {
        Vector2 dir;
        if (UsePathfinding && navAgent != null)
        {
            navAgent.TargetPosition = player.GlobalPosition;
            Vector2 nextPos = navAgent.GetNextPathPosition();
            dir = (nextPos - GlobalPosition).Normalized();
        }
        else
        {
            dir = (player.GlobalPosition - GlobalPosition).Normalized();
        }

        Velocity = dir * Speed;
        MoveAndSlide();
    }

    public void TakeDamage(int amount)
    {
        if (!IsAlive || amount <= 0) return;
        Hp -= amount;
        if (Hp <= 0)
        {
            Hp = 0;
            ChangeState(EnemyState.Dead);
            Velocity = Vector2.Zero;
            Modulate = new Color(0.5f, 0.5f, 0.5f, 0.6f);
        }
    }

    public override void _PhysicsProcess(double delta)
    {
        if (Input.IsKeyPressed(Key.K))
            TakeDamage(30);

        if (player == null || !IsAlive) return;

        float dist = GlobalPosition.DistanceTo(player.GlobalPosition);

        switch (state)
        {
            case EnemyState.Idle:
            case EnemyState.Patrol:
                Velocity = Vector2.Zero;
                if (dist < 600.0f) ChangeState(EnemyState.Chase);
                break;

            case EnemyState.Chase:
                ChasePlayer();
                if (dist < 60.0f) ChangeState(EnemyState.Attack);
                else if (dist > 700.0f) ChangeState(EnemyState.Patrol);
                break;

            case EnemyState.Attack:
                Velocity = Vector2.Zero;
                if (dist >= 80.0f) ChangeState(EnemyState.Chase);
                break;

            case EnemyState.Dead:
                break;
        }
    }
}
