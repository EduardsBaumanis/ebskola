4.4 Pathfinding ar A*

Stundas uzdevums: Saprast un implementēt pathfinding (ceļa meklēšana) algoritmu spēles AI.

SR 2.4.19. Algoritmu efektivitāte SR 2.4.16. Datu struktūras

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - sagatavo navigācijas reģionu · 2. uzdevums (~25 min) - liec ienaidniekam sekot ceļam · 3. uzdevums (~20 min) - salīdzini taisno kustību ar pathfinding · Iesniegšana (~5 min).

Pirms sāc: atver savu projektu ar stāvokļu mašīnu no 4.3 stundas. Šodien ienaidnieks vairs neiestrēgs aiz sienas.

Teorija: A* algoritms un NavigationAgent2D

Reālistiska AI prasa pathfinding - meklēt īsāko ceļu starp diviem punktiem, izvairoties no šķēršļiem.

A* algoritms izmanto:

  • g(n) - faktiskais ceļa garums no sākuma līdz n.
  • h(n) - heuristika (taisns attālums līdz mērķim).
  • f(n) = g(n) + h(n) - kopējais novērtējums.

Godot 4 piedāvā NavigationAgent2D kas to dara automātiski.

#include <godot_cpp/classes/navigation_agent2d.hpp>

class Enemy : public CharacterBody2D {
    NavigationAgent2D *nav_agent;
public:
    void _ready() override {
        nav_agent = get_node<NavigationAgent2D>("NavigationAgent2D");
        nav_agent->set_target_position(player_pos);
    }

    void _physics_process(double delta) override {
        if (nav_agent->is_navigation_finished()) return;

        Vector2 next_pos = nav_agent->get_next_path_position();
        Vector2 dir = (next_pos - get_position()).normalized();
        velocity = dir * speed;
        move_and_slide();
    }
};

Praktiskie uzdevumi

1. uzdevums - Sagatavo navigācijas reģionu

Beigās Godot zinās, pa kurām vietām drīkst staigāt.

  1. Pievieno scēnai mezglu NavigationRegion2D.
  2. Izveido tam NavigationPolygon resursu Inspector panelī.
  3. Uzzīmē daudzstūri, kas aptver visu staigājamo laukumu.
  4. Pievieno laukumā divas sienas kā StaticBody2D.
  5. Izgriez navigācijas daudzstūrī caurumus ap sienām.
  6. Nospied Bake NavigationPolygon.
  7. Pārbaudi, ka zilā zona neiet pāri sienām.

Gatavs, kad: navigācijas zona aptver grīdu, bet ne sienas, un tā ir redzama editorā zilā krāsā.

2. uzdevums - Liec ienaidniekam sekot ceļam

Beigās ienaidnieks apstaigās sienu, nevis iestrēgs tajā.

  1. Pievieno ienaidniekam bērnu NavigationAgent2D.
  2. Iekļauj C++ failā #include <godot_cpp/classes/navigation_agent2d.hpp>.
  3. Paņem to kodā ar get_node<NavigationAgent2D>("NavigationAgent2D");.
  4. Iestati mērķi ar agent->set_target_position(player_pos);.
  5. Paņem nākamo punktu ar Vector2 next = agent->get_next_path_position();.
  6. Virzies uz to ar (next - get_position()).normalized() * speed.
  7. Kompilē un noliec spēlētāju aiz sienas.

Gatavs, kad: ienaidnieks apiet sienu apkārt un nonāk pie spēlētāja, nevis spiežas sienā.

3. uzdevums - Salīdzini taisno kustību ar pathfinding

Beigās tu redzēsi, ko tieši pathfinding atrisina.

  1. Nomaini kodu uz taisnu kustību tieši pret spēlētāju, bez agenta.
  2. Noliec spēlētāju aiz sienas un palaid.
  3. Pieraksti, kur ienaidnieks apstājās.
  4. Ieliec pathfinding kodu atpakaļ un atkārto to pašu testu.
  5. Pieraksti, cik ilgi tagad aizņēma nonākšana pie spēlētāja.
  6. Pārbaudi, kas notiek, ja spēlētājs ir ārpus navigācijas zonas.
  7. Pieraksti, ko dara g un ko h A* algoritmā.

Gatavs, kad: bez pathfinding ienaidnieks iestrēgst pie sienas, bet ar to - apiet apkārt.

Papildu uzdevums - Zīmē ceļu uz ekrāna

Ja pamatdarbs ir gatavs, parādi, pa kuru ceļu ienaidnieks iet.

  1. Paņem pilnu ceļu ar agent->get_current_navigation_path();.
  2. Pievieno scēnai Line2D mezglu.
  3. Iestati tā punktus uz ceļa punktiem katrā kadrā.
  4. Palaid un vēro, kā līnija mainās, kustinot spēlētāju.
  5. Pieraksti, cik punktu parasti ir ceļā.

Gatavs, kad: ekrānā redzama līnija, kas rāda ienaidnieka plānoto ceļu ap sienu.

Ko iesniedz skolotājam

Stundas mērķis: Tavā līmenī ir izcepts navigācijas reģions, un ienaidnieks ar NavigationAgent2D apiet sienas, lai nonāktu pie spēlētāja, nevis iestrēgst pret tām.

Iesniedzamais:

  1. Video, kurā ienaidnieks apiet sienu, lai nonāktu pie spēlētāja.
  2. Ekrānuzņēmums ar navigācijas zonu editorā (zilā zona ap sienām).
  3. Fails enemy.cpp ar NavigationAgent2D kodu.
  4. Burtnīcā: ko A* algoritmā nozīmē g un ko h.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti, video un ekrānuzņēmumu skolotāja norādītajā vietā.

Biežākās kļūdas

  • NavigationAgent neatrod ceļu: NavigationPolygon nav baked vai nepareiza forma.
  • Ienaidnieki iestrēgst stūros: Path radius pārāk mazs vai šķēršļi pārāk tuvu.
  • Slow performance: Pārāk daudz NavigationAgent - pārbaudi update freq.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

#include <godot_cpp/classes/navigation_agent2d.hpp>
#include <godot_cpp/classes/character_body2d.hpp>

void Enemy::_ready() {
    nav_agent = get_node<NavigationAgent2D>("NavigationAgent2D");
    nav_agent->set_avoidance_enabled(true);
    update_target();
}

void Enemy::_physics_process(double delta) {
    if (nav_agent->is_navigation_finished()) return;

    Vector2 current = get_position();
    Vector2 next = nav_agent->get_next_path_position();
    Vector2 direction = (next - current).normalized();

    velocity = direction * speed;
    move_and_slide();
}

void Enemy::update_target() {
    if (player) nav_agent->set_target_position(player->get_position());
}
