Pirms sāc: šis ir 4. tēmas noslēguma projekts. Izmanto visu apgūto: sarakstus, vārdnīcas, stāvokļu mašīnu, pathfinding un lādiņu krātuvi. Sāc ar VIENU ienaidnieka tipu.

Teorija: Spēles apraksts un arhitektūra

Top-down šautene ar šādām funkcijām:

  • Spēlētājs ar 8 virzienu kustību un mouse-aimed šaušanu.
  • 3 ienaidnieku tipi ar dažādu AI uzvedību.
  • Pathfinding ap šķēršļiem.
  • Wave system: ienaidnieku viļņi ar augošu sarežģītību.
  • Pickup sistēma: HP, ammo, power-ups.
  • Score un wave skaitītājs.

Praktiskie uzdevumi

1. uzdevums - Spēlētājs ar kustību un mērķēšanu

Beigās spēlētājs pārvietosies ar WASD un šaus peles virzienā.

  1. Izveido spēlētāja klasi ar 8 virzienu kustību un normalizētu vektoru.
  2. Paņem peles pozīciju ar get_global_mouse_position();.
  3. Pagriez spēlētāju pret peli ar look_at(...).
  4. Pievieno šaušanu no 4.5 stundas ar lādiņu krātuvi.
  5. Izšauj lādiņu spēlētāja skatīšanās virzienā.
  6. Kompilē un pārbaudi kustību visos virzienos un šaušanu.
  7. Pārliecinies, ka diagonālā kustība nav ātrāka.

Gatavs, kad: spēlētājs kustas visos virzienos, vienmēr skatās uz peli un šauj tieši tajā virzienā.

2. uzdevums - Divi ienaidnieku tipi ar AI

Beigās ienaidnieki uzvedīsies atšķirīgi.

  1. Izveido bāzes klasi Enemy ar stāvokļu mašīnu no 4.3 stundas.
  2. Izveido bērna klasi Chaser, kas dzenas ar pathfinding.
  3. Izveido otru bērna klasi Shooter, kas apstājas un šauj no attāluma.
  4. Glabā visus ienaidniekus vienā std::vector<Enemy*>.
  5. Uzraksti vienu ciklu, kas atjaunina visus ienaidniekus.
  6. Pievieno ienaidniekiem HP un dzēšanu, kad tie tiek nošauti.
  7. Pārbaudi, ka abi tipi uzvedas atšķirīgi.

Gatavs, kad: viens ienaidnieku tips dzenas pakaļ, otrs apstājas un šauj, un abus apstrādā viens cikls.

3. uzdevums - Viļņu sistēma un rezultāts

Beigās spēle kļūs arvien grūtāka un skaitīs punktus.

  1. Izveido klasi WaveManager ar lauku int wave = 1;.
  2. Radi katrā vilnī vairāk ienaidnieku nekā iepriekšējā.
  3. Pārej uz nākamo vilni, kad visi ienaidnieki iznīcināti.
  4. Pievieno punktu skaitītāju un HUD ar vilni, punktiem un HP.
  5. Pievieno spēles beigas, kad spēlētāja HP sasniedz nulli.
  6. Izspēlē vismaz trīs viļņus.
  7. Veic commit un push.

Gatavs, kad: spēle pāriet no viļņa uz vilni, katrā ir vairāk ienaidnieku, un beidzas, kad spēlētājs zaudē HP.

Papildu uzdevums - Pievieno savācamos bonusus

Ja pamatdarbs ir gatavs, ļauj spēlētājam atjaunot HP un munīciju.

  1. Izveido Area2D bonusa scēnu ar veidu HP vai AMMO.
  2. Radi bonusu nejaušā vietā pēc katra viļņa.
  3. Palielini attiecīgo vērtību, kad spēlētājs to savāc.
  4. Ierobežo HP, lai tas nepārsniegtu maksimumu.
  5. Pārbaudi abus bonusa veidus.

Gatavs, kad: bonusi parādās pēc katra viļņa un atjauno HP vai munīciju, nepārsniedzot maksimumu.

Stundas mērķis: Tev ir izspēlējama top-down šautene: spēlētājs ar 8 virzienu kustību un mērķēšanu pret peli, vismaz divi ienaidnieku tipi ar atšķirīgu AI, viļņu sistēma ar augošu grūtību un HUD ar punktiem un HP.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

class WaveManager : public Node {
    GDCLASS(WaveManager, Node)

private:
    int current_wave = 0;
    float wave_timer = 0;
    std::vector<Enemy*> active_enemies;

    struct Wave { int fast_enemies, brutes, shooters; };
    std::vector<Wave> waves = {
        {3, 0, 0},      // wave 1
        {5, 1, 0},      // wave 2
        {6, 2, 1},      // wave 3
        {8, 3, 2},      // wave 4
        {10, 5, 3}      // wave 5 + boss
    };

public:
    void _process(double delta) override {
        wave_timer -= delta;
        if (active_enemies.empty() && wave_timer <= 0) {
            start_next_wave();
        }
    }

    void start_next_wave() {
        if (current_wave >= waves.size()) {
            UtilityFunctions::print("All waves complete!");
            return;
        }
        Wave w = waves[current_wave];
        for (int i = 0; i < w.fast_enemies; i++) spawn(EnemyType::FAST);
        for (int i = 0; i < w.brutes; i++) spawn(EnemyType::BRUTE);
        for (int i = 0; i < w.shooters; i++) spawn(EnemyType::SHOOTER);
        current_wave++;
        wave_timer = 30.0f;
    }
};
