4.2 Map un Dictionary

Pirms sāc: atceries no Programmēšanas I vārdnīcas: inventars["zobens"] = 1. C++ tas pats saucas std::map, un Godot pusē - Dictionary.

Teorija: std::map un Godot Dictionary

Asociatīvā datu struktūra glabā atslēga → vērtība pārus.

// std::map (sakārtots, log n)
#include <map>
std::map<String, int> inventory;
inventory["Health Potion"] = 5;
inventory["Mana Potion"] = 3;

if (inventory.count("Health Potion") > 0) {
    int amount = inventory["Health Potion"];
}

// std::unordered_map (hash, O(1))
#include <unordered_map>
std::unordered_map<int, Enemy*> enemy_by_id;

// Godot Dictionary
Dictionary inv;
inv["coins"] = 100;
inv["arrows"] = 25;
if (inv.has("coins")) print(inv["coins"]);

Praktiskie uzdevumi

1. uzdevums - Izveido inventāru ar std::map

Beigās priekšmetus varēs atrast pēc nosaukuma, nevis pēc numura.

  1. Iekļauj #include <map>.
  2. Izveido std::map<String, int> inventory;.
  3. Pievieno inventory["Health Potion"] = 5;.
  4. Pievieno vēl divus priekšmetus ar dažādiem daudzumiem.
  5. Izdrukā viena priekšmeta daudzumu pēc nosaukuma.
  6. Uzraksti ciklu for (auto& p : inventory) { ... }, kas izdrukā visu.
  7. Pieraksti, kādā secībā priekšmeti izdrukājās.

Gatavs, kad: izdrukā redzami visi trīs priekšmeti, un tie ir sakārtoti pēc nosaukuma alfabētiski.

2. uzdevums - Pievieno drošu meklēšanu

Beigās neesoša priekšmeta pieprasījums vairs neradīs pārsteigumus.

  1. Izdrukā inventory["Nav taada"] un pieraksti rezultātu.
  2. Izdrukā pēc tam saraksta izmēru un pieraksti, vai tas mainījās.
  3. Pieraksti, kāpēc tas ir bīstami.
  4. Nomaini pārbaudi uz if (inventory.count("Health Potion") > 0) { ... }.
  5. Uzraksti metodi int get_amount(String name);, kas atgriež 0, ja priekšmeta nav.
  6. Izsauc to ar esošu un neesošu nosaukumu.
  7. Pārbaudi, ka saraksta izmērs vairs nemainās.

Gatavs, kad: kvadrātiekavas ar neesošu atslēgu klusi pievieno jaunu ierakstu, bet tava metode to nedara.

3. uzdevums - Salīdzini map ar Godot Dictionary

Beigās tu zināsi, kuru struktūru lietot saziņai ar Godot.

  1. Izveido Dictionary save_data;.
  2. Pievieno tam save_data["player_name"] = "Anna"; un save_data["level"] = 5;.
  3. Izdrukā abas vērtības.
  4. Pieraksti, vai Dictionary pieļauj dažādu tipu vērtības vienā struktūrā.
  5. Mēģini to pašu ar std::map<String, int> un izlasi kļūdu.
  6. Pieraksti, kura struktūra derēs saglabāšanai failā.
  7. Izvēlies savam inventāram pareizo variantu un pamato.

Gatavs, kad: Dictionary pieņem dažādus tipus vienā struktūrā, bet std::map - tikai vienu.

Papildu uzdevums - Izmēģini unordered_map

Ja pamatdarbs ir gatavs, salīdzini divas C++ vārdnīcas.

  1. Iekļauj #include <unordered_map>.
  2. Izveido to pašu inventāru ar std::unordered_map.
  3. Izdrukā to ciklā un salīdzini secību ar std::map.
  4. Pieraksti, kura no tām saglabā kārtību.
  5. Pieraksti, kura ir ātrāka meklēšanai.

Gatavs, kad: std::map izdrukā alfabētiski, bet unordered_map - nesakārtoti.

Ko iesniedz skolotājam

Stundas mērķis: Tu proti C++ izveidot std::map inventāru, droši meklēt tajā priekšmetus, nepievienojot tukšus ierakstus, un izskaidrot, kad jālieto Godot Dictionary.

Iesniedzamais:

  1. C++ fails ar inventāru un get_amount metodi GitHub krātuvē.
  2. Ekrānuzņēmums, kurā redzams, ka pēc neesoša priekšmeta pieprasījuma saraksta izmērs nemainās.
  3. README.md: kāpēc kvadrātiekavas ar neesošu atslēgu ir bīstamas un kad lieto Dictionary.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un ekrānuzņēmumu skolotāja norādītajā vietā; README.md failā jābūt prasītajiem pierakstiem.

Biežākās kļūdas

  • Map operator[] uz neeksistējošu key: Izveido jaunu ar default. Lieto find() pārbaudei.
  • String key sajaucies: C++ String ir Godot Variant - atšķiras no std::string.
  • unordered_map ar custom key: Vajag operator== un std::hash specializāciju.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

#include <map>

class Player {
private:
    std::map<String, int> inventory;
public:
    void add_item(String name, int amount = 1) {
        inventory[name] += amount;
        UtilityFunctions::print("+", amount, " ", name);
    }

    bool use_item(String name) {
        auto it = inventory.find(name);
        if (it == inventory.end() || it->second <= 0) {
            UtilityFunctions::print("Nav ", name);
            return false;
        }
        it->second--;
        return true;
    }

    void print_inventory() {
        for (const auto& [name, count] : inventory) {
            UtilityFunctions::print(name, ": ", count);
        }
    }
};
Inventārs rāda: Health Potion: 5, Mana Potion: 3, Sword: 1; pēc lietošanas Health Potion: 4.
