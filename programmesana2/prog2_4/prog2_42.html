4.2 Dictionary (vārdnīca) un Godot Dictionary

Sasniedzamais rezultāts: Apgūt asociatīvās data structure (datu struktūras) inventāram un konfigurācijai.

SR 2.4.16. Saliktas data structure SR 2.4.4. Iegūst un apstrādā datus

Teorija: asociatīvās vārdnīcas C# un Godot vidē

Atslēgas un vērtības pāri (Dictionary<TKey, TValue>)

Asociatīvā datu struktūra jeb vārdnīca (Dictionary<TKey, TValue>) glabā datus pāros atslēga → vērtība (key → value). Atšķirībā no saraksta, kur meklējot jāpārbauda elementi pēc kārtas no indeksa 0, vārdnīca ar jaukšanas (hashing) palīdzību uzreiz atrod vērtību pēc tās unikālās atslēgas — līdzīgi kā skolas garderobē doties tieši pie skapīša ar uzrakstu "B-14", nevis vērt vaļā katras durtiņas pēc kārtas.

Katra atslēga vārdnīcā var būt tikai vienā eksemplārā: piešķīrums vardnica[atslega] = vertiba izveido jaunu ierakstu, ja atslēgas vēl nav, vai pārraksta iepriekšējo vērtību, ja tā jau eksistē (tāpat pēc skaitliska identifikatora var glabāt arī veselus objektus, piemēram, Dictionary<int, Klients>). Tā kā parastais Dictionary ir veidots maksimāli ātrai meklēšanai, foreach ciklā tas negarantē alfabētisku secību — ja atslēgas vienmēr jāizvada sakārtoti, izmanto SortedDictionary<TKey, TValue>:

using System.Collections.Generic;

Dictionary<string, string> skapisi = new();
skapisi["B-14"] = "Līga";
skapisi["A-03"] = "Kārlis";
skapisi["B-14"] = "Ieva"; // Pārraksta "B-14" vērtību (Count paliek 2).

foreach (var paris in skapisi)
{
    GD.Print(paris.Key, " -> ", paris.Value); // Secība nav garantēta
}

// Alfabētiski sakārtotām atslēgām ("A-03", pēc tam "B-14"):
SortedDictionary<string, string> sakartoti = new(skapisi);

Droša nolasīšana (TryGetValue) un Godot.Collections.Dictionary

Mēģinot ar kvadrātiekavām nolasīt atslēgu, kuras vārdnīcā nav, programma apstājas ar kļūdu KeyNotFoundException (pati vārdnīca un tās Count nemainās). Tāpēc nezināmas atslēgas droši pārbauda ar metodi TryGetValue, kas vienā solī gan pārbauda esamību (true vai false), gan ievieto atrasto vērtību out mainīgajā:

using Godot;
using System.Collections.Generic;

Dictionary<string, int> noliktava = new();
noliktava["Kabelis"] = 5;
noliktava["Adapteris"] = 3;

if (noliktava.TryGetValue("Kabelis", out int daudzums))
    GD.Print("Pieejami: ", daudzums);
else
    GD.Print("Prece nav atrasta (0)"); // Neizraisa KeyNotFoundException

Godot.Collections.Dictionary iestatijumi = new();
iestatijumi["lietotajs"] = "Līga";
iestatijumi["versija"] = 2;
if (iestatijumi.ContainsKey("versija")) GD.Print(iestatijumi["versija"]);

Iekšējam C# kodam piemērotāks ir System.Collections.Generic.Dictionary<TKey, TValue>, jo tas ir tipdrošs (type-safe) un pieprasa vienotu atslēgas un vērtības tipu. Savukārt Godot.Collections.Dictionary glabā universālus Variant datus, pieļaujot vienā struktūrā gan tekstus, gan skaitļus — to izvēlas datu apmaiņai ar Godot redaktoru vai saglabāšanai JSON failos.

1. uzdevums

Izveido inventāru un spēles datus ar Dictionary

Kur strādāt: Izveido scēnu Scenes/InventoryDemo.tscn ar saknes mezglu Node (InventoryDemo) un piesaisti tam jaunu skriptu Scripts/Inventory.cs. Bibliotēku using liec Scripts/Inventory.cs sākumā, vārdnīcu inventory — klases Inventory laukā, bet ierakstu pievienošanu un izdrukas — metodē _Ready().

Beigās priekšmetu skaitu vai spēles rādītājus varēsi uzreiz atrast pēc teksta atslēgas, nevis meklējot pēc kārtas numura.

  1. Godot redaktorā izveido jaunu scēnu ar saknes mezglu Node, pārdēvē to par InventoryDemo un saglabā kā Scenes/InventoryDemo.tscn. Ar Attach Script pievieno tam skriptu Scripts/Inventory.cs.
  2. Faila Scripts/Inventory.cs pašā sākumā (zem using Godot;) pievieno using System.Collections.Generic;.
  3. Klases Inventory iekšienē (pirms metodes _Ready()) deklarē vārdnīcas lauku private Dictionary<string, int> inventory = new();, lai tas būtu pieejams visās šīs klases metodēs.
  4. Faila Scripts/Inventory.cs metodē _Ready() pievieno trīs ierakstus: inventory["Health Potion"] = 5;, inventory["Mana Potion"] = 3; un inventory["Ammo Pack"] = 20;.
  5. Tajā pašā metodē _Ready() izdrukā viena priekšmeta daudzumu pēc atslēgas (GD.Print("Health Potion: ", inventory["Health Potion"]);) un zem tā ar ciklu foreach (var pair in inventory) izdrukā visus atslēgu un vērtību pārus.
  6. Saglabā failu, nospied Build un palaid scēnu ar F6. Pārbaudi Output paneli un README.md pieraksti, kāpēc Dictionary ir paredzēts ātrai piekļuvei pēc atslēgas un kāpēc uz elementu secību tajā nevajag paļauties.
// Scripts/Inventory.cs — klases lauks un _Ready() sākums:
private Dictionary<string, int> inventory = new();

public override void _Ready()
{
    inventory["Health Potion"] = 5;
    inventory["Mana Potion"] = 3;
    inventory["Ammo Pack"] = 20;

    GD.Print("Health Potion: ", inventory["Health Potion"]);
    foreach (var pair in inventory)
    {
        GD.Print(pair.Key, " -> ", pair.Value);
    }
}

Gatavs, kad: Output panelī redzami visi trīs ieraksti, un tu vari paskaidrot, kāpēc Dictionary atrod vērtību pēc atslēgas.

2. uzdevums

Pievieno drošu meklēšanu ar TryGetValue

Kur strādāt: Papildini failu Scripts/Inventory.cs: klases Inventory iekšienē (ārpus _Ready()) pievieno metodi GetAmount(string name), bet tās izsaukumus un pārbaudes raksti metodē _Ready().

Beigās neesoša priekšmeta vai rādītāja pieprasījums neapturēs spēli ar kļūdu.

  1. Faila Scripts/Inventory.cs metodē _Ready() (zem 1. uzdevuma cikla) uz brīdi pievieno rindu GD.Print(inventory["Nav tada"]); un palaid ar F6. Cilnē Debugger → Errors izlasi kļūdas nosaukumu (KeyNotFoundException), pieraksti to README.md un pēc tam šo kļūdaino rindu izdzēs.
  2. Metodē _Ready() tās vietā ieraksti drošu pārbaudi ar if (inventory.TryGetValue("Health Potion", out int amount)) { GD.Print("Atrasts: ", amount); }.
  3. Klases Inventory iekšienē (ārpus _Ready(), pirms klases pēdējās }) pievieno metodi public int GetAmount(string name) pēc parauga zemāk — tā ar TryGetValue atgriež priekšmeta skaitu vai 0, ja atslēgas vārdnīcā nav.
  4. Metodē _Ready() izsauc GetAmount("Ammo Pack") (esoša atslēga, jāatgriež 20) un GetAmount("Shield") (neesoša atslēga, jāatgriež 0), un izdrukā abus rezultātus kopā ar inventory.Count.
  5. Saglabā failu, nospied Build un F6, un pārliecinies, ka pēc neesošas atslēgas pārbaudes vārdnīcas izmērs inventory.Count nemainās (paliek 3).
// Scripts/Inventory.cs — drošas nolasīšanas metode klasē:
public int GetAmount(string name)
{
    if (inventory.TryGetValue(name, out int amount))
        return amount;
    return 0;
}

// Izsaukumi metodē _Ready():
GD.Print("Ammo Pack skaits: ", GetAmount("Ammo Pack")); // 20
GD.Print("Shield skaits: ", GetAmount("Shield"));       // 0
GD.Print("Vārdnīcas Count: ", inventory.Count);         // 3

Gatavs, kad: neesoša atslēga vairs neaptur programmu, metode GetAmount() atgriež 0 un inventory.Count paliek nemainīgs.

3. uzdevums

Salīdzini Dictionary ar Godot Dictionary

Kur strādāt: Abu vārdnīcu salīdzinājumu pievieno faila Scripts/Inventory.cs metodes _Ready() beigās. Secinājumus pieraksti README.md.

Beigās tu zināsi, kuru vārdnīcu lietot iekšējiem C# aprēķiniem un kuru — datu saglabāšanai vai saziņai ar Godot.

  1. Faila Scripts/Inventory.cs metodes _Ready() beigās izveido Godot vārdnīcu Godot.Collections.Dictionary saveData = new();.
  2. Tajā pašā saveData vārdnīcā ievieto gan teksta, gan skaitļa vērtību: saveData["player_name"] = "Anna"; un saveData["level"] = 5;, un ar ContainsKey pārbaudi izdrukā abas vērtības.
  3. Zem tā uz brīdi pamēģini C# vārdnīcai inventory (kas deklarēta kā Dictionary<string, int>) piešķirt tekstu inventory["player_name"] = "Anna";. Nospied Build, izlasi kompilatora kļūdu un pēc tam šo rindu izdzēs.
  4. Saglabā failu, nospied Build un F6, lai pārliecinātos, ka viss Scripts/Inventory.cs kods izpildās bez kļūdām.
  5. Failā README.md pieraksti: kāpēc tieša kvadrātiekavu lasīšana ar neesošu atslēgu ir bīstama, kāpēc inventāra un viļņu statistikas skaitļiem C# kodā izvēlas Dictionary<string, int> un kad noder Godot.Collections.Dictionary.
// Scripts/Inventory.cs metodē _Ready():
Godot.Collections.Dictionary saveData = new();
saveData["player_name"] = "Anna";
saveData["level"] = 5;

if (saveData.ContainsKey("player_name"))
{
    GD.Print("Spēlētājs: ", saveData["player_name"], ", līmenis: ", saveData["level"]);
}

Gatavs, kad: Godot.Collections.Dictionary izdrukā dažādu tipu vērtības, un README.md ir pamatota atšķirība starp abām vārdnīcām.

Papildu uzdevums — Izmēģini SortedDictionary

Kur strādāt: SortedDictionary<string, int> izveidi un ciklu pievieno faila Scripts/Inventory.cs metodes _Ready() beigās; salīdzinājumu pieraksti README.md.

Ja pamatdarbs ir gatavs, salīdzini parasto Dictionary ar automātiski sakārtotu SortedDictionary.

  1. Faila Scripts/Inventory.cs metodes _Ready() beigās izveido SortedDictionary<string, int> sortedInv = new(inventory);.
  2. Ar ciklu foreach (var pair in sortedInv) izdrukā visas atslēgas un vērtības un salīdzini secību ar parasto inventory vārdnīcu.
  3. Failā README.md pieraksti, kura struktūra vienmēr kārto atslēgas alfabētiski un kura ir ātrāka ikdienas meklēšanai spēles ciklā.

Gatavs, kad: SortedDictionary izdrukā atslēgas alfabētiskā secībā (Ammo Pack, Health Potion, Mana Potion).

Pilnie faili salīdzināšanai

Šis ir pilnais Scripts/Inventory.cs fails pēc visu trīs pamatuzdevumu izpildes.

Scripts/Inventory.cs

using Godot;
using System.Collections.Generic;

public partial class Inventory : Node
{
    private Dictionary<string, int> inventory = new();

    public override void _Ready()
    {
        // 1. uzdevums: pievieno ierakstus vārdnīcai un izdrukā tos
        inventory["Health Potion"] = 5;
        inventory["Mana Potion"] = 3;
        inventory["Ammo Pack"] = 20;

        GD.Print("Health Potion: ", inventory["Health Potion"]);
        foreach (var pair in inventory)
        {
            GD.Print(pair.Key, " -> ", pair.Value);
        }

        // 2. uzdevums: droša meklēšana ar TryGetValue un GetAmount()
        if (inventory.TryGetValue("Health Potion", out int amount))
        {
            GD.Print("Atrasts Health Potion: ", amount);
        }

        GD.Print("Ammo Pack skaits: ", GetAmount("Ammo Pack"));
        GD.Print("Shield skaits: ", GetAmount("Shield"));
        GD.Print("Vārdnīcas Count: ", inventory.Count);

        // 3. uzdevums: Godot.Collections.Dictionary dažādu tipu datiem
        Godot.Collections.Dictionary saveData = new();
        saveData["player_name"] = "Anna";
        saveData["level"] = 5;

        if (saveData.ContainsKey("player_name"))
        {
            GD.Print("Spēlētājs: ", saveData["player_name"],
                ", līmenis: ", saveData["level"]);
        }
    }

    public int GetAmount(string name)
    {
        if (inventory.TryGetValue(name, out int amount))
            return amount;
        return 0;
    }
}

Ko sagatavo

Stundas mērķis: Tu proti C# izveidot Dictionary vārdnīcu, droši meklēt tajā vērtības ar TryGetValue un izskaidrot, kad jālieto Godot.Collections.Dictionary.

GitHub krātuvē jābūt:

  • Fails Scripts/Inventory.cs ar inventory vārdnīcu un GetAmount() metodi, kā arī scēna Scenes/InventoryDemo.tscn.
  • Ekrānuzņēmums ar Output paneli, kurā redzams, ka pēc neesoša priekšmeta pieprasījuma vārdnīcas Count nemainās.
  • README.md: kāpēc kvadrātiekavas ar neesošu atslēgu ir bīstamas un kad lieto Godot.Collections.Dictionary.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • KeyNotFoundException (atslēga nav atrasta): Kvadrātiekavas lasa tikai esošas atslēgas. Lieto TryGetValue vai ContainsKey.
  • Sajauktas dictionary: Dictionary<string, int> ir type-safe (tipdroša) C# struktūra, bet Godot.Collections.Dictionary glabā Variant datus.
  • Negaidīta secība: parasts Dictionary nav paredzēts sakārtotai izdrukai. Ja vajag sakārtotas atslēgas, lieto SortedDictionary.
