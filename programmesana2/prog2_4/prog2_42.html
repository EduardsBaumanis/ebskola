4.2 Dictionary (vārdnīca) un Godot Dictionary

Stundas uzdevums: Apgūt asociatīvās data structure (datu struktūras) inventāram un konfigurācijai.

SR 2.4.16. Saliktas data structure SR 2.4.4. Iegūst un apstrādā datus

Teorija: asociatīvās vārdnīcas C# un Godot vidē

Atslēgas un vērtības pāri (Dictionary<TKey, TValue>)

Asociatīvā datu struktūra jeb vārdnīca (Dictionary<TKey, TValue>) glabā datus pāros atslēga → vērtība (key → value). Atšķirībā no saraksta, kur meklējot jāpārbauda elementi pēc kārtas no indeksa 0, vārdnīca ar jaukšanas (hashing) palīdzību uzreiz atrod vērtību pēc tās unikālās atslēgas — līdzīgi kā skolas garderobē doties tieši pie skapīša ar uzrakstu "B-14", nevis vērt vaļā katras durtiņas pēc kārtas.

Katra atslēga vārdnīcā var būt tikai vienā eksemplārā: piešķīrums vardnica[atslega] = vertiba izveido jaunu ierakstu, ja atslēgas vēl nav, vai pārraksta iepriekšējo vērtību, ja tā jau eksistē (tāpat pēc skaitliska identifikatora var glabāt arī veselus objektus, piemēram, Dictionary<int, Klients>). Tā kā parastais Dictionary ir veidots maksimāli ātrai meklēšanai, foreach ciklā tas negarantē alfabētisku secību — ja atslēgas vienmēr jāizvada sakārtoti, izmanto SortedDictionary<TKey, TValue>:

using System.Collections.Generic;

Dictionary<string, string> skapisi = new();
skapisi["B-14"] = "Līga";
skapisi["A-03"] = "Kārlis";
skapisi["B-14"] = "Ieva"; // Pārraksta "B-14" vērtību (Count paliek 2).

foreach (var paris in skapisi)
{
    GD.Print(paris.Key, " -> ", paris.Value); // Secība nav garantēta
}

// Alfabētiski sakārtotām atslēgām ("A-03", pēc tam "B-14"):
SortedDictionary<string, string> sakartoti = new(skapisi);

Droša nolasīšana (TryGetValue) un Godot.Collections.Dictionary

Mēģinot ar kvadrātiekavām nolasīt atslēgu, kuras vārdnīcā nav, programma apstājas ar kļūdu KeyNotFoundException (pati vārdnīca un tās Count nemainās). Tāpēc nezināmas atslēgas droši pārbauda ar metodi TryGetValue, kas vienā solī gan pārbauda esamību (true vai false), gan ievieto atrasto vērtību out mainīgajā:

using Godot;
using System.Collections.Generic;

Dictionary<string, int> noliktava = new();
noliktava["Kabelis"] = 5;
noliktava["Adapteris"] = 3;

if (noliktava.TryGetValue("Kabelis", out int daudzums))
    GD.Print("Pieejami: ", daudzums);
else
    GD.Print("Prece nav atrasta (0)"); // Neizraisa KeyNotFoundException

Godot.Collections.Dictionary iestatijumi = new();
iestatijumi["lietotajs"] = "Līga";
iestatijumi["versija"] = 2;
if (iestatijumi.ContainsKey("versija")) GD.Print(iestatijumi["versija"]);

Iekšējam C# kodam piemērotāks ir System.Collections.Generic.Dictionary<TKey, TValue>, jo tas ir tipdrošs (type-safe) un pieprasa vienotu atslēgas un vērtības tipu. Savukārt Godot.Collections.Dictionary glabā universālus Variant datus, pieļaujot vienā struktūrā gan tekstus, gan skaitļus — to izvēlas datu apmaiņai ar Godot redaktoru vai saglabāšanai JSON failos.

1. uzdevums

Izveido inventāru ar Dictionary

Kur strādāt: Izveido Scripts/Inventory.cs un piesaisti to Node mezglam scēnā Scenes/InventoryDemo.tscn. using liec faila sākumā, inventory vārdnīcu — klases laukā, bet priekšmetu pievienošanu un izdrukas — metodē _Ready().

Beigās priekšmetus varēs atrast pēc nosaukuma, nevis pēc numura.

  1. Pievieno faila sākumā using System.Collections.Generic;.
  2. Izveido Dictionary<string, int> inventory = new();.
  3. Pievieno inventory["Health Potion"] = 5;.
  4. Pievieno vēl divus priekšmetus ar dažādiem daudzumiem.
  5. Izdrukā viena priekšmeta daudzumu pēc nosaukuma.
  6. Uzraksti loop (ciklu) foreach (var pair in inventory) { ... }, kas izdrukā visu.
  7. Pieraksti, kāpēc uz izdrukas secību nevajag paļauties.
Dictionary<string, int> inventory = new();
inventory["Health Potion"] = 5;
inventory["Mana Potion"] = 3;

Gatavs, kad: izdrukā redzami visi trīs priekšmeti, un tu vari paskaidrot, ka Dictionary ir paredzēts ātrai meklēšanai pēc atslēgas.

2. uzdevums

Pievieno drošu meklēšanu

Kur strādāt: Papildini Scripts/Inventory.cs: meklēšanas izmēģinājumus raksti _Ready(), bet GetAmount() pievieno kā atsevišķu klases metodi.

Beigās neesoša priekšmeta pieprasījums vairs neradīs pārsteigumus.

  1. Izdrukā inventory["Nav taada"] un pieraksti kļūdas ziņojumu.
  2. Izdrukā pēc tam inventory.Count un pieraksti, vai tas mainījās.
  3. Pieraksti, kāpēc tieša kvadrātiekavu lietošana bez pārbaudes ir bīstama.
  4. Nomaini pārbaudi uz if (inventory.TryGetValue("Health Potion", out int amount)) { ... }.
  5. Uzraksti method int GetAmount(string name), kas atgriež 0, ja priekšmeta nav.
  6. Izsauc to ar esošu un neesošu nosaukumu.
  7. Pārbaudi, ka dictionary izmērs vairs nemainās.
if (inventory.TryGetValue("Health Potion", out int amount))
{
    GD.Print(amount);
}

Gatavs, kad: neesoša atslēga vairs neaptur programmu, bet tava method korekti atgriež 0.

3. uzdevums

Salīdzini Dictionary ar Godot Dictionary

Kur strādāt: Godot Dictionary salīdzinājumu pievieno Scripts/Inventory.cs metodei _Ready(). Pēc kompilācijas kļūdas izpētes kļūdaino piešķīrumu izdzēs; secinājumus raksti README.md.

Beigās tu zināsi, kuru struktūru lietot saziņai ar Godot.

  1. Izveido Godot.Collections.Dictionary saveData = new();.
  2. Pievieno tam saveData["player_name"] = "Anna"; un saveData["level"] = 5;.
  3. Izdrukā abas vērtības.
  4. Pieraksti, vai Godot.Collections.Dictionary pieļauj dažādu type (tipu) vērtības vienā struktūrā.
  5. Mēģini līdzīgus datus ielikt Dictionary<string, int> un izlasi kļūdu.
  6. Pieraksti, kura struktūra derēs saglabāšanai failā.
  7. Izvēlies savam inventāram pareizo variantu un pamato.
Godot.Collections.Dictionary inv = new();
inv["coins"] = 100;
inv["arrows"] = 25;
if (inv.ContainsKey("coins")) GD.Print(inv["coins"]);

Gatavs, kad: Godot.Collections.Dictionary pieņem dažādus type vienā struktūrā, bet Dictionary<string, int> prasa vienu vērtības type.

Papildu uzdevums - Izmēģini SortedDictionary

Kur strādāt: SortedDictionary izveidi un izdrukas pievieno Scripts/Inventory.cs metodei _Ready(); salīdzinājumu raksti README.md.

Ja pamatdarbs ir gatavs, salīdzini ātru meklēšanu ar sakārtotu izdruku.

  1. Izveido to pašu inventāru ar SortedDictionary<string, int>.
  2. Izdrukā to loop un salīdzini secību ar Dictionary<string, int>.
  3. Pieraksti, kura struktūra izdrukā atslēgas sakārtoti.
  4. Pieraksti, kura struktūra parasti ir piemērotāka vienkāršai ātrai meklēšanai.

Gatavs, kad: SortedDictionary (sakārtota vārdnīca) izdrukā atslēgas alfabētiski, bet parastais Dictionary tiek lietots ikdienas ātrai piekļuvei.

Paplašināts koda piemērs 
using Godot;
using System.Collections.Generic;

public class PlayerInventory
{
    private readonly Dictionary<string, int> inventory = new();

    public void AddItem(string name, int amount = 1)
    {
        inventory.TryGetValue(name, out int current);
        inventory[name] = current + amount;
        GD.Print("+", amount, " ", name);
    }

    public bool UseItem(string name)
    {
        if (!inventory.TryGetValue(name, out int count) || count <= 0)
        {
            GD.Print("Nav ", name);
            return false;
        }

        inventory[name] = count - 1;
        return true;
    }

    public void PrintInventory()
    {
        foreach ((string name, int count) in inventory)
        {
            GD.Print(name, ": ", count);
        }
    }
}
Inventārs rāda: Health Potion: 5, Mana Potion: 3, Sword: 1; pēc lietošanas Health Potion: 4.

Ko sagatavo

Stundas mērķis: Tu proti C# izveidot Dictionary inventāru, droši meklēt tajā priekšmetus un izskaidrot, kad jālieto Godot Dictionary.

GitHub krātuvē jābūt:

  • Ekrānuzņēmums, kurā redzams, ka pēc neesoša priekšmeta pieprasījuma dictionary izmērs nemainās.
  • README.md: kāpēc kvadrātiekavas ar neesošu atslēgu ir bīstamas un kad lieto Godot.Collections.Dictionary.

Kā iesniedz: Veic commit (izmaiņu fiksējums) un push (nosūtīšana uz attālo krātuvi). Skolotāja norādītajā vietā ievieto tikai GitHub krātuves saiti; visiem prasītajiem failiem, README.md pierakstiem un pierādījumiem jābūt pašā krātuvē.

Ja kaut kas nestrādā

  • KeyNotFoundException (atslēga nav atrasta): Kvadrātiekavas lasa tikai esošas atslēgas. Lieto TryGetValue vai ContainsKey.
  • Sajauktas dictionary: Dictionary<string, int> ir type-safe (tipdroša) C# struktūra, bet Godot.Collections.Dictionary glabā Variant datus.
  • Negaidīta secība: parasts Dictionary nav paredzēts sakārtotai izdrukai. Ja vajag sakārtotas atslēgas, lieto SortedDictionary.
