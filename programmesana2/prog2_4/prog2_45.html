Teorija: dinamiska objektu dzīves cikla pārvaldība un Object Pooling

Atkārtotas izveides (Instantiate) un dzēšanas (QueueFree) izmaksas

Kad programmā pēc lietotāja darbības uz īsu brīdi jāparāda jauns objekts no sagatavotas .tscn veidnes (PackedScene), vienkāršākā pieeja ir to katrā reizē izveidot ar Instantiate<T>(), pievienot scēnas kokam un pēc noteikta darbības laika izdzēst ar QueueFree() (lai darbība nenotiktu katrā kadrā pēc kārtas, ievieš arī cooldown laika atskaiti, ko ik kadrā samazina par delta).

Ja šādi īslaicīgi objekti rodas un izzūd retumis, veiktspēja necieš. Taču, ja vienlaikus vai īsā laikā tiek radīti un iznīcināti simtiem eksemplāru, nepārtraukta atmiņas piešķiršana, mezglu pārkārtošana scēnas kokā un C# automātiskā atkritumu savācēja (Garbage Collector) darbība rada mikroaiztures un pazemina kadru skaitu sekundē (FPS):

// 1. Jauna eksemplāra izveide ar intervāla ierobežojumu (cooldown):
[Export] public PackedScene Veidne { get; set; }
private double gaidisana = 0.0;

public override void _PhysicsProcess(double delta)
{
    gaidisana -= delta;
    if (Input.IsActionPressed("aktivizet") && gaidisana <= 0.0)
    {
        Vienums v = Veidne.Instantiate<Vienums>();
        GetParent().AddChild(v); // Katrā reizē pievieno jaunu mezglu
        v.GlobalPosition = GlobalPosition;
        gaidisana = 0.2;
    }
}

// 2. Paša Vienums mezgla skriptā — dzēšana pēc darbības laika beigām:
dzivesLaiks -= (float)delta;
if (dzivesLaiks <= 0.0f) QueueFree(); // Atbrīvo mezglu (noslogo GC)

Objektu krātuve (Object Pooling) un atkārtota izmantošana

Objektu atkārtota izmantošana jeb krātuve (Object Pooling) aizstāj nepārtrauktu objektu radīšanu un dzēšanu ar fiksēta izmēra rezervi — līdzīgi kā ēdnīcā pusdienu laikā mazgā un lieto vienus un tos pašus 50 šķīvjus, nevis katram apmeklētājam izgatavo jaunu šķīvi un pēc maltītes to izmet. Krātuves darbība balstās uz trim posmiem:

public class VienumuKratuve
{
    private readonly List<Vienums> kratuve = new();
    private const int Izmers = 50;

    public void Sagatavot(Node vecaks, PackedScene veidne)
    {
        for (int i = 0; i < Izmers; i++)
        {
            Vienums v = veidne.Instantiate<Vienums>();
            vecaks.AddChild(v);
            Atgriezt(v);
            kratuve.Add(v);
        }
    }

    public Vienums SanemtBrivo()
    {
        foreach (Vienums v in kratuve)
        {
            if (!v.IrAktivs)
            {
                v.IestatitAktivu(true);
                v.Visible = true;
                return v;
            }
        }
        return null; // Visi eksemplāri pašlaik aizņemti.
    }

    public void Atgriezt(Vienums v)
    {
        v.IestatitAktivu(false);
        v.Visible = false;
    }
}

Sākumā visi rezerves mezgli vienreiz tiek izveidoti, pievienoti scēnai un paslēpti (Visible = false, atslēdzot fizikas apstrādi ar SetPhysicsProcess(false)). Kad objekts kļūst vajadzīgs, paņem pirmo neaktīvo eksemplāru (izsaucējam vienmēr jāpārbauda, vai metode nav atgriezusi null, ja krātuve pilnībā aizņemta), bet darbības beigās to atkal paslēpj — tādējādi mezglu skaits scēnas kokā paliek nemainīgs.

  1. Projekta iestatījumos (Project → Project Settings → Input Map) augšējā laukā Add New Action ieraksti shoot, nospied Add, tad pie shoot nospied + un izvēlies Mouse Buttons → Left Mouse Button.
  2. Izveido lādiņa scēnu: izvēlies Scene → New Scene → Other Node → Area2D, pārsauc saknes mezglu par Bullet un pievieno tam divus bērnmezglus:
    • CollisionShape2D — Inspector panelī Shape izvēlies New CircleShape2D ar Radius = 6;
    • Polygon2D (pārsauc par Visual) — uzzīmē nelielu taisnstūri vai rombu (aptuveni 12×6 px) un Color iestati koši dzeltenu.
    Saglabā scēnu mapē Scenes/ ar nosaukumu Scenes/Bullet.tscn.
  3. Piesaisti Bullet saknes mezglam jaunu C# skriptu Scripts/Bullet.cs un ievieto tajā kustības, dzīves laika un trāpījuma kodu: 
    using Godot;

public partial class Bullet : Area2D
{
    [Export] public float Speed { get; set; } = 700.0f;
    [Export] public int Damage { get; set; } = 10;
    [Export] public float MaxLifetime { get; set; } = 2.0f;

    private Vector2 direction = Vector2.Right;
    private float lifetime = 0.0f;

    public bool IsActive { get; private set; } = false;
    public bool UsePool { get; set; } = false;

    public override void _Ready()
    {
        BodyEntered += OnBodyEntered;
    }

    public override void _PhysicsProcess(double delta)
    {
        if (!IsActive) return;

        GlobalPosition += direction * Speed * (float)delta;
        lifetime -= (float)delta;

        if (lifetime <= 0.0f)
        {
            if (UsePool) Deactivate();
            else QueueFree();
        }
    }

    public void Fire(Vector2 startPos, Vector2 moveDir, bool fromPool)
    {
        GlobalPosition = startPos;
        direction = moveDir.Normalized();
        Rotation = direction.Angle();
        lifetime = MaxLifetime;
        UsePool = fromPool;
        SetActiveState(true);
    }

    public void Deactivate()
    {
        SetActiveState(false);
    }

    public void SetActiveState(bool active)
    {
        IsActive = active;
        Visible = active;
        SetPhysicsProcess(active);
        SetDeferred(Area2D.PropertyName.Monitoring, active);
    }

    private void OnBodyEntered(Node2D body)
    {
        if (!IsActive || body is Player) return;

        if (body is Enemy enemy)
        {
            enemy.TakeDamage(Damage);
        }

        if (UsePool) Deactivate();
        else QueueFree();
    }
}

if (Input.IsActionJustPressed("shoot"))

2. uzdevums

Izveido BulletPool un pārslēdz šaušanu uz objektu krātuvi

Kur strādāt: 1) Mapē Scripts/ izveido jaunu C# failu Scripts/BulletPool.cs (parasta C# klase ar List<Bullet>, nav jāpiesaista mezglam).
2) Esošajā failā Scripts/Player.cs pievieno BulletPool lauku, sagatavo krātuvi _Ready() metodē un papildini Shoot() metodi.

Tagad aizstāsim nepārtrauktu Instantiate() un QueueFree() ar 50 lādiņu rezervi (BulletPool), kuru vienreiz sagatavo spēles sākumā un pēc tam atkārtoti izmanto.

  1. Mapē Scripts/ izveido jaunu C# failu Scripts/BulletPool.cs.
  2. Failā Scripts/BulletPool.cs ieraksti pilno objektu krātuves klasi, kas glabā List<Bullet> un nodrošina metodes Initialize(...), GetBullet() un ReturnBullet(...): 
    using Godot;
using System.Collections.Generic;

public class BulletPool
{
    private readonly List<Bullet> pool = new();

    public void Initialize(Node parent, PackedScene bulletScene, int poolSize = 50)
    {
        if (parent == null || bulletScene == null || pool.Count > 0) return;

        for (int i = 0; i < poolSize; i++)
        {
            Bullet bullet = bulletScene.Instantiate<Bullet>();
            parent.AddChild(bullet);
            bullet.Deactivate();
            pool.Add(bullet);
        }
        GD.Print($"[BulletPool] Sagatavoti {pool.Count} rezerves lādiņi.");
    }

    public Bullet GetBullet()
    {
        foreach (Bullet bullet in pool)
        {
            if (!bullet.IsActive)
            {
                return bullet;
            }
        }
        return null; // Visi krātuves lādiņi pašlaik lido
    }

    public void ReturnBullet(Bullet bullet)
    {
        bullet?.Deactivate();
    }
}
  3. Atver failu Scripts/Player.cs un klases augšdaļā nomaini UsePooling noklusējuma vērtību uz true, pievieno bulletPool lauku un _Ready() metodi, kas ar CallDeferred sagatavo krātuvi tiklīdz `Arena` vecākmezgls ir gatavs: 
    [Export] public bool UsePooling { get; set; } = true;
[Export] public int PoolSize { get; set; } = 50;

private readonly BulletPool bulletPool = new();

public override void _Ready()
{
    CallDeferred(nameof(SetupPool));
}

private void SetupPool()
{
    bulletPool.Initialize(GetParent(), BulletScene, PoolSize);
}
  4. Tajā pašā Scripts/Player.cs failā atjaunini metodi Shoot(), lai tā atbalstītu abus režīmus — gan UsePooling == true (paņem brīvo lādiņu no `bulletPool`), gan UsePooling == false (izveido jaunu ar `Instantiate` salīdzināšanai 3. uzdevumā): 
    private void Shoot()
{
    if (BulletScene == null) return;

    if (UsePooling)
    {
        Bullet pooledBullet = bulletPool.GetBullet();
        if (pooledBullet == null) return; // Krātuve pilnībā aizņemta

        pooledBullet.Fire(GlobalPosition, Transform.X, true);
    }
    else
    {
        Bullet newBullet = BulletScene.Instantiate<Bullet>();
        GetParent().AddChild(newBullet);
        newBullet.Fire(GlobalPosition, Transform.X, false);
    }
}
  5. Nospied Build un palaid Scenes/Arena.tscn (F5): pārliecinies, ka Output konsolē parādās [BulletPool] Sagatavoti 50 rezerves lādiņi..
  6. Kamēr spēle darbojas, Godot redaktora kreisajā panelī virs scēnas koka pārslēdz cilni no Local uz Remote: zem Arena redzēsi tieši 50 Bullet mezglus, un šaujot jauni mezgli klāt vairs nerodas.

Gatavs, kad: šaujot lādiņi lido un trāpa kā iepriekš, bet cilnē Scene → Remote mezglu skaits šaušanas laikā paliek nemainīgs.

Papildu uzdevums — Pievieno aptveres izmēru un pārlādēšanu (R)

Kur strādāt: Papildini esošo Scripts/Player.cs failu ar patronu skaitītāju un pārlādēšanas taimeri.

Ja pamatdarbs ir gatavs, pievieno spēlētājam ierobežotu aptveri (piemēram, 15 lādiņi), kas pēc izšaušanas vai taustiņa R nospiešanas pārlādējas 1,2 sekundes.

  1. Failā Scripts/Player.cs pievieno laukus public int MaxAmmo = 15;, public int CurrentAmmo = 15; un private double reloadTimer = 0.0;.
  2. Metodē _PhysicsProcess(double delta) apstrādā reloadTimer atskaiti: kamēr reloadTimer > 0, šaut nevar, bet kad tas sasniedz 0, atjauno CurrentAmmo = MaxAmmo un izdrukā [Player] Aptvere pārlādēta (15/15).
  3. Metodē Shoot() pirms šāviena pārbaudi if (CurrentAmmo <= 0) — ja patronas beigušās, uzsāc pārlādēšanu (reloadTimer = 1.2;); pretējā gadījumā pēc šāviena samazini CurrentAmmo--.

Gatavs, kad: pēc 15 šāvieniem spēlētājs uz 1,2 sekundēm pārlādē ieroci un Output konsolē redzams atlikušo patronu skaits.

using Godot;

public partial class Player : CharacterBody2D
{
    [Export] public float Speed { get; set; } = 240.0f;
    [Export] public PackedScene BulletScene { get; set; } = GD.Load<PackedScene>("res://Scenes/Bullet.tscn");
    [Export] public bool UsePooling { get; set; } = true;
    [Export] public int PoolSize { get; set; } = 50;
    [Export] public float FireCooldown { get; set; } = 0.18f;

    private readonly BulletPool bulletPool = new();

    public override void _Ready()
    {
        CallDeferred(nameof(SetupPool));
    }

    private void SetupPool()
    {
        bulletPool.Initialize(GetParent(), BulletScene, PoolSize);
    }

    public override void _PhysicsProcess(double delta)
    {
        Vector2 inputDir = new Vector2(
            Input.GetAxis("move_left", "move_right"),
            Input.GetAxis("move_up", "move_down")

        if (inputDir != Vector2.Zero)

            inputDir = inputDir.Normalized();

        Velocity = inputDir * Speed;
        MoveAndSlide();

        LookAt(GetGlobalMousePosition());
