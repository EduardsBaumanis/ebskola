2. Kāds ir skapisi.Count un skapisi["B-14"] pēc šī koda?

Katra atslēga ir tikai vienreiz. Piešķirot esošai atslēgai, vecā vērtība tiek pārrakstīta. Atkārto: 4.2 — Teorija: asociatīvās vārdnīcas C# un Godot vidē ↗

3. Kas notiek ar GD.Print(inventory["Nav tada"]);, ja tādas atslēgas nav?

Ar kvadrātiekavām nezināmu atslēgu nolasīt nedrīkst. Droši to dara TryGetValue. Atkārto: 4.2 — 2. uzdevums — Droša meklēšana ar TryGetValue ↗

4. Inventārā ir Health Potion, Mana Potion un Ammo Pack. Ko atgriež GetAmount("Shield")? 
public int GetAmount(string name)
{
    if (inventory.TryGetValue(name, out int amount))
        return amount;
    return 0;
}

TryGetValue atgriež false, tāpēc metode atgriež 0. Vārdnīca nemainās. Atkārto: 4.2 — 2. uzdevums — Droša meklēšana ar TryGetValue ↗

Godot vārdnīca der saglabāšanai un saziņai ar Godot; tipdrošā C# vārdnīca — inventāra skaitļiem kodā. Atkārto: 4.2 — 3. uzdevums — Salīdzini Dictionary ar Godot Dictionary ↗
