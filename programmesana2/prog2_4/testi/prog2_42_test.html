Atkārtojuma tests: 4.1 List (saraksts) un Array (masīvs)

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kas notiek ar List<int> merijumi, ja tajā mēģina pievienot "kļūda"?

List<T> ir tipdrošs. Netipizēts Godot.Collections.Array gan atļautu jaukt skaitļus un tekstu. Atkārto: 4.1 — Teorija: dinamiskie saraksti C# un Godot vidē ↗

2. Ko satur saraksts pēc šī koda? 
enemies.Add(new Enemy { EnemyName = "Skauts" });
enemies.Add(new Enemy { EnemyName = "Sargs" });
enemies.Add(new Enemy { EnemyName = "Snaiperis" });
enemies.RemoveAt(1);

Numerācija sākas ar 0, tāpēc indekss 1 ir otrais elements — Sargs. Count kļūst 2. Atkārto: 4.1 — 2. uzdevums — Pievieno un izņem elementus droši ↗

3. Sarakstā ir 3 elementi. Kas notiek ar GD.Print(enemies[10].EnemyName);?

Pirms piekļuves pārbauda index >= 0 && index < enemies.Count. Atkārto: 4.1 — 2. uzdevums — Pievieno un izņem elementus droši ↗

4. Kāpēc nedrīkst rakstīt enemies.Remove(enemy) tieši foreach (Enemy enemy in enemies) cikla iekšienē?

Tas ir kā izņemt pakāpienu no kāpnēm, kamēr pa tām kāpj. Tāpēc dzēš divos posmos ar toRemove sarakstu. Atkārto: 4.1 — 2. uzdevums — Pievieno un izņem elementus droši ↗

5. Kuru sarakstu izvēlas, lai to varētu aizpildīt Inspector panelī?

Godot Array<T> var eksportēt un nodot Godot API. Iekšējiem aprēķiniem C# kodā lieto List<T>. Atkārto: 4.1 — 3. uzdevums — Salīdzini List ar Godot Array ↗
