4.1 Vector un Array

Stundas uzdevums: Saprast atšķirību starp std::vector un Godot Array, izvēlēties piemēroto datu struktūru.

SR 2.4.16. Saliktas datu struktūras SR 2.4.13. Datu tipi

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido ienaidnieku sarakstu ar vector · 2. uzdevums (~25 min) - pievieno un izņem elementus droši · 3. uzdevums (~20 min) - salīdzini vector ar Godot Array · Iesniegšana (~5 min).

Pirms sāc: atceries no Programmēšanas I sarakstus: materiali.append("x") un materiali.pop(0). C++ tas pats saucas std::vector, ar push_back un erase.

Praktiskie uzdevumi

1. uzdevums - Izveido ienaidnieku sarakstu ar vector

Beigās viens mainīgais glabās visus ienaidniekus.

  1. Iekļauj #include <vector>.
  2. Pievieno klasei lauku std::vector<Enemy*> enemies;.
  3. Pievieno trīs ienaidniekus ar enemies.push_back(...);.
  4. Izdrukā to skaitu ar enemies.size();.
  5. Uzraksti ciklu for (Enemy* e : enemies) { ... }, kas izdrukā katra nosaukumu.
  6. Pievieno ceturto ienaidnieku un palaid vēlreiz.
  7. Pārbaudi, vai cikls bija jāmaina.

Gatavs, kad: cikls izdrukā visus ienaidniekus, un pievienojot ceturto, kods nav jāmaina.

2. uzdevums - Pievieno un izņem elementus droši

Beigās tu zināsi, kāpēc sarakstu nedrīkst mainīt cikla laikā.

  1. Izņem otro elementu ar enemies.erase(enemies.begin() + 1);.
  2. Izdrukā saraksta izmēru pirms un pēc izņemšanas.
  3. Mēģini piekļūt elementam enemies[10] un pieraksti, kas notiek.
  4. Nomaini to uz enemies.at(10) un salīdzini rezultātu.
  5. Uzraksti ciklu, kas cikla iekšpusē mēģina izdzēst elementu, un palaid to.
  6. Pārraksti to tā, lai dzēšamos vispirms savāktu otrā sarakstā.
  7. Pieraksti, kāpēc pirmais variants ir bīstams.

Gatavs, kad: saraksta izmērs pēc dzēšanas ir par vienu mazāks, un droši dzēst izdodas tikai pēc cikla.

3. uzdevums - Salīdzini vector ar Godot Array

Beigās tu zināsi, kuru sarakstu kurā vietā lietot.

  1. Izveido Array bullets; un pievieno tam dažas vērtības.
  2. Izdrukā tā izmēru ar bullets.size();.
  3. Mēģini ielikt Array sarakstā gan skaitli, gan tekstu.
  4. Mēģini to pašu ar std::vector<int> un izlasi kompilatora kļūdu.
  5. Pieraksti, kurš saraksts pieļauj dažādus tipus.
  6. Pieraksti, kurš saraksts ir vajadzīgs, lai datus nodotu Godot editoram.
  7. Izvēlies savam ienaidnieku sarakstam pareizo variantu un pamato izvēli.

Gatavs, kad: tu vari pateikt, ka std::vector ir tipa-drošs un ātrs iekšējam kodam, bet Array vajadzīgs saziņai ar Godot.

Papildu uzdevums - Atrodi tuvāko ienaidnieku

Ja pamatdarbs ir gatavs, izmanto sarakstu reālam aprēķinam.

  1. Uzraksti metodi, kas saņem spēlētāja pozīciju.
  2. Izej ciklā cauri visiem ienaidniekiem.
  3. Izrēķini katram attālumu ar position.distance_to(...).
  4. Saglabā mainīgajā to, kuram attālums ir mazākais.
  5. Izdrukā tuvākā ienaidnieka nosaukumu un attālumu.

Gatavs, kad: metode atgriež tieši to ienaidnieku, kurš ekrānā ir vistuvāk spēlētājam.

Ko iesniedz skolotājam

Stundas mērķis: Tu proti C++ izveidot std::vector sarakstu, droši pievienot un izņemt elementus un izskaidrot, ar ko tas atšķiras no Godot Array.

Iesniedzamais:

  1. C++ fails ar ienaidnieku sarakstu un ciklu GitHub krātuvē.
  2. Ekrānuzņēmums ar Output paneli, kurā redzams saraksta izmērs pirms un pēc dzēšanas.
  3. README.md: kāpēc sarakstu nedrīkst mainīt cikla laikā un kad lieto Array, nevis std::vector.

Kā iesniedz: Veic commit un push, tad iesniedz krātuves saiti un ekrānuzņēmumu skolotāja norādītajā vietā; README.md failā jābūt prasītajiem pierakstiem.

Biežākās kļūdas

  • Crash with begin(): Vector tukšs, bet mēģini iegūt elements.
  • Memory leak: 'new Enemy' bez delete. Lieto unique_ptr vai add_child.
  • Iterator invalidation: Pievienojot/dzēšot vektoru cikla laikā, iterator var kļūt nederīgs.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

#include <godot_cpp/variant/utility_functions.hpp>

std::vector<Enemy*> enemies;

void spawn_enemy() {
    Enemy* e = memnew(Enemy);
    add_child(e);
    e->set_position(Vector2(UtilityFunctions::randf_range(0.0, 1280.0), 0));
    enemies.push_back(e);
}

void Game::_physics_process(double delta) {
    spawn_timer += delta;
    if (spawn_timer >= 2.0) {
        spawn_enemy();
        spawn_timer = 0;
    }
    // Noņem mirušos
    enemies.erase(
        std::remove_if(enemies.begin(), enemies.end(),
            [](Enemy* e) { return !e->is_alive(); }),
        enemies.end());
}
