4.1 List (saraksts) un Array (masīvs)

Stundas uzdevums: Saprast atšķirību starp C# List<T> (tipizēts saraksts) un Godot Array (masīvs), izvēlēties piemēroto data structure (datu struktūru).

Praktiskie uzdevumi

1. uzdevums -

Izveido ienaidnieku list (sarakstu) ar List (saraksts)

Beigās viens variable (mainīgais) glabās visus ienaidniekus.

  1. Pievieno file (faila) sākumā using System.Collections.Generic;.
  2. Pievieno class (klasei) field (lauku) private List<Enemy> enemies = new();.
  3. Pievieno trīs ienaidniekus ar enemies.Add(enemy);.
  4. Izdrukā to skaitu ar enemies.Count.
  5. Uzraksti loop (ciklu) foreach (Enemy enemy in enemies) { ... }, kas izdrukā katra nosaukumu.
  6. Pievieno ceturto ienaidnieku un palaid vēlreiz.
  7. Pārbaudi, vai loop (cikls) bija jāmaina.

Gatavs, kad: loop (cikls) izdrukā visus ienaidniekus, un pievienojot ceturto, code (kods) nav jāmaina.

2. uzdevums -

Pievieno un izņem element (elementus) droši

Beigās tu zināsi, kāpēc list (sarakstu) nedrīkst mainīt loop (cikla) laikā.

  1. Izņem otro element (elementu) ar enemies.RemoveAt(1);.
  2. Izdrukā list (saraksta) izmēru pirms un pēc izņemšanas.
  3. Mēģini piekļūt element (elementam) enemies[10] un pieraksti, kas notiek.
  4. Nomaini to uz if (index >= 0 && index < enemies.Count) pārbaudi un salīdzini rezultātu.
  5. Uzraksti loop (ciklu), kas loop (cikla) iekšpusē mēģina izdzēst element (elementu), un palaid to.
  6. Pārraksti to tā, lai dzēšamos vispirms savāktu otrā list (sarakstā).
  7. Pieraksti, kāpēc pirmais variants ir bīstams.

Gatavs, kad: list (saraksta) izmērs pēc dzēšanas ir par vienu mazāks, un droši dzēst izdodas tikai pēc loop (cikla).

3. uzdevums -

Salīdzini List (saraksts) ar Godot Array (masīvs)

Beigās tu zināsi, kuru list (sarakstu) kurā vietā lietot.

  1. Izveido Godot.Collections.Array bullets = new(); un pievieno tam dažas value (vērtības).
  2. Izdrukā tā izmēru ar bullets.Count.
  3. Mēģini ielikt Array (masīvs) list (sarakstā) gan skaitli, gan tekstu.
  4. Mēģini to pašu ar List<int> un izlasi compiler error (kompilatora kļūdu).
  5. Pieraksti, kurš list (saraksts) pieļauj dažādus type (tipus).
  6. Pieraksti, kurš list (saraksts) ir vajadzīgs, lai data (datus) nodotu Godot editoram.
  7. Izvēlies savam ienaidnieku list (sarakstam) pareizo variantu un pamato izvēli.

Gatavs, kad: tu vari pateikt, ka List<T> (tipizēts saraksts) ir type-safe (tipdrošs) un ērts iekšējam C# kodam, bet Array (masīvs) vajadzīgs saziņai ar Godot data (datiem).

Papildu uzdevums - Atrodi tuvāko ienaidnieku

Ja pamatdarbs ir gatavs, izmanto list (sarakstu) reālam aprēķinam.

  1. Uzraksti method (metodi), kas saņem spēlētāja position (pozīciju).
  2. Izej loop (ciklā) cauri visiem ienaidniekiem.
  3. Izrēķini katram attālumu ar Position.DistanceTo(...).
  4. Saglabā variable (mainīgajā) to, kuram attālums ir mazākais.
  5. Izdrukā tuvākā ienaidnieka nosaukumu un attālumu.

Gatavs, kad: method (metode) atgriež tieši to ienaidnieku, kurš screen (ekrānā) ir vistuvāk spēlētājam.

  • Collection (kolekcija) was modified: pievienojot vai dzēšot no List<T> (tipizēts saraksts) foreach (katra elementa cikls) laikā, loop (cikls) apstājas ar kļūdu.

using Godot;
using System.Collections.Generic;

public partial class Game : Node2D
{
    [Export] public PackedScene EnemyScene;
    private readonly List<Enemy> enemies = new();
    private double spawnTimer = 0.0;

    private void SpawnEnemy()
    {
        Enemy enemy = EnemyScene.Instantiate<Enemy>();
        AddChild(enemy);
        enemy.Position = new Vector2((float)GD.RandRange(0.0, 1280.0), 0);
        enemies.Add(enemy);
    }

    public override void _PhysicsProcess(double delta)
    {
        spawnTimer += delta;
        if (spawnTimer >= 2.0)
        {
            SpawnEnemy();
            spawnTimer = 0.0;
        }

        // Noņem mirušos
        enemies.RemoveAll(enemy => !enemy.IsAlive());
    }
}
Spēle spawno 1 ienaidnieku ik pa 2 sec, mirstīgi tiek noņemti no vector (vektora) un scene (scēnas).
