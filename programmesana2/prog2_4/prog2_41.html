4.1 List un Array

Stundas uzdevums: Saprast atšķirību starp C# List<T> un Godot Array, izvēlēties piemēroto datu struktūru.

SR 2.4.16. Saliktas datu struktūras SR 2.4.13. Datu tipi

80 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~20 min) - izveido ienaidnieku sarakstu ar List<T> · 2. uzdevums (~25 min) - pievieno un izņem elementus droši · 3. uzdevums (~20 min) - salīdzini List<T> ar Godot Array · Iesniegšana (~5 min).

Pirms sāc: atceries no Programmēšanas I sarakstus: materiali.append("x") un materiali.pop(0). C# tas pats parasti ir List<T>, ar Add() un RemoveAt().

Praktiskie uzdevumi

1. uzdevums - Izveido ienaidnieku sarakstu ar List

Beigās viens mainīgais glabās visus ienaidniekus.

  1. Pievieno faila sākumā using System.Collections.Generic;.
  2. Pievieno klasei lauku private List<Enemy> enemies = new();.
  3. Pievieno trīs ienaidniekus ar enemies.Add(enemy);.
  4. Izdrukā to skaitu ar enemies.Count.
  5. Uzraksti ciklu foreach (Enemy enemy in enemies) { ... }, kas izdrukā katra nosaukumu.
  6. Pievieno ceturto ienaidnieku un palaid vēlreiz.
  7. Pārbaudi, vai cikls bija jāmaina.

Gatavs, kad: cikls izdrukā visus ienaidniekus, un pievienojot ceturto, kods nav jāmaina.

2. uzdevums - Pievieno un izņem elementus droši

Beigās tu zināsi, kāpēc sarakstu nedrīkst mainīt cikla laikā.

  1. Izņem otro elementu ar enemies.RemoveAt(1);.
  2. Izdrukā saraksta izmēru pirms un pēc izņemšanas.
  3. Mēģini piekļūt elementam enemies[10] un pieraksti, kas notiek.
  4. Nomaini to uz if (index >= 0 && index < enemies.Count) pārbaudi un salīdzini rezultātu.
  5. Uzraksti ciklu, kas cikla iekšpusē mēģina izdzēst elementu, un palaid to.
  6. Pārraksti to tā, lai dzēšamos vispirms savāktu otrā sarakstā.
  7. Pieraksti, kāpēc pirmais variants ir bīstams.

Gatavs, kad: saraksta izmērs pēc dzēšanas ir par vienu mazāks, un droši dzēst izdodas tikai pēc cikla.

3. uzdevums - Salīdzini List ar Godot Array

Beigās tu zināsi, kuru sarakstu kurā vietā lietot.

  1. Izveido Godot.Collections.Array bullets = new(); un pievieno tam dažas vērtības.
  2. Izdrukā tā izmēru ar bullets.Count.
  3. Mēģini ielikt Array sarakstā gan skaitli, gan tekstu.
  4. Mēģini to pašu ar List<int> un izlasi kompilatora kļūdu.
  5. Pieraksti, kurš saraksts pieļauj dažādus tipus.
  6. Pieraksti, kurš saraksts ir vajadzīgs, lai datus nodotu Godot editoram.
  7. Izvēlies savam ienaidnieku sarakstam pareizo variantu un pamato izvēli.

Gatavs, kad: tu vari pateikt, ka List<T> ir tipa-drošs un ērts iekšējam C# kodam, bet Array vajadzīgs saziņai ar Godot datiem.

Papildu uzdevums - Atrodi tuvāko ienaidnieku

Ja pamatdarbs ir gatavs, izmanto sarakstu reālam aprēķinam.

  1. Uzraksti metodi, kas saņem spēlētāja pozīciju.
  2. Izej ciklā cauri visiem ienaidniekiem.
  3. Izrēķini katram attālumu ar Position.DistanceTo(...).
  4. Saglabā mainīgajā to, kuram attālums ir mazākais.
  5. Izdrukā tuvākā ienaidnieka nosaukumu un attālumu.

Gatavs, kad: metode atgriež tieši to ienaidnieku, kurš ekrānā ir vistuvāk spēlētājam.

Biežākās kļūdas

  • ArgumentOutOfRangeException: sarakstā nav elementa ar tādu indeksu - pārbaudi index < enemies.Count.
  • NullReferenceException: sarakstā ielikta tukša reference vai mezgls nav atrasts.
  • Collection was modified: pievienojot vai dzēšot no List<T> foreach laikā, cikls apstājas ar kļūdu.

Godot ekrānuzņēmumi

Koda piemērs (paplašināts)

using Godot;
using System.Collections.Generic;

public partial class Game : Node2D
{
    [Export] public PackedScene EnemyScene;
    private readonly List<Enemy> enemies = new();
    private double spawnTimer = 0.0;

    private void SpawnEnemy()
    {
        Enemy enemy = EnemyScene.Instantiate<Enemy>();
        AddChild(enemy);
        enemy.Position = new Vector2((float)GD.RandRange(0.0, 1280.0), 0);
        enemies.Add(enemy);
    }

    public override void _PhysicsProcess(double delta)
    {
        spawnTimer += delta;
        if (spawnTimer >= 2.0)
        {
            SpawnEnemy();
            spawnTimer = 0.0;
        }

        // Noņem mirušos
        enemies.RemoveAll(enemy => !enemy.IsAlive());
    }
}
Spēle spawno 1 ienaidnieku ik pa 2 sec, mirstīgi tiek noņemti no vektora un scēnas.
