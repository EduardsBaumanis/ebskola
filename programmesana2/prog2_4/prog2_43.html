4.3 State machines AI uzvedībai

Stundas uzdevums: Implementēt AI ar stāvokļu mašīnu (state machine) reālistiskai uzvedībai.

Teorija: State machine konceptu

State machine (stāvokļu mašīna) ir AI dizaina paraugs, kur objekts vienlaikus ir vienā no diskrētiem stāvokļiem un pāriet starp tiem pēc noteikumiem.

enum class EnemyState {
    IDLE,       // gaida
    PATROL,     // staigā
    CHASE,      // dzenas
    ATTACK,     // uzbrūk
    DEAD
};

class Enemy : public CharacterBody2D {
private:
    EnemyState state = EnemyState::IDLE;
    Vector2 patrol_target;
    Player* player = nullptr;

public:
    void _physics_process(double delta) override {
        switch (state) {
            case EnemyState::IDLE:
                if (player_visible()) state = EnemyState::CHASE;
                else if (idle_too_long()) state = EnemyState::PATROL;
                break;
            case EnemyState::PATROL:
                move_to_patrol_target();
                if (player_visible()) state = EnemyState::CHASE;
                break;
            case EnemyState::CHASE:
                move_toward(player->get_position());
                if (in_attack_range()) state = EnemyState::ATTACK;
                else if (!player_visible()) state = EnemyState::IDLE;
                break;
            case EnemyState::ATTACK:
                attack_player();
                if (!in_attack_range()) state = EnemyState::CHASE;
                break;
        }
    }
};

Praktiskie uzdevumi

1. uzdevums - Izveido stāvokļu enum un pārslēgšanu

Beigās ienaidnieks zinās, kurā stāvoklī tas atrodas.

  1. Ieraksti enum class EnemyState { IDLE, PATROL, CHASE, ATTACK, DEAD };.
  2. Pievieno klasei lauku EnemyState state = EnemyState::IDLE;.
  3. Uzraksti _physics_process metodē switch (state) { ... }.
  4. Pievieno katram stāvoklim savu case ar izdruku un break;.
  5. Kompilē un palaid - jāizdrukājas tikai IDLE.
  6. Nomaini sākuma stāvokli uz PATROL un palaid vēlreiz.
  7. Pieraksti, kāpēc vienlaikus izdrukājas tikai viens stāvoklis.

Gatavs, kad: Output panelī atkārtojas tikai viena stāvokļa nosaukums, nevis visi pieci.

2. uzdevums - Pievieno pārejas noteikumus

Beigās ienaidnieks pats pārslēgsies starp stāvokļiem.

  1. Uzraksti metodi void change_state(EnemyState new_state);, kas izdrukā pāreju.
  2. Izrēķini katrā kadrā attālumu līdz spēlētājam ar distance_to.
  3. Pārslēdz uz CHASE, ja attālums ir mazāks par 300.
  4. Pārslēdz uz ATTACK, ja attālums ir mazāks par 50.
  5. Pārslēdz atpakaļ uz PATROL, ja attālums pārsniedz 400.
  6. Kompilē un pastaigā ar spēlētāju tuvāk un tālāk.
  7. Pieraksti, kāpēc atgriešanās slieksnis (400) ir lielāks par dzīšanās slieksni (300).

Gatavs, kad: pieejot tuvāk, ienaidnieks pāriet CHASE un ATTACK, bet aizejot - atgriežas PATROL.

3. uzdevums - Iztestē visus stāvokļus

Beigās tu būsi pārliecinājies, ka neviens stāvoklis neiestrēgst.

  1. Pieraksti tabulu ar visiem pieciem stāvokļiem.
  2. Atzīmē katram, no kura stāvokļa tajā var nokļūt.
  3. Pārbaudi spēlē katru pāreju un atzīmē tabulā, vai tā notika.
  4. Atrodi stāvokli, no kura nevar izkļūt, ja tāds ir.
  5. Pārbaudi, kas notiek, kad ienaidnieka HP nokrīt līdz nullei.
  6. Pievieno pāreju uz DEAD un pārliecinies, ka no tā vairs neizkļūst.
  7. Pieraksti, kurš stāvoklis ir gala stāvoklis.

Gatavs, kad: tabulā katrai pārejai ir atzīme, un no DEAD stāvokļa ienaidnieks vairs neatgriežas.

Papildu uzdevums - Pievieno stāvokļa taimeri

Ja pamatdarbs ir gatavs, neļauj stāvokļiem mainīties pārāk bieži.

  1. Pievieno lauku double state_time = 0.0;.
  2. Palielini to katrā kadrā ar delta.
  3. Atiestati to uz nulli katrā change_state izsaukumā.
  4. Neļauj mainīt stāvokli, ja state_time ir mazāks par 0.3.
  5. Pārbaudi, ka ienaidnieks vairs nemirgo starp diviem stāvokļiem.

Gatavs, kad: stāvot tieši uz sliekšņa robežas, ienaidnieks vairs nemaina stāvokli vairākas reizes sekundē.

Koda piemērs (paplašināts)

enum class EnemyState { IDLE, PATROL, CHASE, ATTACK, DEAD };

void Enemy::_physics_process(double delta) {
    state_timer += delta;

    switch (state) {
        case EnemyState::IDLE:
            if (player_in_vision) change_state(EnemyState::CHASE);
            else if (state_timer > 3.0) change_state(EnemyState::PATROL);
            break;

        case EnemyState::PATROL: {
            Vector2 dir = (patrol_target - get_position()).normalized();
            velocity = dir * 100.0f;
            move_and_slide();
            if (get_position().distance_to(patrol_target) < 10) {
                swap_patrol_target();
            }
            if (player_in_vision) change_state(EnemyState::CHASE);
        } break;

        case EnemyState::CHASE: {
            Vector2 dir = (player_pos - get_position()).normalized();
            velocity = dir * 200.0f;
            move_and_slide();
            if (get_position().distance_to(player_pos) < 50) {
                change_state(EnemyState::ATTACK);
            }
        } break;

        case EnemyState::ATTACK:
            if (state_timer >= 1.0) {
                player->take_damage(10);
                state_timer = 0;
            }
            break;
    }
}

void Enemy::change_state(EnemyState new_state) {
    state = new_state;
    state_timer = 0;
}
