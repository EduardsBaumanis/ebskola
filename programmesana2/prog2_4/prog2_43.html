Teorija: galīga stāvokļu mašīna (State Machine) un pāreju loģika

Stāvokļu mašīnas princips, enum un switch izvēle

Ja autonoma objekta uzvedību mēģina aprakstīt ar daudziem atsevišķiem bool karodziņiem un sazarotām if-else virknēm, noteikumi ātri sāk pretrunot cits citam. Galīga stāvokļu mašīna (Finite State Machine) ir uzvedības projektēšanas paraugs (design pattern), kur objekts katrā laika brīdī atrodas tieši vienā diskrētā stāvoklī — līdzīgi kā robots putekļsūcējs vienlaikus neveic gan telpas tīrīšanu, gan uzlādi dokstacijā, bet darbojas vienā skaidrā režīmā.

Pieļaujamos režīmus C# kodā apraksta ar enum (uzskaitījuma tipu), pašreizējo stāvokli glabā private laukā, bet cikliskajā metodē _PhysicsProcess(double delta) ar switch struktūru izpilda tikai aktīvajam case atbilstošās darbības (noslēdzot katru zaru ar break;):

public enum IericesStavoklis { Gaidisana, Marsruts, Sekosana, Darbiba, Izslegts }

private IericesStavoklis stavoklis = IericesStavoklis.Gaidisana;

public override void _PhysicsProcess(double delta)
{
    switch (stavoklis)
    {
        case IericesStavoklis.Gaidisana:
            if (VaiMerkisUztverts()) stavoklis = IericesStavoklis.Sekosana;
            break;
        case IericesStavoklis.Sekosana:
            VirzitiesPretiMerkim();
            if (!VaiMerkisUztverts()) stavoklis = IericesStavoklis.Marsruts;
            break;
        case IericesStavoklis.Izslegts:
            break; // Gala stāvoklis — izejošu pāreju nav.
    }
}

Pārejas noteikumi, sliekšņu atstarpe un gala stāvoklis

Noteikumus, kas pārslēdz objektu no viena režīma citā (piemēram, pēc laika atskaites vai attāluma Position.DistanceTo(merkis.Position), iepriekš pārliecinoties, ka merkis != null), sauc par stāvokļu pārejām (transitions). Pārslēgšanu parasti izdala atsevišķā palīgmetodē, lai vienuviet fiksētu maiņu vai atiestatītu laika skaitītāju.

Ja režīma ieslēgšanai un izslēgšanai izmanto vienu un to pašu attāluma robežu, sīkas svārstības uz šīs līnijas liek objektam raustīties starp diviem stāvokļiem katrā kadrā. Tāpēc ievieš sliekšņu atstarpi jeb histerēzi (vai minimālo stāvokļa noturēšanas laiku) — gluži kā telpas apkures termostats ieslēdz sildītāju pie 19 °C, bet izslēdz tikai sasniedzot 21 °C, lai pie 20 °C relejs nepārtraukti neklikšķētu. Savukārt režīmu, no kura nav nevienas izejošas pārejas, sauc par gala stāvokli (terminal state):

private Node2D merkis;
private double rezimaLaiks = 0.0;

private void MainitStavokli(IericesStavoklis jaunais)
{
    if (stavoklis == IericesStavoklis.Izslegts || stavoklis == jaunais) return;
    GD.Print(stavoklis, " -> ", jaunais);
    stavoklis = jaunais;
    rezimaLaiks = 0.0; // Katrā pārejā atiestata režīma laika skaitītāju
}

private void ParbauditParejas(double delta)
{
    rezimaLaiks += delta;
    if (merkis == null || stavoklis == IericesStavoklis.Izslegts) return;

    float attalums = Position.DistanceTo(merkis.Position);
    // Sliekšņu atstarpe: ieslēdz pie < 300, atslēdz tikai pie > 400
    if (stavoklis == IericesStavoklis.Marsruts && attalums < 300.0f)
        MainitStavokli(IericesStavoklis.Sekosana);
    else if (stavoklis == IericesStavoklis.Sekosana && attalums > 400.0f)
        MainitStavokli(IericesStavoklis.Marsruts);
}

1. uzdevums

Izveido stāvokļu enum un pārslēgšanu

Kur strādāt: Papildini ienaidniekam piesaistīto Scripts/Enemy.cs. Enum un state lauku liec Enemy klases iekšienē, bet switch — tās metodē _PhysicsProcess(); esošu tāda paša nosaukuma metodi papildini.

Beigās ienaidnieks zinās, kurā stāvoklī tas atrodas.

  1. Ieraksti private enum EnemyState { Idle, Patrol, Chase, Attack, Dead }.
  2. Pievieno class lauku private EnemyState state = EnemyState.Idle;.
  3. Uzraksti _PhysicsProcess method switch (state) { ... }.
  4. Pievieno katram stāvoklim savu case (izvēles gadījums) ar izdruku un break;.
  5. Būvē un palaid - jāizdrukājas tikai Idle.
  6. Nomaini sākuma stāvokli uz Patrol un palaid vēlreiz.
  7. Pieraksti, kāpēc vienlaikus izdrukājas tikai viens stāvoklis.
public enum EnemyState
{
    Idle,   // gaida
    Patrol, // patrulē
    Chase,  // dzenas
    Attack, // uzbrūk
    Dead    // gala stāvoklis
}

Gatavs, kad: Output panelī atkārtojas tikai viena stāvokļa nosaukums, nevis visi pieci.

2. uzdevums

Pievieno pārejas noteikumus

Kur strādāt: ChangeState() pievieno Scripts/Enemy.cs kā atsevišķu klases metodi. Attāluma aprēķinu un pāreju pārbaudes raksti esošajā _PhysicsProcess().

Beigās ienaidnieks pats pārslēgsies starp stāvokļiem.

  1. Uzraksti method private void ChangeState(EnemyState newState), kas izdrukā pāreju.
  2. Izrēķini katrā kadrā attālumu līdz spēlētājam ar Position.DistanceTo(player.Position).
  3. Pārslēdz uz Chase, ja attālums ir mazāks par 300.
  4. Pārslēdz uz Attack, ja attālums ir mazāks par 50.
  5. Pārslēdz atpakaļ uz Patrol, ja attālums pārsniedz 400.
  6. Būvē un pastaigā ar spēlētāju tuvāk un tālāk.
  7. Pieraksti, kāpēc atgriešanās slieksnis (400) ir lielāks par dzīšanās slieksni (300).
float dist = Position.DistanceTo(player.Position);
switch (state)
{
    case EnemyState.Patrol:
        if (dist < 300.0f) ChangeState(EnemyState.Chase);
        break;
    case EnemyState.Chase:
        if (dist < 50.0f) ChangeState(EnemyState.Attack);
        else if (dist > 400.0f) ChangeState(EnemyState.Patrol);
        break;
    case EnemyState.Attack:
        if (dist >= 50.0f) ChangeState(EnemyState.Chase);
        break;
}

Gatavs, kad: pieejot tuvāk, ienaidnieks pāriet CHASE un ATTACK, bet aizejot - atgriežas PATROL.

3. uzdevums

Iztestē visus stāvokļus

Kur strādāt: Pāreju uz Dead un pārbaudi, kas liedz to atstāt, raksti Scripts/Enemy.cs. Pāreju tabulu un testu rezultātus saglabā README.md.

Beigās tu būsi pārliecinājies, ka neviens stāvoklis neiestrēgst.

  1. Pieraksti tabulu ar visiem pieciem stāvokļiem.
  2. Atzīmē katram, no kura stāvokļa tajā var nokļūt.
  3. Pārbaudi spēlē katru pāreju un atzīmē tabulā, vai tā notika.
  4. Atrodi stāvokli, no kura nevar izkļūt, ja tāds ir.
  5. Pārbaudi, kas notiek, kad ienaidnieka HP (dzīvības punkti) nokrīt līdz nullei.
  6. Pievieno pāreju uz Dead un pārliecinies, ka no tā vairs neizkļūst.
  7. Pieraksti, kurš stāvoklis ir gala stāvoklis.

Gatavs, kad: tabulā katrai pārejai ir atzīme, un no Dead stāvokļa ienaidnieks vairs neatgriežas.

Papildu uzdevums - Pievieno stāvokļa timer (taimeri)

Kur strādāt: State_time lauku pievieno Scripts/Enemy.cs klasei; laiku palielini _PhysicsProcess(), bet pārejas ierobežojumu un atiestatīšanu raksti ChangeState().

Ja pamatdarbs ir gatavs, neļauj stāvokļiem mainīties pārāk bieži.

  1. Pievieno lauku double state_time = 0.0;.
  2. Palielini to katrā kadrā ar delta.
  3. Atiestati to uz nulli katrā ChangeState izsaukumā.
  4. Neļauj mainīt stāvokli, ja state_time ir mazāks par 0.3.
  5. Pārbaudi, ka ienaidnieks vairs nemirgo starp diviem stāvokļiem.

Gatavs, kad: stāvot tieši uz sliekšņa robežas, ienaidnieks vairs nemaina stāvokli vairākas reizes sekundē.

Paplašināts koda piemērs 
public enum EnemyState { Idle, Patrol, Chase, Attack, Dead }

public override void _PhysicsProcess(double delta)
{
    stateTimer += delta;

    switch (state)
    {
        case EnemyState.Idle:
            if (playerInVision) ChangeState(EnemyState.Chase);
            else if (stateTimer > 3.0) ChangeState(EnemyState.Patrol);
            break;

        case EnemyState.Patrol:
            Vector2 patrolDir = (patrolTarget - Position).Normalized();
            Velocity = patrolDir * 100.0f;
            MoveAndSlide();
            if (Position.DistanceTo(patrolTarget) < 10) SwapPatrolTarget();
            if (playerInVision) ChangeState(EnemyState.Chase);
            break;

        case EnemyState.Chase:
            Vector2 chaseDir = (playerPos - Position).Normalized();
            Velocity = chaseDir * 200.0f;
            MoveAndSlide();
            if (Position.DistanceTo(playerPos) < 50) ChangeState(EnemyState.Attack);
            break;

        case EnemyState.Attack:
            if (stateTimer >= 1.0)
            {
                player.TakeDamage(10);
                stateTimer = 0.0;
            }
            break;
    }
}

private void ChangeState(EnemyState newState)
{
    state = newState;
    stateTimer = 0.0;
}
Ienaidnieks staigā patrol līdz pamana spēlētāju, dzenas un uzbrūk; izvairoties - atgriežas patrol režīmā.

Ja kaut kas nestrādā

  • State paliek IDLE: Pārbaudi, vai pārejas nosacījumi tiek izpildīti.
