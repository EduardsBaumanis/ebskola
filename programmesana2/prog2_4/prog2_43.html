Teorija: State machine (stāvokļu mašīna) konceptu

State machine (stāvokļu mašīna) ir AI (mākslīgais intelekts) design pattern (dizaina paraugs), kur object (objekts) vienlaikus ir vienā no diskrētiem state (stāvokļiem) un pāriet starp tiem pēc noteikumiem.

using Godot;

public enum EnemyState
{
    Idle,       // gaida
    Patrol,     // staigā
    Chase,      // dzenas
    Attack,     // uzbrūk
    Dead
}

public partial class Enemy : CharacterBody2D
{
    private EnemyState state = EnemyState.Idle;
    private Vector2 patrolTarget;
    private Player player;

    public override void _PhysicsProcess(double delta)
    {
        switch (state)
        {
            case EnemyState.Idle:
                if (PlayerVisible()) state = EnemyState.Chase;
                else if (IdleTooLong()) state = EnemyState.Patrol;
                break;
            case EnemyState.Patrol:
                MoveToPatrolTarget();
                if (PlayerVisible()) state = EnemyState.Chase;
                break;
            case EnemyState.Chase:
                MoveToward(player.Position);
                if (InAttackRange()) state = EnemyState.Attack;
                else if (!PlayerVisible()) state = EnemyState.Idle;
                break;
            case EnemyState.Attack:
                AttackPlayer();
                if (!InAttackRange()) state = EnemyState.Chase;
                break;
        }
    }
}

Praktiskie uzdevumi

1. uzdevums -

Izveido state (stāvokļu) enum (uzskaitījuma tips) un pārslēgšanu

Beigās ienaidnieks zinās, kurā state (stāvoklī) tas atrodas.

  1. Ieraksti private enum EnemyState { Idle, Patrol, Chase, Attack, Dead }.
  2. Pievieno class (klasei) field (lauku) private EnemyState state = EnemyState.Idle;.
  3. Uzraksti _PhysicsProcess method (metodē) switch (state) { ... }.
  4. Pievieno katram stāvoklim savu case (izvēles gadījums) ar output (izdruku) un break;.
  5. Būvē un palaid - jāizdrukājas tikai Idle.
  6. Nomaini sākuma state (stāvokli) uz Patrol un palaid vēlreiz.
  7. Pieraksti, kāpēc vienlaikus izdrukājas tikai viens state (stāvoklis).

Gatavs, kad: Output (izvade) panel (panelī) atkārtojas tikai viena state (stāvokļa) nosaukums, nevis visi pieci.

2. uzdevums -

Pievieno pārejas noteikumus

Beigās ienaidnieks pats pārslēgsies starp state (stāvokļiem).

  1. Uzraksti method (metodi) private void ChangeState(EnemyState newState), kas izdrukā pāreju.
  2. Izrēķini katrā frame (kadrā) attālumu līdz spēlētājam ar Position.DistanceTo(player.Position).
  3. Pārslēdz uz Chase, ja attālums ir mazāks par 300.
  4. Pārslēdz uz Attack, ja attālums ir mazāks par 50.
  5. Pārslēdz atpakaļ uz Patrol, ja attālums pārsniedz 400.
  6. Būvē un pastaigā ar spēlētāju tuvāk un tālāk.
  7. Pieraksti, kāpēc atgriešanās slieksnis (400) ir lielāks par dzīšanās slieksni (300).

Gatavs, kad: pieejot tuvāk, ienaidnieks pāriet CHASE un ATTACK, bet aizejot - atgriežas PATROL.

3. uzdevums -

Iztestē visus state (stāvokļus)

Beigās tu būsi pārliecinājies, ka neviens state (stāvoklis) neiestrēgst.

  1. Pieraksti tabulu ar visiem pieciem state (stāvokļiem).
  2. Atzīmē katram, no kura state (stāvokļa) tajā var nokļūt.
  3. Pārbaudi spēlē katru pāreju un atzīmē tabulā, vai tā notika.
  4. Atrodi state (stāvokli), no kura nevar izkļūt, ja tāds ir.
  5. Pārbaudi, kas notiek, kad ienaidnieka HP (dzīvības punkti) nokrīt līdz nullei.
  6. Pievieno pāreju uz Dead un pārliecinies, ka no tā vairs neizkļūst.
  7. Pieraksti, kurš state (stāvoklis) ir gala state (stāvoklis).

Gatavs, kad: tabulā katrai pārejai ir atzīme, un no Dead state (stāvokļa) ienaidnieks vairs neatgriežas.

Papildu uzdevums - Pievieno state (stāvokļa) timer (taimeri)

Ja pamatdarbs ir gatavs, neļauj state (stāvokļiem) mainīties pārāk bieži.

  1. Pievieno field (lauku) double state_time = 0.0;.
  2. Palielini to katrā frame (kadrā) ar delta.
  3. Atiestati to uz nulli katrā ChangeState izsaukumā.
  4. Neļauj mainīt state (stāvokli), ja state_time ir mazāks par 0.3.
  5. Pārbaudi, ka ienaidnieks vairs nemirgo starp diviem state (stāvokļiem).

Gatavs, kad: stāvot tieši uz sliekšņa robežas, ienaidnieks vairs nemaina state (stāvokli) vairākas reizes sekundē.

public enum EnemyState { Idle, Patrol, Chase, Attack, Dead }

public override void _PhysicsProcess(double delta)
{
    stateTimer += delta;

    switch (state)
    {
        case EnemyState.Idle:
            if (playerInVision) ChangeState(EnemyState.Chase);
            else if (stateTimer > 3.0) ChangeState(EnemyState.Patrol);
            break;

        case EnemyState.Patrol:
            Vector2 patrolDir = (patrolTarget - Position).Normalized();
            Velocity = patrolDir * 100.0f;
            MoveAndSlide();
            if (Position.DistanceTo(patrolTarget) < 10) SwapPatrolTarget();
            if (playerInVision) ChangeState(EnemyState.Chase);
            break;

        case EnemyState.Chase:
            Vector2 chaseDir = (playerPos - Position).Normalized();
            Velocity = chaseDir * 200.0f;
            MoveAndSlide();
            if (Position.DistanceTo(playerPos) < 50) ChangeState(EnemyState.Attack);
            break;

        case EnemyState.Attack:
            if (stateTimer >= 1.0)
            {
                player.TakeDamage(10);
                stateTimer = 0.0;
            }
            break;
    }
}

private void ChangeState(EnemyState newState)
{
    state = newState;
    stateTimer = 0.0;
}
