Tēmu secība un savienojumi

Katrs projekts ir atsevišķa spēle - bet koncepti veido pakāpenisku kāpumu. Agrāko tēmu prasmes tiek izmantotas katrā jaunajā projektā. 6., 7., 9. un 10. tēma vēl tiek izstrādāta: tajās būs valsts standarta sasniedzamie rezultāti, kurus citas tēmas neaptver.

01

Ievads Godot 4 un C# - Pong

Godot redaktors, scēnu un node (mezglu) sistēma, Godot .NET uzstādīšana, pirmā C# class (klase), Pong spēles laukums, fizika un tastatūras vadīšana.

Godot .NET · C# pamati ↗ Projekts: Pong spēle
↓ static (statiska) fizika → dinamiska kustība un sadursmes
02

Kustība un sadursmes - Platformas spēle

CharacterBody2D (vadāma 2D tēla mezgls) un fizika, gravitācija un lēkšana, TileMap (flīžu karte) līmeņu celtniecība, animācijas (AnimationPlayer (animāciju atskaņotājs)), sadursmes slāņi, ienaidnieki ar vienkāršu kustību, savācamie objekti.

CharacterBody2D · TileMap · animācija ↗ Projekts: 2D platformas spēle
↓ fizika → OOP (objektorientētā programmēšana) un spēles sistēmas
03

Object-oriented programming - RPG (lomu spēle)

C# class inheritance (mantošana) un polymorphism (polimorfisms), spēlētāja un ienaidnieka class hierarchy (klašu hierarhija), inventāra sistēma ar array (masīviem), dialogu sistēma, spēles State Machine (stāvokļu mašīna).

OOP · inheritance · State Machine ↗ Projekts: RPG spēle ar dialogiem
↓ sistēmas → data structure (datu struktūras) un AI (mākslīgais intelekts) uzvedība
04

Data structure un AI - Šaušanas spēle skatā no augšas

Rindas (Queue (rinda)), steki (Stack (steks)), prioritāšu rindas; ienaidnieku AI ar Navigation2D un A* algoritmu, ieroču sistēma ar array, viļņu pārvaldnieks, highscore (rekords) tabula memory (atmiņā).

Queue · Stack · A* · Navigation2D ↗ Projekts: Šaušanas spēle skatā no augšas ar AI
↓ AI → datu saglabāšana un procedural generation (procedurālā ģenerēšana)
05

Datu saglabāšana un algoritmi - Roguelike (spēle ar nejaušiem līmeņiem un neatgriezenisku nāvi)

Saglabāšana un ielāde ar FileAccess (failu piekļuve) un JSON (JavaScript objektu pieraksts), procedural generation ar BSP (binārā telpas sadalīšana) algoritmu, roguelike gameplay mehānikas (permadeath (neatgriezeniska nāve), random loot (nejaušas balvas)), konfigurāciju faili, skaņas un mūzika.

saglabāšana/ielāde · BSP · procedural generation ↗ Projekts: Roguelike ar procedural (procedurālu) karti
↓ spēles dati failos → datubāze ar vairākām tabulām
06

Datubāzes spēlēm - inventārs un statistika

ER modelis, SQLite datubāze C# projektā ar Microsoft.Data.Sqlite, vairākas tabulas, ārējās atslēgas un JOIN, datu piekļuves slānis un transakcijas, indeksi un ātrdarbības mērījumi.

ER modelis · SQLite · SQL tēma tiek izstrādāta
↓ saglabāti dati → mašīnmācīšanās modelis
07

Mašīnmācīšanās spēlēs - pretinieks, kas mācās

Treniņa dati no spēles telemetrijas, klasifikācija ar ML.NET, algoritmu salīdzināšana, attēlu atpazīšana ar gatavu ONNX modeli, apmācīts pretinieks Godot spēlē.

ML.NET · ONNX · telemetrija tēma tiek izstrādāta
↓ spēle pilnībā funkcionāla → polish un publicēšana
08

UI (lietotāja saskarne), skaņa un publicēšana - Atjautības uzdevums

Pārskatāma UI ar Control (saskarnes vadīkla) node, galvenā izvēlne un iestatījumi, skaņas efekti un mūzikas pārvaldnieks, eksportēšana uz Windows/Linux/macOS, publicēšana itch.io, spēles prezentācija klasē.

UI · skaņa · eksportēšana · itch.io ↗ Projekts: Publicēta Atjautības spēle
↓ publicēta spēle → daudzspēlētāju režīms un serveris
09

Tīkls, serveris un kriptogrāfija - daudzspēlētāju arēna

Aizsargāts lokālais tīkls, Godot ENetMultiplayerPeer, RPC un sinhronizācija, paroļu hash, HMAC paraksti un AES šifrēšana, rekordu serveris ar ASP.NET Core, pieejams no interneta.

ENet · RPC · HMAC · ASP.NET tēma tiek izstrādāta
↓ individuālie projekti → komandas projekts pasūtītājam
10

Komandas projekts - no pasūtījuma līdz laidienam

Darba uzdevums citai komandai, izstrādes modeļa izvēle, prasību specifikācija un projektējums, zari un pull request, vienots koda stils, vienībtesti un akcepttests, laidiens ar licenci un lietotāja ceļvedi.

Git komandā · xUnit · laidiens tēma tiek izstrādāta
