01

Ievads Godot 4 un C# - Pong

Godot editor (redaktors), scene (scēnu) un node (mezglu) system (sistēma), Godot .NET uzstādīšana, pirmā C# class (klase), Pong spēles laukums, fizika un keyboard (tastatūras) vadīšana.

Godot .NET · C# pamati ↗ Project (projekts): Pong spēle
↓ static (statiska) fizika → dynamic (dinamiska) kustība un collision (sadursmes)
02

Kustība un collision (sadursmes) - Platformer (platformas spēle)

CharacterBody2D (vadāma 2D tēla mezgls) un fizika, gravitācija un lēkšana, TileMap (flīžu karte) līmeņu celtniecība, animation (animācijas) (AnimationPlayer (animāciju atskaņotājs)), collision (sadursmes) slāņi, ienaidnieki ar vienkāršu kustību, savācamie object (objekti).

CharacterBody2D (vadāma 2D tēla mezgls) · TileMap (flīžu karte) · animation (animācija) ↗ Project (projekts): 2D platformer (platformas spēle)
↓ fizika → OOP (objektorientētā programmēšana) un spēles system (sistēmas)
03

Object-oriented programming (objektorientētā programmēšana) - RPG (lomu spēle)

C# class (klasēs) inheritance (mantošana) un polymorphism (polimorfisms), spēlētāja un ienaidnieka class hierarchy (klašu hierarhija), inventory (inventāra) system (sistēma) ar array (masīviem), dialogu system (sistēma), spēles State Machine (stāvokļu mašīna).

OOP (objektorientētā programmēšana) · inheritance (mantošana) · State Machine (stāvokļu mašīna) ↗ Project (projekts): RPG (lomu spēle) spēle ar dialogiem
↓ system (sistēmas) → data structure (datu struktūras) un AI (mākslīgais intelekts) uzvedība
04

Data structure (datu struktūras) un AI (mākslīgais intelekts) - Top-down Shooter (šaušanas spēle skatā no augšas)

Rindas (Queue (rinda)), steki (Stack (steks)), prioritāšu rindas; ienaidnieku AI (mākslīgais intelekts) ar Navigation2D un A* algorithm (algoritmu), ieroču system (sistēma) ar array (masīviem), viļņu pārvaldnieks, highscore (rekords) tabula memory (atmiņā).

Queue (rinda) · Stack (steks) · A* · Navigation2D ↗ Project (projekts): Top-down Shooter (šaušanas spēle skatā no augšas) ar AI (mākslīgais intelekts)
↓ AI (mākslīgais intelekts) → data (datu) save (saglabāšana) un procedural generation (procedurālā ģenerēšana)
05

Data persistence (datu pastāvība) un algorithm (algoritmi) - Roguelike (spēle ar nejaušiem līmeņiem un neatgriezenisku nāvi)

Save/load (saglabāšana un ielāde) ar FileAccess (failu piekļuve) un JSON (JavaScript objektu pieraksts), procedural generation (procedurālā ģenerēšana) ar BSP (binārā telpas sadalīšana) algorithm (algoritmu), roguelike (spēle ar nejaušiem līmeņiem un neatgriezenisku nāvi) gameplay mechanic (mehānikas) (permadeath (neatgriezeniska nāve), random loot (nejaušas balvas)), configuration (konfigurāciju) file (faili), audio (skaņas) un mūzika.

save/load (saglabāšana/ielāde) · BSP (binārā telpas sadalīšana) · procedural generation (procedurālā ģenerēšana) ↗ Project (projekts): Roguelike (spēle ar nejaušiem līmeņiem un neatgriezenisku nāvi) ar procedural (procedurālu) karti
↓ spēle pilnībā funkcionāla → polish un publishing (publicēšana)
06

UI (lietotāja saskarne), audio (skaņa) un publishing (publicēšana) - Puzzle (atjautības uzdevums)

Polished UI (lietotāja saskarne) ar Control (saskarnes vadīkla) node (mezgliem), main menu (galvenā izvēlne) un settings (iestatījumi), sound effect (skaņas efekti) un mūzikas pārvaldnieks, export (eksportēšana) uz Windows/Linux/macOS, publishing (publicēšana) itch.io, spēles prezentācija klasē.

UI (lietotāja saskarne) · audio (skaņa) · export (eksportēšana) · itch.io ↗ Noslēguma project (projekts): Publicēta Puzzle game (atjautības spēle)
