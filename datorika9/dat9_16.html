1.6 Pabeidz spēles pieteikumu — projekta 2. daļa

Šodien: Pabeidz savas spēles apraksta lapu un iesniedz GitHub projekta saiti.

Tēmas projekts · 2. daļa no 2

Īsā teorija

Projekta pieteikums šajā kursā ir darbojoša HTML lapa ar spēles ideju un ekrāniem.

README.md ir īss projekta apraksts GitHub. Tajā raksti tikai darbam vajadzīgo.

Šajā tēmā pogas pārslēdz ekrānus; pašu spēlēšanu pievienosi vēlāk. 

# Mana spēle
Mērķis: savākt piecas zvaigznes.
Atvēršana: atver index.html pārlūkā.

Sākuma kods un darba vieta

Turpini savu iepriekšējās nodarbības projektu pēc 1. uzdevuma soļiem. Ja tā nav, šeit ir pilns sākuma paraugs. Jauno kopiju saglabā kā index.html mapē Desktop/datorika9-tema1 .

1. uzdevums

Turpini savu projektu

Vide: VS Code

  1. Atver savu 15.html un ar File → Save As saglabā kopiju kā index.html tajā pašā tēmas mapē.
  2. Ja iepriekšējā darba nav, izmanto šīs lapas sākuma kodu un ieraksti savu nosaukumu un mērķi.
  3. Pārliecinies, ka sākuma ekrānā ir trīs noteikumi: darbība, uzvara un zaudējums.

Gatavs, kad: index.html satur tavas spēles ideju un noteikumus.

2. uzdevums

Pabeidz lapu un aprakstu

Vide: VS Code

  1. Spēles ekrānā pārbaudi punktu rindu un vadības norādi; pievieno trūkstošo.
  2. VS Code failu sarakstā spied New File un izveido README.md . Ja tas jau ir, atver to.
  3. Pēc teorijas parauga ieraksti nosaukumu, mērķi un atvēršanas norādi. Saglabā.

Gatavs, kad: Lapā ir abi ekrāni, bet README ir īsa atvēršanas norāde.

3. uzdevums

Iesniedz tēmas projektu

Vide: Pārlūks → VS Code → GitHub

  1. Atver index.html pārlūkā. Pārbaudi sākšanas un atgriešanās pogu.
  2. Parādi lapu klasesbiedram un mutiski izstāsti, ko spēlētājs darīs.
  3. Saglabā visus failus un nosūti izmaiņas uz GitHub ar zemāk dotajām pogām.
  4. GitHub pārbaudi index.html un README.md . Iesniedz projekta saiti skolotāja norādītajā vietā.

Gatavs, kad: GitHub projekta saite ved uz pabeigto darbu.

Iesniedz 3. uzdevuma rezultātu

Iesniedz GitHub projekta saiti . Projektā jābūt pabeigtajam index.html un šajā nodarbībā prasītajiem failiem.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • index.html ir paša spēles mērķis, trīs noteikumi un vadības norāde.
  • Darbojas abu ekrānu pārslēgšana.
  • GitHub projektā ir index.html un īss README; iesniegta projekta saite.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Saglabā un nosūti uz GitHub — pogu atgādne

Vide: VS Code / Source Control → GitHub pārlūkā

  1. Ar File → Save All saglabā failus. Atver Source Control ar Ctrl+Shift+G .
  2. Pie Changes nospied + (Stage All Changes). Pārbaudi, ka vajadzīgie faili pārvietojas uz Staged Changes .
  3. Ziņas laukā ieraksti īsu izmaiņu, piemēram, Pabeigts 1.6 darbs . Spied Commit .
  4. Ja šī tēmas mape vēl nav GitHub, spied Publish to GitHub un izveido publisku projektu datorika9-tema1 . Jau publicētam projektam spied Sync Changes . Ja pogas nav, atver … → Push .
  5. Pārlūkā atver savu GitHub projektu un pārbaudi faila pēdējās izmaiņas.

Ja Source Control rāda Initialize Repository , vispirms nospied to. Ja parādās kļūda vai sapludināšanas pieprasījums, izmanto palīdzību un palūdz skolotāja atbalstu.

Papildu uzdevums: Pievieno norādi par nākamo versiju

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

  1. README beigās pievieno vienu konkrētu nākamās versijas darbu, piemēram, “Pievienot punktu skaitītāju”.
  2. Nosūti šo izmaiņu uz GitHub.
Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši index.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Poga nestrādā? Pārbaudi, vai neizdzēsi pēdiņu, iekavu vai elementa id. Salīdzini savu laboto vietu ar sākuma kodu.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
