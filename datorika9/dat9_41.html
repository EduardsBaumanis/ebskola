4.1 Funkcijas un koda atkārtota izmantošana

Stundas uzdevums: Izstrādāt un pielietot atkārtoti izmantojamus koda blokus (funkcijas), lai optimizētu spēles loģiku un izvairītos no koda dublēšanās.

2.6.1. Ievēro programmas pieraksta un strukturēšanas labās prakses ieteikumus; 1.3.4. Izvēlas programmu izvēlētā izstrādājuma īstenošanai.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - palaid gatavu funkciju pievienotPunktus() · 2. uzdevums (~25 min) - uzraksti dzīvību un restarta funkcijas · 3. uzdevums (~20 min) - izsauc visas trīs funkcijas konsolē un salabo kļūdu. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu spēles mapi koda redaktorā ar failiem index.html un script.js, un atver index.html pārlūkā.

Teorija: Koda "Receptes" (Funkcijas)

Funkcija ir kā recepte – tu to uzraksti vienreiz, bet vari "pagatavot" (izsaukt) cik reizes vien vēlies. Tā ļauj sagrupēt kodu loģiskos blokos.

  • Definēšana: Mēs izveidojam funkciju ar atslēgas vārdu function, iedodam tai nosaukumu un figūriekavās {} ieliekam kodu, kas būs jāizpilda.
  • Izsaukšana: Funkcija pati no sevis neko nedara, kamēr mēs to neizsaucam, aiz nosaukuma uzrakstot iekavas, piemēram, saktSpeli();.
  • Parametri (Argumenti): Funkcijām var iedot datus, ar kuriem strādāt. Piemēram, pieskaititPunktus(10) un pieskaititPunktus(50) izmanto vienu un to pašu funkciju, bet ar dažādām vērtībām.

Praktiskie uzdevumi

1. uzdevums - Palaid gatavu punktu pieskaitīšanas funkciju

Beigās poga "Savākt monētu" pieskaitīs 10 punktus, un skaitlis lapā mainīsies.

Kopējamais paraugs: divas rindas HTML failā un viena funkcija JavaScript failā.

<p id="punkti">Punkti: 0</p>
<button id="monetaPoga">Savākt monētu</button>
let punkti = 0;

function pievienotPunktus(daudzums) {
  punkti = punkti + daudzums;
  document.getElementById("punkti").textContent = "Punkti: " + punkti;
}

document.getElementById("monetaPoga").addEventListener("click", function () {
  pievienotPunktus(10);
});
  1. Atver index.html un ielīmē abas HTML rindas pirms </body>.
  2. Atver script.js un ielīmē JavaScript kodu faila beigās.
  3. Saglabā abus failus un pārlādē lapu pārlūkā.
  4. Nospied pogu trīs reizes un vēro, kā skaitlis aug par 10.
  5. Nomaini izsaukumā skaitli 10 uz 25 un pārlādē lapu.
  6. Pārbaudi, ka tagad viens klikšķis pieskaita 25 punktus.

Gatavs, kad: pēc trim klikšķiem lapā redzams teksts "Punkti: 75".

2. uzdevums - Uzraksti dzīvību un restarta funkcijas

Beigās divas jaunas pogas atņems dzīvību un atgriezīs spēli sākuma stāvoklī.

  1. Atver index.html un pievieno rindu <p id="dzivibas">Dzīvības: 3</p>.
  2. Pievieno divas pogas: <button id="bojajumsPoga">Saņemt bojājumu</button> un <button id="restartsPoga">Restarts</button>.
  3. Atver script.js un pievieno faila augšā mainīgo let dzivibas = 3;.
  4. Uzraksti funkciju zaudetDzivibu(), kas atņem vienu dzīvību un ieraksta jauno skaitli elementā #dzivibas.
  5. Uzraksti funkciju restartetSpeli(), kas atgriež punkti = 0 un dzivibas = 3 un pārraksta abus tekstus.
  6. Piesaisti abas funkcijas pogām ar addEventListener un saglabā failu.

Gatavs, kad: pēc "Restarts" nospiešanas lapā atkal redzams "Punkti: 0" un "Dzīvības: 3".

3. uzdevums - Izsauc funkcijas konsolē un salabo kļūdu

Beigās tu būsi pārliecinājies, ka visas trīs funkcijas strādā pareizi arī pēc restarta.

  1. Atver pārlūkā izstrādātāja rīkus ar taustiņu F12 un pārej uz cilni Console.
  2. Ieraksti pievienotPunktus(50) un nospied Enter - skaitlim lapā jākļūst 50.
  3. Ieraksti to pašu vēlreiz - rezultātam jābūt 100, nevis 50.
  4. Izsauc zaudetDzivibu() trīs reizes un pārbaudi, ka dzīvības nokrīt līdz 0.
  5. Salabo, ja skaitlis mainās tikai konsolē, bet ne lapā: funkcijas beigās trūkst teksta pārrakstīšanas rindas.
  6. Pieraksti vienu secinājumu: kāpēc viena funkcija ar parametru ir labāka par divām atsevišķām funkcijām.

Gatavs, kad: pēc restartetSpeli() izsaukuma konsolē lapā redzams "Punkti: 0" un "Dzīvības: 3".

Papildu uzdevums - Pievieno līmeņa funkciju

Beigās poga "Nākamais līmenis" palielinās līmeņa numuru, un restarts to atgriezīs uz 1.

  1. Pievieno index.html rindu <p id="limenis">Līmenis: 1</p> un pogu <button id="limenaPoga">Nākamais līmenis</button>.
  2. Pievieno script.js faila augšā mainīgo let limenis = 1;.
  3. Uzraksti funkciju iestatitLimeni(n), kas piešķir limenis = n un pārraksta tekstu elementā #limenis.
  4. Piesaisti pogai izsaukumu iestatitLimeni(limenis + 1) ar addEventListener.
  5. Paplašini restartetSpeli(), lai tā izsauc iestatitLimeni(1).
  6. Veic git commit -m "Add level function and full restart".

Gatavs, kad: pēc trim klikšķiem redzams "Līmenis: 4", un "Restarts" atgriež "Līmenis: 1".

Biežākās kļūdas (un kā tās labot):

  • Funkcija neizpildās: Esi uzrakstījis smuku function start() {...}, bet pārlūkā nekas nenotiek. Tu aizmirsi to izsaukt! Neaizmirsti pievienot start(); faila beigās.
  • Mainīgo tvērums (Scope): Ja izveidosi mainīgo (ar let) funkcijas IEKŠPUSĒ, tas "nomirs" brīdī, kad funkcija beigs darbu. Ārpus funkcijas tu to neredzēsi. Tāpēc galvenos spēles datus (punktus, dzīvības) vienmēr definē faila augšā, ārpus jebkuras funkcijas!
  • Aizmirstas iekavas izsaukumā: Ja kodā uzrakstīsi saktSpeli (bez iekavām), JavaScript tikai sapratīs, ka tāda funkcija eksistē, bet to nepalaidīs. Vienmēr vajag saktSpeli().

Koda piemērs (globālie mainīgie un ekrāna atjaunošana funkcijā)

// SVARĪGI: spēles dati definēti ĀRPUS funkcijām, citādi tie "nomirst"
let punkti = 0;
let dzivibas = 3;

// Viena vieta, kas pārraksta abus tekstus lapā
function atjaunotEkranu() {
    document.getElementById("punkti").textContent = "Punkti: " + punkti;
    document.getElementById("dzivibas").textContent = "Dzīvības: " + dzivibas;
}

function pievienotPunktus(daudzums) {
    punkti = punkti + daudzums;
    atjaunotEkranu();   // bez šīs rindas skaitlis lapā nemainītos
}

function zaudetDzivibu() {
    dzivibas = dzivibas - 1;
    atjaunotEkranu();
    if (dzivibas <= 0) {
        document.getElementById("statuss").textContent = "Spēle beigusies!";
    }
}

function restartetSpeli() {
    punkti = 0;
    dzivibas = 3;
    document.getElementById("statuss").textContent = "";
    atjaunotEkranu();
}

pievienotPunktus(10);   // Punkti: 10
pievienotPunktus(50);   // Punkti: 60
zaudetDzivibu();        // Dzīvības: 2
restartetSpeli();       // Punkti: 0, Dzīvības: 3
Lapā secīgi redzēsi:
Punkti: 10 → Punkti: 60 → Dzīvības: 2 → Punkti: 0 un Dzīvības: 3.

Kāpēc tas strādā: punkti un dzivibas ir definēti faila augšā, tāpēc visas trīs funkcijas redz vienas un tās pašas vērtības. Ja tos definētu funkcijas iekšpusē ar let, katrs izsaukums sāktu no nulles.
