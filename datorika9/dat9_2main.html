# 02 špikeris

2. tēmas špikeris - CSS, multimediji un failu ceļi

Krāsas, Box Model, attēli, skaņa un mapju struktūra. Katrs bloks atbilst vienai stundai.

2.1 CSS pamati un kontrasts

/* NEPAREIZI: pirmajai rindai trūkst semikola,
   tāpēc pārlūks nenolasa arī nākamo rindu */
body {
    background-color: #222831
    color: #DFD0B8;
}

/* PAREIZI */
body {
    background-color: #222831;
    color: #DFD0B8;
    font-family: Arial, sans-serif;
}

/* Selektori */
body        { }   /* visiem šāda tipa tagiem */
#menu       { }   /* elementam ar id="menu"   - viens lapā */
.poga       { }   /* visiem ar class="poga"   - var būt daudzi */

h1 { color: #FFB142; text-align: center; }

Katras rindas beigās semikols. Bez tā pārlūks klusi ignorē arī nākamo rindu - kļūdas paziņojuma nebūs.

2.2 Box Model - kāpēc kaste ir platāka nekā domāji

/* NEPAREIZI: pārlūks rēķina 400 + 10 + 10 + 5 + 5 = 430 px.
   Tieši tāpēc laukums izspiežas ārpus ekrāna. */
#game-container {
    width: 400px;
    padding: 10px;
    border: 5px solid #333;
}

/* PAREIZI: box-sizing liek platumā IEKĻAUT padding un border */
#game-container {
    box-sizing: border-box;
    width: 400px;      /* tagad kopā tiešām ir 400 px */
    padding: 10px;
    border: 5px solid #333;
    margin: 0 auto;    /* centrē horizontāli */
}

/*  content  <- pats saturs
    padding  <- atstarpe IEKŠPUSĒ
    border   <- rāmis
    margin   <- atstarpe ĀRPUSĒ  */

box-sizing: border-box atrisina 90% izkārtojuma problēmu - liec to uzreiz.

2.3 Attēli: ceļi un optimizācija

<!-- NEPAREIZI: liels burts ceļā un tukšs alt.
     Serverī "Atteli" un "atteli" ir DIVAS dažādas mapes -> 404 -->
<img src="Atteli/Varonis.PNG" alt="">

<!-- PAREIZI -->
<img src="atteli/varonis.webp"
     alt="Raķete ar zilu dzinēja liesmu"
     width="120" loading="lazy">

<!-- Formāti:
     WebP  mazs izmērs, mūsdienīgs  -> lieto šo
     PNG   caurspīdīgums
     JPG   fotogrāfijas
     SVG   ikonas, nezaudē kvalitāti

     Failu nosaukumos: tikai mazie burti, bez atstarpēm
     un garumzīmēm: varonis-1.webp , NEVIS "Varoņa attēls.PNG" -->

alt teksts nav neobligāts - to lasa ekrānlasītājs un tas parādās, ja attēls neielādējas.

2.4 Skaņa JavaScript pusē

// NEPAREIZI: otrajā ātrajā klikšķī skaņa neatskan,
// jo tā vēl skan un netiek attīta uz sākumu
const klikskis = new Audio("skanas/klikskis.mp3");
poga.addEventListener("click", () => klikskis.play());

// PAREIZI: pirms atskaņošanas attin uz sākumu
poga.addEventListener("click", () => {
    klikskis.currentTime = 0;
    klikskis.play();
});

// Audio objektu veido VIENU reizi faila sākumā, ne katrā klikšķī
const fons = new Audio("skanas/fons.mp3");
fons.loop = true;      // atkārtojas bezgalīgi
fons.volume = 0.3;     // 0.0 līdz 1.0

// Pārlūks neļauj atskaņot skaņu, pirms lietotājs ir kaut ko nospiedis.

Formāts .mp3 vai .ogg - tos atbalsta visi pārlūki.

2.5-2.6 Mapju struktūra un relatīvie ceļi

/* Mapju struktūra
projekts/
├── index.html
├── css/style.css
├── js/script.js
└── atteli/fons.webp                            */

/* NEPAREIZI: šis ceļš meklē mapi atteli/ IEKŠĀ mapē css/ -> 404 */
body { background-image: url("atteli/fons.webp"); }

/* PAREIZI: ../ nozīmē "izej no mapes css/ vienu līmeni uz augšu" */
body { background-image: url("../atteli/fons.webp"); }

/*  fails.png      tajā pašā mapē
    mape/fails.png apakšmapē
    ../fails.png   vienu līmeni uz augšu     */

/* Responsīvs attēls - neizlec no ekrāna */
.hero-image { max-width: 100%; height: auto; }

Ceļu vienmēr skaita no tā faila, kurā raksti. CSS failā ceļš ir citāds nekā HTML failā.

.knopite { cursor: pointer; } /* CSS padara lapas interaktīvas */
