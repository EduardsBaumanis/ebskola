4.4 Laika kontrole (Timers) un spēles cikls

Stundas uzdevums: Izveidot automātisku spēles ciklu, izmantojot laika kontroles funkcijas, lai spēles elementi (šķēršļi, laika atskaite) darbotos patstāvīgi bez lietotāja iejaukšanās.

2.6.1. Pieraksta un izpilda algoritmus; 3.4.3. Skaidro tehnoloģisko procesu norisi (reāllaika sistēmas).

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - palaid gatavu sekunžu skaitītāju · 2. uzdevums (~25 min) - uzbūvē spēles ciklu, kas kustina ienaidnieku · 3. uzdevums (~20 min) - salabo dubultā starta kļūdu. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu 4.3 stundas projektu ar laukumu #laukums un spēlētāju #speletajs koda redaktorā un pārlūkā.

Teorija: Kas ir Spēles Cikls (Game Loop)?

Gandrīz visas datorspēles pamatā ir "Game Loop" – kods, kas atkārtojas desmitiem reižu sekundē (FPS - frames per second). Tas dara trīs lietas: nolasa spēlētāja ievadi, atjaunina pozīcijas un pārzīmē ekrānu.

  • setInterval(funkcija, milisekundes): Iebūvēts JS rīks, kas liek pārlūkam atkārtoti izsaukt norādīto funkciju ik pēc noteikta laika (1000 ms = 1 sekunde).
  • clearInterval(id): Rīks, kas aptur iepriekš sākto ciklu. Tas ir svarīgi, lai spēle apstātos, kad iestājas "Game Over" vai beidzas laiks.
  • Automātiskā kustība: Ja mēs setInterval ciklā katru reizi palielinām ienaidnieka X koordinātu par 5 pikseļiem (ik pēc 20 ms), cilvēka acij izskatīsies, ka objekts plūdeni slīd pa ekrānu.

// Spēles cikls: funkcija atkārtojas ik pēc 100 ms
let punkti = 0;
let ciklsId = setInterval(function () {
  punkti = punkti + 1;
  document.getElementById("punkti").textContent = punkti;
}, 100);

// Apturēšana - šo rindu izpilda TIKAI tad, kad spēle jābeidz
function beigtSpeli() {
  clearInterval(ciklsId);
}

Praktiskie uzdevumi

1. uzdevums - Palaid gatavu sekunžu skaitītāju

Beigās skaitlis lapā pieaugs par vienu katru sekundi, un poga to apturēs.

Kopējamais paraugs: divas rindas HTML failā un viens taimeris JavaScript failā.

<p id="skaititajs">0</p>
<button id="apturetPoga">Apturēt</button>
let sekundes = 0;
let ciklsId = setInterval(function () {
  sekundes = sekundes + 1;
  document.getElementById("skaititajs").textContent = sekundes;
}, 1000);

document.getElementById("apturetPoga").addEventListener("click", function () {
  clearInterval(ciklsId);
});
  1. Atver index.html un ielīmē abas HTML rindas pirms </body>.
  2. Atver script.js un ielīmē taimera kodu faila beigās.
  3. Saglabā, pārlādē lapu un vēro, kā skaitlis aug pats no sevis.
  4. Nospied "Apturēt" un pārbaudi, ka skaitlis vairs nemainās.
  5. Nomaini skaitli 1000 uz 200 un pārlādē lapu.
  6. Pārbaudi, ka skaitītājs tagad aug piecas reizes ātrāk.

Gatavs, kad: skaitlis aug bez tavas iejaukšanās un poga to nekavējoties aptur.

2. uzdevums - Uzbūvē spēles ciklu, kas kustina ienaidnieku

Beigās sarkanais kvadrāts pats slīdēs pa laukumu, un pogas to sāks un apturēs.

  1. Atver index.html un pievieno laukumā ienaidnieku: <div id="ienaidnieks" style="position:absolute;left:0;top:100px;width:30px;height:30px;background:red;"></div>.
  2. Pievieno divas pogas: <button id="saktPoga">Sākt</button> un <button id="beigtPoga">Apturēt</button>.
  3. Atver script.js un uzraksti faila augšā let ienX = 0; un let ciklsId = null;.
  4. Uzraksti funkciju spelesCikls(), kas pieskaita ienX = ienX + 3, atgriež ienX uz 0, kad tas pārsniedz 400, un iestata style.left ar "px".
  5. Uzraksti funkciju saktSpeli(), kas piešķir ciklsId = setInterval(spelesCikls, 16);.
  6. Uzraksti funkciju beigtSpeli(), kas izsauc clearInterval(ciklsId), un piesaisti abas funkcijas pogām.

Gatavs, kad: pēc "Sākt" sarkanais kvadrāts slīd pa laukumu, un "Apturēt" to nostādina uz vietas.

3. uzdevums - Salabo dubultā starta kļūdu

Beigās spēle darbosies vienādā ātrumā, lai cik reižu tu spiestu pogu "Sākt".

  1. Nospied "Sākt" vienu reizi un iegaumē, cik ātri kvadrāts slīd.
  2. Nospied "Sākt" vēl divas reizes bez apturēšanas - kustība kļūst neprātīgi ātra.
  3. Atver script.js un funkcijas saktSpeli() pirmajā rindā pievieno clearInterval(ciklsId);.
  4. Pārlādē lapu un nospied "Sākt" piecas reizes pēc kārtas.
  5. Pārbaudi, ka ātrums vairs nemainās, lai cik reižu pogu nospiestu.
  6. Pieraksti vienu secinājumu: kāpēc katra setInterval ID jāglabā mainīgajā ārpus funkcijas.

Gatavs, kad: pēc piecām "Sākt" nospiešanām kvadrāts slīd tikpat ātri kā pēc pirmās.

Papildu uzdevums - Pievieno 30 sekunžu atskaiti

Beigās spēle pati beigsies, kad taimeris nolaidīsies līdz nullei.

  1. Pievieno index.html rindu <p id="taimeris">30</p>.
  2. Pievieno script.js faila augšā let sekundes = 30;.
  3. Uzraksti otru taimeri ar setInterval, kas ik sekundi atņem 1 no sekundes.
  4. Ieraksti jauno vērtību elementā #taimeris katrā taimera izsaukumā.
  5. Izsauc beigtSpeli(), kad sekundes kļūst 0, un apturi arī pašu atskaiti.
  6. Veic git commit -m "Add countdown timer to game".

Gatavs, kad: pēc 30 sekundēm taimeris rāda 0 un ienaidnieks pats apstājas.

Biežākās kļūdas (un kā tās labot):

  • "Zūdošais" taimera ID: Ja definēsi let spelesTaimeris = setInterval(...) funkcijas iekšpusē, tu nevarēsi to apturēt ar clearInterval() citā funkcijā (Scope kļūda). Taimera mainīgo vienmēr definē faila sākumā!
  • Paātrināšanās kļūda (Multiple intervals): Ja funkcija, kas iedarbina setInterval, tiek izsaukta vairākas reizes (piemēram, katru reizi nospiežot "Sākt spēli"), tiks palaisti vairāki paralēli taimeri, un laiks vai kustība kļūs neprātīgi ātra. Vienmēr pārbaudi, vai iepriekšējais intervāls ir apturēts pirms jauna sākšanas.
  • Neaizmirsti "px": Automātiskā kustība nestrādās, ja piemirsīsi pievienot mērvienību (...style.top = Y + "px").

Koda piemērs (taimera apturēšana un dubultā setInterval novēršana)

// SVARĪGI: ID definēts ĀRPUS funkcijām, citādi to nevar apturēt citā funkcijā
let ciklsId = null;
let ienX = 0;
const ienaidnieks = document.getElementById("ienaidnieks");

function spelesCikls() {
    ienX = ienX + 3;
    if (ienX > 400) {
        ienX = 0;                            // sāk no jauna no kreisās malas
    }
    ienaidnieks.style.left = ienX + "px";    // bez "px" kustība nenotiek
}

function saktSpeli() {
    clearInterval(ciklsId);                  // apturam veco ciklu, ja tāds jau darbojas
    ciklsId = setInterval(spelesCikls, 16);  // ~60 kadri sekundē
}

function beigtSpeli() {
    clearInterval(ciklsId);
    document.getElementById("statuss").textContent = "Spēle beigusies!";
}

document.getElementById("saktPoga").addEventListener("click", saktSpeli);
document.getElementById("beigtPoga").addEventListener("click", beigtSpeli);
Ekrānā: pēc "Sākt" sarkanais kvadrāts slīd pa labi un pēc laukuma malas parādās no jauna kreisajā pusē.

Pēc "Apturēt": kustība apstājas un parādās teksts "Spēle beigusies!".

Kāpēc svarīga pirmā rinda funkcijā saktSpeli(): bez clearInterval(ciklsId) katrs jauns "Sākt" klikšķis palaistu vēl vienu paralēlu ciklu, un kvadrāts kļūtu arvien ātrāks.
