SR 2.6.1. Pieraksta, lasa un izpilda vārdiski un grafiski pierakstītus algoritmus, kas satur vairākas secīgas, dažādu veidu cikliskas un komplicētas darbības. Pieraksta algoritmu, izmanto atbilstošas vienkāršas datu struktūras vienā no programmēšanas valodām. Ievēro programmas pieraksta un strukturēšanas labās prakses ieteikumus. SR 2.6.2. Teorija ar piemēriem

Automātiska kustība no maziem atkārtotiem soļiem un apļa atgriešanās

4.2. un 4.3. nodarbībā spēlētājs izkustējās tikai tad, kad tika nospiesta poga vai taustiņš. Lai spēles pretinieks vai šķērslis slīdētu pār laukumu pats, pārlūkam jālūdz vienu un to pašu mazo kustības funkciju izsaukt daudzas reizes sekundē:

let x = 0;
const atrums = 4;

function biditSkersli() {
  x = x + atrums;
  const robeza = document.getElementById("laukums").clientWidth - 30;
  if (x > robeza) {
    x = 0;
  }
  document.getElementById("pretinieks").style.left = x + "px";
  document.getElementById("vieta").textContent = "X: " + x;
}
  • Pikseļi vienā solī: konstante atrums = 4 pasaka, par cik pikseļiem mainās x vienā izsaukuma reizē (0 → 4 → 8 → 12 → 16...), nevis sekundē. Cik ātri tas izskatās ekrānā, nosaka gan soļa garums (atrums), gan tas, cik bieži taimeris izsauc šo funkciju.
  • Atgriešanās sākumā aiz labās robežas: spēlētājam pie sienas rakstījām if (x > robeza) { x = robeza; }, lai tas apstātos. Turpretim pretiniekam rakstām if (x > robeza) { x = 0; } — tiklīdz 30 px platais kvadrāts pārsniedz 270 px robežu, tas pārlec atpakaļ kreisajā malā pie x = 0 un sāk jaunu apli!
  • Atsevišķi teksta lauki: spēles režīmu (Stāvoklis: Kustas / Apturēts) un mainīgo koordināti (#vieta) glabā divās atsevišķās rindkopās, lai koordinātes atjaunošana ik pēc pāris milisekundēm neizdzēstu stāvokļa paziņojumu.

Taimera ieslēgšana (setInterval), izslēgšana (clearInterval) un null

JavaScript iebūvētā komanda setInterval izveido atkārtotu laika taimeri un atdod tā numuru (identifikatoru), kuru saglabā mainīgajā, lai vēlāk taimeri varētu apturēt ar clearInterval:

let pulkstenis = null;

function palaist() {
  pulkstenis = setInterval(biditSkersli, 50);
}

function apturet() {
  clearInterval(pulkstenis);
  pulkstenis = null;
}
Pieraksts Ko tas nozīmē?
let pulkstenis = null; Īpašā vērtība null nozīmē “tukšs — pašlaik neviens taimeris nedarbojas”.
setInterval(biditSkersli, 50) Izsauc doto funkciju atkārtoti aptuveni ik pēc 50 milisekundēm (1000 ms = 1 sekunde; jo mazāks milisekunžu skaitlis, jo biežāki soļi un ātrāka kustība!).
Funkcijas vārds bez () Gan setInterval(biditSkersli, 50), gan addEventListener("click", palaist) funkcijas vārdu padod bez iekavām — mēs nododam pārlūkam pašu darbību vēlākai izsaukšanai. Ar biditSkersli() tā izpildītos tikai vienu reizi uzreiz!
clearInterval(pulkstenis) Atrod un aptur taimeri pēc mainīgajā saglabātā numura. Ja mainīgajā ir null, komanda droši neko nedara un kļūdu neizraisa.

Aizsardzība pret dubultu taimeri un atšķirība starp pauzi un atjaunošanu

Kas notiek, ja spēlētājs nospiež pogu Sākt trīs vai piecas reizes pēc kārtas, kamēr funkcija palaist() tikai izsauc setInterval? Katrs klikšķis iedarbina vēl vienu paralēlu taimeri: objekts sāk traukties vairākkārt ātrāk, bet mainīgajā pulkstenis saglabājas tikai pēdējā taimera numurs — iepriekšējos taimerus poga Apturēt vairs nespēj izslēgt!

Lai jebkurā brīdī darbotos ne vairāk kā viens taimeris, sākšanas funkcijas pašā sākumā vienmēr vispirms izslēdz iepriekšējo taimeri:

function palaist() {
  clearInterval(pulkstenis);
  pulkstenis = setInterval(biditSkersli, 50);
}

Spēlēs skaidri nošķir arī pauzi (apturēšanu uz vietas) no pilnas atjaunošanas sākuma pozīcijā:

Darbība Kas notiek ar taimeri? Kas notiek ar koordināti x un ekrānu?
Apturēt (pauze) clearInterval aptur taimeri. x nemainās — kvadrāts paliek turpat, un nākamais Sākt turpina no šīs vietas.
Atjaunot (no sākuma) Vispirms aptur taimeri (piemēram, izsaucot apturet();). Noliek x = 0; un atjauno gan .style.left ("0px"), gan koordinātes tekstu lapā.
Pašpārbaude: kāpēc iekš setInterval(solis, 30) vārdam solis galā neraksta iekavas (), un kāpēc bez clearInterval pieci klikšķi uz “Sākt” salauž pogu “Apturēt”?

1) Bez iekavām pārlūkam nodod pašu funkciju atkārtotai izsaukšanai ik pēc 30 ms; ar iekavām solis() tā izpildītos tikai vienu reizi uzreiz. 2) Pieci klikšķi bez iepriekšējās izslēgšanas palaiž piecus taimerus vienlaikus, bet mainīgais taimeris atceras tikai piektā taimera numuru, tāpēc clearInterval(taimeris) vairs nespēj apturēt pirmos četrus.

1. uzdevums

Izpēti taimera palaišanu, pauzi un pielāgo pretinieka izskatu

Izmanto teoriju: Taimera ieslēgšana (setInterval), izslēgšana (clearInterval) un null.

Vide: Windows File Explorer → pārlūks → VS Code

  1. Windows mapē Desktop/datorika9-tema4 atver saglabāto 44.html pārlūkā (Open with → Edge) un pārliecinies, ka sākumā kvadrāts stāv pie kreisās malas un redzams Stāvoklis: Apturēts un Pretinieka X: 0.
  2. Vienu reizi nospied pogu Sākt: vēro, kā pretinieks pats slīd pa labi, stāvoklis nomainās uz Stāvoklis: Kustas un aiz labās malas kvadrāts atkal parādās kreisajā pusē.
  3. Laukuma vidū nospied pogu Apturēt un pēc mirkļa atkal Sākt — pārliecinies, ka pauze aptur kvadrātu uz vietas un nākamā sākšana turpina kustību no tās pašas vietas.
  4. VS Code atver 44.html un <script> blokā izpēti funkcijas solis(), sakt() un apturet(), īpaši pievēršot uzmanību tam, ka solis, sakt un apturet ir padoti bez iekavām ().
  5. Nomaini <title> un <h1> uz savas spēles nosaukumu (piemēram, patrulējoša sarga, šķēršļa vai asteroīda kustībai).
  6. <style> blokā pie #pretinieks izvēlies savai tēmai atbilstošu background krāsu (nemainot width: 30px, height: 30px un position: absolute).
  7. Saglabā ar Ctrl+S, pārlūkā nospied Ctrl+R un pārliecinies, ka redzams jaunais virsraksts un krāsa, un viena klikšķa Sākt un Apturēt darbojas.

Gatavs, kad: esi pārbaudījis pretinieka automātisko kustību un pauzi un pielāgojis spēles virsrakstu un pretinieka krāsu.

2. uzdevums

Palielini pretinieka ātrumu uz 3 px un parādi X koordināti kustībā

Izmanto teoriju: Automātiska kustība no maziem atkārtotiem soļiem un apļa atgriešanās.

Vide: VS Code → pārlūks

  1. <script> sākumā atrodi konstanti const atrums = 2; un nomaini tās vērtību no 2 uz 3.
  2. Pirms pārbaudes izrēķini galvā pirmās četras x vērtības pēc starta no 0, kad solis() katrā reizē pieskaita 3.
  3. Funkcijā solis() zem rindas document.getElementById("pretinieks").style.left = x + "px"; (2. uzdevuma komentāra vietā) pievieno rindu, kas elementā ar id="vieta" ieraksta "Pretinieka X: " + x.
  4. Pārbaudi, ka solis() funkcijā atjauno tieši id="vieta", nevis id="stavoklis", lai abi teksta lauki netraucētu viens otram.
  5. Saglabā ar Ctrl+S, pārlūkā nospied Ctrl+R un nospied Sākt: pārliecinies, ka virsū paliek Stāvoklis: Kustas, bet pie Pretinieka X: skaitļi strauji mainās.
  6. Pavēro brīdi, kad pretinieks sasniedz laukuma labo malu (robeza = 270), un pārliecinies, ka aiz 270 gan kvadrāts, gan Pretinieka X: skaitītājs atgriežas uz 0.
  7. Nospied Apturēt kustības vidū un pārbaudi, ka redzamā Pretinieka X: vērtība dalās ar 3 un sakrīt ar kvadrāta attālumu no kreisās malas.

Gatavs, kad: pretinieks pārvietojas pa 3 px katrā solī, vienlaikus ir redzams gan #stavoklis, gan mainīgais #vieta skaitlis, un aiz 270 px kustība sākas no 0.

3. uzdevums

Novērs dubultā taimera kļūdu un izveido pogu “Atjaunot”

Izmanto teoriju: Aizsardzība pret dubultu taimeri un atšķirība starp pauzi un atjaunošanu.

Vide: pārlūks → VS Code → pārlūks (ar F12 Console)

  1. Pārlūkā piecas reizes pēc kārtas nospied pogu Sākt un tad nospied Apturēt — novēro kļūdu: pretinieks traucas daudz ātrāk un vairs neapstājas, jo darbojas vairāki paralēli taimeri!
  2. VS Code <script> blokā atver funkciju sakt() un 3. uzdevuma komentāra vietā (pirms rindas taimeris = setInterval(solis, 30);) pievieno iepriekšējā taimera apturēšanu ar clearInterval.
  3. Saglabā ar Ctrl+S, pārlūkā nospied Ctrl+R, atkal piecas reizes pēc kārtas nospied Sākt un tad vienreiz Apturēt — pārliecinies, ka ātrums vairs nepieaug un pirmais klikšķis uz Apturēt tūlīt aptur kustību!
  4. HTML daļā aiz pogas Apturēt (3. uzdevuma komentāra vietā) pievieno pogu <button class="secondary" id="atjaunot">Atjaunot</button>.
  5. <script> blokā pie 3. uzdevuma komentāra uzraksti funkciju function atjaunot() { ... }, kas izsauc apturet();, noliek x = 0;, atjauno pretinieks .style.left uz "0px" (jeb x + "px") un #vieta tekstu uz "Pretinieka X: 0", un piesaisti to pogai #atjaunot ar addEventListener("click", atjaunot).
  6. Saglabā ar Ctrl+S, pārlūkā nospied Ctrl+R un salīdzini abas darbības: palaid ar Sākt, pusceļā nospied Apturēt (paliek uz vietas), atkal Sākt (turpina no tās pašas vietas), un tad nospied Atjaunot (apstājas un atlec uz Pretinieka X: 0).
  7. Pārlūkā nospied F12, atver cilni Console, izmēģini visas trīs pogas un pārliecinies, ka konsolē nav neviena sarkana kļūdas paziņojuma.

Gatavs, kad: pieci klikšķi uz Sākt nepaātrina kustību, Apturēt nopauzē pašreizējā vietā, Atjaunot aptur taimeri un atgriež pretinieku uz X: 0, un Console cilnē nav kļūdu.

Papildu uzdevums: Pielāgo taimera intervālu un skaiti pretinieka apļus

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Apļa atgriešanās pie x > robeza un Milisekunžu intervāls iekš setInterval.

  1. Funkcijā sakt() pamēģini nomainīt setInterval(solis, 30) otro skaitli uz 60, saglabā (Ctrl+S), pārbaudi pārlūkā (Ctrl+R), kā dubultots intervāls palēnina kustību, un izvēlies savai spēlei tīkamu vērtību (piemēram, 25–60 ms).
  2. HTML daļā zem <p id="vieta"> pievieno <p id="apli">Apļi: 0</p> un <script> sākumā izveido mainīgo let apli = 0;.
  3. Funkcijā solis() nosacījuma if (x > robeza) { ... } iekšpusē (tieši tajā brīdī, kad pretinieks pabeidz skrējienu un x kļūst 0) palielini apli par 1 un atjauno #apli tekstu.
  4. Funkcijā atjaunot() pievieno arī apli = 0; un #apli teksta atjaunošanu, saglabā ar Ctrl+S un pārlūkā (Ctrl+R) pārbaudi, ka katrs pilnais pretinieka skrējiens pieskaita vienu apli!

Gatavs, kad: katra pretinieka atgriešanās no labās malas uz sākumu palielina apļu skaitītāju par 1, un poga Atjaunot to atiestata uz 0.

Ja kaut kas neizdodas
  • Nospiežot “Sākt” vai “Atjaunot”, darbība notiek nepareizi vai tikai vienu reizi? Pārliecinies, ka iekš setInterval(solis, 30) un addEventListener("click", atjaunot) funkcijas vārdam galā nav apaļo iekavu ()!
  • Pieci klikšķi uz “Sākt” joprojām paātrina pretinieku un “Apturēt” to neaptur? Pārbaudi, vai rinda ar clearInterval ievietota funkcijas sakt() sākumā pirms setInterval rindas, un pēc saglabāšanas pārlūkā obligāti nospied Ctrl+R, lai notīrītu iepriekš palaistos taimerus.
  • Kustības laikā pazūd teksts “Stāvoklis: Kustas”? Funkcijā solis() koordinātes teksts jāieraksta elementā getElementById("vieta"), nevis getElementById("stavoklis").
  • Poga “Atjaunot” noliek pretinieku sākumā, bet tas tūlīt turpina kustēties? Funkcijā atjaunot() vispirms jāaptur taimeris (piemēram, izsaucot apturet();) un pēc tam jāuzstāda x = 0; un jāatjauno gan .style.left (ar + "px"), gan #vieta teksts.
  • Konsolē (F12 → Console) rāda Cannot read properties of null (reading 'addEventListener')? Pārbaudi, vai HTML daļā jaunajai pogai ir precīzi uzrakstīts id="atjaunot" bez drukas kļūdām.
