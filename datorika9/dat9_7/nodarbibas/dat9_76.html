Ergonomika: datora vieta un ķermenis

  • Ekrāns — roku stiepiena attālumā (50–70 cm), augšmala acu augstumā vai nedaudz zemāk.
  • Gaisma — logs sānis no ekrāna, ne aiz tā un ne aiz muguras; ekrāns nav daudz gaišāks par telpu.
  • Poza — kājas uz grīdas, mugura pret krēsla atzveltni, elkoņi aptuveni taisnā leņķī, plaukstu locītavas taisnas.
  • Noteikums 20-20-20 — ik pēc 20 minūtēm 20 sekundes skaties uz kaut ko vismaz 20 pēdu (ap 6 m) attālumā. Acis atpūšas.
  • Kustība — vismaz reizi stundā piecelies un izstaipies.

Telefonam tas pats: neturi to tuvu sejai un nespēlē guļus tumsā.

Pārmērīga lietošana un kā sev palīdzēt

Spēles, telefons un sociālie tīkli ir veidoti tā, lai gribētos „vēl vienu reizi”. Pazīmes, ka lietošana kļūst pārmērīga:

  • nevari apstāties, kad biji plānojis, un laiks „pazūd”;
  • atliec mācības, miegu, ēšanu vai tikšanos ar draugiem;
  • esi aizkaitināts vai nemierīgs, ja nevari spēlēt;
  • naktīs spēlē vai pārbaudi telefonu, un no rīta esi noguris.

Kā iestatīt robežas: telefonā — Screen Time (iPhone) vai Digital Wellbeing (Android) ar dienas limitu lietotnēm; Windows datorā — Microsoft Family Safety kopā ar vecākiem. Noder arī vienkārši noteikumi: telefons ārpus guļamistabas naktī, spēles tikai pēc mājasdarbiem.

Kur meklēt palīdzību: vecāki, klases audzinātājs, skolas psihologs vai sociālais pedagogs. Bērnu un pusaudžu uzticības tālrunis 116111 ir bez maksas, anonīms un pieejams visu diennakti; tiešsaistes tērzēšana — uzticibastalrunis.lv. Par kaitīgu saturu internetā var ziņot drossinternets.lv.

Pārtraukuma atgādinājums spēlē

Atgādinājumam vajag otru taimeri, kas reizi sekundē skaita spēles laiku. Tas skaita tikai tad, kad spele.aktiva ir true — laiks sākuma un beigu ekrānā neskaitās. Kad laiks sasniegts, spēli aptur tāpat kā 4.4. un 5. tēmā: spele.aktiva = false un clearInterval(taimeris).

let spelesSekundes = 0;
function skaititLaiku() {
  if (!spele.aktiva) { return; }
  spelesSekundes = spelesSekundes + 1;
  if (spelesSekundes >= partraukumsPecMinutem * 60) {
    spele.aktiva = false;            // pogas un bultiņas vairs nekustina
    clearInterval(taimeris);         // pretinieks apstājas
    ... parāda atgādinājumu ...
  }
}

Svarīgi: laika taimeri sāk vienu reizi, kad lapa ielādējas, nevis funkcijā sakt(). Ja to sāktu katrā spēles sākumā, pēc trim spēlēm būtu trīs taimeri, un laiks skaitītos trīs reizes ātrāk.

Pārbaudei iestati partraukumsPecMinutem = 1, lai nav jāgaida pusstunda; pirms publicēšanas — 30.

Pašpārbaude: atgādinājums parādās pēc 20 sekundēm, lai gan iestatīta 1 minūte. Kas, visticamāk, noticis?

Laika taimeris sākts vairākas reizes — piemēram, funkcijā sakt(), un spēle sākta trīs reizes. Trīs taimeri katrā sekundē pieskaita 3. Taimeri jāsāk tikai vienreiz, ārpus sakt(), ar pārbaudi if (laikaTaimeris === null).

Izveido lapu drosiba.html savai spēlei

Izmanto teoriju: Noslēguma darba uzbūve, Ergonomika un Pārmērīga lietošana.

Vide: File Explorer → VS Code → pārlūks

  1. VS Code atver mapi Desktop/datorika9-tema5 un saglabā sākuma kodu kā drosiba.html. Iekopē šajā mapē arī tikls_71.png no datorika9-tema7.

  3. Sadaļā „Kā spēle nonāk pie tevis” uzraksti 2–3 teikumus spēlētājam: kur glabājas spēle, kas notiek, kad viņš atver saiti, un kāpēc bez interneta spēle neatveras.

3. uzdevums

Salauz un pārbaudi atgādinājumu, tad publicē

Izmanto teoriju: Pārtraukuma atgādinājums spēlē.

Vide: VS Code → pārlūks (F12) → GitHub Pages

  1. Salauz: uz brīdi pārvieto rindu laikaTaimeris = setInterval(skaititLaiku, 1000); funkcijas sakt() iekšpusē (bez if). Saglabā, sāc spēli, nospied Beigt spēli un Spēlēt vēlreiz trīs reizes. Ar pulksteni pārbaudi, pēc cik sekundēm parādās atgādinājums.
  2. Atgriez rindu sākotnējā vietā ar if (laikaTaimeris === null) un pārbaudi, ka atgādinājums atkal nāk pēc minūtes, arī pēc vairākām spēlēm. README sadaļā par pārbaudi ieraksti, ko novēroji un kāpēc.
  3. Pārbaudi robežgadījumus: atgādinājuma laikā nospied Beigt spēli un tad Spēlēt vēlreiz — jaunajā spēlē atgādinājuma nav. F12 → Console nav sarkanu kļūdu.
  4. Abos failos iestati partraukumsPecMinutem = 30. Pārbaudi, ka lapās nav personas datu: e-pasta, tālruņa, adreses, publiskās IP adreses.
  5. Saglabā visu, nosūti projektu datorika9-tema5 uz GitHub (Sync Changes) un pēc pāris minūtēm atver publicēto spēli. Pārbaudi saiti uz drosiba.html, shēmu un saiti atpakaļ.

Gatavs, kad: publicētajā spēlē ir saite uz drošības lapu, atgādinājums nesākas divreiz, un abos failos ir 30 minūtes.

Iesniedz tēmas noslēguma darbu

Iesniedz divas saites skolotāja norādītajā vietā: publicēto spēli (https://lietotajs.github.io/datorika9-tema5/) un drošības lapu (…/drosiba.html). Iesniedz arī tēmas projekta datorika9-tema7 saiti ar 7.1.–7.5. darbiem.

Noslēguma darbs ir pabeigts, ja:

  • Publicētās spēles sākuma ekrānā ir saite uz drosiba.html, un no tās — atpakaļ uz spēli.
  • Drošības lapā ir četras aizpildītas sadaļas ar tīkla shēmu.
  • Atgādinājums publicētajā spēlē aptur spēli, Turpināt spēli to atsāk, un laika taimeris tiek sākts tikai vienreiz.
  • Abās lapās iestatītas 30 minūtes, un nav personas datu.

Vērtējumu nosaka tālāk dotie kritēriji. Papildu uzdevums nav vajadzīgs nevienam snieguma līmenim.

Vērtēšanas kritēriji (SLA)

Snieguma līmeņu apraksts (SLA) attiecas uz publicēto spēli ar lapu drosiba.html un tēmas projektu datorika9-tema7: tajā vērtē gan 7.6. nodarbības noslēguma darbu, gan iepriekšējo tēmas nodarbību (7.1.–7.5.) uzdevumu izpildi.

Iepriekšējo tēmas uzdevumu izpilde (7.1.–7.5.)
7.1. · 7.2. · 7.3. · 7.4. · 7.5.		 Projektā datorika9-tema7 ir 1–2 darbi vai tikai nemainīti sākuma kodi. Ir vismaz 3 no 5 darbiem, bet daļā nav izpildīti visi 3. uzdevuma ieskaites punkti. Tīkla shēma un skaidrojums (SR 2.3.2.)
1. uzdevums · 7.1. teorija		 Shēmas nav vai tā nav saistīta ar spēles ceļu. Shēma ir, bet trūkst ierīču vai to funkciju, vai teksts nepaskaidro klientu un serveri. Shēmā ir ceļš no spēlētāja līdz GitHub Pages serverim ar nosauktām ierīcēm un DNS, un 2–3 teikumi to pareizi paskaidro spēlētājam. Izpildīts “Apguvis”; skaidrojums ir vienkāršs un precīzs, un tajā izmantoti paša mērījumi (ping, tracert).
Veselīga spēlēšana (SR 3.3.1.)
1. uzdevums · teorija		 Sadaļa tukša vai ar vispārīgiem vārdiem („nespēlē par daudz”). Ir daži padomi, bet trūkst pārmērīgas lietošanas pazīmju, ierobežojumu iestatīšanas vai palīdzības. Vismaz četri konkrēti ergonomikas padomi, trīs pārmērīgas lietošanas pazīmes, kā iestatīt laika ierobežojumu un kur meklēt palīdzību. Izpildīts “Apguvis”; padomi pielāgoti tieši tavas spēles spēlētājiem un ierīcēm (dators, telefons) un pamatoti.
Drošība un privātums (SR 3.3.3., 3.3.5.)
1. uzdevums · 7.4. · 7.5.		 Sadaļa tukša, vai lapās ir personas dati. Nosaukti 1–2 draudi vai bez skaidra „ko darīt”; nav pateikts, kādus datus spēle vāc. Pateikts, kādus datus spēle vāc, un vismaz trīs reāli draudi ar konkrētu rīcību; lapās nav personas datu. Izpildīts “Apguvis”; draudi izvēlēti tieši tavas spēles situācijai (saite, kopijas, konti), un rīcība ir praktiska.
Pārtraukuma atgādinājums spēlē
2. uzdevums · 3. uzdevums · teorija		 Atgādinājuma nav, vai tas salauž spēli. Atgādinājums parādās, bet spēle neapstājas, Turpināt nedarbojas vai taimeris sākas atkārtoti. Publicētajā spēlē pēc iestatītā laika spēle apstājas, atgādinājums parādās, Turpināt to atsāk, taimeris sākas vienreiz, iestatītas 30 minūtes. Izpildīts “Apguvis”; pārbaudīti robežgadījumi (beigas atgādinājuma laikā, vairākas spēles pēc kārtas), un README pierakstīts „salauz un pārbaudi” rezultāts.
Publicēšana un saites
3. uzdevums		 Drošības lapa nav publicēta. Lapa publicēta, bet nav saites no spēles, nestrādā saite atpakaļ vai nerādās shēma. Publicētajā spēlē sākuma ekrānā ir saite uz drosiba.html, tās saite atpakaļ un shēma darbojas tiešsaistē. Izpildīts “Apguvis”; abas lapas pārbaudītas arī telefonā, un README apraksta jauno lapu.
Papildu uzdevums: spēlētājs pats izvēlas atgādinājuma laiku

Sāc, kad visi trīs pamatuzdevumi ir pabeigti. Papildu uzdevums nav nepieciešams nevienam SLA līmenim.

Izmanto teoriju: Pārtraukuma atgādinājums spēlē.

  1. Sākuma ekrānā pievieno sarakstu <select id="minutes"> ar vērtībām 15, 30 un 45.
  2. const partraukumsPecMinutem nomaini uz let, un funkcijā sakt() nolasi izvēli: partraukumsPecMinutem = Number(document.getElementById("minutes").value);.
  3. Pārbaudi ar pagaidu vērtību 1 sarakstā, tad to izņem un publicē.

Gatavs, kad: spēlētājs pirms spēles izvēlas laiku, un atgādinājums parādās pēc izvēlētā laika.
