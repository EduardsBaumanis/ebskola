2.4 Audio materiālu apstrāde un integrācija

Tavs šīs stundas izaicinājums: Izvēlēties spēles noskaņai atbilstošus skaņas efektus, veikt to pēcapstrādi un sagatavot tos integrācijai tīmekļa projektā.

2.4.6. Veic iegūto materiālu pēcapstrādi; 2.4.10. Saglabā dokumentu mākoņkrātuvē atbilstošā formātā.
SR 2.4.9. Satura sinhronizācija starp dokumentiem

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — atskaņo pirmo skaņu ar pogas klikšķi · 2. uzdevums (~25 min) — pievieno spēles pogai klikšķa skaņu no script.js · 3. uzdevums (~20 min) — nogriez klusumu skaņas sākumā un pārbaudi kavēšanos. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu projektu VS Code un lejupielādē no freesound.org vai pixabay.com vienu īsu klikšķa skaņu MP3 formātā.

Teorija: Audio formāti un lietojamība

Tīmekļa spēlēs mēs parasti izmantojam divu veidu skaņas:

  • SFX (Sound Effects): Īsas skaņas (līdz 2 sek.) darbībām — lēciens, sadursme, pogas klikšķis.
  • BGM (Background Music): Garākas, cikliskas (looping) melodijas fona noskaņai.
Formāti: Visizplatītākais ir MP3 (labs kompromiss starp kvalitāti un izmēru), bet modernākais un efektīvākais ir Ogg Vorbis vai AAC. Svarīgi: Skaņa nedrīkst sākt skanēt automātiski, pirms lietotājs ir mijiedarbojies ar lapu (pārlūku drošības noteikums). 

<!-- Audio integrācija: skaņa sākas tikai pēc klikšķa -->
<audio id="sound-jump" src="skanas/jump.mp3" preload="auto"></audio>
<button id="poga-lekt">Lēkt</button>
<script>
  document.getElementById("poga-lekt").addEventListener("click", function () {
    document.getElementById("sound-jump").play();
  });
</script>

Praktiskie uzdevumi

1. uzdevums — Atskaņo pirmo skaņu ar pogas klikšķi

Beigās tavā lapā būs poga, kas pēc nospiešanas atskaņo klikšķa skaņu.

<audio id="sana" src="skanas/klikskis.mp3" preload="auto"></audio>
<button id="poga-tests">Skaņas tests</button>
  1. Izveido projekta mapē apakšmapi skanas.
  2. Saglabā tajā lejupielādēto skaņu ar nosaukumu klikskis.mp3.
  3. Nokopē augšējās divas rindas index.html faila <body> daļā.
  4. Atver script.js un pievieno: document.getElementById("poga-tests").addEventListener("click", () => document.getElementById("sana").play());
  5. Saglabā abus failus, pārlādē lapu un nospied pogu.

Gatavs, kad: pēc pogas nospiešanas skaļrunī atskan klikšķis un DevTools konsolē nav sarkanas kļūdas.

2. uzdevums — Pievieno klikšķa skaņu savas spēles pogai

Beigās tavas spēles īstā poga skanēs katru reizi, arī nospiežot to ātri pēc kārtas.

  1. Atver script.js un ieraksti faila sākumā const klikskis = new Audio("skanas/klikskis.mp3");
  2. Pievieno nākamajā rindā klikskis.volume = 0.5;, lai skaņa nebūtu pārāk skaļa.
  3. Atrodi funkciju, kas izpildās, nospiežot tavas spēles sākuma pogu.
  4. Ieraksti tās sākumā divas rindas: klikskis.currentTime = 0; un klikskis.play();
  5. Saglabā un nospied spēles pogu piecas reizes ātri pēc kārtas.
  6. Pārbaudi DevTools cilnē "Console", vai neparādās kļūda NotAllowedError.
  7. Veic git commit -m "Add click sound effect".

Gatavs, kad: skaņa atskan katrā no piecām ātrajām nospiešanām, nevis tikai pirmajā.

3. uzdevums — Nogriez klusumu un izmēri kavēšanos

Beigās tava skaņa sāksies uzreiz pēc klikšķa, bez pusotras sekundes pauzes.

  1. Atver pārlūkā rīku twistedwave.com/online vai programmu Audacity un ielādē klikskis.mp3.
  2. Atlasi viļņa formas klusumu faila pašā sākumā un izdzēs to ar Delete taustiņu.
  3. Eksportē failu atpakaļ kā MP3 ar bitreitu 128 kbps un pārraksti skanas/klikskis.mp3.
  4. Nolasi jaunā faila izmēru — tam jābūt mazākam par 100 KB.
  5. Pārlādē lapu ar Ctrl+F5, lai pārlūks paņemtu jauno failu, un nospied pogu.
  6. Salīdzini, cik ātri skaņa sākas tagad, salīdzinot ar iepriekšējo versiju.
  7. Pieraksti vienu secinājumu: kāpēc klusums faila sākumā spēlē jūtas kā "lags".

Gatavs, kad: skaņa atskan tajā pašā mirklī, kad nospied pogu, un fails ir mazāks par 100 KB.

Papildu uzdevums — Pievieno uzvaras skaņu

Beigās tava spēle atskaņos citu, garāku skaņu brīdī, kad spēlētājs uzvar.

  1. Saglabā mapē skanas otru failu uzvara.mp3.
  2. Pievieno script.js rindu const uzvara = new Audio("skanas/uzvara.mp3");
  3. Ieraksti uzvaras pārbaudes vietā rindu uzvara.play();
  4. Izspēlē spēli līdz uzvarai un pārbaudi, vai skan pareizā skaņa.
  5. Veic git commit -m "Add win sound effect".

Gatavs, kad: uzvarot skan uzvaras skaņa, bet parasts klikšķis joprojām skan klikšķa skaņu.

Biežākās kļūdas (un kā tās labot):

  • Kavēšanās (Latency): Ja skaņas faila sākumā ir 0.5s klusums, spēlētājs jutīs "lagu". Vienmēr nogriez klusumu!
  • Pārāk lieli faili: Fona mūzika var būt liela. Mēģini to saspiest (bitrate 128kbps ir pietiekams).
  • Autortiesības: Vienmēr pārliecinies, ka skaņai ir "Creative Commons" vai "Royalty Free" licence.

Koda piemērs (skaņa ātros klikšķos un pārlūka autoplay aizliegums)

// NEPAREIZI: otrajā ātrajā klikšķī skaņa neatskan,
// jo tā vēl skan un netiek attīta uz sākumu
const klikskis = new Audio("skanas/klikskis.mp3");
poga.addEventListener("click", () => klikskis.play());

// NEPAREIZI: lapas ielādes brīdī pārlūks atskaņošanu bloķē
// un konsolē parādās NotAllowedError
fonaMuzika.play();

// PAREIZI: attin uz sākumu un pieķer atteikumu
const skana = new Audio("skanas/klikskis.mp3");
skana.volume = 0.5;

poga.addEventListener("click", () => {
  skana.currentTime = 0;            // atsāk no nulles
  skana.play().catch(() => {
    console.log("Pārlūks gaida pirmo lietotāja klikšķi");
  });
});

// Fona mūziku ieslēdz tikai pēc pirmā klikšķa lapā
const fons = new Audio("skanas/fons.mp3");
fons.loop = true;
fons.volume = 0.2;
document.addEventListener("click", () => fons.play(), { once: true });

Kad kods strādā, klikšķa skaņa atskan katrā no piecām ātrajām nospiešanām, fona mūzika sākas tikai pēc pirmā klikšķa lapā un DevTools konsolē nav sarkanā NotAllowedError ziņojuma.
