1. tēma — Tīmekļa struktūra un dizaina domāšana

Izveido savas spēles apraksta lapu un iemācies saglabāt darbu GitHub.

Tēmā ir 6 nodarbības. Noslēguma projektu veido 5. un 6. nodarbībā.

Nodarbības

  1. 1.1 Sagatavo VS Code un GitHub

    Izveido un atver savu pirmo HTML failu. Sagatavo GitHub kontu.

  2. 1.2 HTML lapas uzbūve un pirmā saglabātā versija

    Izveido spēles noteikumu lapu un saglabā darba versiju ar Source Control.

  3. 1.3 Salīdzini spēles lapas un nosūti darbu uz GitHub

    Izvēlies saprotamu spēles pogu un nosūti savu lapu uz GitHub.

  4. 1.4 Izvēlies spēles ideju un spēlētāju

    Izveido lapu, kurā spēlētājs saprot mērķi, vadību un spēles beigas.

  5. 1.5 Izveido spēles ekrānus — projekta 1. daļa

    Sāc tēmas noslēguma darbu: izveido saprotamu spēles lapu ar diviem ekrāniem.

  6. 1.6 Pabeidz spēles pieteikumu — projekta 2. daļa

    Pabeidz savas spēles apraksta lapu un iesniedz GitHub projekta saiti.
