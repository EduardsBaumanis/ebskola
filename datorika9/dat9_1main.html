# 02 špikeris

1. tēmas špikeris - HTML struktūra un dizaina domāšana

HTML skelets, semantiskie tagi, GitHub un projekta plānošana. Katrs bloks atbilst vienai stundai.

1.1 GitHub darba cikls

# 1. Ko git redz šobrīd
git status

# 2. Sagatavo failu un saglabā ar ziņu
git add index.html
git commit -m "Add control hint"

# 3. Nosūti uz GitHub
git push

# commit = saglabā LOKĀLI    push = nosūta uz GitHub
# Ja fails GitHub neparādās - visbiežāk aizmirsts push.

# GitHub Pages: Settings -> Pages -> Branch: main -> Save
# Pēc dažām minūtēm spēle būs pieejama pa publisku saiti.

Commit ziņu raksti tā, lai pēc mēneša saprastu, ko mainīji. update neko nepasaka.

1.2 HTML skelets un semantiskie tagi

<!DOCTYPE html>
<html lang="lv">
<head>
    <meta charset="UTF-8">   <!-- bez šī garumzīmes izskatīsies kā Ä« -->
    <title>Zvaigžņu mednieks</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>Zvaigžņu mednieks</h1>   <!-- lapā tikai VIENS h1 -->
    </header>

    <main>
        <section>
            <h2>Ideja</h2>
            <p>Apraksts...</p>
        </section>
    </main>

    <footer><p>Autors: Vārds</p></footer>
    <script src="script.js"></script>  <!-- pirms </body> -->
</body>
</html>

Semantiskie tagi (header, main, section, footer) pasaka, ko nozīmē saturs - div nepasaka neko.

1.3 Tabula tirgus analīzei

<table border="1">
    <thead>
        <tr>
            <th>Kritērijs</th>
            <th>1. spēle</th>
            <th>2. spēle</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Vadība</td>
            <td>Bultiņas</td>
            <td>Pele</td>
        </tr>
    </tbody>
</table>

<!-- table  tabula        thead  galvenes rinda
     tbody  saturs        tr     rinda
     th     galvenes šūna td     parasta šūna -->

Katrai <tr> rindai jābūt vienādam šūnu skaitam, citādi tabula izjūk.

1.4-1.5 Koncepcija un prototips

<section>
    <h2>Spēles koncepcija</h2>
    <p>Spēlētājs vada raķeti un savāc zvaigznes, lai iegūtu punktus,
       un zaudē, kad trīs reizes ietriecas asteroīdā.</p>

    <h3>Mērķauditorija</h3>
    <p>12-15 gadus veci spēlētāji, kas spēlē pārlūkā starpbrīžos.</p>
</section>

<!-- UX prototips: katrs ekrāns = viena kaste -->
<main>
    <div id="menu">
        <button id="start">Sākt</button>
        <p>Kā spēlēt: vadi ar bultiņām, savāc zvaigznes.</p>
    </div>

    <div id="spele"></div>
    <div id="beigas"></div>
</main>

<!-- UI = kā izskatās   UX = cik viegli saprast un lietot -->

Koncepcijas teikumā jābūt trim lietām: ko dara spēlētājs, kāpēc, un kad zaudē.

1.6 Projekta pieteikuma kontrolsaraksts

Pirms iesniegšanas pārbaudi:

[ ] Ir  un 
[ ] Ir   (garumzīmes rādās pareizi)
[ ] Lapā ir tikai VIENS 

[ ] Lietoti semantiskie tagi: header / main / section / footer
[ ] Katrs atvērtais tags ir aizvērts
[ ] Ir apraksts: ideja, mērķauditorija, vadība
[ ] Ir tabula ar vismaz divu spēļu salīdzinājumu
[ ] Fails ir GitHub (git push izpildīts)
[ ] Lapa atveras pārlūkā bez tukšām vietām

Pārbaudi ar pārlūka izstrādātāja rīkiem: F12 -> Console
Ja tur ir sarkans teksts, kaut kas nestrādā.

Atver savu lapu telefonā - tur uzreiz redzēsi, vai teksts nav par mazu un vai attēli neizlec no ekrāna.

$ git init && git add . && git commit -m "Pirmais commits" # No tukšas mapes uz GitHub repozitoriju
