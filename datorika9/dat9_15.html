1.5 Izveido spēles ekrānus — projekta 1. daļa

Šodien: Sāc tēmas noslēguma darbu: izveido saprotamu spēles lapu ar diviem ekrāniem.

Tēmas projekts · 1. daļa no 2

Projekta gala prasības un vērtēšanas tabula ir kopīgas abām projekta nodarbībām.

Īsā teorija

Divu ekrānu skice HTML lapā

Ekrāna skice parāda, kur atradīsies spēlētājam vajadzīgā informācija. Šajā projektā tā ir HTML lapa: sākuma ekrānā ir spēles mērķis, paredzētais spēlētājs, trīs noteikumi un sākšanas poga; spēles ekrānā — punktu rinda, varoņa vai spēles objektu apraksts, vadības norāde un atgriešanās poga.

Spēles nosaukums <h1> un mērķa rindkopa sākuma kodā atrodas pirms abām sadaļām, tāpēc paliek redzami abos ekrānos. Pārlūka cilnes nosaukumu nosaka <title>. Teksta un sarakstu veidošanai izmanto 1.2. nodarbības HTML piemēru, saturam — 1.4. nodarbības noteikumu paraugu.

Kā darbojas gatavās pogas?

<section> grupē viena ekrāna saturu. id="sakums" un id="laukums" ir sadaļu unikālie nosaukumi. hidden sākumā paslēpj spēles laukumu. Sākšanas poga izsauc gatavo paraditSpeli(), bet atgriešanās poga — paraditSakumu().

<section id="sakums">
  <h2>Sākuma ekrāns</h2>
  <button onclick="paraditSpeli()">Sākt spēli</button>
</section>
<section id="laukums" hidden>
  <h2>Spēles ekrāns</h2>
  <button onclick="paraditSakumu()">Atpakaļ uz sākumu</button>
</section>

Darbojies ar pilno sākuma kodu: tajā ir arī pogām vajadzīgās funkcijas sadaļā <script>. Mainot tekstus, saglabā sadaļu id, hidden, pogu onclick un gatavās funkcijas.

Ko pārbaudīt pārlūkā?

Pēc lapas atvēršanas redzama sākuma sadaļa. Pēc Sākt spēli redzams laukums un sākuma sadaļa paslēpta. Pēc Atpakaļ atkal redzama sākuma sadaļa un laukums paslēpts. Katrā brīdī redzama viena no šīm divām sadaļām; kopīgais nosaukums un mērķis paliek redzami.

Šīs tēmas rezultāts ir spēles pieteikums ar ekrānu pārslēgšanu. Rinda Punkti: 0 pagaidām ir nemainīgs teksts; punktu skaitīšanu un spēlēšanu pievienosi vēlāk.

Sākuma kods un darba vieta

Vide: mācību lapa → VS Code

  1. VS Code ar File → Open Folder atver Desktop/datorika9-tema1 . Ja mapes nav, izveido to darbvirsmā.
  2. Šajā mācību lapā nospied Kopēt sākuma kodu .
  3. VS Code nospied Ctrl+N un ielīmē kodu ar Ctrl+V .
  4. Saglabā ar Ctrl+Shift+S tēmas mapē kā 15.html .

1. uzdevums

Izveido sākuma ekrānu

Vide: VS Code

Izmanto teoriju: Abu ekrānu saturs; mērķis un noteikumi.

  1. Izveido 15.html pēc sākuma koda soļiem. Izmanto 1.4. nodarbībā izvēlēto ideju; ja iepriekšējā faila nav, izveido ideju pēc tajā dotā teorijas parauga. Iepazīsties ar noslēguma projekta vērtēšanas kritērijiem.
  2. Ieraksti savas spēles nosaukumu <h1> un <title>. Rindkopā zem <h1> ieraksti spēles mērķi.
  3. Sadaļā <section id="sakums"> pēc <h2> pievieno <p> rindkopu par paredzēto spēlētāju un viņa vajadzību, izmantojot 1.4. nodarbības aprakstu.
  4. Tajā pašā sadaļā pirms sākšanas pogas pievieno <ul> ar tieši trim <li>: darbība un punktu iegūšana, uzvara, zaudējums. Vari pārnest sava 14.html sarakstu. Saglabā esošo pogu.

Gatavs, kad: sākuma skatā ir spēles nosaukums, mērķis, paredzētais spēlētājs, trīs noteikumi un sākšanas poga.

2. uzdevums

Izveido spēles ekrānu

Vide: VS Code

Izmanto teoriju: Spēles ekrāna saturs; gatavās pogas un sadaļu id.

  1. Atrodi <section id="laukums" hidden>. Visas šī uzdevuma rindkopas ievieto šīs sadaļas iekšpusē pirms atgriešanās pogas.
  2. Rindkopā Šeit vēlāk būs spēlētājs. ieraksti sava varoņa vai spēles objektu aprakstu, piemēram, “Spēles laukumā būs zvaigznes un akmeņi.”
  3. Saglabā rindu <p>Punkti: 0</p>. Zem tās pievieno jaunu <p> ar konkrētu vadības norādi, kas sakrīt ar pirmo noteikumu, piemēram, “Vadība: ar peli spied uz zvaigznes.”
  4. Pārbaudi abu pogu tekstu: tam jānosauc sākšana un atgriešanās. Vari precizēt tekstu uz Atpakaļ uz sākumu, saglabājot onclick. Saglabā failu, nemainot gatavo pārslēgšanas kodu.

Gatavs, kad: spēles sadaļā ir punktu rinda, varoņa vai objektu apraksts, vadības norāde un atgriešanās poga.

3. uzdevums

Pārbaudi ekrānu pārslēgšanu

Vide: Pārlūks → VS Code → GitHub

Izmanto teoriju: Trīs ekrānu pārbaudes soļi; saprotams pogas teksts.

  1. Saglabā 15.html un atver to pārlūkā. Pārbaudi sākuma skatu: noteikumi un sākšanas poga redzami, bet spēles laukums un atgriešanās poga paslēpti.
  2. Nospied sākšanas pogu. Jāparādās laukuma saturam, punktiem, vadības norādei un atgriešanās pogai; sākuma sadaļai jāpaslēpjas. Nospied atgriešanās pogu un pārliecinies, ka atkal redzama tikai sākuma sadaļa.
  3. Palūdz klasesbiedram no sākuma skata sākt un atgriezties bez tavas palīdzības, kā arī atrast vadības norādi. Ja teksts ir neskaidrs, precizē to; ja pārslēgšana nedarbojas, salīdzini id, onclick un funkcijas ar sākuma kodu.
  4. Pēc labojumiem saglabā un atkārto visus trīs pārbaudes soļus. Nosūti 15.html uz GitHub pēc zemāk dotās atgādnes un faila kodā pārbaudi pēdējo labojumu.
  5. Iesniedz pārbaudīto 15.html. Paturi šo failu tēmas mapē: nākamajā nodarbībā no tā izveidosi index.html.

Gatavs, kad: sākuma un spēles sadaļa pārslēdzas abos virzienos, klasesbiedrs saprot pogas un vadību, un pārbaudītais fails ir iesniegts.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 15.html skolotāja norādītajā vietā. Šo pašu versiju saglabā arī GitHub.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • Sākuma skatā ir savas spēles nosaukums, mērķis, paredzētais spēlētājs un trīs noteikumi.
  • Laukumā ir Punkti: 0, varoņa vai objektu apraksts un ar noteikumiem saskaņota vadības norāde.
  • Sākotnēji redzama sākuma sadaļa; abas pogas pārslēdz sadaļas, katrā brīdī rādot vienu no tām. Pārbaudītais 15.html iesniegts un saglabāts GitHub.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Saglabā un nosūti uz GitHub — pogu atgādne

Vide: VS Code / Source Control → GitHub pārlūkā

  1. Ar File → Save All saglabā failus. Atver Source Control ar Ctrl+Shift+G .
  2. Pie Changes nospied + (Stage All Changes). Pārbaudi, ka vajadzīgie faili pārvietojas uz Staged Changes .
  3. Ziņas laukā ieraksti īsu izmaiņu, piemēram, Pabeigts 1.5 darbs . Spied Commit .
  4. Ja šī tēmas mape vēl nav GitHub, spied Publish to GitHub un izveido publisku projektu datorika9-tema1 . Jau publicētam projektam spied Sync Changes . Ja pogas nav, atver … → Push .
  5. Pārlūkā atver savu GitHub projektu un pārbaudi faila pēdējās izmaiņas.

Ja Source Control rāda Initialize Repository , vispirms nospied to. Ja parādās kļūda vai sapludināšanas pieprasījums, izmanto palīdzību un palūdz skolotāja atbalstu.

Papildu uzdevums: Sakārto spēles informāciju

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Papildu uzdevums nav obligāts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

Izmanto teoriju: Spēles ekrāna saturs; virsrakstu līmeņi.

  1. Sadaļā id="laukums" tieši pirms vadības rindkopas pievieno <h3>Vadība</h3>.
  2. Saglabā, atver lapu un nospied sākšanas pogu. Pārbaudi, ka virsraksts un vadības rindkopa ir kopā spēles ekrānā.

Gatavs, kad: spēles ekrānā vadības teksts atrodas zem atsevišķa apakšvirsraksta.

Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 15.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Poga nestrādā? Pārbaudi, vai neizdzēsi pēdiņu, iekavu vai elementa id. Salīdzini savu laboto vietu ar sākuma kodu.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
