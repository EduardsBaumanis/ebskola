1.2 HTML lapas uzbūve un pirmā saglabātā versija

Šodien: Izveido spēles noteikumu lapu un saglabā darba versiju ar Source Control.

Īsā teorija

Virsraksts, mērķis un noteikumu saraksts

<title> nosaka pārlūka cilnes nosaukumu, <h1> — galveno virsrakstu lapā, bet <p> — rindkopu. Šajā darbā rindkopā virs saraksta raksti spēles mērķi.

<ul> veido sarakstu ar punktiem. Katru noteikumu ievieto atsevišķā <li>...</li> pārī saraksta iekšpusē. Trīs noteikumi atbild: kā vadīt, kā iegūt punktu un kad spēle beidzas.

<h1>Zvaigžņu mednieks</h1>
<p>Savāc 5 zvaigznes.</p>
<ul>
  <li>Ar peli spied uz zvaigznes.</li>
  <li>Katra savāktā zvaigzne dod 1 punktu.</li>
  <li>Spēle beidzas ar uzvaru, kad sasniedz 5 punktus.</li>
</ul>

Faila saglabāšana un Git versija

Ctrl+S saglabā failu datorā. VS Code sadaļā Source Control vari saglabāt arī darba versiju: Initialize Repository vienreiz ieslēdz Git darba mapei, Stage Changes (+) sagatavo izvēlētās izmaiņas, bet Commit saglabā tās kopā ar īsu aprakstu.

Pirms Stage Changes atver failu sarakstā Changes un apskati labojumus. Pēc veiksmīga Commit šīm izmaiņām vairs nav jābūt sarakstā Staged Changes. Ja ir kļūdas paziņojums, versija vēl nav saglabāta. Commit glabājas datorā; nosūtīšanu uz GitHub apgūsi nākamajā nodarbībā.

Galvenie HTML tagi

Izmanto šo pārskatu kā atgādni. Šodienas darbam īpaši vajadzīgi virsraksti, rindkopas un saraksti.

Vairumam elementu ir sākuma un beigu tags: <p>Teksts</p> . Tagiem meta , link , img , input , br un hr beigu taga nav. <!DOCTYPE html> ir dokumenta tipa norāde.

1. uzdevums

Pielāgo nosaukumu

Vide: VS Code → pārlūks

Izmanto teoriju: Virsraksts un cilnes nosaukums; HTML tagu atgādne.

  1. Pēc sākuma koda soļiem izveido 12.html mapē Desktop/datorika9-tema1 un atver šo failu VS Code.
  2. Starp <h1> un </h1> ieraksti savas spēles nosaukumu. Saglabā virsraksta tagus un apkārtējo <header> sadaļu.
  3. Starp <title> un </title> ieraksti tieši to pašu nosaukumu. Saglabā failu un atver to pārlūkā, kā darīji 1.1. nodarbībā.

Gatavs, kad: pārlūka cilnē un lapas galvenajā virsrakstā ir viens un tas pats tevis izvēlētais nosaukums.

2. uzdevums

Pievieno noteikumu sarakstu

Vide: VS Code → pārlūks

Izmanto teoriju: Mērķa rindkopa un trīs saraksta punkti.

  1. Sadaļā <main> atrodi rindkopu <p>Savāc zvaigznes.</p> virs saraksta. Aizstāj tās tekstu ar savas spēles mērķi vienā teikumā.
  2. Esošajā <li> punktā norādi vadību: ko spēlētājs spiež vai kuru taustiņu lieto. Izmanto teorijas piemēra uzbūvi.
  3. Pirms </ul> pievieno divus jaunus <li>...</li> punktus: otrajā pasaki, par kādu darbību iegūst punktu, trešajā — pie kāda punktu skaita spēle beidzas. Sarakstā kopā jābūt trim punktiem.
  4. Saglabā ar Ctrl+S un pārlūkā nospied Ctrl+R. Pārbaudi, ka mērķis ir atsevišķā rindkopā, bet katrs noteikums — savā saraksta punktā; mērķī un noteikumos minētie skaitļi saskan.

Gatavs, kad: lapā ir mērķis un trīs atsevišķi noteikumi par vadību, punktu iegūšanu un spēles beigām.

3. uzdevums

Pārbaudi un saglabā versiju

Vide: Pārlūks → VS Code / Source Control

Izmanto teoriju: Faila saglabāšana un Git versija.

  1. Saglabā 12.html un pārlūkā pārbaudi nosaukumu cilnē, galveno virsrakstu, mērķi un trīs noteikumus. Izlabo atrastās nepilnības.
  2. VS Code atver tēmas mapi un Source Control ar Ctrl+Shift+G. Spied Initialize Repository, ja poga redzama. Ja šī mape jau ir Git projekts, turpini ar nākamo soli.
  3. Sarakstā Changes atver 12.html un pārskati nosaukumu un noteikumus. Pie šī faila spied + (Stage Changes); pārliecinies, ka tas redzams Staged Changes.
  4. Ziņas laukā ieraksti Pievienoti spēles noteikumi un spied Commit. Ja prasa user.name vai user.email, palūdz skolotāja palīdzību un pēc iestatīšanas atkārto Commit.
  5. Pārbaudi, ka nav kļūdas paziņojuma un saglabātās 12.html izmaiņas vairs nav Staged Changes. Parādi skolotājam Commit rezultātu un iesniedz 12.html.

Gatavs, kad: noteikumu lapa atbilst pārbaudes punktiem, un tās izmaiņas saglabātas ar aprakstošu Commit ziņu.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 12.html skolotāja norādītajā vietā.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • Cilnē un <h1> redzams viens un tas pats paša izvēlētais nosaukums.
  • Ir mērķa rindkopa un trīs <li> punkti par vadību, punktu iegūšanu un spēles beigām; skaitļi saskan.
  • Skolotājam parādīts veiksmīgs Commit ar aprakstošu ziņu; iesniegts 12.html.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Papildu uzdevums: Pievieno otru sadaļu

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Papildu uzdevums nav obligāts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

Izmanto teoriju: Virsraksti un teksts HTML tagu atgādnē.

  1. Sadaļā <main> uzreiz aiz </ul> pievieno <h2>Vadība</h2>.
  2. Zem virsraksta pievieno <p> ar precīzu peles vai taustiņu lietošanas aprakstu. Tam jāsaskan ar pirmo noteikumu. Saglabā un pārbaudi pārlūkā.

Gatavs, kad: zem noteikumiem ir sadaļa “Vadība” ar atsevišķu rindkopu.

Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 12.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
