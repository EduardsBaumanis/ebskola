1.2 HTML skelets un satura strukturēšana

Stundas uzdevums: Izveidot tehniski pareizu HTML5 dokumenta struktūru un strukturēt informāciju, izmantojot semantiskos tagus un hierarhiju.

2.6.1. Pieraksta algoritmu, izmantojot programmēšanas valodu; 2.3.3. Pārvalda un organizē datņu sistēmu.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - uzraksti HTML5 skeletu no nulles · 2. uzdevums (~25 min) - saliec spēles lapu no header, main un footer · 3. uzdevums (~20 min) - pārbaudi lapu W3C validatorā un izlabo kļūdas. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver VS Code mapi spele, kuru izveidoji 1.1 stundā, un tajā failu index.html; ieslēdz paplašinājumu Live Server.

Teorija: Tīmekļa lapas anatomija

Katrs HTML dokuments līdzinās koka struktūrai. Ir galvenais tags <html>, kurā iekšā ir divas lielas sadaļas:

  • <head> (Galva): Informācija pārlūkam un meklētājiem (nosaukums, kodējums, stili). Lietotājs lapā to neredz.
  • <body> (Ķermenis): Viss redzamais saturs - virsraksti, teksti, attēli un pogas.
Pārlūks lasa kodu no augšas uz leju. Lai kods būtu glīts un lasāms, mēs izmantojam atkāpes (indentation), kas parāda, kurš elements atrodas kura iekšpusē.

Praktiskie uzdevumi

1. uzdevums - Uzraksti HTML5 skeletu no nulles

Beigās pārlūka cilnē būs redzams tavas spēles nosaukums, nevis faila ceļš.

  1. Atver mapē spele failu index.html un izdzēs visu tā līdzšinējo saturu.
  2. Ieraksti pirmajā rindā <!DOCTYPE html>.
  3. Pievieno nākamajā rindā <html lang="lv">, bet faila beigās </html>.
  4. Ieraksti starp tiem <head> ar <meta charset="UTF-8"> un <title>Mana spēle</title>.
  5. Pievieno zem </head> pāri <body></body> un ieliec tajā <h1>Mana spēle</h1>.
  6. Saglabā (Ctrl+S) un atver lapu ar Live Server.

Gatavs, kad: pārlūka cilnes nosaukumā ir "Mana spēle" un lapā redzams liels virsraksts ar garumzīmi.

2. uzdevums - Saliec spēles lapu no semantiskajiem tagiem

Beigās tavai lapai būs galvene ar nosaukumu, vidus ar diviem spēles blokiem un kājene ar autoru.

  1. Atver index.html un pievieno <body> iekšā <header>, <main>, <footer>.
  2. Pārvieto jau uzrakstīto <h1> ar spēles nosaukumu <header> iekšpusē.
  3. Ielīmē <main> iekšā bloku <div id="menu"></div>.
  4. Ielīmē zem tā otru bloku <div id="spele"></div>.
  5. Ielīmē <footer> iekšā <p>Autors: [tavs vārds]</p>.
  6. Saglabā un pārlādē lapu pārlūkā.
  7. Veic git commit -m "Add semantic HTML page structure".

Gatavs, kad: lapas augšā redzams spēles nosaukums, bet pašā apakšā - rinda "Autors: ...".

3. uzdevums - Izlabo HTML kļūdas ar W3C validatoru

Beigās validators par tavu lapu neziņos nevienu sarkanu kļūdu.

  1. Atver validator.w3.org un izvēlies cilni "Validate by Direct Input".
  2. Ielīmē tur visu sava index.html kodu un spied "Check".
  3. Izlasi pirmo sarkano kļūdu un atrodi VS Code norādīto rindu.
  4. Salabo šo vienu kļūdu, saglabā failu un ielīmē kodu validatorā vēlreiz.
  5. Atkārto labošanu, līdz sarkano kļūdu vairs nav.
  6. Spied lapā F12 → "Elements" un pārbaudi koku html → head + body → header + main + footer.
  7. Pieraksti vienu secinājumu: kāpēc <main> ir labāks par <div id="main">.

Gatavs, kad: validators rāda zaļu joslu "Document checking completed. No errors or warnings to show."

Papildu uzdevums - Pievieno iekšējās navigācijas saites

Beigās klikšķis uz saites "Spēle" aizritinās lapu līdz spēles blokam.

  1. Pievieno <header> iekšā bloku <nav></nav>.
  2. Ielīmē tajā saiti <a href="#spele">Spēle</a>.
  3. Ielīmē blakus otru saiti <a href="#autors">Par autoru</a>.
  4. Pievieno <footer> tagam atribūtu id="autors".
  5. Saglabā un noklikšķini pārlūkā uz abām saitēm.
  6. Veic git commit -m "Add in-page navigation links".

Gatavs, kad: klikšķis uz "Par autoru" aizritina lapu līdz kājenei un adresē parādās #autors.

Biežākās kļūdas (un kā tās labot):

  • Aizmirsts aizverošais tags: Ja nenoslēdz </h1>, viss teksts zem tā izskatīsies pēc milzīga virsraksta.
  • Nesting (ligzdošanas) kļūdas: Tags ir jāaizver tādā pašā secībā, kā tas tika atvērts (piem., <p><b>teksts</b></p>).
  • Garumzīmes: Ja lapā redzi dīvainus simbolus, pārliecinies, ka <head> sadaļā ir <meta charset="UTF-8">.

Koda piemērs (pareizs tagu ligzdojums un aizvēršana)

<!DOCTYPE html>
<html lang="lv">
<head>
    <meta charset="UTF-8">  <!-- bez šī garumzīmes izskatīsies kā Ä« -->
    <title>Zvaigžņu mednieks</title>
</head>
<body>
    <header>
        <h1>Zvaigžņu mednieks</h1>
    </header>   <!-- aizvērts pirms nākamā bloka -->

    <main>
        <div id="menu">
            <p>Spied <b>Sākt</b>, lai spēlētu.</p>
            <!-- pareizi: <b> aizveras pirms </p>, nevis pēc tā -->
        </div>

        <div id="spele">
            <ul>
                <li>Savāc zvaigznes</li>
                <li>Izvairies no asteroīdiem</li>
            </ul>
        </div>
    </main>

    <footer>
        <p>Autors: Anna</p>
    </footer>
</body>
</html>
Pārlūka cilnē: Zvaigžņu mednieks. Lapā no augšas uz leju: liels virsraksts, rinda "Spied Sākt, lai spēlētu.", divu punktu saraksts un apakšā "Autors: Anna".
Ja kāds tags paliek neaizvērts, pārlūkā parasti viss teksts zem tā pārvēršas par milzīgu virsrakstu vai pazūd.
