1. tēma / 1.3

1.3 Salīdzini spēles lapas un nosūti darbu uz GitHub

Šodien: Izvēlies saprotamu spēles pogu un nosūti savu lapu uz GitHub.

Īsā teorija

Kā salīdzināt pogu tekstus?

Pogas teksts pasaka, kas notiks pēc klikšķa. Sākt spēli nosauc konkrētu darbību, bet Spied šeit to nepaskaidro. Salīdzini abus variantus pēc viena kritērija: vai spēlētājs pirms klikšķa saprot, ko poga darīs?

Lai salīdzinājums būtu vienāds, pirms katras pogas izmēģināšanas atjauno lapu ar Ctrl+R. Šīs nodarbības paraugā abas pogas maina vienu un to pašu rindkopu uz Spēle sākta!. Atšķiras tikai pogu teksts.

Kuru pogas koda daļu mainīt?

<button> veido pogu. Redzamais teksts ir starp sākuma un beigu tagu. Paraugā onclick satur gatavo klikšķa darbību; id="atbilde" norāda rindkopu, kurā parādās ziņa. Kopējot pogu, saglabā visu rindu un maini tikai redzamo tekstu.

<button onclick="document.getElementById('atbilde').textContent='Spēle sākta!'">Sākt spēli</button>

Saglabāšana un nosūtīšana uz GitHub

Ctrl+S saglabā failu. Stage Changes sagatavo izmaiņas, bet Commit saglabā darba versiju datorā. Publish to GitHub pirmoreiz izveido GitHub projektu un nosūta failus; turpmāk pēc Commit lieto Sync Changes.

GitHub faila skatā pārbaudi kodu, piemēram, jaunās pogas tekstu. Pogas darbību pārbaudi savā datorā pārlūkā atvērtajā 13.html. Publiskajā mācību projektā iekļauj tikai šī darba failus.

Sākuma kods un darba vieta

Vide: mācību lapa → VS Code

  1. VS Code ar File → Open Folder atver Desktop/datorika9-tema1 . Ja mapes nav, izveido to darbvirsmā.
  2. Šajā mācību lapā nospied Kopēt sākuma kodu .
  3. VS Code nospied Ctrl+N un ielīmē kodu ar Ctrl+V .
  4. Saglabā ar Ctrl+Shift+S tēmas mapē kā 13.html .

1. uzdevums

Izmēģini divus variantus

Vide: VS Code → pārlūks

Izmanto teoriju: Pogu salīdzinājums pēc viena kritērija.

  1. Pēc sākuma koda soļiem izveido 13.html tēmas mapē un atver to pārlūkā. Atrodi A un B varianta pogu.
  2. Pirms klikšķa izlasi A pogas tekstu un pasaki, kādu darbību sagaidi. Nospied pogu un pārbaudi, ka rindkopa Izmēģini abas pogas. mainās uz Spēle sākta!.
  3. Atjauno lapu ar Ctrl+R, lai atgrieztu sākotnējo ziņu. Tāpat izmēģini B pogu un salīdzini, vai tās teksts skaidrāk pasaka sagaidāmo darbību.
  4. Klasesbiedram vienā teikumā pamato izvēli: “Izvēlos ... variantu, jo tā teksts pirms klikšķa pasaka ...”. Pamato ar pogas darbību, kā skaidrots teorijā.

Gatavs, kad: abas pogas ir izmēģinātas no sākotnējā stāvokļa un vari pamatot, kurš teksts skaidrāk nosauc darbību.

2. uzdevums

Izveido savu pogas variantu

Vide: VS Code → pārlūks

Izmanto teoriju: Pogas redzamais teksts un gatavā klikšķa darbība.

  1. Failā 13.html zem <h2>Mana izvēle</h2> atrodi rindkopu Manai spēlei būs poga:. Aizstāj to ar savas spēles nosaukumu un vienu teikumu, kas pamato izvēlēto pogas tekstu.
  2. Nokopē visu B varianta <button ...>...</button> rindu, ieskaitot onclick, un ielīmē to zem savas rindkopas pirms </body>. Saglabā arī abus sākotnējos variantus.
  3. Jaunajā pogā maini tikai tekstu starp tagiem, piemēram, uz Sākt zvaigžņu medības. Tekstam jānosauc sākšanas darbība. Saglabā gatavo onclick un rindkopu ar id="atbilde".
  4. Saglabā failu, atjauno lapu pārlūkā un izmēģini trešo pogu. Arī tai jāparāda ziņa Spēle sākta!.

Gatavs, kad: saglabāti A un B varianti, bet sadaļā “Mana izvēle” ir spēles nosaukums, izvēles pamatojums un trešā darbojošā poga.

3. uzdevums

Publicē projekta failus

Vide: Pārlūks → VS Code / Source Control → GitHub

Izmanto teoriju: Saglabāšana un nosūtīšana uz GitHub.

  1. Pārlūkā vēlreiz pārbaudi 13.html: ir visi trīs varianti, un katra poga parāda Spēle sākta!. Pirms katras pārbaudes atjauno lapu ar Ctrl+R.
  2. VS Code saglabā failus ar File → Save All. Source Control pārskati 13.html izmaiņas, veic Stage Changes (+) un Commit ar ziņu Pievienota spēles poga.
  3. Pirmajai nosūtīšanai spied Publish to GitHub. Pieslēdzies savam kontam un apstiprini VS Code piekļuvi, ja to prasa. Izvēlies Publish to GitHub public repository un nosaukumu datorika9-tema1. Failu atlasē iekļauj savus mācību failus. Jau publicētam projektam lieto Sync Changes.
  4. GitHub atver savu projektu un failu 13.html. Tā kodā atrodi tieši savu jaunās pogas tekstu un pamatojumu. Ja redzi veco versiju, pārbaudi, vai pēc pēdējā labojuma veici Commit un nosūtīšanu.
  5. Iesniedz pārbaudīto 13.html skolotāja norādītajā vietā un parādi šo pašu versiju GitHub.

Gatavs, kad: pogas darbojas lokāli, bet GitHub failā redzams tas pats teksts, kas pārbaudītajā un iesniegtajā 13.html.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 13.html skolotāja norādītajā vietā. Šo pašu versiju saglabā arī GitHub.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • Saglabāti A un B varianti; sadaļā “Mana izvēle” ir spēles nosaukums un pogas teksta pamatojums.
  • Trešās pogas teksts nosauc sākšanas darbību; visas trīs pogas parāda ziņu Spēle sākta!.
  • Iesniegtā 13.html saturs sakrīt ar GitHub projekta faila jaunāko versiju.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Saglabā un nosūti uz GitHub — pogu atgādne

Vide: VS Code / Source Control → GitHub pārlūkā

  1. Ar File → Save All saglabā failus. Atver Source Control ar Ctrl+Shift+G .
  2. Pie Changes nospied + (Stage All Changes). Pārbaudi, ka vajadzīgie faili pārvietojas uz Staged Changes .
  3. Ziņas laukā ieraksti īsu izmaiņu, piemēram, Pabeigts 1.3 darbs . Spied Commit .
  4. Ja šī tēmas mape vēl nav GitHub, spied Publish to GitHub un izveido publisku projektu datorika9-tema1 . Jau publicētam projektam spied Sync Changes . Ja pogas nav, atver … → Push .
  5. Pārlūkā atver savu GitHub projektu un pārbaudi faila pēdējās izmaiņas.

Ja Source Control rāda Initialize Repository , vispirms nospied to. Ja parādās kļūda vai sapludināšanas pieprasījums, izmanto palīdzību un palūdz skolotāja atbalstu.

Papildu uzdevums: Uzlabojums abiem variantiem

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Papildu uzdevums nav obligāts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

Izmanto teoriju: Saprotams pogas teksts.

  1. Saglabā darba kopiju kā 13-papildus.html, lai iesniegtajā 13.html paliktu sākotnējie A un B varianti.
  2. Kopijā nomaini A pogas tekstu uz citu skaidru sākšanas norādi, piemēram, “Sākt jaunu spēli”. Saglabā tās gatavo darbību.
  3. Atver kopiju pārlūkā. Atjaunojot lapu pirms katra mēģinājuma, pārbaudi abas pogas: tām joprojām jāparāda Spēle sākta!.

Gatavs, kad: kopijā abu variantu pogu teksti nosauc darbību un abas pogas darbojas.

Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 13.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Poga nestrādā? Pārbaudi, vai neizdzēsi pēdiņu, iekavu vai elementa id. Salīdzini savu laboto vietu ar sākuma kodu.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
