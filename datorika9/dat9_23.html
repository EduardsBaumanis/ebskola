2. tēma / 2.3

2.3 Sagatavo un pievieno spēles attēlu

Šodien: Uzzīmē nelielu spēles varoni un ievieto to HTML lapā.

Teorija ar piemēriem

Attēls ir atsevišķs projekta fails

Šajā nodarbībā Paint izveido savu 128 × 128 pikseļu varoni un saglabā to PNG formātā. Tīmekļa lapai vajag gan HTML failu, gan attēla failu. Attēla ievietošanas kods pats nesatur zīmējumu — tas norāda, kur to atrast.

Sākuma kodā vietā <!-- ŠEIT ATTĒLS --> ievieto, piemēram, šo rindu. Aprakstu pielāgo savam zīmējumam.

<img src="varonis.png" alt="Zils kosmosa robots" width="128">
Koda daļaNozīme
src="varonis.png"Meklē attēlu tajā pašā mapē, kur ir HTML fails.
alt="Zils kosmosa robots"Īss attēla satura apraksts, ko var izmantot arī ekrānlasītājs.
width="128"Norāda attēla rādīšanas platumu lapā.

Faila izmēri un izmērs lapā

128 × 128 nozīmē 128 pikseļu platumu un 128 pikseļu augstumu pašā zīmējumā. Mainot HTML platumu uz 64, lapā redzēsi mazāku attēlu, bet saglabātajam PNG joprojām būs 128 × 128 pikseļi. Ļoti maza attēla palielināšana neveido jaunas detaļas.

Ja attēls neparādās

Pārbaudi, vai fails ir saglabāts pareizajā mapē un vai src precīzi sakrīt ar tā nosaukumu, ieskaitot paplašinājumu. varonis.png un varonis.jpg ir dažādi nosaukumi. Ar nosaukuma pārrakstīšanu JPG failu nepārvērš PNG formātā; formātu izvēlies attēlu programmas saglabāšanas logā.

Pašpārbaude: vai pietiek klasesbiedram aizsūtīt tikai HTML failu?

Nē. Viņam vajag arī attēla failu ar tādu pašu nosaukumu un atrašanās vietu pret HTML failu. Citādi lapa nevarēs attēlu atrast.

1. uzdevums

Uzzīmē varoni

Izmanto teoriju: Faila izmēri un izmērs lapā.

Vide: Windows / Paint

  1. Atver Start , ieraksti Paint un atver lietotni.
  2. Ar formām un otu uzzīmē vienkāršu varoni no trim vai četrām formām.
  3. Izvēlies Resize (Mainīt izmēru) un Pixels (Pikseļi). Izslēdz malu attiecības saglabāšanu un iestati 128 × 128.
  4. Ar File → Save as → PNG picture saglabā varonis.png savā Desktop/datorika9-tema2 mapē.

Gatavs, kad: Tēmas mapē ir tavs varonis.png.

2. uzdevums

Pievieno attēlu lapai

Izmanto teoriju: Attēls ir atsevišķs projekta fails.

Vide: Paint → VS Code

  1. Atver sākuma kodu failā 23.html tajā pašā mapē.
  2. Rindas <!-- ŠEIT ATTĒLS --> vietā ievieto teorijas <img> piemēru.
  3. Nomaini alt tekstu, lai tas apraksta tavu varoni. Nomaini arī lapas virsrakstu.

Gatavs, kad: HTML kodā ir saite uz varonis.png un atbilstošs alt teksts.

3. uzdevums

Pabeidz varoņa lapu

Izmanto teoriju: Ja attēls neparādās.

Vide: VS Code → pārlūks

  1. Zem attēla pievieno rindkopu, kas pasaka, ko varonis dara spēlē.
  2. Saglabā un atver 23.html pārlūkā. Pārliecinies, ka redzi savu zīmējumu.
  3. Ja attēla nav, pārbaudi, vai 23.html un varonis.png ir vienā mapē un nosaukumi sakrīt.
  4. Uz GitHub nosūti abus failus. Iesniedz HTML failu kopā ar PNG attēlu.

Gatavs, kad: Pārlūkā ir tavs varonis, tā nosaukums un apraksts.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 23.html un varonis.png skolotāja norādītajā vietā. Šo pašu versiju saglabā arī GitHub.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • varonis.png ir paša zīmējums 128 × 128 px izmērā.
  • 23.html parāda šo attēlu un satur atbilstošu alt tekstu.
  • Iesniegts HTML un PNG; abi ir arī GitHub projektā.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Saglabā un nosūti uz GitHub — pogu atgādne

Vide: VS Code / Source Control → GitHub pārlūkā

  1. Ar File → Save All saglabā failus. Atver Source Control ar Ctrl+Shift+G .
  2. Pie Changes nospied + (Stage All Changes). Pārbaudi, ka vajadzīgie faili pārvietojas uz Staged Changes .
  3. Ziņas laukā ieraksti īsu izmaiņu, piemēram, Pabeigts 2.3 darbs . Spied Commit .
  4. Ja šī tēmas mape vēl nav GitHub, spied Publish to GitHub un izveido publisku projektu datorika9-tema2 . Jau publicētam projektam spied Sync Changes . Ja pogas nav, atver … → Push .
  5. Pārlūkā atver savu GitHub projektu un pārbaudi faila pēdējās izmaiņas.

Ja Source Control rāda Initialize Repository , vispirms nospied to. Ja parādās kļūda vai sapludināšanas pieprasījums, izmanto palīdzību un palūdz skolotāja atbalstu.

Papildu uzdevums: Izveido otru varoni

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

  1. Paint izveido citu zīmējumu un saglabā kā draugs.png .
  2. Lapā pievieno otru <img> un savu alt tekstu.
Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 23.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Poga nestrādā? Pārbaudi, vai neizdzēsi pēdiņu, iekavu vai elementa id. Salīdzini savu laboto vietu ar sākuma kodu.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
