2. tēma / 2.3

2.3 Sagatavo un pievieno spēles attēlu

Šodien: Uzzīmē nelielu spēles varoni un ievieto to HTML lapā.

Teorija ar piemēriem

Attēls ir atsevišķs projekta fails un <img> birka

Šajā nodarbībā sasaistīsi divu programmu darbu: rastra grafikas redaktorā Paint uzzīmēsi savu spēles varoni un saglabāsi to kā attēla datni varonis.png, bet VS Code HTML failā ierakstīsi norādi uz šo datni. Pats HTML fails zīmējumu sevī neglabā — pārlūks attēlu ielādē no blakus esošā faila.

Kāpēc izvēlamies PNG formātu? Spēļu varoņiem, ikonām un shēmām ar skaidrām kontūrām un vienmērīgiem krāsu laukumiem vispiemērotākais ir PNG (.png), jo tas saglabā asas malas bez saspiešanas plankumiem. Turpretī JPG (.jpg) ir paredzēts fotogrāfijām un pie asām līnijām var radīt izplūdušus punktus. Formātu vienmēr izvēlies saglabāšanas logā (Save as → PNG picture) — vienkārša faila nosaukuma pārrakstīšana formātu nepārveido.

HTML kodā attēlu ievieto ar nepāra tagu <img> (tam nav aizverošā </img> taga):

<img src="varonis.png" alt="Zils kosmosa robots ar antenu" width="128">
Koda daļa Nozīme
<img ...> Nepāra birka attēla parādīšanai lapā (aizverošo </img> neraksta).
src="varonis.png" Norāda attēla faila nosaukumu vai ceļu. Ja rakstīts tikai nosaukums, pārlūks to meklē tajā pašā mapē, kur atrodas HTML fails.
alt="Zils kosmosa robots ar antenu" Alternatīvais teksts: īss zīmējuma apraksts ekrānlasītājiem un gadījumiem, kad attēla fails neielādējas.
width="128" Attēla rādīšanas platums lapā pikseļos (HTML atribūtā raksta tikai skaitli pēdiņās bez px).

Rastra attēla pikseļi un izmērs lapā

Paint veido rastra attēlu — zīmējumu no sīku krāsainu kvadrātiņu jeb pikseļu režģa. Izmērs 128 × 128 nozīmē 128 pikseļus platumā un 128 pikseļus augstumā. Šo audekla izmēru Paint programmā iestata pirms zīmēšanas un ērtam darbam pietuvina skatu ar Zoom — ja vispirms uzzīmē uz liela taisnstūra audekla un tikai beigās to saspiež uz 128 × 128, zīmējums tiek deformēts.

Atšķir faila pikseļus no attēlošanas izmēra lapā: ja HTML kodā width="128" nomaini uz width="64", pārlūkā varonis izskatīsies divreiz mazāks, bet saglabātajam varonis.png failam mapē joprojām būs 128 × 128 pikseļi. Savukārt, ja mazu rastra attēlu lapā pārāk izstiepj (piemēram, width="400"), jaunas detaļas nerodas un kļūst redzami robaini pikseļi.

Precīzi failu nosaukumi un kļūdu pārbaude

Tīmekļa projektos failu nosaukumus raksti ar mazajiem latīņu burtiem, bez atstarpēm un garumzīmēm — piemēram, varonis.png, nevis Mans Varonis.PNG. Ja src vērtība kaut par vienu burtu vai paplašinājumu nesakrīt ar īsto failu (piemēram, varonis.jpg vai varonis2.png), pārlūks attēlu neatradīs un tā vietā parādīs salauzta attēla ikonu kopā ar alt tekstu.

Pašpārbaude: vai pietiek klasesbiedram aizsūtīt tikai 23.html failu, lai viņš savā datorā redzētu tavu varoni?

Nē. HTML failā ir tikai teksta norāde src="varonis.png", nevis pats zīmējums. Lai attēls parādītos citā datorā, vienā mapē jābūt gan 23.html, gan attēla datnei varonis.png ar tieši tādu pašu nosaukumu.

1. uzdevums

Sagatavo audeklu un uzzīmē varoni programmā Paint

Izmanto teoriju: PNG formāts un Rastra attēla pikseļi.

Vide: Windows / Paint → VS Code

  1. Atver izvēlni Start, ieraksti Paint un atver zīmēšanas lietotni.
  2. Pirms sāc zīmēt, nospied rīkjoslas pogu Resize (vai taustiņus Ctrl+W), pārslēdz uz Pixels (Pikseļi), atslēdz malu attiecības saglabāšanu (ķēdītes ikonu starp laukiem vai rūtiņu Maintain aspect ratio), abos laukos ieraksti 128 un apstiprini ar OK.
  3. Paint loga apakšējā labajā stūrī palielini pietuvinājumu (Zoom) uz 400% (vai turi Ctrl un pagriez peles rullīti uz augšu), lai nelielais 128 × 128 audekls uz ekrāna būtu liels un ērti zīmējams.
  4. Ar figūrām (Shapes), otu (Brushes) un krāsas aizpildīšanu (Fill) uzzīmē savas spēles varoni no skaidrām formām un vismaz trim krāsām.
  5. Izvēlies File → Save as → PNG picture, atver mapi Desktop/datorika9-tema2, laukā File name ieraksti varonis (ar mazajiem burtiem, bez atstarpēm un garumzīmēm) un spied Save.
  6. Pārslēdzies uz VS Code un kreisajā Explorer failu sarakstā pārliecinies, ka blakus 23.html ir redzams fails varonis.png; noklikšķini uz tā, lai pārbaudītu saglabāto zīmējumu.

Gatavs, kad: mapē Desktop/datorika9-tema2 blakus 23.html atrodas paša uzzīmēts 128 × 128 pikseļu fails varonis.png.

2. uzdevums

Pievieno attēlu un varoņa aprakstu HTML lapā

Izmanto teoriju: Attēls ir atsevišķs projekta fails un <img> birka.

Vide: VS Code → pārlūks

  1. VS Code atver failu 23.html un gan <title>, gan <h1> tagos ieraksti sava varoņa vārdu vai lomu spēlē.
  2. Bloka <div class="kartite"> iekšpusē nomaini <p>Šeit būs īss varoņa ievads.</p> uz teikumu, kas iepazīstina ar varoni.
  3. Komentāra rindas <!-- ŠEIT ATTĒLS --> vietā ieraksti attēla birku <img src="varonis.png" alt="" width="128"> (atceries, ka <img> tagam nav aizverošā </img>).
  4. Atribūtā alt="" starp pēdiņām ieraksti konkrētu sava zīmējuma izskata aprakstu (piemēram, Zaļš bruņurupucis ar sarkanu vairogu).
  5. Tajā pašā <div class="kartite"> blokā tieši zem <img> rindas pievieno vēl vienu <p>...</p> rindkopu, kurā paskaidro, kādu uzdevumu vai spēju šis varonis veic spēlē.
  6. Saglabā failu ar Ctrl+S, atver 23.html no mapes Desktop/datorika9-tema2 pārlūkā (Open with → Edge) un pārliecinies, ka kartītē redzams tavs zīmējums un abas rindkopas.

Gatavs, kad: pārlūkā redzams tavs varonis.png attēls, varoņa vārds un divas apraksta rindkopas, bet kodā aizpildīts precīzs alt teksts.

3. uzdevums

Pārbaudi izmēru, alt tekstu un noformē varoņa kartīti

Izmanto teoriju: Faila pikseļi un izmērs lapā un Kļūdu pārbaude.

Vide: VS Code → pārlūks

  1. VS Code birkā <img> nomaini width="128" uz width="64", saglabā (Ctrl+S) un atjauno pārlūku (Ctrl+R) — novēro, ka zīmējums lapā kļuva mazāks, lai gan fails varonis.png mapē nemainījās.
  2. Atgriez platumu atpakaļ uz width="128", saglabā un ar Ctrl+R pārliecinies, ka varonis atkal redzams pilnā 128 pikseļu platumā.
  3. Pārbaudi, kā darbojas alt teksts: īslaicīgi izmaini src="varonis.png" uz neesošu faila vārdu src="varonis2.png", saglabā un atjauno pārlūku — pārliecinies, ka attēla vietā parādās tavs uzrakstītais alt apraksts.
  4. Izlabo atpakaļ uz src="varonis.png", saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka zīmējums atkal ielādējas bez kļūdām.
  5. CSS blokā .kartite { ... } pielieto iepriekšējās stundās apgūto noformējumu: pieskaņo background-color un border krāsu savam varonim, kā arī pievieno border-radius: 12px;, max-width: 360px;, margin: 20px auto; un text-align: center;.
  6. Virs .kartite bloka pievieno h1 { text-align: center; }, saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārliecinies, ka virsraksts un varoņa kartīte ir centrēti un viss teksts ir labi salasāms.

Gatavs, kad: esi pārbaudījis attēla platuma un alt teksta darbību, un pārlūkā redzama centrēta, noformēta varoņa kartīte ar strādājošu 128 × 128 PNG attēlu.

Papildu uzdevums: Pievieno otru spēles objektu (draugs.png)

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Attēla sagatavošana un <img> birka.

  1. Programmā Paint izveido jaunu lapu (File → New), ar Resize → Pixels iestati 64 × 64 pikseļu audeklu (atslēdzot malu attiecību) un palielini Zoom uz 500%.
  2. Uzzīmē otru spēles elementu — sabiedroto, bonusu vai šķērsli — un ar File → Save as → PNG picture saglabā to mapē Desktop/datorika9-tema2 kā draugs.png.
  3. Failā 23.html bloka .kartite apakšā pievieno otru <img src="draugs.png" alt="..." width="64"> ar precīzu alt tekstu un īsu <p> paskaidrojumu par šī objekta nozīmi.
  4. Saglabā failu ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka lapā redzami abi zīmējumi atšķirīgos izmēros (128 un 64 px).

Gatavs, kad: tēmas mapē ir draugs.png un lapā korekti attēlojas abi spēles objekti ar saviem alt aprakstiem.

Ja kaut kas neizdodas
  • Attēla vietā redzama salauzta ikona un alt teksts? Pārbaudi, vai varonis.png atrodas tieši mapē Desktop/datorika9-tema2 blakus 23.html un vai nosaukumā nav lielo burtu, atstarpju vai dubulta paplašinājuma (piemēram, varonis.png.png).
  • Neredzi, kāds ir īstais faila paplašinājums? Windows File Explorer augšējā joslā atver View → Show → File name extensions — tad pie katra faila redzēsi .html, .png vai .jpg.
  • Paint audekls izskatās pārāk mazs vai zīmējums saspiests? Izmēru 128 × 128 iestati pirms zīmēšanas ar Ctrl+W → Pixels. Lai zīmēt būtu ērti, palielini tikai Zoom slīdni loga apakšējā labajā stūrī (uz 400%), nevis audekla pikseļu skaitu.
  • Neredzi HTML vai CSS izmaiņas pārlūkā? VS Code saglabā ar Ctrl+S, tad pārlūkā nospied Ctrl+R un pārliecinies, ka atvērts tieši Desktop/datorika9-tema2/23.html.
