1. tēma / 1.4 / Atkārtojuma tests

Atkārtojuma tests: 1.3 Salīdzini spēles lapas un nosūti darbu uz GitHub

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kurš pogas teksts vislabāk pasaka, kas notiks pēc klikšķa?

“Sākt spēli” nosauc konkrētu darbību, bet “Spied šeit” nepaskaidro, kas notiks pēc klikšķa. Atkārto: 1.3 — Kā salīdzināt pogu tekstus? ↗

2. Tu salīdzini divas pogas, lai uzzinātu, kurš teksts ir saprotamāks. Kas abām pogām drīkst atšķirties?

Ja atšķiras tikai teksts, zini, ka cilvēkam palīdzēja tieši teksts, nevis, piemēram, lielāka poga. Atkārto: 1.3 — Ko patiesībā salīdzini? ↗

3. Kur pogas kodā atrodas teksts, ko redz uz pogas?

Redzamais teksts ir starp pogas sākuma un beigu tagu. onclick satur klikšķa darbību. Atkārto: 1.3 — Kuru pogas koda daļu mainīt? ↗

4. Projekts GitHub jau ir izveidots. Ar ko pēc Commit nosūti jauno versiju?

Publish to GitHub lieto pirmoreiz: tas izveido GitHub projektu un nosūta failus. Turpmāk pēc Commit lieto Sync Changes. Atkārto: 1.3 — Saglabāšana un nosūtīšana uz GitHub ↗

5. Tu izveidoji Commit, bet neko nenosūtīji. Vai skolotājs GitHub jau redz tavu labojumu?

Commit saglabā versiju datorā. Pēc nosūtīšanas atver failu GitHub un pārbaudi, vai tur ir jaunais saturs. Atkārto: 1.3 — Saglabāts datorā vēl nenozīmē nosūtīts ↗
