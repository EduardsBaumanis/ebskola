3.5 Cikls: izveido izvēļu pogas un skaiti gājienus

Sasniedzamais rezultāts: Izveido for ciklu, kas no vietu masīva automātiski uzbūvē spēles izvēļu pogas, parāda pieejamo vietu kopskaitu un skaita spēlētāja gājienus.

Teorija ar piemēriem

Kā for cikls apstaigā masīvu no pirmā līdz pēdējam vienumam

Ja piedzīvojumu spēlē ir piecas vai desmit apmeklējamas vietas, rakstīt katrai savu HTML <button> birku ar roku ir neērti un kļūdaini. Glabājot nosaukumus masīvā, for cikls atkārto vienu un to pašu koda bloku katram masīva indeksam:

const durvis = ["Ziemeļu vārti", "Slepenā eja", "Sardzes tornis"];

for (let i = 0; i < durvis.length; i = i + 1) {
  // Šīs rindas izpildās katram indeksam i
}
Cikla daļa Kad izpildās? Ko tā nozīmē?
let i = 0 Vienu reizi pirms cikla sākuma Izveido skaitītāju i ar pirmā vienuma indeksu 0.
i < durvis.length Pirms katra cikla apļa Turpina ciklu, kamēr indekss ir stingri mazāks par skaitu (<, nevis <=!).
i = i + 1 Pēc katra pabeigta apļa Palielina indeksu par 1, lai pārietu uz nākamo masīva vietu.

Apskati, kā cikls soli pa solim iziet cauri 3 vienumu masīvam (durvis.length ir 3):

i vērtība Pārbaude i < 3 Nolasītā vērtība durvis[i] Kas notiek?
0 true "Ziemeļu vārti" Izpilda 1. apli.
1 true "Slepenā eja" Izpilda 2. apli.
2 true "Sardzes tornis" Izpilda 3. apli.
3 false — Cikls apstājas; ceturto apli neveic.

Tiklīdz masīvam pievieno jaunus nosaukumus (piemēram, kopā 5), .length automātiski kļūst 5 un tas pats cikls izpildās piecas reizes — pats cikla kods vispār nav jāpārraksta!

Pogu izveidošana ar JavaScript un atšķirība no klikšķa

Lai ievietotu pogas lapā, HTML daļā sagatavo tukšu konteineru (piemēram, <div id="pogas"></div>), bet ciklā katram masīva vienumam uzbūvē savu pogu:

for (let i = 0; i < durvis.length; i = i + 1) {
  const poga = document.createElement("button");
  poga.textContent = durvis[i];
  poga.onclick = function () {
    atvertDurvis(durvis[i]);
  };
  document.getElementById("pogas").append(poga);
}
  • document.createElement("button") — atmiņā izveido jaunu HTML pogas elementu.
  • poga.textContent = durvis[i] — uzraksta uz pogas attiecīgās vietas nosaukumu (ja vēlas pogas numurēt no 1, priekšā var pielikt (i + 1) + ". ").
  • poga.onclick = function () { atvertDurvis(durvis[i]); }; — piesaista pogai instrukciju, ko darīt vēlāk, kad spēlētājs uzklikšķinās. Pogu izveidošanas brīdī funkcija atvertDurvis(...) vēl neizpildās! Tā kā ciklā rakstīts let i = 0, katra poga precīzi atceras tieši savu indeksu i.
  • document.getElementById("pogas").append(poga) — pievieno gatavo pogu lapas konteinerā #pogas (izveidotās <button> birkas vari apskatīt pārlūka rīkā F12 → Elements).

Funkcijas parametrs, gājienu skaitītājs un sākšana no jauna

Kad spēlētājs nospiež kādu no cikla izveidotajām pogām, izpildās gājiena funkcija un saņem nospiestās vietas nosaukumu savā parametrā (mainīgajā apaļajās iekavās):

let gajieni = 0;

function atvertDurvis(nosaukums) {
  gajieni = gajieni + 1;
  document.getElementById("zinojums").textContent = "Tu pārbaudīji: " + nosaukums;
  document.getElementById("skaititajs").textContent = "Veiktie gājieni: " + gajieni;
}
  • Parametrs nosaukums: nospiežot pirmo pogu, nosaukums ir "Ziemeļu vārti"; nospiežot otro — "Slepenā eja". Tāpēc viena funkcija apkalpo visas pogas.
  • Skaitītājs let gajieni = 0;: obligāti jāizveido ārpus funkcijas, lai vērtība saglabātos starp klikšķiem. Katrs klikšķis (arī atkārtots klikšķis uz tās pašas pogas) palielina gajieni par 1.
  • Sākšana no jauna: atsevišķa HTML poga ar onclick="location.reload()" pārlādē lapu pārlūkā, atgriežot gajieni uz 0 un sākotnējo uzaicinājuma tekstu.
Pašpārbaude: masīvā ir 5 vietas un zem <div id="pogas"> ir poga “Sākt no jauna” — cik pogu izveidos for cikls, un cik gājienu rādīsies uzreiz pēc lapas atvēršanas?

for cikls izveidos tieši 5 vietu pogas (indeksiem 0, 1, 2, 3 un 4); poga “Sākt no jauna” ir atsevišķa HTML poga ārpus cikla. Uzreiz pēc lapas atvēršanas gājienu skaits ir 0, jo pogu uzzīmēšana vēl neizsauc klikšķa funkciju.

1. uzdevums

Izpēti cikla izveidotās pogas un pielāgo spēles ievadu

Izmanto teoriju: Pogu izveidošana ar JavaScript un atšķirība no klikšķa.

Vide: Windows File Explorer → pārlūks (ar F12 Elements) → VS Code

  1. Windows mapē Desktop/datorika9-tema3 atver saglabāto 35.html pārlūkā (Open with → Edge) un pārliecinies, ka redzamas trīs vietu pogas (Mežs, Upe, Pils) un sākuma uzraksts Gājieni: 0.
  2. Nospied pogas Mežs un Pils, novērojot izmaiņas rindkopās #atbilde un #gajieni; pēc tam nospied Sākt no jauna un pārliecinies, ka skaitītājs atgriežas uz 0.
  3. Pārlūkā nospied F12 → Elements, atver <div class="panelis"> un izvērs <div id="pogas"> — apskati trīs <button> elementus, kurus konteinerā ievietoja JavaScript cikls.
  4. VS Code failā 35.html nomaini <title> un <h1> uz savas piedzīvojumu vai meklēšanas spēles nosaukumu.
  5. Rindkopā <p id="noteikumi"> ieraksti īsu uzdevumu savas spēles dalībniekam, atstājot tukšu konteineru <div id="pogas"></div>.
  6. Saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka redzams jaunais spēles virsraksts un noteikumu apraksts.

Gatavs, kad: esi pārbaudījis sākuma pogu darbību pārlūkā un pielāgojis spēles virsrakstu un noteikumu rindkopu.

2. uzdevums

Izveido 5 savas spēles vietas un parādi to kopskaitu

Izmanto teoriju: Kā for cikls apstaigā masīvu no pirmā līdz pēdējam vienumam.

Vide: VS Code → pārlūks

  1. <script> daļas sākumā atrodi masīvu const vietas = ["Mežs", "Upe", "Pils"];.
  2. Nomaini parauga vārdus un papildini masīvu tā, lai tajā būtu tieši piecas tavai spēlei piemērotas vietas (nerakstot nevienu jaunu <button> birku HTML daļā!).
  3. Pārbaudi masīva sintaksi: kvadrātiekavas [...] ap visu sarakstu, pēdiņas "..." ap katru vietas nosaukumu un komats , starp tiem.
  4. HTML daļas blokā <div class="panelis"> tieši virs <div id="pogas"></div> pievieno tukšu rindkopu <p id="vietu-skaits"></p>.
  5. <script> daļā zem let gajieni = 0; pievieno rindu, kas elementam id="vietu-skaits" ar .textContent parāda kopējo vietu skaitu no vietas.length (piemēram, "Pieejamās vietas: " + vietas.length).
  6. Paredzi, cik pogu tagad izveidos for cikls, saglabā failu ar Ctrl+S, pārlūkā nospied Ctrl+R un pārliecinies, ka redzams skaits 5 un tieši piecas vietu pogas.

Gatavs, kad: masīvā ir piecas paša izvēlētas vietas, lapā parādīts to skaits 5, un for cikls bez roku darba HTML daļā uzzīmē visas piecas pogas.

3. uzdevums

Pilnveido gājiena paziņojumu un pārbaudi skaitītāja darbību

Izmanto teoriju: Funkcijas parametrs, gājienu skaitītājs un sākšana no jauna.

Vide: VS Code → pārlūks (ar F12 Console)

  1. <script> daļā izpēti funkciju izveleties(vieta) un pārliecinies, ka mainīgais let gajieni = 0; joprojām atrodas skripta augšpusē ārpus funkcijas.
  2. Funkcijā izveleties(vieta) pielāgo #atbilde tekstu savas spēles stāstam, obligāti iekļaujot tajā parametru vieta (piemēram, "Tu pārmeklēji vietu: " + vieta + ". Turpini meklējumus!").
  3. Pārbaudi vai pielāgo #gajieni izvades tekstu tā, lai tas skaidri rādītu veikto gājienu skaitu (saglabājot aprēķinu gajieni = gajieni + 1;).
  4. Saglabā failu ar Ctrl+S, pārlūkā nospied Ctrl+R un pārliecinies, ka uzreiz pēc atvēršanas Gājieni ir 0.
  5. Secīgi nospied trīs dažādas vietu pogas (pārbaudi, ka nosaukums katrā reizē mainās un skaits ir 3), un pēc tam vēl divreiz nospied vienu un to pašu pogu (skaits pieaug uz 4 un 5).
  6. Nospied pogu Sākt no jauna, pārliecinies, ka gājienu skaits atgriežas uz 0, un atver F12 → Console, pārbaudot, ka nav nevienas sarkanas kļūdas.

Gatavs, kad: visas piecas pogas parāda spēlei pielāgotu ziņu ar izvēlēto vietu, precīzi skaita gājienus, poga Sākt no jauna atjauno 0, un konsolē nav kļūdu.

Papildu uzdevums: Sanumurē vietu pogas no 1 līdz 5

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Indekss i iekš for cikla un Pogu izveidošana.

  1. <script> daļas for ciklā atrodi rindu poga.textContent = vietas[i];.
  2. Papildini pogas uzrakstu ar kārtas numuru i + 1 (jo indekss i sākas ar 0): poga.textContent = (i + 1) + ". " + vietas[i];.
  3. Atstāj nākamajā rindā izveleties(vietas[i]) bez izmaiņām un saglabā failu ar Ctrl+S.
  4. Pārlūkā nospied Ctrl+R un pārbaudi, ka pogu uzraksti ir numurēti no 1. līdz 5., bet gājiena paziņojumā #atbilde joprojām rādās tīrs vietas nosaukums bez cipara.

Gatavs, kad: visas piecas pogas ir pārskatāmi sanumurētas no 1. līdz 5. un paziņojumi strādā nevainojami.

Ja kaut kas neizdodas
  • Lapā neparādās neviena vietas poga? Atver F12 → Console: pārbaudi, vai masīvā const vietas = [...] ap visiem pieciem nosaukumiem ir pēdiņas un starp tiem komati, un vai HTML daļā nav izdzēsts <div id="pogas"></div> vai tikko pievienotais <p id="vietu-skaits"></p>.
  • Aiz piecām vietām parādās sestā poga ar uzrakstu undefined? Cikla galvenē i < vietas.length vietā esi uzrakstījis i <= vietas.length. Indeksi pieciem vienumiem beidzas pie 4, tāpēc jālieto stingri mazāks <.
  • Gājienu skaits pēc katra klikšķa paliek 1 un nekad nekļūst 2? Pārliecinies, ka rinda let gajieni = 0; atrodas skripta augšā ārpus funkcijas izveleties(vieta) — ja tā atrodas funkcijas iekšpusē, skaitītājs katrā klikšķī tiek nolikts atpakaļ uz 0.
  • Uzreiz atverot lapu, jau ir pieskaitīti gājieni, bet pogu klikšķi nestrādā? Pārbaudi cikla rindu poga.onclick = function () { izveleties(vietas[i]); }; — tai obligāti jābūt ietvertai function () { ... } apvalkā, nevis rakstītai kā tiešam izsaukumam poga.onclick = izveleties(vietas[i]);.
  • Neredzi izmaiņas vai kods pārlūkā redzams kā parasts teksts? VS Code nospied Ctrl+S, pārlūkā Ctrl+R un pārliecinies, ka atvērts Desktop/datorika9-tema3/35.html ar īstu .html galotni (nevis .html.txt).
