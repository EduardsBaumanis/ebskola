3.5 Cikls izveido izvēles — projekta 1. daļa

Šodien: Sāc teksta spēles projektu: no saraksta izveido izvēles pogas un skaiti gājienus.

Tēmas projekts · 1. daļa no 2

Teorija ar piemēriem

Vienu darbību atkārto katrai vietai

Teksta spēlei vajag pogu katrai apmeklējamai vietai. Ja vietu nosaukumus glabā masīvā, cikls var tos apskatīt pēc kārtas un izveidot vajadzīgo pogu skaitu. Pievienojot masīvam vietu, nav ar roku jāraksta vēl viena HTML poga.

const vietas = ["Mežs", "Upe", "Pils"];

for (let i = 0; i < vietas.length; i = i + 1) {
  const poga = document.createElement("button");
  poga.textContent = vietas[i];
  poga.onclick = function () {
    izveleties(vietas[i]);
  };
  document.getElementById("pogas").append(poga);
}

Šis ir sākuma kodā jau dotais princips. i glabā pašreizējās vietas indeksu. Sāk ar 0; pirms katras atkārtošanas pārbauda, vai indekss vēl ir mazāks par vietu skaitu; pēc atkārtošanas palielina to par vienu.

iPārbaude i < 3Rezultāts
0Patiesa.Izveido pogu “Mežs”.
1Patiesa.Izveido pogu “Upe”.
2Patiesa.Izveido pogu “Pils”.
3Aplama.Cikls beidzas; ceturto pogu neveido.

Pogas izveidošana vēl nav gājiens

createElement("button") izveido pogu, textContent uzraksta tās tekstu, bet append pievieno to lapai. Ar onclick saglabā norādi, ko darīt vēlāk, kad pogu nospiedīs. Funkcija izveleties šajā brīdī vēl neizpildās.

Pēc lapas atvēršanas pogas jau ir redzamas, bet gājienu skaits ir 0. Katrs vietas pogas klikšķis palielina gājienus par vienu un parāda izvēlēto vietu. Trīs klikšķi dod trīs gājienus, arī tad, ja visus veic uz vienas pogas. Sākšana no jauna pārlādē lapu un atgriež sākuma vērtības.

Pašpārbaude: masīvā ir piecas vietas — cik vietu pogu izveidos cikls?

Piecas: ar indeksiem 0, 1, 2, 3 un 4. Sākšanas no jauna poga ir atsevišķa HTML poga; tā nav sestā vieta masīvā.

1. uzdevums

Izmēģini izvēļu sarakstu

Izmanto teoriju: Pogas izveidošana vēl nav gājiens.

Vide: VS Code → pārlūks

  1. Sāc ar 35.html .
  2. Pārlūkā nospied visas trīs vietu pogas.
  3. Pārbaudi, ka mainās vietas nosaukums un gājienu skaits.

Gatavs, kad: Saraksta vietām ir strādājošas pogas.

2. uzdevums

Izveido savas spēles vietas

Izmanto teoriju: Vienu darbību atkārto katrai vietai.

Vide: VS Code

  1. Masīvā vietas ieraksti četras savas vietas.
  2. Nemainot ciklu, saglabā failu.
  3. HTML daļā pielāgo spēles nosaukumu un sākuma norādi.

Gatavs, kad: Spēles kodā ir četras savas vietas.

3. uzdevums

Pievieno piekto vietu un pārbaudi ciklu

Izmanto teoriju: Pogas izveidošana vēl nav gājiens.

Vide: VS Code → pārlūks

  1. Pievieno masīvam piekto vietu. Papildu HTML pogu neraksti.
  2. Atver lapu pārlūkā: jāparādās piecām vietu pogām.
  3. Nospied trīs dažādas vietas. Pārbaudi vietu nosaukumus un gājienu skaitu 3.
  4. Nospied Sākt no jauna : gājieniem jābūt 0. Nosūti darbu uz GitHub.

Gatavs, kad: Cikls veido piecas pogas, un darbojas gājienu skaitīšana.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 35.html skolotāja norādītajā vietā. Šo pašu versiju saglabā arī GitHub.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • Ir savs spēles nosaukums un piecas paša izvēlētas vietas.
  • Visas vietu pogas veido for cikls no masīva.
  • Trīs izvēles dod 3 gājienus; sākšana no jauna atjauno 0.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Saglabā un nosūti uz GitHub — pogu atgādne

Vide: VS Code / Source Control → GitHub pārlūkā

  1. Ar File → Save All saglabā failus. Atver Source Control ar Ctrl+Shift+G .
  2. Pie Changes nospied + (Stage All Changes). Pārbaudi, ka vajadzīgie faili pārvietojas uz Staged Changes .
  3. Ziņas laukā ieraksti īsu izmaiņu, piemēram, Pabeigts 3.5 darbs . Spied Commit .
  4. Ja šī tēmas mape vēl nav GitHub, spied Publish to GitHub un izveido publisku projektu datorika9-tema3 . Jau publicētam projektam spied Sync Changes . Ja pogas nav, atver … → Push .
  5. Pārlūkā atver savu GitHub projektu un pārbaudi faila pēdējās izmaiņas.

Ja Source Control rāda Initialize Repository , vispirms nospied to. Ja parādās kļūda vai sapludināšanas pieprasījums, izmanto palīdzību un palūdz skolotāja atbalstu.

Papildu uzdevums: Numurē vietu pogas

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

  1. Maini pogas teksta rindu uz poga.textContent = (i + 1) + ". " + vietas[i]; .
  2. Pārbaudi, ka numerācija sākas ar 1.
Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 35.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Poga nestrādā? Pārbaudi, vai neizdzēsi pēdiņu, iekavu vai elementa id. Salīdzini savu laboto vietu ar sākuma kodu.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
