3.5 Cikli (Loops) un atkārtošanās loģika

Stundas uzdevums: Izstrādāt ciklisku algoritmu, lai automātiski apstrādātu datu masīvus un ģenerētu HTML saturu, izvairoties no manuālas koda pārrakstīšanas.

2.6.1. Pieraksta, lasa un izpilda algoritmus ar cikliskām darbībām; 5.2.1. Problēmrisināšana un optimizācija.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - palaid pirmo for ciklu ar izvadi konsolē · 2. uzdevums (~25 min) - uzģenerē inventāra sarakstu lapā ar ciklu · 3. uzdevums (~20 min) - pārbaudi cikla robežas un salabo undefined. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu 3.4 stundas projektu, kur script.js jau ir masīvs inventars un poga "Pacelt mantu".

Teorija: Automātiskais dzinējs (For cikls) un DOM manipulācija

Vai gribi lapā parādīt 100 ienaidniekus? Tev nav jāraksta 100 koda rindiņas! Lai liktu datoram atkārtot darbību, mēs izmantojam for ciklu. Tas sastāv no trim svarīgām daļām iekavās, kas atdalītas ar semikolu (;):

Daļa Kods (Sintakse) Ko tas nozīmē?
1. Sākums let i = 0; Kur sākam skaitīt? Parasti no 0, jo masīvi sākas ar 0.
2. Nosacījums i < 5; Cik ilgi atkārtosim? (Kamēr i ir mazāks par 5).
3. Solis i++ Ko darām pēc katra apļa? Palielinām i par 1.

Kā tas izskatās kopā:

for (let i = 0; i < 5; i++) {
    console.log("Šis teksts parādīsies 5 reizes!");
}

Saziņa ar HTML lapu (document.getElementById)

Lai JavaScript varētu dinamiski mainīt to, ko lietotājs redz ekrānā, tam ir jāatrod konkrēts HTML elements. Programmēšanā mēs to panākam ar document.getElementById(), kas sameklē elementu pēc tā unikālā id atribūta. Kad elements ir atrasts, varam mainīt tā saturu, izmantojot .innerHTML (ja satur HTML tagus) vai .innerText (tikai tekstam).

1. HTML sagatave:

<!-- Izveidojam elementu ar unikālu identifikatoru (id) -->
<div id="rezultats">Sākotnējais teksts</div>

2. JavaScript rīcība:

// Atrodam elementu un pārrakstām tā saturu
document.getElementById("rezultats").innerHTML = "Sistēma veiksmīgi ielādēta!";

// Apvienojumā ar 'for' ciklu, lai pakāpeniski papildinātu saturu
document.getElementById("rezultats").innerHTML = ""; // Vispirms iztukšojam saturu
for (let i = 1; i <= 3; i++) {
    // Izmantojam += , lai pievienotu jaunu informāciju klāt esošajai
    document.getElementById("rezultats").innerHTML += "Ielādēts modulis " + i + "<br>";
}

Praktiskie uzdevumi

1. uzdevums - Palaid pirmo for ciklu ar izvadi konsolē

Beigās viena koda rinda uzrakstīs konsolē piecas rindiņas ar dažādiem numuriem.

  1. Uzraksti script.js beigās ciklu for (let i = 0; i < 5; i++) { console.log("Aplis " + i); }.
  2. Pārlādē lapu un saskaiti, cik rindu parādījās konsolē.
  3. Nomaini nosacījumā skaitli 5 uz 3 un pārlādē vēlreiz.
  4. Nomaini sākumu uz let i = 1 un nosacījumu uz i <= 3.
  5. Pieraksti, ar kuru skaitli cikls sākās un beidzās katrā no trim variantiem.
  6. Pārbaudi, ka visas trīs cikla daļas iekavās atdala semikols, nevis komats.

Gatavs, kad: pirmajā variantā konsolē ir tieši piecas rindas no "Aplis 0" līdz "Aplis 4".

2. uzdevums - Uzģenerē inventāra sarakstu ar ciklu

Beigās katra tavas somas manta parādīsies kā atsevišķs saraksta punkts lapā.

  1. Pievieno index.html failā elementu <ul id="inventara-saraksts"></ul>.
  2. Uzraksti script.js failā funkciju function zimetSarakstu() { }.
  3. Ieraksti tajā pirmo rindu let saraksts = document.getElementById("inventara-saraksts");.
  4. Pievieno nākamo rindu saraksts.innerHTML = "";, lai vecais saturs netiktu dublēts.
  5. Pievieno ciklu for (let i = 0; i < inventars.length; i++), kas raksta saraksts.innerHTML += "<li>" + inventars[i] + "</li>";.
  6. Izsauc zimetSarakstu(); arī funkcijas paceltMantu() pēdējā rindā.
  7. Nospied pogu "Pacelt mantu" divas reizes.

Gatavs, kad: sarakstā ir tieši tik punktu, cik mantu somā, un pēc pogas nospiešanas tie nedublējas.

3. uzdevums - Pārbaudi cikla robežas un salabo undefined

Beigās tu zināsi, kāpēc cikls masīvā beidzas pirms garuma, nevis pie tā.

  1. Nomaini ciklā nosacījumu uz i <= inventars.length un pārlādē lapu.
  2. Pieraksti, kas parādījās saraksta pēdējā punktā.
  3. Atgriez nosacījumu atpakaļ uz i < inventars.length.
  4. Iztukšo somu konsolē ar inventars = []; zimetSarakstu();.
  5. Atver DevTools sadaļu "Elements" un saskaiti <li> elementus iekš <ul>.
  6. Pieraksti vienu secinājumu: kas notiktu ar pārlūku, ja ciklā aizmirstu i++.

Gatavs, kad: ar <= saraksta beigās parādās "undefined", bet ar < saraksts ir tieši pareizā garumā.

Papildu uzdevums - Ienaidnieku rinda ar bosu beigās

Beigās viens funkcijas izsaukums uzzīmēs lapā piecus ienaidniekus, no kuriem pēdējais ir boss.

  1. Pievieno index.html failā elementu <div id="ienaidnieki"></div>.
  2. Pievieno style.css failā klasi .ienaidnieks { display: inline-block; margin: 4px; padding: 8px; background: #FF5733; color: white; border-radius: 4px; }.
  3. Uzraksti funkciju raditIenaidniekus(skaits), kas vispirms notīra elementu ar innerHTML = "".
  4. Pievieno ciklu, kas skaits reizes pieraksta "<span class='ienaidnieks'>E" + (i + 1) + "</span>".
  5. Pievieno ciklā nosacījumu: ja i === skaits - 1, teksta vietā raksti "BOSS".
  6. Izsauc raditIenaidniekus(5); un atver lapu pārlūkā.

Gatavs, kad: lapā redzami pieci sarkani lauciņi E1, E2, E3, E4 un BOSS.

Biežākās kļūdas (un kā tās labot):

  • Mūžīgais cikls (Infinite Loop): Ja uzrakstīsi i-- (samazināt) vietā i++ (palielināt), nosacījums vienmēr būs patiess. Pārlūks uzkārsies un "iesaldēs" lapu. Rūpīgi pārbaudi cikla soli!
  • Komati semikolu vietā: For cikla iekavās trīs daļas ir jāatdala ar semikolu (;), nevis komatu. for (let i = 0, i < 5, i++) izmetīs kļūdu.
  • Kļūda "undefined" pēdējā aplī: Ja izmantosi i <= masivs.length (mazāks vai vienāds), cikls mēģinās nolasīt neeksistējošu elementu. Indeksi beidzas pirms garuma, tāpēc izmanto tikai < (mazāks).

Koda piemērs (cikls, kas pārzīmē sarakstu bez dublēšanās)

let inventars = ["marķieris", "plāns", "lapiņa"];

function zimetSarakstu() {
    let saraksts = document.getElementById("inventara-saraksts");

    // Bez šīs rindas katrs izsaukums pieliktu sarakstu vēlreiz klāt vecajam
    saraksts.innerHTML = "";

    // i < length, NEVIS i <= length - citādi pēdējais punkts būtu "undefined"
    for (let i = 0; i < inventars.length; i++) {
        saraksts.innerHTML += "<li>" + (i + 1) + ". " + inventars[i] + "</li>";
    }
}

function paceltMantu() {
    inventars.push(prompt("Ko pacēli?"));
    zimetSarakstu(); // pārzīmē sarakstu ar jauno mantu
}

zimetSarakstu();
Lapā ģenerētais saraksts:
  • 1. marķieris
  • 2. plāns
  • 3. lapiņa
Pēc pogas nospiešanas un vārda "atslēga" ievadīšanas parādās ceturtais punkts - bez trim vecajiem dublikātiem.

Ja nosacījumu nomaini uz i <= inventars.length, saraksta beigās parādās lieks punkts "4. undefined".
