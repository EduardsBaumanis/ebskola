3.4 Masīvs: spēlētāja priekšmetu saraksts

Sasniedzamais rezultāts: Izveido spēlētāja priekšmetu masīvu, papildini to ar pogas klikšķi un parādi lapā gan visu sarakstu un skaitu, gan atsevišķi pirmo priekšmetu.

SR 2.6.1. Algoritmu pieraksts un izpilde

Teorija ar piemēriem

Masīvs ([...]), indeksi no 0 un garums .length

Ja spēlē jāglabā vairāki līdzīgi dati — piemēram, uzdevumu saraksts, kartes vietas vai spēlētāja somas priekšmeti — katram neveido atsevišķu mainīgo. Visus vienumus saliek vienā sakārtotā sarakstā jeb masīvā:

const uzdevumi = ["atvērt vārtus", "šķērsot tiltu", "izpētīt torni"];
  • Kvadrātiekavas [ un ] pasaka JavaScript valodai, ka tas ir masīvs (sākumā var izveidot arī tukšu masīvu []).
  • Katru teksta vienumu liek pēdiņās "...", bet vienumus savā starpā atdala ar komatu ,.
  • Katrai vietai masīvā ir savs kārtas numurs jeb indekss, un programmēšanā numerācija vienmēr sākas ar 0!
Indekss (vietas numurs) Pieraksts kodā Nolasītā vērtība
0 (pirmais!) uzdevumi[0] "atvērt vārtus"
1 (otrais) uzdevumi[1] "šķērsot tiltu"
2 (trešais / pēdējais) uzdevumi[2] "izpētīt torni"

Īpašība uzdevumi.length atdod kopējo vienumu skaitu (šajā piemērā 3). Nepārsauc skaitu ar pēdējo indeksu: ja masīvā ir 3 vienumi, to indeksi ir 0, 1 un 2 (tātad pēdējais indekss vienmēr ir uzdevumi.length - 1). Ja pieprasīsi neesošu vietu uzdevumi[3], JavaScript atbildēs ar undefined (“nav definēts”).

Saraksta papildināšana ar .push(...) un atjaunošana lapā

Lai pogas klikšķis sarakstam pievienotu jaunu vienumu un spēlētājs to uzreiz ieraudzītu ekrānā, vajadzīgas divas darbības — masīva papildināšana atmiņā un lapas teksta atjaunošana:

function atjaunotSarakstu() {
  document.getElementById("zurnals").textContent = uzdevumi.join(", ");
  document.getElementById("kopskaits").textContent = "Uzdevumu skaits: " + uzdevumi.length;
}

function pievienotUzdevumu() {
  uzdevumi.push("atrast dārgumus");
  atjaunotSarakstu();
}

atjaunotSarakstu();
  • .push("...") pieliek jaunu vienumu masīva pašās beigās. Ja pogu nospiež divas reizes pēc kārtas, tas pats vienums tiks pievienots divreiz (skaits kļūs 4, tad 5), jo .push(...) automātiski neatmet atkārtojumus.
  • .join(", ") salīmē visus masīva tekstus vienā glītā virknē, starp tiem ieliekot komatu un atstarpi (pats masīvs atmiņā paliek neskarts).
  • Funkciju atjaunotSarakstu() izsauc gan skripta beigās (lai parādītu sākuma datus, tiklīdz lapa atveras), gan pēc katra .push(...).
  • Kāpēc te der const? Atslēgvārds const aizliedz aizstāt visu mainīgo ar pavisam jaunu sarakstu (uzdevumi = [...]), bet jau izveidota masīva saturu papildināt ar .push(...) drīkst.
  • Kas notiek pēc Ctrl+R? Pievienotie vienumi glabājas pārlūka cilnes pagaidu atmiņā, tāpēc lapas pārlāde atgriež sākotnējo sarakstu no faila koda.

Atsevišķa saraksta elementa nolasīšana pēc indeksa

Bieži spēles panelī līdzās pilnajam sarakstam vajag izcelt vienu konkrētu vienumu — piemēram, pašu pirmo uzdevumu, ar kuru viss sākās, vai pašu pēdējo pievienoto ierakstu.

Ja HTML daļā izveidota atsevišķa rindkopa (piemēram, <p id="aktivais"></p>), to atjauno tajā pašā parādīšanas funkcijā, nolasot vērtību pēc indeksa kvadrātiekavās:

document.getElementById("aktivais").textContent = "Sākuma uzdevums: " + uzdevumi[0];

Tā kā .push(...) jaunos vienumus vienmēr pievieno saraksta beigās, pirmā elementa vērtība uzdevumi[0] pēc pogas spiešanas nemainās, savukārt pēdējo vienumu jebkurā brīdī var nolasīt ar uzdevumi[uzdevumi.length - 1].

Pašpārbaude: masīvā sākumā ir 3 vienumi un spēlētājs divreiz nospiež pievienošanas pogu — kāda tagad ir .length vērtība, kāds ir pēdējā vienuma indekss, un vai mainās vienums ar indeksu [0]?

Tagad .length ir 5, pēdējā vienuma indekss ir 4 (jo skaitīšana sākas no 0: 0, 1, 2, 3, 4), bet [0] vērtība nemainās, jo .push(...) jaunos vienumus pievieno saraksta beigās.

1. uzdevums

Izpēti sākuma kodu un izveido 3 sākuma priekšmetu somu

Izmanto teoriju: Masīvs ([...]), indeksi no 0 un garums .length.

Vide: Windows File Explorer → pārlūks → VS Code

  1. Windows mapē Desktop/datorika9-tema3 atver saglabāto 34.html pārlūkā (Open with → Edge) un novēro, ka sākumā somā redzami 2 priekšmeti un poga Paņemt atslēgu.
  2. VS Code failā 34.html nomaini <title> un <h1> uz savas spēles somas vai ekipējuma nosaukumu.
  3. <script> daļas sākumā atrodi masīvu const manta = ["karte", "lukturis"];.
  4. Nomaini un papildini šo sarakstu tā, lai tajā sākumā būtu tieši trīs tavai spēlei piemēroti priekšmeti (piemēram, kompass, virve, burvestību grāmata vai citi paša izdomāti nosaukumi).
  5. Rūpīgi pārbaudi masīva sintaksi: sarakstu aptver kvadrātiekavas [...], katrs priekšmeta nosaukums ir pēdiņās "...", un starp nosaukumiem ir komats ,.
  6. Paredzi, ko tagad parādīs manta.length, saglabā failu ar Ctrl+S, pārlūkā nospied Ctrl+R un pārliecinies, ka uzreiz redzami visi trīs priekšmeti un Priekšmetu skaits: 3.

Gatavs, kad: atverot lapu, somas masīvā ir trīs paša izvēlēti sākuma priekšmeti un skaits rāda 3.

2. uzdevums

Pielāgo priekšmeta pievienošanas pogu un pārbaudi .push(...)

Izmanto teoriju: Saraksta papildināšana ar .push(...) un atjaunošana lapā.

Vide: VS Code → pārlūks

  1. Izdomā vēl vienu jaunu priekšmetu, kuru spēlētājs atradīs un ieliks somā, nospiežot pogu.
  2. Funkcijā pievienot() rindā manta.push("atslēga"); nomaini pēdiņās rakstīto vārdu uz savu jauno priekšmetu, atstājot neskartu nākamo rindu paradit();.
  3. HTML daļā pie <button onclick="pievienot()"> nomaini pogas redzamo tekstu tā, lai spēlētājs zinātu, kuru priekšmetu viņš paņems (saglabā atribūtu onclick="pievienot()").
  4. Saglabā failu ar Ctrl+S, pārlūkā nospied Ctrl+R un pārbaudi, ka redzams jaunais pogas uzraksts un sākuma skaits joprojām ir 3.
  5. Nospied pogu vienu reizi un tad otro reizi — pārliecinies, ka jaunais priekšmets parādās saraksta beigās un skaits secīgi pieaug uz 4 un 5.
  6. Pārlūkā vēlreiz nospied Ctrl+R un novēro, ka pēc pārlādes saraksts atgriežas sākuma stāvoklī ar 3 priekšmetiem.

Gatavs, kad: pogas uzraksts un .push(...) pievienotais priekšmets sakrīt, un katrs klikšķis palielina priekšmetu skaitu par 1.

3. uzdevums

Parādi pirmo priekšmetu ar manta[0] un pārbaudi darbību

Izmanto teoriju: Atsevišķa saraksta elementa nolasīšana pēc indeksa.

Vide: VS Code → pārlūks (ar F12 Console)

  1. HTML daļā blokā <div class="panelis"> starp <p id="soma"></p> un <p id="skaits"></p> pievieno jaunu tukšu rindkopu <p id="pirmais"></p>.
  2. <script> daļas funkcijā paradit() zem komentāra // === 3. UZDEVUMS ... === pievieno rindu, kas elementam ar id="pirmais" īpašībā .textContent ieraksta paskaidrojošu sākumu un pirmo masīva vienumu manta[0].
  3. Pirms atjauno pārlūku, pēc sava masīva pieraksta paredzi, kuram tieši priekšmetam jāparādās šajā rindkopā.
  4. Saglabā ar Ctrl+S, pārlūkā nospied Ctrl+R un pārbaudi sākuma stāvokli: pilnajā sarakstā ir 3 priekšmeti, skaits ir 3, un rindkopa id="pirmais" nosauc tieši pašu pirmo priekšmetu.
  5. Nospied pievienošanas pogu divas reizes un pārliecinies, ka priekšmetu skaits kļūst 5, saraksta beigās ir divi jaunie priekšmeti, bet pirmā priekšmeta rinda joprojām rāda to pašu manta[0].
  6. Pārlūkā atver F12 → Console un pārbaudi, ka nav nevienas sarkanas kļūdas; ja nepieciešams, izlabo kodu un saglabā gala versiju ar Ctrl+S.

Gatavs, kad: lapa parāda pilno somas sarakstu, pirmo priekšmetu ar manta[0] un precīzu skaitu (sākumā 3, pēc diviem klikšķiem 5), un konsolē nav kļūdu.

Papildu uzdevums: Parādi arī pēdējo somā ielikto priekšmetu

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Garums .length un pēdējais indekss un Elementa nolasīšana pēc indeksa.

  1. HTML blokā <div class="panelis"> zem <p id="pirmais"></p> pievieno vēl vienu tukšu rindkopu <p id="pedejais"></p>.
  2. Funkcijā paradit() pievieno rindu, kas elementā id="pedejais" ar .textContent parāda pēdējo masīva vienumu manta[manta.length - 1].
  3. Saglabā ar Ctrl+S, pārlūkā nospied Ctrl+R un pārliecinies, ka sākumā kā pēdējais redzams trešais sākuma priekšmets.
  4. Nospied pievienošanas pogu un pārbaudi, ka pirmā priekšmeta rinda nemainās, bet pēdējā priekšmeta rinda uzreiz parāda tikko paņemto lietu.

Gatavs, kad: lapa vienlaikus pareizi rāda gan pirmo (manta[0]), gan pēdējo (manta[manta.length - 1]) priekšmetu gan sākumā, gan pēc pogas klikšķa.

Ja kaut kas neizdodas
  • Pirmā priekšmeta vietā rādās otrais vai uzraksts undefined? Atceries, ka masīva indeksācija sākas no nulles: pirmais vienums ir manta[0], bet manta[1] jau ir otrais! Savukārt undefined parādās tad, ja kvadrātiekavās norādīts indekss ārpus saraksta robežām (piemēram, manta[manta.length] bez - 1).
  • Nospiežot pogu, nekas nemainās? Pārbaudi funkciju pievienot(): vai aiz manta.push(...) joprojām ir izsaukums paradit(); ar iekavām () un vai pogai nav izdzēsts onclick="pievienot()".
  • Lapa rādās tukša un F12 → Console parāda sarkanu kļūdu? Ja redzi SyntaxError, pārbaudi masīva const manta = [...] rindu — vai ap katru vārdu ir abas pēdiņas un starp vārdiem komats. Ja redzi Cannot set properties of null, pārbaudi, vai HTML daļā esi pievienojis <p id="pirmais"></p> ar precīzi tādu pašu id.
  • Neredzi savas izmaiņas pārlūkā? VS Code nospied Ctrl+S un pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši Desktop/datorika9-tema3/34.html.
  • Kods pārlūkā redzams kā parasts teksts? Saglabā ar galotni .html. Windows File Explorer ieslēdz View → Show → File name extensions un pārbaudi, ka faila beigās nav .txt.
