3.4 Masīvi (Arrays) un datu strukturēšana

Tavs šīs stundas izaicinājums: Pielietot masīvus, lai organizētu, saglabātu un atjauninātu vairākus saistītus spēles elementus (inventāru un rezultātus) vienuviet, veidojot interaktīvu datu bāzi.

2.6.1. Izmanto atbilstošas vienkāršas datu struktūras; 2.4.2. Strukturē datus, izvēloties racionālākos paņēmienus.
SR 2.4.3. Datu attēlošanas veidi

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — izveido inventāra masīvu un nolasi elementus pēc indeksa · 2. uzdevums (~25 min) — parādi inventāru lapā un pievieno mantu ar .push() · 3. uzdevums (~20 min) — izmet mantu ar .pop() un apstrādā tukšu somu. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu projektu ar index.html un script.js un pārlūka konsoli (F12). Šajā stundā vēl neizmanto ciklus — tos apgūsi 3.5 stundā.

Teorija: Datu vilciens (Masīvi)

Mainīgais ir kā viena kaste. Bet ko darīt, ja klasei ir projekta materiālu saraksts ar 10 lietām? Mēs izmantojam masīvu (Array) – tas ir kā vilciens, kur katrā vagonā ir savs saturs. Programmēšanā vagonus (indeksus) sāk skaitīt no 0!

Darbība Kods (Sintakse) Skaidrojums
Izveidot let soma = ["Koks", "Akmens"]; Izmanto kvadrātiekavas [ ] un komatus.
Izlasīt (Indekss) console.log( materiali[0] ); Dabū pirmo elementu ("Marķieris").
Pievienot materiali.push("Uzlīmes"); Pieliek jaunu vagonu vilciena beigās.
Saskaitīt materiali.length Pasaka, cik elementu kopā ir masīvā.

Praktiskie uzdevumi

1. uzdevums — Izveido inventāra masīvu un nolasi tā elementus

Beigās konsole pēc indeksa parādīs jebkuru priekšmetu no tavas spēles somas.

  1. Uzraksti script.js augšā rindu let inventars = ["marķieris", "plāns", "lapiņa"];.
  2. Pievieno zem tās rindu console.log(inventars[0]); un pārlādē lapu.
  3. Nomaini indeksu no [0] uz [2] un pārlādē vēlreiz.
  4. Pievieno rindu console.log(inventars.length); un pārlādē.
  5. Ieraksti konsolē inventars[3] un nolasi atbildi.
  6. Pieraksti, kāpēc trešais indekss neatgriež nevienu priekšmetu.

Gatavs, kad: konsolē redzams "lapiņa", skaitlis 3 un atbilde undefined uz inventars[3].

2. uzdevums — Parādi inventāru lapā un pacel jaunu mantu

Beigās poga "Pacelt mantu" pievienos priekšmetu somai, un saraksts lapā uzreiz atjaunosies.

  1. Pievieno index.html failā elementu <p id="inventars-parads"></p>.
  2. Uzraksti funkciju paraditInventaru(), kas šajā elementā ieraksta inventars.join(", ").
  3. Izsauc paraditInventaru(); faila pēdējā rindā un pārlādē lapu.
  4. Pievieno pogu <button onclick="paceltMantu()">Pacelt mantu</button>.
  5. Uzraksti funkciju function paceltMantu() { let manta = prompt("Ko pacēli?"); inventars.push(manta); paraditInventaru(); }.
  6. Nospied pogu un ievadi vārdu atslēga.
  7. Pārbaudi konsolē inventars.length.

Gatavs, kad: lapā redzams "marķieris, plāns, lapiņa, atslēga" un garums ir 4.

3. uzdevums — Izmet mantu un apstrādā tukšu somu

Beigās tukša soma rādīs saprotamu paziņojumu, nevis tukšu rindu lapā.

  1. Ieraksti konsolē inventars.pop(); paraditInventaru(); un pieraksti, kurš priekšmets pazuda.
  2. Ieraksti inventars[0] un inventars[inventars.length - 1].
  3. Pieraksti, kāpēc pēdējais elements ir length - 1, nevis length.
  4. Iztukšo somu konsolē ar inventars = []; paraditInventaru();.
  5. Pievieno funkcijā nosacījumu: ja inventars.length === 0, ieraksti tekstu "Soma ir tukša".
  6. Pieraksti vienu secinājumu: kāpēc viens masīvs ir ērtāks nekā trīs atsevišķi mainīgie.

Gatavs, kad: pēc somas iztukšošanas lapā redzams "Soma ir tukša", nevis tukša vieta.

Papildu uzdevums — Labākais rezultāts no rezultātu masīva

Beigās lapa rādīs augstāko rezultātu no visiem sakrātajiem punktu ierakstiem.

  1. Pievieno script.js rindu let rezultati = [12, 45, 30];.
  2. Pievieno index.html failā elementu <p id="labakais"></p>.
  3. Uzraksti funkciju paraditLabako(), kas ieraksta tajā Math.max(...rezultati).
  4. Izsauc to un pārbaudi, ka lapā parādās 45.
  5. Ieraksti konsolē rezultati.push(70); paraditLabako();.
  6. Pievieno funkcijā nosacījumu tukšam masīvam ar tekstu "Vēl nav rezultātu".

Gatavs, kad: lapā redzams "Labākais: 70", bet pēc rezultati = [] — "Vēl nav rezultātu", nevis -Infinity.

Biežākās kļūdas (un kā tās labot):

  • Nobīde par viens (Off-by-one error): Mēģinot dabūt pirmo elementu ar masivs[1]. Atceries: pirmā elementa numurs ir 0!
  • Neatrodams elements (undefined): Ja masīvā ir 3 lietas (indeksi 0, 1, 2) un tu prasi masivs[3], JavaScript atbildēs ar "undefined", jo ceturtā vagona nav.
  • Kvadrātiekavu sajaukšana ar figūriekavām: Masīvi izmanto [ ], nevis { }. Figūriekavas kalpo objektu izveidei un funkciju blokiem.

Koda piemērs (masīva pārzīmēšana lapā pēc push un pop)

let inventars = ["marķieris", "plāns", "lapiņa"];

function paraditInventaru() {
    let vieta = document.getElementById("inventars-parads");

    // Bez šī nosacījuma tukša soma lapā izskatītos kā pazudusi rinda
    if (inventars.length === 0) {
        vieta.textContent = "Soma ir tukša";
        return;
    }

    vieta.textContent = inventars.join(", ");   // saliek visus elementus vienā tekstā
}

function paceltMantu() {
    let manta = prompt("Ko pacēli?");
    inventars.push(manta);        // pievieno somas beigās
    paraditInventaru();           // OBLIGĀTI pārzīmē lapu, citādi izmaiņas nav redzamas
}

// Pēdējais elements vienmēr ir length - 1, nevis length!
console.log("Pēdējā manta: " + inventars[inventars.length - 1]); // lapiņa
console.log(inventars[3]); // undefined — ceturtā vagona nav

paraditInventaru();
Lapā sākumā parādās marķieris, plāns, lapiņa.

Pēc pogas nospiešanas un vārda "atslēga" ievadīšanas rinda kļūst par marķieris, plāns, lapiņa, atslēga.

Ja konsolē izpildi inventars = []; paraditInventaru();, lapā parādās Soma ir tukša.

Ja aizmirsti izsaukt paraditInventaru(), masīvs mainās, bet lapa rāda veco sarakstu.
