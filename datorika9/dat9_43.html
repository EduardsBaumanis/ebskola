4.3 DOM manipulācija – dinamiska elementu pārvaldība

Stundas uzdevums: Izstrādāt algoritmu spēles varoņa vizuālai pārvietošanai pa ekrānu, mainot tā CSS koordinātas reāllaikā caur JavaScript.

2.6.1. Pieraksta, lasa un izpilda algoritmus; 2.4.7. Veido kompleksu pieeju (apvieno CSS un JS).

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - pārvieto kvadrātu ar gatavu koda rindu · 2. uzdevums (~25 min) - uzraksti funkciju kustinat(dx, dy) un četras pogas · 3. uzdevums (~20 min) - salīdzini koordinātes konsolē un pievieno robežas. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu 4.2 stundas projektu ar spēles laukumu #laukums un spēlētāju #speletajs koda redaktorā un pārlūkā.

Teorija: Tīmekļa koordinātu sistēma un CSS pozicionēšana

Lai mēs varētu kustināt elementu (piemēram, spēlētāja kvadrātu vai attēlu) ar JavaScript, tam HTML/CSS vidē ir jābūt "atrautam" no parastās teksta plūsmas.

  • CSS Position: Elementam jāpiešķir position: absolute; (kustas attiecībā pret savu rāmi) vai position: fixed; (kustas attiecībā pret visu logu). Tā vecākam (spēles laukumam) jābūt position: relative;.
  • Koordinātas: Tīmeklī X ass iet no kreisās uz labo (kā matemātikā), bet Y ass iet no augšas uz leju! (0,0 ir augšējais kreisais stūris).
  • JS manipulācija: Mēs varam mainīt elementa pozīciju, mainot tā style.left (X) un style.top (Y) īpašības. Svarīgi: tām vienmēr jāpievieno teksta mērvienība "px"!

Praktiskie uzdevumi

1. uzdevums - Pārvieto kvadrātu ar gatavu koda rindu

Beigās kvadrāts pārlēks uz laukuma vidu, kad nospiedīsi pogu.

Kopējamais paraugs: viena poga HTML failā un divas style rindas JavaScript failā.

<button id="lektPoga">Pārlec uz vidu</button>
const speletajs = document.getElementById("speletajs");

document.getElementById("lektPoga").addEventListener("click", function () {
  speletajs.style.left = "180px";
  speletajs.style.top = "130px";
});
  1. Atver index.html un pievieno pogu zem spēles laukuma.
  2. Atver script.js un ielīmē gatavo kodu faila beigās.
  3. Saglabā, pārlādē lapu un nospied pogu - kvadrāts pārlec uz laukuma vidu.
  4. Nomaini vērtību "130px" uz "10px" un pārlādē lapu.
  5. Nospied pogu vēlreiz un vēro, uz kuru pusi kvadrāts pārvietojas.
  6. Pieraksti, vai mazāka top vērtība nozīmē augstāk vai zemāk.

Gatavs, kad: ar top: 10px kvadrāts atrodas pie laukuma augšmalas, nevis pie apakšmalas.

2. uzdevums - Uzraksti funkciju kustinat(dx, dy) un četras pogas

Beigās četras pogas pārvietos kvadrātu pa visām četrām debespusēm.

  1. Pārbaudi, ka laukumam ir position: relative; un spēlētājam position: absolute;.
  2. Atver script.js un uzraksti divus mainīgos: let spX = 180; un let spY = 250;.
  3. Uzraksti funkciju kustinat(dx, dy), kas pieskaita dx pie spX un dy pie spY.
  4. Pievieno funkcijas beigās speletajs.style.left = spX + "px"; un speletajs.style.top = spY + "px";.
  5. Atver index.html un pievieno četras pogas: "Pa kreisi", "Pa labi", "Augšup", "Lejup".
  6. Piesaisti pogām izsaukumus kustinat(-10, 0), kustinat(10, 0), kustinat(0, -10) un kustinat(0, 10).

Gatavs, kad: ar četrām pogām kvadrātu var aizvest uz jebkuru laukuma stūri.

3. uzdevums - Salīdzini koordinātes konsolē un pievieno robežas

Beigās konsolē redzamie skaitļi vienmēr sakritīs ar kvadrāta vietu laukumā.

  1. Atver izstrādātāja rīkus ar F12 un pārej uz cilni Console.
  2. Pievieno funkcijai kustinat rindu console.log("X: " + spX + ", Y: " + spY);.
  3. Nospied pogu "Pa labi" piecas reizes un salīdzini konsoles skaitli ar kvadrāta vietu ekrānā.
  4. Pievieno robežas pa X: ja spX < 0, iestati 0; ja spX > 360, iestati 360.
  5. Pievieno tādas pašas robežas pa Y starp 0 un 260.
  6. Pieraksti vienu secinājumu: kas notiek ar kustību, ja pie style.top vērtības aizmirst pievienot "px".

Gatavs, kad: konsolē redzamās koordinātes paliek robežās 0–360 pa X un 0–260 pa Y.

Papildu uzdevums - Novieto monētu nejaušā vietā

Beigās zeltainā monēta pēc katras lapas pārlādes parādīsies citā laukuma vietā.

  1. Pievieno laukuma iekšpusē <div id="moneta" style="position:absolute;width:20px;height:20px;background:gold;border-radius:50%;"></div>.
  2. Atver script.js un uzraksti funkciju parvietotMonetu().
  3. Aprēķini funkcijā nejaušu X vērtību ar Math.floor(Math.random() * 380).
  4. Aprēķini nejaušu Y vērtību ar Math.floor(Math.random() * 280) un piešķir abas ar "px".
  5. Izsauc parvietotMonetu() faila beigās un pārlādē lapu piecas reizes.
  6. Veic git commit -m "Add collectable coin element".

Gatavs, kad: pēc katras pārlādes monēta ir citā vietā, bet vienmēr paliek laukuma iekšpusē.

Biežākās kļūdas (un kā tās labot):

  • Varonis nekustas vispār: Visbiežāk aizmirsts position: absolute; CSS failā. Bez tā left un top īpašības vienkārši nedarbojas.
  • Kļūda "px" pievienošanā: Ja JS failā ierakstīsi varonisObj.style.left = varonisX; (bez + "px"), pārlūks to nesapratīs. Skaitlim obligāti jāpievieno teksta mērvienība.
  • Y ass pārpratumi: Atceries, lai varonis "lektu" uz augšu (ArrowUp), tev Y koordināta ir jāsamazina, nevis jāpalielina!

Koda piemērs (abu asu robežas un "px" pievienošana)

let spX = 180;
let spY = 250;
const speletajs = document.getElementById("speletajs");

function kustinat(dx, dy) {
    // 1. Mainām koordinātas
    spX = spX + dx;
    spY = spY + dy;

    // 2. Robežas (laukums 400x300, kvadrāts 40x40)
    if (spX < 0)   spX = 0;
    if (spX > 360) spX = 360;
    if (spY < 0)   spY = 0;     // 0 ir laukuma AUGŠA, ne apakša!
    if (spY > 260) spY = 260;

    // 3. Vizuālā atjaunināšana - bez "px" pārlūks vērtību ignorē
    speletajs.style.left = spX + "px";
    speletajs.style.top  = spY + "px";

    console.log("X: " + spX + ", Y: " + spY);
}

kustinat(10, 0);    // pa labi
kustinat(0, -10);   // AUGŠUP - Y kļūst mazāks
kustinat(0, 999);   // mēģina lejup, bet apstājas pie 260
Konsolē:
X: 190, Y: 250
X: 190, Y: 240
X: 190, Y: 260

Ekrānā: kvadrāts pārvietojas pa labi, tad par 10 pikseļiem uz augšu, un pēdējā izsaukumā apstājas tieši pie laukuma apakšmalas, nevis izlien ārā.
