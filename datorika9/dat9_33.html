3.3 Loģiskie operatori un sazarojumi (If/Else)

Stundas uzdevums: Analizēt spēles stāvokli un izstrādāt algoritma sazarojumus, lai programma spētu patstāvīgi pieņemt lēmumus un reaģēt uz dažādām spēlētāja situācijām.

2.6.1. Lasa un izpilda algoritmus ar sazarojumiem; 5.2.1. Kritiskā domāšana problēmu risināšanā.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — palaid pirmo if/else bloku ar punktu pārbaudi · 2. uzdevums (~25 min) — uzraksti funkciju parbauditStavokli(), kas maina statusa tekstu lapā · 3. uzdevums (~20 min) — pārbaudi zaru secību pie 0 dzīvībām. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu projektu ar index.html un script.js, kur jau ir mainīgie punkti, dzivibas un poga "Pievienot punktus".

Teorija: Kā dators pieņem lēmumus?

Dators nesaprot vārdu "varbūt". Tas atpazīst tikai divus stāvokļus: true (patiess) un false (aplams). Lai spēle pati saprastu, vai spēlētājs ir uzvarējis, mēs izmantojam If/Else (Ja/Citādi) blokus un operatorus.

Kods Ko tas dara? Piemērs spēlē
=== Precīzi vienāds (Svarīgi: trīs vienādības zīmes!) dzivibas === 0 (Vai esi miris?)
!== Nav vienāds atslega !== true (Nav atslēgas?)
> un < Lielāks / Mazāks punkti > 100
&& UN (Abiem nosacījumiem jāizpildās) punkti > 50 && laiks > 0
|| VAI (Vismaz vienam jāizpildās) dzivibas === 0 || laiks === 0

Pareizais rakstības stils (Sintakse):

if (punkti >= 100) {
    console.log("Uzvara!"); // Notiks tikai tad, ja nosacījums ir TRUE
} else {
    console.log("Turpini cīnīties!"); // Notiks visos citos gadījumos (FALSE)
}

Praktiskie uzdevumi

1. uzdevums — Palaid pirmo if/else pārbaudi ar punktiem

Beigās konsole pati pateiks, vai spēlētājs jau ir sakrājis vajadzīgos 100 punktus.

  1. Atver script.js un iestati faila augšā let punkti = 40;.
  2. Uzraksti zem tā bloku if (punkti >= 100) { console.log("Uzvara!"); } else { console.log("Turpini!"); }.
  3. Pārlādē lapu un nolasi konsoles ziņojumu.
  4. Nomaini punktu vērtību uz 100 un pārlādē vēlreiz.
  5. Nomaini nosacījumā >= uz > un pārlādē trešo reizi.
  6. Pieraksti, kurš ziņojums tagad parādās tieši pie 100 punktiem.

Gatavs, kad: ar >= konsole pie 100 punktiem rāda "Uzvara!", bet ar > — "Turpini!".

2. uzdevums — Uzraksti funkciju parbauditStavokli()

Beigās lapā būs statusa rindiņa, kas pati maina tekstu atkarībā no punktiem un dzīvībām.

  1. Pievieno index.html failā elementu <p id="statuss"></p>.
  2. Uzraksti script.js failā tukšu funkciju function parbauditStavokli() { }.
  3. Ieraksti tajā pirmo zaru: if (dzivibas <= 0) — statuss kļūst "Spēle beigusies!".
  4. Pievieno otro zaru: else if (punkti >= 100) — statuss kļūst "Uzvara!".
  5. Pievieno trešo zaru: else — statuss kļūst "Turpinās. Punkti: " + punkti.
  6. Izsauc parbauditStavokli(); funkcijas pievienotPunktus() pēdējā rindā.
  7. Nospied pogu "Pievienot punktus", līdz punkti sasniedz 100.

Gatavs, kad: statusa rindiņa lapā pati nomainās no "Turpinās" uz "Uzvara!", tiklīdz punkti sasniedz 100.

3. uzdevums — Pārbaudi, kurš zars nostrādā pirmais

Beigās tu zināsi, kāpēc zaru secība maina spēles rezultātu pie 0 dzīvībām.

  1. Ieraksti konsolē punkti = 0; dzivibas = 3; parbauditStavokli(); un nolasi statusu.
  2. Ieraksti punkti = 150; dzivibas = 0; parbauditStavokli(); un nolasi statusu vēlreiz.
  3. Pieraksti, kurš no diviem zariem nostrādāja, kaut arī abi nosacījumi bija patiesi.
  4. Pievieno funkcijā jaunu zaru else if (dzivibas === 1) ar tekstu "Pēdējā dzīvība!".
  5. Pārbaudi to ar dzivibas = 1; parbauditStavokli();.
  6. Pieraksti vienu secinājumu: kāpēc drošāk rakstīt dzivibas <= 0 nekā dzivibas === 0.

Gatavs, kad: pie 150 punktiem un 0 dzīvībām lapā redzams "Spēle beigusies!", nevis "Uzvara!".

Papildu uzdevums — Laika beigu nosacījums ar taimeri

Beigās spēle beigsies arī tad, kad taimeris noskaitīs līdz nullei.

  1. Pievieno script.js augšā rindu let laiks = 5;.
  2. Pievieno index.html failā elementu <p id="taimeris">Laiks: 5</p>.
  3. Pievieno pogu <button onclick="pagajaSekunde()">Pagāja sekunde</button>.
  4. Uzraksti funkciju function pagajaSekunde() { laiks--; document.getElementById("taimeris").textContent = "Laiks: " + laiks; parbauditStavokli(); }.
  5. Pievieno funkcijai parbauditStavokli() zaru else if (laiks <= 0) ar tekstu "Laiks beidzies!".
  6. Nospied pogu piecas reizes pēc kārtas.

Gatavs, kad: pēc piektā klikšķa statusa rindiņa rāda "Laiks beidzies!".

Biežākās kļūdas (un kā tās labot):

  • Vienas = zīmes izmantošana pārbaudē: Ja rakstīsi if (parole = "777"), kods nevis pārbaudīs, bet gan nomainīs paroli un vienmēr atļaus ieeju. Vienmēr izmanto ===!
  • Aizmirstas figūriekavas {}: Katram if, else if un else blokam ir nepieciešamas savas figūriekavas.
  • Nepareiza secība else if blokos: Vienmēr sāc pārbaudi no visstingrākā/lielākā nosacījuma (piem. > 1000) uz mazāko. Dators lasa kodu no augšas uz leju!

Koda piemērs (zaru pareiza secība funkcijā parbauditStavokli())

let punkti = 150;
let dzivibas = 0;

function parbauditStavokli() {
    let statuss = document.getElementById("statuss");

    // SVARĪGI: vissvarīgākais nosacījums vienmēr ir PIRMAIS.
    // Ja "Uzvara!" būtu augšā, spēlētājs uzvarētu pat bez dzīvībām.
    if (dzivibas <= 0) {            // <= 0, nevis === 0: pasargā arī no -1
        statuss.textContent = "Spēle beigusies!";
    } else if (punkti >= 100) {     // === salīdzina, = piešķir vērtību!
        statuss.textContent = "Uzvara!";
    } else if (dzivibas === 1) {
        statuss.textContent = "Pēdējā dzīvība!";
    } else {
        statuss.textContent = "Turpinās. Punkti: " + punkti;
    }
}

parbauditStavokli();
Ar punkti = 150 un dzivibas = 0 lapā parādās Spēle beigusies! — pirmais patiesais zars apstādina pārējos.

Ar dzivibas = 3 tas pats kods rāda Uzvara!, bet ar punkti = 40 — Turpinās. Punkti: 40.

Ja kļūdas pēc uzraksti if (dzivibas = 0) ar vienu vienādības zīmi, dzīvības tiek pārrakstītas uz 0 un spēle beidzas uzreiz.
