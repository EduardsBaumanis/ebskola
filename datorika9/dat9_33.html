3. tēma / 3.3

3.3 Nosacījumi: kad spēlētājs uzvar?

Sasniedzamais rezultāts: Izveido punktu pārbaudi ar if / else if / else, kas atpazīst negatīvu ievadi, parāda trūkstošos punktus līdz mērķim un paziņo par uzvaru.

SR 2.6.1. Algoritmu pieraksts un izpilde SR 2.6.2. Algoritma pārbaude

Teorija ar piemēriem

Salīdzināšana un divi nosacījuma zari (if / else)

Spēlei ir jāprot pieņemt lēmumu atkarībā no skaitļa lieluma. JavaScript nosacījums apaļajās iekavās aiz vārda if (“ja”) uzdod jautājumu, uz kuru ir tikai divas iespējamas atbildes: true (patiess) vai false (aplams).

if (energija >= 15) {
  zina = "Vārti atvērti!";
} else {
  zina = "Vēl trūkst enerģijas.";
}
  • Ja salīdzinājums iekavās ir true, izpildās kods pirmajās figūriekavās { ... } aiz if.
  • Ja salīdzinājums ir false, programma pāriet uz else (“citādi”) zaru. Ievēro: aiz else vairs neraksta apaļās iekavas ar nosacījumu, jo else uztver visus atlikušos gadījumus!
Pieraksts Nozīme Piemērs, kad rezultāts ir true
>= Lielāks vai vienāds (ietver arī pašu robežu) 15 >= 15 un 18 >= 15
> Stingri lielāks (robežas skaitlis neder!) 16 > 15 (bet 15 > 15 ir false)
< Stingri mazāks (noder negatīvu skaitļu ķeršanai) -2 < 0
<= Mazāks vai vienāds 0 <= 0
=== Precīzi vienāds (trīs vienādības zīmes!) 15 === 15 vai "Pils" === "Pils"

Svarīgi: salīdzināšanai nekad neizmanto vienu vienādības zīmi =! Viena = piešķir jaunu vērtību mainīgajam, bet vienādību pārbauda ar === (vai ar robežzīmēm >= un <=). Tāpat ievēro, ka skaitļa laukā <input type="number"> bez min="0" lietotājs var ierakstīt arī negatīvu skaitli (piemēram, -3).

Vairāki gadījumi pēc kārtas (if / else if / else) un secības nozīme

Kad ar diviem iznākumiem nepietiek, starp if un else var pievienot vienu vai vairākus else if (...) (“citādi, ja”) zarus. Apskati piemēru ar varoņa enerģiju, kur mērķis ir sakrāt vismaz 15 vienības:

let zina = "";

if (energija < 0) {
  zina = "Kļūda: enerģija nevar būt negatīva!";
} else if (energija >= 15) {
  zina = "Vārti atvērti! Vari doties tālāk.";
} else {
  const pietrukst = 15 - energija;
  zina = "Turpini meklēt! Vēl pietrūkst: " + pietrukst;
}

Kā darbojas šī nosacījumu ķēde?

  1. JavaScript pārbauda nosacījumus stingri no augšas uz leju.
  2. Tiklīdz pirmais no nosacījumiem izrādās true, izpildās tā { ... } bloks, un visi pārējie šīs ķēdes zari tiek izlaisti. Tāpēc par vienu ievadi vienmēr tiek izvēlēta tieši viena ziņa.
  3. Ja nākotnē pievieno vēl augstāku sasniegumu (piemēram, superjaudu pie energija >= 50), tas obligāti jāraksta pirms energija >= 15. Pretējā gadījumā skaitlis 50 jau atbildīs nosacījumam >= 15 un līdz zemākajam zaram nekad netiks!
  4. Katram zaram (if, else if, else) ir savs figūriekavu pāris { un }, un vēl viens ārējais pāris aptver visu function ...() { ... }.

Robežvērtību pārbaude: kā pārliecināties, ka visi zari strādā

Ja pārbaudi savu kodu tikai ar vienu nejaušu skaitli (piemēram, 40), viegli nepamanīt kļūdu uz pašas robežas — piemēram, uzrakstītu > zīmes >= vietā. Tāpēc programmēšanā izmanto robežvērtību testēšanu: pārbauda skaitļus tieši uz robežas un par vienu vienību abās pusēs.

Testa ievade Kurš zars nostrādā? Ko šī pārbaude atklāj?
-1 if (energija < 0) Vai pirmais negatīvais skaitlis tiek atpazīts kā kļūda.
0 else (pietrūkst 15) Vai nulle netiek kļūdaini uzskatīta par negatīvu skaitli.
14 else (pietrūkst 1) Vai skaitlis tieši zem mērķa (15 - 1) prasa turpināt.
15 else if (energija >= 15) Vai sasniegtā robeža jau dod uzvaru (atklāj > kļūdu!).
16 else if (energija >= 15) Vai darbojas arī skaitļi virs mērķa (15 + 1).

Kad maini mērķa skaitli JavaScript kodā, vienmēr atjauno arī noteikumu rindkopu HTML lapā, lai spēlētājs redzētu patieso uzvaras slieksni.

Pašpārbaude: kāpēc ar nosacījumu energija > 15 pie ievades 15 parādās ziņa par trūkstošo enerģiju, un vai pie ievades -1 izpildās arī beigu else zars?

1) Izteiksme 15 > 15 ir false (15 nav stingri lielāks par 15), tāpēc programma nokļūst else zarā; lai iekļautu pašu robežu, vajag >=. 2) Pie -1 izpildās jau pirmais if (energija < 0) zars, un vienā if / else if / else ķēdē pārējie zari pēc tam tiek izlaisti.

1. uzdevums

Izmēģini divu zaru robežu un atrodi sākuma koda nepilnību

Izmanto teoriju: Salīdzināšana un divi nosacījuma zari (if / else).

Vide: Windows File Explorer → pārlūks → VS Code

  1. Windows mapē Desktop/datorika9-tema3 atver saglabāto 33.html pārlūkā (Open with → Edge) un salīdzini redzamo formu ar sākuma koda funkciju parbaudit().
  2. Laukā Punkti ievadi 9, paredzi iznākumu pēc nosacījuma punkti >= 10, nospied Pārbaudīt un pārliecinies, ka parādās Turpini spēli!.
  3. Ievadi tieši robežas skaitli 10, nospied Pārbaudīt un pārliecinies, ka ziņa nomainās uz Uzvara!.
  4. Tagad ievadi negatīvu skaitli -3 un nospied Pārbaudīt — pamani nepilnību: esošais divu zaru kods negatīvus punktus neatšķir no parastas spēles un rāda Turpini spēli!.
  5. VS Code failā 33.html nomaini <title>, <h1> un <label for="skaits"> uz savai spēlei piemērotiem uzrakstiem, atstājot neskartus id="skaits", id="atbilde" un pogas onclick="parbaudit()".
  6. Saglabā failu ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka redzami jaunie uzraksti un poga joprojām darbojas.

Gatavs, kad: esi pārbaudījis sākuma robežu 10, pamanījis negatīvās ievades nepilnību un pielāgojis lapas virsrakstu savai spēlei.

2. uzdevums

Izveido trīs zaru pārbaudi ar if / else if / else

Izmanto teoriju: Vairāki gadījumi pēc kārtas (if / else if / else) un secības nozīme.

Vide: VS Code → pārlūks

  1. <script> daļas funkcijā parbaudit() atrodi nosacījumu bloku zem komentāra // === 2. un 3. UZDEVUMS — MAINI ŠEIT ... ===.
  2. Uzraksti pirmo zaru if (punkti < 0) { ... }, kurā mainīgajam zina piešķir brīdinājumu par negatīviem punktiem (piemēram, "Kļūda: punkti nevar būt negatīvi!").
  3. Uzreiz aiz pirmā zara aizverošās figūriekavas } pievieno otro zaru else if (punkti >= 10) { ... }, kurā zina saņem uzvaras paziņojumu "Uzvara!".
  4. Noslēdz ķēdi ar trešo zaru else { ... } (bez apaļajām nosacījuma iekavām!), kurā zina saņem tekstu "Turpini spēli!".
  5. Pārskati figūriekavu pārus: katram no trim zariem jābūt savām { un }, un aiz rindas document.getElementById("atbilde").textContent = zina; jāpaliek noslēdzošajai } visai funkcijai parbaudit().
  6. Saglabā failu ar Ctrl+S, pārlūkā nospied Ctrl+R un secīgi pārbaudi visus trīs zarus ar vērtībām -3, 9 un 10.

Gatavs, kad: if / else if / else ķēde pārlūkā pareizi nodala negatīvu ievadi, turpināšanu un uzvaru.

3. uzdevums

Nomaini uzvaras mērķi uz 20 un pārbaudi robežvērtības

Izmanto teoriju: Robežvērtību pārbaude: kā pārliecināties, ka visi zari strādā.

Vide: VS Code → pārlūks (ar F12 Console)

  1. Funkcijā parbaudit() otrajā zarā nomaini uzvaras slieksni no 10 uz 20 (else if (punkti >= 20)).
  2. HTML daļā tieši zem <h1> virsraksta (komentāra vietā virs <div class="panelis">) pievieno rindkopu <p id="noteikumi">, kurā skaidri norādi spēlētājam, ka uzvarai nepieciešami vismaz 20 punkti.
  3. Pielāgo visas trīs zina atbildes savai spēlei, turklāt else zarā aprēķini arī atlikušos punktus ar 20 - punkti un iekļauj šo skaitli turpināšanas ziņā.
  4. Saglabā failu ar Ctrl+S un pārlūkā nospied Ctrl+R, lai lapā parādītos jaunie noteikumi.
  5. Pārbaudi nulles robežu abās pusēs: ievadi -1 (jāparādās negatīvu punktu brīdinājumam) un 0 (jāparādās turpināšanas ziņai, kur līdz mērķim pietrūkst 20).
  6. Pārbaudi uzvaras robežu abās pusēs: ievadi 19 (turpināšanas ziņa — pietrūkst 1), tad 20 (uzvaras paziņojums!) un 21 (uzvaras paziņojums!).
  7. Pārlūkā atver F12 → Console un pārbaudi, ka nav nevienas sarkanas kļūdas; ja nepieciešams, izlabo kodu un saglabā gala versiju ar Ctrl+S.

Gatavs, kad: gan lapas noteikumos, gan kodā uzvaras robeža ir 20, ievade -1 dod brīdinājumu, 19 rāda turpināšanu ar trūkstošo 1 punktu, 20 rāda uzvaru, un konsolē nav kļūdu.

Papildu uzdevums: Pievieno meistara rekorda zaru no 100 punktiem

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Nosacījumu secības nozīme un Robežvērtību pārbaude.

  1. Atceries secības likumu: lielāks slieksnis (100) ir jāpārbauda pirms mazākā sliekšņa (20), citādi programma apstāsies jau pie parastās uzvaras.
  2. Funkcijā parbaudit() starp if (punkti < 0) zaru un else if (punkti >= 20) zaru pievieno jaunu zaru else if (punkti >= 100) ar īpašu meistara rekorda ziņu.
  3. Papildini <p id="noteikumi"> rindkopu ar informāciju par 100 punktu meistara titulu un saglabā ar Ctrl+S.
  4. Pārlūkā nospied Ctrl+R un pārbaudi visas četras situācijas ar vērtībām -1, 19, 20, 99 un 100.

Gatavs, kad: 20 un 99 rāda parasto uzvaru, 100 rāda meistara rekordu, un visi pārējie zari joprojām strādā pareizi.

Ja kaut kas neizdodas
  • Pie 20 punktiem rādās turpināšana, un uzvara sākas tikai no 21? Pārbaudi nosacījuma zīmi: tev ir uzrakstīts stingri lielāks >, bet, lai iekļautu arī pašu skaitli 20, jāraksta punkti >= 20.
  • Neatkarīgi no ievades vienmēr parādās viena un tā pati ziņa? Pārbaudi trīs biežākās vietas: 1) vai iekš if (...) neesi uzrakstījis vienu vienādības zīmi = salīdzināšanas zīmes vietā; 2) vai uzreiz aiz if (...) apaļajām iekavām nav kļūdaini ielikts semikols ;; 3) vai lielāks slieksnis nav nejauši ielikts aiz mazāka sliekšņa.
  • Nospiežot pogu, nekas nenotiek un F12 → Console rāda SyntaxError? Pārbaudi, vai vārdi else if ir rakstīti ar atstarpi (nevis elseif), vai pie pēdējā else neesi pielicis apaļās nosacījuma iekavas un vai katrai atverošajai figūriekavai { ir sava aizverošā }.
  • Neredzi savas izmaiņas pārlūkā? VS Code nospied Ctrl+S, pārlūkā nospied Ctrl+R un pēc skaitļa ievadīšanas noteikti nospied pogu Pārbaudīt. Pārliecinies, ka atvērts tieši Desktop/datorika9-tema3/33.html.
  • Kods pārlūkā redzams kā parasts teksts? Saglabā ar galotni .html. Windows File Explorer ieslēdz View → Show → File name extensions un pārbaudi, ka faila beigās nav .txt.
