Kas jāiesniedz

Katras nodarbības beigās iesniedz 3. uzdevuma pabeigto failu. Ja darbā ir atsevišķi attēli vai skaņas, pievieno arī tos. Katras tēmas beigās iesniedz GitHub projekta saiti. Kursa beigās iesniedz arī publicētās spēles saiti.

Viss obligātais darbs paredzēts stundās. Pieraksti vajadzīgi tikai tur, kur uzdevumā norādīts īss projekta plāns, instrukcija vai pārbaužu saraksts README failā.
