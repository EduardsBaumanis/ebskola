2.5 Sakārto failus mapēs un ZIP arhīvā

Sasniedzamais rezultāts: Sakārto tīmekļa lapas attēlus un skaņas atsevišķās apakšmapēs, atjauno relatīvos ceļus un pārbaudi pilnu ZIP arhīvu.

SR 2.3.3. Pārvalda un organizē datņu un mapju sistēmu, ievērojot informācijas strukturēšanas labās prakses piemērus un lietojot konkrētajā situācijā pieejamo datņu pārvaldības sistēmu. Veic datu arhivēšanu un atarhivēšanu. SR 2.4.8. Apvieno teksta, attēlu, audio un video saturu vienotā multimediju produktā, ievērojot izvirzīto mērķi un mērķauditoriju. SR 2.4.10. Saglabā dokumentu izvēlētajā vai norādītajā atmiņas ierīces (tai skaitā mākoņkrātuves) mapē un formātā, nepieciešamības gadījumā aizsargājot vai ierobežojot piekļuves tiesības šai datnei.

Teorija ar piemēriem

Mapju struktūra un relatīvie ceļi

Kad tīmekļa lapā parādās gan HTML kods, gan vairāki attēli un skaņas, visu failu glabāšana vienā kopīgā mapē ātri kļūst nepārskatāma. Tāpēc HTML failu patur galvenajā mapē, bet multivides datnes sagrupē loģiskās apakšmapēs ar īsiem nosaukumiem bez atstarpēm un garumzīmēm — piemēram, atteli un skanas:

25-mape/
  25.html
  atteli/
    varonis.svg
  skanas/
    klikskis.wav

Tiklīdz pārvieto failu uz apakšmapi, jāatjauno arī src norāde HTML kodā. Šādu pierakstu sauc par relatīvo ceļu — pārlūks sāk meklēt no tās mapes, kurā atrodas pats 25.html, ieiet apakšmapē un atver vajadzīgo datni:

Resurss Pirms pārvietošanas (blakus HTML) Pēc pārvietošanas apakšmapē
Attēls src="varonis.svg" src="atteli/varonis.svg"
Skaņa src="klikskis.wav" src="skanas/klikskis.wav"

Divi svarīgi ceļu rakstības noteikumi:

  • HTML kodā vienmēr lieto parasto slīpsvītru / (nevis Windows atpakaļvērsto \).
  • Nekad neraksti sava datora pilno ceļu (piemēram, C:\Users\Janis\Desktop\...) — citā datorā šādas lietotāja mapes nebūs un fails neielādēsies. Relatīvais ceļš atteli/varonis.svg darbojas jebkurā datorā, ja vien mapes turas kopā.

Kā pareizi atarhivēt un izveidot ZIP arhīvu

ZIP arhīvs (.zip) sapako vairākus failus un apakšmapes vienā datnē, lai visu komplektu varētu ērti pārsūtīt vai saglabāt kā rezerves kopiju, neizjaucot mapju koku.

Uzmanies no Windows ZIP priekšskatījuma slazda: ja uz .zip faila vienkārši divreiz uzklikšķina un atver HTML failu tieši no neatspiesta arhīva loga, Windows pagaidu mapē izceļ tikai vienu pašu HTML failu bez mapēm atteli un skanas — tāpēc attēls un skaņa nerādās pat pareizā arhīvā! Vienmēr vispirms ar peles labo pogu izvēlies Extract All (Izvilkt visu) un strādā tikai ar izvilkto mapi.

Savukārt, lai izveidotu savu arhīvu, File Explorer logā ar taustiņu Ctrl iezīmē vajadzīgos failus un apakšmapes un ar peles labo pogu izvēlies Compress to ZIP file (Saspiest ZIP failā).

Kā pārbaudīt, vai arhīvs ir pilnīgs?

Atvērt 25.html savā sākotnējā darba mapē vēl nepierāda, ka izveidotajā .zip failā tiešām iekļuva visas mapes. Īstā pārbaude vienmēr notiek trīs soļos: iekopē .zip failu citā vietā (piemēram, Downloads), izvelc to ar Extract All jaunā pārbaudes mapē un atver HTML failu no šīs izvilktās kopijas. Pārbaudi visas trīs daļas: attēlu, skaņu un pogas klikšķu skaitītāju.

Pašpārbaude: pārvietoji varonis.svg uz mapi atteli, bet pēc lapas atjaunošanas attēls pazuda — kas jāpārbauda?

Pārbaudi, vai failā 25.html nomainīji arī ceļu no src="varonis.svg" uz src="atteli/varonis.svg" ar slīpsvītru / un precīzu faila nosaukumu. Ja testē .zip arhīvu, pārliecinies arī, ka pirms atvēršanas nospiedi Extract All.

1. uzdevums

Atarhivē komplektu un izveido apakšmapes

Izmanto teoriju: Mapju struktūra un Kā pareizi atarhivēt ZIP arhīvu.

Vide: pārlūks → Windows File Explorer → VS Code

  1. Lejupielādē 25.zip, Windows mapē Downloads uzklikšķini uz 25.zip ar peles labo pogu un izvēlies Extract All (Izvilkt visu) → Extract.
  2. Mapē Desktop/datorika9-tema2 izveido jaunu mapi 25-mape un no tikko izvilktās mapes iekopē tajā visus trīs failus: 25.html, varonis.svg un klikskis.wav.
  3. Atver 25.html no mapes Desktop/datorika9-tema2/25-mape pārlūkā (Open with → Edge) un pārbaudi sākuma stāvokli: ir redzams robots, skan klikskis.wav un poga palielina klikšķu skaitu.
  4. VS Code ar File → Open Folder atver mapi Desktop/datorika9-tema2/25-mape, lai kreisajā Explorer sarakstā būtu redzami tieši šīs nodarbības faili.
  5. VS Code Explorer joslā nospied ikonu New Folder un izveido apakšmapi atteli (ar mazajiem burtiem, bez garumzīmēm un atstarpēm).
  6. Noklikšķini uz tukšās vietas Explorer saraksta apakšā (lai jaunā mape neveidotos atteli iekšpusē!), vēlreiz nospied New Folder un izveido apakšmapi skanas blakus atteli.

Gatavs, kad: mapē 25-mape vienā līmenī redzami sākuma faili un divas atsevišķas apakšmapes — atteli un skanas.

2. uzdevums

Pārvieto failus un atjauno relatīvos ceļus

Izmanto teoriju: Mapju struktūra un relatīvie ceļi.

Vide: VS Code → pārlūks

  1. VS Code Explorer sarakstā ar peli ievelc varonis.svg mapē atteli (ja parādās apstiprinājuma logs Move, apstiprini pārvietošanu).
  2. Tāpat ievelc klikskis.wav mapē skanas un pārliecinies koka skatā, ka galvenajā mapē palicis tikai 25.html un abas apakšmapes.
  3. Pirms labo HTML kodu, pārslēdzies uz pārlūku un nospied Ctrl+R: novēro, ka pogas skaitītājs joprojām strādā, taču attēla vietā parādās alt teksts un skaņa vairs neskan, jo vecās adreses pārvietotos failus neatrod.
  4. VS Code failā 25.html atrodi <img> birku un nomaini src="varonis.svg" uz relatīvo ceļu src="atteli/varonis.svg", lietojot slīpsvītru /.
  5. Saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārliecinies, ka robota attēls atkal ir redzams.
  6. Atrodi <audio> elementu, nomaini src="klikskis.wav" uz src="skanas/klikskis.wav", saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka skaņa atkal atskaņojas.
  7. Pielāgo lapas <title>, <h1> un CSS krāsas blokos body, .kartite un button, saglabā ar Ctrl+S un pārbaudi izskatu pārlūkā.

Gatavs, kad: attēls atrodas mapē atteli, skaņa — mapē skanas, un pārlūkā ar jaunajiem relatīvajiem ceļiem atkal darbojas gan attēls, gan skaņa, gan poga.

3. uzdevums

Izveido ZIP arhīvu un pārbaudi neatkarīgu kopiju

Izmanto teoriju: ZIP arhīva izveide un Arhīva pilnīguma pārbaude.

Vide: Windows File Explorer → pārlūks

  1. Windows File Explorer atver mapi Desktop/datorika9-tema2/25-mape un pārliecinies, ka tajā redzamas tieši trīs vienības: 25.html, mape atteli un mape skanas.
  2. Turot nospiestu taustiņu Ctrl, ar peles klikšķi iezīmē visas trīs vienības (25.html, atteli un skanas).
  3. Uzklikšķini uz iezīmētajām vienībām ar peles labo pogu, izvēlies Compress to ZIP file (Saspiest ZIP failā) un pārdēvē izveidoto arhīvu par 25-darbs.zip.
  4. Iekopē 25-darbs.zip citā vietā — Windows mapē Downloads —, lai pārbaude nenotiktu sākotnējā darba mapē.
  5. Mapē Downloads uzklikšķini ar peles labo pogu uz 25-darbs.zip, izvēlies Extract All (Izvilkt visu), gala ceļā norādi atsevišķu mapi 25-parbaude un spied Extract.
  6. Atver izvilkto mapi 25-parbaude, no tās atver 25.html pārlūkā un pārbaudi visas trīs daļas: vai rādās attēls, vai skan audio un vai poga pieskaita klikšķus.

Gatavs, kad: arhīvs 25-darbs.zip pēc izvilkšanas ar Extract All pilnīgi citā mapē atver strādājošu lapu ar attēlu, skaņu un pogu.

Papildu uzdevums: Pievieno mapēs arī savu PNG zīmējumu un ierakstīto skaņu

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Relatīvie ceļi un Arhīva pārbaude.

  1. No iepriekšējo stundu mapes Desktop/datorika9-tema2 iekopē savu varonis.png apakšmapē 25-mape/atteli un savu ierakstīto skaņu — apakšmapē 25-mape/skanas.
  2. Failā 25.html bloka .kartite iekšpusē pievieno otru <img src="atteli/varonis.png" alt="..." width="128"> un otru <audio controls src="skanas/..."></audio> ar īsto skaņas faila nosaukumu.
  3. Saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka lapā darbojas gan abi attēli, gan abas skaņas.
  4. Izveido atjauninātu 25-darbs.zip arhīvu un pēc izvilkšanas ar Extract All pārliecinies, ka arī papildinātie faili ir iekļauti arhīvā.

Gatavs, kad: apakšmapēs un pārbaudītajā ZIP arhīvā veiksmīgi darbojas gan dotie parauga faili, gan tavi paša veidotie resursi.

Ja kaut kas neizdodas
  • Izvilktajā kopijā nav attēla vai skaņas, lai gan arhīvs ir atvērts? Pārliecinies, ka nenoklikšķināji uz 25.html tieši neatspiestā .zip logā! Vispirms ar labo peles pogu uz .zip faila jāizvēlas Extract All un jāatver 25.html no izvilktās parastās mapes.
  • Mape skanas izveidojās mapes atteli iekšpusē? VS Code Explorer sarakstā ar peli izvelc skanas uz augšu virs 25-mape nosaukuma, lai abas apakšmapes atrastos vienā līmenī blakus 25.html.
  • Pēc pārvietošanas attēls vai skaņa neielādējas? Pārbaudi, ka src ceļā izmantota parastā slīpsvītra / (atteli/varonis.svg un skanas/klikskis.wav) un mapju nosaukumos nav garumzīmju vai lielo burtu.
  • Pārbaudes poga neskaita klikšķus? Pārbaudi, vai HTML kodā saglabāts <p id="punkti">, pogas atribūts onclick="pieskaitit()" un neskarts <script>...</script> bloks faila apakšā.
