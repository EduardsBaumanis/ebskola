2.1 CSS pamati un vizuālā ergonomika

Tavs šīs stundas izaicinājums: Pieslēgt stila lapu savam projektam un uzlabot lapas lasāmību, izmantojot krāsu teorijas un ergonomikas pamatprincipus.

1.1.1. Secina par estētiskajām īpašībām; 2.5.3. Lieto tiešsaistes rīkus uzdevuma veikšanai.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — pieslēdz style.css un nomaini lapas fona krāsu · 2. uzdevums (~25 min) — iekrāso virsrakstu un izcel vienu satura bloku · 3. uzdevums (~20 min) — pārbaudi teksta kontrastu DevTools un salabo to. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu spēles projekta mapi VS Code, pārliecinies, ka tajā ir index.html, un atver to arī pārlūkā.

Teorija: Kas ir CSS?

CSS (Cascading Style Sheets) nosaka, kā HTML elementi izskatīsies ekrānā.

  • Selektors: Norāda, kuru elementu mēs stilosim (piem., h1 vai p).
  • Īpašība un vērtība: Pasaka, ko tieši mainīt (piem., color: red;).
  • Vizuālā ergonomika: Programmētājam jārūpējas, lai teksts būtu salasāms (piemērots kontrasts starp fonu un burtu krāsu) un acīm patīkams.
Labākā prakse ir rakstīt CSS atsevišķā failā, lai kods būtu pārskatāms.

Praktiskie uzdevumi

1. uzdevums — Pieslēdz style.css un iekrāso lapas fonu

Beigās tava lapa būs tumša ar gaišu tekstu, jo krāsas nāks no atsevišķa stila faila.

body {
  background-color: #222831;
  color: #DFD0B8;
  font-family: Arial, sans-serif;
}
  1. Atver index.html VS Code un atrodi <head> daļu.
  2. Ieraksti tur rindu <link rel="stylesheet" href="style.css">.
  3. Izveido tajā pašā mapē failu style.css, ja tāda vēl nav.
  4. Nokopē augšējo CSS bloku style.css sākumā un saglabā ar Ctrl+S.
  5. Pārlādē lapu pārlūkā ar F5 un paskaties uz fona krāsu.
  6. Nomaini background-color vērtību no #222831 uz #1a1a2e un pārlādē vēlreiz.

Gatavs, kad: lapas fons ir tumšs un burti gaiši, nevis melns teksts uz balta fona.

2. uzdevums — Izcel spēles virsrakstu un noteikumu bloku

Beigās tavas lapas virsraksts būs oranžs un centrēts, bet noteikumu bloks — uz gaišāka fona.

  1. Atver style.css un pievieno faila beigās h1 { color: #FFB142; text-align: center; }.
  2. Saglabā un pārlādē lapu — virsrakstam jākļūst oranžam un centrētam.
  3. Pievieno kārtulu .izcelts { background-color: #393E46; padding: 12px; border-radius: 6px; }.
  4. Atver index.html un pieraksti class="izcelts" pie spēles noteikumu <div>.
  5. Pievieno style.css kārtulu p { line-height: 1.6; }, lai rindas nesalīp kopā.
  6. Saglabā abus failus un pārlādē lapu pārlūkā.
  7. Veic git commit -m "Add base CSS styles".

Gatavs, kad: virsraksts ir oranžs un lapas vidū, bet noteikumu bloks ir uz gaišāka fona ar apaļiem stūriem.

3. uzdevums — Salabo teksta kontrastu ar DevTools

Beigās tavā lapā nebūs nevienas vietas, kur teksts saplūst ar fona krāsu.

  1. Spied F12 pārlūkā, lai atvērtu izstrādātāja rīkus (DevTools).
  2. Atlasi cilnē "Elements" savu <h1> elementu.
  3. Pārbaudi panelī "Styles", vai tur redzama tava kārtula color: #FFB142.
  4. Nomaini turpat panelī teksta krāsu uz #3a3f47 un paskaties, cik grūti to lasīt.
  5. Ieraksti labāk salasāmo krāsu #FFB142 atpakaļ style.css failā un saglabā.
  6. Pārbaudi, vai arī <h2> un <p> teksts ir salasāms uz tumšā fona.
  7. Pieraksti vienu secinājumu: kāpēc color un background-color vienmēr jāizvēlas kopā.

Gatavs, kad: visu lapas tekstu var izlasīt no metra attāluma un tavs secinājums ir pierakstīts.

Papildu uzdevums — Uztaisi pogu, kas maina krāsu zem peles

Beigās tava spēles poga kļūs oranža tieši tajā brīdī, kad pele ir virs tās.

  1. Pievieno style.css klasi .poga { background-color: #393E46; color: #DFD0B8; padding: 10px 20px; border: none; border-radius: 6px; cursor: pointer; }.
  2. Atver index.html un pieraksti class="poga" pie sava <button> elementa.
  3. Pievieno kārtulu .poga:hover { background-color: #FFB142; color: #222831; }.
  4. Saglabā un uzbrauc pārlūkā ar peli virsū pogai.
  5. Veic git commit -m "Add button hover style".

Gatavs, kad: poga kļūst oranža, kad pele ir virs tās, un atgriežas pelēka, kad pele aiziet.

Biežākās kļūdas (un kā tās labot):

  • CSS nedarbojas: Pārbaudi, vai href ceļš link tagā sakrīt ar faila nosaukumu un abi faili ir vienā mapē.
  • Aizmirsts semikols: Katra CSS rinda ir jābeidz ar ;, citādi nākamās rindas netiks nolasītas.
  • Pārāk mazs kontrasts: Gaiši pelēks teksts uz balta fona ir kļūda — lietotājam būs grūti lasīt!

Koda piemērs (kad CSS nedarbojas: ceļš, semikols un kontrasts)

<!-- index.html — saite uz stila failu jāraksta <head> iekšpusē -->
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="style.css">
</head>
/* NEPAREIZI: pirmajai rindai trūkst semikola,
   tāpēc pārlūks nenolasa arī nākamo rindu */
body {
    background-color: #222831
    color: #DFD0B8;
}

/* NEPAREIZI: pelēks uz pelēka — teksts saplūst ar fonu */
.izcelts {
    background-color: #393E46;
    color: #3a3f47;
}

/* PAREIZI: katra rinda beidzas ar ; un krāsas ir kontrastainas */
body {
    background-color: #222831;
    color: #DFD0B8;
    font-family: Arial, sans-serif;
}

.izcelts {
    background-color: #393E46;
    color: #DFD0B8;
    padding: 12px;
    border-radius: 6px;
}

Ja ceļš un semikoli ir pareizi, lapa pārlūkā izskatās šādi — tumšs fons, oranžs centrēts virsraksts un salasāms izceltais bloks. Ja fons paliek balts, kļūda ir href ceļā; ja mainās tikai fons, bet ne teksta krāsa, trūkst semikola.
