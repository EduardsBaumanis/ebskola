2.1 Maini lapas krāsas un tekstu

Šodien: Noformē savas spēles lapu ar labi salasāmu tekstu un izceltu pogu.

Teorija ar piemēriem

CSS noteikums: ko mainīt un kā mainīt

HTML nosaka, kādas daļas ir lapā — virsraksts, rindkopa, noteikumu sadaļa un poga. CSS nosaka, kā šīs daļas izskatās: fona un burtu krāsu, teksta izmēru, izlīdzinājumu un stūru noapaļojumu. Šajā failā CSS noteikumi atrodas <head> daļā starp <style> un </style>.

body {
  background-color: #f1f5f9;
  color: #1e293b;
}

h1 {
  color: #174ea6;
  font-size: 36px;
  text-align: center;
}

Lasām CSS bloku pa daļām: pirms atverošās figūriekavas { raksta, kuru elementu noformējam (piemēram, body — visu lapas pamatdaļu, h1 — galveno virsrakstu). Starp { un } katrā rindā ir viena norāde formā īpašība: vērtība;. Aiz īpašības nosaukuma vienmēr ir kols (:), bet rindas beigās — semikols (;). Ja aizmirst semikolu, nākamā rinda tajā pašā blokā pārstāj darboties.

Īpašība Ko tā maina? Piemērs
background-color Lapas, bloka vai pogas fona krāsu. background-color: #f1f5f9;
color Teksta (burtu) krāsu. color: #1e293b;
font-size Burtu augstumu pikseļos (bez atstarpes pirms px). font-size: 36px;
text-align Teksta novietojumu rindā (left — kreisajā malā, center — vidū). text-align: center;
border-radius Bloka vai pogas stūru noapaļojumu pikseļos. border-radius: 12px;

Kā izvēlēties krāsas kodu? Krāsu pieraksta ar restīti # un sešām zīmēm (piemēram, #ffffff ir balta, #0f172a — ļoti tumši zila). VS Code redaktorā blakus katram krāsas kodam parādās mazs krāsains kvadrātiņš: uzved uz tā peles kursoru, lai atvērtu krāsu paleti un izvēlētos jebkuru citu toni. Vari izmantot arī kādu no šiem pārbaudītajiem krāsu salikumiem:

Noskaņa Lapas fons un teksts (body) Noteikumu bloks (.noteikumi) Poga (button)
Gaiša dienas tēma Fons #f1f5f9, teksts #1e293b Fons #dbeafe, teksts #1e3a8a Fons #174ea6, teksts #ffffff
Siltā piedzīvojumu tēma Fons #fffbeb, teksts #292524 Fons #fef3c7, teksts #451a03 Fons #b45309, teksts #ffffff
Tumšā kosmosa tēma Fons #0f172a, teksts #e2e8f0 Fons #1e293b, teksts #f8fafc Fons #38bdf8, teksts #0f172a

Kuru lapas daļu maini: tags un klase (.noteikumi)

Ja raksti taga vārdu (piemēram, p vai section), stils maina visus šādus elementus lapā. Lai izceltu vienu konkrētu bloku — šeit noteikumu sadaļu —, HTML tagā pievieno atribūtu class="noteikumi", bet CSS šo nosaukumu raksta ar punktu priekšā: .noteikumi.

Pieraksts CSS Ko tas atrod HTML kodā?
body { ... } Visu <body> saturu — nosaka lapas fonu un noklusējuma teksta krāsu.
h1 { ... } Galveno virsrakstu <h1>...</h1>.
.noteikumi { ... } Tikai elementu ar class="noteikumi" (punkts CSS nozīmē klasi).
button { ... } Visas <button> pogas.

Katram blokam var būt savas krāsas. Kad nomaini body teksta krāsu, mainās parastā mērķa rindkopa zem virsraksta, taču h1, .noteikumi un button saglabā krāsas, kuras tiem uzdotas viņu pašu CSS blokos.

Kontrasts un pārbaude pa vienam solim

Lai spēlētājs lapu varētu ērti izlasīt, ievēro kontrastu — skaidru gaišuma atšķirību starp fonu un burtiem. Uz gaiša fona raksti tumšu tekstu, bet uz tumša fona — gaišu tekstu. Vienmēr pārbaudi visas trīs zonas atsevišķi: lapas pamattekstu, noteikumu kastīti un pogas uzrakstu.

Strādā pa vienam solim: paredzi izmaiņu → izlabo vienu CSS bloku → saglabā ar Ctrl+S → atjauno pārlūku ar Ctrl+R. Tā uzreiz redzēsi katras rindas ietekmi un viegli pamanīsi, ja kaut kur pietrūkst semikola. Atceries, ka CSS maina tikai pogas izskatu; pogas klikšķa darbību vēlāk pievienosim ar JavaScript.

Pašpārbaude: uzliki tumšu lapas fonu un baltu body tekstu, bet noteikumu blokā burti kļuva nesalasāmi, kad nomainīji arī tā fonu uz tumšu — kāpēc?

Blokam .noteikumi sākuma kodā ir pašam sava rinda color: #222222;, tāpēc tas nepārņem body balto teksta krāsu. Ja .noteikumi fonu nomaini uz tumšu, tajā pašā .noteikumi { ... } blokā nomaini arī color uz gaišu toni, piemēram, #f8fafc.

1. uzdevums

Maini lapas fonu, pamattekstu un virsrakstu

Izmanto teoriju: CSS noteikums: ko mainīt un kā mainīt.

Vide: VS Code → pārlūks

  1. Windows mapē Desktop/datorika9-tema2 atver saglabāto 21.html pārlūkā (ar peles labo pogu izvēlies Open with → Edge), lai pirms darba apskatītu sākuma izskatu.
  2. VS Code HTML daļā ieraksti savas spēles nosaukumu gan <title>, gan <h1> tagos, bet rindkopā <p>Īss spēles mērķa apraksts.</p> ieraksti savas spēles mērķi.
  3. Atrodi komentāru /* MAINI ŠEIT: lapas krāsas un teksts */ un zem tā esošajā body { ... } blokā nomaini background-color uz izvēlētu lapas fonu (piemēram, #f1f5f9 vai tumšu #0f172a).
  4. Saglabā failu ar Ctrl+S un pārlūkā nospied Ctrl+R, lai pārliecinātos, ka mainījās visas lapas fons.
  5. Tajā pašā body { ... } blokā pielāgo color vērtību tā, lai mērķa rindkopa skaidri izceltos uz jaunā fona; saglabā un pārlūkā ievēro, ka mērķa rindkopa mainīja krāsu, bet .noteikumi bloks un poga paturēja savas krāsas.
  6. Atrodi h1 { ... } bloku: nomaini virsraksta color, pielāgo burtu izmēru font-size (piemēram, uz 36px) un jaunā rindā pirms } pievieno text-align: center;.
  7. Saglabā ar Ctrl+S un atjauno pārlūku ar Ctrl+R, pārbaudot, ka virsraksts stāv lapas vidū un ir skaidri salasāms.

Gatavs, kad: pārlūkā redzams tavs spēles nosaukums un mērķis, centrēts h1 virsraksts un saskaņotas body fona un pamatteksta krāsas.

2. uzdevums

Noformē noteikumu bloku ar klasi

Izmanto teoriju: Kuru lapas daļu maini: tags un klase (.noteikumi).

Vide: VS Code → pārlūks

  1. HTML daļā atrodi <section class="noteikumi"> un salīdzini tā class nosaukumu ar CSS bloku .noteikumi { ... }.
  2. Sadaļas <section class="noteikumi"> iekšpusē nomaini pirmo <p> uz savas spēles punktu vai uzvaras noteikumu un zem tā pievieno otru <p> ar vadības teikumu (piemēram, kā spēlētājs kustas vai klikšķina).
  3. CSS blokā .noteikumi { ... } nomaini background-color uz toni, kas skaidri atšķiras no visas lapas fona, tad saglabā (Ctrl+S) un pārbaudi izmaiņu pārlūkā (Ctrl+R).
  4. Tajā pašā .noteikumi { ... } blokā pielāgo color vērtību, lai gan Noteikumi apakšvirsraksts, gan abas rindkopas uz bloka fona būtu viegli salasāmas.
  5. Pirms .noteikumi aizverošās iekavas } pievieno jaunu rindu border-radius: 12px;, kas noapaļo bloka stūrus.
  6. Saglabā failu ar Ctrl+S un pārlūkā ar Ctrl+R pārliecinies, ka abi noteikumi atrodas noapaļotā kartītē un izmaiņas skāra tikai .noteikumi bloku, nevis mērķa rindkopu virs tā.

Gatavs, kad: noteikumu blokā ir divas ar spēli saistītas rindkopas, un pārlūkā tas izceļas ar savu fonu, salasāmu tekstu un noapaļotiem stūriem.

3. uzdevums

Izcel pogu un pārbaudi lasāmību

Izmanto teoriju: Kontrasts un pārbaude pa vienam solim.

Vide: VS Code → pārlūks

  1. HTML daļā pārskati <button>Sākt spēli</button> un pēc vēlēšanās precizē pogas uzrakstu atbilstoši savai spēlei (piemēram, Sākt misiju).
  2. CSS daļā atrodi button { ... } bloku un nomaini background-color uz pamanāmu akcenta krāsu, kas uzreiz izceļ pogu uz lapas fona.
  3. Tajā pašā button { ... } blokā iestati kontrastējošu color vērtību (gaišu tekstu tumšai pogai vai tumšu tekstu gaišai pogai), saglabā ar Ctrl+S un apskati pārlūkā ar Ctrl+R.
  4. Pirms button aizverošās iekavas } pievieno border-radius: 8px; un font-size: 18px;, saglabā failu un atjauno pārlūku.
  5. Pārbaudi lasāmību visās trīs vietās: pārlasi mērķa rindkopu uz lapas fona, abus noteikumus .noteikumi blokā un uzrakstu uz pogas — ja kāds teksts saplūst ar fonu, izlabo tā krāsu.
  6. Palūdz klasesbiedram paskatīties uz tavu atvērto lapu, atrast sākšanas pogu un skaļi nolasīt vadības noteikumu; ja kaut ko ir grūti pamanīt vai izlasīt, uzlabo kontrastu un saglabā gala izmaiņas ar Ctrl+S.

Gatavs, kad: poga ir noapaļota un vizuāli izcelta, visas trīs lapas daļas ir skaidri salasāmas, un klasesbiedrs bez piepūles izlasa noteikumus un pamana pogu.

Papildu uzdevums: Pogas izskats zem peles kursora (:hover)

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: CSS selektori.

  1. CSS daļas beigās (tieši virs </style>) pievieno jaunu noteikumu button:hover { background-color: #163b61; }, izvēloties nedaudz tumšāku vai gaišāku toni par savu pogas pamatkrāsu.
  2. Ja :hover stāvoklī fons kļuva daudz gaišāks vai tumšāks, tajā pašā button:hover { ... } blokā pievieno arī piemērotu color vērtību.
  3. Saglabā failu ar Ctrl+S un atjauno lapu pārlūkā ar Ctrl+R.
  4. Uzved peles kursoru uz pogas un pārliecinies, ka poga maina toni un uzraksts paliek salasāms.

Gatavs, kad: uzvedot peles kursoru uz pogas, tās fons mainās un teksts joprojām ir skaidri salasāms.

Ja kaut kas neizdodas
  • Neredzi izmaiņas pārlūkā? VS Code nospied Ctrl+S (pie faila nosaukuma cilnē nedrīkst būt balts aplītis), pēc tam pārlūkā nospied Ctrl+R. Pārbaudi, ka pārlūkā atvērts tieši Desktop/datorika9-tema2/21.html.
  • CSS rinda nedarbojas vai pazuda stils zem tās? Pārbaudi, vai aiz īpašības nosaukuma ir kols (:), rindas beigās ir semikols (;) un bloku noslēdz figūriekava (}). Krāsas kodam priekšā jābūt restītei (#f1f5f9), bet starp skaitli un px nedrīkst būt atstarpe (36px).
  • Noteikumu bloks nemaina krāsu? Pārbaudi, ka CSS selektoram priekšā ir punkts (.noteikumi), bet HTML tagā punkta nav (class="noteikumi").
  • Kods pārlūkā redzams kā parasts teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka faila beigās nav .txt.
  • Poga pēc klikšķa neko nedara? Šajā nodarbībā veidojam tikai pogas izskatu ar CSS — klikšķa darbību pievienosim vēlāk ar JavaScript.
