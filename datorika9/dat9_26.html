2.6 Noslēguma projekts: Stilizēta spēles lapa

Stundas uzdevums: Pabeigt spēles pieteikuma vizuālo noformējumu, izmantojot tikai 2. tēmā apgūto CSS, Box Model, multimediju un datņu pārvaldības prasmes.

SR 1.4.1. Dizaina risinājuma pilnveide SR 2.4.5. Attēlu apstrāde un formāti SR 2.4.6. Audio un multimediju sagatavošana SR 2.4.10. Datņu saglabāšana un kārtošana SR 2.4.8. Multimediju produkta izveide

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - ietērp spēli konteinerā .game-container · 2. uzdevums (~25 min) - pabeidz virsraksta, pogas un attēla dizainu · 3. uzdevums (~20 min) - pārbaudi lapu šaurā ekrānā un nosūti uz GitHub. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu projektu VS Code, pārliecinies ar git status, ka viss ir nokomitēts, un atver lapu pārlūkā ar F12 ieslēgtiem DevTools.

Teorija: kā CSS, resursi un mapes strādā kopā

Stilizēta spēles lapa sastāv no trim saistītām daļām: HTML satur lapas struktūru, CSS nosaka vizuālo izskatu, bet resursu mapes glabā attēlus un audio. Ja kaut viena daļa nav sakārtota, lapa var izskatīties nepabeigta vai resursi internetā neielādēsies.

.game-container {
  max-width: 720px;
  margin: 32px auto;
  padding: 24px;
  background-color: #393E46;
}

.hero-image {
  max-width: 100%;
  border-radius: 6px;
}
Šis piemērs izmanto 2. tēmā apgūto: klases, margin, padding, fonu un attēla izmēra kontroli.

Praktiskie uzdevumi

1. uzdevums - Ietērp spēli konteinerā .game-container

Beigās viss tavas spēles saturs stāvēs vienā centrētā kastē, nevis izpletīsies pa visu ekrānu.

.game-container {
  max-width: 720px;
  margin: 32px auto;
  padding: 24px;
  background-color: #393E46;
  border-radius: 8px;
}

.hero-image {
  max-width: 100%;
  border-radius: 6px;
}
  1. Nokopē augšējo CSS bloku css/style.css faila beigās.
  2. Atver index.html un ieliec visu spēles saturu iekšā <div class="game-container">.
  3. Pieraksti class="hero-image" pie lapas lielākā attēla.
  4. Saglabā un pārlādē lapu ar Ctrl+F5.
  5. Nomaini max-width no 720px uz 480px un paskaties, kā kaste saraujas.
  6. Atgriez vērtību 720px atpakaļ.

Gatavs, kad: viss spēles saturs ir vienā pelēkā kastē lapas vidū ar brīvu vietu abās malās.

2. uzdevums - Pabeidz virsraksta, pogas un attēla dizainu

Beigās tavai lapai būs viena krāsu palete, viens fontu izmērs virsrakstiem un stilizēta spēles poga.

  1. Atver css/style.css un pārbaudi, ka tajā ir kārtulas body, h1 un .poga.
  2. Uzstādi virsrakstam h1 { font-size: 2rem; color: #FFB142; margin-bottom: 16px; }.
  3. Uzstādi pogai .poga { padding: 12px 24px; font-size: 1rem; border-radius: 6px; cursor: pointer; }.
  4. Pievieno spēles laukumam #spele { width: 400px; height: 300px; margin: 0 auto; background: #222831; box-sizing: border-box; }.
  5. Pārbaudi DevTools cilnē "Network", vai visi attēli un skaņas ielādējas ar statusu 200.
  6. Saglabā un pārlādē lapu - visām krāsām jābūt no vienas paletes.
  7. Veic git commit -m "Complete styled game page".

Gatavs, kad: lapā nav neviena nestilizēta elementa un DevTools nerāda nevienu 404 kļūdu.

3. uzdevums - Pārbaudi lapu telefona ekrānā un nosūti uz GitHub

Beigās tava lapa būs salasāma arī 375 pikseļu platā ekrānā un pieejama pa GitHub saiti.

  1. Spied F12, tad Ctrl+Shift+M, lai ieslēgtu ierīces režīmu.
  2. Izvēlies sarakstā "iPhone SE" (375 px) un paskaties, vai saturs neizspiežas ārpus ekrāna.
  3. Salabo pirmo elementu, kas izlien ārā - pievieno tam max-width: 100%;.
  4. Pārbaudi, vai teksts joprojām ir salasāms uz fona krāsas šaurajā ekrānā.
  5. Izpildi git add ., tad git commit -m "Fix mobile layout" un git push.
  6. Atver savu GitHub Pages saiti telefonā vai citā logā.
  7. Pieraksti vienu secinājumu: kura 2. tēmas prasme visvairāk uzlaboja tavas lapas izskatu.

Gatavs, kad: 375 px režīmā nav horizontālās ritjoslas un GitHub saite atveras citā ierīcē.

Papildu uzdevums - Pievieno Google Fonts fontu un gludu pāreju

Beigās tavas lapas virsraksti būs īpašā fontā, bet sākuma ekrāns pazudīs plūstoši.

  1. Atver fonts.google.com, atrodi fontu "Press Start 2P" un nokopē tā <link> tagu.
  2. Ielīmē šo tagu index.html faila <head> daļā.
  3. Pievieno css/style.css kārtulu h1 { font-family: "Press Start 2P", monospace; }.
  4. Pievieno kārtulu #menu { transition: opacity 0.4s; }.
  5. Ieraksti js/script.js pirms izvēlnes paslēpšanas rindu menu.style.opacity = 0;.
  6. Veic git commit -m "Add screen transition and custom font".

Gatavs, kad: virsraksts ir pikseļu fontā un sākuma ekrāns izgaist gludi, nevis pazūd uzreiz.

Biežākās kļūdas (un kā tās labot)

  • Attēls pazūd pēc pārvietošanas mapē: atjauno relatīvo ceļu, piemēram, assets/images/varonis.png.
  • CSS nepieslēdzas: pārbaudi, vai <link> ceļš sakrīt ar mapes nosaukumu.
  • Teksts slikti salasāms: palielini kontrastu starp color un background-color.
  • Lapa izskatās pārblīvēta: pievieno padding saturam un margin starp sadaļām.

Koda piemērs (kad lapa izspiežas ārpus telefona ekrāna)

/* NEPAREIZI: fiksēts 720 px platums un attēls dabiskajā izmērā.
   375 px ekrānā parādās horizontālā ritjosla. */
.game-container { width: 720px; padding: 24px; }
.hero-image     { width: 1200px; }

/* PAREIZI: max-width ļauj kastei sarukt, border-box ieskaita padding */
.game-container {
    max-width: 720px;
    margin: 32px auto;
    padding: 24px;
    background-color: #393E46;
    box-sizing: border-box;
}

.hero-image {
    max-width: 100%;   /* attēls nekad neizaug platāks par kasti */
    height: auto;      /* proporcijas paliek pareizas */
    display: block;
}

/* Šaurā ekrānā samazinām atkāpes un virsrakstu */
@media (max-width: 480px) {
    .game-container { padding: 12px; margin: 12px auto; }
    h1              { font-size: 1.4rem; }
    #spele          { width: 100%; height: 220px; }
}

DevTools ierīces režīmā (Ctrl+Shift+M, "iPhone SE" - 375 px) lapa iztiek bez horizontālās ritjoslas: kaste saraujas līdz ekrāna platumam, attēls samazinās kopā ar to, bet teksts paliek salasāms. Ja ritjosla joprojām ir, meklē elementu ar fiksētu width pikseļos.

Datņu pārvaldība un multimediji (2.3.3., 2.4.6.) Faili atrodas vienā mapē, daži attēli vai skaņas nedarbojas nepareizu saīšņu dēļ. Ir izveidotas mapes, bet struktūra ir nepilnīga. Attēli un audio ir ievietoti, bet nav optimizēti (ir pārāk lieli). Visi faili ir precīzi sakārtoti mapēs (css, assets). Saites strādā nevainojami, failu izmēri ir piemēroti web videi. Loģiska un nemainīga failu struktūra. Izmantoti atbilstošākie formāti (piem., PNG ar caurspīdīgumu spēles elementiem). Pievienoti "alt" teksti visiem attēliem.
Vizuālā ergonomika un CSS (1.1.1., 1.4.1.) CSS fails ir pieslēgts, bet stili pielietoti haotiski, teksts grūti salasāms. Ir pamata izkārtojums, izmantoti foni un krāsas, bet "Box Model" principi (padding/margin) pielietoti kļūdaini. Lapai ir saskanīgs, estētisks dizains. "Box Model" izmantots pareizi – saturs ir centrēts, elpojošs un vizuāli atdalīts. Dizains mērķtiecīgi atbalsta spēles tēmu. Izcils krāsu kontrasts, pārdomāta fontu hierarhija. Kods CSS failā ir labi strukturēts un izmanto klases.
