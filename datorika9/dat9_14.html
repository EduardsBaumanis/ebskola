1. tēma / 1.4

1.4 Izvēlies spēles ideju un spēlētāju

Šodien: Izveido lapu, kurā spēlētājs saprot mērķi, vadību un spēles beigas.

Īsā teorija

Spēles ideja un paredzētais spēlētājs

Izvēlies vienu vienkāršu darbību, piemēram, klikšķināt uz priekšmetiem vai izvēlēties pareizo atbildi. Paredzētais spēlētājs ir cilvēks, kuram veido spēli, piemēram, klasesbiedrs, kurš to spēlē pirmoreiz. Spēles varonis ir tēls pašā spēlē.

Norādi, kam spēle domāta un kāda palīdzība šim cilvēkam vajadzīga. Piemēram: “Spēle paredzēta iesācējam; pirms sākšanas viņš redzēs īsus noteikumus un peles vadības norādi.”

Mērķis, vadība un pārbaudāmi noteikumi

Mērķis pasaka, ko spēlētājs cenšas sasniegt. Trīs noteikumi paskaidro darbību un punktu iegūšanu, uzvaru un zaudējumu. Pārbaudāms noteikums nosauc konkrētu skaitu vai notikumu: “Uzvara ir pie 5 punktiem”, nevis “Savāc daudz punktu”.

<h2>Mērķis</h2>
<p>Savāc 5 zvaigznes, neuzklikšķinot uz akmens.</p>
<ul>
  <li>Ar peli spied uz zvaigznes; katra zvaigzne dod 1 punktu.</li>
  <li>Tu uzvari, kad sasniedz 5 punktus.</li>
  <li>Tu zaudē, ja uzklikšķini uz akmens.</li>
</ul>

Mērķim un noteikumiem jāsaskan: ja katra zvaigzne dod 1 punktu, 5 zvaigznes nozīmē 5 punktus. Šodien veido spēles ieceres aprakstu. Sākuma koda pogai vēl nav pievienota darbība; ekrānu pārslēgšanu izmantosi 1.5. nodarbībā.

Pārbaude ar lasītāju

Parādi lapu klasesbiedram un ļauj atbildes atrast pašam: ko darīt, ar ko vadīt, kā uzvarēt un kā zaudēt? Ja atbilde nav atrodama, precizē attiecīgo teikumu un atkārto pārbaudi.

Sākuma kods un darba vieta

Vide: mācību lapa → VS Code

  1. VS Code ar File → Open Folder atver Desktop/datorika9-tema1 . Ja mapes nav, izveido to darbvirsmā.
  2. Šajā mācību lapā nospied Kopēt sākuma kodu .
  3. VS Code nospied Ctrl+N un ielīmē kodu ar Ctrl+V .
  4. Saglabā ar Ctrl+Shift+S tēmas mapē kā 14.html .

1. uzdevums

Izvēlies savu ideju

Vide: VS Code

Izmanto teoriju: Spēles ideja un paredzētais spēlētājs.

  1. Pēc sākuma koda soļiem izveido un atver 14.html. Vari turpināt iepriekš izvēlēto spēles ideju.
  2. Izvēlies vienu galveno spēles darbību. Izdomā tai divus iespējamos spēles nosaukumus, pasaki tos klasesbiedram un izvēlies vienu.
  3. Ieraksti izvēlēto nosaukumu gan <h1>, gan <title> tagos, kā apguvi 1.2. nodarbībā.
  4. Zem virsraksta Kam spēle domāta? esošajā <p> ieraksti, kuram cilvēkam veido spēli un kāda palīdzība viņam vajadzīga. Izmanto teorijas piemēru, pielāgojot to savai idejai.

Gatavs, kad: lapai ir tavs nosaukums un rindkopa, kas nosauc paredzēto spēlētāju un vienu viņa vajadzību.

2. uzdevums

Uzraksti spēlēšanai vajadzīgo

Vide: VS Code → pārlūks

Izmanto teoriju: Mērķis, vadība un pārbaudāmi noteikumi; HTML saraksts.

  1. Zem <h2>Mērķis</h2> rindkopā vienā teikumā pasaki, ko spēlētājs cenšas sasniegt. Izvēlies konkrētu sasniedzamo skaitu.
  2. Pirmajā esošajā <li> ieraksti vadības veidu, spēlētāja darbību un par to iegūstamos punktus, piemēram, klikšķis uz zvaigznes dod 1 punktu.
  3. Otrajā <li> norādi precīzu uzvaras punktu skaitu. Pirms </ul> pievieno trešo <li> ar zaudējuma notikumu vai skaitu, piemēram, klikšķi uz akmens.
  4. Saglabā failu un atver to pārlūkā. Pārbaudi, ka ir trīs atsevišķi noteikumi un mērķī minētais daudzums atbilst punktu iegūšanas un uzvaras nosacījumiem.

Gatavs, kad: mērķis un trīs noteikumi viennozīmīgi pasaka vadību, punktu iegūšanu, uzvaru un zaudējumu; skaitļi saskan.

3. uzdevums

Padari lapu saprotamu citam

Vide: Pārlūks → VS Code → GitHub

Izmanto teoriju: Pārbaude ar lasītāju; nosūtīšana uz GitHub.

  1. Parādi saglabāto 14.html klasesbiedram pārlūkā. Ļauj viņam lasīt lapu bez tava skaidrojuma.
  2. Palūdz viņam atrast un pateikt: kam spēle domāta, kāds ir mērķis, ar ko vadīt, kā iegūt punktu, kad uzvar un kad zaudē.
  3. Ja kāda atbilde nav atrodama vai ir pretrunīga, VS Code precizē attiecīgo rindkopu vai noteikumu. Saglabā, atjauno lapu un palūdz klasesbiedram vēlreiz atbildēt uz neskaidro jautājumu.
  4. Pārbaudi, ka nosaukums cilnē un lapā sakrīt un visur lietoti vienādi priekšmetu nosaukumi un skaitļi. Saglabā un nosūti 14.html uz GitHub pēc zemāk dotās pogu atgādnes.
  5. GitHub faila kodā pārbaudi pēdējo labojumu. Iesniedz to pašu pabeigto 14.html skolotāja norādītajā vietā.

Gatavs, kad: klasesbiedrs lapā atrod visas prasītās atbildes, un iesniegtais fails sakrīt ar GitHub saglabāto versiju.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 14.html skolotāja norādītajā vietā. Šo pašu versiju saglabā arī GitHub.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • Nosaukums cilnē un lapā sakrīt; aprakstīts paredzētais spēlētājs un viena viņa vajadzība.
  • Mērķis un trīs noteikumi pasaka vadību, punktu iegūšanu, precīzu uzvaras un zaudējuma nosacījumu.
  • Aprakstā nav pretrunu; klasesbiedrs lapā atrod atbildes. Iesniegtais 14.html saglabāts arī GitHub.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Saglabā un nosūti uz GitHub — pogu atgādne

Vide: VS Code / Source Control → GitHub pārlūkā

  1. Ar File → Save All saglabā failus. Atver Source Control ar Ctrl+Shift+G .
  2. Pie Changes nospied + (Stage All Changes). Pārbaudi, ka vajadzīgie faili pārvietojas uz Staged Changes .
  3. Ziņas laukā ieraksti īsu izmaiņu, piemēram, Pabeigts 1.4 darbs . Spied Commit .
  4. Ja šī tēmas mape vēl nav GitHub, spied Publish to GitHub un izveido publisku projektu datorika9-tema1 . Jau publicētam projektam spied Sync Changes . Ja pogas nav, atver … → Push .
  5. Pārlūkā atver savu GitHub projektu un pārbaudi faila pēdējās izmaiņas.

Ja Source Control rāda Initialize Repository , vispirms nospied to. Ja parādās kļūda vai sapludināšanas pieprasījums, izmanto palīdzību un palūdz skolotāja atbalstu.

Papildu uzdevums: Pievieno padomu

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Papildu uzdevums nav obligāts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

Izmanto teoriju: Paredzētā spēlētāja vajadzība.

  1. Aiz noteikumu saraksta un pirms pogas pievieno <h2>Padoms iesācējam</h2>.
  2. Zem tā <p> rindkopā uzraksti vienu praktisku padomu, kas palīdz ievērot kādu esošo noteikumu, piemēram, kā izvairīties no zaudējuma. Saglabā un pārbaudi pārlūkā.

Gatavs, kad: padoms palīdz izvēlētajam spēlētājam un nav pretrunā ar noteikumiem.

Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 14.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
