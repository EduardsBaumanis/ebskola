1. tēma / 1.1

1.1 Sagatavo VS Code un GitHub

Šodien: Izveido un atver savu pirmo HTML failu. Sagatavo GitHub kontu.

Īsā teorija

VS Code ir programma, kurā labosi kodu. Git saglabā darba versijas datorā. GitHub glabā tās internetā.

Fails ar galotni .html ir tīmekļa lapa. Tā saturu vari apskatīt pārlūkā.

<h1> sāk virsrakstu; </h1> to beidz. Maini tekstu starp šīm zīmēm. 

<h1>Mana spēle</h1>

Sākuma kods un darba vieta

Vispirms izpildi 1. un 2. uzdevumu. Šo pilno kodu izmantosi 3. uzdevumā.

1. uzdevums

Sagatavo darba mapi

Vide: Windows → VS Code

  1. Atver Start (Sākums) un meklē Visual Studio Code . Ja tā nav, Microsoft Store meklē Microsoft veidoto Visual Studio Code un spied Install (Instalēt). Ja tas nav atļauts, palūdz skolotāja palīdzību.
  2. Darbvirsmā ( Desktop ) ar peles labo pogu izvēlies New → Folder (Jauns → Mape). Nosauc to datorika9-tema1 .
  3. VS Code izvēlies File → Open Folder (Fails → Atvērt mapi) un atver šo mapi. Ja prasa uzticēties, apstiprini savai mapei.
  4. Palūdz skolotājam pārbaudīt, vai datorā ir Git. Pēc Git uzstādīšanas aizver un atver VS Code.

Gatavs, kad: VS Code ir atvērta mape datorika9-tema1.

2. uzdevums

Sagatavo GitHub kontu

Vide: Pārlūks → e-pasts → pārlūks

  1. Atver GitHub . Ar esošu kontu spied Sign in (Pieslēgties). Ja konta nav, spied Sign up (Reģistrēties).
  2. Ja veido kontu, seko reģistrācijas soļiem. Atver savu e-pastu un apstiprini GitHub atsūtīto vēstuli.
  3. Atgriezies GitHub. Atver sava profila izvēlni un pārliecinies, ka redzi savu lietotājvārdu.

Gatavs, kad: Vari pieslēgties savam GitHub kontam.

3. uzdevums

Izveido un iesniedz savu lapu

Vide: Mācību lapa → VS Code → Windows → pārlūks

  1. Nokopē šīs nodarbības sākuma kodu. VS Code nospied Ctrl+N un ielīmē to ar Ctrl+V .
  2. Starp <h1> un </h1> ieraksti savu spēles nosaukumu. Rindkopā ieraksti vienu noteikumu.
  3. Nospied Ctrl+Shift+S un saglabā failu 11.html mapē Desktop/datorika9-tema1 .
  4. Windows atver šo mapi. Uz 11.html nospied peles labo pogu: Open with → Edge (Atvērt ar → Edge). Pārbaudi nosaukumu un noteikumu.

Gatavs, kad: Pārlūkā redzi paša izvēlētu nosaukumu un noteikumu.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 11.html skolotāja norādītajā vietā.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • Fails 11.html atveras pārlūkā.
  • Lapā ir paša izvēlēts nosaukums un viens spēles noteikums.
  • Ir sagatavots personīgais GitHub konts.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Papildu uzdevums: Pievieno otru noteikumu

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

  1. Zem rindkopas pievieno vēl vienu <p>...</p> .
  2. Saglabā failu un pārlūkā nospied Ctrl+R .
Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 11.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Poga nestrādā? Pārbaudi, vai neizdzēsi pēdiņu, iekavu vai elementa id. Salīdzini savu laboto vietu ar sākuma kodu.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
