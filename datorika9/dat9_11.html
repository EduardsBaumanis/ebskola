1.1 Izstrādes vide un GitHub integrācija

Stundas uzdevums: Konfigurēt profesionālu programmēšanas vidi un izveidot automātisku koda sinhronizāciju ar GitHub mākoņkrātuvi.

2.3.1. Lieto programmvadāmas ierīces un pielāgo saskarni; 5.2.6. Digitālā pratība.
SR 2.3.2. Datortīklu uzbūves pamatprincipi SR 2.5.2. Tīmekļvietnes, konti un e-pakalpojumi

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — izveido mapi spele un tajā git repozitoriju · 2. uzdevums (~25 min) — nosūti index.html uz savu GitHub repozitoriju · 3. uzdevums (~20 min) — pievieno otro commit un pārbaudi vēsturi GitHub. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: datorā jābūt uzstādītam VS Code un Git; tev jābūt GitHub kontam ar apstiprinātu e-pastu un jāzina sava GitHub lietotājvārda rakstība.

Teorija: Profesionāli rīki

Visual Studio Code (VS Code) ir koda redaktors, nevis teksta apstrādes rīks (kā Word). Tas saprot koda struktūru un palīdz to rakstīt ar krāsu izcelšanu un paplašinājumiem. GitHub ir koda "mākonis", kas glabā visas tavas izmaiņas (versijas). Tas ļauj tev piekļūt savam darbam no jebkura datora un droši iesniegt mājasdarbus skolotājam.

Svarīgākie jēdzieni:

  • Repository (Repo): Tava projekta mape mākonī.
  • Commit: Izmaiņu "nofotografēšana" un saglabāšana ar komentāru.
  • Push: Saglabāto izmaiņu nosūtīšana no lokālā datora uz GitHub serveri.

# Termināļa pārbaude pirms darba sākuma
git --version
code --version
# Identitātes iestatīšana (vienreiz)
git config --global user.name "Vārds Uzvārds"
git config --global user.email "tavs@pasts.lv"

Praktiskie uzdevumi

1. uzdevums — Izveido projekta mapi ar git repozitoriju

Beigās tavā datorā būs mape spele, kurā git jau seko līdzi izmaiņām.

  1. Izveido uz darbvirsmas mapi ar nosaukumu spele (bez garumzīmēm un atstarpēm).
  2. Atver šo mapi VS Code: File → Open Folder → spele.
  3. Atver termināli ar taustiņiem Ctrl+` un izpildi git --version.
  4. Izpildi git config --global user.name "Vārds Uzvārds" ar savu vārdu.
  5. Izpildi git config --global user.email "tavs@pasts.lv" ar savu GitHub e-pastu.
  6. Izpildi git init — terminālis atbild Initialized empty Git repository.
  7. Pārbaudi ar git status, ka atbildē parādās On branch main.

Gatavs, kad: komanda git status mapē spele parāda zaru, nevis kļūdu not a git repository.

2. uzdevums — Nosūti pirmo failu uz GitHub

Beigās tavs fails index.html būs redzams GitHub lapā jebkurā datorā.

  1. Izveido mapē spele failu index.html ar rindu <h1>Mana spēle</h1> un saglabā (Ctrl+S).
  2. Atver github.com un izveido jaunu tukšu repozitoriju ar nosaukumu spele (ar README).
  3. Izpildi git remote add origin https://github.com/TAVSVARDS/spele.git ar savu lietotājvārdu.
  4. Izpildi git add index.html — terminālis neko neatbild, un tas ir pareizi.
  5. Izpildi git commit -m "Add game page".
  6. Izpildi git branch -M main.
  7. Izpildi git push -u origin main un pārlādē GitHub lapu.

Gatavs, kad: GitHub repozitorija lapā spele ir redzams fails index.html.

3. uzdevums — Pievieno otro commit un izlasi vēsturi

Beigās GitHub sadaļā "Commits" būs divi ieraksti, un tu redzēsi, kas mainījās katrā.

  1. Pievieno failā index.html rindu <p>Vadi spēli ar bultiņu taustiņiem.</p> un saglabā.
  2. Izpildi git add index.html.
  3. Izpildi git commit -m "Add control hint".
  4. Izpildi git push.
  5. Atver GitHub repozitoriju un noklikšķini uz saraksta "Commits".
  6. Noklikšķini uz jaunākā commit — zaļā krāsā jābūt tieši tai rindai, ko pievienoji.
  7. Pieraksti vienu secinājumu: ar ko git commit atšķiras no git push.

Gatavs, kad: GitHub "Commits" sarakstā ir divi ieraksti un jaunākajā zaļā krāsā redzama pievienotā <p> rinda.

Papildu uzdevums — Pievieno README ar projekta aprakstu

Beigās tava repozitorija sākumlapā būs redzams spēles nosaukums un īss apraksts.

  1. Izveido mapē spele failu README.md.
  2. Ieraksti pirmajā rindā # Mana spēle ar savu spēles nosaukumu.
  3. Pievieno zem tā divus teikumus par to, ko spēlētājs darīs.
  4. Izpildi git add README.md un git commit -m "Add project README".
  5. Izpildi git push un pārlādē GitHub lapu.

Gatavs, kad: GitHub repozitorija sākumlapā zem failu saraksta redzams tavs spēles nosaukums un apraksts.

Biežākās kļūdas (un kā tās labot):

  • Fails neparādās GitHub: Pārliecinies, vai pēc "Commit" nospiedi "Push" vai "Sync Changes".
  • VS Code neatpazīst Git: Restartē programmu pēc Git instalēšanas.
  • E-pasta apstiprināšana: GitHub neļaus veikt "Push", ja e-pasts nav apstiprināts.

Koda piemērs (viss commit → push cikls un biežākās kļūdas labošana)

# 1. Ko git redz šobrīd
git status

# 2. Sagatavo failu saglabāšanai un saglabā ar ziņu
git add index.html
git commit -m "Add control hint"

# 3. Nosūti uz GitHub
git push

# --- Ja push neizdodas ---

# Kļūda: "error: remote origin already exists"
# Nomaini esošo adresi, nevis pievieno jaunu:
git remote set-url origin https://github.com/TAVSVARDS/spele.git

# Kļūda: "src refspec main does not match any"
# Zars vēl saucas master — pārsauc to un mēģini vēlreiz:
git branch -M main
git push -u origin main

# Kļūda: "Updates were rejected" (GitHub ir jaunāka versija)
git pull --rebase
git push
Terminālī parādās 1 file changed un pēc tam main -> main.
GitHub repozitorija lapā fails index.html ir atjaunots, un "Commits" sarakstā ir jauns ieraksts ar tavu ziņu.
