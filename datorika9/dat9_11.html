1. tēma / 1.1

1.1 Sagatavo VS Code un GitHub

Šodien: Izveido un atver savu pirmo HTML failu. Sagatavo GitHub kontu.

Īsā teorija

Darba mape, VS Code, Git un GitHub

VS Code ir programma, kurā raksti un labo kodu. Atver tajā visu darba mapi datorika9-tema1, lai failu sarakstā redzētu savus šīs tēmas darbus. Git saglabā darba versijas datorā, bet GitHub glabā nosūtītās versijas internetā.

GitHub konts ļauj pieslēgties ar savu lietotājvārdu. Konta izveidošana vēl nenosūta failus uz GitHub: versiju saglabāšanu un nosūtīšanu apgūsi 1.2. un 1.3. nodarbībā.

HTML tags un teksts

Fails ar paplašinājumu .html satur tīmekļa lapas kodu. <h1> sāk galveno virsrakstu, bet </h1> to beidz. Rindkopu ietver <p> un </p>. Mainot tekstu starp tagiem, maini lapā redzamo saturu.

<h1>Zvaigžņu mednieks</h1>
<p>Spied uz zvaigznes, lai iegūtu vienu punktu.</p>

No koda līdz lapai pārlūkā

VS Code rāda kodu, bet pārlūks — no tā veidoto lapu. Pēc labojuma vispirms saglabā failu ar Ctrl+S, tad pārlūkā atjauno lapu ar Ctrl+R. Abās programmās jābūt atvērtam vienam un tam pašam failam.

Vispirms izpildi 1. un 2. uzdevumu. Šo pilno kodu izmantosi 3. uzdevumā.

1. uzdevums

Sagatavo darba mapi

Vide: Windows → VS Code

Izmanto teoriju: Darba mape, VS Code, Git un GitHub.

  1. Atver Start (Sākums) un meklē Visual Studio Code. Ja tā nav, Microsoft Store meklē Microsoft veidoto Visual Studio Code un spied Install (Instalēt). Ja tas nav atļauts, palūdz skolotāja palīdzību.
  2. Darbvirsmā (Desktop) ar peles labo pogu izvēlies New → Folder (Jauns → Mape). Nosauc mapi datorika9-tema1. Ja tāda jau ir, izmanto esošo mapi.
  3. VS Code izvēlies File → Open Folder un atver Desktop/datorika9-tema1. Ja prasa uzticēties, apstiprini savai mapei. Kreisajā failu sarakstā pārbaudi mapes nosaukumu.
  4. Palūdz skolotājam pārbaudīt, vai datorā ir Git. Ja to tikko uzstādīja, aizver un vēlreiz atver VS Code ar savu tēmas mapi.

Gatavs, kad: VS Code failu sarakstā redzama atvērtā mape datorika9-tema1, un skolotājs ir pārbaudījis Git pieejamību.

2. uzdevums

Sagatavo GitHub kontu

Vide: Pārlūks → e-pasts → pārlūks

Izmanto teoriju: GitHub konta loma.

  1. Atver GitHub. Ar esošu kontu spied Sign in (Pieslēgties); ja konta nav, spied Sign up (Reģistrēties).
  2. Ja veido kontu, izpildi reģistrācijas soļus un savā e-pastā apstiprini GitHub atsūtīto vēstuli. Ar jau apstiprinātu kontu šo soli izlaid.
  3. GitHub atver profila izvēlni un atrodi savu lietotājvārdu. Parādi skolotājam, ka esi pieslēdzies savam kontam; paroli nerādi.

Gatavs, kad: esi pieslēdzies GitHub ar savu kontu un profila izvēlnē redzi savu lietotājvārdu.

3. uzdevums

Izveido un iesniedz savu lapu

Vide: Mācību lapa → VS Code → Windows → pārlūks

Izmanto teoriju: HTML tags un teksts; saglabāšana un pārbaude pārlūkā.

  1. Sadaļā Sākuma kods nospied Kopēt sākuma kodu. VS Code nospied Ctrl+N un ielīmē visu kodu ar Ctrl+V.
  2. Atrodi <h1>Mana spēle</h1>. Aizstāj tikai tekstu Mana spēle ar savu spēles nosaukumu, saglabājot abus tagus.
  3. Atrodi <p>Šeit būs spēles noteikumi.</p>. Starp tagiem ieraksti vienu noteikumu, kas nosauc spēlētāja darbību, piemēram, “Spied uz zvaigznes, lai iegūtu vienu punktu.”
  4. Ar Ctrl+Shift+S saglabā failu kā 11.html mapē Desktop/datorika9-tema1. Pārbaudi, ka faila nosaukums nav 11.html.txt.
  5. Windows atver šo mapi, uz 11.html nospied peles labo pogu un izvēlies Open with → Edge. Pārlūkā jāredz tavs virsraksts un noteikums. Ja labo tekstu, saglabā ar Ctrl+S un atjauno lapu ar Ctrl+R.
  6. Iesniedz pārbaudīto 11.html skolotāja norādītajā vietā. Konta gatavību skolotājs pārbauda atsevišķi, kā norādīts 2. uzdevumā.

Gatavs, kad: fails 11.html atveras pārlūkā, rāda tavu nosaukumu un vienu konkrētu noteikumu un ir iesniegts.

Iesniedz 3. uzdevuma rezultātu

Iesniedz pabeigto 11.html skolotāja norādītajā vietā.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • 11.html atveras pārlūkā un rāda lapu.
  • Lapā ir paša izvēlēts nosaukums un viena <p> rindkopa ar konkrētu spēlētāja darbību.
  • Skolotājam parādīts, ka vari pieslēgties savam GitHub kontam.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Papildu uzdevums: Pievieno otru noteikumu

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Papildu uzdevums nav obligāts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

Izmanto teoriju: HTML rindkopa.

  1. Uzreiz aiz esošā </p> pievieno otru <p>...</p> ar citu konkrētu noteikumu.
  2. Saglabā un pārlūkā nospied Ctrl+R. Pārbaudi, ka abi noteikumi redzami atsevišķās rindkopās.

Gatavs, kad: pārlūkā redzamas divas atsevišķas noteikumu rindkopas.

Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši 11.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
