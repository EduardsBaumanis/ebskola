1.1 Sagatavo VS Code un GitHub

Stundas uzdevums: Lejupielādē VS Code, izveido spēles mapi ar failu index.html, reģistrējies GitHub, uzstādi Git un pieslēdz VS Code savam GitHub kontam.

2.3.1. Lieto programmvadāmas ierīces un pielāgo saskarni; 5.2.6. Digitālā pratība.
SR 2.3.2. Datortīklu uzbūves pamatprincipi SR 2.5.2. Tīmekļvietnes, konti un e-pakalpojumi

70 min plāns: Ievads (~10 min) · 1. uzdevums (~20 min) - VS Code un spēles mape · 2. uzdevums (~25 min) - GitHub konts un Git · 3. uzdevums (~15 min) - VS Code savienošana ar GitHub. Papildu uzdevumu sāc, ja paliek laiks.

Pirms sāc: vajadzīgs Windows dators, internets un piekļuve savam e-pastam. Programmas uzstādīsi un GitHub kontu izveidosi uzdevumu laikā. Ja skolas dators neļauj uzstādīt programmu, lūdz skolotāja palīdzību.

Ko izmantosim?

  • VS Code ir programma, kurā rakstīsi un labosi savas spēles failus.
  • GitHub ir vietne, kurā var glabāt savus darbus un parādīt tos citiem.
  • Git ir programma, kas palīdz saglabāt failu izmaiņas un nosūtīt tās uz GitHub.
  • index.html būs tavas spēles sākumlapa.

Tālāk pogu nosaukumi rakstīti angliski, lai vari tos atrast ekrānā. Blakus ir īss skaidrojums latviski.

Praktiskie uzdevumi

1. uzdevums - Lejupielādē VS Code un izveido spēles mapi

Uzstādi VS Code un sagatavo vietu savas spēles failiem.

  1. Atver Microsoft Store: nospied Windows pogu, ieraksti Microsoft Store un atver atrasto lietotni.
  2. Meklē Visual Studio Code. Izvēlies Microsoft piedāvāto programmu un nospied Install (Instalēt) vai Get (Iegūt). Sagaidi, līdz tā ir uzstādīta. Ja VS Code jau ir datorā, šo soli izlaid.
  3. Izveido mapi uz darbvirsmas: noklikšķini tukšā vietā ar peles labo pogu un izvēlies New → Folder (Jauns → Mape). Nosauc mapi spele.
  4. Atver VS Code. Izvēlies File → Open Folder (Fails → Atvērt mapi), atrodi darbvirsmā mapi spele un atver to.
  5. Izveido jaunu failu: nospied Ctrl+N un ieraksti <h1>Mana spēle</h1>.
  6. Saglabā failu: nospied Ctrl+S, izvēlies mapi spele un faila nosaukumā ieraksti index.html. Nospied Save (Saglabāt).

Gatavs, kad: VS Code kreisajā pusē redzi mapi spele un tajā failu index.html ar ierakstīto rindu.

2. uzdevums - Reģistrējies GitHub un lejupielādē Git

Izveido savu GitHub kontu un uzstādi datorā Git.

  1. Atver GitHub un nospied Sign up (Reģistrēties). Ja konts jau ir, izvēlies Sign in (Pieslēgties) un izmanto to.
  2. Izveido kontu: ievadi savu e-pastu, izdomā paroli un izvēlies lietotājvārdu. Seko norādēm ekrānā.
  3. Apstiprini e-pastu: atver GitHub atsūtīto vēstuli un izpildi tajā norādīto. Pēc tam pieslēdzies GitHub. Ja izmanto jau esošu, apstiprinātu kontu, 2. un 3. soli izlaid.
  4. Lejupielādē Git: atver Git lejupielādes lapu Windows datoriem un nospied lapas augšpusē esošo lejupielādes saiti Click here to download.
  5. Uzstādi Git: atver lejupielādēto failu. Atstāj piedāvātos iestatījumus un spied Next (Tālāk), tad Install (Instalēt) un beigās Finish (Pabeigt). Ja Git jau ir datorā, lejupielādi un uzstādīšanu izlaid.
  6. Aizver VS Code un atver to vēlreiz, lai programma varētu atrast tikko uzstādīto Git.

Git programmai atsevišķs konts nav jāveido.

Gatavs, kad: vari pieslēgties savam GitHub kontam, e-pasts ir apstiprināts un Git ir uzstādīts datorā.

3. uzdevums - Savieno VS Code ar GitHub

Pieslēdzies savam GitHub kontam arī VS Code programmā.

  1. Atver VS Code un kreisajā apakšējā stūrī nospied cilvēciņa ikonu Accounts (Konti).
  2. Izvēlies Backup and Sync Settings… (Saglabāt un saskaņot iestatījumus). Šādi vari atvērt pieslēgšanos savam kontam.
  3. Nospied Sign in (Pieslēgties) un izvēlies Sign in with GitHub (Pieslēgties ar GitHub). Ja redzi iestatījumu sarakstu, vari atstāt piedāvātās izvēles.
  4. Pārlūkā pieslēdzies savam GitHub kontam, ja tas tiek prasīts. Izmanto 2. uzdevumā izveidoto kontu.
  5. Apstiprini pieslēgšanos, ja parādās poga Authorize Visual Studio Code (Atļaut VS Code piekļuvi). Ja pārlūks jautā, vai atvērt VS Code, atļauj to.
  6. Atgriezies VS Code un vēlreiz atver Accounts. Pārbaudi, vai tur redzi savu GitHub lietotājvārdu.

Ja tavs GitHub konts jau redzams Accounts izvēlnē, atkārtoti pieslēgties nevajag. Šī pieslēgšanās ļauj saglabāt VS Code iestatījumus lietošanai arī citā datorā. Spēles fails pagaidām paliek tavā datorā; tā nosūtīšanu uz GitHub apgūsi vēlāk.

Gatavs, kad: VS Code izvēlnē Accounts redzi savu GitHub lietotājvārdu.

Papildu uzdevums - Apskati savu lapu

Ja visi trīs uzdevumi ir gatavi, apskati savu pirmo spēles lapu pārlūkā.

  1. Atver darbvirsmā mapi spele. Uz faila index.html nospied peles labo pogu un izvēlies Open with (Atvērt ar), tad savu pārlūku, piemēram, Edge vai Chrome.
  2. Pārbaudi, vai lapā redzi virsrakstu “Mana spēle”.
  3. Atgriezies VS Code un tekstu “Mana spēle” aizstāj ar savu spēles nosaukumu. Saglabā ar Ctrl+S.
  4. Pārlūkā nospied Ctrl+R, lai pārlādētu lapu un ieraudzītu jauno nosaukumu.

Gatavs, kad: pārlūkā redzi savu spēles nosaukumu.

Ja kaut kas neizdodas

  • Nevari uzstādīt VS Code vai Git: ja dators prasa administratora paroli vai neļauj turpināt, lūdz skolotāja palīdzību.
  • VS Code neredzi savu failu: ar File → Open Folder atver mapi spele. Pārbaudi, vai failu saglabāji šajā mapē un tā nosaukums ir tieši index.html.
  • GitHub e-pasts nav atnācis: pārbaudi mēstuļu mapi un to, vai e-pasta adresi ierakstīji pareizi.
  • Neatrodi pieslēgšanās pogu: nospied zobrata ikonu VS Code kreisajā apakšējā stūrī un meklē Backup and Sync Settings…. Tad turpini pēc 3. uzdevuma soļiem.
  • Pārlūks neatver VS Code: apstiprini atļauju atvērt Visual Studio Code. Ja pieslēgšanos nejauši atcēli, atkārto 3. uzdevuma soļus.
  • VS Code rāda cita cilvēka kontu: lūdz skolotāja palīdzību, lai pieslēgtos savam kontam.

Pirms stundas beigām

Parādi skolotājam:

  • VS Code atvērtu mapi spele un failu index.html.
  • Savu GitHub kontu pārlūkā un datorā uzstādīto Git.
  • Savu GitHub lietotājvārdu VS Code izvēlnē Accounts.

Atceries saglabāt failu ar Ctrl+S.

Papildu palīdzība angļu valodā: VS Code pamācība par pieslēgšanos un iestatījumu saglabāšanu.
