2.2 Izkārtojuma kontrole un "Box Model"

Stundas uzdevums: Pārveidot haotisku saturu sakārtotā dizainā, kontrolējot elementu izmērus, atkāpes un apmales atbilstoši "Box Model" principiem.

1.1.1. Secina par struktūru un ergonomiku; 2.4.1. Strukturē teksta dokumentu atbilstoši prasībām.
SR 2.4.9. Satura sinhronizācija starp dokumentiem

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - uztaisi kasti ar padding un border · 2. uzdevums (~25 min) - centrē spēles laukumu 400×300 px · 3. uzdevums (~20 min) - salabo kastes platumu ar box-sizing. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu projektu VS Code, atver index.html un style.css, kas tapa 2.1 stundā, un pārlūkā ieslēdz DevTools ar F12.

Teorija: Kas ir Box Model?

Katrs HTML elements pārlūka acīs ir taisnstūra kaste. Box Model sastāv no četrām daļām:

  • Content: Pašsaturs (teksts, attēls).
  • Padding (Iekšējā atkāpe): Telpa starp saturu un apmali. Tā padara elementu "elpojošāku".
  • Border (Apmale): līnija apkārt paddingam un saturam.
  • Margin (Ārējā atkāpe): Telpa ap elementu, kas atgrūž citus elementus.
Pareiza šo īpašību lietošana nodrošina spēles saskarnes (UI) skaidrību un lietojamību. 

/* Box Model: padding ir iekšpusē, margin ārpusē */
.kaste {
  width: 200px;
  padding: 16px;       /* iekšējā atstarpe */
  border: 2px solid #948979;
  margin: 20px auto;   /* ārējā atstarpe + centrēšana */
}
/* Flex izkārtojums */
.menu { display: flex; gap: 12px; justify-content: center; }

Praktiskie uzdevumi

1. uzdevums - Uztaisi pirmo kasti ar padding un border

Beigās tavā lapā būs 200 px plata kaste ar apmali, un teksts tajā nepieskarsies malai.

.kaste {
  width: 200px;
  padding: 16px;       /* iekšējā atstarpe */
  border: 2px solid #948979;
  margin: 20px auto;   /* ārējā atstarpe + centrēšana */
}
  1. Nokopē augšējo CSS bloku style.css faila beigās.
  2. Atver index.html un pievieno <div class="kaste">Testa kaste</div>.
  3. Saglabā abus failus un pārlādē lapu ar F5.
  4. Nomaini padding no 16px uz 2px un pārlādē lapu vēlreiz.
  5. Salīdzini, cik tuvu teksts tagad ir apmalei, un atgriez 16px atpakaļ.

Gatavs, kad: lapas vidū ir kaste ar redzamu apmali un brīvu vietu starp tekstu un apmali.

2. uzdevums - Centrē spēles laukumu 400×300 px

Beigās tavas spēles laukums būs noteikta izmēra taisnstūris tieši lapas vidū.

  1. Atver style.css un pievieno klasi .speles-laukums { width: 400px; height: 300px; background-color: #393E46; }.
  2. Pievieno tai pašai klasei padding: 16px; border: 3px solid #FFB142; border-radius: 8px;.
  3. Pievieno tai arī margin: 20px auto; - vārds auto centrē laukumu horizontāli.
  4. Atver index.html un pieraksti class="speles-laukums" pie galvenā spēles <div>.
  5. Saglabā un pārlādē lapu pārlūkā.
  6. Atlasi DevTools cilnē "Elements" spēles laukumu un apskati "Box Model" diagrammu.
  7. Veic git commit -m "Style game container with box model".

Gatavs, kad: spēles laukums ir oranži apmalīts taisnstūris tieši lapas vidū, arī paplašinot pārlūka logu.

3. uzdevums - Salabo laukuma platumu ar box-sizing

Beigās tavs spēles laukums aizņems tieši 400 px, nevis 438 px kopā ar apmali un atkāpi.

  1. Atlasi DevTools cilnē "Elements" spēles laukumu un nolasi tā īsto platumu Box Model diagrammā.
  2. Saskaiti README.md failā: 400 + 16 + 16 + 3 + 3 - tik pikseļu laukums aizņem patiesībā.
  3. Pievieno style.css klasei .speles-laukums rindu box-sizing: border-box;.
  4. Pārlādē lapu un nolasi platumu DevTools vēlreiz - tagad jābūt 400 px.
  5. Pievieno vēl max-width: 100%;, lai laukums neizspiestos ārpus šaura ekrāna.
  6. Sašaurini pārlūka logu līdz pusei un pārbaudi, vai parādās horizontālā ritjosla.
  7. Pieraksti vienu secinājumu: ko tieši border-box maina platuma aprēķinā.

Gatavs, kad: DevTools rāda laukuma platumu 400 px un šaurā logā nav horizontālās ritjoslas.

Papildu uzdevums - Saliec izvēlnes pogas rindā ar Flexbox

Beigās tavas trīs izvēlnes pogas stāvēs vienā rindā ar vienādu atstarpi.

  1. Pievieno style.css kārtulu .menu-pogas { display: flex; gap: 12px; justify-content: center; }.
  2. Atver index.html un ieliec trīs pogas iekšā <div class="menu-pogas">.
  3. Pārlādē lapu un paskaties, vai pogas stāv blakus.
  4. Nomaini justify-content uz space-between un pārlādē vēlreiz.
  5. Atgriez vērtību center un pievieno flex-wrap: wrap;.
  6. Veic git commit -m "Add flex layout for menu buttons".

Gatavs, kad: pogas stāv rindā lapas vidū un šaurā logā pārceļas uz nākamo rindu, nevis izlien ārā.

Biežākās kļūdas (un kā tās labot):

  • Kastes kopējais platums: Atceries, ka width + padding + border summējas. Ja lapa "iziet" no rāmjiem, izmanto box-sizing: border-box;.
  • Margin sabrukšana: Divi kaimiņu margini nevis saskaitās, bet pārklājas (lielākais uzvar).
  • Padding trūkums: Teksts, kas pieskaras apmalei, izskatās neprofesionāli un ir grūti lasāms.

Koda piemērs (kāpēc 400 px kaste aizņem 430 px un kā to salabot)

/* NEPAREIZI: pārlūks rēķina 400 + 10 + 10 + 5 + 5 = 430 px.
   Tieši tāpēc laukums izspiežas ārpus ekrāna. */
#game-container {
    width: 400px;
    padding: 10px;
    border: 5px solid #333;
}

/* PAREIZI: border-box ieskaita padding un border iekšā 400 px */
#game-container {
    width: 400px;
    height: 300px;
    padding: 10px;
    border: 5px solid #333;
    margin: 20px auto;      /* auto = centrēts horizontāli */
    background-color: #95a5a6;
    box-sizing: border-box; /* satura laukums saruk līdz 370 px */
    max-width: 100%;        /* neizspiežas šaurā ekrānā */
}

DevTools Box Model diagrammā pirmajā variantā redzēsi platumu 430 px, otrajā - tieši 400 px. Kaste paliek lapas vidū arī tad, ja logu sašaurina.
