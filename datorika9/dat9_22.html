2.2 Sakārto atstarpes un spēles laukumu

Sasniedzamais rezultāts: Izveido noteikta izmēra spēles laukumu ar atstarpēm un rāmi.

SR 2.6.1. Algoritmu pieraksts un izpilde

Teorija ar piemēriem

Katram lapas blokam ir savs laukums (kastes modelis)

CSS valodā katrs lapas elements — virsraksts, spēles laukums vai poga — ir taisnstūra kaste ar četriem slāņiem no iekšpuses uz āru: pašā vidū ir saturs (teksts vai attēls), ap to ir iekšējā atstarpe (padding), tad apmale (border) un ārpus apmales — ārējā atstarpe (margin), kas atdala šo bloku no kaimiņu elementiem.

Īpašība Ko tā maina? Piemērs
width un height Bloka platumu un augstumu pikseļos. width: 320px;
padding Brīvo vietu bloka iekšpusē starp saturu un apmali (tajā pašā fona krāsā). padding: 16px;
border Apmali trīs daļās: biezums, līnijas veids (solid — nepārtraukta, dashed — raustīta) un krāsa. border: 4px solid #0f766e;
margin Tukšo atstarpi ārpus apmales līdz citiem elementiem. margin: 16px auto;
box-sizing Ar vērtību border-box iekļauj padding un border kopējā bloka platumā un augstumā. box-sizing: border-box;
max-width Maksimālais platums — 100% neļauj blokam iziet ārpus šaura loga malām. max-width: 100%;

Viens vai divi skaitļi atstarpēs: ja pie padding vai margin raksta vienu vērtību (piemēram, padding: 20px;), vienāda atstarpe tiek uzlikta visās četrās malās. Ja raksta divas vērtības ar atstarpi (piemēram, padding: 10px 18px;), pirmā nosaka atstarpi augšā un apakšā, bet otrā — pa kreisi un pa labi.

Kā rēķina bloka kopējo izmēru (box-sizing)

Apskati paraugu informācijas kartītei ar platumu 320px, iekšējo atstarpi 16px un 4px biezu apmali:

.paraugs {
  width: 320px;
  height: 180px;
  padding: 16px;
  border: 4px solid #0f766e;
  background-color: #f0fdfa;
  box-sizing: border-box;
}

Rinda box-sizing: border-box; nodrošina, ka visa kaste kopā uz ekrāna aizņem tieši 320 pikseļus, jo abas apmales un abas iekšējās atstarpes tiek ierēķinātas šajā platumā. Saturam iekšpusē paliek 320 − 16 − 16 − 4 − 4 = 280 pikseļi. Bez border-box pārlūks atstarpes un apmali pieskaitītu klāt (320 + 32 + 8 = 360 px), un kaste kļūtu platāka nekā plānots. Ārējā atstarpe (margin) vienmēr paliek ārpus rāmja un šajos 320 pikseļos neietilpst.

Centrēšana ar auto un pielāgošana šauram logam

2.1. nodarbībā ar text-align: center; mēs centrējām tekstu bloka iekšpusē. Lai lapas vidū novietotu pašu taisnstūra bloku, tam uzdod platumu (width) un kreisajai/labajai ārējai atstarpei iestata vērtību auto:

margin: 20px auto;

Pirmā vērtība (20px) atstāj 20 pikseļus virs un zem bloka, bet otrā (auto) brīvo vietu kreisajā un labajā pusē sadala uz pusēm — tā bloks nostājas tieši pa vidu.

Ja blokam ir tikai fiksēts platums (piemēram, width: 360px;), tad logā, kas ir šaurāks par 360 pikseļiem, bloks nespēj sarauties: tā labā mala iziet ārpus ekrāna un parādās neērta horizontālā ritjosla. Pievienojot max-width: 100%;, bloks plašā ekrānā saglabā savu pilno platumu, bet šaurā logā automātiski sašaurinās līdz pieejamajai vietai. Ja sašaurinātā logā teksts sadalās vairākās rindās un vairs neietilpst fiksētā augstumā, tekstu saīsina vai height aizstāj ar min-height (minimālo augstumu, kas ļauj blokam pastiepties uz leju).

Pašpārbaude: spēles laukumā teksts gandrīz pieskaras rāmim, un abas pogas zem laukuma ir pārāk cieši kopā — kur jāmaina padding un kur margin?

Tekstam laukuma iekšpusē jāpalielina .laukums īpašība padding, jo vajadzīga brīva vieta starp saturu un apmali. Savukārt pogu atdalīšanai vienai no otras jāpalielina button īpašība margin, jo tā rada atstarpi ārpus pogu malām.

1. uzdevums

Izveido spēles laukuma izmēru un apmali

Izmanto teoriju: Kastes modelis un Kā rēķina bloka kopējo izmēru.

Vide: VS Code → pārlūks

  1. Windows mapē Desktop/datorika9-tema2 atver saglabāto 22.html pārlūkā (Open with → Edge) un novēro sākuma skatu: nelielu laukumu kreisajā malā un divas pogas cieši zem tā.
  2. VS Code HTML daļā nomaini <title> un <h1> uz savas spēles nosaukumu, bet CSS blokā h1 { ... } pievieno text-align: center;.
  3. Bloka <div class="laukums"> iekšpusē nomaini <p>Šeit būs spēle.</p> uz savas spēles darbības aprakstu un zem tā pievieno vēl vienu <p> rindkopu (piemēram, par pirmo līmeni vai uzdevumu laukumā).
  4. CSS blokā .laukums { ... } nomaini platumu un augstumu uz width: 360px; un height: 240px;.
  5. Saglabā failu ar Ctrl+S un atjauno pārlūku ar Ctrl+R, lai redzētu, kā izmainījās spēles laukuma izmērs un virsraksta novietojums.
  6. Tajā pašā .laukums { ... } blokā pielāgo apmali border savai spēlei (piemēram, 3px solid #174ea6 vai raustītu 3px dashed #174ea6) un izvēlies pieskaņotu background-color, paturot rindu box-sizing: border-box;.
  7. Saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka abas rindkopas uz laukuma fona ir labi salasāmas (ja izvēlējies tumšu laukuma fonu, tajā pašā blokā pievieno gaišu color).

Gatavs, kad: spēles laukuma izmēri ir 360 × 240 px, tajā ir divas ar spēli saistītas rindkopas, un pārlūkā redzams pielāgots rāmis un fons.

2. uzdevums

Sakārto iekšējās un ārējās atstarpes

Izmanto teoriju: Kastes modelis un Centrēšana ar auto.

Vide: VS Code → pārlūks

  1. Apskati .laukums pārlūkā: šobrīd padding: 8px; atstāj šauru malu iekšpusē, tāpēc teksts atrodas tuvu rāmim, bet pats laukums stāv lapas kreisajā pusē.
  2. CSS blokā .laukums { ... } nomaini padding: 8px; uz padding: 20px;, saglabā ar Ctrl+S un atjauno pārlūku ar Ctrl+R — ievēro, kā teksts atkāpās no visām četrām rāmja malām, kamēr ārējais platums palika 360px.
  3. Tajā pašā .laukums { ... } blokā pievieno rindu margin: 20px auto;, saglabā un atjauno pārlūku: pārliecinies, ka laukums nostājās lapas vidū un ieguva 20px atstarpi virs un zem apmales.
  4. Pievieno .laukums { ... } blokam arī border-radius: 12px;, saglabā un pārbaudi pārlūkā, kā noapaļojas laukuma rāmis.
  5. Atrodi button { ... } bloku un nomaini pogu iekšējo atstarpi no padding: 8px 12px; uz padding: 10px 18px;; saglabā un pārlūkā novēro, ka pašas pogas kļuva plašākas ap uzrakstiem Sākt un Noteikumi.
  6. Tajā pašā button { ... } blokā nomaini margin: 4px; uz margin: 8px 10px; un pieskaņo pogu background-color savai spēlei; saglabā ar Ctrl+S un pārlūkā ar Ctrl+R pārliecinies, ka starp pogām ir skaidra atstarpe.

Gatavs, kad: spēles laukumam ir 20px iekšējā atstarpe, noapaļots rāmis un centrēts novietojums ar margin: 20px auto, un abām pogām ir sakārtots gan padding, gan margin.

3. uzdevums

Pielāgo laukumu šauram logam

Izmanto teoriju: Centrēšana ar auto un pielāgošana šauram logam.

Vide: pārlūks → VS Code → pārlūks

  1. Pirms maini kodu, pārbaudi problēmu pārlūkā: sašaurini pārlūka logu un, ja logs neļauj sašaurināt zem 360px, pietuvini skatu ar Ctrl un + (līdz 175%–200%) — ievēro, ka laukuma labā mala iziet ārpus ekrāna un apakšā parādās horizontālā ritjosla.
  2. Atgriezies VS Code un CSS blokā .laukums { ... } pirms aizverošās iekavas } pievieno rindu max-width: 100%;.
  3. Saglabā failu ar Ctrl+S un tajā pašā sašaurinātajā pārlūka logā nospied Ctrl+R: pārliecinies, ka horizontālā ritjosla pazuda un abas laukuma apmales pilnībā ietilpst logā.
  4. Sašaurinātajā skatā pārbaudi tekstu .laukums iekšpusē — tam jāatrodas vismaz 20px no rāmja un tas nedrīkst iziet pāri apakšējai apmalei (ja teksts ir garš, saīsini to vai nomaini height: 240px; uz min-height: 240px;).
  5. Tajā pašā šaurajā skatā pārbaudi abas pogas zem laukuma: pārliecinies, ka uzraksti Sākt un Noteikumi ir pilnībā redzami un pogas nepārklājas.
  6. Pārlūkā nospied Ctrl+0, lai atgrieztu 100% mērogu, izplet logu pilnā platumā, pārbaudi, ka plašā ekrānā laukums joprojām stāv centrā 360px platumā, un saglabā gala izmaiņas ar Ctrl+S.

Gatavs, kad: plašā logā laukums ir centrēts 360px platumā, bet sašaurinātā skatā tas automātiski saraujas bez sāniskas ritināšanas un teksts paliek rāmja iekšpusē.

Papildu uzdevums: Centrē pogas vienā rindā ar Flexbox

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Atstarpes starp elementiem.

  1. HTML daļā abas <button> pogas ietver kopīgā blokā <div class="pogas">...</div> tieši zem </div>, kas noslēdz .laukums.
  2. CSS daļas beigās (tieši virs </style>) pievieno noteikumu .pogas { display: flex; justify-content: center; gap: 12px; flex-wrap: wrap; }.
  3. Blokā button { ... } nomaini margin uz margin: 0;, lai vienādu 12px atstarpi starp pogām veidotu gap: 12px;, un saglabā failu ar Ctrl+S.
  4. Atjauno pārlūku ar Ctrl+R un pārbaudi gan platā, gan sašaurinātā logā, ka abas pogas atrodas centrētā rindā zem spēles laukuma.

Gatavs, kad: abas pogas stāv centrētas zem spēles laukuma ar 12px atstarpi un šaurā ekrānā glīti pārceļas jaunā rindā.

Ja kaut kas neizdodas
  • Neredzi izmaiņas pārlūkā? VS Code nospied Ctrl+S, pēc tam pārlūkā nospied Ctrl+R. Pārbaudi, ka pārlūkā atvērts tieši Desktop/datorika9-tema2/22.html.
  • Laukums nenostājas lapas vidū? Pārbaudi, ka .laukums blokā ir gan platums (width: 360px;), gan rinda margin: 20px auto; ar atstarpi starp 20px un auto (bez komata) un semikolu beigās.
  • Apmale pazuda pēc labošanas? Īpašībā border vienmēr jābūt trim daļām ar atstarpēm — biezumam, līnijas veidam un krāsai, piemēram, border: 3px solid #174ea6;. Ja izdzēš vārdu solid vai dashed, rāmis netiek uzzīmēts.
  • Izmērs vai atstarpe nestrādā? Pārbaudi, ka starp skaitli un mērvienību nav atstarpes (360px, 20px, 100%) un iepriekšējās rindas beigās nav aizmirsts semikols (;).
  • Kods pārlūkā redzams kā parasts teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka faila beigās nav .txt.
