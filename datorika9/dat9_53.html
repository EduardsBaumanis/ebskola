5.3 Spēles pamatloģikas programmēšana

Tavs šīs stundas izaicinājums: Apvienot UI elementus ar spēles dzinēju, nodrošinot pilnu spēles ciklu: palaišanu, aktīvo darbību un rezultātu fiksēšanu.

2.6.1. Programmē un strukturē kodu; 2.6.2. Veic algoritmu un programmu testēšanu.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — palaid stāvokļa objektu spele un funkciju zaudetDzivibu() konsolē · 2. uzdevums (~25 min) — savieno stāvokļa objektu ar HUD un spēles sākšanu · 3. uzdevums (~20 min) — izspēlē pilnu ciklu no sākuma līdz restartam un salabo vienu kļūdu. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu spēles projektu un pārliecinies, ka 5.2 stundas trīs ekrāni (#menu, #spele-logs, #beigas) un HUD jau darbojas.

Teorija: Spēles stāvokļa vadība

Laba spēle sastāv no skaidriem stāvokļiem (States). Tavai programmai ir jāzina:

  • Gaidīšanas režīms: Redzama sākuma izvēlne, nekas nekustas.
  • Aktīvā spēle: Izvēlne paslēpta, taimeri darbojas, ienaidnieki kustas.
  • Beigu stāvoklis (Game Over): Viss apstājas, parādās rezultāts un poga "Mēģināt vēlreiz".
Svarīgi: Atceries vienmēr resetot (atjaunot uz sākuma vērtībām) mainīgos, kad spēle tiek sākta no jauna, citādi punkti turpinās skaitīties no iepriekšējās reizes! 

// Viss spēles stāvoklis vienā objektā
const spele = { dzivibas: 3, punkti: 0, limenis: 1, aktiva: false };

function zaudetDzivibu() {
  spele.dzivibas--;
  console.log("Dzīvības:", spele.dzivibas);
  if (spele.dzivibas <= 0) {
    spele.aktiva = false;
    console.log("GAME OVER");
  }
}

Praktiskie uzdevumi

1. uzdevums — Palaid dzīvību skaitītāju konsolē

Beigās pārlūka konsolē pēc trim izsaukumiem parādīsies uzraksts GAME OVER.

Nokopējamais paraugs: ielīmē to script.js faila sākumā.

// Viss spēles stāvoklis vienā objektā
const spele = { dzivibas: 3, punkti: 0, limenis: 1, aktiva: false };

function zaudetDzivibu() {
  spele.dzivibas--;
  console.log("Dzīvības:", spele.dzivibas);
  if (spele.dzivibas <= 0) {
    spele.aktiva = false;
    console.log("GAME OVER");
  }
}
  1. Atver script.js un ielīmē paraugu faila pašā sākumā.
  2. Saglabā failu un atver lapu pārlūkā ar F12 atvērtu konsoli.
  3. Ieraksti konsolē zaudetDzivibu() un nospied Enter trīs reizes.
  4. Ieraksti konsolē spele un apskati visas objekta vērtības.
  5. Nomaini kodā sākuma vērtību dzivibas: 3 uz dzivibas: 5.
  6. Pārlādē lapu un atkārto izsaukumus — tagad GAME OVER jāparādās pēc piektās reizes.

Gatavs, kad: konsolē redzama rinda "Dzīvības: 0" un tūlīt aiz tās "GAME OVER".

2. uzdevums — Savieno stāvokļa objektu ar HUD un spēles sākšanu

Beigās punkti un dzīvības ekrānā mainīsies pašas, tiklīdz mainās objekta spele vērtības.

  1. Izveido script.js funkciju atjaunotHud(), kas ieraksta spele.punkti elementā #punkti.
  2. Papildini to ar rindu, kas ieraksta spele.dzivibas elementā #dzivibas.
  3. Atjaunini funkciju saktSpeli(): iestati spele.punkti = 0, spele.dzivibas = 3, spele.aktiva = true.
  4. Izsauc atjaunotHud() funkcijas saktSpeli() beigās un funkcijā zaudetDzivibu().
  5. Pievieno funkcijas zaudetDzivibu() beigās izsaukumu beigtSpeli(), kad dzīvības sasniedz 0.
  6. Saglabā un sāc spēli — HUD jārāda 0 punkti un 3 dzīvības.
  7. Izpildi git commit -am "Connect game state to HUD".

Gatavs, kad: katra sadursme ar pretinieku uzreiz samazina HUD dzīvību skaitli par vienu.

3. uzdevums — Izspēlē pilnu ciklu līdz restartam un salabo vienu kļūdu

Beigās pēc "Mēģināt vēlreiz" spēle sāksies ar 0 punktiem un 3 dzīvībām.

  1. Sāc spēli un zaudē vienu dzīvību — HUD jārāda 2.
  2. Zaudē atlikušās dzīvības — jāparādās beigu ekrānam un pretiniekiem jāapstājas.
  3. Pārbaudi konsolē, ka spele.aktiva tagad ir false.
  4. Nospied "Mēģināt vēlreiz" un paskaties HUD skaitļus.
  5. Salabo vienu atrasto kļūdu, piemēram, punktus, kas turpinās no iepriekšējās kārtas.
  6. Pieraksti vienu secinājumu: kāpēc viens objekts spele ir ērtāks par pieciem atsevišķiem mainīgajiem.

Gatavs, kad: divas kārtas pēc kārtas sākas ar vienādiem skaitļiem HUD panelī.

Papildu uzdevums — Pievieno pauzi ar taustiņu P

Beigās taustiņš P apturēs spēli un otrs spiediens to atsāks no tās pašas vietas.

  1. Pievieno script.js notikuma klausītāju document.addEventListener("keydown", ...).
  2. Pārbaudi tajā, vai e.key === "p", un tad apgriez vērtību: spele.aktiva = !spele.aktiva;.
  3. Pievieno galvenā cikla funkcijas pirmajā rindā if (!spele.aktiva) return;.
  4. Atver pārlūkā, sāc spēli un nospied P — visam jāapstājas.
  5. Nospied P vēlreiz un pārbaudi, ka spēle turpinās ar tiem pašiem punktiem.
  6. Izpildi git commit -am "Add pause on P key".

Gatavs, kad: ar P nospiestu pretinieki stāv uz vietas, un ar otru spiedienu turpina kustēties.

Biežākās kļūdas (un kā tās labot):

  • "Restart" kļūda: Spēlētājs nospiež "Mēģināt vēlreiz", bet laiks iet divreiz ātrāk. Risinājums: Vienmēr izmanto clearInterval() pirms jauna taimera sākšanas.
  • Mainīgie netiek atiestatīti: Jaunā spēlē dzīvības joprojām ir 0. Risinājums: Funkcijas saktSpeli() sākumā iestati spele.dzivibas = 3; spele.punkti = 0;.
  • Klaviatūras "bug": Spēlētājs var kustināt varoni, kamēr vēl redzama sākuma izvēlne. Risinājums: Pirms kustības pārbaudi if (!spele.aktiva) return;.

Koda piemērs (restarts, kas nesāk otru setInterval)

let spelesIntervals = null;

function atjaunotHud() {
    document.getElementById("punkti").textContent = spele.punkti;
    document.getElementById("dzivibas").textContent = spele.dzivibas;
}

function saktSpeli() {
    // 1. Apturam iepriekšējo ciklu, ja tāds vēl skrien!
    clearInterval(spelesIntervals);

    // 2. Atiestatām visus datus uz sākuma vērtībām
    spele.punkti = 0;
    spele.dzivibas = 3;
    spele.aktiva = true;
    atjaunotHud();

    // 3. Pārslēdzam ekrānus
    document.getElementById("menu").style.display = "none";
    document.getElementById("beigas").style.display = "none";
    document.getElementById("spele-logs").style.display = "block";

    // 4. Palaižam dzinēju no jauna
    spelesIntervals = setInterval(galvenaisCikls, 20);
}

function galvenaisCikls() {
    if (!spele.aktiva) return; // pauzē nekas nenotiek
    kustinatObjektus();
    parbauditSadursmes();
}

function beigtSpeli() {
    clearInterval(spelesIntervals);
    spele.aktiva = false;
    document.getElementById("gala-rezultats").textContent = spele.punkti;
    document.getElementById("spele-logs").style.display = "none";
    document.getElementById("beigas").style.display = "block";
}
Spēli var restartēt piecas reizes pēc kārtas, un objekti kustas tikpat ātri kā pirmajā reizē. Ja clearInterval() pirms setInterval() nav, katrs restarts pievieno vēl vienu ciklu un spēle kļūst arvien ātrāka.
