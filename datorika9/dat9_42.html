4.2 Notikumu klausītāji (Event Listeners) un interakcija

Stundas uzdevums: Piesaistīt izstrādātās JavaScript funkcijas reālām lietotāja darbībām (peles klikšķiem un klaviatūras taustiņiem), padarot spēles saskarni pilnībā interaktīvu.

2.6.1. Ievēro programmas pieraksta labo praksi; 1.3.3. Īsteno risinājumu atbilstoši plānam.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - parādi lapā nospiestā taustiņa nosaukumu · 2. uzdevums (~25 min) - vadi spēlētāja kvadrātu ar bultiņu taustiņiem · 3. uzdevums (~20 min) - pievieno laukuma robežas un pārbaudi tās. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu spēles mapi koda redaktorā ar failiem index.html un script.js, un atver index.html pārlūkā.

Teorija: Kā iemācīt lapai "klausīties"?

Lai pārlūkprogramma zinātu, kad izsaukt tavu funkciju, mēs izmantojam notikumu klausītājus (Event Listeners). Tas ir kā neredzams sargs, kas stāv pie HTML elementa un gaida, kad notiks konkrēta darbība (notikums).

  • Notikumu veidi: click (peles klikšķis), keydown (taustiņa nospiešana), mouseenter (peles novietošana virs elementa).
  • Sintakse: elements.addEventListener('notikums', funkcijasNosaukums);
  • Notikuma objekts (Event Object): Kad notiek darbība, pārlūks bieži nodod papildu informāciju (piemēram, KURU tieši taustiņu tu nospiedi). Mēs to varam "noķert" funkcijas parametros, visbiežāk apzīmējot ar burtu e vai event.
Piezīme: Projektos parasti izvairāmies no onclick="" rakstīšanas tieši HTML failā. HTML ir struktūrai, JS ir uzvedībai!

Praktiskie uzdevumi

1. uzdevums - Parādi lapā nospiestā taustiņa nosaukumu

Beigās lapā parādīsies tā taustiņa nosaukums, ko tu tikko nospiedi.

Kopējamais paraugs: viena rinda HTML failā un viens klausītājs JavaScript failā.

<p id="taustins">Nospied jebkuru taustiņu</p>
document.addEventListener("keydown", function (e) {
  document.getElementById("taustins").textContent = "Nospiests: " + e.key;
});
  1. Atver index.html un ielīmē rindu ar id="taustins" pirms </body>.
  2. Atver script.js un ielīmē klausītāja kodu faila beigās.
  3. Saglabā abus failus un pārlādē lapu pārlūkā.
  4. Nospied bultiņu pa labi - lapā jāparādās tekstam "Nospiests: ArrowRight".
  5. Nospied atstarpes taustiņu un pieraksti, kāds nosaukums parādās.
  6. Nomaini vārdu "keydown" uz "keyup" un pārbaudi, kad teksts tagad mainās.

Gatavs, kad: spiežot dažādus taustiņus, teksts lapā katru reizi nomainās uz citu nosaukumu.

2. uzdevums - Vadi spēlētāja kvadrātu ar bultiņu taustiņiem

Beigās zilais kvadrāts pārvietosies pa kreisi un pa labi, kad spiedīsi bultiņu taustiņus.

  1. Atver index.html un pievieno spēles laukumu: <div id="laukums" style="position:relative;width:400px;height:300px;border:2px solid #fff;overflow:hidden;"></div>.
  2. Pievieno laukuma iekšpusē spēlētāju: <div id="speletajs" style="position:absolute;left:180px;top:250px;width:40px;height:40px;background:blue;"></div>.
  3. Atver script.js un uzraksti faila augšā let spX = 180;.
  4. Uzraksti funkciju atjaunotSpeletaju(), kas iestata style.left uz spX + "px".
  5. Pievieno keydown klausītāju, kurā "ArrowLeft" atņem 10 no spX, bet "ArrowRight" pieskaita 10.
  6. Izsauc atjaunotSpeletaju() klausītāja beigās, saglabā failu un pārlādē lapu.

Gatavs, kad: katrs bultiņas nospiediens pārvieto zilo kvadrātu par 10 pikseļiem pa laukumu.

3. uzdevums - Pievieno laukuma robežas un pārbaudi tās

Beigās kvadrāts apstāsies pie laukuma malām, nevis izlīdīs ārā no rāmja.

  1. Nospied bultiņu pa kreisi 25 reizes un vēro, kā kvadrāts pazūd aiz laukuma malas.
  2. Atver script.js un pievieno pirmo robežu: ja spX < 0, iestati spX = 0.
  3. Pievieno otro robežu: ja spX > 360, iestati spX = 360.
  4. Pārlādē lapu un turi bultiņu nospiestu abos virzienos līdz galam.
  5. Salabo, ja kvadrāts nemaz nekustas: pārbaudi, vai id="speletajs" sakrīt ar tekstu getElementById izsaukumā.
  6. Pieraksti vienu secinājumu: kāpēc addEventListener ir labāks par onclick="" tieši HTML failā.

Gatavs, kad: kvadrāts apstājas pie abām malām un nekad neizlien ārpus laukuma rāmja.

Papildu uzdevums - Pievieno šaušanu ar peles klikšķi

Beigās klikšķis uz spēles laukuma parādīs "Šāviens!" un pieskaitīs 5 punktus.

  1. Atver index.html un pievieno zem laukuma rindu <p id="statuss">Gatavs</p>.
  2. Atver script.js un uzraksti funkciju saut(), kas ieraksta "Šāviens!" elementā #statuss.
  3. Pievieno klikšķa klausītāju: document.getElementById("laukums").addEventListener("click", saut);
  4. Paplašini funkciju saut(), lai tā pieskaita 5 punktus mainīgajam punkti.
  5. Noklikšķini uz laukuma trīs reizes un vienlaikus spied bultiņu taustiņus.
  6. Veic git commit -m "Add mouse click shoot event".

Gatavs, kad: pēc trim klikšķiem statuss rāda "Šāviens!" un punkti ir palielinājušies par 15.

Biežākās kļūdas (un kā tās labot):

  • Funkcijas tūlītēja izsaukšana: Rakstot poga.addEventListener("click", savakt()); (ar iekavām beigās), funkcija izpildīsies UZREIZ lapas ielādes brīdī, nevis gaidīs klikšķi. Pareizi ir savakt (bez iekavām).
  • Nepareizs notikuma nosaukums: Rakstīt "onClick" JS failā ir kļūda. HTML vidē tas bija "onclick", bet addEventListener prasa tikai "click".
  • Elementa neatrašana (null): Ja mēģini pievienot klausītāju pogai, pirms HTML fails to ir uzzīmējis (piemēram, <script> tags ir lapas sākumā), radīsies kļūda. Novieto <script> tieši pirms </body>.

Koda piemērs (klausītāja piesaiste bez iekavām un e.key nolasīšana)

let spX = 180;
const speletajs = document.getElementById("speletajs");

function veiktUzbrukumu() {
    console.log("Bam! Ienaidnieks saņem bojājumus.");
}

// PAREIZI: funkcijas nosaukums BEZ iekavām - tā gaida klikšķi
document.getElementById("uzbrukt-btn").addEventListener("click", veiktUzbrukumu);

// NEPAREIZI: ar iekavām funkcija izpildās uzreiz lapas ielādes brīdī
// document.getElementById("uzbrukt-btn").addEventListener("click", veiktUzbrukumu());

// Tastatūras uztveršana visā lapā
document.addEventListener("keydown", function (e) {
    if (e.key === "ArrowLeft")  spX = spX - 10;
    if (e.key === "ArrowRight") spX = spX + 10;

    // Robežas, lai kvadrāts nepazustu aiz laukuma malas
    if (spX < 0)   spX = 0;
    if (spX > 360) spX = 360;

    speletajs.style.left = spX + "px";   // mērvienība "px" ir obligāta
});
Pēc pogas nospiešanas konsolē parādās: Bam! Ienaidnieks saņem bojājumus.

Spiežot bultiņas: zilais kvadrāts slīd pa laukumu un apstājas pie abām malām.

Ja pieliktu iekavas veiktUzbrukumu(), tad teksts konsolē parādītos uzreiz pēc lapas ielādes un vēlāk klikšķis vairs neko nedarītu.
