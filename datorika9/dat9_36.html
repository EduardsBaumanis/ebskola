const vietas = ["Mežs", "Upe", "Pils"];
const dargumuVieta = "Pils";
const gajienuLimits = 3;
let gajieni = 0;
let beigas = false;

// Cikls izveido vienu pogu katrai vietai.

function izveleties(vieta) {
  if (beigas) { return; }
  gajieni = gajieni + 1;
  let zina = "Šeit dārgumu nav: " + vieta;
  if (vieta === dargumuVieta) {
    zina = "Uzvara! Tu atradi dārgumus!";
    beigas = true;
  } else if (gajieni >= gajienuLimits) {
    zina = "Gājieni beigušies. Mēģini vēlreiz!";
    beigas = true;

  document.getElementById("atbilde").textContent = zina;
  document.getElementById("gajieni").textContent = "Gājieni: " + gajieni;
}

1. uzdevums

Savieno savu ideju ar spēles paraugu

Vide: VS Code

  1. Sāc ar šīs lapas pilno kodu failā index.html . Tas papildina 3.5. nodarbības spēli.
  2. Pārnes savu nosaukumu un piecas vietas no iepriekšējā darba. Ja tā nav, izvēlies jaunas.
  3. Vērtībā dargumuVieta ieraksti precīzi vienu no masīvā esošajām vietām.

Gatavs, kad: Spēlē ir tava tēma un sasniedzama dārgumu vieta.

2. uzdevums

Pielāgo spēles noteikumus

Vide: VS Code

  1. Izvēlies gājienu limitu no 3 līdz 5 un ieraksti gajienuLimits .
  2. HTML noteikumu rindkopā norādi to pašu limitu.
  3. Maini uzvaras un zaudējuma ziņas atbilstoši savam stāstam.

Gatavs, kad: Teksts un kods izmanto vienādus noteikumus.

3. uzdevums

Pārbaudi un iesniedz teksta spēli

Vide: Pārlūks → VS Code → GitHub

  1. Atver spēli un izvēlies dārgumu vietu: jāparādās uzvarai. Pēc tās cita vietas poga nedrīkst palielināt gājienus.
  2. Sāc no jauna un izvēlies tukšu vietu tik reižu, cik ir limits: jāparādās zaudējumam.
  3. README ieraksti spēles nosaukumu, atvēršanu un gājienu limitu. Pievieno divas īsas pārbaudes rindas: Uzvara: darbojas un Zaudējums: darbojas pēc to izmēģināšanas.
  4. Nosūti projektu uz GitHub un iesniedz tā saiti.

Gatavs, kad: Spēlē darbojas abi beigu veidi un atkārtota sākšana.

Iesniedz 3. uzdevuma rezultātu

Iesniedz GitHub projekta saiti . Projektā jābūt pabeigtajam index.html un šajā nodarbībā prasītajiem failiem.

Stunda ir ieskaitīta, ja 3. uzdevuma rezultāts atbilst visiem šiem punktiem:

  • Ir piecas vietas, sava tēma un ciklā izveidotas pogas.
  • Darbojas uzvara, gājienu limits un zaudējums; pēc beigām skaitītājs nemainās.
  • Darbojas sākšana no jauna; GitHub ir index.html un īss README ar pārbaudes rezultātiem.

1. un 2. uzdevums sagatavo šo rezultātu. Papildu uzdevums nav vajadzīgs ieskaitei.

Saglabā un nosūti uz GitHub — pogu atgādne

Vide: VS Code / Source Control → GitHub pārlūkā

  1. Ar File → Save All saglabā failus. Atver Source Control ar Ctrl+Shift+G .
  2. Pie Changes nospied + (Stage All Changes). Pārbaudi, ka vajadzīgie faili pārvietojas uz Staged Changes .
  3. Ziņas laukā ieraksti īsu izmaiņu, piemēram, Pabeigts 3.6 darbs . Spied Commit .
  4. Ja šī tēmas mape vēl nav GitHub, spied Publish to GitHub un izveido publisku projektu datorika9-tema3 . Jau publicētam projektam spied Sync Changes . Ja pogas nav, atver … → Push .
  5. Pārlūkā atver savu GitHub projektu un pārbaudi faila pēdējās izmaiņas.

Ja Source Control rāda Initialize Repository , vispirms nospied to. Ja parādās kļūda vai sapludināšanas pieprasījums, izmanto palīdzību un palūdz skolotāja atbalstu.

Papildu uzdevums: Pievieno vēl vienu dārgumu vietu

Sāc, kad 3. uzdevums ir gatavs un iesniegts. Ja vēlies paturēt obligāto versiju, saglabā kopiju ar citu nosaukumu.

  1. Nosacījumā izmanto vieta === dargumuVieta || vieta === "Otra vieta" . || nozīmē “vai”.
  2. Ieraksti kādas citas masīva vietas nosaukumu un pārbaudi abas uzvaras.
Ja kaut kas neizdodas
  • Neredzi izmaiņas? VS Code nospied Ctrl+S. Pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši index.html .
  • Kods redzams kā teksts? Saglabā ar galotni .html. Windows ieslēdz View → Show → File name extensions un pārbaudi, ka beigās nav .txt.
  • Poga nestrādā? Pārbaudi, vai neizdzēsi pēdiņu, iekavu vai elementa id. Salīdzini savu laboto vietu ar sākuma kodu.
  • Nesaproti nākamo soli? Atrodi pirmo nepabeigto soli un parādi skolotājam tieši šo vietu.
