Spēles daļa Kuras 3. tēmas prasmes jāparāda?
Mainīgie un izvade (3.1.) const un let spēles dati (dargumuVieta, gajienuLimits, gajieni, punkti, beigas), atlikušo gājienu aprēķins un parādīšana lapā ar .textContent.
Ievade un formula (3.2.) Spēlētāja vārda <label> un <input id="vards"> nolasīšana ar .value, uzvaras punktu aprēķins pēc saliktas formulas (atlikusie * 10 + 15).
Nosacījumi (3.3.) Spēles apturēšana ar if (beigas) { return; } un trīs zaru if / else if / else pārbaude uzvarai (===), zaudējumam (>=) un turpināšanai.
Masīvi (3.4.) Vismaz 5 paša izdomātu vietu masīvs const vietas = [...] un maršruta masīvs const apmekletas = [], ko papildina ar .push(vieta) un attēlo ar .join(" → ").
Cikls un restarts (3.5.) for cikls izveido visas vietu pogas konteinerā #pogas, un poga Sākt no jauna ar location.reload() atjauno sākuma stāvokli.

Spēles stāvokļa atmiņa un bloķēšana pēc beigām (beigas un return)

Lai programma zinātu, vai drīkst pieņemt nākamo gājienu, tā izmanto loģisko mainīgo let beigas = false;. Kamēr spēle vēl norit, vērtība ir false (“nav beigusies”). Tiklīdz spēlētājs uzvar vai iztērē visus mēģinājumus, kods iestata beigas = true;.

if (beigas) {
  return;
}

Šī pārbaude atrodas pašā funkcijas izveleties(vieta) sākumā. Komanda return; nozīmē “nekavējoties pārtraukt šīs funkcijas izpildi”. Tāpēc jebkurš klikšķis uz vietu pogām pēc uzvaras vai zaudējuma vairs nepieskaita gājienus, nemaina punktus un nepapildina apmeklēto vietu sarakstu.

Kādā secībā pārbauda vienu gājienu un aprēķina punktus?

Katrā atļautajā gājienā darbību secībai ir izšķiroša nozīme:

  1. Vispirms pārbauda if (beigas) { return; }.
  2. Nolasa spēlētāja vārdu, palielina gajieni par 1, aprēķina atlikušos mēģinājumus const atlikusie = gajienuLimits - gajieni; un ar .push(...) pieraksta pārbaudīto vietu maršruta masīvā.
  3. Ar if / else if / else pārbauda iznākumu: vispirms uzvaru (vieta === dargumuVieta), tikai pēc tam zaudējumu (gajieni >= gajienuLimits) un visbeidzot else turpināšanu!

Šāda secība ļauj spēlētājam uzvarēt arī pašā pēdējā atļautajā gājienā. Turklāt izteiksme atlikusie * 10 + 15 piešķir lielāku punktu skaitu par ātrāku atrašanu (piemēram, ja limits ir 3):

Spēles situācija (limits = 3) gajieni un atlikusie Izvēlētais zars un punkti
1. gājienā uzreiz atrod mērķa vietu 1 gājiens, atlikuši 2 Uzvara! 2 * 10 + 15 = 35 punkti; beigas = true.
1. un 2. gājienā izvēlas tukšas vietas 2 gājieni, atlikušais 1 else zars: spēle turpinās, punkti vēl 0.
3. (pēdējā!) gājienā atrod mērķa vietu 3 gājieni, atlikuši 0 Uzvara! 0 * 10 + 15 = 15 punkti; beigas = true.
Visos 3 gājienos izvēlas tukšas vietas 3 gājieni, atlikuši 0 Zaudējums (else if); punkti 0, beigas = true.

Precīza nosaukumu sakritība un README.md paraugs

Salīdzinājums vieta === dargumuVieta pārbauda tekstus burtu pa burtam: "Tornis" un "tornis" JavaScript valodā ir divi dažādi vārdi! Tāpēc dargumuVieta vērtībai precīzi jāsakrīt ar vienu no vietas masīvā ierakstītajiem nosaukumiem, savukārt gajienuLimits (3 vai 4) jāizvēlas mazāks par vietu kopskaitu, lai spēlē būtu īsts izaicinājums.

Papildu uzdevums: Sanumurē izvēļu pogas un iekrāso beigu paziņojumu

Sāc, kad visi trīs pamatuzdevumi ir pabeigti. Papildu uzdevums nav nepieciešams nevienam SLA līmenim.

Izmanto teoriju: Pogu izveidošana ciklā.

  1. for ciklā papildini pogas teksta rindu uz poga.textContent = (i + 1) + ". " + vietas[i]; (atstājot izveleties(vietas[i]) bez izmaiņām).
  2. Funkcijā izveleties(vieta) uzvaras zarā pievieno document.getElementById("atbilde").style.color = "#15803d"; (tumši zaļš), bet zaudējuma zarā — document.getElementById("atbilde").style.color = "#b91c1c"; (tumši sarkans).
  3. Saglabā index.html ar Ctrl+S un atjauno pārlūku ar Ctrl+R.
  4. Pārbaudi abus spēles iznākumus un pogu Sākt no jauna — pārliecinies, ka numurētās pogas joprojām atpazīst dargumuVieta un paziņojums iekrāsojas atbilstoši iznākumam.

Gatavs, kad: izvēļu pogas ir sanumurētas no 1. un spēles beigu paziņojums vizuāli izceļ uzvaru un zaudējumu.

Ja kaut kas neizdodas
  • Spiežot uz pareizās vietas pogas, nekad neparādās uzvara? Salīdzini const dargumuVieta = "..." ar ierakstiem masīvā const vietas = [...]: abiem tekstiem jāsakrīt pilnīgi precīzi (lielie/mazie burti, garumzīmes un nekādu lieku atstarpju pirms vai pēc vārda).
  • Pēdējā atļautajā gājienā, pat uzminot pareizo vietu, parādās zaudējums? Pārbaudi zaru secību funkcijā izveleties(vieta): vispirms jābūt if (vieta === dargumuVieta) un tikai pēc tam else if (gajieni >= gajienuLimits).
  • Pēc uzvaras vai zaudējuma pogas joprojām pieskaita gājienus? Pārliecinies, ka pašā funkcijas izveleties(vieta) sākumā ir saglabāts if (beigas) { return; }, un gan uzvaras, gan zaudējuma zarā tiek izpildīta rinda beigas = true;.
  • Rinda “Pārbaudītās vietas” paliek tukša? Pārbaudi, vai funkcijā izveleties(vieta) esi pievienojis apmekletas.push(vieta); pirms #marsruts teksta atjaunošanas.
