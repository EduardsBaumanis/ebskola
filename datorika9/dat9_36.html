Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: izveido jaunu mapi ar tukšu index.html un script.js; blakus atver savas 3.4 un 3.5 stundas piezīmes par masīviem un cikliem.

Teorija: mini spēle no jau apgūtiem blokiem

Šajā projektā nav jāizmanto jaunas JavaScript bibliotēkas vai sarežģīta animācija. Spēle veidojas no pazīstamiem blokiem: HTML poga izsauc funkciju, prompt() iegūst izvēli, if/else pieņem lēmumu, masīvs glabā materiālu sarakstu, bet for cikls parāda saturu lapā.

let materiali = ["plāns", "marķieris", "taimeris"];

for (let i = 0; i < materiali.length; i++) {
  materialuSaraksts.innerHTML += "<li>" + materiali[i] + "</li>";
}
Iepriekš apgūtais saturs: masīvs, cikls, DOM elementa satura maiņa.

Ko no kuras stundas izmantosi: mainīgos no 3.1, prompt() un Number() no 3.2, if/else no 3.3, masīvu ar .push() no 3.4 un for ciklu no 3.5.

Praktiskie uzdevumi

1. uzdevums - Palaid spēles skeletu un sveicienu ar vārdu

Beigās poga "Sākt spēli" pajautās spēlētāja vārdu un uzrunās viņu lapā.

  1. Iekopē augstāk doto HTML skeletu savā index.html failā un saglabā.
  2. Izveido blakus tukšu failu script.js.
  3. Uzraksti tā augšā let speletajs = ""; let inventars = ["marķieris", "plāns", "lapiņa"];.
  4. Uzraksti funkciju saktIzaicinajumu(), kas ar prompt() pajautā vārdu un saglabā to mainīgajā speletajs.
  5. Ieraksti elementā sveiciens tekstu "Sveiks, " + speletajs + "! Izaicinājums sācies."
  6. Nospied pogu "Sākt spēli" un ievadi savu vārdu.
  7. Pārbaudi konsolē (F12), ka nav neviena sarkana kļūdas ziņojuma.

Gatavs, kad: lapā redzams "Sveiks, {tavs vārds}! Izaicinājums sācies."

2. uzdevums - Uzzīmē inventāru un pievieno rīka izvēli

Beigās spēlētājs varēs izmantot vienu mantu, un tā pazudīs no saraksta lapā.

  1. Uzraksti funkciju zimetInventaru(), kas vispirms notīra materialuSaraksts ar innerHTML = "".
  2. Pievieno tajā for ciklu, kas katrai mantai izveido <li> elementu.
  3. Izsauc zimetInventaru(); funkcijas saktIzaicinajumu() pēdējā rindā.
  4. Pievieno pogu <button onclick="izmantotRiku()">Izmantot rīku</button>.
  5. Uzraksti funkciju izmantotRiku(), kas ar prompt() pajautā mantas nosaukumu.
  6. Pievieno if/else: ja inventars.indexOf(riks) !== -1, izņem mantu ar splice(); citādi rādi kļūdas ziņu.
  7. Nospied pogu un ievadi vārdu plāns.

Gatavs, kad: pēc "plāns" izmantošanas sarakstā palikušas divas mantas un parādās ziņa par veiksmi.

3. uzdevums - Pārbaudi nepareizu izvēli, tukšu somu un restartu

Beigās spēle korekti tiks galā ar kļūdainu ievadi un varēs sākties no jauna.

  1. Ievadi mantu lāpsta, kuras somā nav, un pārbaudi kļūdas ziņojumu.
  2. Izmanto visas trīs mantas pēc kārtas, līdz saraksts ir tukšs.
  3. Pievieno nosacījumu: ja inventars.length === 0, rādi "Soma tukša - izaicinājums pabeigts!".
  4. Pievieno pogu "Restartēt" un funkciju restartet(), kas atjauno sākuma inventāru.
  5. Salabo pirmo kļūdu, ko konsole rāda sarkanā krāsā.
  6. Pieraksti vienu secinājumu: kurš 3. tēmas rīks - mainīgais, if/else, masīvs vai cikls - tev noderēja visvairāk.

Gatavs, kad: pēc "Restartēt" nospiešanas sarakstā atkal ir visas trīs sākuma mantas.

Papildu uzdevums - Punktu skaitīšana un spēles beigas

Beigās spēle parādīs gala rezultātu, kad soma būs iztukšota.

  1. Pievieno script.js rindu let punkti = 0;.
  2. Pievieno index.html failā elementu <p id="rezultats">Punkti: 0</p>.
  3. Pieskaiti 10 punktus katrā veiksmīgajā izmantotRiku() izsaukumā.
  4. Ieraksti jaunos punktus elementā rezultats pēc katras izvēles.
  5. Papildini beigu nosacījumu ar tekstu "Spēle pabeigta! Rezultāts: " + punkti.
  6. Izspēlē spēli no sākuma līdz beigām un palūdz klasesbiedram to izspēlēt bez paskaidrojumiem.

Gatavs, kad: pēc trim veiksmīgām izvēlēm lapā redzams "Spēle pabeigta! Rezultāts: 30".

Biežākās kļūdas (un kā tās labot)

  • Poga neko nedara: pārbaudi, vai funkcijas nosaukums HTML un JS failā ir identisks.
  • Saraksts dublējas: pirms cikla iztukšo sarakstu ar materialuSaraksts.innerHTML = "";.
  • Skaitliskā izvēle nestrādā: pārveido ievadi ar Number() un salīdzini ar skaitli, nevis tekstu.
  • Masīva elements pazūd nepareizi: pārbaudi indeksu; pirmais elements ir 0.

Koda piemērs (mantas izņemšana no inventāra ar indexOf un splice)

let speletajs = "";
let inventars = ["marķieris", "plāns", "lapiņa"];

function zimetInventaru() {
    let saraksts = document.getElementById("materialuSaraksts");
    saraksts.innerHTML = ""; // bez šīs rindas saraksts dublējas katrā zīmēšanā

    for (let i = 0; i < inventars.length; i++) {
        saraksts.innerHTML += "<li>" + inventars[i] + "</li>";
    }
}

function izmantotRiku() {
    let riks = prompt("Kuru mantu izmantosi?");
    let vieta = inventars.indexOf(riks); // -1 nozīmē "somā tādas nav"

    if (vieta === -1) {
        document.getElementById("sveiciens").textContent = "Somā nav tādas mantas: " + riks;
        return; // svarīgi: apstājamies, citādi splice(-1, 1) izmestu pēdējo mantu!
    }

    inventars.splice(vieta, 1); // izņem 1 elementu tieši no atrastās vietas
    zimetInventaru();

    if (inventars.length === 0) {
        document.getElementById("sveiciens").textContent = "Soma tukša - izaicinājums pabeigts!";
    } else {
        document.getElementById("sveiciens").textContent = speletajs + " izmantoja: " + riks;
    }
}
Ievadot plāns, saraksts pārzīmējas un tajā paliek "marķieris" un "lapiņa", bet virsrakstā parādās "{vārds} izmantoja: plāns".

Ievadot lāpsta, saraksts nemainās un parādās "Somā nav tādas mantas: lāpsta".

Pēc trešās mantas izmantošanas saraksts ir tukšs un parādās "Soma tukša - izaicinājums pabeigts!".

Bez return rindas nepareiza ievade izmestu pēdējo mantu, jo splice(-1, 1) strādā no masīva beigām.

Vērtēšanas kritēriji (SLA)

Kritēriji Sācis apgūt (1-3) Turpina apgūt (4-6) Apguvis (7-8) Apguvis padziļināti (9-10)
1. Radošais saturs un dizains (Stāsts, HTML/CSS) Stāsta nav, atstāti oriģinālie piemēri. Vizuālais dizains nav mainīts. Izdomāti unikāli priekšmeti masīvam un pamata stāsts. Nomainīta vismaz viena krāsa. Izveidots oriģināls, asprātīgs sižets. CSS dizains pilnībā pielāgots tēmai (krāsas saskaņotas). Izcils stāstījums un dizains, iekļauti papildu HTML elementi stāsta bagātināšanai (piem., emocijzīmes).
2. Funkcijas un interaktivitāte Faili eksistē, funkcija netiek izsaukta vai ID ir kļūdaini. JS fails pievienots, poga bez kļūdām iedarbina funkciju. Dati tiek iegūti un veiksmīgi izvadīti HTML tagos. Darba vide organizēta perfekti, ievade pārveidota pareizā datu tipā.
3. Loģika un struktūras (If/Else, Masīvi) Masīvs vai If bloks uzrakstīts ar lielām sintakses kļūdām. If/Else strādā un masīvs eksistē, taču tajā netiek veiktas izmaiņas. Loģika strādā korekti – masīvs tiek papildināts vai mainīts atkarībā no lietotāja izvēles. Precīza masīva apstrāde un nevainojama programmas plūsma, kas pielāgota unikālajam stāstam.
4. Automatizācija (Cikli) Cikls nedarbojas vai nespēj nolasīt masīvu. Cikls strādā, bet saturs netiek dinamiski pievienots HTML lapai. Cikls iziet cauri masīvam un veiksmīgi ģenerē HTML sarakstu. Pirms saraksta ģenerēšanas tas tiek iztukšots. Kods ir pilnībā optimizēts.

Pašpārbaudes saraksts pirms darba nodošanas

  • Vai esmu nomainījis sākuma priekšmetus un izveidojis savu, unikālu sižetu?
  • Vai esmu pielāgojis CSS krāsas un fontus savas spēles tematikai?
  • Vai, nospiežot pogu "Sākt spēli", parādās ievades lodziņi un mans vārds tiek attēlots uz ekrāna?
  • Vai inventāra saraksts mainās atkarībā no manas izvēles (1 vai 2)?
  • Vai pārlūkprogrammas Konsolē (F12) nav kļūdu (sarkani paziņojumi)?
