3.2 Ievadi tekstu un aprēķini punktus

Sasniedzamais rezultāts: Izveido ievades formu ar pogu, kas nolasa spēlētāja vārdu un savākto vienību skaitu, aprēķina punktus pēc formulas un parāda atbildi lapā.

Teorija ar piemēriem

Ievades lauki (<input>), etiķetes (<label>) un pogas funkcija

3.1. nodarbībā visi skaitļi bija ierakstīti kodā un aprēķins notika uzreiz, atverot lapu. Lai datus varētu ievadīt pats spēlētājs, HTML izmanto ievades laukus un pogu, kas klikšķa brīdī palaiž JavaScript funkciju:

<label for="vards">Spēlētāja vārds</label>
<input id="vards" value="Ceļotājs">

<label for="kristali">Savākto kristālu skaits</label>
<input id="kristali" type="number" min="0" value="3">

<button onclick="aprekinat()">Parādīt punktus</button>
Elements vai atribūts Ko tas dara?
<label for="vards"> Paskaidrojošs uzraksts virs lauka; atribūtam for jāsakrīt ar attiecīgā <input> atribūtu id.
<input id="..."> Aizpildāms lauciņš (tam nav aizverošās birkas </input>). Pēc id to atrod gan <label>, gan JavaScript.
value="..." Sākotnējā vērtība, kas jau ir ierakstīta laukā, atverot lapu.
type="number" min="0" Atļauj laukā vadīt skaitļus un ar bultiņām neļauj noslīdēt zem 0.
onclick="aprekinat()" Norāda pārlūkam: kad uz pogas uzklikšķina, izpildi funkciju aprekinat() (iekavas () ir obligātas!).

Kas ir funkcija? Pieraksts function aprekinat() { ... } sagrupē vairākas JavaScript komandas starp figūriekavām { un }. Atverot lapu, šīs rindas vēl neizpildās — pārlūks tās ielāgo un palaiž katru reizi, kad spēlētājs nospiež pogu. Tāpēc pēc teksta vai skaitļa pamainīšanas laukā poga ir jānospiež vēlreiz.

Kā nolasīt .value un kāpēc skaitlim vajag Number(...)

Lai nolasītu to, ko lietotājs ierakstījis <input> laukā, izmanto īpašību .value (savukārt parastās rindkopās <p> tekstu joprojām maina ar .textContent):

function aprekinat() {
  const vards = document.getElementById("vards").value;
  const kristali = Number(document.getElementById("kristali").value);
  const punkti = kristali * 4;
  document.getElementById("atbilde").textContent = vards + ": " + punkti + " punkti";
}

Svarīga JavaScript īpatnība: īpašība .value no ievades lauka vienmēr atdod tekstu — pat tad, ja laukam norādīts type="number"! Piemēram, ierakstīts trijnieks ienāk kā teksts "3".

  • Ja ar tekstu mēģina saskaitīt ("3" + 10), JavaScript zīmes vienkārši salipina kopā un iegūst "310".
  • Komanda Number(...) pārvērš tekstu īstā skaitlī, tāpēc Number("3") + 10 izrēķina pareizo summu 13 (ja lauks atstāts tukšs, Number("") atdod 0).
  • Reizināšanu JavaScript kodā vienmēr pieraksta ar zvaigznīti * (nekad neraksti burtu x vai zīmi ×!).

Salikta punktu formula un pārbaude ar vairākiem skaitļiem

Spēlēs kopējo rezultātu bieži veido divas daļas: punkti par katru savākto priekšmetu un nemainīgs sākuma vai dalības bonuss. Apskati piemēru, kur katrs kristāls dod 4 punktus, bet par piedalīšanos piešķir vēl 10 bonusa punktus:

const punkti = kristali * 4 + 10;

Tāpat kā matemātikā, JavaScript vispirms izpilda reizināšanu (*) un tikai pēc tam saskaitīšanu (+). Tāpēc bonuss 10 tiek pieskaitīts vienu reizi pašās beigās, nevis reizināts ar priekšmetu skaitu.

Ievadītais kristali skaits Aprēķina gaita Rezultāts (punkti) Ko šis tests pārbauda?
0 0 * 4 + 10 10 Vai darbojas sākuma bonuss, ja nav savākts nekas.
2 2 * 4 + 10 18 Vai reizināšana un saskaitīšana notiek pareizā secībā.
5 5 * 4 + 10 30 Vai formula pareizi rēķina lielākam skaitam.

Vienmēr pārbaudi savu formulu vismaz ar nullei vienādu skaitu un ar diviem dažādiem pozitīviem skaitļiem, kā arī pārliecinies, ka noteikumu teikums HTML lapā pasaka spēlētājam tieši tos pašus skaitļus, kurus izmanto kods.

Pašpārbaude: spēlētājs nomainīja vārdu un skaitu ievades laukos, bet apakšā vēl rādās vecais rezultāts; savukārt citam skolēnam 3 + 5 aprēķinā parādījās 35 nevis 8 — kāpēc?

1) Rezultāts mainās tikai pēc pogas nospiešanas, jo tieši onclick no jauna izsauc funkciju, kas nolasa .value un atjauno #atbilde tekstu. 2) Rezultāts 35 (no "3" + 5) parādās tad, ja ievades lauka vērtība nav ielikta Number(...) iekavās un JavaScript skaitļa vietā savieno tekstu.

1. uzdevums

Izmēģini ievades formu un pielāgo spēles uzrakstus

Izmanto teoriju: Ievades lauki (<input>), etiķetes (<label>) un pogas funkcija.

Vide: Windows File Explorer → pārlūks → VS Code

  1. Windows mapē Desktop/datorika9-tema3 atver saglabāto 32.html pārlūkā (Open with → Edge) un apskati sākuma stāvokli: laukos jau ir vērtības Spēlētājs un 2, bet apakšā redzams uzaicinājums nospiest pogu.
  2. Nospied pogu Aprēķināt punktus un pārliecinies, ka funkcija paradit() nolasa abus laukus un parāda Spēlētājs: 10 punkti.
  3. Laukā Spēlētāja vārds ieraksti Lote un novēro, ka atbilde vēl nemainās; pēc tam nospied pogu vēlreiz un pārliecinies, ka parādās Lote: 10 punkti.
  4. VS Code failā 32.html nomaini <title> un <h1> uz savas spēles punktu aprēķina virsrakstu.
  5. HTML daļā pie <input id="vards" value="Spēlētājs"> nomaini sākuma atribūtu value uz izvēlētu varoņa vārdu (piemēram, value="Lote"), atstājot neskartus atribūtus id="vards", id="skaits" un pogas onclick="paradit()".
  6. Saglabā failu ar Ctrl+S, pārlūkā atjauno lapu (Ctrl+F5 vai nospied Enter adreses joslā, lai ielādētos jaunā value vērtība) un nospied aprēķina pogu — pārbaudi, ka redzams jaunais virsraksts un sākuma vārds.

Gatavs, kad: esi pārbaudījis ievades un pogas klikšķa saistību, un lapai ir tavas spēles virsraksts un sākotnējais spēlētāja vārds.

2. uzdevums

Maini vienas zvaigznes punktu vērtību un pievieno noteikumu

Izmanto teoriju: Kā nolasīt .value un kāpēc skaitlim vajag Number(...).

Vide: VS Code → pārlūks

  1. <script> daļas funkcijā paradit() izpēti rindu const skaits = Number(document.getElementById("skaits").value); un pārliecinies, ka tā paliek neskarta.
  2. Zem komentāra // === 2. un 3. UZDEVUMS — MAINI ŠEIT: punktu aprēķina formula === atrodi rindu const punkti = skaits * 5; un nomaini vienas zvaigznes vērtību no 5 uz 10 (const punkti = skaits * 10;).
  3. Pirms atjauno pārlūku, aprēķini galvā rezultātu pie zvaigžņu skaita 2; tad saglabā ar Ctrl+S, pārlūkā nospied Ctrl+R, nospied pogu un pārliecinies, ka parādās 20 punkti.
  4. HTML daļā tieši zem <h1> virsraksta (komentāra vietā virs <div class="panelis">) pievieno rindkopu <p id="noteikumi">Viena zvaigzne dod 10 punktus.</p>.
  5. Saglabā failu ar Ctrl+S un pārlūkā ar Ctrl+R pārbaudi, ka noteikumu rindkopa ir skaidri izlasāma virs ievades formas.
  6. Pārlūkā laukā Savākto zvaigžņu skaits ieraksti 4, paredzi rezultātu, nospied aprēķina pogu un pārliecinies, ka atbildē parādās 40 punkti.

Gatavs, kad: gan aprēķina kods, gan paskaidrojuma rindkopa lapā izmanto 10 punktus par vienu zvaigzni.

3. uzdevums

Pievieno sākuma bonusu un pārbaudi formulu dažādos gadījumos

Izmanto teoriju: Salikta punktu formula un pārbaude ar vairākiem skaitļiem.

Vide: VS Code → pārlūks (ar F12 Console)

  1. Funkcijā paradit() papildini aprēķina rindu tā, lai reizinājumam ar 10 tiktu pieskaitīts 5 punktu sākuma bonuss: const punkti = skaits * 10 + 5;.
  2. HTML daļā atjauno rindkopu <p id="noteikumi">, skaidri pasakot spēlētājam abus noteikumus: katra zvaigzne dod 10 punktus un spēlētājs saņem arī 5 sākuma punktus.
  3. Saglabā ar Ctrl+S un pārlūkā nospied Ctrl+R, lai ielādētu atjaunoto formulu un noteikumu aprakstu.
  4. Pārbaudi nulles gadījumu: skaita laukā ieraksti 0, paredzi iznākumu (0 × 10 + 5), nospied pogu un pārliecinies, ka rezultātā redzami tieši 5 punkti.
  5. Vārda laukā ieraksti Lote, zvaigžņu skaitā ieraksti 3, paredzi iznākumu (3 × 10 + 5), nospied pogu un pārbaudi, ka parādās Lote: 35 punkti.
  6. Pārbaudi formu vēl ar cita spēlētāja vārdu un lielāku skaitu (piemēram, 7 → 75 punkti), pārliecinoties, ka atbildes teikumā vārds un skaitlis nesalīp bez atstarpēm.
  7. Pārlūkā atver F12 → Console un pārbaudi, ka sarakstā nav nevienas sarkanas kļūdas; ja nepieciešams, izlabo kodu un saglabā gala versiju ar Ctrl+S.

Gatavs, kad: lapa izskaidro noteikumu skaits × 10 + 5, ievade 0 dod 5 punktus, ievade 3 dod 35 punktus, un konsolē nav kļūdu.

Papildu uzdevums: Pievieno otru ievades lauku retajiem dārgakmeņiem (+25 punkti)

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Ievades lauki un Salikta punktu formula.

  1. HTML blokā <div class="panelis"> zem zvaigžņu <input> lauka (virs pogas) pievieno jaunu etiķeti <label for="dargakmeni">Atrastie dārgakmeņi</label> un skaitļa lauku <input id="dargakmeni" type="number" min="0" value="0">.
  2. Funkcijā paradit() nolasīšanas daļā pievieno const dargakmeni = Number(document.getElementById("dargakmeni").value);.
  3. Papildini punktu formulu līdz const punkti = skaits * 10 + dargakmeni * 25 + 5; un piemin dārgakmeņu vērtību arī <p id="noteikumi"> tekstā.
  4. Saglabā ar Ctrl+S, atjauno pārlūku ar Ctrl+R un pārbaudi abus gadījumus: pie 3 zvaigznēm un 0 dārgakmeņiem rezultāts joprojām ir 35, bet pie 3 zvaigznēm un 2 dārgakmeņiem — 85 punkti.

Gatavs, kad: forma nolasa trīs ievades laukus un precīzi aprēķina punktus gan ar dārgakmeņiem, gan bez tiem.

Ja kaut kas neizdodas
  • Nospiežot pogu, nekas nenotiek? Atver pārlūkā F12 → Console: pārbaudi, vai pogai saglabāts onclick="paradit()" ar iekavām (), vai funkcijai nav izdzēsta beigu figūriekava } un vai getElementById("...") pēdiņās esošie vārdi precīzi sakrīt ar HTML id="vards", id="skaits" un id="atbilde".
  • Rezultātā parādās salipināts skaitlis (piemēram, 305) vai NaN? Salipināts teksts ("30" + 5 → "305") parādās, ja skaitlis nav ielikts Number(...) iekavās vai formulā ap skaitļiem uzliktas pēdiņas. Savukārt NaN (Not a Number) parādās, ja Number(...) iekavās kļūdaini nolasīts teksta lauks "vards" vai reizināšanā zvaigznītes * vietā ierakstīts burts x.
  • Nomainīji skaitli vai vārdu laukā, bet rezultāts nemainās? Pēc katras ievades izmaiņas nospied pogu vēlreiz — funkcija paradit() nolasa .value tikai pogas klikšķa brīdī.
  • Neredzi savas koda izmaiņas pārlūkā? VS Code nospied Ctrl+S, tad pārlūkā nospied Ctrl+F5 (vai uzklikšķini adreses joslā un nospied Enter, lai pārlūks nepaturētu iepriekš ar roku ierakstīto lauka vērtību). Pārbaudi, ka atvērts tieši Desktop/datorika9-tema3/32.html.
  • Kods pārlūkā redzams kā parasts teksts? Saglabā ar galotni .html. Windows File Explorer ieslēdz View → Show → File name extensions un pārbaudi, ka faila beigās nav .txt.
