3.2 Datu tipi un interaktivitāte (Input/Output)

Stundas uzdevums: Izstrādāt interaktīvu datu apmaiņas ciklu, kurā programma pieņem lietotāja ievadi, identificē datu tipu un izvada apstrādātu rezultātu.

2.6.1. Izmanto mainīgos un datu tipus; 5.2.1. Kritiskā domāšana un problēmrisināšana; 5.2.6. Digitālā pratība.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — palaid pogu, kas ar prompt() pajautā vārdu · 2. uzdevums (~25 min) — parādi sveicienu un pieskaiti ievadītos punktus ar Number() · 3. uzdevums (~20 min) — ievadi tekstu skaitļa vietā un izlabo NaN. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu 3.1 stundas projektu ar index.html un script.js, kur jau ir mainīgais punkti un funkcija atjaunotEkranu().

Teorija: Saziņa ar lietotāju un funkcijas

Programmēšanā Input ir dati, ko lietotājs iedod datoram, bet Output ir informācija, ko dators parāda lietotājam.

1. Datu tipi un apstrāde:

  • Datu tipi: String (teksts), Number (skaitlis), Boolean (loģiskā vērtība).
  • Ievade: prompt("Ziņa") - atver lodziņu ievadei. Rezultāts vienmēr ir String.
  • Pārveidošana: Number() - pārvērš tekstu par skaitli matemātiskām darbībām.

2. Funkcijas un pogas:

Lai koda rindiņas neizpildītos uzreiz pēc lapas ielādes, tās "iesaiņo" funkcijā. Funkcija ir kā recepte - tā stāv virtuvē, līdz kāds izdomā to pagatavot.

  • Definēšana (JS): Izmanto atslēgvārdu function, kam seko nosaukums un figūriekavas { } koda blokam.
  • Izsaukšana (HTML): Poga izmanto atribūtu onclick, lai iedarbinātu konkrēto funkciju.
// Funkcijas definēšana
function mana_funkcija() {
    console.log("Poga tika nospiesta!");
}
<!-- Funkcijas izsaukšana -->
<button onclick="mana_funkcija()">Spied šeit!</button>

Praktiskie uzdevumi

1. uzdevums — Palaid pogu, kas pajautā tavu vārdu

Beigās, nospiežot pogu, atvērsies lodziņš, un tavs vārds parādīsies konsolē.

  1. Pievieno index.html failā pogu <button onclick="prasitVardu()">Ievadīt vārdu</button>.
  2. Uzraksti script.js failā funkciju function prasitVardu() { }.
  3. Ieraksti funkcijas iekšpusē rindu let vards = prompt("Kā tevi sauc?");.
  4. Pievieno zem tās rindu console.log("Sveiks, " + vards + "!");.
  5. Nospied pogu pārlūkā un ievadi savu vārdu lodziņā.
  6. Pārbaudi konsolē (F12), ka ziņojumā ir tieši tavs ievadītais vārds.

Gatavs, kad: pēc pogas nospiešanas konsolē parādās "Sveiks, {tavs vārds}!".

2. uzdevums — Parādi sveicienu un pieskaiti ievadītos punktus

Beigās spēlētājs varēs ievadīt vārdu un punktus, un abi parādīsies lapā.

  1. Pievieno index.html failā elementu <p id="sveiciens"></p>.
  2. Nomaini funkcijā prasitVardu() rindu console.log(...) pret document.getElementById("sveiciens").textContent = "Sveiks, " + vards + "!";.
  3. Pievieno otru pogu <button onclick="pievienotPunktus()">Pievienot punktus</button>.
  4. Uzraksti funkciju pievienotPunktus() ar pirmo rindu let ievade = prompt("Cik punktu?");.
  5. Pārvērš ievadi par skaitli ar let jauni = Number(ievade); un pieskaiti to mainīgajam punkti.
  6. Izsauc funkcijas beigās atjaunotEkranu();, lai lapa rāda jauno summu.
  7. Nospied pogu divas reizes, ievadot 10 un 15.

Gatavs, kad: lapā redzams tavs vārds un "Punkti: 25", nevis "Punkti: 1015".

3. uzdevums — Notver NaN, kad ievadīts teksts

Beigās programma neļaus sabojāt punktus, ja spēlētājs ieraksta vārdu skaitļa vietā.

  1. Nospied pogu "Pievienot punktus" un ievadi vārdu divi.
  2. Pieraksti, kas parādījās lapā punktu vietā.
  3. Pievieno funkcijā pārbaudi if (isNaN(jauni)) { alert("Ievadi ciparu!"); return; } pirms saskaitīšanas.
  4. Ievadi vēlreiz vārdu divi un pārbaudi, ka punkti nemainās.
  5. Ievadi skaitli 20 un pārbaudi, ka punkti atkal pieaug.
  6. Pieraksti vienu teikumu: kāpēc prompt() vienmēr atdod tekstu, pat ja ievadi ciparu.

Gatavs, kad: pēc vārda "divi" ievadīšanas lapā nekad neparādās NaN, bet parādās brīdinājums.

Papildu uzdevums — Spēlētāja vecuma ievade vienā teikumā

Beigās lapā būs viens teikums ar spēlētāja vārdu un vecumu kopā.

  1. Pievieno pogu <button onclick="prasitVecumu()">Ievadīt vecumu</button>.
  2. Uzraksti funkciju prasitVecumu(), kas ar prompt() pajautā vecumu.
  3. Pārvērš atbildi ar Number() un saglabā mainīgajā vecums.
  4. Ieraksti elementā sveiciens tekstu "Sveiks, {vārds}! Tev ir {vecums} gadi."
  5. Pārbaudi, ka teikumā parādās abas ievadītās vērtības.
  6. Ievadi vecuma vietā burtus un pārliecinies, ka parādās brīdinājums, nevis NaN.

Gatavs, kad: lapā redzams viens teikums ar tavu vārdu un vecumu, un burtu ievade to nesabojā.

Biežākās kļūdas (un kā tās labot):

  • NaN (Not a Number): Parādās, ja mēģini pārvērst tekstu (piem., "Sveiki") par skaitli. Pārbaudi, vai ievadīji ciparus!
  • Poga neko nedara: Pārbaudi, vai funkcijas nosaukums JS failā un onclick atribūtā sakrīt (arī iekavas ir obligātas).
  • Teksta savienošana tā vietā, lai saskaitītu: Ja neizmanto Number(), tad "10" + "10" būs "1010".

Koda piemērs (teksta pārvēršana skaitlī un NaN pārbaude)

let punkti = 0;

function pievienotPunktus() {
    let ievade = prompt("Cik punktu pievienot?"); // prompt VIENMĒR atdod tekstu
    let jauni = Number(ievade);                   // teksts "10" kļūst par skaitli 10

    // Bez šīs pārbaudes ievade "divi" sabojātu punktus uz visiem laikiem
    if (isNaN(jauni)) {
        alert("Ievadi ciparu!");
        return; // funkcija apstājas, punkti paliek nemainīti
    }

    punkti = punkti + jauni; // ar Number() saskaita; bez tā "10" + "15" būtu "1015"
    document.getElementById("punkti-parads").textContent = "Punkti: " + punkti;
}
Ievadot 10 un pēc tam 15, lapā parādās Punkti: 25.

Ja aizmirsti Number(), lapā parādās Punkti: 01015 — teksti tiek salikti kopā, nevis saskaitīti.

Ievadot vārdu "divi", parādās brīdinājums "Ievadi ciparu!", un punktu skaits paliek iepriekšējais (nevis NaN).
