5.4 Papildfunkciju ieviešana (Power-ups, līmeņi, skaņa)

Stundas uzdevums: Papildināt spēles prototipu ar unikālām funkcijām, kas uzlabo spēlējamību (Game Juice), piemēram, pieaugošu grūtības pakāpi vai multimediju efektiem.

5.2.1. Definē problēmas būtību un risina izaicinājumus; 2.3.1. Izmanto lietojumprogrammatūras specifiskas funkcijas.
SR 3.4.4. Inovāciju un produktu attīstības izpēte SR 5.2.2. Jaunrade un uzņēmējspēja

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - palaid bonusa funkciju savaktPowerUp() konsolē · 2. uzdevums (~25 min) - ieliec laukumā zeltu bonusu, ko var savākt un kas dod 25 punktus · 3. uzdevums (~20 min) - pievieno bonusam skaņu un pārbaudi robežgadījumus. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu spēles projektu; jādarbojas 5.3 stundas objektam spele, HUD atjaunošanai un sadursmju pārbaudei.

Teorija: "Game Juice" un grūtības līkne

Kas atšķir garlaicīgu spēli no tādas, kuru gribas spēlēt vēlreiz?

  • Atgriezeniskā saite (Feedback): Spēlētājam ir jājūt, ka viņa darbībai ir rezultāts. Skaņa pie monētas pacelšanas vai ekrāna nodrebēšana pie sadursmes sniedz šo sajūtu.
  • Grūtības līkne (Difficulty Curve): Ja spēle visu laiku ir vienādi viegla, tā ātri apnīk. Grūtībai ir jāpieaug līdz ar spēlētāja prasmēm (piem., ienaidnieki sāk kustēties ātrāk, kad sasniegti 100 punkti).
  • Bonusi (Power-ups): Elementi, kas uz laiku maina spēles noteikumus (piem., "vairogs", kas pasargā no vienas sadursmes, vai "magnēts").

// Audio objektu veido vienu reizi faila sākumā, nevis katrā sadursmē
const bonusaSkana = new Audio("assets/audio/bonuss.mp3");

function savaktPowerUp(tips) {
  if (tips === "atrums") spele.atrums = spele.atrums * 1.5;
  if (tips === "dziviba") spele.dzivibas++;
  bonusaSkana.currentTime = 0; // atgriež skaņu sākumā
  bonusaSkana.play();
}

Praktiskie uzdevumi

1. uzdevums - Palaid bonusa funkciju konsolē

Beigās konsolē redzēsi, kā viens bonuss maina spēlētāja ātrumu un dzīvību skaitu.

Nokopējamais paraugs: ielīmē to script.js faila beigās; objektu spele izveidoji 5.3 stundā.

spele.atrums = 3; // pievienojam bonusiem vajadzīgo lauku

function savaktPowerUp(tips) {
  if (tips === "atrums") spele.atrums = spele.atrums * 1.5;
  if (tips === "dziviba") spele.dzivibas++;
  console.log(tips, "→ ātrums:", spele.atrums, "dzīvības:", spele.dzivibas);
}
  1. Atver script.js un ielīmē paraugu faila beigās.
  2. Saglabā un atver lapu pārlūkā ar F12 atvērtu konsoli.
  3. Ieraksti konsolē savaktPowerUp("atrums") un nospied Enter.
  4. Ieraksti konsolē savaktPowerUp("dziviba") un apskati jauno dzīvību skaitu.
  5. Nomaini kodā reizinātāju 1.5 uz 2 un pārlādē lapu.
  6. Izsauc savaktPowerUp("atrums") vēlreiz un salīdzini abus rezultātus.

Gatavs, kad: konsolē pēc pirmā izsaukuma redzams ātrums 4.5, bet pēc reizinātāja maiņas - 6.

2. uzdevums - Ieliec laukumā zeltu bonusu, kas dod 25 punktus

Beigās spēlētājs varēs savākt zeltu apli, kas pazūd un pieskaita punktus.

  1. Atver index.html un pievieno spēles laukumā <div id="bonuss"></div>.
  2. Uzraksti style.css stilu #bonuss: position: absolute; width: 20px; height: 20px; background: gold; border-radius: 50%; display: none;.
  3. Izveido script.js funkciju paraditBonusu(), kas ar Math.random() piešķir bonusam left un top laukuma robežās.
  4. Iestati tās beigās bonuss.style.display = "block"; un izsauc funkciju no saktSpeli().
  5. Papildini sadursmju pārbaudi: ja spēlētājs skar bonusu, izpildi spele.punkti += 25 un atjaunotHud().
  6. Paslēp savākto bonusu ar bonuss.style.display = "none"; un izsauc paraditBonusu() pēc 3 sekundēm.
  7. Izpildi git commit -am "Add gold power-up worth 25 points".

Gatavs, kad: uzbraucot spēlētājam virsū zeltajam aplim, tas pazūd un HUD punkti palielinās par 25.

3. uzdevums - Pievieno bonusam skaņu un pārbaudi robežas

Beigās katra bonusa savākšana atskaņos īsu skaņu, un bonuss vienmēr būs laukuma iekšpusē.

  1. Pievieno script.js sākumā rindu const bonusaSkana = new Audio("assets/audio/bonuss.mp3");.
  2. Izsauc bonusa savākšanas vietā bonusaSkana.currentTime = 0; un bonusaSkana.play();.
  3. Savāc bonusu piecas reizes pēc kārtas un klausies, vai skaņa nesāk raustīties.
  4. Pārbaudi, vai bonuss kādreiz parādās ārpus laukuma malas.
  5. Salabo Math.random() robežas: reizini ar laukuma platumu mīnus 20 pikseļi.
  6. Pieraksti vienu secinājumu: kāpēc skaņa un pazūdošs objekts kopā ir labāka atgriezeniskā saite nekā tikai punkti.

Gatavs, kad: desmit savāktiem bonusiem visi parādās laukuma iekšpusē un katrs atskaņo skaņu.

Papildu uzdevums - Pievieno vairogu uz 3 sekundēm

Beigās savāktais vairogs uz trim sekundēm pasargās spēlētāju no sadursmes ar pretinieku.

  1. Pievieno index.html otru bonusu <div id="vairogs"></div> un tam zilu CSS stilu.
  2. Definē script.js sākumā let vairogAktivs = false;.
  3. Iestati vairoga savākšanas brīdī vairogAktivs = true;.
  4. Pievieno tur pašā setTimeout(() => { vairogAktivs = false; }, 3000);.
  5. Pārbaudi sadursmju funkcijā: ja vairogAktivs ir true, dzīvību neatņem.
  6. Piešķir spēlētājam border: 3px solid gold;, kamēr vairogs ir aktīvs.
  7. Izpildi git commit -am "Add shield power-up with 3s protection".

Gatavs, kad: ar zeltu rāmi spēlētājs izbrauc cauri pretiniekam bez dzīvības zaudēšanas, bet pēc 3 sekundēm atkal to zaudē.

Biežākās kļūdas (un kā tās labot):

  • Skaņu pārklāšanās: Ja skaņa tiek atskaņota pārāk bieži (piem., katru sekundi), tā var sākt "raustīties". Izmanto tikai īsus efektus.
  • Pārāk liela grūtība: Ja spele.atrums pieaug pārāk strauji, spēle kļūst nespēlējama jau pēc 20 sekundēm. Testē un pielāgo skaitļus!
  • Atmiņas noplūde: Ja tu katrā ciklā veido jaunu new Audio() objektu, dators var sākt bremzēt. Labāk definē audio mainīgo vienreiz faila sākumā.

Koda piemērs (skaņa bez atmiņas noplūdes un līmeņa maiņa)

// Audio objektu izveido VIENU reizi faila sākumā, ne katrā sadursmē
const punktaSkana = new Audio("assets/audio/point.mp3");

function savaktPunktus() {
    spele.punkti += 10;

    punktaSkana.currentTime = 0; // atgriež skaņu sākumā, ja tā vēl skan
    punktaSkana.play();

    // Katri 100 punkti = jauns līmenis un lielāks ātrums
    if (spele.punkti >= 100 * spele.limenis) {
        spele.limenis++;
        spele.atrums = spele.atrums + 1;
        document.getElementById("limenis").textContent = spele.limenis;
    }

    atjaunotHud();
}
Katrs savāktais objekts atskaņo īsu skaņu, un pie 100 punktiem HUD līmenis pārslēdzas uz 2, bet pretinieki kļūst ātrāki. Ja new Audio() rakstītu funkcijas iekšpusē, pēc 50 savākumiem pārlūks sāktu bremzēt.
