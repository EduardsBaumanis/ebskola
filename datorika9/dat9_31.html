3.1 JavaScript: spēles nosaukums, punkti un dzīvības

Šodien: Saglabā spēles datus JavaScript mainīgajos, veic punktu un dzīvību aprēķinus un parādi rezultātus HTML lapā.

Teorija ar piemēriem

Mainīgie (const un let): kā spēle kodā glabā datus

Pirmajās divās tēmās ar HTML izveidojām lapas daļas, bet ar CSS — to izskatu. JavaScript lapai piešķir loģiku: tas glabā spēles datus, veic aprēķinus un maina lapas saturu. Šajā tēmā JavaScript komandas rakstām starp <script> un </script> birkām tieši pirms </body>, lai pārlūks vispirms izveidotu visus HTML elementus un tikai pēc tam tos aizpildītu no koda.

Mainīgais ir nosaukta atmiņas vieta, kurā programma glabā vienu vērtību — piemēram, spēles nosaukumu, pašreizējos punktus vai vairogu skaitu:

// Spēles sākuma dati
const vards = "Kosmosa kurjers";
let punkti = 10;
let vairogi = 4;
Pieraksts Ko tas nozīmē? Piemērs
const Izveido nemainīgu vērtību (konstanti), kurai vēlāk citu vērtību nepiešķirs. const vards = "Kosmosa kurjers";
let Izveido maināmu mainīgo, kura vērtību spēles gaitā rēķinās un atjaunos. let punkti = 10;
Teksts pēdiņās Vārdus un teikumus vienmēr liek pēdiņās "..." (tajos drīkst būt latviešu burti un atstarpes). "Vēl 3 mēģinājumi"
Skaitlis bez pēdiņām Skaitļus aprēķiniem raksta bez pēdiņām — pēdiņas tos pārvērstu par parastu tekstu. 10, 4, 50
Komentāri un ; Komentārus cilvēkam JS raksta aiz // (HTML daļā — <!-- ... -->); komandas noslēdz ar semikolu ;. // Šo rindu pārlūks neizpilda

Mainīgo nosaukumu rakstība: mainīgā nosaukumā nelieto garumzīmes, mīkstinājuma zīmes un atstarpes (raksta dzivibas, nevis dzīvības). Ja nosaukumā ir divi vārdi, otro vārdu sāk ar lielo burtu bez atstarpes — piemēram, merkaPunkti. JavaScript atšķir lielos un mazos burtus: punkti un Punkti programmai ir divi dažādi nosaukumi.

Vienādības zīme (=) nozīmē “izrēķini un saglabā vērtību”

Programmēšanā zīmi = nelasa kā matemātikas vienādību. Pārlūks vispirms labajā pusē nolasa pašreizējās vērtības un izpilda aprēķinu (+ saskaitīšanai, - atņemšanai), bet pēc tam iegūto rezultātu ieraksta kreisajā pusē norādītajā mainīgajā, aizstājot veco vērtību:

let punkti = 10;
let vairogi = 4;
const rekords = 30;

punkti = punkti + 5;
vairogi = vairogi - 2;
let atlikums = rekords - punkti;
Izpildītā koda rinda punkti vairogi atlikums Kas notika?
Sākuma rindas ar let un const 10 4 — Izveido sākuma vērtības (rekords ir 30).
punkti = punkti + 5; 15 4 — Nolasa 10, pieskaita 5 un saglabā 15.
vairogi = vairogi - 2; 15 2 — Nolasa 4, atņem 2 un saglabā 2.
let atlikums = rekords - punkti; 15 2 15 No rekords (30) atņem tā brīža punkti (15).

Svarīgi: vārdu let pie katra mainīgā nosaukuma raksta tikai vienu reizi — tad, kad mainīgo izveido pirmo reizi (piemēram, let atlikums = ...;). Kad maini jau esoša mainīgā vērtību (punkti = punkti + 5;), vārdu let otrreiz vairs neraksta — pretējā gadījumā skripts apstāsies ar kļūdu.

Vērtības parādīšana lapā (getElementById) un kļūdu meklēšana konsolē

Mainīgā aprēķināšana notiek datora atmiņā — ekrānā tā kļūst redzama tikai tad, kad kods atrod konkrētu HTML elementu pēc tā id="..." atribūta un nomaina tā tekstu ar .textContent:

// HTML daļā ir <p id="punkti"> un <p id="atlikums">
document.getElementById("punkti").textContent = "Punkti: " + punkti;
document.getElementById("atlikums").textContent = "Līdz rekordam vēl: " + atlikums + " punkti";

Ievēro precīzu rakstību: komandā document.getElementById("...") lielie burti ir E, B un I, bet īpašībā .textContent lielais burts ir C. Pēdiņās rakstītajam id ir burts pa burtam jāsakrīt ar HTML birkas id.

Ja vienā no + pusēm ir teksts pēdiņās, JavaScript šīs daļas savieno vienā teikumā. Atstarpes vārdu malās jāieliek pašās pēdiņās (piemēram, "Līdz rekordam vēl: " un " punkti"), citādi skaitlis salips ar vārdiem (Līdz rekordam vēl:15punkti).

Izpildes secība un kļūdu pārbaude:

  • Kods <script> blokā izpildās no augšas uz leju — visiem aprēķiniem jāatrodas virs textContent rindām, lai lapā tiktu ierakstītas jau izrēķinātās vērtības.
  • Nospiežot pārlūkā Ctrl+R, lapa un skripts tiek ielādēti no sākuma — aprēķins sākas no koda sākuma skaitļiem, nevis turpina skaitīt klāt iepriekšējai reizei.
  • Ja pārlūkā nekas nemainās, nospied F12 (vai ar peles labo pogu izvēlies Inspect) un atver cilni Console: tur sarkanā krāsā redzēsi precīzu kļūdas iemeslu un rindas numuru.
Pašpārbaude: skolēns vispirms atstāja rindu ar textContent un tikai pašās <script> beigās pierakstīja punkti = punkti + 5; — kādu skaitli parādīs lapa?

Lapa parādīs sākotnējo punktu skaitu pirms pieskaitīšanas, jo JavaScript komandas izpildās pēc kārtas no augšas uz leju: brīdī, kad textContent nomainīja rindkopas tekstu, mainīgajam punkti vēl nebija pieskaitīti 5 punkti. Aprēķina rindai vienmēr jāatrodas pirms parādīšanas rindas.

1. uzdevums

Izpēti sākuma kodu un iestati savas spēles datus

Izmanto teoriju: Mainīgie (const un let): kā spēle kodā glabā datus.

Vide: Windows File Explorer → pārlūks → VS Code

  1. Windows mapē Desktop/datorika9-tema3 atver saglabāto 31.html pārlūkā (ar peles labo pogu izvēlies Open with → Edge) un salīdzini redzamo lapu ar HTML birkām: HTML rakstīts Mana spēle un Dzīvības: 0, bet pārlūkā redzi Zvaigžņu mednieks un Dzīvības: 3, jo <script> bloks aizstāja tekstu.
  2. VS Code faila <head> daļā atrodi <title>Mana spēle</title> un ieraksti tajā savas spēles nosaukumu, lai tas parādītos pārlūka cilnē.
  3. Ritini lejup līdz <script> blokam, atrodi komentāru // === 1. UZDEVUMS — MAINI ŠEIT: spēles sākuma dati === un rindā const nosaukums = "..."; pēdiņās ieraksti to pašu savas spēles nosaukumu (paturot pēdiņas un semikolu ; rindas beigās).
  4. Nākamajā rindā const apraksts = "..."; pēdiņās uzraksti vienu teikumu par savas spēles galveno mērķi spēlētājam.
  5. Saglabā failu ar Ctrl+S un pārlūkā nospied Ctrl+R — pārbaudi, ka jaunais nosaukums parādās gan cilnē, gan virsrakstā <h1>, un zem tā redzams tavs apraksts.
  6. Zem konstantu rindām nomaini let punkti = 0; uz let punkti = 20; (skaitli raksti bez pēdiņām) un pārliecinies, ka dzīvību sākuma rinda ir let dzivibas = 3;.
  7. Vispirms paredzi, kādus skaitļus tagad parādīs lapa, tad saglabā ar Ctrl+S un atjauno pārlūku ar Ctrl+R — pārliecinies, ka kartītē redzams Punkti: 20 un Dzīvības: 3.

Gatavs, kad: pārlūkā redzams tavs spēles nosaukums un mērķa teikums, bet datu panelī parādās sākuma vērtības Punkti: 20 un Dzīvības: 3.

2. uzdevums

Aprēķini jaunos punktus un dzīvības kodā

Izmanto teoriju: Vienādības zīme (=) nozīmē “izrēķini un saglabā vērtību”.

Vide: VS Code → pārlūks

  1. <script> blokā atrodi komentāru // === 2. UZDEVUMS — RAKSTI ŠEIT: punktu un dzīvību aprēķini === un pārliecinies, ka šī vieta atrodas virs document.getElementById parādīšanas rindām.
  2. Jaunā rindā zem šī komentāra ieraksti punktu palielināšanu par 7 punktiem: punkti = punkti + 7; (bez vārda let sākumā, jo mainīgais punkti jau ir izveidots augstāk).
  3. Pirms pārslēdzies uz pārlūku, galvā aprēķini jauno punkti vērtību (20 + 7); pēc tam nospied Ctrl+S un pārlūkā Ctrl+R, pārbaudot, ka kartītē parādās Punkti: 27.
  4. Zem punktu aprēķina nākamajā rindā pieraksti vienas dzīvības zaudēšanu: dzivibas = dzivibas - 1;.
  5. Paredzi atlikušo dzīvību skaitu (3 - 1), saglabā failu ar Ctrl+S un pārlūkā nospied Ctrl+R — pārliecinies, ka lapā redzams Punkti: 27 un Dzīvības: 2.
  6. Pārlūkā vēl divas reizes pēc kārtas nospied Ctrl+R un novēro, ka skaitļi paliek 27 un 2: katra lapas pārlāde izpilda skriptu no jauna, sākot no koda sākuma skaitļiem 20 un 3.

Gatavs, kad: kods pirms parādīšanas izrēķina abas izmaiņas un pārlūkā redzami 27 punkti un 2 dzīvības.

3. uzdevums

Pievieno mērķa aprēķinu un savieno to ar jaunu HTML rindkopu

Izmanto teoriju: Vērtības parādīšana lapā (getElementById) un kļūdu meklēšana konsolē.

Vide: VS Code → pārlūks (ar F12 Console)

  1. Apskati gatavās parādīšanas rindas <script> beigās un pārbaudi, kā katrs vārds pēdiņās iekš document.getElementById("...") precīzi atbilst HTML birkas atribūtam id="...".
  2. HTML daļas blokā <div class="panelis"> (zem <p id="dzivibas">, komentāra vietā) pievieno jaunu rindkopu <p id="merkis">Mērķis: nav aprēķināts</p>.
  3. <script> sākuma datu daļā (zem let dzivibas = 3;) izveido konstanti uzvarai vajadzīgajam punktu skaitam, piemēram, const merkaPunkti = 50; (izvēlies skaitli virs 30, bez pēdiņām).
  4. Aprēķinu daļā (zem dzivibas = dzivibas - 1;) izveido jaunu mainīgo, kas aprēķina, cik punktu vēl pietrūkst līdz uzvarai: let lidzMerkim = merkaPunkti - punkti;.
  5. Parādīšanas daļas beigās (tieši pirms </script>) uzraksti rindu document.getElementById("merkis").textContent = "Līdz uzvarai vēl: " + lidzMerkim + " punkti";, ievērojot atstarpes pēdiņu iekšpusē.
  6. Paredzi rezultātu (piemēram, pie mērķa 50 aprēķins ir 50 - 27 = 23), saglabā ar Ctrl+S un atjauno pārlūku ar Ctrl+R — pārbaudi, ka panelī redzami 27 punkti, 2 dzīvības un pareizi aprēķināts atlikums līdz uzvarai.
  7. Pārlūkā nospied F12 (vai ar peles labo pogu izvēlies Inspect) un atver cilni Console: pārliecinies, ka tajā nav neviena sarkana kļūdas paziņojuma; ja parādās kļūda, izlabo norādīto koda rindu un saglabā ar Ctrl+S.

Gatavs, kad: lapa parāda tavu spēles nosaukumu, aprakstu, 27 punktus, 2 dzīvības un aprēķinātos punktus līdz mērķim, un pārlūka Console cilnē nav nevienas kļūdas.

Papildu uzdevums: Pievieno spēles līmeni un pāreju uz nākamo līmeni

Sāc, kad visi trīs pamatuzdevumi ir pabeigti.

Izmanto teoriju: Piešķiršana un Vērtības parādīšana lapā.

  1. HTML blokā <div class="panelis"> zem <p id="merkis"> pievieno rindkopu <p id="limenis">Līmenis: 0</p>.
  2. <script> sākuma datu daļā izveido mainīgo let limenis = 1;, bet aprēķinu daļā palielini to par vienu līmeni ar limenis = limenis + 1;.
  3. Parādīšanas daļas beigās pievieno rindu document.getElementById("limenis").textContent = "Līmenis: " + limenis;.
  4. Saglabā failu ar Ctrl+S, atjauno pārlūku ar Ctrl+R un pārbaudi, ka panelī redzams Līmenis: 2 un F12 → Console sarakstā nav kļūdu.

Gatavs, kad: spēles datu kartītē kopā ar pārējiem rādītājiem parādās aprēķinātais Līmenis: 2.

Ja kaut kas neizdodas
  • Neredzi izmaiņas pārlūkā? VS Code nospied Ctrl+S (pie faila nosaukuma cilnē nedrīkst būt balts aplītis), pēc tam pārlūkā nospied Ctrl+R. Pārbaudi, ka atvērts tieši Desktop/datorika9-tema3/31.html.
  • Vērtības nemainās vai <script> pārstāja darboties? Pārlūkā nospied F12 → Console un izlasi sarkano paziņojumu: Identifier 'punkti' has already been declared nozīmē, ka pie aprēķina otrreiz uzrakstīji vārdu let; Assignment to constant variable nozīmē, ka mēģini mainīt const vērtību (jālieto let); is not defined norāda uz drukas vai lielā/mazā burta kļūdu mainīgā nosaukumā vai aizmirstām pēdiņām ap tekstu; Cannot set properties of null nozīmē, ka getElementById("...") pēdiņās ierakstītais vārds nesakrīt ne ar vienu HTML id="...".
  • Punktu skaitam rāda 20 (nevis 27) vai Mērķis: nav aprēķināts? Pārbaudi rindu secību <script> blokā: visām aprēķinu rindām jāatrodas virs document.getElementById(...).textContent rindām.
  • Saskaitīšanas vietā parādās 207 (nevis 27)? Noņem pēdiņas ap skaitļiem (raksti let punkti = 20; un punkti = punkti + 7;, nevis "20" vai "7"). Pēdiņās skaitlis kļūst par tekstu un tiek piekabināts galā.
  • Kods pārlūkā redzams kā parasts teksts? Saglabā ar galotni .html. Windows File Explorer ieslēdz View → Show → File name extensions un pārbaudi, ka faila beigās nav .txt.
