3.1 Ievads JavaScript un mainīgie

Stundas uzdevums: Konstruēt programmas "atmiņu", definējot mainīgos un konstantes, lai manipulētu ar spēles pamatdatiem un kontrolētu to izvadi pārlūka konsolē.

2.6.1. Pieraksta, lasa un izpilda algoritmus; 5.2.1. Kritiskā domāšana un problēmrisināšana; 5.2.6. Digitālā pratība.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - savieno script.js ar lapu un izvadi punktus konsolē · 2. uzdevums (~25 min) - parādi punktus un dzīvības uz lapas ar atjaunotEkranu() · 3. uzdevums (~20 min) - pārbaudi konsolē, ar ko let atšķiras no const. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu projekta mapi ar index.html, izveido tukšu failu script.js un atver pārlūka konsoli ar F12.

Teorija: Smadzenes un Atmiņa (Mainīgie)

JavaScript (JS) ir programmēšanas valoda, kas padara lapu interaktīvu. Lai programma varētu kaut ko aprēķināt (piemēram, spēlētāja punktus), tai šī informācija ir jāsaglabā mainīgajos - "kastēs" ar nosaukumiem.

1. Failu sasaiste:

Lai pārlūks zinātu, ka HTML failam ir pievienota loģika, mums tie ir jāsavieno, izmantojot <script> tagu. Tā atribūts src (source) norāda uz Tavu JS failu.

<!-- Šo rindu liek HTML faila beigās, tieši virs </body> -->
<script src="script.js"></script>

2. Datu uzglabāšana:

Veids Atslēgvārds Lietojums
Mainīgais let Vērtībām, kas mainīsies (punkti, dzīvības).
Konstante const Vērtībām, kas paliek nemainīgas (spēles nosaukums).

Izstrādes laikā mēs izmantojam console.log(), lai nosūtītu ziņojumus uz pārlūka slēpto konsoli (F12), pārbaudot, vai kods strādā pareizi.

Praktiskie uzdevumi

1. uzdevums - Savieno script.js ar lapu un izvadi punktus

Beigās pārlūka konsolē parādīsies tavs pirmais JavaScript ziņojums ar punktu skaitu.

  1. Izveido savā projekta mapē tukšu failu script.js blakus index.html.
  2. Ievieto index.html failā tieši pirms </body> rindu <script src="script.js"></script>.
  3. Uzraksti failā script.js pirmo rindu let punkti = 0;.
  4. Pievieno nākamo rindu console.log("Punkti: " + punkti);.
  5. Atver lapu pārlūkā un nospied F12, lai atvērtu sadaļu "Console".
  6. Nomaini nulli uz 25 un pārlādē lapu ar F5.

Gatavs, kad: konsolē redzams ieraksts "Punkti: 25" un nav neviena sarkana kļūdas ziņojuma.

2. uzdevums - Parādi punktus un dzīvības uz lapas

Beigās tavu spēles datus redzēs arī spēlētājs lapā, nevis tikai tu konsolē.

  1. Pievieno index.html failā rindu <p id="punkti-parads">Punkti: 0</p>.
  2. Pievieno zem tās otru rindu <p id="dzivibas-parads">Dzīvības: 3</p>.
  3. Uzraksti script.js augšā rindu let dzivibas = 3;.
  4. Uzraksti funkciju atjaunotEkranu(), kas abos elementos ieraksta mainīgo vērtības (paraugs ir lapas apakšā).
  5. Izsauc atjaunotEkranu(); faila pēdējā rindā.
  6. Nomaini punktu sākuma vērtību uz let punkti = 40; un saglabā failu.
  7. Pārlādē lapu pārlūkā ar F5.

Gatavs, kad: lapā redzams "Punkti: 40", lai gan HTML failā joprojām rakstīts "Punkti: 0".

3. uzdevums - Pārbaudi, ar ko let atšķiras no const

Beigās tu būsi redzējis pats savām acīm kļūdu, kas rodas, mēģinot mainīt konstanti.

  1. Pievieno script.js augšā rindu const SPELES_NOSAUKUMS = "Klases cīņa";.
  2. Ieraksti konsolē punkti = 100; atjaunotEkranu(); un pārbaudi lapu.
  3. Ieraksti konsolē SPELES_NOSAUKUMS = "Cita spēle";.
  4. Nolasi sarkano kļūdas ziņojumu un pieraksti tā nosaukumu burtnīcā.
  5. Ieraksti konsolē dzivibas = 0; atjaunotEkranu(); un pārbaudi, ka lapa rāda "Dzīvības: 0".
  6. Pieraksti vienu teikumu: kāpēc dzīvībām der let, bet spēles nosaukumam - const.

Gatavs, kad: konsolē esi ieraudzījis "TypeError: Assignment to constant variable" un burtnīcā ir pierakstīts secinājums.

Papildu uzdevums - Līmeņa skaitītājs ar pogu

Beigās poga "Nākamais līmenis" palielinās līmeņa numuru uz lapas.

  1. Pievieno script.js augšā rindu let limenis = 1;.
  2. Pievieno index.html failā rindu <p id="limenis-parads">Līmenis: 1</p>.
  3. Papildini funkciju atjaunotEkranu(), lai tā ieraksta līmeni arī šajā elementā.
  4. Pievieno pogu <button onclick="nakamaisLimenis()">Nākamais līmenis</button>.
  5. Uzraksti funkciju function nakamaisLimenis() { limenis++; atjaunotEkranu(); }.
  6. Nospied pogu pārlūkā trīs reizes.

Gatavs, kad: pēc trim klikšķiem lapā redzams "Līmenis: 4".

Biežākās kļūdas (un kā tās labot):

  • ReferenceError: Tu lieto mainīgo, ko neesi izveidojis, vai esi kļūdījies burtu lielumā.
  • TypeError: Assignment to constant variable: Tu mēģini mainīt const vērtību. Nomaini to uz let.
  • Fails netiek atrasts: Pārliecinies, ka src="script.js" precīzi sakrīt ar faila nosaukumu mapē.

Koda piemērs (mainīgā vērtības ierakstīšana lapā)

// script.js - pieslēgts ar <script src="script.js"></script> pirms </body>
let punkti = 40;
let dzivibas = 3;
const SPELES_NOSAUKUMS = "Klases cīņa"; // šo vērtību vairs nedrīkst mainīt

function atjaunotEkranu() {
    // Ja šeit rodas kļūda "Cannot set properties of null",
    // tad id iekavās nesakrīt ar id HTML failā.
    document.getElementById("punkti-parads").textContent = "Punkti: " + punkti;
    document.getElementById("dzivibas-parads").textContent = "Dzīvības: " + dzivibas;
}

atjaunotEkranu(); // pirmā izvade uzreiz pēc lapas ielādes
console.log(SPELES_NOSAUKUMS + " sākusies!");
Lapā redzēsi:
Punkti: 40
Dzīvības: 3

Konsolē (F12) redzēsi: Klases cīņa sākusies!

Ja konsolē ieraksti punkti = 100; atjaunotEkranu();, lapas teksts uzreiz nomainās uz "Punkti: 100". Ja ieraksti SPELES_NOSAUKUMS = "Cita";, parādās kļūda "TypeError: Assignment to constant variable".
