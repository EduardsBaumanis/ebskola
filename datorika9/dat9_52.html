5.2 Vizuālo resursu un saskarnes (UI) pabeigšana

Stundas uzdevums: Izveidot funkcionālu un estētisku spēles lietotāja saskarni (UI), iekļaujot sākuma izvēlni un spēles stāvokļa informācijas paneli.

2.4.11. Veido tīmekļa vietnes noformējumu; 1.1.2. Analizē lietojamību un vizuālo komunikāciju.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - uzbūvē punktu un dzīvību paneli (HUD) spēles augšmalā · 2. uzdevums (~25 min) - izveido trīs ekrānus: izvēlni, spēles logu un beigu ekrānu · 3. uzdevums (~20 min) - pārbaudi, ka vienlaikus redzams tikai viens ekrāns. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu spēles projektu VS Code un pārliecinies, ka index.html, style.css un script.js ir savstarpēji saistīti.

Teorija: UI vs UX spēlēs

Spēļu izstrādē mēs runājam par diviem svarīgiem jēdzieniem:

  • UI (User Interface): Pogas, teksti, ikonas un saraksti – viss, ko spēlētājs redz un kam pieskaras.
  • UX (User Experience): Sajūta, ko rada spēle. Vai pogas ir pietiekami lielas? Vai punkti ir saskatāmi uz fona? Vai ir skaidrs, kā sākt spēli?
Laba prakse: Izmanto display: none; un display: block; savā CSS, lai pārslēgtos starp "Sākuma ekrānu" un pašu "Spēles laukumu" bez jaunas lapas pārlādēšanas.

Praktiskie uzdevumi

1. uzdevums - Uzbūvē punktu un dzīvību paneli (HUD)

Beigās tavas spēles augšmalā būs vienmēr redzams panelis ar punktiem un dzīvībām.

Nokopējamais paraugs: HTML liec index.html, CSS - style.css, JavaScript - script.js beigās.

<div id="hud">
  <span>Punkti: <b id="punkti">0</b></span>
  <span>Dzīvības: <b id="dzivibas">3</b></span>
</div>
#hud {
  display: flex;
  justify-content: space-between;
  padding: 8px 16px;
  background: #222831;
  color: #FFB142;
  font-family: monospace;
}
document.querySelector("#punkti").textContent = 120;
document.querySelector("#dzivibas").textContent = 2;
  1. Atver index.html un ielīmē HTML paraugu tieši virs spēles laukuma.
  2. Ielīmē CSS paraugu style.css faila beigās.
  3. Saglabā un atver lapu pārlūkā - panelim jābūt vienā rindā spēles augšmalā.
  4. Ielīmē JavaScript paraugu script.js faila beigās un pārlādē lapu.
  5. Nomaini skaitli 120 uz 350 un pārlādē lapu vēlreiz.
  6. Nomaini HUD fona krāsu #222831 uz savas spēles krāsu.

Gatavs, kad: spēles augšmalā redzams panelis, kurā punkti rāda 350 un dzīvības rāda 2.

2. uzdevums - Izveido trīs ekrānus: izvēlni, spēli un beigu ekrānu

Beigās spēlētājs redzēs sākuma izvēlni, un tikai pēc pogas nospiešanas parādīsies spēles laukums.

  1. Atver index.html un ietin savu saturu trīs blokos: #menu, #spele-logs un #beigas.
  2. Pievieno blokiem #spele-logs un #beigas atribūtu style="display: none;".
  3. Atver script.js un funkcijā saktSpeli() paslēp #menu, bet parādi #spele-logs.
  4. Papildini funkciju beigtSpeli(): paslēp #spele-logs un parādi #beigas.
  5. Pievieno blokā #beigas pogu "Mēģināt vēlreiz", kas izsauc saktSpeli().
  6. Saglabā un atver lapu pārlūkā - sākumā jābūt redzamai tikai izvēlnei.
  7. Izpildi git commit -am "Add start menu and game over screen".

Gatavs, kad: nospiežot "Sākt", izvēlne pazūd un parādās spēles laukums ar HUD.

3. uzdevums - Pārbaudi, ka vienlaikus redzams tikai viens ekrāns

Beigās neviens ekrāns vairs nepaliks redzams zem cita ekrāna.

  1. Atver lapu pārlūkā un pārbaudi, ka pirmais redzamais ekrāns ir izvēlne.
  2. Nospied "Sākt" un pārbaudi, ka izvēlne pilnībā pazūd.
  3. Izsauc konsolē beigtSpeli() - jāparādās beigu ekrānam.
  4. Nospied "Mēģināt vēlreiz" un pārbaudi, ka atgriežas spēles laukums.
  5. Salabo ekrānu, kas paliek redzams, - tam trūkst rindas style.display = "none".
  6. Pieraksti vienu secinājumu: kāpēc ekrānu slēpšana ar display: none ir ērtāka par elementa dzēšanu.

Gatavs, kad: visos trīs spēles brīžos ekrānā redzams tieši viens no trim blokiem.

Papildu uzdevums - Padari izvēlnes pazušanu gludu

Beigās izvēlne nepazudīs uzreiz, bet lēni izgaisīs 0,3 sekundēs.

  1. Pievieno style.css: #menu { transition: opacity 0.3s; }.
  2. Iestati funkcijā saktSpeli() vispirms menu.style.opacity = 0;.
  3. Ietin rindu menu.style.display = "none"; iekšā setTimeout(..., 300).
  4. Atver lapu pārlūkā un nospied "Sākt" - izvēlnei jāizgaist, nevis jāpazūd uzreiz.
  5. Salabo, ja izgaišanas nav: pārbaudi, vai transition ir uzrakstīts tieši #menu stilā.
  6. Izpildi git commit -am "Add menu fade transition".

Gatavs, kad: izvēlne pēc "Sākt" nospiešanas izgaist pakāpeniski, nevis pazūd vienā kadrā.

Biežākās kļūdas (un kā tās labot):

  • Pārāk raibs fons: Ja spēlētājs neredz savu varoni fona dēļ, spēle kļūst nespēlējama. Risinājums: Padari fonu blāvāku vai pievieno elementiem apmales.
  • Pogu "klikšķējamība": Pārliecinies, ka pogas reaģē uz peles uzvirzīšanu (izmantojot :hover efektu). Tas dod spēlētājam atgriezenisko saiti.
  • Failu ceļi: Atceries, ja tavs CSS fails ir mapē css/, bet attēls assets/images/, ceļš būs ../assets/images/bilde.png.

Koda piemērs (ekrāns paliek redzams pa virsu spēlei)

/* Izvēlne stāv pa virsu spēles laukumam */
#menu {
    position: absolute;
    width: 100%;
    height: 100%;
    background: rgba(0, 0, 0, 0.8);
    color: white;
    display: flex; /* Centrē saturu */
    flex-direction: column;
    justify-content: center;
    align-items: center;
    z-index: 10; /* Vienmēr pa virsu */
}

/* Poga dod atgriezenisko saiti, kad pele ir virsū */
#menu button:hover {
    background: #FFB142;
    cursor: pointer;
}

/* Klase, ko pievienosim ar JS. !important pārspēj display: flex */
.hidden {
    display: none !important;
}
const menu = document.getElementById("menu");
const speleLogs = document.getElementById("spele-logs");

function saktSpeli() {
    menu.classList.add("hidden");      // izvēlne pazūd
    speleLogs.style.display = "block"; // spēles laukums parādās
}

function beigtSpeli() {
    speleLogs.style.display = "none";
    document.getElementById("beigas").style.display = "block";
}
Nospiežot "Sākt", tumšais izvēlnes pārklājums pazūd un zem tā atklājas spēles laukums. Ja izvēlne paliek redzama, tai ir display: flex, ko pārraksta tikai .hidden ar !important. Pogai, pār kuru ved peli, jāmaina krāsa.
