Atkārtojuma tests: 3.5 Cikls: izveido izvēļu pogas un skaiti gājienus

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Masīvā durvis ir 3 vienumi. Cik reizes izpildās cikls for (let i = 0; i < durvis.length; i = i + 1)?

i ir 0, 1 un 2. Kad i kļūst 3, pārbaude 3 < 3 ir false, un cikls apstājas. Atkārto: 3.5 — Kā for cikls apstaigā masīvu no pirmā līdz pēdējam vienumam ↗

2. Aiz piecām vietu pogām parādās sestā poga ar uzrakstu undefined. Kas ir nepareizi?

Pieciem vienumiem indeksi beidzas pie 4. Ar <= cikls izpildās arī pie i = 5, un vietas[5] ir undefined. Atkārto: 3.5 — Kā for cikls apstaigā masīvu no pirmā līdz pēdējam vienumam ↗

3. Kas notiek ar rindu poga.onclick = function () { atvertDurvis(durvis[i]); }; pogu izveidošanas brīdī?

function () { ... } apvalks aizkavē izsaukumu līdz klikšķim. Tāpēc uzreiz pēc lapas atvēršanas gājienu skaits ir 0. Atkārto: 3.5 — Pogu izveidošana ar JavaScript un atšķirība no klikšķa ↗

4. Gājienu skaits pēc katra klikšķa paliek 1 un nekļūst 2. Kur, visticamāk, ir kļūda?

Ja skaitītāju izveido funkcijā, katrs klikšķis to noliek atpakaļ uz 0. Skaitītājam jābūt ārpus funkcijas, lai vērtība saglabātos starp klikšķiem. Atkārto: 3.5 — Funkcijas parametrs, gājienu skaitītājs un sākšana no jauna ↗

5. Viena funkcija atvertDurvis(nosaukums) apkalpo visas pogas. Kā tā zina, kura poga nospiesta?

Parametrs ir mainīgais funkcijas apaļajās iekavās. Pirmā poga nodod "Ziemeļu vārti", otrā — "Slepenā eja". Atkārto: 3.5 — Funkcijas parametrs, gājienu skaitītājs un sākšana no jauna ↗
