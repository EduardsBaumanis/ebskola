4.5 Sadursmju noteikšanas (Collision detection) pamati

Stundas uzdevums: Izstrādāt matemātisku algoritmu, kas reāllaikā pārbauda, vai divi spēles elementi (piemēram, spēlētājs un šķērslis) ekrānā pārklājas, un atbilstoši reaģēt.

2.6.1. Izstrādā komplicētas darbības un algoritmus; 5.2.1. Definē problēmas būtību un risina kompleksus izaicinājumus.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) — izmēri elementa kasti ar getBoundingClientRect() · 2. uzdevums (~25 min) — uzraksti AABB sadursmes pārbaudi un apturi spēli · 3. uzdevums (~20 min) — notestē sadursmi konsolē un pievieno sarkano efektu. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver savu 4.4 stundas projektu, kurā jau darbojas spēles cikls un kustīgs ienaidnieks #ienaidnieks.

Teorija: Kā dators redz sadursmi?

Dators neskatās uz tavu uzzīmēto varoni kā uz cilvēku. Tas redz tikai kastes (taisnstūrus). Divas kastes saduras TIKAI TAD, ja vienlaicīgi izpildās četri nosacījumi:

  • Varoņa kreisā mala ir tālāk par ienaidnieka labo malu? NĒ.
  • Varoņa labā mala ir pirms ienaidnieka kreisās malas? NĒ.
  • Varoņa augša ir zemāk par ienaidnieka apakšu? NĒ.
  • Varoņa apakša ir augstāk par ienaidnieka augšu? NĒ.
Tīmekļa pārlūkprogrammās ir iebūvēts ģeniāls rīks getBoundingClientRect(), kas uzreiz iedod elementa X un Y koordinātas, kā arī tā platumu un augstumu, padarot šo matemātiku daudz vieglāku!

Praktiskie uzdevumi

1. uzdevums — Izmēri elementa kasti ar getBoundingClientRect()

Beigās konsolē redzēsi sava spēlētāja kvadrāta četras malas skaitļos.

Kopējamais paraugs: trīs rindas, ko ielīmē script.js faila beigās.

const kaste = document.getElementById("speletajs").getBoundingClientRect();

console.log("kreisā:", kaste.left, "labā:", kaste.right);
console.log("augša:", kaste.top, "apakša:", kaste.bottom);
  1. Atver script.js un ielīmē gatavo kodu faila beigās.
  2. Saglabā, pārlādē lapu un atver konsoli ar taustiņu F12.
  3. Pieraksti, kāds skaitlis ir "kreisā" un kāds "labā".
  4. Nomaini index.html failā spēlētāja left vērtību no 180px uz 300px.
  5. Pārlādē lapu un salīdzini jaunos skaitļus ar iepriekšējiem.
  6. Pārbaudi, ka gan "kreisā", gan "labā" pieauga par 120.

Gatavs, kad: konsolē redzami četri skaitļi un "apakša" ir lielāka par "augša".

2. uzdevums — Uzraksti AABB sadursmes pārbaudi un apturi spēli

Beigās spēle apstāsies tajā brīdī, kad tavs kvadrāts pieskarsies ienaidniekam.

  1. Atver script.js un uzraksti funkciju parbauditSadursmi().
  2. Iegūsti funkcijas sākumā abas kastes ar getBoundingClientRect() — spēlētājam un ienaidniekam.
  3. Uzraksti return ar četriem nosacījumiem, kas savienoti ar &&: a.left < b.right, a.right > b.left, a.top < b.bottom, a.bottom > b.top.
  4. Izsauc parbauditSadursmi() funkcijas spelesCikls() beigās.
  5. Izsauc beigtSpeli() un ieraksti "Sadursme!" elementā #statuss, kad rezultāts ir true.
  6. Saglabā, sāc spēli un aizvadi savu kvadrātu ienaidniekam ceļā.

Gatavs, kad: brīdī, kad abi kvadrāti saskaras, kustība apstājas un parādās teksts "Sadursme!".

3. uzdevums — Notestē sadursmi konsolē un pievieno sarkano efektu

Beigās spēlētājs sadursmes brīdī kļūs sarkans, un konsolē redzēsi, kad tieši tas notiek.

  1. Pievieno funkcijas spelesCikls() beigās rindu console.log(parbauditSadursmi());.
  2. Sāc spēli un novieto savu kvadrātu laukuma malā, tālu no ienaidnieka.
  3. Pārbaudi, ka konsolē visu laiku parādās tikai false.
  4. Aizvadi kvadrātu ienaidniekam ceļā un pārbaudi, ka true parādās tikai saskaršanās brīdī.
  5. Pievieno sadursmes blokā rindu speletajs.style.background = "red";.
  6. Pieraksti vienu secinājumu: kāpēc alert() sadursmes brīdī "uzkārtu" pārlūku.

Gatavs, kad: konsolē pirms saskaršanās ir tikai false, un pēc tās kvadrāts ekrānā ir sarkans.

Papildu uzdevums — Pievieno otro ienaidnieku ar vertikālu kustību

Beigās spēli beigs sadursme ar jebkuru no diviem ienaidniekiem.

  1. Pievieno laukumā otro ienaidnieku <div id="ienaidnieks2" style="position:absolute;left:300px;top:0;width:30px;height:30px;background:orange;"></div>.
  2. Pievieno script.js mainīgo let ien2Y = 0;.
  3. Papildini spelesCikls(), lai tas palielina ien2Y un iestata otrā ienaidnieka style.top.
  4. Paplašini parbauditSadursmi(), lai tā pārbauda arī otro ienaidnieku un atgriež true, ja sakrīt kaut viena kaste.
  5. Sāc spēli un mēģini izvairīties no abiem ienaidniekiem vienlaikus.
  6. Veic git commit -m "Add second enemy with collision".

Gatavs, kad: viens ienaidnieks kustas horizontāli, otrs vertikāli, un abi beidz spēli pie saskaršanās.

Biežākās kļūdas (un kā tās labot):

  • Nepārtraukti "Game Over" paziņojumi: Ja sadursme fiksējas un tu izmanto alert, tas var izlēkt 50 reizes sekundē un "uzkārt" pārlūku. Vienmēr labāk nomainīt HTML tekstu vai apturēt ciklu ar clearInterval!
  • Sajaukta "top" un "bottom" loģika: Atceries, tīmeklī Y koordinātas iet UZ LEJU. Tāpēc elementa bottom (apakša) vērtība vienmēr ir lielāka (vairāk pikseļu) nekā top (augša).
  • Pārbaude ārpus cikla: Ja tu izsauksi parbauditSadursmi() faila sākumā tikai vienu reizi, dators to pārbaudīs tikai lapas ielādes brīdī un pēc tam vairs nekad. Tai obligāti jābūt ciklā vai uz taustiņa nospiešanas notikuma!

Koda piemērs (AABB pārbaude katrā kadrā un cikla apturēšana pēc sadursmes)

let spelesCiklsID = null;

function parbauditSadursmi() {
    // 1. Iegūstam abu elementu kastes (taisnstūrus atmiņā)
    const a = document.getElementById("speletajs").getBoundingClientRect();
    const b = document.getElementById("ienaidnieks").getBoundingClientRect();

    // 2. AABB: sadursme ir TIKAI tad, ja izpildās visi četri nosacījumi
    return (
        a.left < b.right &&
        a.right > b.left &&
        a.top < b.bottom &&
        a.bottom > b.top
    );
}

function spelesCikls() {
    // ... šeit kustinām ienaidnieku ...

    // 3. Pārbaudām KATRU kadru, nevis vienu reizi faila sākumā
    if (parbauditSadursmi()) {
        clearInterval(spelesCiklsID);   // bez šī teksts rakstītos 50 reizes sekundē
        document.getElementById("statuss").textContent = "GAME OVER";
        document.getElementById("speletajs").style.background = "red";
    }
}

spelesCiklsID = setInterval(spelesCikls, 20);   // 20 ms = 50 kadri sekundē
Ekrānā: kamēr kvadrāti ir tālu viens no otra, spēle turpinās. Tiklīdz tie saskaras, kustība apstājas, spēlētājs kļūst sarkans un parādās uzraksts "GAME OVER".

Kāpēc clearInterval ir tieši šeit: tas aptur ciklu uzreiz pēc pirmās sadursmes, tāpēc paziņojums parādās vienu reizi, nevis 50 reizes sekundē.
