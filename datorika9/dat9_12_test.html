Atkārtojuma tests: 1.1 Sagatavo VS Code un GitHub

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kam šajā kursā izmanto GitHub?

GitHub glabā nosūtītās darba versijas internetā. Kodu raksti un labo VS Code, bet Git saglabā versijas datorā. Atkārto: 1.1 — Darba mape, VS Code, Git un GitHub ↗

2. Kodā ir rinda <h1>Mana spēle</h1>. Ko redzi pārlūkā?

Pārlūks tagus izpilda, nevis rāda: <h1> sāk galveno virsrakstu, bet </h1> to beidz. Atkārto: 1.1 — Viens fails, divi skati ↗

3. Kurš tagu pāris veido rindkopu?

Rindkopu ietver <p> un </p>. Mainot tekstu starp tagiem, maini lapā redzamo saturu. Atkārto: 1.1 — HTML tags un teksts ↗

4. Tu izlaboji tekstu VS Code. Kādā secībā rīkojies, lai labojumu ieraudzītu pārlūkā?

Ctrl+S saglabā labojumu failā. Ctrl+R pārlūkā nolasa jau saglabāto failu, tāpēc vispirms jāsaglabā. Atkārto: 1.1 — No koda līdz lapai pārlūkā ↗

5. Pārlūks lapas vietā rāda kodu kā parastu tekstu. Ko pārbaudi vispirms?

Ja faila nosaukums beidzas ar .txt, pārlūks to rāda kā tekstu. Lapas failam jābeidzas ar .html. Atkārto: 1.1 — Viens fails, divi skati ↗
