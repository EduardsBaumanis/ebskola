Atkārtojuma tests: 2.1 Maini lapas krāsas un tekstu

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kur šajā nodarbībā HTML failā atrodas CSS noteikumi?

HTML nosaka, kādas daļas ir lapā, bet CSS — kā tās izskatās. Šajā failā CSS noteikumi atrodas <head> daļā starp <style> un </style>. Atkārto: 2.1 — CSS noteikums: ko mainīt un kā mainīt ↗

2. Kura CSS rinda ir uzrakstīta pareizi?

Aiz īpašības nosaukuma raksta kolu (:), rindas beigās — semikolu (;), bet krāsas kodam priekšā jābūt restītei (#). Atkārto: 2.1 — CSS noteikums: ko mainīt un kā mainīt ↗

3. Kā CSS pierakstā noformē tikai elementu ar class="noteikumi"?

Punkts CSS nozīmē klasi: .noteikumi atrod tikai elementu ar class="noteikumi". HTML tagā punktu neraksta. Atkārto: 2.1 — Kuru lapas daļu maini: tags un klase ↗

4. Kā lapā panākt labu kontrastu?

Kontrasts ir skaidra gaišuma atšķirība starp fonu un burtiem. Pārbaudi visas trīs zonas atsevišķi: pamattekstu, noteikumu bloku un pogas uzrakstu. Atkārto: 2.1 — Kontrasts un pārbaude pa vienam solim ↗

5. Tu nomainīji body teksta krāsu uz baltu, bet noteikumu bloka teksts nemainījās. Kāpēc?

Katram blokam var būt savas krāsas. .noteikumi blokā ir sava rinda color: #222222;, tāpēc tas nepārņem body teksta krāsu. Atkārto: 2.1 — Kuru lapas daļu maini: tags un klase ↗
