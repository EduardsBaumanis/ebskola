SR 2.3.8. Saziņas un laika plānošanas rīki (vispārīgais līmenis)

Teorija: rīku izvēlas pēc darba

Sākt testu →

Nav viena labākā saziņas rīka. Pirms raksti, uzdod sev trīs jautājumus:

Kalendāri saprot kopīgu faila formātu .ics (iCalendar). Tas ir parasts teksts. Viens notikums izskatās tā:

BEGIN:VEVENT
UID:termins-2-20261126@kalendars74
DTSTAMP:20261123T000000Z
DTSTART;VALUE=DATE:20261126
SUMMARY:7.4 Kalendāra programma
END:VEVENT

UID ir notikuma unikālais nosaukums, DTSTAMP - kad fails izveidots, DTSTART;VALUE=DATE - visas dienas notikums šajā datumā, SUMMARY - virsraksts. Datums ir bez domuzīmēm: GGGGMMDD.

Tavai programmai teksts 2026-12-07 jāpārvērš par datumu un tad par tekstu 20261207. To dara modulis datetime:

from datetime import datetime

datums = datetime.strptime("2026-12-07", "%Y-%m-%d").date()
print(datums)
print(datums.strftime("%Y%m%d"))

Terminālī parādās:

2026-12-07
20261207

strptime nolasa tekstu pēc parauga: %Y ir gads, %m mēnesis, %d diena. strftime dara pretējo: no datuma izveido tekstu.

Pašpārbaude: komandai jāizlemj, kurš uzrakstīs kuru projekta daļu, un tas jāatceras arī pēc nedēļas. Čats vai uzdevumu sekotājs?

Uzdevumu sekotājs. Lēmums paliek pie konkrētā uzdevuma ar atbildīgo un statusu, bet čatā tas pēc dienas būtu jāmeklē starp simtiem ziņu.

1. uzdevums -

Saplāno darbu GitHub Projects dēlī

Beigās tavā GitHub krātuvē būs trīs uzdevumi (issues) un dēlis ar kolonnām Todo (jādara), In Progress (top) un Done (gatavs).

  1. Atver uzdevumus: GitHub Desktop izvēlies Repository → View on GitHub. Krātuves lapā atver cilni Issues (uzdevumi) un nospied New issue (jauns uzdevums).
  2. Izveido pirmo uzdevumu: laukā Title (virsraksts) ieraksti 7.4 Kalendāra programma, aprakstā Uzrakstīt kalendars_74.py, kas termiņus no CSV ieraksta .ics failā. un nospied Create (izveidot).
  3. Izveido vēl divus uzdevumus tāpat: 7.5 Apps Script apkopojums un 7.6 Pasākuma plānotājs. Cilnē Issues tagad ir trīs atvērti uzdevumi.
  4. Izveido dēli: krātuves lapā atver cilni Projects un nospied New project. Izvēlies veidni Board (dēlis), laukā Project name ieraksti Tēma 7 un nospied Create project.
  5. Pievieno uzdevumus dēlim: kolonnas Todo apakšā nospied + Add item, ieraksti #, izvēlies krātuvi programmesana-pamatkurss un tad uzdevumu 7.4 Kalendāra programma. Atkārto pārējiem diviem.
  6. Pārvieto uzdevumu, ko dari tagad: ar peli pārvelc karti 7.4 Kalendāra programma uz kolonnu In Progress.
  7. Padari dēli redzamu skolotājam: augšējā labajā stūrī nospied … → Settings (iestatījumi). Sadaļā Danger zone pie Visibility nospied Change visibility → Public (publisks) un apstiprini. Atgriezies dēlī un nokopē adresi no pārlūka adreses joslas.
  8. Saglabā saiti piezīmēs: VS Code atver README.md, faila beigās pievieno šīs rindas, aiz Dēlis: ielīmē adresi un saglabā: 
    ### 7.4 Saziņas un plānošanas rīki

- Dēlis:

Gatavs, kad: dēlī Tēma 7 kolonnā In Progress ir 7.4 Kalendāra programma, kolonnā Todo ir abi pārējie uzdevumi, un README.md ir saite uz dēli.

Iestrēgi?
  • 1. solis: nav cilnes Issues. Krātuvē uzdevumi ir izslēgti. Atver Settings → General, sadaļā Features ieķeksē Issues.
  • 2. solis: pogas nosaukums ir Submit new issue. Tā ir tā pati poga vecākā GitHub izskatā.
  • 4. solis: pogas New project nav. Nospied bultiņu pie Link a project un izvēlies New project.
  • 5. solis: pēc # nav saraksta. Ieraksti krātuves nosaukuma sākumu programmesana, tad izvēlies krātuvi un uzdevumu.
  • Kolonnas sauc citādi nekā "To do / Doing / Done". GitHub nosaukumi ir Todo, In Progress, Done. Tie nozīmē to pašu.
  • 7. solis: skolotājs redz krātuvi, bet ne dēli. Jauns dēlis ir privāts, līdz tu to padari publisku. Atkārto 7. soli.

Iestrēgi?
  • 3.–5. solis, vietas ___: rinda["datums"], rinda["uzdevums"], f"SUMMARY:{teksts}" un notikums(nr, datums, teksts).
  • KeyError: 'datums' - CSV pirmajā rindā kolonnas nosaukums ir citāds (piemēram, ar lielo burtu vai atstarpi). Tam jābūt tieši datums,uzdevums.
  • FileNotFoundError - fails termini_74.csv nav mapē tema07 vai tā nosaukumā ir kļūda.
  • ValueError: time data ... does not match format '%Y-%m-%d' - kāds datums nav formātā GGGG-MM-DD, piemēram, 2026-12-7 vai 07.12.2026. Šo kļūdu salabosi 3. uzdevumā; tagad izlabo datumu failā.
  • 8. solis: nevari atrast mapi tema07 izvēles logā. GitHub Desktop izvēlies Repository → Show in Explorer, atver tema07, nokopē adresi no adreses joslas un ielīmē to izvēles loga adreses joslā.
  • 8. solis: Google ir latviešu valodā. Zobrats → Iestatījumi → Importēšana un eksportēšana → Atlasīt failu no datora → Importēt.
  • 8. solis: lieto Outlook, nevis Google. Outlook izvēlies Pievienot kalendāru → Augšupielādēt no faila (Add calendar → Upload from file) un izvēlies termini_74.ics.
  • Notikumi ir nepareizā dienā vai Google raksta, ka fails ir bojāts. Atver termini_74.ics un salīdzini ar piemēru teorijā: datumam jābūt bez domuzīmēm, katram BEGIN:VEVENT jābūt savam END:VEVENT.

Iestrēgi?
  • 2. solis: IndentationError. Rindai try: jābūt ar tādu pašu atkāpi kā rindai termini.append(…) zem tās (12 atstarpes). Rindām zem try: un except ir vēl 4 atstarpes vairāk.
  • 2. solis: joprojām ValueError. Virs try: palika vecā rinda datums = datetime.strptime(…. Izdzēs to: tagad šī rinda ir tikai zem try:.
  • 2. solis: parādās Kontroldarbs ar cita termiņa datumu. Blokā except trūkst rindas continue, tāpēc programma izmanto iepriekšējās rindas datumu.
  • 4. solis: izlaiž arī tavus īstos termiņus. Tavi datumi CSV failā jau ir pagājuši. Ieraksti datumus, kas ir šodien vai vēlāk.
  • 4. solis: TypeError: '<' not supported. Tu salīdzini tekstu ar datumu. Salīdzinājumam jābūt zem bloka try/except, kur datums jau ir datums.
  • 6. solis: kalendārā notikumi ir divreiz. Tu nomainīji datumu vai rindu secību CSV failā, tāpēc mainījās UID. Izdzēs liekos notikumus kalendārā: noklikšķini uz notikuma → miskastes ikona.
  • Nezini, ko rakstīt tabulā. Izmanto teorijas tabulu un trīs jautājumus: vai atbilde vajadzīga tūlīt, kam tas jāredz, vai paziņojums traucēs.
Papildu uzdevums - Cik dienu līdz termiņam?

Ja pamatdarbs ir gatavs, liec programmai pateikt, cik dienu palicis līdz katram termiņam.

  1. Nomaini izdruku: funkcijā main aizstāj rindu print(datums, teksts) ar šīm divām rindām (atkāpe 8 atstarpes): 
            dienas = (datums - date.today()).days
        print(f"{datums}  pēc {dienas} dienām  {teksts}")

    Divu datumu starpība ir laika posms, un .days ir dienu skaits tajā.

  2. Palaid. Ja šodien ir 2026-11-23, terminālī parādās:

Stundas beigās

  1. Pabeidz uzdevumu dēlī: GitHub dēlī Tēma 7 pārvelc karti 7.4 Kalendāra programma uz kolonnu Done.
  2. Saglabā visus failus: VS Code izvēlies File → Save All.
  3. Apskati izmaiņas: pārslēdzies uz GitHub Desktop. Zem Changes (izmaiņas) jābūt tema07/kalendars_74.py, tema07/termini_74.csv, tema07/termini_74.ics un README.md.
  4. Apraksti un fiksē: laukā Summary (kopsavilkums) ieraksti Pievieno 7.4 kalendāra programmu un rīku izvēli un nospied Commit to main.
  5. Nosūti: nospied Push origin (nosūtīt uz GitHub).

Gatavs, kad: GitHub vietnē mapē tema07 redzams kalendars_74.py, un dēlī kolonnā Done ir 7.4 Kalendāra programma.

from pathlib import Path

def nolasit_terminus():
    termini = []
    with open(CSV_FAILS, encoding="utf-8") as f:
        for nr, rinda in enumerate(csv.DictReader(f), start=2):
            try:
                datums = datetime.strptime(rinda["datums"], "%Y-%m-%d").date()
            except ValueError:
                print(f"Izlaižu {nr}. rindu: {rinda['datums']} nav formātā GGGG-MM-DD")
                continue
            if datums < date.today():
                print(f"Izlaižu {nr}. rindu: {datums} jau ir pagājis")
                continue
            termini.append((nr, datums, rinda["uzdevums"]))
    return termini
