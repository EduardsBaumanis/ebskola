7. tēmas špikeris - automatizācija un sadarbība

Ko automatizēt, kam ko koplietot, kā noformēt dokumentu un kā rakstīt skriptu izklājlapā. Katrs bloks atbilst vienai stundai.

7.1 Ko var automatizēt un failu kārtošana

# A - atkārtojas, notiek pēc noteikuma, dati jau ir datorā
# D - daļēji: programma sagatavo, cilvēks izlemj
# N - jāspriež vai jārunā ar cilvēkiem

from pathlib import Path
import shutil

MAPE = Path(__file__).parent / "prakse_71"   # tikai prakses mape!
TIKAI_PARADIT = True                         # vispirms tikai parāda

for fails in MAPE.iterdir():
    if not fails.is_file():
        continue                             # mapes neaiztiek
    pap = fails.suffix.lower()[1:]           # ".JPG" -> "jpg"
    if pap == "":
        pap = "bez_tipa"                     # fails bez paplašinājuma
    merkis = MAPE / pap
    if (merkis / fails.name).exists():
        print(f"Izlaižu {fails.name}: mapē {pap}/ jau ir šāds fails")
        continue
    if TIKAI_PARADIT:
        print(f"[tikai parādu] {fails.name} -> {pap}/")
    else:
        merkis.mkdir(exist_ok=True)
        shutil.move(fails, merkis / fails.name)

Programmu, kas pārvieto failus, vienmēr vispirms palaid ar TIKAI_PARADIT = True. Bez pārbaudes exists() jauns fails klusi pārraksta veco.

7.5 No Python uz Apps Script

// Python                    JavaScript (Apps Script)
// def f(x):                 function F(x) { ... }
// skaits = 0                let skaits = 0;   const KOLONNA = 2;
// if a == b:                if (a === b) { ... }
// for i in range(1, n):     for (let i = 1; i < n; i++) { ... }
// x in saraksts             saraksts.includes(x)
// dati[1][2]                šūna C2: rinda 2 ir indekss 1, kolonna C ir indekss 2

const KOLONNA = 2;   // 0 = A, 1 = B, 2 = C
const ATBILDES = ['Ļoti patīk', 'Patīk', 'Nepatīk'];

function apkopot() {
  const tabula = SpreadsheetApp.getActiveSpreadsheet();
  const dati = tabula.getSheetByName('Atbildes').getDataRange().getValues();
  let skaits = {};
  for (let i = 1; i < dati.length; i++) {
    let atbilde = dati[i][KOLONNA];
    if (atbilde === '') {
      continue;
    }
    if (!ATBILDES.includes(atbilde)) {
      atbilde = 'Cits';
    }
    if (skaits[atbilde] === undefined) {
      skaits[atbilde] = 0;
    }
    skaits[atbilde] += 1;
  }
  let lapa = tabula.getSheetByName('Kopsavilkums');
  if (lapa === null) {
    lapa = tabula.insertSheet('Kopsavilkums');
  }
  lapa.clear();
  lapa.appendRow(['Atbilde', 'Skaits']);
  for (let atbilde in skaits) {
    lapa.appendRow([atbilde, skaits[atbilde]]);
  }
}

function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('ebSkola')
    .addItem('Apkopot', 'apkopot')
    .addToUi();
}

onOpen Google palaiž pats, kad izklājlapu atver. Bez lapa.clear() katra palaišana pievieno kopsavilkumu vēlreiz, jo appendRow raksta lapas beigās.
