Sasniedzamais rezultāts: Šajā stundā tu uzrakstīsi savu funkciju izklājlapai un izvēlnes pogu, kas vienā klikšķī sakārto aptaujas atbildes kopsavilkumā.

Teorija: programma lietotnes iekšienē

1. uzdevums -

Uzraksti pielāgotu funkciju =PUNKTI()

Beigās izklājlapas kolonnā E katrai atbildei būs punkti, ko aprēķina tava funkcija, un apakšā to summa 17.

  1. Izveido izklājlapu: atver sheets.google.com ar skolas kontu un nospied Tukša izklājlapa (Blank spreadsheet). Augšā kreisajā stūrī noklikšķini uz Izklājlapa bez nosaukuma un ieraksti 7.5 Aptauja.
  2. Nosauc lapu: apakšā veic dubultklikšķi uz cilnes Lapa1 (Sheet1), ieraksti Atbildes un nospied Enter.
  3. Ielīmē aptaujas atbildes: iezīmē visu zemāk esošo bloku, nospied Ctrl+C, izklājlapā noklikšķini šūnā A1 un nospied Ctrl+V. Tā izskatās Google Forms atbilžu lapa: aizņemtas kolonnas A–D un rindas 1–9.

Iestrēgi?
  • 3. solis: viss ielīmējās kolonnā A. Iezīmē kolonnu A un izvēlies Dati → Sadalīt tekstu kolonnās (Data → Split text to columns). Kā atdalītāju izvēlies tabulēšanu vai automātisku noteikšanu.
  • 4. solis: izvēlnē nav Apps Script vai atveras kļūda. Skolas administrators var būt izslēdzis Apps Script. Pajautā skolotājam.
  • 6. solis: šūnā ir #NAME? - funkcijas nosaukums šūnā atšķiras no koda (piemēram, PUNKTII), vai kods nav saglabāts. Saglabā ar Ctrl+S un ieraksti formulu vēlreiz.
  • 6. solis: šūnā ir 0, nevis 3. Teksts kodā atšķiras no teksta šūnā, piemēram, Loti patīk bez garumzīmes. Salīdzini abus burtu pa burtam.
  • Saglabājot redaktors raksta Syntax error. Pietrūkst iekavas } vai ). Katrai atverošajai iekavai jābūt aizverošajai: salīdzini savu kodu ar 5. soli.

2. uzdevums -

Uzraksti apkopošanas skriptu un izvēlni ebSkola

Beigās skripts saskaitīs, cik reizes izvēlēta katra atbilde, ierakstīs to jaunā lapā Kopsavilkums, un izklājlapā būs izvēlne ebSkola.

Turpini Apps Script failā Code.gs, kurā jau ir funkcija PUNKTI no 1. uzdevuma.

  1. Pievieno konstanti: zem funkcijas PUNKTI atstāj tukšu rindu un ieraksti: 
    const KOLONNA = 2;   // 0 = A, 1 = B, 2 = C

    Atbildes uz jautājumu ir kolonnā C, tāpēc indekss ir 2.

  3. Saglabā un palaid: nospied Ctrl+S. Rīkjoslā sarakstā blakus pogai Debug izvēlies apkopot un nospied Run (izpildīt).
  4. Atļauj skriptam piekļūt izklājlapai: pirmajā reizē parādās logs Authorization required (vajadzīga atļauja). Nospied Review permissions, izvēlies savu skolas kontu un nospied Allow (atļaut). Apakšā žurnālā parādās Execution completed (izpilde pabeigta).

Gatavs, kad: lapā Kopsavilkums ir četras rindas kā 5. solī, un izklājlapas augšējā izvēlnē ir ebSkola → Apkopot.

Iestrēgi?
  • 2. solis, vietas ___: dati[i][KOLONNA], tabula.insertSheet('Kopsavilkums') un skaits[atbilde].
  • TypeError: Cannot read properties of null (reading 'getDataRange') - nav lapas ar nosaukumu Atbildes. Pārbaudi cilnes nosaukumu (1. uzdevuma 2. solis): tam jābūt tieši tādam, bez atstarpes beigās.
  • ReferenceError: KOLONNA is not defined - trūkst 1. soļa rindas vai tajā ir cits nosaukums.
  • 4. solis: parādās Google hasn't verified this app. Nospied Advanced (papildu) un Go to 7.5 Apkopotājs (unsafe). Tā ir tava paša programma, tāpēc tas ir droši.
  • 4. solis: skola neļauj dot atļauju. Pajautā skolotājam; daļa skolu atļauj skriptus tikai pēc administratora iestatījuma.
  • 5. solis: kopsavilkumā ir tikai virsraksts. KOLONNA norāda uz tukšu kolonnu, vai lapā Atbildes dati nesākas šūnā A1.
  • 7. solis: izvēlne neparādās. Pagaidi 10 sekundes un nospied F5 vēlreiz. Pārbaudi, vai funkcijas nosaukums ir tieši onOpen (ar lielo O vidū) un vai kods ir saglabāts.

3. uzdevums -

Pārbaudi skriptu: atkārtota palaišana, tukša rinda, negaidīta atbilde

Beigās skriptu var palaist cik reizes grib, un kopsavilkums vienmēr būs pareizs. Kods būs saglabāts arī tavā GitHub krātuvē.

  1. Palaid no izvēlnes: izklājlapā izvēlies ebSkola → Apkopot un atver lapu Kopsavilkums. Tabula tagad ir divreiz: rindās 1–4 un 5–8. appendRow vienmēr pievieno beigās un veco neizdzēš.

Iestrēgi?
  • 2. solis: tabula joprojām ir divreiz. Rinda lapa.clear(); ir zem appendRow rindām vai kods nav saglabāts. Tai jābūt pirms pirmās appendRow rindas.
  • 2. solis: TypeError: Cannot read properties of null (reading 'clear') - rinda lapa.clear(); ir virs bloka if (lapa === null), un lapas Kopsavilkums vēl nav. Pārnes rindu zem bloka.
  • 3. solis: tukšās rindas kopsavilkumā nav. Tukšā rinda ir zem pēdējās atbildes, nevis starp tām. Ievieto to virs 5. rindas, kā rakstīts.
  • 4. solis: tukšā rinda joprojām ir kopsavilkumā. Jaunās rindas ir virs let atbilde = …, nevis zem tās, vai kods nav saglabāts.
  • 6. solis: arī pareizās atbildes kļūst par Cits. Teksts sarakstā ATBILDES atšķiras no teksta šūnās. Salīdzini burtus un garumzīmes.
  • 6. solis: ReferenceError: ATBILDES is not defined - trūkst rindas const ATBILDES = … vai tā ir funkcijas iekšienē zem tās izmantošanas.
  • VS Code piedāvā instalēt paplašinājumu JavaScript failam. Tas nav vajadzīgs: aizver paziņojumu.
Papildu uzdevums - Apkopo savas 5.4 aptaujas atbildes

Ja pamatdarbs ir gatavs, palaid to pašu skriptu uz īstajām atbildēm no savas 5.4 stundas aptaujas.

  1. Atver atbilžu izklājlapu: Google Forms atver savu 5.4 aptauju, cilnē Atbildes (Responses) nospied Skatīt izklājlapā (View in Sheets).
  2. Ielīmē skriptu: šajā izklājlapā izvēlies Paplašinājumi → Apps Script, izdzēs visu un ielīmē kodu no tema07/apkopot_75.js.
  3. Pielāgo trīs vietas: nomaini 'Atbildes' pret savas lapas nosaukumu (parasti Veidlapas atbildes 1 vai Form Responses 1), KOLONNA pret sava izvēles jautājuma kolonnas indeksu un ATBILDES pret savām atbilžu izvēlēm.
  4. Saglabā, atsvaidzini un palaid: Ctrl+S, izklājlapā F5, tad ebSkola → Apkopot un atļauj piekļuvi kā 2. uzdevuma 4. solī.

Gatavs, kad: tavā 5.4 aptaujas izklājlapā ir lapa Kopsavilkums ar tavu atbilžu skaitu.

Stundas beigās

  1. Saglabā visus failus: VS Code izvēlies File → Save All.
  2. Apskati izmaiņas: pārslēdzies uz GitHub Desktop. Zem Changes (izmaiņas) jābūt tema07/apkopot_75.js un README.md.
  3. Apraksti un fiksē: laukā Summary (kopsavilkums) ieraksti Pievieno 7.5 Apps Script apkopotāju un nospied Commit to main.
  4. Nosūti: nospied Push origin (nosūtīt uz GitHub).
  5. Atjaunini dēli: 7.4 stundas dēlī Tēma 7 pārvelc karti 7.5 Apps Script apkopojums uz Done.

Gatavs, kad: GitHub vietnē mapē tema07 redzams apkopot_75.js, un, to atverot, kods ir iekrāsots kā JavaScript.

function PUNKTI(atbilde) {
  if (atbilde === 'Ļoti patīk') {
    return 3;
  }

    return 2;
  }

const KOLONNA = 2;   // 0 = A, 1 = B, 2 = C
const ATBILDES = ['Ļoti patīk', 'Patīk', 'Nepatīk'];

function apkopot() {
  const tabula = SpreadsheetApp.getActiveSpreadsheet();
  const dati = tabula.getSheetByName('Atbildes').getDataRange().getValues();
  let skaits = {};
  for (let i = 1; i < dati.length; i++) {
    let atbilde = dati[i][KOLONNA];
    if (atbilde === '') {
      continue;
    }
    if (!ATBILDES.includes(atbilde)) {
      atbilde = 'Cits';
    }
    if (skaits[atbilde] === undefined) {
      skaits[atbilde] = 0;
    }
    skaits[atbilde] += 1;
  }
  let lapa = tabula.getSheetByName('Kopsavilkums');
  if (lapa === null) {
    lapa = tabula.insertSheet('Kopsavilkums');
  }
  lapa.clear();
  lapa.appendRow(['Atbilde', 'Skaits']);
  for (let atbilde in skaits) {
    lapa.appendRow([atbilde, skaits[atbilde]]);
  }
}
