7.2 Koplietošana un piekļuves tiesības

Sasniedzamais rezultāts: Šajā stundā tu koplietosi projekta mapi trim lomām ar atšķirīgām tiesībām un pārbaudīsi kopā ar klasesbiedru, ka katrs var tieši to, kas atļauts.

SR 2.3.2. Dokumentu koplietošana un tiesības (vispārīgais līmenis)

Teorija: kam ko drīkst

Sākt testu →

Kad dokumentu koplieto (share), tu katram cilvēkam izvēlies lomu. Loma nosaka, ko viņš drīkst darīt. Google Docs un Google Drive ir četras lomas:

LomaVarNevar
Skatītājs (Viewer)lasīt; pēc noklusējuma arī lejupielādēt un drukātmainīt, komentēt
Komentētājs (Commenter)lasīt, komentēt, ieteikt labojumusmainīt tekstu tieši
Redaktors (Editor)mainīt saturu, redzēt versiju vēsturi; pēc noklusējuma arī koplietot tālākizdzēst īpašnieka failu, mainīt īpašnieku
Īpašnieks (Owner)visu: arī izdzēst failu un noteikt, kam ir piekļuve-

Koplietot var divos veidos:

  • Konkrētiem cilvēkiem: tu ieraksti viņu e-pastu. Atvērt var tikai tas, kas piesakās ar šo kontu. Sarakstā redzi visus un vari noņemt vienu.
  • Ar saiti (Anyone with the link, ikviens, kam ir saite): atvērt var ikviens, pie kura saite nonāk, arī tad, ja tā tika pārsūtīta tālāk. Tu neredzi, kas to atvēra.

Mazāko tiesību princips: katram dod tikai tās tiesības, kas vajadzīgas viņa darbam, un tikai uz laiku, kamēr tās vajag. Ja klasesbiedram jāiesaka labojumi, viņš ir komentētājs, nevis redaktors.

Versiju vēsture (Version history): Google saglabā katru izmaiņu ar vārdu un laiku. Īpašnieks un redaktori to atver ar File → Version history → See version history un var atjaunot vecāku versiju.

Piemērs: klases avīzes mape. Šādu prasību tabulu tu izpildīsi 2. uzdevumā.

Un GitHub? Tava krātuve programmesana-pamatkurss ir publiska (Public, 1.2 stunda): kodu var lasīt ikviens, tāpat kā ar saiti koplietotu skatītāja failu. Personīga konta krātuvei ir tikai divas lomas: īpašnieks un līdzstrādnieks (collaborator), kas var gan lasīt, gan nosūtīt izmaiņas. Sīkākas lomas, piemēram Read (tikai lasīt), Triage (kārtot uzdevumus) un Write (rakstīt), ir tikai organizāciju krātuvēm. Skolotājam vajag tikai lasīt, tāpēc viņu nepievieno kā līdzstrādnieku: publiska krātuve jau ļauj lasīt.

Ja tavs Google ir latviešu valodā, pogas sauc citādi: Share = Kopīgot, Viewer = Skatītājs, Commenter = Komentētājs, Editor = Redaktors.

Pašpārbaude: klasesbiedram jāizlabo kļūdas tavā referātā, bet tu gribi pats izlemt, kurus labojumus pieņemt. Kādu lomu dosi?

Komentētāju. Viņa labojumi parādīsies kā ieteikumi, un tu katru pieņemsi vai noraidīsi. Redaktors tekstu mainītu uzreiz.

1. uzdevums -

Koplieto dokumentu ar klasesbiedru kā komentētājs

Beigās tavā dokumentā būs klasesbiedra komentārs un ieteikums, bet tavu tekstu viņš nebūs varējis mainīt. Šo uzdevumu dari pārī: abi dara tos pašus soļus.

  1. Izveido dokumentu: pārlūkā atver docs.google.com un nospied Blank document (tukšs dokuments), laukumu ar krāsaino plusu.
  2. Sagatavo dokumentu: augšā kreisajā stūrī noklikšķini uz Untitled document, ieraksti 7.2 Koplietošanas tests un nospied Enter. Dokumentā ieraksti teikumu Šo tekstu drīkst komentēt, bet ne mainīt.
  3. Atver koplietošanas logu: augšā labajā stūrī nospied Share (kopīgot). Laukā Add people, groups, and calendar events ieraksti klasesbiedra skolas e-pastu un sarakstā noklikšķini uz viņa vārda.
  4. Izvēlies lomu: pa labi no e-pasta lauka ir saraksts, kurā rakstīts Editor. Izvēlies tajā Commenter (komentētājs) un nospied Send (sūtīt).
  5. Atver klasesbiedra dokumentu: jaunā cilnē atver drive.google.com, kreisajā pusē izvēlies Shared with me (kopīgots ar mani) un atver dokumentu 7.2 Koplietošanas tests ar klasesbiedra vārdu.
  6. Mēģini izdzēst vārdu: klasesbiedra dokumentā iezīmē vārdu komentēt un nospied Delete. Vārds neizzūd, bet kļūst pārsvītrots un krāsains. Tas ir ieteikums (suggestion): to pieņems vai noraidīs īpašnieks.
  7. Pievieno komentāru: iezīmē vārdu mainīt, nospied Ctrl+Alt+M, ieraksti Kāpēc ne? un nospied Comment (komentēt).
  8. Apskati savu dokumentu: atgriezies savā dokumentā. Labajā malā ir klasesbiedra ieteikums un komentārs ar viņa vārdu. Pie ieteikuma nospied ķeksīti ✓ (pieņemt) vai krustiņu ✗ (noraidīt).

Gatavs, kad: tava dokumenta labajā malā ir klasesbiedra komentārs Kāpēc ne?, un, atverot Share, pie viņa vārda rakstīts Commenter.

Iestrēgi?
  • 1. solis: atveras cits Google konts. Augšā labajā stūrī noklikšķini uz konta attēla un izvēlies savu skolas kontu, to pašu, ko lietoji 5.4 stundā. Ja tā nav sarakstā, nospied Add another account (pievienot citu kontu).
  • 3. solis: sarakstā neparādās klasesbiedra vārds. Ieraksti pilnu e-pasta adresi un nospied Enter. Ja Google raksta, ka ārpus skolas koplietot nedrīkst, pārbaudi, vai adrese ir skolas, nevis privātā.
  • 4. solis: nav saraksta ar Editor. Tas parādās tikai pēc tam, kad ir pievienots vismaz viens e-pasts.
  • 5. solis: Shared with me ir tukšs. Klasesbiedrs vēl nav nospiedis Send, vai tu esi pieteicies ar citu kontu. Pagaidi minūti un atsvaidzini lapu ar F5.
  • 6. solis: vārds izdzēšas parasti. Tev ir loma Editor. Lai klasesbiedrs to nomaina: Share → saraksts pie tava vārda → Commenter → Save.
  • 7. solis: nevar pievienot komentāru, augšā rakstīts View only. Tev ir loma Viewer. Lai klasesbiedrs to nomaina uz Commenter, kā iepriekšējā punktā.

2. uzdevums -

Izveido projekta mapi ar trim piekļuves līmeņiem

Beigās tavā Google Drive būs mape, kuru klasesbiedrs var rediģēt, skolotājs var komentēt, bet ar saiti var atvērt tikai gatavo PDF.

Prasības. Tu un klasesbiedrs (komandas biedrs) kopā rakstāt projekta aprakstu:

KasKo koplietoTiesības
Komandas biedrs (klasesbiedrs)mapi 7.2 Projektsrediģēt
Skolotājsmapi 7.2 Projektskomentēt
Ikviens ar saititikai failu Projekta apraksts.pdfskatīt, bet ne lejupielādēt
  1. Izveido mapi: atver drive.google.com, kreisajā augšējā stūrī nospied New (jauns) → New folder (jauna mape), ieraksti 7.2 Projekts un nospied Create (izveidot).
  2. Izveido dokumentu mapē: divreiz noklikšķini uz mapes 7.2 Projekts, tad New → Google Docs → Blank document. Nosauc dokumentu Projekta apraksts un ieraksti tajā Šis ir mūsu projekta apraksts.
  3. Saglabā dokumentu kā PDF: dokumentā izvēlies File → Download → PDF Document (.pdf). Fails Projekta apraksts.pdf nonāk mapē Lejupielādes (Downloads).
  4. Augšupielādē PDF mapē: pārslēdzies uz Drive cilni, kurā ir atvērta mape 7.2 Projekts. Nospied New → File upload (augšupielādēt failu), atver mapi Lejupielādes, izvēlies Projekta apraksts.pdf un nospied Open. Mapē tagad ir divi faili.
  5. Komandas biedram dod rediģēšanu: kreisajā pusē izvēlies My Drive (mans disks), ar peles labo pogu noklikšķini uz mapes 7.2 Projekts → Share → Share. Ieraksti klasesbiedra e-pastu, lomu atstāj Editor un nospied Send.
  6. Skolotājam dod komentēšanu: atver mapes Share logu vēlreiz. Ieraksti skolotāja e-pastu (skolotājs to pateiks stundā), izvēlies lomu Commenter, noņem ķeksīti Notify people (paziņot) un nospied Share. Skolotājs mapi atradīs sadaļā Shared with me.
  7. PDF failam dod saiti: atver mapi, ar peles labo pogu noklikšķini uz Projekta apraksts.pdf → Share → Share. Sadaļā General access (vispārējā piekļuve) noklikšķini uz Restricted (ierobežota) un izvēlies Anyone with the link. Pa labi lomu atstāj Viewer. Nospied Copy link (kopēt saiti) un Done (gatavs).
  8. Saglabā saites piezīmēs: VS Code atver README.md, faila beigās pievieno šīs rindas un aiz PDF saite: ielīmē nokopēto saiti ar Ctrl+V: 
    ### 7.2 Koplietošana

- PDF saite:
- Mapes saite:

    Tad Drive ar peles labo pogu noklikšķini uz mapes 7.2 Projekts → Share → Copy link un ielīmē to aiz Mapes saite:. Saglabā ar Ctrl+S.

Gatavs, kad: mapes Share logā ir trīs cilvēki: tu (Owner), klasesbiedrs (Editor) un skolotājs (Commenter), un zem General access rakstīts Restricted. PDF faila Share logā zem General access rakstīts Anyone with the link un Viewer.

Iestrēgi?
  • 3. solis: fails sauc Projekta apraksts (1).pdf. Tu to lejupielādēji vairākas reizes. Tas nekas: augšupielādē jaunāko.
  • 4. solis: PDF nonāca My Drive, nevis mapē. Ar peles labo pogu noklikšķini uz faila → Organize → Move (pārvietot), izvēlies 7.2 Projekts un nospied Move.
  • 5. solis: izvēlnē nav Share. Noklikšķini uz mapes vienu reizi un augšējā joslā nospied ikonu ar cilvēciņu un plusu.
  • 6. solis: poga saucas Send, nevis Share. Ķeksītis Notify people vēl ir ieslēgts. Noņem to.
  • 7. solis: Anyone with the link vietā ir tikai skolas nosaukums. Skolas administrators ļauj koplietot tikai skolas iekšienē. Izvēlies skolas nosaukumu un 3. uzdevumā pieraksti, ka saite strādā tikai skolas kontiem.
  • Prasība "ne lejupielādēt" vēl nav izpildīta. Tā tam jābūt. 3. uzdevumā tu to atklāsi pārbaudē un salabosi.

3. uzdevums -

Pārbaudi katru lomu un salabo nepareizo iestatījumu

Beigās tavā README.md būs tabula, kurā katrai lomai gaidītais rezultāts sakrīt ar faktisko. Strādā pārī ar to pašu klasesbiedru, kuram 2. uzdevumā devi lomu Editor.

  1. Ieraksti, ko gaidi: README.md zem rindas - Mapes saite: atstāj tukšu rindu, ielīmē šo tabulu un saglabā: 
    | Kas | Darbība | Gaidīts | Faktiski |
|---|---|---|---|
| Komandas biedrs (Editor) | raksta dokumentā | var |  |
| Skolotājs (Commenter) | raksta dokumentā | tikai ieteikums |  |
| Skolotājs (Commenter) | pievieno komentāru | var |  |
| Ikviens ar saiti | atver PDF | var |  |
| Ikviens ar saiti | lejupielādē PDF | nevar |  |
| Ikviens ar saiti | atver mapi | nevar |  |
| Ikviens | lasa manu GitHub krātuvi | var |  |
  2. Pārbaudi redaktoru: klasesbiedrs atver Shared with me → 7.2 Projekts → Projekta apraksts un dokumenta beigās ieraksti Labojums no komandas biedra. Ja teksts parādās parastā krāsā, ailē Faktiski pirmajā rindā ieraksti var.
  3. Apskati versiju vēsturi: savā dokumentā Projekta apraksts izvēlies File → Version history → See version history. Labajā pusē ir jaunākā versija ar klasesbiedra vārdu, un viņa teksts ir iekrāsots. Aizver vēsturi ar bultiņu augšā kreisajā stūrī.
  4. Pārbaudi komentētāju: skolotāja lomu izmēģina klasesbiedrs. Drive mapes Share logā pie klasesbiedra vārda izvēlies Commenter un nospied Save. Klasesbiedrs atsvaidzina dokumentu ar F5, mēģina ierakstīt vārdu un pievieno komentāru ar Ctrl+Alt+M. Ieraksti abus rezultātus tabulā. Pēc tam atgriez klasesbiedram lomu Editor.
  5. Pārbaudi saiti kā svešinieks: pārlūkā nospied Ctrl+Shift+N. Atveras privātais logs (InPrivate vai Incognito), kurā tu neesi pieteicies. Ielīmē tajā PDF saiti no README.md. PDF atveras, un augšējā labajā stūrī ir lejupielādes ikona (bultiņa uz leju). Ieraksti tabulā: atver PDF var, lejupielādē PDF var.
  6. Pārbaudi mapi un GitHub: tajā pašā privātajā logā ielīmē mapes saiti. Google prasa pieteikties vai raksta, ka vajag piekļuvi: ieraksti nevar. Tad atver github.com/TAVS-LIETOTĀJVĀRDS/programmesana-pamatkurss: kods ir redzams, ieraksti var.
  7. Salabo nepareizo iestatījumu: rindā lejupielādē PDF gaidīts nevar, bet faktiski var. Drive ar peles labo pogu noklikšķini uz Projekta apraksts.pdf → Share → Share, loga augšējā labajā stūrī nospied zobratu ⚙ un noņem ķeksīti Viewers and commenters can see the option to download, print, and copy. Privātajā logā atver PDF saiti vēlreiz: lejupielādes ikonas vairs nav. Tabulā izlabo uz nevar (pēc labojuma).
  8. Pieraksti secinājumu. Aizver privāto logu. README.md zem tabulas atstāj tukšu rindu, pievieno šo teikumu, pabeidz to un saglabā: 
    Saite "Anyone with the link" ir risks, ja ..., piemēram, ...

Gatavs, kad: Markdown priekšskatījumā (Ctrl+Shift+V) visās tabulas rindās aile Faktiski ir aizpildīta un sakrīt ar Gaidīts, un zem tabulas ir pabeigts teikums par saites risku.

Iestrēgi?
  • 2. solis: klasesbiedra teksts ir pārsvītrots vai krāsains. Viņam ir loma Commenter, nevis Editor. Pārbaudi mapes Share logu (2. uzdevuma 5. solis).
  • 3. solis: izvēlne Version history ir pelēka. Tu esi atvēris klasesbiedra kopiju vai neesi dokumenta īpašnieks. Atver dokumentu no My Drive → 7.2 Projekts.
  • 4. solis: klasesbiedrs joprojām var rakstīt parasti. Lomu maini mapei, nevis dokumentam, un nospied Save. Ja dokumentam pašam ir dota cita loma, nomaini arī to dokumenta Share logā.
  • 5. solis: Ctrl+Shift+N neko neatver. Pārlūka izvēlnē (trīs punkti augšā labajā stūrī) izvēlies New InPrivate window (Edge) vai New Incognito window (Chrome).
  • 5. solis: PDF prasa pieteikties. Skola ļauj koplietot tikai skolas iekšienē (2. uzdevuma 7. solis). Ailē Faktiski ieraksti tikai skolas kontiem. Tas nav tava kļūda.
  • 7. solis: zobrata nav. Tas ir loga Share "Projekta apraksts.pdf" augšējā labajā stūrī, blakus jautājuma zīmei. Tu esi atvēris mapes, nevis PDF faila logu.
  • Vai bez lejupielādes pogas failu tiešām nevar paņemt? Var, piemēram, ar ekrānuzņēmumu. Šis iestatījums apgrūtina, bet neaizsargā pilnībā. Tāpēc slepenu failu ar saiti nekoplieto vispār.
Papildu uzdevums - Pievieno līdzstrādnieku GitHub un noņem viņu

Ja pamatdarbs ir gatavs, izmēģini, ko nozīmē līdzstrādnieks (collaborator) GitHub. Vajag klasesbiedra GitHub lietotājvārdu.

  1. Atver krātuves iestatījumus: GitHub Desktop izvēlies Repository → View on GitHub. Krātuves lapā nospied Settings (iestatījumi), kreisajā pusē Collaborators (līdzstrādnieki). Ja GitHub prasa paroli, ievadi to.
  2. Uzaicini klasesbiedru: nospied Add people, ieraksti klasesbiedra GitHub lietotājvārdu, izvēlies viņu sarakstā un nospied Add … to this repository.
  3. Klasesbiedrs pieņem uzaicinājumu: viņš atver GitHub e-pastu vai github.com/notifications un nospied Accept invitation (pieņemt).
  4. Klasesbiedrs izveido failu tavā krātuvē: viņš atver tavu krātuvi, mapi tema07, nospied Add file → Create new file, nosauc failu sveiciens_72.txt, ieraksta vienu teikumu un divreiz nospied Commit changes.
  5. Saņem failu: GitHub Desktop nospied Fetch origin, tad Pull origin. VS Code mapē tema07 parādās sveiciens_72.txt.
  6. Noņem piekļuvi: Settings → Collaborators pie klasesbiedra vārda nospied Remove un apstiprini. Pēc mazāko tiesību principa tiesības paliek tikai tik ilgi, cik tās vajag.

Gatavs, kad: VS Code mapē tema07 ir fails sveiciens_72.txt, bet lapā Collaborators klasesbiedra vārda vairs nav.

Stundas beigās

  1. Saglabā visus failus: VS Code izvēlies File → Save All.
  2. Apskati izmaiņas: pārslēdzies uz GitHub Desktop. Zem Changes (izmaiņas) jābūt README.md.
  3. Apraksti un fiksē: laukā Summary (kopsavilkums) ieraksti Pievieno 7.2 piekļuves pārbaudi un nospied Commit to main.
  4. Nosūti: nospied Push origin (nosūtīt uz GitHub).

Gatavs, kad: GitHub vietnē failā README.md redzama sadaļa 7.2 Koplietošana ar aizpildītu tabulu.
