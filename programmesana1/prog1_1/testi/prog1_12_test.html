Atkārtojuma tests: 1.1 Datora sagatavošana un IDE

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kas izpilda tavu Python kodu?

Interpreteris ir programma, kas kodu izpilda. VS Code ir redaktors, kurā kodu raksti, un paplašinājums tikai palīdz VS Code saprast Python failus. Atkārto: 1.1 — Teorija: Kas ir IDE un Python? ↗

2. Tu uzstādīji VS Code Python paplašinājumu, bet terminālis uz python --version atbild, ka Python nav atrasts. Kas visticamāk trūkst?

Paplašinājums un interpreteris ir divas dažādas lietas. Python interpreteris jāuzstāda atsevišķi no Microsoft Store, un pēc tam jāatver jauns terminālis. Atkārto: 1.1 — 1. uzdevums — Uzstādi VS Code un Python ↗

3. Kura rinda izdrukā tekstu Sveika, pasaule!?

Teksts jāraksta pēdiņās, un pēdiņas jāliek iekavās aiz vārda print. Vārdam print jābūt uzrakstītam precīzi. Atkārto: 1.1 — 2. uzdevums — Uzraksti un palaid 11.py ↗

4. Rindā print("Sveika, pasaule!") tu izdzēsi pēdējo pēdiņu un palaid kodu. Kuru kļūdu redzēsi?

SyntaxError nozīmē, ka kods uzrakstīts nepareizi, piemēram, trūkst pēdiņas vai iekavas. NameError rodas, ja Python nepazīst vārdu, piemēram, prnt. Atkārto: 1.1 — 3. uzdevums — Salauz kodu un iemācies lasīt kļūdu ↗

5. Ko nosaka 20-20-20 noteikums?

Ik pēc 20 minūtēm atpūtini redzi: 20 sekundes skaties tālumā, piemēram, pa logu. Tā acis mazāk nogurst. Atkārto: 1.1 — Teorija: Kas ir IDE un Python? ↗
