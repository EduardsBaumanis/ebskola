1.2 GitHub un Mākoņkrātuve

Stundas uzdevums: Izveidot profesionālu profilu koda glabāšanas platformā, uzstādīt vizuālu koda pārvaldības rīku un iniciēt savu pirmo attālināto krātuvi mākonī.

2.4.9. Lieto versiju pārvaldības sistēmas (Git). 2.4.12. Sagatavo un konfigurē programmēšanas vidi.

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - izveido GitHub kontu · 2. uzdevums (~25 min) - izveido pirmo krātuvi un uzstādi GitHub Desktop · 3. uzdevums (~20 min) - uzraksti programmu, kas saliek tavu krātuves saiti. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: sagatavo e-pasta adresi, kurai vari piekļūt stundas laikā - GitHub prasīs apstiprināt e-pastu, un bez tā krātuvi izveidot nevarēsi.

Teorija: Koda glabāšana mākonī

Programmēšanā jānodrošina, lai kods nepazustu un būtu pieejams neatkarīgi no konkrētā datora.

  • Cloud hosting (Mākoņvides uzturēšana): GitHub ir platforma, kas glabā tavu kodu drošībā internetā un ļauj pie tā strādāt komandā.
  • Repository (Krātuve): Tava projekta "mape" GitHub vidē, kas satur visus failus un to izmaiņu vēsturi.
  • Version control (Versiju kontrole): Sistēma (Git), kas izseko katrai izmaiņai kodā. GitHub Desktop ir vizuāla programma, kas palīdz lietot šo sistēmu, neizmantojot sarežģītas komandrindas komandas.
# Demonstrācija: Kā koda mainīgie atspoguļo GitHub saites struktūru
lietotajvards = "Programmetajs123"
kratuves_nosaukums = "programmesana-pamatkurss"
gala_saite = f"github.com/{lietotajvards}/{kratuves_nosaukums}"

Praktiskie uzdevumi

1. uzdevums -

Izveido GitHub kontu

Beigās tev būs savs GitHub konts ar apstiprinātu e-pastu.

  1. Atver github.com un nospied Sign up.
  2. Izvēlies lietotājvārdu bez garumzīmēm un atstarpēm, piemēram janis-programmetajs.
  3. Ievadi savu e-pasta adresi un izdomā paroli.
  4. Atver e-pastu un nospied GitHub atsūtīto apstiprinājuma saiti.
  5. Pieraksti savu lietotājvārdu README.md failā - tas būs vajadzīgs katrā nākamajā stundā.

Gatavs, kad: vari ieiet github.com ar savu lietotājvārdu un lapas augšā redzi savu profila bildi.

2. uzdevums -

Izveido pirmo krātuvi un uzstādi GitHub Desktop

Beigās tev mākonī būs tukša krātuve, un dators to redzēs.

  1. Nospied GitHub lapā zaļo pogu New jaunas krātuves izveidei.
  2. Ieraksti nosaukumu programmesana-pamatkurss.
  3. Izvēlies Public un ieķeksē Add a README file.
  4. Nospied Create repository.
  5. Lejupielādē GitHub Desktop no desktop.github.com un uzstādi to.
  6. Pieraksties GitHub Desktop ar to pašu kontu.

Gatavs, kad: GitHub Desktop kreisajā pusē redzi savu krātuvi programmesana-pamatkurss.

3. uzdevums -

Uzraksti programmu, kas saliek tavu krātuves saiti

Beigās Python pats izdrukās pilnu saiti uz tavu krātuvi.

  1. Izveido VS Code jaunu failu saite.py.
  2. Ieraksti mainīgo lietotajvards = "tavs_vards" ar savu īsto lietotājvārdu.
  3. Ieraksti otru mainīgo kratuve = "programmesana-pamatkurss".
  4. Uzraksti rindu saite = f"https://github.com/{lietotajvards}/{kratuve}".
  5. Pievieno rindu print(saite) un palaid kodu.
  6. Nokopē izdrukāto saiti un atver to pārlūkā.
  7. Pieraksti vienu secinājumu: ko dara burts f pirms pēdiņām.

Gatavs, kad: izdrukātā saite atveras pārlūkā un rāda tieši tavu krātuvi, nevis kļūdu 404.

Papildu uzdevums - Papildini savu profilu

Ja pamatdarbs ir gatavs, padari savu GitHub profilu saprotamu citiem.

  1. Atver Settings -> Profile savā GitHub kontā.
  2. Ieraksti laukā Bio vienu teikumu par sevi.
  3. Augšupielādē profila bildi vai izvēlies avataru.
  4. Atver savu krātuvi un nospied zīmuļa ikonu pie README.
  5. Ieraksti vienu rindu par to, kas šajā krātuvē būs, un saglabā.

Gatavs, kad: tavā profilā ir redzams apraksts, bet krātuves sākumlapā - tavs teikums par projektu.

Biežākās kļūdas (un kā tās labot):

  • Neapstiprināts e-pasts: GitHub ierobežos tavas iespējas (neļaus izveidot krātuves), ja nebūsi apstiprinājis savu e-pastu. Pārbaudi "Spam" vai "Surogātpasts" mapi, ja neredzi vēstuli.
  • Neprofesionāls lietotājvārds: Izvairies no iesaukām, kuras būtu neērti rādīt nākotnes darba devējam vai skolotājam. Izmanto sava vārda un uzvārda variācijas.
  • Autorizācijas kļūda Desktop lietotnē: Ja programmai neizdodas savienoties ar tavu kontu, dodies uz File -> Options -> Accounts, izraksties (Sign out) un mēģini autorizācijas procesu no jauna.
