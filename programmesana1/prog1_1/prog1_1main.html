# 02 špikeris

1. tēmas špikeris - darba vide un kodu pārvaldība

Viss, ko apgūsti šajā tēmā: no Python uzstādīšanas līdz publicētam projektam GitHub. Katrs bloks atbilst vienai stundai.

1.1 Pirmās komandas un pirmā programma

# Pārbaudi, vai Python ir uzstādīts (pēc instalēšanas atver JAUNU termināli)
python --version          # -> Python 3.12.1
py --version              # Windows alternatīva

# Ja redzi 'python' is not recognized / command not found:
#   instalēšanas logā nebija ieķeksēts "Add Python to PATH"
#   -> palaid instalētāju vēlreiz -> Modify -> ieķeksē

# Programmas palaišana
python hello.py

# Divas biežākās sākuma kļūdas:
#   SyntaxError  - trūkst pēdiņa, iekava vai kols  -> rāda rindas numuru
#   NameError    - uzrakstīts prnt( ) vietā print( )

Kļūdas paziņojumu vienmēr lasi no apakšas uz augšu - pēdējā rindā ir kļūdas tips un iemesls.

1.2-1.3 Git darba cikls

# Vienreiz katrā datorā
git config --global user.name "Vārds Uzvārds"
git config --global user.email "tavs@pasts.lv"

# Vienreiz katram projektam
git clone https://github.com/lietotajs/kratuve.git

# KATRU reizi, kad esi kaut ko izdarījis
git add .                          # sagatavo izmaiņas
git commit -m "Pievieno sveiciens.py"   # saglabā LOKĀLI
git push                           # nosūta uz GitHub

# Saņemt izmaiņas no mākoņa
git pull

git status                         # ko esmu mainījis?
git log --oneline                  # izmaiņu vēsture

commit saglabā tikai tavā datorā. Bez push GitHub nekas neparādās.

1.4 Mapju struktūra un .gitignore

projekts/
├── .gitignore          <- ko NESŪTĪT uz GitHub
├── README.md           <- projekta apraksts
├── LICENSE             <- lietošanas noteikumi
├── uzdevumi/
│   └── diena1.py
└── dati/
    └── noslepums.txt   <- šo neviens neredzēs

# .gitignore saturs
noslepums.txt           # konkrēts fails
*.png                   # visi faili ar šo paplašinājumu
pagaidu_dati/           # vesela mape
__pycache__/            # Python ģenerētie faili
venv/                   # virtuālā vide

# Relatīvie ceļi tiek skaitīti no tās mapes, kurā ATRODAS terminālis
python uzdevumi/diena1.py     # no projekta saknes - strādā
cd uzdevumi && python diena1.py   # arī strādā
cd uzdevumi && python uzdevumi/diena1.py   # KĻŪDA: nav tādas mapes

Ja programma "neatrod" failu, vispirms pārbaudi, kurā mapē stāv terminālis.

1.6 Pārbaudes darba kontrolsaraksts

Pirms iesniegšanas pārbaudi:

[ ] Mapju struktūra ir sakārtota (nav visi faili vienā kaudzē)
[ ] .gitignore eksistē un personīgie faili GitHub NAV nonākuši
[ ] Programma palaižas bez kļūdām
[ ] README.md ir virsraksts, autors un vismaz divas ## sadaļas
[ ] README GitHub lapā izskatās noformēts, nevis kā viena rinda
[ ] LICENSE fails ir pievienots
[ ] commit ziņas ir saprotamas ("Pievieno README", nevis "update")
[ ] git push ir izpildīts un fails GitHub tiešām ir redzams
[ ] Krātuves saite ir iesniegta skolotājam

Pārbaudi krātuves saiti inkognito logā - tā tu redzēsi to, ko redz skolotājs.
