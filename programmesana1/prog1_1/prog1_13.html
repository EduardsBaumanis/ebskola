1.3 Koda sinhronizācija (Desktop)

Stundas uzdevums: Klonēt mākoņkrātuvi, nofiksēt lokālās izmaiņas kodā un sinhronizēt tās ar galveno projektu, izmantojot versiju kontroles pamatdarbības.

2.4.9. Lieto versiju pārvaldības sistēmas (Git).

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - klonē krātuvi uz datoru · 2. uzdevums (~25 min) - izdari izmaiņu, commit un push · 3. uzdevums (~20 min) - izlasi Diff un salabo neskaidru commit ziņu. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver GitHub Desktop un pārliecinies, ka esi pieteicies ar savu kontu no 1.2 stundas.

Teorija: Sinhronizācijas darba cikls

Lai Tavas koda izmaiņas nonāktu no VS Code uz GitHub mākoni, vienmēr tiek izmantots konkrēts trīs soļu cikls.

  • Clone (Klonēšana): Vienreizējs process, kurā Tu lejupielādē krātuves kopiju no interneta savā datorā.
  • Commit (Fiksēšana): Kad esi veicis izmaiņas, Tu radi "saglabāšanas punktu" lokālajā datorā, pievienojot tam īsu aprakstu.
  • Push (Augšupielāde): Tavu lokālo fiksējumu nosūtīšana uz GitHub mākoni, lai tie būtu pieejami citiem.
  • Diff (Atšķirības): Vizuāls rīks GitHub Desktop vidē, kas parāda izdzēsto kodu ar sarkanu mīnusu un pievienoto – ar zaļu plusu.

Praktiskie uzdevumi

1. uzdevums - Klonē krātuvi uz datoru

Beigās tava mākoņa krātuve būs kā parasta mape tavā datorā.

  1. Atver GitHub Desktop un izvēlies File -> Clone repository.
  2. Izvēlies sarakstā savu krātuvi programmesana-pamatkurss.
  3. Pieraksti vietu, kur mape tiks saglabāta (Local path).
  4. Nospied Clone un pagaidi, līdz lejupielāde beidzas.
  5. Atver šo mapi datorā un pārbaudi, vai tajā ir fails README.md.

Gatavs, kad: tavā datorā ir mape ar README.md, un GitHub Desktop raksta "No local changes".

2. uzdevums - Izdari izmaiņu, commit un push

Beigās tava izmaiņa no datora būs redzama GitHub mājaslapā.

  1. Atver klonēto mapi VS Code un izveido failu sveiciens.py.
  2. Ieraksti tajā print("Mans pirmais commit!") un saglabā.
  3. Pārslēdzies uz GitHub Desktop - kreisajā pusē parādīsies faila nosaukums.
  4. Ieraksti Summary laukā īsu ziņu, piemēram Pievieno sveiciens.py.
  5. Nospied Commit to main.
  6. Nospied Push origin augšējā joslā.
  7. Atver savu krātuvi pārlūkā un pārbaudi, vai fails ir tur.

Gatavs, kad: GitHub mājaslapā redzi failu sveiciens.py un savu commit ziņu blakus tam.

3. uzdevums - Izlasi Diff un salabo neskaidru commit ziņu

Beigās tu pratīsi pateikt, kura rinda tika pievienota un kura izdzēsta.

  1. Nomaini failā sveiciens.py tekstu pēdiņās uz kaut ko citu un saglabā.
  2. Paskaties GitHub Desktop labajā pusē: sarkanā rinda ar mīnusu ir vecā, zaļā ar plusu - jaunā.
  3. Ieraksti apzināti neskaidru Summary, piemēram izmainas, un veic commit.
  4. Nospied Push origin un atver GitHub vēsturi (Commits).
  5. Pārliecinies, ka pēc mēneša tu vairs nesaprastu, ko šī ziņa nozīmē.
  6. Izdari vēl vienu izmaiņu ar skaidru ziņu, piemēram Nomaina sveiciena tekstu.
  7. Pieraksti vienu secinājumu: kāpēc commit ziņai jābūt konkrētai.

Gatavs, kad: GitHub vēsturē ir vismaz trīs commit ieraksti un tu vari izskaidrot, ko katrs mainīja.

Papildu uzdevums - Izmēģini Pull

Ja pamatdarbs ir gatavs, uzzini, kā saņemt izmaiņas no mākoņa uz datoru.

  1. Atver savu krātuvi pārlūkā un nospied zīmuļa ikonu pie README.md.
  2. Pievieno vienu jaunu rindu un nospied Commit changes tieši pārlūkā.
  3. Pārslēdzies uz GitHub Desktop un nospied Fetch origin.
  4. Nospied Pull origin, kad parādās šī poga.
  5. Atver README.md datorā un pārbaudi, vai jaunā rinda ir klāt.

Gatavs, kad: rinda, ko uzrakstīji pārlūkā, ir parādījusies arī failā tavā datorā.

Biežākās kļūdas (un kā tās labot):

  • GitHub Desktop neredz izmaiņas: Tu esi aizmirsis saglabāt failu iekš VS Code (ja pie faila nosaukuma augšā ir balts aplītis, izmanto Ctrl+S).
  • Izmaiņas nav redzamas internetā: Tu uztaisīji Commit, bet aizmirsi nospiest Push origin. Commit notiek tikai tavā lokālajā datorā, Push sūta datus uz internetu.
  • Bezjēdzīgi Commit ziņojumi: Atstājot tukšu vai rakstot "asdfgh", vēlāk History cilnē būs neiespējami saprast, kad kura kļūda tikusi izlabota. Vienmēr raksti aprakstošu kopsavilkumu!
