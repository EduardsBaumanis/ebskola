1.1 Datora sagatavošana un IDE

Stundas uzdevums: Sagatavot datoru profesionālam programmētāja darbam, uzstādīt atvērtā pirmkoda rīkus un palaist savu pirmo kodu Python valodā.

SR 2.3.1. Datorikas nozares attīstība un ietekme

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - uzstādi Python un VS Code · 2. uzdevums (~25 min) - uzraksti un palaid hello.py · 3. uzdevums (~20 min) - salauz kodu un iemācies lasīt kļūdu. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: pārliecinies, ka vari instalēt programmas šajā datorā. Ja skolas datorā instalēt nedrīkst, pasaki skolotājam - strādāsi ar jau uzstādīto vidi.

Teorija: Kas ir IDE un Python?

Lai rakstītu kodu, nepietiek ar parastu teksta redaktoru. Mums ir nepieciešama specializēta vide.

  • Python: Programmēšanas valoda jeb "tulks", kas paskaidro datoram Tavas instrukcijas.
  • IDE (Integrated Development Environment): Programma koda rakstīšanai. Mēs izmantosim Visual Studio Code (VS Code) - tas ir bezmaksas, viegls un profesionāls rīks.
  • Extensions (Paplašinājumi): VS Code papildrīki. Lai VS Code "saprastu" Python, mums būs jāuzstāda atbilstošs spraudnis.
  • Ergonomika: Programmējot mugurai jābūt taisnai, ekrānam acu līmenī un ik pēc 20 minūtēm jāatpūtina redze (20-20-20 noteikums).
# Pirmā Python programma (hello.py)
print("Sveika, pasaule!")
# Palaiž ar Run pogu vai terminālī:
# python hello.py

Praktiskie uzdevumi

1. uzdevums - Uzstādi Python un VS Code

Beigās tavs dators zinās, kas ir Python, un tu to redzēsi terminālī.

  1. Lejupielādē Python no python.org/downloads.
  2. Ieķeksē instalēšanas logā rūtiņu Add Python to PATH - bez tās terminālis Python neatradīs.
  3. Lejupielādē un uzstādi VS Code no code.visualstudio.com.
  4. Atver VS Code un kreisajā joslā izvēlies Extensions (kvadrātiņu ikona).
  5. Atrodi paplašinājumu Python (autors Microsoft) un nospied Install.
  6. Atver termināli ar Ctrl+` un izpildi python --version.

Gatavs, kad: terminālis atbild ar versijas numuru, piemēram Python 3.12.1, nevis ar kļūdu.

2. uzdevums - Uzraksti un palaid hello.py

Beigās tava pirmā programma izdrukās tekstu terminālī.

  1. Izveido uz darbvirsmas mapi python_darbi.
  2. Atver šo mapi VS Code ar File -> Open Folder.
  3. Izveido jaunu failu ar nosaukumu hello.py.
  4. Ieraksti tajā rindu print("Sveika, pasaule!").
  5. Saglabā failu ar Ctrl+S.
  6. Palaid kodu ar zaļo Run pogu augšējā labajā stūrī.

Gatavs, kad: termināļa apakšā parādās teksts Sveika, pasaule!.

3. uzdevums - Salauz kodu un iemācies lasīt kļūdu

Beigās tu pratīsi pateikt, kurā rindā ir kļūda, tikai paskatoties uz sarkano tekstu.

  1. Izdzēs failā hello.py pēdējo pēdiņu un palaid kodu.
  2. Izlasi sarkano paziņojumu un atrodi tajā vārdu SyntaxError un rindas numuru.
  3. Ieliec pēdiņu atpakaļ un pārliecinies, ka kods atkal strādā.
  4. Nomaini print uz prnt un palaid vēlreiz.
  5. Izlasi jauno kļūdu - tagad tur būs NameError.
  6. Salabo vārdu atpakaļ uz print.
  7. Pieraksti vienu secinājumu: ar ko SyntaxError atšķiras no NameError.

Gatavs, kad: tu vari nosaukt abas kļūdas un pateikt, kurā rindā katra radās.

Papildu uzdevums - Iekārto ergonomisku darba vietu

Ja pamatdarbs ir gatavs, sakārto savu sēdvietu tā, lai mugura un acis nenogurtu.

  1. Paceļ ekrānu tā, lai tā augšmala būtu acu līmenī.
  2. Pieregulē krēslu tā, lai pēdas stāv uz grīdas un mugura ir taisna.
  3. Ieslēdz telefonā taimeri uz 20 minūtēm.
  4. Paskaties pēc signāla 20 sekundes uz tālāko punktu aiz loga.
  5. Pieraksti savā burtnīcā 20-20-20 noteikumu ar saviem vārdiem.

Gatavs, kad: tavs ekrāns ir acu līmenī un burtnīcā ir pierakstīts 20-20-20 noteikums.

Biežākās kļūdas (un kā tās labot):

  • "Python is not recognized": Restartē VS Code programmu pēc Python instalācijas, lai tā pamanītu jauno "tulku".
  • SyntaxError: Esi aizmirsis pēdiņas vai iekavas print() funkcijai. Pārbaudi piemēru koda sadaļā!
  • Balts aplītis pie faila nosaukuma: Fails nav saglabāts. Lieto Ctrl+S vai ieslēdz Auto Save.

Koda piemērs (kad terminālis neatrod Python - grūtākā daļa)

# Pirmā komanda, ko izpildi pēc instalēšanas:
python --version

# JA VISS KĀRTĪBĀ, terminālis atbild ar versiju:
#   Python 3.12.1

# JA REDZI ŠO, Python ir uzstādīts, bet terminālis nezina, kur tas atrodas:
#   'python' is not recognized as an internal or external command
#   (Windows)
#   command not found: python
#   (macOS / Linux)
#
# Iemesls gandrīz vienmēr ir viens: instalēšanas logā nebija ieķeksēts
# "Add Python to PATH". Risinājums - palaid instalētāju vēlreiz,
# izvēlies "Modify" un ieķeksē šo rūtiņu.
#
# Windows datoros dažreiz palīdz arī:
py --version

# Pēc labošanas OBLIGĀTI aizver termināli un atver to no jauna -
# vecais terminālis joprojām atceras veco PATH un rādīs to pašu kļūdu.
Pēc veiksmīgas uzstādīšanas python --version atbild ar versijas numuru. Ja tā vietā redzi "not recognized" vai "command not found", tā nav koda kļūda - Python vienkārši nav pierakstīts PATH sarakstā, un pats kods vēl nav ne palaists.
