1.1 Datora sagatavošana un IDE

Stundas uzdevums: Sagatavot datoru profesionālam programmētāja darbam, uzstādīt VS Code no Microsoft Store, pievienot Python atbalstu VS Code vidē un palaist savu pirmo kodu Python valodā.

Pirms sāc: pārliecinies, ka vari instalēt programmas šajā datorā. Ja skolas datorā instalēt nedrīkst, pasaki skolotājam - strādāsi ar jau uzstādīto vidi.

Teorija: Kas ir IDE un Python?

Lai rakstītu kodu, nepietiek ar parastu teksta redaktoru. Mums ir nepieciešama specializēta vide.

  • Python: Programmēšanas valoda un "tulks", kas izpilda Tavas instrukcijas datorā.
  • IDE (Integrated Development Environment): Programma koda rakstīšanai. Mēs izmantosim Visual Studio Code (VS Code) - tas ir bezmaksas, viegls un profesionāls rīks.
  • Extensions (Paplašinājumi): VS Code papildrīki. Lai VS Code "saprastu" Python failus, mums būs jāuzstāda Python paplašinājums no VS Code Extensions sadaļas.
  • Interpreteris: Programma, kas patiesībā palaiž Python kodu. Ja tā datorā vēl nav, VS Code pēc Python paplašinājuma uzstādīšanas piedāvās sākt Python instalēšanu.
  • Ergonomika: Programmējot mugurai jābūt taisnai, ekrānam acu līmenī un ik pēc 20 minūtēm jāatpūtina redze (20-20-20 noteikums).
# Pirmā Python programma (hello.py)
print("Sveika, pasaule!")
# Palaiž ar Run pogu vai terminālī:
# python hello.py

Praktiskie uzdevumi

1. uzdevums -

Uzstādi VS Code no Microsoft Store un Python no VS Code

Beigās VS Code būs gatavs Python failiem, un tu redzēsi Python versiju terminālī.

  1. Atver Windows datorā Microsoft Store.
  2. Atrodi Visual Studio Code un nospied Get vai Install.
  3. Atver VS Code no Start izvēlnes vai Microsoft Store pogas Open.
  4. Atver VS Code kreisajā joslā Extensions (kvadrātiņu ikona).
  5. Atrodi paplašinājumu Python (autors Microsoft) un nospied Install.
  6. Nospied Ctrl+Shift+P, ieraksti Python: Select Interpreter un nospied Enter.
  7. Aizver un atver VS Code no jauna, lai tas pamanītu tikko uzstādīto Python.
  8. Atver termināli (Win poga + raksti terminal) un izpildi python --version.

Gatavs, kad: terminālis atbild ar versijas numuru, piemēram Python 3.12.1, un VS Code apakšējā joslā ir redzams izvēlētais Python interpreteris.

2. uzdevums -

Uzraksti un palaid hello.py

Beigās tava pirmā programma izdrukās tekstu terminālī.

  1. Izveido uz darbvirsmas mapi python_darbi.
  2. Atver šo mapi VS Code ar File -> Open Folder.
  3. Izveido jaunu failu ar nosaukumu hello.py.
  4. Ieraksti tajā rindu print("Sveika, pasaule!").
  5. Saglabā failu ar Ctrl+S.
  6. Palaid kodu ar zaļo Run pogu augšējā labajā stūrī.

Gatavs, kad: termināļa apakšā parādās teksts Sveika, pasaule!.

3. uzdevums -

Salauz kodu un iemācies lasīt kļūdu

Beigās tu pratīsi pateikt, kurā rindā ir kļūda, tikai paskatoties uz sarkano tekstu.

  1. Izdzēs failā hello.py pēdējo pēdiņu un palaid kodu.
  2. Izlasi sarkano paziņojumu un atrodi tajā vārdu SyntaxError un rindas numuru.
  3. Ieliec pēdiņu atpakaļ un pārliecinies, ka kods atkal strādā.
  4. Nomaini print uz prnt un palaid vēlreiz.
  5. Izlasi jauno kļūdu - tagad tur būs NameError.
  6. Salabo vārdu atpakaļ uz print.
  7. Pieraksti vienu secinājumu: ar ko SyntaxError atšķiras no NameError.

Gatavs, kad: tu vari nosaukt abas kļūdas un pateikt, kurā rindā katra radās.

Papildu uzdevums - Iekārto ergonomisku darba vietu

Ja pamatdarbs ir gatavs, sakārto savu sēdvietu tā, lai mugura un acis nenogurtu.

  1. Paceļ ekrānu tā, lai tā augšmala būtu acu līmenī.
  2. Pieregulē krēslu tā, lai pēdas stāv uz grīdas un mugura ir taisna.
  3. Ieslēdz telefonā taimeri uz 20 minūtēm.
  4. Paskaties pēc signāla 20 sekundes uz tālāko punktu aiz loga.
  5. Pieraksti savā README.md failā 20-20-20 noteikumu ar saviem vārdiem.

Gatavs, kad: tavs ekrāns ir acu līmenī un README.md failā ir pierakstīts 20-20-20 noteikums.

Biežākās kļūdas (un kā tās labot):

  • "Python is not recognized": Aizver veco termināli un atver jaunu. Ja kļūda paliek, nospied Ctrl+Shift+P, izvēlies Python: Select Interpreter un atlasi uzstādīto Python.
  • Uzstādīts tikai paplašinājums: Python paplašinājums palīdz VS Code strādāt ar Python failiem, bet interpreteris joprojām jāuzstāda, kad VS Code to piedāvā.
  • SyntaxError: Esi aizmirsis pēdiņas vai iekavas print() funkcijai. Pārbaudi piemēru koda sadaļā!
  • Balts aplītis pie faila nosaukuma: Fails nav saglabāts. Lieto Ctrl+S vai ieslēdz Auto Save.

Koda piemērs (kad VS Code vēl neatrod Python)

# Pirmā komanda, ko izpildi pēc VS Code Python sagatavošanas:
python --version

# JA VISS KĀRTĪBĀ, terminālis atbild ar versiju:
#   Python 3.12.1

# JA REDZI ŠO, VS Code vai terminālis vēl neatrod Python:
#   Python was not found
#   'python' is not recognized as an internal or external command
#   (Windows)
#   command not found: python
#   (macOS / Linux)
#
# Ko dari Windows datorā:
# 1) Aizver šo termināli un atver jaunu VS Code termināli.
# 2) Nospied Ctrl+Shift+P -> Python: Select Interpreter.
# 3) Ja Python sarakstā nav, atver Python failu un VS Code paziņojumā
#    izvēlies Install Python / Install from Microsoft Store.
# 4) Kad instalēšana pabeigta, aizver un atver VS Code vēlreiz.
#
# Windows datoros dažreiz palīdz arī:
py --version

# Pēc labošanas OBLIGĀTI atver jaunu termināli -
# vecais terminālis var joprojām neatpazīt tikko uzstādīto Python.
Pēc veiksmīgas uzstādīšanas python --version atbild ar versijas numuru. Ja tā vietā redzi "not recognized" vai "command not found", tā nav koda kļūda - iespējams, ir uzstādīts tikai VS Code Python paplašinājums, Python interpreteris vēl nav atlasīts, vai arī jāatver jauns terminālis.
