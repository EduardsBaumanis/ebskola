Atkārtojuma tests: 13.5 Python ↔ PostgreSQL (psycopg2)

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Jautājumi

1. Kas ir psycopg2?

To uzstāda ar pip install psycopg2-binary, un tā ļauj no Python izpildīt SQL vaicājumus. Atkārto: 13.5 — Teorija: psycopg2 — Python ↔ PostgreSQL tilts ↗

2. Kāpēc vaicājumā vērtības nodod ar %s, nevis ievieto ar f-string?

Ar f-string lietotāja teksts kļūst par daļu no SQL komandas. Ar %s tas vienmēr paliek tikai vērtība. Atkārto: 13.5 — Teorija: psycopg2 — Python ↔ PostgreSQL tilts ↗

3. Lietotājs ievada vārdu ' OR '1'='1. Kādu SQL izveido f-string? 
vards = "' OR '1'='1"
print(f"SELECT * FROM speletaji WHERE vards = '{vards}'")

Lietotāja pēdiņa aizver vārdu, un OR '1'='1' ir patiess katrai rindai, tāpēc vaicājums atgriež visu tabulu. Atkārto: 13.5 — 2. uzdevums — Ievadi un nolasi datus ar parametriem ↗

4. Programma izpilda INSERT, bet bez conn.commit(). Kas notiek ar jauno rindu?

commit() apstiprina izmaiņas. Bez tā rinda pazūd, kad programma beidz darbu. Atkārto: 13.5 — 2. uzdevums — Ievadi un nolasi datus ar parametriem ↗

5. Kur jāglabā datubāzes parole, lai tā nenonāktu GitHub?

Paroles failu ieraksta .gitignore, tāpēc Git to nesūta uz GitHub, un parole paliek tikai tavā datorā. Atkārto: 13.5 — 1. uzdevums — Pieslēdzies datubāzei no Python ↗
