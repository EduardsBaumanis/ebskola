3. Ko izdrukā šis kods? 
class Dalibnieks:
    def __init__(self, vards, energija, temps):
        self.vards = vards
        self.energija = energija
        self.temps = temps

class Skerslis:
    def iedarbojas(self, dalibnieks):
        pass

class PrinteraRinda(Skerslis):
    def iedarbojas(self, dalibnieks):
        dalibnieks.energija -= 20

class WiFiPauze(Skerslis):
    def iedarbojas(self, dalibnieks):
        dalibnieks.temps -= 3

d = Dalibnieks("Anna", 100, 10)
for s in [PrinteraRinda(), WiFiPauze()]:
    s.iedarbojas(d)
print(d.energija, d.temps)

Printera rinda atņem 20 enerģijas, Wi-Fi pauze samazina tempu par 3. Viens cikls apstrādā abus šķēršļus. Atkārto: 14.6 — 2. uzdevums — Pievieno šķēršļus un polimorfismu ↗
