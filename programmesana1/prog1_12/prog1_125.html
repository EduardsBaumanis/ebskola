12.5 Izvietošana mākonī un drošība

Sasniedzamais rezultāts: Izvietot lietotni publiski un saprast pamata drošības principus produkcijas vidē.

SR 2.4.6. Plāno un dokumentē programmatūras izstrādes procesu. SR 3.1.1. Ievēro ergonomikas un darba drošības principus. SR 3.2.5. Analizē un mazina digitālās drošības riskus. SR 2.3.3. Izvērtē tehnoloģiju lomu un ietekmi dažādās dzīves jomās.

Teorija: No localhost uz internetu

Lokālā lietotne, kas darbojas uz localhost:5000, nav pieejama citiem. Lai pasaule to redzētu, jāizvieto mākonī.

Bezmaksas mākoņi (2026):

  • Render (render.com) - bezmaksas Python apps, viegls process.
  • Railway (railway.app) - bezmaksas $5 kredīts mēnesī.
  • Fly.io - bezmaksas mazām aplikācijām.
  • Vercel/Netlify - tikai statiskām lapām un serverless funkcijām.

Drošības pamati:

  • Vides mainīgie - paroles, API atslēgas NEKAD kodā. Lieto .env.
  • HTTPS - vienmēr produkcijā (Render to dod automātiski).
  • Validē visus ievadus - pārlūkā IR un servera pusē.
  • Lietotāja paroles - bcrypt hash, NEKAD plain text.
  • SQL injekcija - vienmēr parametrizēti vaicājumi.

from dotenv import load_dotenv

Praktiskie uzdevumi

1. uzdevums -

Izņem noslēpumus no koda

Beigās tavā kodā vairs nebūs nevienas paroles.

  1. Atrodi failā 125.py visas vietas, kur ierakstīta parole vai atslēga.
  2. Aizstāj katru ar os.environ.get("DATABASE_URL").
  3. Uzstādi bibliotēku, kas nolasa .env failu: VS Code terminālī izpildi pip install python-dotenv.
  4. Pievieno faila 125.py pašā augšā šīs trīs rindas. Tām jābūt pirms visām rindām, kurās ir os.environ.get: 
    import os
from dotenv import load_dotenv
load_dotenv()  # nolasa .env failu un ieliek vērtības vides mainīgajos
  5. Izveido tajā pašā mapē, kur atrodas 125.py, failu ar nosaukumu tieši .env un ieraksti tajā īstās vērtības. Katrā rindā ir NOSAUKUMS=vērtība, bez atstarpēm ap = un bez pēdiņām: 
    DATABASE_URL=postgresql://postgres:TAVA_PAROLE@localhost:5432/spele
SECRET_KEY=gars-nejauss-teksts
  6. Pārbaudi, ka vērtība tiek nolasīta: zem load_dotenv() uz brīdi pievieno print(os.environ.get("DATABASE_URL") is not None) un palaid 125.py. Jāizdrukājas True. Pēc tam šo rindu izdzēs.
  7. Pievieno .gitignore failam rindu .env.
  8. Izpildi git status un pārliecinies, ka .env tur nav.

Gatavs, kad: pārbaude izdrukāja True, git status nerāda .env, un kodā nav neviena ierakstīta paroles teksta.

2. uzdevums -

Sagatavo projektu izvietošanai

Beigās serveris varēs palaist tavu lietotni bez tavas palīdzības.

  1. Izpildi pip freeze > requirements.txt.
  2. Pievieno pip install gunicorn un atjauno requirements.txt.
  3. Nomaini app.run(debug=True) uz app.run(debug=False).
  4. Pieraksti, kāpēc debug=True publiskā serverī ir bīstams.
  5. Izveido failu Procfile ar rindu web: gunicorn 125:app (kur 125 ir faila 125.py nosaukums).
  6. Veic commit un push uz GitHub.

Gatavs, kad: krātuvē ir requirements.txt un Procfile, bet nav .env.

3. uzdevums -

Izvieto mākonī un pārbaudi

Beigās tava lietotne būs pieejama no jebkura datora.

  1. Izveido kontu vietnē render.com.
  2. Izvēlies New -> Web Service un pieslēdz savu GitHub krātuvi.
  3. Ievadi vides mainīgos Render sadaļā Environment.
  4. Palaid izvietošanu un vēro žurnālu, līdz parādās Live.
  5. Atver iegūto adresi telefonā, nevis savā datorā.
  6. Pārbaudi, ka API atgriež datus arī no turienes.
  7. Pieraksti vienu secinājumu: ar ko localhost atšķiras no publiskas adreses.

Gatavs, kad: lapa atveras telefonā pa mobilo internetu, nevis tikai tavā datorā.

Papildu uzdevums - Pievieno pieprasījumu ierobežojumu

Ja pamatdarbs ir gatavs, pasargā API no pārslodzes.

  1. Instalē pip install flask-limiter.
  2. Pievieno ierobežojumu, piemēram 30 pieprasījumi minūtē.
  3. Izsauc API ciklā vairāk reižu, nekā atļauts.
  4. Pieraksti, kāds statusa kods atnāca.
  5. Pieraksti, kāpēc šāds ierobežojums ir vajadzīgs.

Gatavs, kad: pārsniedzot ierobežojumu, serveris atgriež kodu 429, nevis apstājas.

Biežākās kļūdas

  • os.environ.get(...) lokāli atgriež None: Python pats .env failu nelasa. Pārbaudi, vai ir uzstādīts python-dotenv, vai load_dotenv() ir izsaukts pirms os.environ.get un vai fails saucas tieši .env (nevis .env.txt) un atrodas blakus 125.py.
  • ModuleNotFoundError: No module named 'dotenv': Izpildi pip install python-dotenv tajā pašā terminālī, kurā palaid 125.py. Bibliotēkas nosaukums ir python-dotenv, bet importē dotenv.
  • .env failā ielikts GitHub: Slepenās atslēgas tagad publiski. Atsauc tās un izveido jaunas. Nekad neielādē .env!
  • App nedarbojas mākonī, bet darbojās lokāli: Pārbaudi vides mainīgos un Python versiju (runtime.txt).
  • DB savienojuma kļūdas: Pārliecinies, ka DATABASE_URL izmanto SSL un pareizu psycopg2 sintakse (Render dod URL sākot ar postgres:// - pielāgo uz postgresql://).

Koda piemērs

# 125.py - produkcijai gatavs
import os
from dotenv import load_dotenv
from flask import Flask, jsonify, request
import psycopg2

load_dotenv()  # lokāli nolasa .env; mākonī faila nav, un vērtības dod Render

app = Flask(__name__)

DATABASE_URL = os.environ.get("DATABASE_URL")
SECRET_KEY = os.environ.get("SECRET_KEY", "dev-only-key")

def get_db():
    return psycopg2.connect(DATABASE_URL, sslmode="require")

@app.route("/api/rezultati")
def saraksts():
    with get_db() as conn, conn.cursor() as cur:
        cur.execute("SELECT vards, punkti FROM rezultati ORDER BY punkti DESC LIMIT 10")
        return jsonify([dict(zip(["vards","punkti"], r)) for r in cur.fetchall()])

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=int(os.environ.get("PORT", 5000)))
