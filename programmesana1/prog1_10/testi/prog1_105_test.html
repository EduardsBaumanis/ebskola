Atkārtojuma tests: 10.4 Testēšana ar unittest

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Ko pārbauda self.assertEqual(a, b)?

assertEqual salīdzina funkcijas atbildi ar gaidīto vērtību. Ja tās atšķiras, rindā AssertionError redzi abas, piemēram None != 'X'. Atkārto: 10.4 — Teorija: akceptēšanas kritērijs kļūst par testu ↗

2. Testu palaižot, terminālī ir Ran 0 tests un NO TESTS RAN. Kas visticamāk nav pareizi?

unittest par testiem uzskata tikai klases funkcijas, kuru nosaukums sākas ar test_, piemēram test_x_augseja_rinda. Atkārto: 10.4 — 1. uzdevums — Uzraksti uzvarētāja funkciju un pirmo testu ↗

3. Ar ko beidzas šī testa izvade terminālī? 
import unittest


def dubulto(x):
    return x + 2


class TestDubulto(unittest.TestCase):

    def test_tris(self):
        self.assertEqual(dubulto(3), 6)


unittest.main()

Funkcija pieskaita 2, nevis reizina ar 2, tāpēc dubulto(3) ir 5. Tests to atklāj: AssertionError: 5 != 6 un beigās FAILED (failures=1). Atkārto: 10.4 — 3. uzdevums — Salauz funkciju un pievieno savu testu ↗

4. Palaižot test_104.py, parādās ModuleNotFoundError: No module named 'spele_104'. Kāpēc?

Rinda from spele_104 import uzvaretajs meklē failu spele_104.py blakus testam. Abiem jābūt mapē tema10. Atkārto: 10.4 — 1. uzdevums — Uzraksti uzvarētāja funkciju un pirmo testu ↗

5. Kritērijs: „Ja laukums ir tukšs, uzvarētāja nav.” Kura rinda to pārbauda pareizi?

Funkcija atgriež None bez pēdiņām. Ar "None" pēdiņās tests salīdzinātu ar tekstu un neizdotos; print neko nepārbauda. Atkārto: 10.4 — 2. uzdevums — Pārvērs kritērijus testos ↗
