Atkārtojuma tests: 10.2 SQL CRUD: SELECT, INSERT, UPDATE, DELETE

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kurai SQL komandai atbilst burts U vārdā CRUD?

Create — INSERT, Read — SELECT, Update — UPDATE, Delete — DELETE. Atkārto: 10.2 — Teorija: CRUD — datu pārvaldības četri stūrakmeņi ↗

2. Tabulā speletaji ir Anna (120), Jānis (95), Eva (145) un Pēteris (40). Kādus vārdus un kādā secībā atgriež šis vaicājums? 
SELECT vards FROM speletaji
WHERE punkti > 100
ORDER BY punkti DESC;

WHERE atstāj tikai tos, kam vairāk par 100 (Anna un Eva), bet ORDER BY … DESC sakārto no lielākā. Atkārto: 10.2 — 2. uzdevums — Filtrē un kārto ar SELECT ↗

3. Ko dara LIMIT 3 vaicājuma beigās?

LIMIT ierobežo rindu skaitu. Kopā ar ORDER BY punkti DESC tas dod TOP 3. Atkārto: 10.2 — 2. uzdevums — Filtrē un kārto ar SELECT ↗

4. Kas notiek pēc komandas UPDATE speletaji SET punkti = 0;?

Bez WHERE UPDATE maina visas rindas. Tāpēc tam vienmēr vajag WHERE, piemēram WHERE vards = 'Anna'. Atkārto: 10.2 — Teorija: CRUD — datu pārvaldības četri stūrakmeņi ↗

5. Kāpēc pirms DELETE … WHERE punkti < 50 izpilda SELECT … WHERE punkti < 50?

Ja SELECT parāda nepareizas rindas, tu to pamani, pirms tās ir neatgriezeniski izdzēstas. Atkārto: 10.2 — 3. uzdevums — Droši lieto UPDATE un DELETE ↗
