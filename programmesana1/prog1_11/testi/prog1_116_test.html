Atkārtojuma tests: 11.5 Polimorfisms un dunder metodes

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kas ir polimorfisms?

Visām klasēm ir metode runa(), bet katra izdrukā savu tekstu. Atkārto: 11.5 — Teorija: Polimorfisms un dunder (__metode__) ↗

2. Ko izdrukā šis kods? 
class Dalibnieks:
    def runa(self):
        print("Runā vispārīgi.")

class Prezentetajs(Dalibnieks):
    def runa(self):
        print("Slaids ir gatavs!")

class Kapteinis(Dalibnieks):
    pass

for d in [Prezentetajs(), Kapteinis()]:
    d.runa()

Prezentētājam ir sava runa(). Kapteinis savu nav uzrakstījis, tāpēc izmanto mantoto vecāku versiju. Atkārto: 11.5 — 2. uzdevums — Izsauc tās vienā ciklā ↗

3. Kāpēc ciklā for d in dalibnieki: d.runa() nav vajadzīgs if pēc klases nosaukuma?

Pievienojot jaunu lomu ar savu runa(), cikls strādā bez izmaiņām. Atkārto: 11.5 — 2. uzdevums — Izsauc tās vienā ciklā ↗

4. Ko izdrukā šis kods? 
class Dalibnieks:
    def __init__(self, vards, energija):
        self.vards = vards
        self.energija = energija

    def __str__(self):
        return f"{self.vards}: {self.energija}"

d = Dalibnieks("Anna", 100)
print(d)

print() izsauc objekta __str__ metodi. Bez tās redzētu tehnisku tekstu ar atmiņas adresi. Atkārto: 11.5 — 3. uzdevums — Pievieno __str__ un __repr__ ↗

5. Klasei ir abas metodes. Ko izdrukā print([d])? 
class Dalibnieks:
    def __init__(self, vards):
        self.vards = vards

    def __str__(self):
        return self.vards

    def __repr__(self):
        return f"Dalibnieks('{self.vards}')"

d = Dalibnieks("Anna")
print([d])

Izdrukājot sarakstu, Python katram elementam izmanto __repr__. print(d) izmantotu __str__ un izdrukātu Anna. Atkārto: 11.5 — 3. uzdevums — Pievieno __str__ un __repr__ ↗
