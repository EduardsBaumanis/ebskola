Atkārtojuma tests: 11.1 Klases un objekti

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Ar ko klase atšķiras no objekta?

No vienas klases (cepuma formas) var izveidot daudz objektu (cepumu), un katram var būt savas vērtības. Atkārto: 11.1 — Teorija: Klase = veidne, objekts = eksemplārs ↗

2. Ko izdrukā šis kods? 
class Speletajs:
    pass

speletajs1 = Speletajs()
speletajs2 = Speletajs()
print(speletajs1 == speletajs2)

Tie ir divi atsevišķi objekti dažādās atmiņas vietās, tāpēc tie nav vienādi, lai gan izveidoti vienādi. Atkārto: 11.1 — 1. uzdevums — Izveido pirmo klasi un divus objektus ↗

3. Ko izdrukā šis kods? 
class Speletajs:
    pass

speletajs1 = Speletajs()
speletajs2 = Speletajs()
speletajs1.energija = 100
speletajs2.energija = 80
speletajs1.energija = 50
print(speletajs2.energija)

Katram objektam ir savi atribūti. Mainot pirmā objekta enerģiju, otrā paliek nemainīga. Atkārto: 11.1 — 2. uzdevums — Pievieno atribūtus katram objektam ↗

4. Ko izdrukā šis kods? 
class Speletajs:
    maks_energija = 100

speletajs1 = Speletajs()
speletajs2 = Speletajs()
Speletajs.maks_energija = 120
print(speletajs1.maks_energija, speletajs2.maks_energija)

maks_energija ir klases atribūts — kopīgs visiem objektiem. Mainot to klasē, tas mainās abiem. Atkārto: 11.1 — 3. uzdevums — Salīdzini klases un objekta atribūtus ↗

5. Turpinot iepriekšējo kodu, izpilda speletajs1.maks_energija = 200. Ko tagad izdrukā print(speletajs1.maks_energija, speletajs2.maks_energija)?

Piešķirot vērtību caur objektu, tam izveidojas savs atribūts, kas aizsedz klases atribūtu. Otrais objekts joprojām redz klases vērtību 120. Atkārto: 11.1 — 3. uzdevums — Salīdzini klases un objekta atribūtus ↗
