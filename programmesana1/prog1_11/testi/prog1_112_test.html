Atkārtojuma tests: 11.1 Ārējās bibliotēkas un instalēšana

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kas ir bibliotēka Python valodā?

Bibliotēku uzstāda ar pip install un izmanto ar import. Publiskās bibliotēkas glabājas vietnē PyPI. Atkārto: 11.1 — Teorija: pip un virtual environment ↗

2. Ar kuru komandu Windows terminālī aktivizē virtuālo vidi?

Windows datorā aktivizēšanas skripts ir mapē venv\Scripts. Atkārto: 11.1 — 1. uzdevums — Izveido virtuālo vidi un instalē bibliotēku ↗

3. Kā redzi, ka virtuālā vide ir aktīva?

Kamēr rindas sākumā ir (venv), pip install uzstāda bibliotēkas projekta vidē, nevis visā datorā. Atkārto: 11.1 — 1. uzdevums — Izveido virtuālo vidi un instalē bibliotēku ↗

4. Kāpēc mapi venv/ ieraksta failā .gitignore?

Krātuvē liek tikai requirements.txt — bibliotēku sarakstu. Katrs pēc tā uzbūvē savu vidi pats. Atkārto: 11.1 — 3. uzdevums — Saglabā atkarības requirements.txt ↗

5. Ko dara komanda pip freeze > requirements.txt?

pip freeze izdrukā bibliotēkas ar versijām, un > ieraksta to failā. Uzstāda no faila pip install -r requirements.txt. Atkārto: 11.1 — 3. uzdevums — Saglabā atkarības requirements.txt ↗
