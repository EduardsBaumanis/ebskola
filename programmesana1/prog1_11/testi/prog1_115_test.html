Atkārtojuma tests: 11.4 HTML un Python sasaiste

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Ko dara unsafe_allow_html=True funkcijā st.markdown()?

Bez šī parametra Streamlit tavus HTML tagus neizpilda. Ar to <h1 style='…'> kļūst par īstu krāsainu virsrakstu. Atkārto: 11.4 — Teorija: HTML/CSS Streamlit kontekstā ↗

2. Kāpēc parametrs saucas unsafe (nedrošs)?

Savu HTML ielikt drīkst. Bīstami ir ielikt tekstu, ko ievadījis kāds cits, jo tajā var būt skripts. Atkārto: 11.4 — Teorija: HTML/CSS Streamlit kontekstā ↗

3. Ko nozīmē col1, col2 = st.columns([2, 1])?

Saraksts [2, 1] nosaka platumu attiecību: pirmā kolonna aizņem divas daļas, otrā — vienu. Atkārto: 11.4 — 3. uzdevums — Saliec divu kolonnu izkārtojumu ↗

4. Kur ieraksta CSS stilu kartiņām Streamlit lapā?

Stils attiecas uz visu lapu, tāpēc to pietiek ielikt vienreiz. Kartiņas pēc tam izmanto klasi .metric-card. Atkārto: 11.4 — 2. uzdevums — Uzraksti CSS kartiņu stilu ↗

5. Kā ieliek kartiņu pirmajā kolonnā?

Viss, kas rakstīts ar atkāpi zem with col1:, parādās pirmajā kolonnā. Atkārto: 11.4 — 3. uzdevums — Saliec divu kolonnu izkārtojumu ↗
