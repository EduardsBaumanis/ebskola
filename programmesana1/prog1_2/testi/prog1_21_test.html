Atkārtojuma tests: 1.6 Noslēguma pārbaudes darbs — Darba vide un kodu pārvaldība

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Failā .gitignore ir rinda 16_piezimes.txt, bet GitHub Desktop šo failu joprojām rāda. Ko pārbaudi vispirms?

.gitignore darbojas uz visu projektu tikai tad, ja tas ir saknē, un nosaukumam tajā jāsakrīt burtu pa burtam ar faila nosaukumu. Atkārto: 1.6 — 1. uzdevums — Izveido projekta struktūru un .gitignore ↗

2. Kāda saite jāiesniedz skolotājam?

Skolotājs var atvērt tikai saiti, kas sākas ar https://github.com/. Adrese C:\... ved uz mapi tavā datorā, un citi to atvērt nevar. Atkārto: 1.6 — 3. uzdevums — Publicē GitHub un pārbaudi pēc kritērijiem ↗

3. README failā ir komanda python pd1/kods/16.py. No kuras mapes terminālī tā jāizpilda?

Relatīvais ceļš tiek skaitīts no mapes, kurā ir terminālis. No krātuves saknes ceļš pd1/kods/16.py ved tieši līdz failam. Atkārto: 1.6 — 2. uzdevums — Uzraksti programmu un README ↗

4. GitHub lapā tavs pd1/README.md izskatās kā parasts teksts bez virsrakstiem. Kas visticamāk nav pareizi?

GitHub formatē tikai .md failus, un virsrakstam aiz # vajag atstarpi: # PD1 darba vide. Atkārto: 1.6 — 3. uzdevums — Publicē GitHub un pārbaudi pēc kritērijiem ↗

5. Kādā secībā pabeidz darbu, lai skolotājs to redzētu GitHub?

Commit saglabā versiju datorā, Push to nosūta uz GitHub. Pirms saites iesniegšanas atver krātuvi pārlūkā un pārliecinies, ka viss tur ir. Atkārto: 1.6 — 3. uzdevums — Publicē GitHub un pārbaudi pēc kritērijiem ↗
