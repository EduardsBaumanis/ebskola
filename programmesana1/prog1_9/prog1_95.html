9.5 Attēli, skaņa un video lietotnei

Sasniedzamais rezultāts: Šajā stundā tu sagatavosi attēlus ar Python programmu, apstrādāsi skaņu un samontēsi īsu video, kas parāda tavu lietotni.

SR 2.2.3. Attēli, audio un video (vispārīgais līmenis)

Teorija: cik liels ir fails un kāpēc

Sākt testu →

Rastra attēls sastāv no pikseļiem (krāsainiem punktiem), piemēram, foto vai ekrānuzņēmums. Ja to palielina, tas kļūst izplūdis. Vektorattēls sastāv no formām (līnijām, apļiem, tekstiem), tāpēc to var palielināt bez zuduma. 9.4 stundas piemēri bija vektorattēli SVG formātā.

Izšķirtspēja ir pikseļu skaits platumā un augstumā, piemēram, 2400×1600. Katram pikselim vajag 3 baitus (sarkanais, zaļais, zilais), tāpēc bez saspiešanas tāds attēls aizņemtu 2400 × 1600 × 3 = 11 520 000 baitu, aptuveni 11 MB. Formāti attēlu saspiež:

FormātsSaspiešanaDer
PNGbez zudumiem; caurspīdīgumsekrānuzņēmumi, zīmējumi ar vienkrāsainiem laukumiem
JPGar zudumiem (izmet sīkumus, ko acs nepamana); bez caurspīdīgumafoto
WebPabi veidi; caurspīdīgumstīmeklim: bieži mazāks par abiem, bet ne vienmēr (to pārbaudīsi papildu uzdevumā)
SVGvektors, tekstsikonas, logo, diagrammas

Tīmekļa lapā attēlam reti vajag vairāk nekā 800–1200 pikseļu platumu. Foto no telefona (4000 pikseļu un vairāki MB) pirms ielikšanas lapā samazina, citādi lapa ielādējas lēni.

Skaņa. Mikrofons mēra skaņas spiedienu daudzas reizes sekundē. Šo biežumu sauc par iztveršanas frekvenci (sample rate): 44 100 Hz nozīmē 44 100 mērījumu sekundē. Balsij pietiek ar vienu kanālu (mono). 10 sekundes mono ieraksta bez saspiešanas (WAV) ir ap 860 KB, bet MP3 formātā ap 160 KB. Normalizēšana pastiprina ierakstu tā, ka skaļākā vieta ir tieši zem maksimuma, piemēram, −1 dB: klusa balss kļūst skaidri dzirdama, bet nesāk krakšķēt.

Video ir daudz attēlu sekundē ar skaņu. Tīmekļa demonstrācijai pietiek ar 1280×720 (720p) un 30–60 sekundēm. Pat tad MP4 fails viegli sasniedz vairākus desmitus MB. Tāpēc video nekomitē Git krātuvē: Git saglabā katru faila versiju uz visiem laikiem, un krātuve kļūst smaga. Video augšupielādē, piemēram, Google Drive, un krātuvē ieliek saiti.

Svešs saturs. Attēlam, mūzikai vai video, ko neesi radījis pats, pēc noklusējuma ir autortiesības: tos drīkst lietot tikai ar atļauju. Creative Commons licences atļauj lietot ar nosacījumiem: CC0 - bez nosacījumiem, CC BY - norādi autoru, CC BY-SA - norādi autoru un dalies ar tādu pašu licenci, NC - tikai nekomerciāli. Tādu saturu var meklēt, piemēram, Wikimedia Commons vai Openverse. Programmatūras licences apgūsi 11.2 stundā.

Attēlus Python apstrādā ar bibliotēku Pillow (PIL). Tā nav standarta bibliotēkā, tāpēc 1. uzdevumā to uzstādīsi ar pip.

Pašpārbaude: tev ir ekrānuzņēmums ar tekstu un foto no ekskursijas. Kādu formātu katram izvēlēsies?

Ekrānuzņēmumam PNG vai WebP: tajā ir lieli vienkrāsaini laukumi un ass teksts, ko JPG izplūdina. Foto - JPG vai WebP: tajā ir tūkstošiem krāsu, un PNG fails būtu ļoti liels.

1. uzdevums -

Uzstādi Pillow un izveido sīktēlu

Beigās tava programma uzzīmēs attēlu, nolasīs tā izmēru un režīmu un izveidos no tā mazu kopiju (sīktēlu).

  1. Uzstādi Pillow: VS Code augšējā izvēlnē izvēlies Terminal → New Terminal. Apakšā atvērtajā terminālī ieraksti šo rindu un nospied Enter: 
    python -m pip install pillow

    Pēc brīža pēdējā rindā jābūt Successfully installed pillow-… (versijas numurs var būt cits). python -m pip uzstāda bibliotēku tieši tam Python, ar kuru palaid savas programmas.

  2. Izveido failu tema09/pillow_95.py un ieraksti:

Iestrēgi?
  • 1. solis: 'python' is not recognized vai atveras Microsoft Store. Python nav uzstādīts vai VS Code to neredz. Pārbaudi to, kā 1.1 stundā, un aizver un atver VS Code no jauna.
  • 1. solis: WARNING: … is not on PATH - to var neņemt vērā, ja pēdējā rindā ir Successfully installed.
  • 1. solis: Requirement already satisfied - Pillow jau ir uzstādīts. Turpini ar 2. soli.
  • 3. solis: ModuleNotFoundError: No module named 'PIL' - Pillow ir uzstādīts citam Python. VS Code apakšējā labajā stūrī noklikšķini uz Python versijas un izvēlies to, kas ir no Microsoft Store, vai atkārto 1. soli tieši VS Code terminālī.
  • 6. solis: nezini, kāpēc fails ir tik mazs. Paskaties uz attēlu: tajā ir tikai divas krāsas un lieli vienādi laukumi. PNG to saglabā kā "nākamie 500 pikseļi ir zili", nevis katru pikseli atsevišķi.

Uzraksti attēlu sagatavotāju atteli_95.py

Beigās programma visus attēlus no mapes atteli_ievade samazinās līdz 800 pikseļu platumam, pievienos tavu vārdu kā ūdenszīmi un saglabās WebP kopijas mapē atteli_gatavi.

  1. Izveido failu tema09/atteli_95.py un ieraksti tā sākumu. Rindā UZRAKSTS ieraksti savu vārdu un uzvārda pirmo burtu: 
    from pathlib import Path
from PIL import Image, ImageDraw

MAPE = Path(__file__).parent
IEVADE = MAPE / "atteli_ievade"
IZVADE = MAPE / "atteli_gatavi"
MAX_PLATUMS = 800
UZRAKSTS = "© Anna B. 2026"
  2. Pievieno prakses attēlu veidotāju (divas tukšas rindas virs tā): 
    def izveido_prakses_attelus():
    IEVADE.mkdir()
    for nosaukums, izmers in [("ainava.jpg", (2400, 1600)), ("ekrans.png", (1920, 1080))]:
        troksnis = Image.effect_noise(izmers, 60).convert("RGB")

Iestrēgi?
  • 3. solis, vietas ___: / platums, (MAX_PLATUMS, jaunais_augstums), fails.stem un quality=80.
  • TypeError: … got an unexpected keyword argument 'font_size' - Pillow ir vecs. Terminālī izpildi python -m pip install --upgrade pillow un palaid vēlreiz.
  • FileNotFoundError pie save - mapes atteli_gatavi nav. Pārbaudi, vai rinda IZVADE.mkdir(exist_ok=True) ir pirms cikla for.
  • Attēls ir saspiests vai izstiepts. Formulā jādala ar platums, nevis augstums. 2400×1600 attēlam jāsanāk 800×533.
  • Gribi sākt no jauna. Izdzēs abas mapes atteli_ievade un atteli_gatavi (peles labā poga → Delete) un palaid. Programma tās izveidos no jauna.
  • VS Code neparāda .webp attēlu. Ar peles labo pogu izvēlies Reveal in File Explorer un atver to ar dubultklikšķi.

        troksnis = Image.effect_noise(izmers, 60).convert("RGB")
        krasa = Image.new("RGB", izmers, "#2b8a3e")
        Image.blend(krasa, troksnis, 0.4).save(IEVADE / nosaukums)
    print("Izveidoju prakses mapi ar 2 attēliem.")


def apstradat(fails):
    try:
        attels = Image.open(fails)
    except UnidentifiedImageError:
        print(f"Izlaižu {fails.name}: tas nav attēls")
        return
    platums, augstums = attels.size
    if platums > MAX_PLATUMS:
        jaunais_augstums = round(augstums * MAX_PLATUMS / platums)
        attels = attels.resize((MAX_PLATUMS, jaunais_augstums))
    zimulis = ImageDraw.Draw(attels)
    zimulis.text((10, attels.height - 30), UZRAKSTS, fill="white", font_size=20)
    jauns = IZVADE / (fails.stem + ".webp")
    attels.save(jauns, quality=80)
    pirms = fails.stat().st_size // 1024
    pec = jauns.stat().st_size // 1024
    print(f"{fails.name}: {platums}x{augstums}, {pirms} KB -> {jauns.name}: {attels.width}x{attels.height}, {pec} KB")


if not IEVADE.exists():
    izveido_prakses_attelus()
IZVADE.mkdir(exist_ok=True)
for fails in sorted(IEVADE.iterdir()):
    apstradat(fails)
