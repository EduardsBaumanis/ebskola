Kontrasta skaitlis

Tīmekļa pieejamības vadlīnijas WCAG kontrastu mēra no 1:1 (vienāda krāsa) līdz 21:1 (melns uz balta). Krāsu tīmeklī raksta kā hex kodu, piemēram, #ff8000: trīs pāri sešpadsmitnieku sistēmā sarkanajam, zaļajam un zilajam, katrs no 00 (0) līdz ff (255). Kontrastu aprēķina tā:

1. Katru kanālu (R, G, B) pārvērš no 0–255 uz 0–1:   c = v / 255
2. Pārrēķina, kā to uztver acs:   ja c ≤ 0.04045, tad c / 12.92, citādi ((c + 0.055) / 1.055) ** 2.4
3. Relatīvais gaišums:   L = 0.2126 × R + 0.7152 × G + 0.0722 × B
4. Kontrasts:   (L_gaišākā + 0.05) / (L_tumšākā + 0.05)

Zaļajam ir lielākais svars (0.7152), jo acs to uztver visjutīgāk. Līmenis AA, ko prasa lielākā daļa vadlīniju:

parasts teksts4.5:1
liels teksts: aptuveni 24 pikseļi vai 19 pikseļi trekns3:1

2. uzdevums -

Uzraksti kontrasta kalkulatoru kontrasts_94.py

Beigās tava programma divām hex krāsām aprēķinās WCAG kontrastu un pateiks, vai teksts sasniedz AA līmeni.

  1. Izveido failu: mapē tema09 izveido failu kontrasts_94.py.
  2. Pārvērš hex krāsu skaitļos: ieraksti šo funkciju un uz brīdi zem tās rindu print(hex_uz_rgb("#ff8000")): 
    def hex_uz_rgb(krasa):
    krasa = krasa.lstrip("#")
    return int(krasa[0:2], 16), int(krasa[2:4], 16), int(krasa[4:6], 16)

    lstrip("#") noņem # sākumā. int("ff", 16) nolasa tekstu kā sešpadsmitnieku skaitli: "ff" ir 255, "80" ir 128. Palaid: terminālī jāparādās (255, 128, 0). Tad izdzēs print rindu.

  3. Pievieno gaišuma aprēķinu (divas tukšas rindas starp funkcijām) un aizpildi divas vietas ___ ar skaitļiem no teorijas formulas: 
    def kanals(vertiba):
    c = vertiba / 255
    if c <= 0.04045:
        return c / ___
    return ((c + 0.055) / 1.055) ** 2.4


def gaisums(krasa):
    r, g, b = hex_uz_rgb(krasa)
    return 0.2126 * kanals(r) + ___ * kanals(g) + 0.0722 * kanals(b)
  4. Pievieno kontrasta aprēķinu un aizpildi divas vietas ___: 
    def kontrasts(krasa1, krasa2):
    l1 = gaisums(krasa1)
    l2 = gaisums(krasa2)
    if l1 < l2:
        l1, l2 = l2, l1
    return (l1 + ___) / (l2 + ___)

    Rinda l1, l2 = l2, l1 samaina abus mainīgos vietām, lai l1 vienmēr būtu gaišākā krāsa.

  5. Pievieno vērtējumu un pārbaudes faila beigās un saglabā: 
    def vertet(teksts, fons, liels=False):
    k = kontrasts(teksts, fons)
    robeza = 4.5
    if liels:
        robeza = 3
    if k >= robeza:
        return f"{k:.2f}:1 - der (AA)"
    return f"{k:.2f}:1 - nepietiek, vajag vismaz {robeza}:1"


print("#777777 uz balta:", vertet("#777777", "#ffffff"))
print("#767676 uz balta:", vertet("#767676", "#ffffff"))
print("balts uz #0055aa:", vertet("#ffffff", "#0055aa"))

    liels=False nozīmē: ja trešo argumentu neiedod, teksts nav liels un robeža ir 4.5.

  6. Palaid programmu ar Run pogu. Terminālī jāparādās: 
    #777777 uz balta: 4.48:1 - nepietiek, vajag vismaz 4.5:1
#767676 uz balta: 4.54:1 - der (AA)
balts uz #0055aa: 7.29:1 - der (AA)

    Pelēkie #777777 un #767676 acij izskatās vienādi, bet viens nedaudz nesasniedz robežu. Tāpēc kontrastu mēra, nevis novērtē ar aci.

Gatavs, kad: terminālī ir tieši 6. soļa trīs rindas.

Iestrēgi?
  • 3.–4. solis, vietas ___: c / 12.92, 0.7152 * kanals(g) un (l1 + 0.05) / (l2 + 0.05).
  • ValueError: invalid literal for int() with base 16 - krāsā ir burts, kas nav 0–9 vai a–f, piemēram, o nulles vietā. Pārbaudi krāsas kodu.
  • Tev sanāk 0.22 vai cits skaitlis zem 1. Kontrasta formulā gaišākajai krāsai jābūt augšā. Pārbaudi rindu if l1 < l2: un samainīšanu.
  • Tev sanāk 4.47 vai 4.49, nevis 4.48. Pārbaudi skaitļus formulā: 0.04045, 12.92, 0.055, 1.055, 2.4 un trīs svarus.
  • TypeError: unsupported operand type(s) for /: 'str' and 'int' - funkcijai kanals tika iedots teksts. Pārbaudi, vai hex_uz_rgb atgriež int(…, 16), nevis tikai krasa[0:2].

    fons = "#fdf6e3"
for v in range(255, -1, -1):
