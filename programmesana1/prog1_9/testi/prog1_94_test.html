Atkārtojuma tests: 9.3 Python pārvēršana tīmekļa saskarnē

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kā palaiž Streamlit lietotni no faila 93.py?

Streamlit lietotni palaiž ar streamlit run. Terminālis izdrukā adresi, kuru atver pārlūkā. Atkārto: 9.3 — Teorija: Streamlit — Python kā web saskarne ↗

2. Ko dara vards = st.text_input("Tavs vārds:")?

Streamlit ievades elementi atgriež vērtību, ko lietotājs ievadīja lapā — tāpat kā input(), tikai pārlūkā. Atkārto: 9.3 — Teorija: Streamlit — Python kā web saskarne ↗

3. Kad izpildās kods zem if st.button("Apstiprināt"):?

st.button() ir True tikai tajā reizē, kad poga ir nospiesta. Atkārto: 9.3 — 2. uzdevums — Pievieno ievades elementus un pogu ↗

4. Lietotājs nospiež pogu ar tukšu vārda lauku. Ko viņš redz? 
vards = st.text_input("Tavs vārds:")
if st.button("Apstiprināt"):
    if vards == "":
        st.warning("Ieraksti vārdu!")
    else:
        st.write(f"Sveiks, {vards}!")

Tukšs lauks atgriež "", tāpēc izpildās pirmais zars. Atkārto: 9.3 — 2. uzdevums — Pievieno ievades elementus un pogu ↗

5. Tu pārcēli skaitļu minētāju uz Streamlit, un slepenais skaitlis mainās pēc katra klikšķa. Kāpēc?

Streamlit katrā darbībā izpilda failu no augšas līdz apakšai. Tāpēc while cikls te neder, un vērtības, kam jāpaliek, glabā st.session_state (9.5 stundā). Atkārto: 9.3 — 3. uzdevums — Pārcel savu Python spēli uz saskarni ↗
