9.1 Dzīves cikls un izstrādes modeļi

# Dzīves cikls: specificēšana -> projektēšana -> izstrāde -> testēšana -> uzturēšana
# Ūdenskritums  posmi pēc kārtas vienu reizi        der, ja prasības nemainās
# V-modelis     katram posmam savs testēšanas līmenis  der, ja kļūda ir dārga
# Pakāpeniskā   pa daļām, katra gatava līdz galam    der, ja kaut ko vajag drīz
# Iteratīvā     viss vienkārši, tad uzlabo kārtās    der, ja prasības mainās

labakais = ""
labakie_punkti = -1
vienadi = []
for nosaukums, punkti in [("Ūdenskritums", 2), ("V-modelis", 2), ("Iteratīvā izstrāde", 1)]:
    if punkti > labakie_punkti:
        labakais = nosaukums
        labakie_punkti = punkti
        vienadi = [nosaukums]
    elif punkti == labakie_punkti:
        vienadi.append(nosaukums)          # neizvēlas klusi vienu no vienādiem
print(labakais, vienadi)                   # Ūdenskritums ['Ūdenskritums', 'V-modelis']

Specificēšana saka, ko programma darīs; projektēšana - kā to uzbūvēs. Testēšana notiek pirms izlaišanas, uzturēšana - pēc.

9.2 Lomas un prasmju normalizēšana

# Projektu vadītājs · dizainers (UX/UI) · izstrādātājs (front-end, back-end)
# testētājs · DevOps · datu analītiķis · drošības speciālists

SINONIMI = {"english": "angļu valoda", "js": "javascript"}


def normalizet(prasme):
    prasme = prasme.strip().lower()            # " Python 3 " -> "python 3"
    if prasme.startswith("python"):
        prasme = "python"
    return SINONIMI.get(prasme, prasme)        # ja nav vārdnīcā, paliek pati


skaits = {}
for prasme in "Python;SQL;python;Python 3;English;angļu valoda;;JS".split(";"):
    prasme = normalizet(prasme)
    if prasme == "":
        continue
    if prasme not in skaits:
        skaits[prasme] = 0
    skaits[prasme] += 1
print(sorted(skaits.items(), key=lambda x: x[1], reverse=True))
# [('python', 3), ('angļu valoda', 2), ('sql', 1), ('javascript', 1)]

Pirms skaitīšanas vienu nozīmi pārvērš vienā rakstībā, citādi "Python" un "python" ir divas dažādas prasmes.

9.3 Svērtais vērtējums

# Kritēriji: funkcijas · tehnoloģija · bezsaiste · cena (freemium?) · pieejamība · privātums
KRITERIJI = {"funkcijas": 0.3, "pieejamība": 0.2, "bezsaiste": 0.2, "cena": 0.2, "privātums": 0.1}
vertejumi = {"funkcijas": 4, "pieejamība": 3, "bezsaiste": 5, "cena": 3, "privātums": 4}

kopa = sum(KRITERIJI.values())
print(kopa)                                # 0.9999999999999999 - daļskaitļi ir aptuveni
if round(kopa, 2) != 1:                    # tāpēc salīdzina noapaļotu
    print("Svari kopā nav 1")

summa = 0
for kriterijs, svars in KRITERIJI.items():
    summa += svars * vertejumi[kriterijs]  # svērtā summa
print(f"{summa:.2f} no 5")                 # 3.80 no 5

Vērtējumi ir par lietotni, svari - par lietotāju. Nomaini svarus, un uzvarētājs var mainīties.

9.4 Dizaina principi un WCAG kontrasts

# Hierarhija · Kontrasts · Izlīdzinājums · Tuvums · Atkārtojums
# WCAG AA: parasts teksts 4.5:1, liels teksts 3:1 (diapazons 1:1 ... 21:1)

def kanals(vertiba):
    c = vertiba / 255
    if c <= 0.04045:
        return c / 12.92
    return ((c + 0.055) / 1.055) ** 2.4


def gaisums(krasa):
    krasa = krasa.lstrip("#")              # "#ff8000" -> 255, 128, 0
    r, g, b = int(krasa[0:2], 16), int(krasa[2:4], 16), int(krasa[4:6], 16)
    return 0.2126 * kanals(r) + 0.7152 * kanals(g) + 0.0722 * kanals(b)


def kontrasts(krasa1, krasa2):
    l1 = gaisums(krasa1)
    l2 = gaisums(krasa2)
    if l1 < l2:
        l1, l2 = l2, l1                    # gaišākā vienmēr augšā
    return (l1 + 0.05) / (l2 + 0.05)


print(f"{kontrasts('#777777', '#ffffff'):.2f}")   # 4.48 - nepietiek
print(f"{kontrasts('#767676', '#ffffff'):.2f}")   # 4.54 - der

Plakātu lasa ejot, dažās sekundēs: tajā paliek tikai kas, kad, kur. Tīmekļa lapā var būt viss pārējais.

9.6 Noslēguma projekts: testi un analīze

# Tests: nolasi uzdevumu -> hronometrs -> nepalīdzi -> maks. 120 s -> pieraksti problēmu
# Pusei lietotāju sāc ar B. 3 lietotāji x 2 uzdevumi x 2 varianti = 12 rindas.

rindas = [                                 # tā izskatās list(csv.DictReader(f))
    {"variants": "A", "uzdevums": "pievienot", "laiks_s": "48"},
    {"variants": "A", "uzdevums": "pievienot", "laiks_s": "55"},
    {"variants": "B", "uzdevums": "pievienot", "laiks_s": "22"},
    {"variants": "B", "uzdevums": "pievienot", "laiks_s": "30"},
]
laiki = {}
for r in rindas:
    atslega = r["variants"] + ", " + r["uzdevums"]
    if atslega not in laiki:
        laiki[atslega] = []
    laiki[atslega].append(int(r["laiks_s"]))
for atslega, saraksts in sorted(laiki.items()):
    print(f"{atslega}: {sum(saraksts) / len(saraksts):.1f} s")
# A, pievienot: 51.5 s
# B, pievienot: 26.0 s

Katrai izmaiņai prototipā jābūt pamatotai ar skaitli vai problēmu no iepriekšējās iterācijas.
