Atkārtojuma tests: 4.2 Vērtību atgriešana (return)

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Ko izdrukā šis kods? 
def saskaiti_a(a, b):
    print(a + b)

rezultats_a = saskaiti_a(2, 3)
print(rezultats_a)

Funkcija izdrukā 5, bet neko neatgriež, tāpēc rezultats_a ir None. Lai vērtību saglabātu, vajag return a + b. Atkārto: 4.2 — 1. uzdevums — Salīdzini print un return ↗

2. Ko atgriež dabut_bonusu("banans")? 
def dabut_bonusu(tips):
    if tips == "markieris":
        return 15
    elif tips == "taimeris":
        return 10
    return 5

Neviens nosacījums neizpildās, tāpēc funkcija nonāk līdz pēdējai rindai return 5. Bez tās rezultāts būtu None. Atkārto: 4.2 — 2. uzdevums — Uzraksti bonusa funkciju ar return ↗

3. Cik ir kopa? Funkcija dabut_bonusu ir tāda pati kā iepriekšējā jautājumā. 
def gala_punkti(bazes, bonuss):
    return bazes + bonuss

kopa = gala_punkti(100, dabut_bonusu("markieris"))

Vispirms izpildās iekšējā funkcija un atgriež 15. Tad gala_punkti(100, 15) atgriež 115. Atkārto: 4.2 — 3. uzdevums — Saliec divas funkcijas kopā ↗

4. Ko izdrukā šis kods? 
def parbaude():
    return 1
    print("Sveiks")

print(parbaude())

return uzreiz beidz funkciju, tāpēc rinda aiz tā nekad neizpildās. Atkārto: 4.2 — 3. uzdevums — Saliec divas funkcijas kopā ↗

5. Ko izdrukā šis kods? 
def uzdevuma_dati():
    return "Kontroldarba bonuss", 100

nosaukums, punkti = uzdevuma_dati()
print(punkti)

Funkcija atgriež divas vērtības. Pirmā nonāk mainīgajā nosaukums, otrā — punkti. Atkārto: 4.2 — Teorija: Datu atgriešanas mehānisms ↗
