Atkārtojuma tests: 3.6 Noslēguma projekts: „Gudrais Akmens-Šķēres-Papīrīts”

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Ko dara rinda datora_gajiens = random.choice(varianti)?

random.choice() katru reizi izvēlas vienu nejaušu elementu no saraksta, tāpēc datora gājiens mainās. Rindas sākumā vajag import random. Atkārto: 3.6 — 1. uzdevums — Uzbūvē spēles kodolu ar random ↗

2. Spēlētājs ievada AKMENS ar atstarpēm. Ko iegūst " AKMENS ".lower().strip()?

lower() pārvērš burtus mazajos, strip() noņem atstarpes abās malās. Tad ievadi var salīdzināt ar sarakstu. Atkārto: 3.6 — Teorija: tiesnesis, cikls un validācija ↗

varianti = ["akmens", "skeres", "papirs"]
while True:
    gajiens = input("Izvēlies: ").lower().strip()
    if gajiens not in varianti:
        print("Nederīga izvēle.")

not in pārbauda, ka vārda nav sarakstā. Tad continue izlaiž pārējo raundu un sāk ciklu no jauna. Atkārto: 3.6 — 3. uzdevums — Pievieno ciklu, validāciju un iesniedz GitHub ↗

4. Spēlētājs izvēlas papirs, dators — akmens. Ko jāizdrukā tiesnesim?

Papīrs uzvar akmeni. Tiesneša nosacījumiem jāaptver visas trīs spēlētāja uzvaras; viss pārējais, kas nav neizšķirts, nonāk else zarā. Atkārto: 3.6 — 2. uzdevums — Pievieno tiesnesi ar if/elif/else ↗

5. Kāpēc visa spēle ir ielikta while True: ciklā?

while True atkārto raundus bez gala, bet break pie ievades stop no cikla iziet. Atkārto: 3.6 — 3. uzdevums — Pievieno ciklu, validāciju un iesniedz GitHub ↗
