5.4 Aptaujas izveide

Stundas uzdevums: Iekāpt spēlētāja kurpēs. Apgūsi, kā izmantot Google Forms, lai uzzinātu, ko Tavi lietotāji patiesībā vēlas redzēt spēlē. Iegūtos datus mēs vēlāk pārvērtīsim koda sarakstos un vārdnīcās, padarot Tavu spēli "datiem vadītu" (data-driven).

SR 2.3.4. (Aptauku veidošana) un SR 2.3.2. (Koplietošana)

70 min plāns: Teorija un paraugs (~10 min) · 1. uzdevums (~15 min) - uzraksti aptaujas jautājumus · 2. uzdevums (~25 min) - izveido aptauju digitālā rīkā · 3. uzdevums (~20 min) - savāc atbildes un ievieto tās Python struktūrās. Papildu uzdevumu sāc tikai tad, ja pārējie trīs ir gatavi.

Pirms sāc: atver pārlūkā Google Forms vai citu skolas izmantoto aptauju rīku, kā arī VS Code - datus pēc tam ievietosi kodā.

Teorija: UX un Datu analīzes pamati

Programmētāji neraksta kodu vakuumā. Mēs veidojam produktus citiem cilvēkiem. Izpratni par to, ko lietotājs vēlas, sauc par UX (User Experience) jeb lietotāja pieredzi.

Datu veidi, ko mēs ievāksim:

  • Kvantitatīvie dati (Skaitļi/Izvēles): Atbildes, kuras var saskaitīt un pārvērst procentos (piem., "60% izvēlējās zobenu"). Python kodā šie dati parasti pārtop par sarakstiem (List).
  • Kvalitatīvie dati (Teksts/Viedokļi): Brīvas teksta atbildes, kas sniedz jaunas idejas. Python kodā tie bieži kļūst par vārdnīcu (Dictionary) atslēgām vai vērtībām.
# Datu eksports no Google Forms uz Python
# 1. Forms → Atbildes → Skatīt izklājlapā
# 2. Lejupielādē kā CSV (File → Download → CSV)

import csv
with open("aptauja.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for rinda in reader:
        print(rinda["Vecums"], rinda["Vēlmes"])

Praktiskie uzdevumi

1. uzdevums -

Uzraksti aptaujas jautājumus

Beigās tev būs pieci jautājumi, no kuriem daļu var saskaitīt.

  1. Uzraksti README.md failā trīs jautājumus ar gatavām atbilžu izvēlēm.
  2. Uzraksti divus jautājumus ar brīvu teksta atbildi.
  3. Atzīmē katram jautājumam, vai tā atbilde ir skaitāma vai teksts.
  4. Pārbaudi, vai neviens jautājums nepasaka priekšā vēlamo atbildi.
  5. Iedod jautājumus klasesbiedram un palūdz atzīmēt neskaidros.
  6. Pārraksti vienu jautājumu pēc saņemtajām piezīmēm.

Gatavs, kad: tev ir 5 jautājumi, katram atzīmēts datu veids, un klasesbiedrs visus saprata.

2. uzdevums -

Izveido aptauju digitālā rīkā

Beigās tev būs saite, ko var nosūtīt klasesbiedriem.

  1. Atver aptauju rīku un izveido jaunu formu.
  2. Ieraksti formas nosaukumu un vienu teikumu, kāpēc tu vāc datus.
  3. Pievieno trīs izvēles jautājumus ar sagatavotajām atbildēm.
  4. Pievieno divus brīvā teksta jautājumus.
  5. Pārbaudi formu, aizpildot to pats vienu reizi.
  6. Nokopē koplietošanas saiti un nosūti to vismaz pieciem klasesbiedriem.

Gatavs, kad: forma atveras pēc saites, un tavā atbilžu tabulā ir vismaz viena atbilde.

3. uzdevums -

Savāc atbildes un ievieto tās Python struktūrās

Beigās reālie dati būs pārvērsti sarakstā un vārdnīcā.

  1. Atver atbilžu kopsavilkumu un pieraksti populārāko izvēli.
  2. Izveido failu aptauja.py.
  3. Ieraksti sarakstu popularakie_riki = [...] ar trim populārākajām atbildēm.
  4. Ieraksti vārdnīcu, kurā atslēga ir vārds, bet vērtība - viņa teksta ieteikums.
  5. Izdrukā sarakstu ar for ciklu.
  6. Izdrukā vārdnīcu ar .items().
  7. Pieraksti vienu secinājumu: kāpēc izvēles atbildes der sarakstam, bet teksts - vārdnīcai.

Gatavs, kad: kods izdrukā gan trīs populārākos rīkus, gan vismaz divus nosauktus ieteikumus.

Papildu uzdevums - Izrēķini procentus

Ja pamatdarbs ir gatavs, pārvērs balsu skaitu procentos.

  1. Izveido vārdnīcu, kurā atslēga ir atbilde, bet vērtība - balsu skaits.
  2. Izrēķini kopējo balsu skaitu ar ciklu.
  3. Izrēķini katrai atbildei procentus.
  4. Izdrukā tos ar :.0f formatējumu.
  5. Pārbaudi, vai visi procenti kopā dod aptuveni 100.

Gatavs, kad: izdrukātie procenti summējas aptuveni līdz 100.
