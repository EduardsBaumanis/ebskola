Atkārtojuma tests: 4.6 Noslēguma projekts: Skaitļu minētājs

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Jautājumi

1. Ko izdrukā šis kods? 
def salidzina(minetais, patiesais):
    if minetais < patiesais:
        return "par mazu"
    if minetais > patiesais:
        return "par lielu"
    return "trāpīts"

print(salidzina(15, 10))

15 nav mazāks par 10, tāpēc pirmā pārbaude neizpildās. 15 > 10 ir True, un funkcija atgriež "par lielu". Atkārto: 4.6 — 1. uzdevums — Uzraksti salidzina() funkciju ↗

2. Kāpēc salidzina() mājienu atdod ar return, nevis izdrukā ar print()?

Spēles ciklam jāzina atbilde, lai izlemtu, vai beigt ar break. print() tikai parāda tekstu, bet neatdod vērtību. Atkārto: 4.6 — Teorija: funkcijas sadala spēli pārbaudāmās daļās ↗

3. Ja salidzina() beigās nebūtu rindas return "trāpīts", ko atgrieztu salidzina(10, 10)?

10 nav ne mazāks, ne lielāks par 10, tāpēc neviens return neizpildās. Funkcija bez return atgriež None. Atkārto: 4.6 — 1. uzdevums — Uzraksti salidzina() funkciju ↗

4. Kur jāraksta meginajumi = 0, lai mēģinājumu skaits būtu pareizs?

Ja skaitītāju nulle ciklā, tas katrā solī sākas no jauna. Pirms cikla to uzstāda vienreiz, un ciklā tikai palielina. Atkārto: 4.6 — 3. uzdevums — Pievieno mēģinājumu skaitu ↗

5. Failā 46.py ir rinda from spele_46 import spele. Kā tajā palaiž spēli?

from … import ieved funkciju tieši, tāpēc to izsauc bez moduļa nosaukuma. Atkārto: 4.6 — Darba uzdevuma gaita ↗
