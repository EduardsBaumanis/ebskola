Atkārtojuma tests: 14.3 Metodes un self

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Par tevi

Jautājumi

1. Kas ir metode?

Metode ir objekta uzvedība. Caur self tā piekļūst tā objekta datiem, kuram to izsauc. Atkārto: 14.3 — Teorija: Metodes — objekta uzvedība ↗

2. Ko izdrukā šis kods? 
class Dalibnieks:
    def __init__(self, vards, energija=100):
        self.vards = vards
        self.energija = energija

    def sanem_punktus(self, punkti):
        self.energija = max(0, self.energija - punkti)

d = Dalibnieks("Anna")
d.sanem_punktus(30)
d.sanem_punktus(200)
print(d.energija)

Pēc pirmā izsaukuma ir 70. Otrajā 70 − 200 = −130, bet max(0, …) izvēlas lielāko, tātad 0. Atkārto: 14.3 — 2. uzdevums — Liec metodei mainīt objekta stāvokli ↗

3. Tu izdzēs self no rindas def apraksts(self): un izsauc dalibnieks.apraksts(). Kas notiek?

Izsaucot dalibnieks.apraksts(), Python pats padod objektu kā pirmo argumentu. Bez self tam nav vietas. Atkārto: 14.3 — 1. uzdevums — Uzraksti pirmo metodi ar self ↗

4. Ko izdrukā šis kods? 
class Dalibnieks:
    def __init__(self, energija):
        self.energija = energija

    def vai_aktivs(self):
        return self.energija > 0

d = Dalibnieks(0)
print(d.vai_aktivs())

0 > 0 ir False. Metode atgriež vērtību, tāpēc to var lietot if nosacījumā. Atkārto: 14.3 — 3. uzdevums — Pievieno metodi, kas atgriež atbildi ↗

5. Ko izdrukā šis kods? 
class Dalibnieks:
    def __init__(self, vards, energija, temps):
        self.vards = vards
        self.energija = energija
        self.temps = temps

    def sanem_punktus(self, punkti):
        self.energija = max(0, self.energija - punkti)

    def gajiens(self, merkis):
        merkis.sanem_punktus(self.temps)

marta = Dalibnieks("Marta", 120, 15)
zvans = Dalibnieks("Zvans", 60, 8)
marta.gajiens(zvans)
print(zvans.energija, marta.energija)

Marta veic gājienu pret Zvanu ar saviem 15 punktiem: Zvana enerģija 60 − 15 = 45, bet Martas paliek 120. Atkārto: 14.3 — Teorija: Metodes — objekta uzvedība ↗
