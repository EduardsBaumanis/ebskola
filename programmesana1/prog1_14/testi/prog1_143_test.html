Atkārtojuma tests: 14.2 Konstruktori un atribūti

Pieci jautājumi par iepriekšējo nodarbību. Katram jautājumam izvēlies vienu atbildi. Pēc iesniegšanas redzēsi pareizās atbildes, un rezultāts tiks nosūtīts skolotājam.

Jautājumi

1. Kad Python izsauc metodi __init__?

__init__ ir konstruktors: rinda Dalibnieks("Marta") izveido objektu un uzreiz izsauc __init__. Atkārto: 14.2 — Teorija: __init__ — objekta dzimšana ↗

2. Ko nozīmē self rindā self.vards = vards konstruktorā?

self.vards ir objekta atribūts, bet vards — parametrs, kas atnāca izsaukumā. Atkārto: 14.2 — Teorija: __init__ — objekta dzimšana ↗

3. Ko izdrukā šis kods? 
class Dalibnieks:
    def __init__(self, vards, energija=100, klase="kapteinis"):
        self.vards = vards
        self.energija = energija
        self.klase = klase

d = Dalibnieks("Marta")
print(d.vards, d.energija, d.klase)

Parametriem energija un klase ir noklusējuma vērtības, tāpēc tos var izlaist. Atkārto: 14.2 — 2. uzdevums — Pievieno noklusējuma vērtības ↗

4. Konstruktors ir def __init__(self, vards, energija):. Kas notiek ar Dalibnieks() bez argumentiem?

Argumentu skaitam jāsakrīt ar parametriem, kuriem nav noklusējuma vērtības. Python nosauc trūkstošos: vards un energija. Atkārto: 14.2 — 1. uzdevums — Pārraksti klasi ar __init__ ↗

5. Kas notiek, palaižot šo kodu? 
class Dalibnieks:
    def __init__(self, vards, energija=100):
        if energija <= 0:
            raise ValueError("Enerģijai jābūt pozitīvai")
        self.vards = vards
        self.energija = energija

d = Dalibnieks("Anna", -5)

raise aptur objekta izveidi ar tavu kļūdas tekstu. Tā klase pati neļauj izveidot bezjēdzīgu objektu. Atkārto: 14.2 — 3. uzdevums — Pārbaudi datus konstruktorā ↗
